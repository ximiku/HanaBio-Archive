# 第一章 绪论

## 一、传染病

- 特点：
  - 病原性：每种传染病都由特异的病原体引起
  - 传染性：传染病与其它类别疾病的主要区别
  - 地方性：某些传染病的中间宿主受地理条件、气温条件变化的影响，常局限于一定的地理范围发生
  - 季节性：传染病的发病率在年度内有季节性升高和降低
  - 流行性、免疫性
  - 注意：季节性和流行性并非传染病的共有特征
- 环节：传染源、传播途径、易感人群
- 感染：
  - 再感染：同一传染病在完全免疫后经过一段时间后，被同一种病原体再次感染
  - 重复感染：某种传染病发病后痊愈前被同一病原体再次感染[血吸虫、疟疾、丝虫]
  - 复发：发病过程中疾病接近痊愈时，病原体再次繁殖使症状重新出现[伤寒]
  - 再燃：症状已经缓解但体温尚未正常而复上升，症状略加重[伤寒]
- 分类：
  - 血液传染病：由寄生在人体血液和淋巴中的病原体引起，以吸血昆虫为媒介的传染病
  - 消化道传染病：通过病人排泄物传播，通过进食进入体内的传染病
  - 呼吸道传染病：通过呼吸道进入体内的传染病
  - 体表传染病（接触传染病）：寄生于皮肤和体表黏膜的病原体引起，通过接触传播的传染病

## 二、学说及人物

- 巴斯德：
  - 病原菌学说：疾病的发生是由病原菌导致的
  - 巴斯德免疫法：减毒疫苗的研究
  - 巴氏消毒法、酒石酸旋光性的发现、鹅颈瓶实验
  - 狂犬病、鸡霍乱、炭疽病、蚕病的研究
  - 地位：微生物学奠基人
- 科赫：
  - 证病律（科赫法则）：①在每病例中都出现相同的微生物，且在健康者不存在
    - ②从宿主分离出这样的微生物并纯培养
    - ③从纯培养接种健康敏感的宿主，同样疾病重复发生
    - ④从试验发病的宿主中能再次培养出这种微生物
  - 平板划线法
  - 地位：细菌学（医学微生物学）奠基人

## 三、微生物的共性

- 体积小、面积大：
  - 比面积：表面积/体积
  - 地位：其他四个特性的来源
- 吸收多、转化快：微生物高速生长和合成大量代谢产物的物质基础

- 适应强、易变异
- 分布广、种类多

# 第二章 原核生物

## 第一节 细菌

- 细菌：一类细胞细短、结构简单、胞壁坚韧、多以二分裂方式繁殖和水生性较强的原核生物
- 特点：偏好中性和弱碱性

## 一、细胞的形态、构造和功能

### （一）形态和染色

- 形态：
  - 球菌
  - 杆菌：最为常见
  - 螺旋菌：
    - 分类：
      - 弧菌：螺旋不足一环的螺旋菌
      - 螺菌：螺旋2~6环的螺旋菌
      - 螺旋体：螺旋6环以上的螺旋菌
    - 特点：最为少见
- 大小：0.5~1μm
- 染色法：
  - 死菌：
    - 正染色：简单染色法
      - 鉴别染色法：革兰氏染色法、抗酸性染色法、Giemsa染色法
        - 芽孢染色法：孔雀石绿染色
    - 负染色：
      - 荚膜染色法：炭黑染色
  - 活菌：美蓝（亚甲蓝）或TTC染色法

## 二、构造

### 1、细菌细胞的一般构造

- 细胞壁：
  - G+：
    - 特点：厚度大，化学成分简单
    - 肽聚糖：
      - 聚糖：NAG和NAM交替连接形成的糖链
      - 肽：
        - 四肽尾：L-Ala→D-Glu→L-Lys→D-Ala
        - 肽桥：变化多样而构成肽聚糖的多样性
          - 氨基酸种类多[四肽尾中氨基酸、Asp、Gly、Ser、Thr]
    - 磷壁酸：结合于G+细菌细胞壁上的一种酸性多糖
      - 成分：甘油磷酸和核糖醇磷酸
      - 分类：
        - 壁磷壁酸：与肽聚糖NAM共价结合，含量随培养基成分变化
        - 膜磷壁酸（脂磷壁酸）：跨越肽聚糖层并与膜磷脂共价结合，含量固定
      - 作用：
        - 浓缩阳离子，提升酶活力
        - 储藏元素
        - 调节自溶素活力
        - 噬菌体受体和表面抗原
        - 增强对宿主细胞的粘连，避免被白细胞吞噬，抵抗补体
  - G-：
    - 特点：厚度薄，层次多，成分复杂
    - 肽聚糖：四肽尾第三个氨基酸为m-DAP（内消旋二氨基庚二酸）
      - 无肽桥，前后单体仅通过甲四肽尾的D-Ala羧基与乙四肽尾的m-DAP氨基相连
    - 外膜：
      - 成分：
        - 脂多糖：G-细菌细胞壁最外层的一层较厚的类脂多糖类物质
          - 分布：外膜外侧
          - 组成：脂质A、核心多糖和O-特异链
          - 作用：
            - 浓缩阳离子，提升酶活力
            - 内毒素的物质基础
            - 选择透过性：抵抗药物，吸收营养
            - 噬菌体受体和表面抗原
        - 磷脂：分布于外膜内侧
        - 外膜蛋白：
          - 脂蛋白：使外膜与内壁肽聚糖层紧密连接
          - 孔蛋白
    - 周质空间：外膜和细胞膜间的狭窄胶质空间
      - 内含物：水解酶、合成酶、运输蛋白等
  - 抗酸细菌：
    - 定义：细胞壁中含有大量分枝菌酸等蜡质的特殊G+细菌[分枝杆菌]
    - 特点：
      - 被酸性复红染色后，不像其他G+被盐酸乙醇脱色
      - 生长极其缓慢，但具高度抗药性
      - 类脂含量极高，肽聚糖含量很低
      - 染色反应类似G+，但细胞壁结构为G-
    - 分枝菌酸：连接于阿拉伯糖和半乳糖上的超长链β-羟脂肪酸，由磷酯键与肽聚糖相连
    - 索状因子：分枝杆菌表层的一种糖脂
      - 作用：引起菌体聚集
      - 地位：分枝杆菌致病性的原因
  - 古菌：
    - 特点：无肽聚糖，有些含假肽聚糖
    - 假肽聚糖：N-乙酰葡糖胺和N-乙酰塔罗糖胺糖醛酸以β-1，3-糖苷键连接而成
      - 具3肽侧链和单谷氨酸肽桥
      - 不含D-氨基酸
  - 缺壁细菌：
    - 分类：
      - L型细菌：遗传性稳定的细胞壁缺损菌株
      - 原生质体：人工除去细胞壁的菌株
        - 特点：
          - G+最易形成
          - 对相应噬菌体缺乏敏感性
          - 不能进行正常的鞭毛运动
          - 不能细胞分裂
      - 球状体（原生质球）：残留部分细胞壁[G-外膜]
      - 支原体
    - 特点：油煎蛋样菌落
  - 革兰氏染色：
    - 过程：
      - 结晶紫初染
      - 碘液媒染：与结晶紫形成不溶于水的复合物
      - 乙醇脱色：最关键的步骤
      - 沙黄/复红复染
    - 结果：
      - 阳性：紫色[真菌]
      - 阴性：红色[大肠杆菌]
    - 成因：G+细胞壁厚且肽聚糖层次多而交联致密，遇脱色剂处理时，因失水使网孔缩小，而且由于不含类脂而不会露出缝隙，保留结晶紫和碘的复合物；G-细胞壁薄且肽聚糖层次少而交联度差，且类脂被乙醇溶解，结晶紫和碘的复合物渗出
- 细胞膜：
  - 特点：
    - 所有细菌的细胞膜上均含PG，G-富含PE，分枝杆菌具PI
    - PC偶见于G-，不存在于G+
  - 间体（中体）：细胞膜内褶形成的囊状结构
    - 特点：多见于G+
    - 位置：
      - 表层：酶的分泌
      - 深层：DNA复制、分配和细胞分裂
    - 其他功能：氧化磷酸化、细胞壁合成、芽孢形成
  - 古菌：疏水尾为异戊二烯单位组成
    - 亲水头和疏水尾之间以醚键连接
    - 存在单分子膜、单双分子混合膜
    - sn-3位可连接多种基团
    - 独特脂质

|  | G+ | G- |
| --- | --- | --- |
| 结构 | 肽聚糖含量高、层数多、厚度厚 | 肽聚糖含量少、层数少、厚度薄 |
| 特有成分 | 磷壁酸 | 脂多糖和外膜 |
| 其他成分 | 类脂和蛋白少 | 类脂和蛋白多 |
| 抗性 | 机械抗性强，对磺胶和青霉素敏感，不抗溶<br>菌酶 | 机械抗性弱，对磺胶和青霉素不敏感，抗溶<br>菌酶 |
| 抗生素 | 对链霉素、氯霉素和四环素不敏感 | 对链霉素、氯霉素和四环素敏感 |
| 敏感性 | 对碱性染料、阳离子去污剂、叠氮化钠敏感 | 对碱性染料、阳离子去污剂、叠氮化钠敏感 |
| 抗逆 | 抗干燥，部分可产出芽孢 | 不抗干燥，不产芽孢 |
| 运动方式 | 多数不运动，少数使用周毛 | 运动或不运动，运动方式多样 |
| 营养方式 | 多为化能有机营养 | 营养方式多样 |

- 细胞质和包涵体：
  - 细胞质：不流动
  - 储藏物：
    - 碳源：糖原[大肠杆菌]
      - 聚-β-羟丁酸：
        - 特点：被尼罗蓝和苏丹黑染色
        - 作用：储存能量、碳源和降低渗透压
      - 硫粒
    - 氮源：藻青素、藻青蛋白[蓝细菌]
    - 磷源：异染粒（迂回体）（捩转菌素）（偏聚磷酸）
      - 特点：被美蓝或甲苯胺蓝染成红紫色
      - 作用：储存能量、磷源和降低渗透压
  - 磁小体：外有磷脂、蛋白或糖蛋白膜包裹的Fe3O4[G-趋磁细菌]
    - 作用：借助鞭毛引导细菌游向最适环境
  - 羧酶体：内含Rubuiso的内含物[蓝细菌]
  - 气泡：被蛋白质膜包裹的空泡
    - 作用：调节相对密度使其漂浮在最适水层
    - [蓝细菌]
- 核区：原核生物特有的无核膜包裹、无固定形态的原始细胞核

### 2、细菌细胞的特殊构造

- 糖被：
  - 分类：
    - 荚膜：包裹在单个细胞上，有固定层次，层次厚
    - 微荚膜：包裹在单个细胞上，有固定层次，层次薄
    - 黏液层：包裹在单个细胞上，松散而不固定
    - 菌胶团：包裹在细胞群上
  - 成分：
    - 多糖
    - 多肽
    - 多肽和多糖
    - 蛋白质
  - 染色：
    - 炭黑：荚膜和微荚膜的负染色
  - 功能：
    - 保护、附着
    - 储藏养料、堆积代谢废物
    - 选择透过性、信息识别
    - 菌种鉴定
    - 药物、生化试剂、污水处理、工业原料
- S层：包围在原核细胞细胞壁外、由大量糖蛋白或蛋白质亚基以方块形或六角形方式排列的连续层
  - 位置：
    - G+：肽聚糖表面，部分具双层
    - G-：细菌外膜
    - 古菌：取代细胞壁
  - 作用：
    - 保护和附着
    - 选择透过性
    - 进入白细胞
- 鞭毛：
  - 分类：
    - G-：
      - 结构：
        - 钩形鞘（鞭毛钩）：连接基体和鞭毛丝
        - 鞭毛丝
        - 基体：
          - L环：连接细胞壁外膜
          - P环：连接肽聚糖
          - S-M环：靠近周质空间，快速旋转
          - C环：位于细胞膜和细胞质之间，快速旋转
      - 能量：1000质子~1周
    - G+：
      - 特点：基体仅有分离的S环和M环
  - 注意：鞭毛的生长依靠其顶部的自我装配而非基部延伸
  - 拴菌实验：
    - 步骤：将单毛菌的游离端用相应抗体牢固地拴在载玻片上，然后观察该细胞的行为
    - 结果：细菌不断打转
    - 意义：证明了“旋转论”的正确性
  - 分布：
    - 弧菌、螺菌：普遍着生鞭毛
    - 杆菌：
      - 假单胞菌：均端生鞭毛
      - 其他：周生鞭毛或不长鞭毛
    - 球菌：一般无鞭毛｛动球菌具鞭毛｝
  - 着生方式：
    - 端生：翻滚运动，方向多变，运动速度快[霍乱弧菌]
    - 周生：直线运动，运动速度慢[肠杆菌科、芽孢杆菌科]
    - 侧生
    - 周质鞭毛：螺旋体细胞表面的2条被细胞壁包裹的固定型鞭毛
      - 运动方式：通过快速旋转使细胞表面的螺旋凸纹不断伸缩移动，从而推动细胞拔塞钻状快速前进
- 菌毛：（纤毛）（伞毛）（线毛）（须毛）
  - 长在细菌体表的纤细、中空、短直且数量较多的蛋白质类附属物
  - 特点：
    - 直接着生于细胞膜上
    - 多数存在于G-致病菌
  - 作用：粘附
- 性毛：
  - 特点：数量很少
  - 位置：G-的雄性（供体菌）
  - 作用：
    - 传递遗传物质
    - 噬菌体受体
- 芽孢：某些G+在生长发育后期，在细胞内形成的一个圆形和椭圆形、厚壁、含水量低、抗逆性强的休眠体
  - 结构：
    - 芽孢囊：产芽孢菌的营养细胞外壳
    - 芽孢：
      - 胞外壁：脂蛋白，降低透性[部分具有]｛某些G+亦可｝
      - 芽孢衣：疏水角蛋白，抗酶解、抗药物、多价阳离子难以通过
      - 皮层：芽孢肽聚糖和DPA-Ca，渗透压高，含水量大，耐热
      - 核心：
        - 芽孢壁：细胞壁
        - 芽孢质膜：细胞膜
        - 芽孢质：含DPA-Ca和其他细胞质成分
        - 核区：含小酸溶性芽孢蛋白，保护DNA
  - 芽孢形成：DNA浓缩，细胞不对称分裂，较小部分变为前芽孢；前芽孢形成双层隔膜提高抗热性；在双层隔膜间填充肽聚糖，再合成DPA-Ca（吡啶二羧酸钙），开始形成皮层；皮层脱水使折光率提高；芽孢衣合成完成；皮层合成完成，芽孢成熟，抗热性出现；芽孢囊裂解
  - 芽孢萌发：
    - 活化：
      - 诱发：短期热处理、酸性、强氧化剂
      - 特点：可逆作用
    - 出芽：
      - 萌发剂：L-丙氨酸、Mn、表面活性剂和葡萄糖
      - 抑制剂：D-丙氨酸、碳酸氢钠
    - 生长：感受态
  - 染色：DPA和Tb结合后在紫外线照射下发出绿色荧光
  - 耐温性：芽孢＞孢子＞营养体
- 孢囊：部分固氮菌在外界缺乏营养的条件下，营养细胞外壁加厚、细胞失水形成的抗旱不抗热的休眠体
- 伴孢晶体（δ内毒素）少数芽孢杆菌产生的碱溶性糖蛋白昆虫毒素｛可攻击昆虫和线虫｝
  - 控制者：质粒
  - C3-41杀蚊剂：由芽孢和伴胞晶体组成

### （三）细菌的繁殖

### 1、裂殖

- 二分裂：一个细胞在其对称中心形成一个隔膜，进而分裂成两个完全相同的子细胞
  - 不等二分裂：
    - 柄细菌：一个有柄不运动，一个有鞭毛运动
- 三分裂[暗网菌]
- 复分裂[蛭弧菌]

### 2、芽殖

- 芽生细菌：通过芽殖进行繁殖的细菌

## 二、细菌的群体形态

### （一）固体培养基的群体形态

- 菌落：固体培养基上以母细胞为中心的一堆肉眼可见的、有一定形态构造等特征的子细胞群体
  - 形态：
    - 运动能力弱：较小、较厚、边缘圆整
    - 运动能力强：较大、较薄、边缘多缺刻
    - 有糖被：大型、透明、蛋清状
    - 有芽孢：粗糙、干燥、不透明
- 菌苔：将大量分散细胞密集接种在固体培养基的较大表面上连成一片的菌落
- 生物被膜：细菌分泌胞外多糖附着于自然物体表面形成的一种由细菌群体组成的膜状构造
  - 作用：
    - 保护
    - 创造合适的小环境
    - 促进物质和信息交换
    - 提供营养物
  - 结果：抗生素、抗体失效和疾病久治不愈

### （三）在液体培养基中的群体形态

- 菌醭：好氧型细菌在液面上大量生长形成的特征性的、厚薄有差异的白霉？
- 菌膜，不停的形成的、粘附在生物或其他物体表面的细菌薄膜？

## 第二节 放线菌

- 放线菌：一类偏好弱碱性，主要以丝状生长和孢子繁殖的陆生性较强、革兰氏阳性菌｛少量G-｝
- 泥腥味：放线菌代谢产物
- 分布：含水量较低、有机物较丰富和弱碱性的图样
- 特点：绝大多数属于有益菌

## 一、放线菌的形态和构造

### （一）链霉菌

- 营养生长：无隔菌丝、多核单细胞
- 基内菌丝体：（基质菌丝）（营养菌丝）（一级菌丝）
  - 特点：色浅、较细
  - 作用：吸收、排泄
- 气生菌丝（二级菌丝）：
  - 特点：颜色较深、直径较粗
  - 去向：孢子丝
- 孢子丝：通过横割分裂产生分生孢子
  - 形态：多数左旋

### （二）其他放线菌特有的形态和构造

### 1、基内菌丝会断裂成大量杆菌状体的放线菌[诺卡氏菌]

### 2、菌丝顶端形成少量孢子的放线菌[单胞菌、双胞菌、多胞菌]

### 3、具有孢囊并产生孢囊孢子的放线菌[孢囊链霉菌]

### 4、具有胞囊并产生游动孢子的放线菌[游动放线菌]

## 二、放线菌的繁殖

- 特点：
  - 自然条件：通常借助形成孢子进行繁殖，少数为基内菌丝分裂繁殖
  - 液体培养：很少形成孢子，但各种菌丝片段都有繁殖功能
  - 孢子形成仅横割分裂一种
- 横割分裂：细胞膜内陷或细胞膜和细胞壁同时内陷，再由外而内收缩分割孢子
- 繁殖方式：
  - 孢子：
    - 分生孢子：最为常见
    - 孢囊孢子：有或无鞭毛
  - 菌丝：基内菌丝断裂
    - 任何菌丝片段：多种放线菌均可进行

## 三、群体特征

### （一）在固体培养基上

- 菌落：小型、干燥、不透明、表面呈致密的丝绒状，上有一层彩色的干粉
  - 连接紧密，难以挑取
  - 正反面颜色不一致
  - 在菌落边缘的琼脂平面有变形现象
- 成因：气生菌丝

### （二）在液体培养基上

- 液面和瓶壁交界处贴着一圈菌苔，培养液清而不混，其中悬浮着许多珠状菌丝团，一些大型菌丝团沉在瓶底

## 第三节 蓝细菌

- 特点：
  - 体积较大，壁外常有黏液鞘进行滑行运动
  - 脂肪酸含有两至多个双键
- 运动方式：粘液滑行
- 细胞：
  - 异形胞：专司固氮
  - 静息孢子：休眠细胞
  - 藻殖段（链丝段）（连锁体）：繁殖
  - 内孢子：繁殖

## 一、支原体

- 支原体：一类无细胞壁，介于独立生活和细胞内寄生生活之间的最小型原核生物
- 植原体（类支原体）：侵染植物的支原体
- 特点：
  - 细胞很小，可以通过滤菌器
  - 无细胞壁，细胞膜含甾醇支持细胞
  - 菌落小，油煎蛋状，能在营养丰富的培养基上生长
  - 兼性厌氧
  - 基因组很小，弥散分布于细胞质中
  - 对抑制蛋白合成和多烯类抗生素抗生素敏感
- 疾病：牛胸膜肺炎
  - 丛枝病、矮缩病、黄化病

## 二、立克次氏体

- 立克次氏体：专性寄生于真核细胞内的G-微生物
- 类立克次氏体：侵染植物的立克次氏体
- 特点：
  - 细胞大，大多不能通过滤菌器
  - 细胞形态多样
  - 大多在真核细胞内专性寄生
  - 不能利用葡萄糖和有机酸，只能利用谷氨酸和谷氨酰胺
  - 基因组很小
  - 对抗生素敏感、对热敏感
- 疾病：斑疹伤寒、恙虫病、Q热
- 机制：寄生于虱、蚤等节肢动物消化道上皮细胞，细胞破裂后随粪便排出；虱、蚤叮咬人体时排粪，人体抓痒时从伤口进入血流，在血细胞中大量繁殖并产生内毒素

## 三、衣原体

- 衣原体：在真核细胞内营专性能量寄生的小型G-原核生物
- 特点：
  - 有细胞壁，仅复制期具有肽聚糖，因此对β-内酰胺类抗生素敏感
  - 缺乏产生能量的酶系，无法产生ATP、GTP
- 生活史：原体：小球状，厚壁致密，不运动，不生长，抗干旱，有传染性，RNA：DNA=1：1
  - 传播方式：空气传播
  - 始体（网状体）：大球状，薄壁脆弱，生长快，可分裂，无传染性，RNA：DNA=3：1
    - 特点：通过二分裂可在细胞中繁殖产生包涵体微菌落
  - 包涵体：微菌落
- 疾病：鹦鹉热、沙眼、肺炎

# 第二章 真核微生物的形态、构造和功能

## 第一节 概述

## 一、真核生物和原核生物的比较


|  | 真核生物 | 原核生物 |
| --- | --- | --- |
| DNA含量 | 低 | 高 |
| 生物固氮 | 无 | 部分有 |
| 专性厌氧 | 几乎无 | 常见 |
| 化能合成 | 无 | 部分有 |
| 鞭毛运动 | 挥动 | 旋转 |
| 鞭毛 | 9+2 | 简单鞭毛 |

| 糖脂 | 有 | 无 |

## 二、真核微生物的主要类群

- 植物界：显微藻类
- 动物界：原生动物
- 菌物界：粘菌
  - 假菌：
    - 相同点：具菌丝体、异养生活
    - 区别：
      - 细胞壁以纤维素和半纤维素为主
      - 水生种类无性繁殖产生双鞭毛游动孢子，陆生种类产生孢囊孢子
      - 生活史以二倍体占优
    - 来源：藻类失去叶绿体与真菌平行进化产生
  - 真菌：
    - 类型：
      - 酵母菌：单细胞真菌
      - 霉菌：丝状真菌
      - 蕈菌：大型子实体真菌
      - 注意：以上三种类群并非分类依据，只是一种俗称
    - 特点：
      - 无叶绿素，异养吸收营养
      - 产生大量无性和有性孢子进行繁殖
      - 多数含几丁质，多数具有发达菌丝体
      - 陆生性较强
- 二态真菌：具有酵母和霉菌形态的真菌

## 三、真核微生物的细胞构造

### （一）细胞壁

- 真菌：
  - 低等真菌：纤维素
  - 酵母菌：葡聚糖
  - 高等真菌：几丁质
- 藻类：纤维素

### （二）鞭毛和纤毛

- 9+2鞭毛：
  - 9二联管：
    - A亚纤维：13条原纤维
    - B亚纤维：10条原纤维
  - 中央鞘：包裹中央微管
  - 2单管：13条原纤维
- 9+0基体：
  - 9三联管：
    - A亚纤维：13条原纤维
    - B亚纤维：10条原纤维
    - C亚纤维：10条原纤维
  - 特点：不具中央鞘和中央微管

## 五、细胞器

- 膜边体：（须边体）（质膜外泡）[真菌]
  - 菌丝四周的质膜和细胞壁间由单层膜包裹的细胞器
  - 来源：高尔基体或内质网
  - 功能：分泌水解酶、合成细胞壁
- 几丁质酶体（壳体）：活跃于菌丝体顶端细胞的单层膜包裹的细胞器
  - 功能：运输几丁质酶以保证菌丝不断向前延伸[真菌]
- 氢化酶体：单层膜包裹的球状细胞器
  - 组成：氢化酶、氧化还原酶、铁氧还蛋白和丙酮酸
  - 存在：反刍动物瘤胃[厌氧性原生动物和厌氧性真菌]

## 第二节 酵母菌

- 酵母菌：能发酵糖类的单细胞真菌
- 特点：
  - 个体以单细胞非菌丝状态存在
  - 多出芽生殖
  - 发酵糖类产能，部分可利用烃类
  - 细胞壁常含甘露聚糖
- 生境：含糖量较高、酸性较大的水生环境，有时在油田或炼油厂附近可找到
- 单细胞蛋白（微生物蛋白）：工农业废料人工培养的微生物菌体
  - 特点：不是纯蛋白质而是混合物组成的细胞质团
- 代表：白色念珠菌、新型隐球菌

## 二、酵母菌细胞的形态和构造

- 酵母纤维素：酵母细胞壁的主要成分｛还有少量几丁质｝
  - 特点：三明治状
  - 结构：
    - 外层：甘露聚糖
    - 中层：
      - 蛋白质：酶
    - 内层：
      - 葡聚糖：赋予细胞壁机械强度的主要成分
- 蜗牛消化酶：
  - 作用：水解酵母纤维素和酵母子囊壁
  - 来源：玛瑙螺
- 细胞膜：含丰富的麦角固醇
- 细胞核：定型细胞核
- 其他：液泡、线粒体、少数具过氧化物酶体
  - 2μm质粒：位于细胞核内的质粒，复制受核基因组控制
  - 特点：缺氧时线粒体无嵴和氧化磷酸化功能

## 三、酵母的繁殖方式和生活史

- 假酵母（拟酵母）：只进行无性繁殖的酵母菌
- 真酵母：进行有性生殖和无性生殖的酵母菌
  - 有性：子囊孢子[酵母]

### （一）无性繁殖

- 芽殖：
  - 假菌丝：长大的子细胞和母细胞不立即分离，其间仅以狭小的面积相连时的细胞串
  - 芽孢子（芽体）
  - 芽痕：芽体和母体分离时在母细胞上留下的痕迹，可有一至多个
  - 蒂痕：芽体和母体分离时在芽孢子上留下的痕迹，任何细胞蒂痕仅一个
  - 地位：酵母菌最普遍的繁殖方式
- 裂殖：与二分裂相似[裂殖酵母]
- 无性孢子：
  - 掷孢子：成熟后孢子喷射而出[掷孢酵母]
    - 特点：用倒置培养基培养时，在皿盖上可看到模糊菌落镜像
  - 厚垣孢子
  - 节孢子[地霉]

### （二）有性繁殖

- 孢子：子囊孢子
- 方式：临近的形态相同，性别不同的细胞伸出一根管状的原生质突起相互接触，局部融合并形成一条通道，再通过质配，核配和减数分裂形成4或8个子核，形成子囊孢子
- 子囊：母细胞

### （三）生活史

### 1、营养体既能以单倍体也能以二倍体形式存在

- 代表酵母：酿酒酵母
- 特点：
  - 一般情况下以营养体出芽繁殖，特定条件下有性生殖
  - 营养体既能以单倍体存在，也能以二倍体存在
- 生活史特点：孢子体产生子囊，子囊孢子产生配子体，配子体接合产生孢子体
  - 孢子体和配子体均可出芽生殖

### 2、营养体只能以单倍体形式存在

- 代表酵母：八胞裂殖酵母
- 特点：
  - 营养细胞单倍体
  - 二倍体细胞不能独立生活
  - 无性生殖为裂殖
- 生活史特点：孢子体产生子囊，子囊孢子产生配子体，配子体接合产生孢子体
  - 只有配子体可以裂殖
  - 子囊产生8个子囊孢子

### 3、营养体只能以二倍体形式存在

- 代表酵母：路德类酵母
- 特点：
  - 营养体为二倍体，不断进行芽殖
  - 单倍体阶段仅以子囊孢子的形式存在，不能独立生活，在子囊内发生接合
- 生活史：孢子体产生子囊，子囊孢子产生配子体，配子体接合产生孢子体
  - 只有孢子体可以芽殖

## 四、菌落

- 相同点：湿润透明光滑、易挑起、质地均匀、正反面颜色一致
- 区别：
  - 颜色单调，往往具有酒香
  - 较大、较厚、较稠、较不透明

## 第三节 丝状真菌——霉菌

- 霉菌：菌丝体发达而不产生大型肉质子实体的真菌
- 地位：植物最主要的病原菌
- 疾病：各种癣
- 生境：分布非常广泛，嗜弱酸性

## 二、霉菌细胞的形态和构造

### （一）菌丝及其延伸过程

- 菌丝：霉菌营养体的基本单位
- 真菌丝：细胞相连且横隔面积与细胞直径一致
  - 无隔菌丝：生长表现为菌丝延长，细胞质增加，核增加
  - 有隔菌丝：多细胞
- 细胞壁：
  - 结构：
    - 顶端：内层几丁质，外层蛋白质
    - 亚顶端（次生壁形成区）：内层几丁质，中层蛋白质，外层葡聚糖蛋白网
    - 成熟区：内层几丁质，中层蛋白质，外层葡聚糖蛋白网，最外层葡聚糖层
  - 隔膜：菌丝内壁向内延伸而成的环片状构造

### （二）菌丝体及其各种分化方式

- 菌丝体：许多菌丝相互交织而成的菌丝集团
  - 营养菌丝体：密布在固体营养基质内部，执行吸取营养物功能的菌丝体
  - 气生菌丝体：伸展到空间的菌丝体

### 1、营养菌丝体的特化形态

- 假根：匍匐菌丝与固体基质处分化出的根状结构
  - 作用：固着和吸取养料[根霉]
- 匍匐菌丝（匍匐枝）：延伸[根霉、毛霉]
- 吸器：吸取宿主内的营养物质[锈菌、霜霉、白粉菌]
- 附着胞、附着枝：附着
- 菌核：休眠[茯苓]
- 菌索：延伸和抗逆[伞菌]
- 菌环和菌网：捕捉线虫等[捕虫菌]

### 2、气生菌丝体的特化形态

- 子实体：可产无性或有性孢子，有一定形状和构造的任何菌丝体组织
- 结构简单的子实体：
  - 无性：分生孢子头（分生孢子穗）、孢子囊
  - 有性：担子
- 结构复杂的子实体：
  - 无性：
    - 分生孢子器：瓶形或球形的、内壁表面或底部产生分生孢子梗的结构
    - 分生孢子座：分生孢子梗紧密聚集成簇，分生孢子在梗顶端形成垫状[瘤座孢科]
    - 分生孢子盘：宿主角质层或表皮下，分生孢子梗簇生形成的盘状结构
  - 有性：
    - 子囊果：
      - 闭囊壳：完全封闭的圆球形[不整囊菌纲]
      - 子囊壳：烧瓶形[核菌纲]
      - 子囊盘：盘状[盘菌纲]

### 3、菌丝体在液体培养时的特化形态

- 菌丝球：真菌在液体培养基中通气搅拌时的特殊构造
- 特点：菌丝体紧密纠缠形成颗粒，均匀悬浮于培养液中

## 第四节 产大型子实体的真菌——蕈菌（伞菌）

- 蕈菌：能形成大型肉质子实体的真菌
  - 组成：多数担子菌和少数子囊菌
- 菌丝分化：
  - 一级菌丝：担孢子萌发形成新菌丝
  - 二级菌丝：一级菌丝发生接合后，质配形成双核二级菌丝，通过锁状联合不断分裂
  - 三级菌丝：二级菌丝分化为菌丝束
  - 子实体：菌丝束形成菌蕾，然后膨大形成
  - 担孢子：子实体成熟后双核菌丝核配，2次分裂｛其中一次减数分裂｝产生4个担孢子
- 锁状联合：两个双核菌丝顶端细胞核间的菌丝壁突起，两核之一进入突起，两核同时进行有丝分裂，产生4个子核，突起中的两核一个留在突起，一个进入尖端形成双核细胞，突起后部形成一个横隔，形成3细胞；突起细胞前端和另一单核细胞接触，融合，单核进入，最终变为双核细胞
- 子实体：
  - 菌盖：位于顶部
    - 表皮：菌丝含不同的色素使菌盖呈现不同的颜色
    - 菌肉、菌褶
  - 菌柄：位于中部
    - 菌环：内菌幕的遗迹
      - 内菌幕：某些伞菌菌盖和菌柄间连接的包膜[竹荪]
    - 菌托：外菌膜的遗迹
  - 菌丝体：位于基部

# 第三章 病毒和亚病毒因子

## 第一节 病毒

- 病毒：一类由核酸和蛋白质组成的超显微非细胞生物
- 特性：
  - 形体极其微小、没有细胞结构、每种病毒只含一种核酸
  - 无产能酶系，也无核酸和蛋白质合成酶系
  - 复制繁殖，离体状态下无生命
  - 对一般抗生素不敏感但对干扰素敏感

### （二）病毒的形态

### 1、典型构造

- 病毒粒：
  - 核衣壳：
    - 核心（基因组）：核酸
    - 衣壳：蛋白质
    - 地位：任何真病毒都具有的基本结构
  - 包膜

### 2、对称体制

- 螺旋对称：
  - 无包膜：
    - 杆状：烟草花叶病毒（TMV）
    - 丝状：M13噬菌体
  - 有包膜：
    - 卷曲：流感病毒（正粘病毒）
    - 弹状：狂犬病毒
- 二十面体对称（等轴对称）：
  - 无包膜：
    - 小型：脊髓灰质炎病毒、Φ174
    - 大型：腺病毒
  - 有包膜：疱疹病毒
- 复合对称：
  - 无包膜：T偶数噬菌体
  - 有包膜：痘苗病毒

- 噬菌斑：噬菌体在菌苔上形成的负菌落
- 空斑：动物病毒在宿主单层细胞上形成的空斑
- 枯斑：植物病毒在植物叶片上形成的枯斑

### （三）代表

- 烟草花叶病毒：最早发现的病毒
- 腺病毒：
  - 实质：动物病毒
  - 疾病：急性咽炎、结膜炎、病毒性肺炎
  - 特点：无包膜、线性双链DNA

    - T奇数噬菌体均为溶源噬菌体
- 流感病毒：H代表血凝素，N代表神经氨酸酶

## 三、4类病毒及其繁殖方式

- 特点：不存在个体生长，同种病毒粒无年龄和大小之分

### （一）噬菌体

### 1、噬菌体的繁殖

- 生殖周期：吸附、侵入、增殖（复制和生物合成）、成熟（装配）、裂解（释放）
- 烈性噬菌体：短时间完成一个生殖周期的噬菌体
- 温和噬菌体：长时间完成一个生殖周期的噬菌体
- 自外裂解：大量噬菌体吸附在同一宿主细胞表面并释放溶菌酶导致细胞裂解
- 裂解量：平均每个宿主细胞裂解产生的子代噬菌体数目

### 2、噬菌体效价及其测定

- 效价（噬菌斑形成单位数）（感染中心数）：每毫升试样中的成熟噬菌体病毒粒数
- 双层平板法：
  - 方式：分别配置含2%和1%琼脂的底层培养基和上层培养基；先用底层培养基在培养皿上浇一层平板，凝固后再将含较浓宿主和待测噬菌体样品的上层培养基加入，保温后计数
  - 优点：
    - 铺平底部使所有的噬菌斑都位于几乎同一平面上，因而大小一致，边缘清晰且无重叠
    - 上层培养基琼脂较少故可形成形态较大的噬菌斑
  - 注意：由于噬菌体并非均有感染力，双层平板法计数出的噬菌体效价总比电镜直接计数的低
- 成斑率：噬菌斑计算出的效价/电镜计算出的效价
  - 噬菌体：＞50%
  - 动植物病毒：≈10%

### 3、一步生长曲线（一级生长曲线）

- 一步生长曲线：定量描述烈性噬菌体生长规律的实验曲线
- 潜伏期：噬菌体的核酸侵入宿主细胞后到第一个病毒粒释放的时间
  - 隐晦期（潜伏前期）：人为裂解宿主细胞后，裂解液仍无侵染性的一段时间
    - 实质：细胞正复制噬菌体核酸和合成其衣壳
  - 胞内积累期（潜伏后期）：人为裂解细胞后，裂解液已有侵染性的一段时间
    - 实质：
      - 实质：细胞开始装配噬菌体
- 裂解期：潜伏期后的宿主细胞迅速裂解，溶液中的病毒粒急速增多
- 平稳期：感染后的宿主细胞几乎全部裂解，溶液中病毒粒效价达到最高

### 4、溶原性

- 溶源现象（溶原性）：温和噬菌体侵入相应宿主细胞后，基因组整合到其基因组上，并随宿主复制同步复制，使温和噬菌体的侵入不引起宿主细胞裂解的现象
- 温和噬菌体：引起溶原性的噬菌体
- 溶源菌：温和噬菌体的宿主
  - 特性：
    - 免疫性：其他同类噬菌体虽可再次感染该细胞，但不能增殖或裂解细胞
      - 成因：细菌编码的阻遏蛋白
    - 溶源转变：前噬菌体引起的溶源菌表型改变
      - 组成：
        - 自发裂解、诱发裂解
        - 复愈性：群体增殖过程中，部分细胞丧失胞内噬菌体
- 存在形式：
  - 游离态：成熟后被释放并有侵染性的游离噬菌体粒子
  - 整合态：已整合到宿主基因组的前噬菌体状态
  - 营养态：前噬菌体脱离宿主基因组处于积极复制，合成和质配的状态
- 例：λ噬菌体｛P1噬菌体以质粒形式存在｝
- 检测方法：将少量溶源菌和大量敏感性指示菌混合，与琼脂培养基混匀后倒入平板，培养形成溶源噬菌斑
  - 敏感性指示菌：遇溶源菌裂解后所释放的温和噬菌体会发生裂解循环
  - 溶源噬菌斑：同心圆状，由透明圈圈着的中央有溶源菌的小菌落
    - 成因：少数溶源菌裂解后侵蚀周围的指示菌菌苔

### （二）植物病毒

- 特点：
  - 一般无包膜
  - 宿主专一性差
  - 无特殊吸附结构而只能以被动方式侵入
  - 侵入宿主细胞后才脱去衣壳
- 实例：马铃薯晚疫病

### （三）人类和脊椎动物病毒

- AIDS（世纪瘟疫）（黄色妖魔）
- 病毒病：流感、肝炎、疱疹、流行性乙型脑炎、狂犬病、SARS、口蹄疫

### （四）昆虫病毒

- 多角体：昆虫病毒在宿主细胞内形成光镜下多角形的包含体
- 成分：包裹若干病毒粒的碱溶性结晶蛋白
- 作用：保护病毒粒免受外界环境的破坏
- 种类：
  - 核型多角体病毒：在昆虫细胞核内增殖，具有蛋白质包含体的杆状病毒
  - 质型多角体病毒：在昆虫细胞质内增殖，具有蛋白质包含体的球状病毒
  - 颗粒体病毒：具蛋白质包含体，但每包含体只含一个病毒粒的杆状病毒

## 第二节 亚病毒因子

- 亚病毒：在核酸和蛋白质中只含其中之一的分子病原体，或由缺陷病毒构成的功能不完整的病原体

## 一、类病毒

- 类病毒：只含ssRNA分子且专性寄生在活细胞里的病原体
- 存在：植物
- 特点：
  - 目前已知的分子最小的可传染致病因子，不编码蛋白
  - 抗热、抗脂溶剂、依赖宿主酶系统进行复制
  - 一般存在于细胞核上，与核仁结合
- 疾病：马铃薯纺锤形块茎病

## 二、拟病毒（类类病毒）（类内类病毒）

- 拟病毒：包裹在真病毒粒中的有缺陷的类病毒
- 辅助病毒：与拟病毒共生的真病毒
- 疾病：绒毛烟斑驳病毒
- 特点：
  - 拟病毒的复制必须依赖辅助病毒的协助
  - 可干扰辅助病毒的复制，减轻其对宿主的危害

## 三、卫星病毒

- 卫星病毒：基因组缺损、必须依赖某形态较大的辅助病毒才能表达的小型伴生病毒
- 特点：侵染细胞起始阶段不需辅助病毒，若存在辅助病毒，则复制转录；反之则以前病毒形式进入潜伏期

## 四、卫星RNA

- 卫星RNA：存在于专一辅助病毒衣壳内，并完全依赖辅助病毒才能复制自己的小分子RNA病原因子
- 特点：
  - 绝大多数为RNA，少数为DNA
  - 多卫星RNA与辅助病毒基因组可存在于同一衣壳中
  - 对宿主植物无独立侵染性
  - 复制和包装全部依赖辅助病毒
  - 不具有mRNA活性，与辅助病毒RNA无同源性
  - 干扰辅助病毒的复制从而降低其增殖量，改变辅助病毒引起的植物病害程度
- 宿主：植物

## 五、阮病毒（普利昂）（蛋白侵染子）

- 阮病毒：不含核酸的传染性蛋白质分子
- 疾病：库鲁病、克雅氏病、GS综合症、疯牛病、羊瘙痒病
- 疾病特点：潜伏期长
  - 中枢系统严重破损[大脑海绵状变形]
- 特点：
  - 毒性很强，无药可治
  - 淀粉样颗粒状、抗逆性极强
  - 无免疫原性
  - 由宿主细胞内基因编码

    - 结果：大肠杆菌阳性，产气肠杆菌阴性

    - 结果：大肠杆菌阴性，产气肠杆菌阳性
  - C实验（柠檬酸盐实验）：
    - 原理：产气肠杆菌能利用柠檬酸钠，产生CO2进而结合产生碳酸钠，导致培养基变碱，使溴麝香草酚蓝由绿变蓝
    - 结果：大肠杆菌阴性，产气肠杆菌阳性

- 反应式：3CO2+12[H]+5ATP→磷酸丙糖
- 起始物：草酰乙酸
- 特点：多数酶与TCA循环相同，但依赖ATP的柠檬酸裂合酶替换柠檬酸合酶
- 分布：绿菌

### （四）羟基丙酸途径

- 反应式：2CO2+4[H]+3ATP→乙醛酸+H2O
- 起始物：乙酰CoA
- 羧化步骤：乙酰CoA羧化为羟基丙酰CoA
  - 羟基丙酰CoA羧化为甲基丙二酰CoA
- 其他步骤：甲基丙二酰CoA→苹果酰-CoA
  - 苹果酰CoA→乙酰CoA+乙醛酸
- 分布：绿弯菌

### 1、生物固氮六要素

### 2、测定固氮酶活力的乙炔还原法

- 经典方法：
  - 克氏定氮法：过于粗放
  - 同位素法：过于烦琐
- 原理：固氮酶可催化2H+2e→H2、H2+C2H2→C2H4
- 步骤：将待测细菌制成悬浮液，放在10%C2H2空气｛好氧菌｝或10%C2H2｛厌氧菌｝的密封容器中，经适当培养后，按不同时间用针筒抽取少量气体至气相色谱仪测定

### 3、生化途径

- 总反应：N2+8[H]+16~24ATP→2NH3+H2+16~24ADP+16~24Pi
- 步骤：Fd或Fld向氧化型固氮二酶还原酶的Fe提供1e使其还原；还原型固氮二酶还原酶与ATP-Mg结合；固氮二酶在Mo上与N2结合，并与固二氮酶还原酶-Mg-ATP复合物反应形成完整的固氮酶；固二氮酶还原酶中1e传递到固氮二酶的Fe上，ATP水解；连续六次使它释放出2个NH3，且必需额外的两次用于产出H2

### 4、固氮酶的产氢反应

- 产氢反应：2H+2e→H2
- 氢化酶：将分子氢重新激活以回收还原力

### （三）好氧菌固氮酶避氧害机制

### 1、好氧性自生固氮菌的抗氧保护机制

- 呼吸保护：固氮菌能以极强的呼吸作用迅速将周围环境中的氧消耗，使细胞周围微环境处于低氧状态
- 构象保护：在高氧分压条件下，部分固氮酶能形成一个无固氮活性但能防止氧害的特殊构象
  - 原因：铁硫蛋白Ⅱ

### 2、蓝细菌固氮酶的抗氧保护机制

- 异形胞：体积大，细胞外具糖脂组成的较厚外膜阻止氧气进入细胞

  - SOD活性高解除氧毒害，呼吸速率快
- 其他：将固氮作用和光合作用进行时间上的分隔
  - 群体中央细胞固氮等

### 3、豆科根瘤菌

- 类菌体：
  - 特点：形状多样、不能繁殖、专门固氮
  - 位置：类菌体周膜内

  - 合成：
    - 球蛋白：植物

# 第六章 微生物的生长及其控制

## 第一节 测定生长繁殖的方法

## 一、测生长量

- 直接法：测干重法
  - 测体积法
- 间接法：
  - 比浊法：用分光光度法测定微生物悬浮液
  - 生理指标法：测含氮量法等
- 适用范围：所有微生物

## 二、计繁殖数

- 直接法：
  - 血球计数板计数：得到的为死菌数+活菌数
  - 活菌染料：
    - 美蓝-酵母：活菌无色、死菌蓝色
    - 吖啶橙：活菌紫外光下橙色，死菌紫外光下绿色
- 间接法：（活菌计数法）
  - 原理：活菌在液体培养基上会使其变混或在固体培养基上形成菌落
  - 平板菌落计数法：将稀释后的菌样浇筑琼脂培养基或涂布琼脂平板，培养后形成菌落并计数
  - 亨盖特滚管培养法
  - 半固体深层琼脂法：试管中的深层半固体琼脂有良好的厌氧性能，并利用其凝固前可稀释，凝固后可代替琼脂平板做菌落计数
- 适用范围：细菌和酵母菌

## 第二节 微生物的生长规律

## 一、微生物的个体生长和同步生长

- 同步生长：通过同步培养的手段使细胞群体中各个体处于分裂步调一致的生长状态
- 环境条件诱导法：氯霉素
  - 细菌芽孢-发芽
  - 藻类光照-黑暗轮换
  - 培养基富含营养-缺乏营养轮换
  - 原生动物短期热休克、酵母菌EDTA或离子载体
- 机械筛选法：
  - 膜洗脱法：
    - 原理：某些滤膜可吸附其相反电荷细胞
    - 方法：将非同步细胞的悬浊液流经此膜，于是一大群细胞被牢牢吸附。然后将滤膜翻转并置于滤器中，其上慢速流下新鲜培养液，最初流出的是未吸附的细胞，不久吸附的细胞开始分裂，在分裂后的子细胞中，一个仍吸附在滤膜上，另一被培养液洗脱；若滤膜面积足够大，收集刚滴落的培养液获得同步细胞

## 二、单细胞培养物的典型生长曲线

- 典型生长曲线：延滞期、指数期、稳定期和衰亡期[细菌和酵母菌]
- 霉菌生长曲线：延滞期、快速生长期、衰亡期
  - 区别：非典型生长曲线缺乏指数生长期
- 生长速率常数（R）：每小时分裂次数

### （一）延滞期（停滞期）（适应期）（调整期）

- 延滞期：少量单细胞微生物接种到新鲜培养液中在开始培养的一段时间内，因正在适应环境没有增长的时期
- 特点：
  - 生长速率常数为0
  - 细胞形态变大或增长
  - RNA含量增加，原生质嗜碱性
  - 合成代谢活跃，对外界不良条件敏感
- 影响因素：
  - 菌种、种子损伤度
  - 接种龄：
    - 短：指数期
    - 长：延滞期、衰亡期
    - 适中：稳定期
  - 接种量：接种量越大，延滞期越短
  - 培养基成分：天然培养基中延滞期较短

### （二）指数期（对数期）

- 指数期：在生长曲线中紧接延滞期的一段细胞数以几何级数增长的时期
- 特点：
  - 生长速率常数R最大，代时最短
  - 细胞进行平衡生长，菌体各个成分均匀
  - 酶系活跃，代谢旺盛
  - 群体生理特性较一致
- 繁殖代数（n）：n=（lgx2-lgx1）/lg2｛lg2≈0.3｝
- 生长速率常数（R）：R=n/（t2-t1）
- 代时（G）：G=1/R
  - 影响因素：
    - 菌种、营养成分、温度
    - 营养物浓度：随着营养物浓度的提高，它对生长速率的影响下降
- 意义：
  - 增殖噬菌体
  - 用于接种

### （三）稳定期（恒定期）（最高生长期）

- 稳定期：新繁殖细胞数与衰亡细胞数相等
- 生长产率常数Y=（x-x0）/（C0-C）｛x细胞干重，C限制性营养物浓度｝
- 特点：
  - 生长速率常数=0
  - 芽孢开始形成
  - 细胞开始积累内含物，形成次生代谢物
- 意义：收获产物和生物测定

### （四）衰亡期

- 衰亡期：新繁殖细胞数小于衰亡细胞数
- 特点：
  - 生长速率常数R＜0
  - 细胞形态多样化，甚至自溶
  - 芽孢杆菌释放芽孢，部分微生物进一步合成或释放次级代谢产物

## 三、微生物的连续培养

- 单批培养（密闭培养）：符合典型生长曲线的培养方式
- 连续培养（开放培养）：向培养容器中连续流加新鲜培养液，使微生物的液体培养物长期维持稳定、高速生长状态的溢流培养技术
- 原理：预防稳定期到来
- 优点：高效、自控、质量稳定、节能
- 缺点：
  - 菌种易于退化
  - 易于污染杂菌
  - 营养物利用率低
- ⑴按控制方式分
- 恒浊器：根据培养器内微生物生长密度，控制培养液流速，取得菌体密度高、生长速率恒定的连续培养器
  - 原理：光电控制
- 恒化器：使培养液流速保持不变并使微生物在低于其最高生长速率的条件下进行生长繁殖的连续培养器
  - 原理：控制某一营养物的浓度使其始终成为生长限制因子
  - 稀释率D=培养基流速/培养器容积

|  | 控制对象 | 控制方法 | 流速 | 生长速率 | 产物 | 应用 |
| --- | --- | --- | --- | --- | --- | --- |
| 恒浊器 | 菌体密度 | 内控制 | 不恒定 | 最高速率 | 大量菌体或与菌体平<br>行的代谢产物 | 生产 |
| 恒化器 | 培养基流速 | 外控制 | 恒定 | 低于最高速率 | 不同生长速率的菌株 | 实验室 |

- ⑵按培养器级数分
- 单级连续培养器：主要用于某微生物代谢产物的产生速率与菌体生长速率平行时
- 多级连续培养器：主要用于某微生物代谢产物的产生速率与菌体生长速率不平行时

## 四、微生物的高密度培养（HCDC）

- HCDC：微生物在液体培养条件下细胞群体密度超过常规培养10倍以上的生长状态或培养技术

## 第三节 影响微生物生长的主要因素

## 一、温度

- 生长温度三基点：最低生长温度、最适生长温度和最高生长温度
- 最适温度：某菌分裂代时最短，生长速率最高的培养温度
  - 注意：最适温度只与生长速率有关，与产率和发酵速率等无关

## 二、氧气

- 微生物：
  - 专性好氧菌：呼吸链完整，以分子氧作为最终氢受体
    - 含SOD和过氧化氢酶
    - [绝大多数真菌、多数细菌、放线菌]
  - 兼性厌氧菌：在有氧时靠呼吸产能，无氧时靠发酵或无氧呼吸产能
    - 含SOD和过氧化氢酶
    - [许多酵母、肠杆菌、变形杆菌]
  - 微好氧菌：在低氧分压下才能正常生长
    - 呼吸链完整，以氧为最终氢受体
    - [霍乱弧菌、螺杆菌]
  - 耐氧性厌氧菌：可在分子氧存在下发酵性厌氧生活
    - 不具呼吸链，但分子氧也无害，依靠专性发酵和底物水平磷酸化获得能量
    - 含SOD和过氧化物酶，无过氧化氢酶
    - [乳酸菌]
  - 厌氧菌：分子氧有毒，依赖呼吸链以外的方式获得能量
    - 细胞内缺乏SOD、细胞色素氧化酶和过氧化氢酶
    - [梭菌、光合细菌、产甲烷菌]
- SOD学说：凡严格厌氧菌就无SOD活力，一般也无H2O2酶活力；
  - 凡具细胞色素系统的好氧菌都由SOD和过氧化氢酶
  - 耐氧性厌氧菌不含细胞色素系统，无过氧化氢酶，但具有SOD
- SOD：
  - Cu-Zn：真核生物细胞质
  - Fe：原核生物
  - Mn：线粒体

## 三、pH

- 变酸：糖类发酵、脂肪水解、生理酸性盐
- 变碱：蛋白质脱羧、生理碱性盐
- 结果：碳氮比高的培养基培养结束后pH通常显著下降，碳氮比低的培养基培养结束后pH通常显著上升
- 调节：
  - 过酸：
    - 快速：加碱中和
    - 持久：加入氮源和提高通气量
  - 过碱：
    - 快速：加酸中和
    - 持久：加入碳源和降低通气量

## 第四节 微生物培养法

## 一、实验室培养法

### （一）固体培养法

### 1、好氧菌的固体培养

- 试管斜面：制作时趁热定量分装于试管内倾斜凝固制成的培养基
  - 优点：厚度增大、营养丰富、不易干燥和开裂
  - 作用：菌种扩大转管与菌种保藏
- 琼脂平板：制作时趁热定量倒在培养皿内凝固成平板的培养基
  - 作用：菌种分离和研究菌类特性
- 克氏扁瓶

### 2、厌氧菌

- 高层培养基：制作时添加还原剂并趁热定量分装于试管内直立凝固制成的培养基[韦荣氏管]
  - 特点：越是深层，氧化还原电势越低
- 厌氧培养皿：
  - Brewer皿：利用特制皿盖创造狭窄空间
  - Bray皿：利用化学反应吸收氧气

## 一、基因突变

### （一）突变类型

- 营养缺陷型：因基因突变丧失合成一些物质的能力，从而不再能够在基本培养基上生长繁殖的变异类型
- 抗性突变性：因基因突变对某化学药物、物理因子或噬菌体的抗性变异类型
- 条件致死突变型：Ts突变株对温度敏感
- 抗原突变型[细胞壁缺陷、荚膜鞭毛成分变异]
- 产量突变型
- 形态突变型

### （四）基因突变自发性和不对应性的实验证明

### 1、Luria变量实验（波动实验）

- 要点：取敏感于T1噬菌体的大肠杆菌指数期的肉汤培养物制成细菌悬液，分管并分别倒入装有T1噬菌体的平板上，分别计算各培养皿上产生的抗噬菌体的菌落数
- 结果：各皿出现的抗性菌落数相差极大
- 结论：抗噬菌体性状的产生并非取决于环境因素，而是早已发生

### 2、Newcombe的涂布试验

- 方法：在12只固体培养皿上涂以相同的T1噬菌体敏感细胞，培养一段时间，取其中6皿喷上T1噬菌体，另6皿重新涂布后配上T1噬菌体
- 结果：最后长出抗T1的菌落重新涂布的远多于直接喷上的
- 结论：抗噬菌体性状的产生并非取决于环境因素，而是早已发生

### 3、Lederberg的影印平板实验

- 方法：将大量对链霉素敏感的大肠杆菌细胞涂布到平板1上，待其长出密集的小菌落后，用影印法接种到平板2上，再影印到含链霉素的平板3上，在平板3上出现抗性菌落。在平板2上找到相应的菌落，将它们加入培养液4，再涂布到平板5→1｛重复｝
- 产物：高纯抗链霉素菌落

### （二）诱变育种

### 1、诱变育种的基本环节

- 存活率突变率正变率高产率 投产率
- 出发菌株→绝大多数死亡
  - 少数存活→多数未变
    - 少数突变→多数负变
      - 少数正变→多数幅度小
        - 少数幅度大→多数不宜投产
          - 少数适宜投产
- 表型延迟：遗传型虽已突变，但表型要经染色体复制、分离和细胞分裂后才表现出来的假象
- Ames实验：
  - 原理：鼠伤寒沙门氏菌的组氨酸营养缺陷型菌株在基本培养基上不能生长
  - 方法：将待测液与与鼠肝匀浆液保温后吸入滤纸片中，再将滤纸片放置于上述平板中央
  - 结果：
    - 不含诱变剂：平板上无大量菌落产生
    - 高浓度诱变剂：纸片周围有一抑制圈，外周出现大量菌落
    - 适当浓度诱变剂：纸片周围长有大量菌落
  - 注意：许多化学物质进入机体后会在肝脏作用下变为有害物质故需加入鼠肝匀浆液保温
    - 所用的试验菌株最好也是DNA修复酶的缺陷菌株
- 特点：随着诱变剂剂量的提高，正向突变占比减少而负向突变占比增高；并且突变超过峰值时由于新产生的突变数已无法抵消突变造成的致死量导致突变率也下降

### 3、3类突变株的筛选方法

- 产量突变：
  - 琼脂块培养法：将诱变后菌株的分生孢子悬液均匀涂布平板，长出稀疏的小菌落后用打孔器取出长有单菌落的琼脂块，整齐地移入灭菌空培养皿继续培养，把琼脂块转移到已混有供试菌种的大块琼脂平板上，分别测定各小块的抑制圈并判断其抗生素效价
- 抗药性突变：
  - 梯度平板：含有某药物浓度梯度的琼脂培养基平板
  - 方法：制备梯度平板→涂布细胞悬液→取下抗药性菌落
  - 应用：通过筛选抗抗代谢药物的菌株来选择对应类似物的高产菌株
- 营养缺陷突变：基本培养基[-]、完全培养基[+]、补充培养基[A][B]、野生型[A+B+]、营养缺陷型[A+B-]
  - 原养型：营养缺陷型突变株经回复突变或重组后产生的菌株
  - 筛选：诱变剂处理
    - 淘汰野生型：
      - 抗生素法：青霉素/制霉菌素只抑制快速生长的细菌/真菌
      - 菌丝过滤法：
        - 适用对象：丝状生长的真菌和放线菌
        - 原理：基本培养基中野生型菌株的孢子能发芽成菌丝而缺陷性菌株不能；使用滤孔较大的擦镜纸过滤，重复数遍后可浓缩营养缺陷型
    - 检出缺陷型：
      - 夹层培养法：先在培养皿底部倒一层不含菌的基本培养基，添加一层混有诱变菌的基本培养基，再浇一层不含菌的基本培养基；经培养后对首次出现的菌落用记号笔标在皿底，再添加一层完全培养基；新长出许多较小菌落为营养缺陷型
      - 限量补充培养法：将诱变处理后的细胞接种在含微量蛋白胨的基本培养基平板上，野生型迅速长大，缺陷性生长缓慢
      - 逐个检出法：把经诱变剂处理后的细胞涂在完全培养基上，长大后将菌落分别接种在基本培养基上和另一完全培养基上，位置严格对应，如果生长不对应，则为营养缺陷型
      - 影印平板法
    - 鉴定缺陷型：
      - 生长谱法：混有供试菌的基本培养基点加微量营养物观察周围出现菌落

## 第三节 基因重组和杂交育种

## 一、原核生物的基因重组

### （一）转化

- 转化：受体菌直接吸收供体菌的DNA片段而获得后者部分遗传性状的现象
- 转化子：通过转化形成的杂交后代
- 转化因子：离体的DNA片段
  - 特点：最易结合的是dsDNA片段，但只有被水解成ssDNA才能进入细胞
- 转染：使用病毒核酸感染宿主增殖出一群正常病毒后代
- 注意：某些真菌制成原生质体后亦可实现转化

### （二）转导

- 转导：以缺陷噬菌体为媒介，把供体细胞DNA携带到受体细胞中，通过交换与整合使其获得前者部分性状
- 转导子：通过转导而成的杂交后代

### 1、普遍转导

- 普遍转导：通过极少数完全缺陷噬菌体对供体菌基因组上的小片段DNA误包而将其遗传性状传递给受体菌
- 特点：
  - 媒介通常为溶源噬菌体
  - 感染复数（m.o.i.）＜1：每个受体细胞至多感染一个完全缺陷噬菌体，细胞不可能溶源化，也不显示免疫性，更不会溶源裂解，而是由外源DNA与同源区段配对并双交换整合
- 分类：
  - 完全转导：外源DNA在其内进行交换、整合或复制并稳定表达
  - 流产转导：外源DNA在其内既不进行交换、整合和复制，也不迅速消失，仅稳定地表达
    - 特点：子细胞仅1个拥有DNA，另1个拥有部分酶且随着分裂逐级稀释
    - 表现：在选择培养基上形成一个微小菌落

### 2、局限转导

- 局限转导：通过部分缺陷的温和噬菌体将供体菌的少数特定基因携带到受体菌中并整合重组
- 分类：
  - 低频转导：通过一般溶源菌释放的噬菌体进行的转导
    - 低频转导裂解物：含有极少数局限转导噬菌体的裂解物
      - 特点：无正常噬菌体致溶源化的能力而只可整合
    - 结果：低频转导裂解物在低感染复数的条件下感染宿主就可获得少数局限转导子
  - 高频转导：对双重溶源菌进行诱导产生的缺陷噬菌体
    - 方法：
      - 低频转导裂解物在高感染复数的条件下感染宿主产生双重溶源菌
      - 双重溶源菌：同时感染正常噬菌体和缺陷噬菌体的受体菌
      - 助体噬菌体：双重溶源菌中的正常噬菌体
        - 作用：补偿缺陷噬菌体的不足
    - 高频转导裂解物：含有一半局限转导噬菌体的裂解物
    - 结果：高频转导裂解物在低感染复数的条件下感染宿主就可获得较多局限转导子

### 3、溶源转变

- 溶源转变：正常温和噬菌体感染宿主使其发生溶源化时，因噬菌体基因整合到宿主的核基因组上，使宿主获得除免疫性外的新遗传性状的现象
- 特点：噬菌体基因提供性状，获得的性状往往随噬菌体的消失而消失
- 白喉杆菌：被β噬菌体感染后才具有毒素

### （三）接合

- 接合：供体菌通过性毛和受体菌直接接触，把F质粒或其携带的不同长度的核基因组片段传递给后者，使其获得若干新遗传性状的现象
- 接合子：通过接合获得新遗传性状的受体细胞
- F+（雄性）：细胞内存在一至多个F质粒，并在细胞表面着生一至几条性菌毛的菌株
  - 特点：与雌性接触时将雌性转化为雄性，并传递遗传信息
  - 过程：
    - F质粒一条DNA单链特定位置裂口；
    - 滚环复制：断裂链逐步解开并以5’端为先导通过性菌毛转移
      - 互补链边滚动边以自身为模板合成另一互补单链
    - 环化
- F-（雌性）：细胞内无F质粒，细胞表面也无性菌毛
  - 特点：与雄性菌株或F’菌株接合接受F质粒或F’质粒，亦可与Hfr结合接受DNA
- Hfr（高频重组）F质粒整合到染色体特定位点上
  - 特点：
    - 重组频率极高
    - 越位于Hfr染色体前端的基因进入F-细胞的可能越高，而性别决定基因位于最后
  - 接合中断法：构建几株有不同整合位点的Hfr菌株，与F-菌株接合，并在不同时间使接合中段，最后根据F-中出现Hfr菌株中各种性状的时间早晚画出环状染色体图
- F’：
  - F’质粒：Hfr菌株F质粒不正常切离染色体时重新形成游离的，但携带整合位点临近染色体的F质粒
  - 初生F’菌株：产生F’质粒的菌株
  - 次生F’菌株：由F’菌株和F-菌株结合产生的F’菌株
    - 部分双倍体
  - 性导（F质粒转导）以F’质粒传递供体基因

## 二、真核微生物的基因重组

- 有性杂交：不同遗传型的两性细胞间发生的接合和随之进行的染色体重组
- 准性生殖：同种不同菌株的体细胞发生的融合，不借减数分裂而导致低频基因重组产生重组子
  - 本质：自然条件下真核微生物体细胞间的自发性原生质体融合
  - 过程：
    - 菌丝联结：发生于同种不同菌株的体细胞间
      - 特点：概率极低
    - 质配：形成异核体
    - 核配：概率低
    - 体细胞交换（有丝分裂交换）和单倍体化
  - 特点：异核体和杂合二倍体均不稳定，但异核体分离产生原有的两种基因型，杂合二倍体则通过不均等分裂产生2n+1和2n-1两种，2n-1进一步丢失染色体变为n，最终产生重组单倍体

|  | 准性生殖 | 有性生殖 |
| --- | --- | --- |
| 亲本细胞 | 形态相同的体细胞 | 形态或生理上分化的性细胞 |
| 异核体 | 有 | 无 |
| 双倍体细胞形态 | 与单倍体基本相同 | 与单倍体明显不同 |

- 准性杂交：
  - 代表：灰黄霉素生产[荨麻青霉]
  - 步骤：
    - 选择亲本：营养缺陷型
    - 强制异合：将两菌株产生的分生孢子相互混匀，用基本培养基倾注培养皿平板，未混合的分生孢子各倒1个基本培养基平板作为对照
    - 移单菌落：将平板上长出的单菌落移到基本培养基斜面上
    - 验稳定性：从斜面上洗下孢子，用基本培养基倾注夹层平板，培养后再倒一层完全培养基，如在基本培养基上仅出现少数菌落，而完全培养基上出现大量菌落，则为异核体；若在基本培养基上出现大量菌落，而在完全培养基上未明显增加，则为杂合二倍体
    - 选出良种

## 第一节 微生物分布和菌种开发

## 一、微生物分布

- 数目：细菌＞放线菌＞霉菌＞酵母菌＞藻类＞原生动物
- 生物劣化：
  - 霉变：霉菌引起的劣化

  - 腐烂：含水量高的产品经细菌生长、繁殖后引起的变软、发臭
  - 腐蚀：由硫酸盐还原细菌、铁细菌或硫细菌引起的金属材料的侵蚀、劣化
- 火鸡X病：黄曲霉素引起
- 正常菌群：生活在健康动物各部位，量大、稳定、有益的微生物种群
  - 条件致病菌：正常菌群失调时原先某些不致病的正常菌群成员变为的致病菌
  - 内源感染：条件致病菌引起的感染
- 微生态制剂：
  - 益生菌剂：分离自正常菌群，以高含量活菌为主体，改善宿主特定部位微生态平衡的生物制剂
  - 益生元（双歧因子）：人体不能消化吸收的低聚糖类营养物质
- 悉生动物：人为接种纯种微生物的动物或植物
- 无菌动物：在体内外不存在任何正常菌群的动物
  - 特点：
    - 免疫功能低下、有关器官萎缩、非致病菌也易感染并能致病

- 硝化作用：氨氧化转变为硝酸[硝化细菌]

### （二）细菌沥滤（细菌浸矿）（细菌冶金）

- 原理：利用化能自养细菌对金属矿物中的硫或硫化物进行氧化，使它不断生产和再生酸性浸矿剂，并将低品位矿石中的铜等金属以硫酸铜的形式不断溶解
- 过程：溶矿→置换→再生浸矿剂

## 一、水体污染

- 自净作用：江河、琥珀、湿地等自然水体对投入其中的少量污染物具有很强的自体净化能力

- 赤潮：发生在河口等咸水区的水体因富营养化而导致其中的蓝细菌、浮游植物和原生动物的爆发性增殖、聚集，从而使水体呈现红棕色

## 三、结局

- 隐性传染：宿主免疫力很强，而病原菌的毒力较弱，数量较少，传染后只引起宿主轻微损害
- 带菌状态：病原体仅被限制在某一局部无法大量繁殖，长期处于相持的状态
- 显性传染：宿主免疫力很弱，或病原菌的毒力较强，数量较多，传染后病原体很快大量繁殖并损伤宿主
  - 毒血症：病原体被限制在宿主的局部病灶，其所带毒素进入血流引起全身症状[白喉、破伤风]
  - 菌血症：病原体侵入血流后传播至远处病灶[伤寒]
  - 败血症：病原体侵入血流后在血流中大量繁殖[绿脓杆菌]
  - 脓毒血症：引起败血症的同时在许多脏器中化脓

### （一）抗原（Ag）

### 1、抗原

- 抗原：能诱导机体发生免疫应答并能与相应抗体或T淋巴细胞受体发生特异性免疫反应的大分子物质
- 特性：
  - 免疫原性（抗原性）：能刺激机体产生免疫应答能力的特性
    - 物质基础：相对分子质量大
      - 分子结构复杂
      - 异物性：某抗原与其刺激的机体的自身物质的理化性质差异程度
        - 本质：胚胎期淋巴细胞未接触过的物质
        - 注意：体内物质也可具有异物性[晶状体蛋白、辐射产物等]
  - 免疫反应性（反应原性）：能与免疫应答的产物发生特异反应的特性
- 完全抗原：同时具有免疫原性和反应原性的抗原
- 半抗原（不完全抗原）：缺乏免疫原性，具有免疫反应性的抗原[青霉烯酸、青霉噻唑、核酸、类脂、多糖]
  - 特点：与适当蛋白载体结合后变为完全抗原
  - 实质：抗原决定簇
  - 分类：
    - 复合半抗原：无免疫原性但具免疫反应性[荚膜多糖]
    - 简单半抗原（阻抑半抗原）：无免疫原性也无免疫反应性，能与抗体发生不可见结合，阻止抗体与相应的完全抗原或复合半抗原相结合的可见反应[荚膜多糖的水解产物]
- 抗原决定簇（抗原表位）：位于抗原表面可决定抗原特异性的特定化学基团，或构成抗原的免疫原性所必需的最少亚单位数
- 抗原结合价：能与抗体相结合的抗原决定簇的总数
- 细菌抗原：
  - 表面抗原：包围在细菌细胞壁外层的抗原[荚膜、微荚膜]
  - 菌体抗原：存在于细胞壁、细胞膜和细胞质上的抗原
  - 鞭毛抗原：H抗原
  - 菌毛抗原
  - 外毒素和类毒素

### 2、共同抗原和交叉抗原

- 特异性抗原：在一个同时存在多种抗原的复杂抗原系统中，只有该系统自身特有的抗原
- 共同抗原（类属抗原）（交叉反应抗原）：多种复杂抗原系统共有的抗原
- 交叉反应：甲乙两菌存在共同抗原而引起甲菌抗原（或抗体）与乙菌抗体（或抗原）间发生较弱的免疫反应
- 吸收反应：将一多价特异抗血清与其共同抗原反应，再把此抗原、抗体复合物去除，即可去除其共同抗体
- 凝集吸收反应：共同抗原为颗粒状的吸收反应

### 6、抗体形成的机制

- 克隆选择学说：①在能产生抗体的高等动物体内，天生存在着大量具有不同抗原受体的免疫细胞克隆，每个克隆，每个克隆产生特异抗体的能力并非决定于外来抗原物质，而是决定于其固有的，在接触抗原前已经存在的遗传基因
  - ②某一特定抗原一旦进入机体，即可与相应淋巴细胞表面上的惟一一个与其相应地特异性受体结合，在无数克隆中选择一个与其相对应的克隆，促使其增殖分化
  - ③生物处于胚胎期时，其免疫系统的发育不完善，这时某一淋巴细胞克隆若接触相应抗原，则其被消除或抑制，形成禁忌克隆，引起免疫耐受性
  - ④禁忌克隆可复活或发生突变，从而与自身抗原成分起反应
- 体细胞突变学说：VJCD序列之间的排列组合增加了抗体蛋白的多样性

  - 单克隆抗体改造
- 应用：
  - 免疫磁珠：利用外面包裹者单克隆抗体的磁珠与相应的生物大分子特异结合，再用磁铁收集磁珠
  - 免疫毒素（药物导弹）：抗肿瘤单克隆抗体或细胞因子与毒素偶联，特异性地将毒素导向肿瘤细胞

## 第四节 免疫学方法及其应用

## 二、抗原-抗体反应的一般规律

- 特异性、可逆性
- 定比性：抗原一般多价，抗体一般二价，比例合适时才能交联成网络，任一过量则形成可溶性复合物
- 阶段性：第一阶段时间短，不可见；第二阶段时间长，可见
- 条件依赖性

## 二、抗原-抗体间的主要反应

- 调理：抗体与细菌表面的抗原结合后促进吞噬细胞吞噬
- 调理素：抗体

### （一）凝集反应（直接凝集反应）

- 凝集反应：颗粒性抗原与相应地抗体在合适条件下反应并出现肉眼可见的凝集团
- 特点：反应前一般应稀释抗体
- 成因：凝集原体积较大，抗原决定簇相对较少
- 方法：
  - 直接法：
    - 肥达试验：诊断伤寒或副伤寒
    - 玻片凝集试验
  - 间接法：
    - 间接凝集实验（被动凝集反应）：将可溶性抗原吸附于适当载体成为颗粒抗原产生凝集反应
    - 反相间接凝集实验：将抗体吸附于适当载体成为颗粒抗原产生凝集反应[甲胎蛋白]

### （二）沉淀反应

- 沉淀反应：可溶性抗原与相应地抗体在适当比例和合适条件下反应并出现肉眼可见的沉淀物

### 1、经典方法

- 环状试验：在小口径试管内加入已知抗体，将稀释待检抗原加在抗体层上，数分钟后出现白色沉淀环为阳性
  - 应用：
    - Ascoli试验：检测炭疽芽孢杆菌
- 絮状反应：将抗原和相应抗体在试管内或凹玻片上混匀，经一段时间后出现肉眼可见的絮状颗粒沉淀为阳性
  - 应用：
    - 康氏实验：诊断梅毒

### 2、现代方法

- 单向免疫扩散法：（单向琼脂扩散法）
  - 方法：将抗原溶液滴加在混有抗体的琼脂小孔中，抗原扩散后在小孔周围适当位置形成一沉淀环，根据环的面积进行抗原定量测定
- 双向免疫扩散法：（双向琼脂扩散法）
  - 方法：将抗原、抗体分别滴加在琼脂介质的不同小孔中，使它们相对扩散，在两孔间合适部位形成沉淀线
  - 特点：灵敏度较差、工作时间较长
  - 结果：
    - 两沉淀线完全融合：两抗原的抗原决定簇完全相同
    - 两沉淀线交叉：两抗原的抗原决定簇完全不同
    - 沉淀线在后者一方形成一突出小刺：两抗原的抗原决定簇部分相同
- 对流免疫电泳法：
  - 方法：抗原和抗体分别置于凝胶板电场负-正极附近的小孔中；通电后，抗原向正极移动，抗体向负极移动，结果在两孔间合适的抗原、抗体浓度处会形成一条沉淀线
  - 特点：灵敏度高、工作时间短
  - 本质：双向免疫扩散-电泳
- 火箭电泳法：
  - 方法：在已经混有抗体的琼脂凝胶板上挖一小孔，向孔内滴加抗原并进行电泳，结果会沿电泳方向形成火箭形沉淀线，沉淀线的高度与抗原量成正比
  - 本质：单向免疫扩散-电泳
- 双向免疫电泳：
  - 方法：先将血清用电泳分离出各个成分，然后切下凝胶版转移至另一加有抗血清的凝胶上，进入垂直方向的第二次电泳，形成火箭形沉淀线
  - 本质：血清免疫电泳-火箭电泳

### （三）补体结合实验

- 补体结合实验：有补体参与，并以绵羊红细胞和溶血素是否发生溶血反应作为指示的高灵敏度测定抗原和抗体间特征性反应的免疫学方法
- 原理：
  - 补体可与任何抗原和抗体的复合物结合
  - 指示系统如遇还未被抗原-抗体复合物结合的游离补体，就会出现可见的溶血反应
- 试验系统：补体-被检抗体（或抗体）-抗原（或被检抗原）
- 指示系统：溶血素-绵羊红细胞
- 方法：将试验系统和指示系统混合，不溶血则为阳性，溶血则为阴性
- 作用：测定未知抗体或抗原
- 瓦瑟曼实验（华氏试验）：检测梅毒

### （四）中和试验

- 中和试验：由特异性抗体抑制相应抗原的生物学活性的反应
- 实例：测定风湿病患者体内是否存在抗链球菌O抗体
- 适用对象：外毒素、酶催化活性、病毒感染性

## 三、免疫标记技术

### （一）免疫荧光技术（荧光抗体法）

- 免疫荧光技术：将结合有荧光素的荧光抗体与相应的抗原反应，借以提高免疫反应灵敏度

### （二）免疫酶技术

- 辣根过氧化物酶：
  - 成分：酶蛋白和铁卟啉
  - 底物：二苯基联苯胺（DAB）
  - 产物：棕褐色

### 1、酶联免疫标记法（ELISA）

- 双抗体夹心法：将含已知抗体的抗血清吸附在微量滴定板上，洗涤；加待测抗原，洗除过量抗体，加入梅联抗抗体，洗除过量抗体，加入底物
- 间接免疫吸附沉淀法：将抗原吸附在微量滴定板上，用缓冲液洗涤。加入待检抗血清，用缓冲液洗涤。加入酶联抗抗体，用缓冲液洗涤，加入底物
- 斑点酶免疫吸附法：用硝酸纤维素膜取代微量滴定板
  - 最终显色反应为不溶于水的有色沉淀物

### 2、酶标记免疫定位

- 免疫组织化学（酶标免疫组织化学）：用组织切片取代固相抗原的斑点酶免疫吸附法
- 免疫印记（Western blot）：经SDS-PAGE电泳分离蛋白质，转印入硝酸纤维素膜，然后用酶标或同位素标抗体对条带进行显色或鉴定

### （三）放射免疫测定法

- 放射免疫标记法：利用放射性同位素标记的抗原或抗体检测相应抗体或抗原的高灵敏度免疫分析

### （四）免疫电镜

- 免疫电镜：采用电子致密物质标记的抗体与相应抗原特异性结合后借电镜检出这一标记复合物

## 一、人工自动免疫类生物制品

### （一）常规疫苗

### 1、疫苗

- 疫苗：
  - 疫苗：用细菌以外的微生物制成的生物制品
  - 菌苗：用细菌制成的生物制品
- 分类：
  - 活疫苗（减毒疫苗）：人工育种使病原体减毒或从自然界筛选无毒或弱毒菌株制成疫苗[卡介苗]
    - 优点：
      - 能继续繁殖
      - 接种剂量低、作用持久
    - 缺点：不易保存、较不安全
  - 死疫苗（灭毒疫苗）：杀死病原体但仍保留原有免疫活性的疫苗
    - 优点：安全、保存容易
    - 缺点：
      - 不能继续繁殖
      - 接种剂量大、免疫持续时间短

### 2、类毒素

- 吸附类毒素：将类毒素吸附在明矾或磷酸铝等佐剂上延缓它在体内的吸收、延长作用时间和增强免疫效果
- 实例：百白破三联制剂

### 3、自体疫苗

- 自体疫苗：用从病人自身病灶处分离出来的病原体制成的死疫苗

### （二）新型疫苗

- 亚单位疫苗：保留病原体中有效抗原成分，去除其无效或有害成分的化学纯品疫苗
- 化学疫苗：用化学方法提取病原体中有效免疫成分制得的化学纯品疫苗
- 多肽疫苗（化学合成疫苗）：用人工合成的高免疫原性多肽片段制成的疫苗
- 基因工程疫苗：利用基因工程操作构建重组基因序列，并用它表达的免疫原性强而无活性的多肽制成的疫苗
- DNA疫苗（核酸疫苗）：用编码抗原的基因制成的疫苗
  - 优点：制备容易、稳定性强、安全稳定、免疫期长
  - 缺点：需要大量DNA
- 抗独特型抗体疫苗：抗体刺激机体产生的抗体制成的疫苗
  - 优点：
    - 克服抗原物质难以提纯的困难和解决免疫原性较弱的问题
    - 避免使用有害病原体
    - 取代蛋白质以外的抗原

## 二、人工被动免疫类生物制品

### （一）特异性免疫治疗剂

- 抗血清（免疫血清）：机体经人工免疫后引起的含某种主要抗体的血清
- 抗毒素：类毒素多次注射马等大型动物，待其产生大量特异性抗体后，经采血分离并浓缩纯化后制得的样品
  - 特点：再次注射同类动物源抗毒素时可能产生超敏反应
- 抗病毒血清：用病毒作为抗原免疫动物后取其含抗体的血清制成
- 抗菌血清
- 免疫球蛋白制剂：
  - γ-球蛋白：从健康人血浆中提取，主要含IgG和IgM的精制多价抗体
  - 胎盘球蛋白：从健康产妇胎盘中提取，主要含IgG
  - 单克隆抗体

### （二）非特异性免疫治疗剂——免疫调节剂

- 免疫调节剂：能增强、促进和调节免疫功能的非特异性生物制品
- 特点：增强促进和调节免疫功能，但对正常人不起作用
- 转移因子（TF）：由淋巴细胞产生的低分子核苷酸和多肽的复合物
  - 特点：无免疫原性，有种属特异性
  - 分类：
    - 特异性TF：从疾病治愈者淋巴细胞中提取，特异性转移某一特定细胞免疫功能
    - 非特异性TF：从健康人的淋巴细胞中提取，非特异性增强细胞免疫功能
- 白介素2（胸腺细胞刺激因子）（T细胞生长因子）：活化T细胞产生的多效能淋巴因子
- 胸腺素、细胞毒T细胞、小棒杆菌、干扰素
- 卡介苗：牛型结核分支杆菌制成、预防肺结核病的优良减毒疫苗
