# 结构化生物学笔记 PDF 转 Markdown 规范

## 1. 适用范围

本规范用于把具有明显视觉缩进和冒号链的生物学 PDF 笔记转换为 Markdown。目标是忠实还原原文件的标题、包含关系和并列关系。视觉缩进是重要证据，但必须结合编号、上下文和基本知识层级校正，不能机械套用坐标，也不能借机改写原文知识内容。

## 2. 来源优先级

1. PDF 是正文、顺序、标点和层级关系的最终来源。
2. 同名 `.doc` 或 `.docx` 只用于检查是否漏段、乱序或出现明显提取错误，不作为缩进来源。
3. 如果 PDF 与 Word 内容不一致，以 PDF 为准。
4. 老式 `.doc` 可在 macOS 使用 `textutil -convert txt -stdout` 抽取正文，但抽取结果通常不能保留可靠缩进。
5. 不使用外部生物数据库补写或校订，不同步 Readwise，不增加源文件没有的解释。

## 3. 基本输出要求

- 输出为 UTF-8 Markdown，保存到 `trans-md/`。
- 每份源笔记生成一个同名 `.md` 文件。
- 普通插图、照片、解剖图、流程图和曲线图忽略，不插入图片、图片占位符或 Markdown 图片语法。
- 图像形式的表格属于结构化正文，必须重建为 Markdown 或 HTML 表格。
- 栅格化正文属于正文，必须 OCR 后按正常标题和列表规则转换，不能因其是图片对象而忽略。
- 删除独立页码，不保留 PDF 分页标记。
- 保留原文的全角标点、括号、箭头和方括号形式，不做 NFKC 等会改变原字符形式的归一化。
- 不改写生物学内容。只允许修复经 PDF 页面明确确认的提取错字、断字或换行。
- 明确的数学、统计、物理或化学公式使用 LaTeX。短公式写为行内 `$...$`；独立公式可作为单独的列表项，例如 `- $s^2=\frac{\sum(x-\bar{x})^2}{n-1}$`。
- 在 LaTeX 中正确使用 `^`、`_`、`\frac`、`\sum`、`\sqrt`、希腊字母和绝对值。表格单元格中的公式同样使用行内 LaTeX。
- LaTeX 只负责还原排版，不得依据学科常识改写源 PDF 的公式、补全缺失项或修正疑似笔记错误；无法可靠识别的式子保留 PDF 可确认的原字符形式。

## 4. 推荐处理顺序

必须按以下顺序处理，不能先生成列表再猜测换行：

1. 用 `pdfplumber` 按字符或单词坐标抽取每页内容。
2. 根据纵坐标把字符组合成 PDF 物理行，并保留每行的 `x0`、`x1`、页码和纵坐标。
3. 删除页脚中的独立页码，并将页面区域区分为可提取正文、栅格化正文、表格和普通插图。
4. 对栅格化正文和图像表格执行本地 OCR；普通插图继续忽略。
5. 先把自动换行产生的多个物理行合并为一个逻辑条目。
6. 根据缩进生成候选包含关系，再用编号连续性、分类关系和上下文语义校正。
7. 识别标题，并检查同级编号是否采用一致的结构表达。
8. 解析冒号链和多值标签，按页面纵坐标插入已重建的表格和 OCR 正文。
9. 输出 Markdown，并逐页对照 PDF 复核。

## 5. 自动换行与真实并列项

### 5.1 应当合并的自动换行

下一物理行同时具有以下特征时，应优先视为上一行的续行：

- 上一行接近当前版心右边界，或者明显在词语、短语、句法中间中断。
- 下一行从当前条目值的悬挂缩进位置继续，而不是回到新的同级标签位置。
- 下一行没有新的标题、编号、分类标签或独立条目标志。
- 合并后的句子在语法和内容上连续。

中文续行直接连接，不人为增加空格。连续英文、拉丁学名或数字应依据原始字符间距保留必要空格。

正确示例：

```text
细胞特点：细胞小而等径，薄壁，排列紧密；原生质浓厚，液泡小而分散，细胞
            核位于中央并占较大体积；通常缺少后含物
```

应转换为：

```markdown
- 细胞特点：细胞小而等径，薄壁，排列紧密；原生质浓厚，液泡小而分散，细胞核位于中央并占较大体积；通常缺少后含物
```

连续三行也要全部合并。例如“维管形成层”的“方式”应为一个逻辑值：

```markdown
- 方式：薄壁细胞脱分化并逐渐向两侧扩展形成条状，后与木质部脊处的中柱鞘相接构成连续波浪环；由于不等速、起始时间不同的细胞分裂活动，维管形成层变为圆状；此后维管形成层的活动等速进行
```

### 5.2 不应合并的真实并列项

以下情况应保留为不同条目：

- 下一行出现新的标题、编号或冒号标签。
- 下一行回到同级或更浅的视觉缩进。
- 上一行没有抵达版心边界且语义已经完整，下一行是同一标签下的另一个值。
- 方括号内容在 PDF 中明确作为独立示例行存在，且前一行语义完整。
- 两行分别描述不同分类、部位、特点或作用。

例如侧生分生组织的两个“细胞特点”是两个并列值，不能因缩进相同而合并：

```markdown
- 细胞特点：
  - 长梭形，薄壁；原生质不浓厚，高度液泡化；
  - 活动受季节变化影响，具周期性
```

居间分生组织的三个分布位置也必须保持并列：

```markdown
- 分布：
  - 禾本科节间基部[拔节、抽穗]
  - 葱、蒜、叶基部
  - 落花生雌蕊柄基部
```

不能只靠固定的 `x1` 阈值自动决定。刚好写满一行的完整条目也可能抵达右边界，所有边界候选都需要结合下一行结构和页面图像复核。

## 6. 标题规则

- `第...章`、`第...部分` 转为一级标题 `#`。
- `第...节` 和浅层 `一、二、三、...` 转为二级标题 `##`。
- 浅层 `（一）（二）...` 和 `1、2、3、...` 通常转为三级标题 `###`，但必须结合其父级结构判断。
- 只有承担章节导航作用的编号才转标题。较深层分类可用嵌套列表，不要为了套用固定规则而把一个分类从父项中拆出去。
- 同一组并列编号必须采用一致表达。例如 `1.简单花序` 与 `2、复合花序` 都属于“无限花序”，应同时作为它的子级，不能一个是普通列表、另一个却成为脱离父项的标题。
- 其他内容根据 PDF 视觉缩进转换为嵌套无序列表。

## 7. 缩进和冒号链

### 7.1 视觉缩进

- 每一级稳定的视觉缩进通常代表一级包含关系，但不是不可推翻的绝对规则。
- PDF 换页、手工排版、编号宽度和文本框位置都可能使同级内容出现不同横坐标。
- 层级先参考每个逻辑片段的起始横坐标，再由编号连续性、术语的上下位关系和上下文内容复核。
- 同一物理行中的不同冒号片段可能位于不同视觉列，必须分别解析其层级。

### 7.2 内容和知识层级校正

- 编号连续的分类应优先视为并列项，例如 `[一]无限花序` 与 `[二]有限花序`。
- 定义、特点、开放顺序、组成和作用应归入它们描述的对象。
- 明确的子类型应放在共同父项下，例如简单花序和复合花序都属于无限花序；螺状、蝎尾状聚伞花序属于单歧聚伞花序。
- “补充”内容如果讨论整个大节，不应因位置相邻而挂到前一个分类下。例如禾本科小穗结构是“花序”的补充，不是有限花序的子项。
- 可以为表达层级而调整 Markdown 标题或列表层次，也可以把单值定义紧凑到父项同一行，但不得增加 PDF 没有的知识、实例或结论。
- 当视觉缩进与明确的编号或知识上下位关系冲突时，以能够同时解释编号和内容的层级为准，并回看页面确认不是自动换行。

“花序”应形成类似以下骨架：

```markdown
### （五）花序

- [一]无限花序（总状类花序）
  - 1.简单花序
    - 总状花序：...
    - 穗状花序：...
  - 2、复合花序
    - 圆锥花序：...
- [二]有限花序
  - 单歧聚伞花序：...
  - 二歧聚伞花序：...
- 补充：
  - 禾本科：...
```

### 7.3 冒号链

冒号链需要逐级拆开。例如：

```text
质体：叶绿体：作用：光合作用等
```

应转换为：

```markdown
- 质体：
  - 叶绿体：
    - 作用：光合作用等
```

`叶绿体`、`有色体（杂色体）`、`白色体` 在 PDF 中处于同一视觉列时，必须作为 `质体` 下的并列子级，不能把 `叶绿体` 留在 `质体` 同一行。

## 8. 单值标签和多值标签

### 8.1 单个值

标签只有一个逻辑值时保持紧凑形式：

```markdown
- 位置：储藏细胞
```

不要无故拆成父子两行。

### 8.2 多个值

同一标签具有多个真实并列值时，标签单独作为父项，所有值放在下一层并列：

```markdown
- 特点：
  - 唯一类囊体堆叠成基粒的质体
  - 凸透镜形或球卵形
```

首个值与后续值必须处于同一级，不能把首个值留在标签行上而只缩进后续值。

同样规则适用于 `作用`、`位置`、`分布`、`组成`、`方式`、`来源` 等标签。

## 9. 典型目标结构

```markdown
- 质体：
  - 叶绿体：
    - 作用：光合作用等
    - 位置：绿色植物绿色细胞｛绿色细胞内不一定含叶绿素，可能为花青素｝
    - 光合色素：主要含叶绿素，还有胡萝卜素、叶黄素
    - 特点：
      - 唯一类囊体堆叠成基粒的质体
      - 凸透镜形或球卵形
  - 有色体（杂色体）：
    - 作用：
      - 积累淀粉和脂质
      - 吸引昆虫等动物传粉
    - 位置：花瓣、果实等
    - 光合色素：胡萝卜素、叶黄素
    - 特点：
      - 无类囊体结构
      - 形态多样
  - 白色体：
    - 作用：淀粉和脂肪的合成中心
    - 位置：储藏细胞
    - 特点：
      - 无光合色素
      - 类囊体膜破裂并相互融合成片层体
      - 颗粒状
    - [淀粉体（造粉体）、造油体]
```

## 10. 图像正文与表格

### 10.1 四类页面区域

逐页区分以下四类内容，不能用“存在图片对象”作为统一跳过条件：

1. **可提取正文**：PDF 有可选择文字层，使用字符坐标恢复行序和缩进。
2. **栅格化正文**：页面上看起来是普通标题、段落、列表或判断分支，但实际保存为像素图，PDF 没有对应文字层。此类内容必须 OCR 并按正常层级转换。
3. **表格**：包括文本/矢量表格、有边框图像表格和无框图像表格，均必须恢复行列结构。
4. **普通插图**：照片、解剖图、形态图、流程图、系统发育树、曲线图及其图注标签，继续忽略。

页面同时含正文、表格和插图时，只处理正文与表格区域。不要 OCR 普通插图中的标注，也不要添加“图片略”等占位符。

### 10.2 栅格化正文 OCR

- 优先使用本地 macOS Vision OCR，识别语言包含 `zh-Hans`、`zh-Hant` 和 `en-US`；文件不得上传。
- OCR 必须保留文字框坐标，据此恢复阅读顺序、缩进和编号层级，不能只把识别结果拼成连续纯文本。
- OCR 后仍要执行物理行合并、标题识别、冒号链解析和多值归组。
- 判断是否为栅格化正文时，要看它是否承担正文叙述或分类功能，而不是只看字符数量。带大量标签的解剖图仍是普通插图。
- OCR 低置信度文字必须回看高分辨率页面或原始图像；不能依据专业知识猜写源图中无法辨认的公式或数值。

### 10.3 表格重建

- 可提取的矢量/文本表格按单元格坐标重建。
- 有边框图像表格先检测横纵网格线，再逐单元格 OCR；不能把整张表识别成若干连续段落。
- 无框表格依据多行重复列起点、列间距和上下文对齐恢复行列，不能因为没有网格线而忽略。
- 简单矩形表格输出 Markdown 管道表。没有明确表头时使用空表头，不虚构列名。
- 有合并单元格、跨行或跨列结构的复杂表格使用 HTML `<table>`、`rowspan` 和 `colspan`。
- 表格在页面上的水平位置通常是版面构图，不代表列表缩进；表格应按纵向阅读顺序作为独立块插入。
- 图像同时含表格与说明文字时只裁取和转换表格区域；说明文字只有在它本身属于正文时才另行转换。
- 公式只保留 PDF 或 OCR 能可靠确认的原文形式，不根据图形或学科常识补写。

### 10.4 图像和表格验收

- 对全部嵌入图像做候选扫描，不能只按整页文字量筛选；正文很多的页面也可能嵌有小表格。
- 网格检测之外还要做 OCR 行列对齐扫描，以发现无框表格。
- 每张候选图必须人工区分表格、栅格化正文和普通插图。
- 每个表格逐项核对标题、行数、列数、表头、合并关系、单元格文字、箭头、正负号、上下标和末行末列。
- OCR 自动结果出现列数异常、空白表、标题落入单元格或低置信度字符时，必须回到源图人工覆盖。
- 栅格化正文应检查段落顺序、标题、缩进、续行及中英文字符，并确认其在 Markdown 中插入到正确页面位置。

## 11. 完整性和质量检查

每次转换必须完成以下检查：

- 逐页检查所有页面，不能只抽查首页。
- 渲染 PDF 页面或关键页面为 PNG，目视确认缩进、续行和并列关系。
- 列出所有抵达或接近右版心边界的物理行，逐项判断是否为自动换行。
- 搜索疑似断句列表项，例如以单个名词片段结尾、下一项从同一短语继续的情况。
- 抽查开头、中段和末尾内容，确认顺序与 PDF 一致。
- 检查预期章节标题和关键锚点均存在。
- 检查不存在独立页码行。
- 检查不存在 `![...](...)` 等 Markdown 图片语法。
- 检查不存在“图片略”“图表略”等图片占位符。
- 检查每个确认的表格均以 Markdown 或 HTML 表格出现，没有退化为连续纯文本。
- 检查所有低文本页和文字密集图像，确认没有漏掉栅格化正文。
- 与同名 Word 纯文本做轻量对照，确认没有整段缺失；差异必须回到 PDF 判断。
- 检查冒号链、多值标签和单值标签没有因续行合并而发生层级回退。
- 检查同组编号是否保持平行，不能一个使用标题、另一个使用普通列表而意外脱离父项。
- 检查“补充”、示例和子类型是否依据内容归入正确父项，而不是只跟随最近的视觉缩进。
- 不把临时页面图、纯文本转换文件或分析脚本留在 `trans-md/`。

## 12. 交付前必查反例

- 自动换行被误当成两个无序列表项。
- 多个真实特点被误合成一句。
- 冒号链仍停留在同一行。
- 首个特点留在标签行，后续特点却成为子项。
- 单值标签被拆成不必要的父子两行。
- 同级分类因编号符号或横坐标略有不同而被拆成不同层级。
- 子类型、特点或“补充”内容被机械挂到相邻但不相关的父项下。
- 方括号示例被错误提升或降低层级。
- PDF 页码、图片占位符或分页标记进入 Markdown。
- 图像表格被当作普通插图忽略，或被 OCR 成无行列结构的连续文本。
- 无框表格因没有网格线而漏掉。
- 普通解剖图、流程图或曲线图中的标签被误当成栅格化正文。
- 复杂表格的合并单元格被强行压成错误的矩形 Markdown 表格。
- 为了“纠正知识”而改写 PDF 原文。
