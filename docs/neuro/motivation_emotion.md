# 动机、奖赏与情绪

动物和人并非对所有可行动结果给予同等优先级。动机把身体状态、预期结果、付出成本和社会情境接入行动选择；奖赏学习持续修正线索与结果的价值；情绪则协调感觉评价、身体反应、记忆和行动准备。这些过程共享皮层—基底神经节—丘脑环、杏仁核、海马、下丘脑、脑干和神经调质系统，却没有一个统一的“边缘系统中枢”独立生成全部体验。

本页从正常的价值更新与情境性行动进入情绪网络，再以成瘾说明这些机制怎样形成持续失调。下丘脑怎样把渗透、能量和温度接入自主—内分泌效应，见[自主神经与内脏调控](neuro_autonomic.md#hypothalamic-integration)；注意、学习和记忆的一般机制见[学习、记忆与语言认知](learning_memory_language.md)。

## 动机把内部状态和结果价值转换为行动 { #motivation-reward }

动机使某些结果获得优先级，并决定个体愿意为其付出多少努力。摄食、饮水、性和防御行为具有进化形成的回路约束，却都受发育、激素、当前内环境、学习和社会情境改变，不能按“先天本能”与“后天行为”截然分开。下丘脑把能量、渗透和生殖状态接入效应系统，自主稳态接口见[自主神经与内脏调控](neuro_autonomic.md#hypothalamic-integration)；本页关注结果预测和行动选择。

奖赏可分为至少三个相互作用的过程：结果带来的享乐反应（liking），线索获得的激励显著性（wanting），以及行为—结果关系的学习。腹侧被盖区（VTA）和黑质多巴胺能神经元的相位性活动常随奖赏预测误差变化：未预期奖赏增强，完全预期的奖赏响应转向预测线索，预期奖赏缺失时活动下降。这类信号有助于更新价值和动作策略，但多巴胺也参与运动、行动活力和其他状态调节，不能把它称为“快乐分子”。[^reward-components]

享乐反应依赖伏隔核、腹侧苍白球等区域内较小的阿片肽／内源性大麻素敏感热点及更广泛的感知网络；中脑边缘多巴胺对线索诱发的激励显著性作用更突出。眶额皮层表示状态依赖的结果价值，杏仁核、海马和纹状体分别把情绪显著性、情境与动作历史带入选择。结果价值会随饱腹、威胁和社会环境重估，而不是存放在一个永久“奖赏中枢”中。

## 情绪协调感觉评价、身体反应与行动准备 { #emotion-networks }

情绪包含主观体验、感觉评价、记忆、自主—内分泌反应、表情和行动倾向，这些成分可以同步，也可以部分分离。杏仁核的多个核对威胁线索学习、显著性评估及向下丘脑、中脑导水管周围灰质和脑干的防御输出十分重要；海马提供情境，岛叶和扣带皮层整合身体状态与行动价值，前额叶网络则按规则、可控性和长期目标调节响应。杏仁核活动不等同主观恐惧，下丘脑刺激引出的防御行为也不是“愤怒中枢”被直接打开。[^emotion-networks]

经典“假怒”实验在去除大部分前脑联系的动物中保留下丘脑—脑干防御输出，揭示皮层和下丘脑连接对反应阈值的调节。切断实验同时严重改变整个网络，不能据此断定正常情绪只是皮层持续压制一个皮层下程序。人类防御还随威胁距离、逃避可能性、社会信息和既往经验在 amygdala、prefrontal cortex、hypothalamus 与 midbrain 网络之间重配。情绪相关的心率、出汗、泪液、胃肠和激素变化同样按情境组合，不是交感或副交感整套单向切换。

## 成瘾重塑奖赏学习、压力与控制网络 { #addiction }

成瘾表现为物质或行为线索获得过强的动机控制、使用逐渐习惯化、戒断期负性情绪增加以及抑制和决策受损的组合。药物可通过不同分子靶点迅速改变多巴胺、阿片肽、GABA、谷氨酸或其他系统；反复暴露后，腹侧／背侧纹状体、扩展杏仁核、前额叶皮层、海马与内感受网络的可塑性共同增加复吸易感性。并不存在一条对所有成瘾都相同的“奖赏回路劫持”路径。[^addiction-circuitry]

强烈 wanting 可以与实际 liking 分离，线索和情境在停止使用很久后仍可能引发寻求。负强化、压力、睡眠、社会环境、药代动力学和个体易感性又改变病程；这使成瘾既不能归为意志薄弱，也不能仅由 dopamine 峰值诊断。具体物质、耐受、戒断、治疗和精神共病属于疾病与药理专题，本页保留正常学习系统如何转为持续失调的机制边界。

[^addiction-circuitry]: Basal ganglia、extended amygdala 与 prefrontal cortex 在成瘾循环中的相互作用和多递质适应，参见 Koob 与 Volkow [Neurobiology of addiction](https://pmc.ncbi.nlm.nih.gov/articles/PMC6135092/)；模型用作跨物质的组织框架，不作为单一病程模板。
