# 周围神经系统

周围神经系统把脑和脊髓与感受器、骨骼肌、平滑肌、心肌及腺体连接起来。它包括脑神经和脊神经、与这些神经相连的感觉神经节与自主神经节，以及分布在组织中的感受末梢和运动末梢。这里的“周围”描述结构位于中枢神经系统之外，不表示它只做被动传输：感觉神经元可在末梢完成换能，自主和肠神经节能够整合局部输入，施万细胞、卫星胶质细胞、免疫细胞及结缔组织共同调节轴突的生存、传导和损伤反应。

## 两组分类轴描述同一条神经 { #pns-organization }

传入（afferent）和传出（efferent）以中枢神经系统为参照。传入纤维把感受器活动送向脊髓或脑，传出纤维把中枢输出送往效应器。躯体和内脏则按信息来源与靶组织区分：躯体感觉主要来自皮肤、骨骼肌和关节，内脏感觉来自器官和血管；躯体运动支配骨骼肌，自主运动调节平滑肌、心肌与腺体。两组分类轴彼此独立，一条混合神经可以同时含躯体传入、内脏传入、躯体传出和自主传出纤维。[^pns-framework]

神经的名称也不总能直接说明纤维方向。“感觉神经”以传入纤维为主，“运动神经”以传出纤维为主，而大多数脊神经及许多具名外周神经是混合神经。动作电位若在实验中从轴突中段被触发，可沿两个方向传播；生理信息方向仍由感受末梢、突触和效应器的连接关系决定。因此，轴突可双向传导与回路具有确定的传入—传出关系并不矛盾。

## 外周神经是一种多层组织器官 { #peripheral-nerve-architecture }

一条外周神经包含许多轴突。髓鞘型施万细胞各自形成一个轴突节间，非髓鞘型施万细胞则可把多条细轴突包在 Remak 束中。神经内膜围绕单根神经纤维，神经束膜把纤维组织成神经束并参与血—神经屏障，神经外膜包合多个神经束、脂肪与较大血管。纵行和横行的胶原结构既抵抗牵拉，也允许神经随关节活动滑动；神经滋养血管（vasa nervorum）维持长轴突的局部代谢。细胞和结缔组织的详细层次见[神经元、胶质与神经组织](neuro_anatomy.md#tissue-organization)。[^peripheral-nerve-structure]

轴突直径、髓鞘、结间长度、离子通道分布和温度共同影响传导速度。Erlanger–Gasser 分类覆盖传入与传出轴突，Lloyd–Hunt 分组则主要用于肌肉感觉传入；旧教材把二者用等号逐项对应，只能作为近似速记。

| 纤维类别 | 髓鞘与相对直径 | 代表性成分 | 与感觉分组的关系 |
| --- | --- | --- | --- |
| Aα | 粗、有髓 | α 运动轴突；肌梭初级和腱器官传入 | 感觉成分多属 I 群（Ia、Ib） |
| Aβ | 中粗、有髓 | 低阈皮肤机械感受传入；肌梭次级传入 | 多与 II 群重叠 |
| Aγ | 较细、有髓 | 支配梭内肌纤维的 γ 运动轴突 | 不属于感觉 I–IV 分组 |
| Aδ | 细、有髓 | 部分伤害性、温度和冷觉传入 | 多与 III 群重叠 |
| B | 细、有髓 | 自主神经节前轴突 | 无统一的感觉分组对应 |
| C | 最细、无髓 | 慢痛、温度、痒觉等传入；多数交感节后轴突 | 感觉成分多属 IV 群 |

同一类别内部仍有连续的直径和速度分布，功能也不是排他的。例如部分 Aβ 传入可编码伤害性机械刺激，C 纤维也可传递温度、痒觉和低阈机械信息。纤维类别适合描述一组电生理和形态特征，不能单凭字母推断受体、递质或完整知觉。[^fiber-classes]

## 感觉神经节与自主神经节 { #peripheral-ganglia }

脊神经后根神经节和多数脑神经感觉神经节容纳初级感觉神经元胞体。后根神经节神经元通常是假单极：一条突起在 T 形分叉处分为通向感受末梢的周围支和进入中枢的中枢支，动作电位可绕过胞体继续传播。胞体被卫星胶质细胞包围。经典感觉神经节内通常没有把传入信息换元给第二个神经元的主通路突触；第一次中枢突触位于脊髓或脑干，但神经节胞体和胶质仍能调节兴奋性、代谢及炎症反应。前庭和蜗神经节的感觉神经元为双极形态，嗅觉感受神经元和视网膜—视神经又具有各自不同的组织方式，不能把一切“特殊感觉”都概括为双极神经节细胞。[^sensory-ganglia]

自主神经节则含多极的节后神经元，节前轴突在其中形成突触。交感神经节包括脊柱两侧的椎旁节和腹主动脉主要分支附近的椎前节；副交感神经节多靠近或位于靶器官壁内。肠壁神经丛还包含感觉神经元、中间神经元、运动神经元和胶质细胞，能够形成局部回路，不能只视为一组“内脏运动换元站”。自主和肠神经节的回路与递质在[自主神经与内脏调控](neuro_autonomic.md)中展开。

## 脊神经从节段根重组为外周神经 { #spinal-nerves }

人体有 31 对脊神经：8 对颈神经、12 对胸神经、5 对腰神经、5 对骶神经和 1 对尾神经。每一节段的许多后根丝和前根丝分别集合成后根与前根。后根含感觉神经元的中枢支，并在椎间孔附近形成后根神经节；前根含躯体运动轴突，也可含从相应脊髓节段发出的自主节前轴突。两根短暂合成一条混合脊神经，随后分支。C1–C7 神经从同号椎骨上方离开，C8 位于 C7 与 T1 椎骨之间，自 T1 起则从同号椎骨下方离开。根的“后感觉、前运动”规律并不等于后支只含感觉、前支只含运动：神经的前、后支均为混合性。[^spinal-nerves]

较小的后支供应脊柱深肌、椎间关节和背部局部皮肤，较大的前支供应躯干前外侧和四肢。多数胸神经前支仍按节段行于肋间，形成肋间神经；颈、臂、腰和骶部前支则相互交换纤维，形成神经丛。神经丛使一条具名外周神经通常包含多个脊髓节段的轴突，也使一个节段的轴突分散到多条外周神经。具名混合神经沿途可发出肌支、皮支和关节支，较大神经还常与血管同行于筋膜间隙，但神经与血管的分支并非处处一一对应。颈丛的膈神经连接膈肌，臂丛产生正中、尺、桡等上肢神经，腰骶丛产生股、闭孔、坐骨等下肢神经。坐骨神经由胫神经和腓总神经成分共同包在一个神经外膜内，是人体最粗大的外周神经之一；“最长神经”并不是有稳定解剖判据的功能分类。

脊膜支从脊神经返回椎管，供应脊膜、韧带、椎间盘外层和血管等结构。交通支把脊神经与交感干连接：白交通支主要见于 T1–L2，含有髓交感节前轴突，也可携带伴行的内脏传入；灰交通支把无髓交感节后轴突送回各节段脊神经，随前、后支到达汗腺、竖毛肌和皮肤血管。完整的交感走行由自主神经页承接。[^rami-communicantes]

### 皮节、肌节与外周神经分布

皮节是一个脊神经根主要供应的皮肤区域，肌节是一个脊髓节段主要支配的肌群。相邻皮节与肌节广泛重叠，所以单一根损伤通常不会使一块边界锐利的皮肤完全失去感觉，也很少使一块肌肉的全部运动单位同时失神经。由神经丛重组后的正中神经、桡神经等具名神经则形成另一套皮肤和肌肉分布图。一条外周神经的感觉区可以横跨多个皮节；反过来，一个皮节的轴突也可经不同外周神经到达皮肤。[^dermatome-nerve-fields]

这种差异提供定位依据。神经根病变沿皮节、肌节和相应反射表现，并可同时影响由该根加入的多条外周神经；神经丛病变跨越若干根和末梢神经，但不完全服从单一皮节；单神经病变则更符合具名神经的分支范围。定位仍需综合感觉、肌力、反射、疼痛走向和电生理，不能只凭一张皮节图。

## 十二对脑神经连接头颈与内脏 { #cranial-nerves }

传统上按 I–XII 记述 12 对脑神经。I、II 与前脑相连；III、IV 与中脑相连；V 主要在脑桥水平出入，VI–VIII 位于脑桥—延髓交界，IX、X、XII 位于延髓，XI 的主要运动神经元则位于上颈髓。脑表面的“出入点”不等于全部核团的位置：例如三叉神经感觉核柱跨越中脑、脑桥和延髓至上颈髓，迷走神经也联系多个延髓核。[^cranial-nerve-topology]

| 脑神经 | 主要传入成分 | 主要传出成分 |
| --- | --- | --- |
| I 嗅 | 嗅黏膜感受神经元传递嗅觉 | — |
| II 视 | 视网膜神经节细胞轴突传递视觉 | — |
| III 动眼 | — | 多数眼外肌和上睑提肌；副交感调节瞳孔括约肌与睫状肌 |
| IV 滑车 | — | 上斜肌 |
| V 三叉 | 面部、角膜、口鼻腔、牙和部分硬膜的一般感觉 | V3 支配咀嚼肌及部分第一鳃弓来源肌 |
| VI 展 | — | 外直肌 |
| VII 面 | 舌前 2/3 味觉及少量耳部一般感觉 | 面部表情肌等第二鳃弓来源肌；副交感支配泪腺、下颌下腺和舌下腺等 |
| VIII 前庭蜗 | 听觉、头部运动与相对重力方向 | — |
| IX 舌咽 | 舌后 1/3 味觉和一般感觉、咽部感觉、颈动脉窦与颈动脉体传入 | 茎突咽肌；副交感支配腮腺 |
| X 迷走 | 咽喉、部分耳部及胸腹腔内脏感觉，兼有会厌区味觉 | 软腭、咽和喉肌；副交感支配胸腔及大部分腹腔脏器 |
| XI 副 | — | 胸锁乳突肌和斜方肌 |
| XII 舌下 | — | 除腭舌肌外的舌内、外肌 |

“感觉、运动或混合”是便捷总类，功能成分能提供更精确的信息。一般躯体传入来自面部等结构，一般内脏传入来自器官和血管；特殊躯体传入用于视觉、听觉和平衡，特殊内脏传入传统上包括嗅觉和味觉。一般躯体传出支配由体节形成的眼外肌和舌肌，鳃弓运动（传统称特殊内脏传出）支配咀嚼、面部表情和咽喉等鳃弓来源骨骼肌，一般内脏传出则是脑神经中的副交感节前成分。III、VII、IX、X 携带副交感节前轴突；VII 和 IX 的节后纤维常借三叉神经分支到达腺体，不能据末端所搭乘的神经误判中枢来源。[^cranial-components]

I、II 还是“脑神经”概念的边界例外。嗅神经由嗅黏膜感受神经元轴突束组成，穿筛板后在嗅球换元；视神经则是间脑的延伸，由视网膜神经节细胞轴突组成，受少突胶质细胞髓鞘化并由脑膜包绕，因此在组织学和疾病反应上更接近中枢白质。XI 的传统“颅根”多随迷走神经分布，现代资料常把真正的副神经限定为来自上颈髓、支配胸锁乳突肌和斜方肌的脊髓根。分类口径改变时，应说明所指纤维，而不是只争论编号。[^optic-accessory-boundary]

## 自主纤维借周围神经抵达器官 { #autonomic-periphery }

自主传出通常由两个神经元串联。交感节前神经元位于 T1–L2 脊髓，轴突经前根、脊神经和白交通支进入交感干，可在同节段、上／下位椎旁节或椎前节换元；节后轴突再经灰交通支、心肺内脏神经或血管周围神经丛到达靶器官。副交感节前轴突随 III、VII、IX、X 或盆内脏神经离开中枢，在靠近靶器官的神经节换元。解剖上与交感或副交感纤维同行的内脏传入轴突仍属于感觉系统，并不会因此变成“交感感觉”或“副交感感觉”。[^autonomic-peripheral-routes]

周围通路决定信号能否到达器官，器官效应还取决于节后递质、受体亚型、基础张力和局部回路。交感不总是全身同步，副交感也不只承担“休息”；二者可协同、拮抗或分别支配不同组织。具体回路、递质与器官调节见[自主神经与内脏调控](neuro_autonomic.md)。

## 损伤层次决定缺失模式与恢复条件 { #peripheral-localization }

周围神经受压可先造成局部髓鞘和结区功能障碍，表现为传导减慢或传导阻滞而轴突仍连续。轴突断裂后，远端轴突和髓鞘发生 Waller 变性；施万细胞转换为修复状态，和巨噬细胞清除碎片，并在残存基底膜管内排列成 Büngner 带，引导近端轴芽。若神经内膜通道、神经束膜和神经外膜保存较好，轴突更可能沿原路径抵达靶点；完全断裂、长缺口、瘢痕、误入错误神经束以及靶肌长期失神经都会限制功能恢复。胞体和胶质反应的细胞机制见[损伤后的清除、重塑与再生](neuro_anatomy.md#injury-response)。[^peripheral-nerve-injury]

神经传导检查以表面刺激和记录估计运动或感觉反应的潜伏期、速度、幅度与跨段变化，针极肌电图则抽样运动单位和失神经后的肌纤维活动。局灶脱髓鞘常突出表现为减慢、时间离散或传导阻滞，轴突丢失更常使复合反应幅度下降。后根神经节近端的神经根病变可在肌电图显示同一根支配、却分属不同末梢神经的肌肉异常，而远端感觉神经动作电位仍可能保存；神经丛和末梢神经病变位于神经节远端，更容易改变相应感觉反应。电生理是对临床定位的约束，不替代病史、查体、影像或病因判断。[^electrodiagnostic-localization]

[^cranial-components]: 一般／特殊、躯体／内脏、传入／传出功能成分及各脑神经的主要任务，参见 NCBI Bookshelf [Neuroanatomy, Cranial Nerve](https://www.ncbi.nlm.nih.gov/books/NBK470353/)；详细感觉换能分别在视觉、听觉前庭与化学感觉页面展开。
[^optic-accessory-boundary]: 视神经作为间脑延伸、由少突胶质细胞髓鞘化并受脑膜包绕，参见 NCBI Bookshelf [Neuroanatomy, Cranial Nerve 2](https://www.ncbi.nlm.nih.gov/books/NBK507907/)；副神经颅根与迷走神经的归属争议见 [Neuroanatomy, Cranial Nerve](https://www.ncbi.nlm.nih.gov/books/NBK470353/)。
[^autonomic-peripheral-routes]: 交感与副交感节前、节后神经元的周围走行，参见 OpenStax [Divisions of the Autonomic Nervous System](https://openstax.org/books/anatomy-and-physiology-2e/pages/15-1-divisions-of-the-autonomic-nervous-system) 与 NCBI Bookshelf [Anatomy, Autonomic Nervous System](https://www.ncbi.nlm.nih.gov/books/NBK539845/)。
[^peripheral-nerve-injury]: Waller 变性、施万细胞修复表型、巨噬细胞清除和 Büngner 带对再生的引导，参见 Gordon [Peripheral Nerve Regeneration and Muscle Reinnervation](https://pmc.ncbi.nlm.nih.gov/articles/PMC7697710/) 与 NCBI Bookshelf [Peripheral Nerve Injury](https://www.ncbi.nlm.nih.gov/books/NBK549848/)。
[^electrodiagnostic-localization]: 神经传导与肌电图对神经根、神经丛、单神经以及脱髓鞘／轴突性损伤的定位边界，参见 NCBI Bookshelf [Nerve Conduction Studies and Electromyography](https://www.ncbi.nlm.nih.gov/books/NBK611987/)。
