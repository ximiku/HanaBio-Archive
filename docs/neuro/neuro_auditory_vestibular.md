# 听觉、前庭与化学感觉

听觉、前庭觉、味觉和嗅觉都把外界能量转换为神经活动，却解决不同的估计问题。耳蜗从快速压力波中分离频率和时间结构，前庭迷路估计头部相对重力的姿态与运动，味蕾采样已经接触口腔的溶质，嗅上皮则从随呼吸进入鼻腔的挥发性分子中识别气味。听觉与前庭觉共用内耳毛细胞的机械换能原理，味觉与嗅觉则展示了离子通道、G protein 偶联受体和初级感觉神经元等多种化学换能方案。

## 声音以压力、频谱和时间结构到达耳 { #sound-and-middle-ear }

声音是在介质中传播的压力扰动。纯音可用频率、相位和幅度描述，现实声音则由许多频率成分及其随时间的起伏构成。频率是音高的重要线索，声压与响度相关，但响度还随频率、持续时间、背景声和听者状态变化。声压级常写为 $L_p=20\log_{10}(p_{\mathrm{rms}}/p_0)$，空气中的参考声压 $p_0$ 通常为 20 µPa；临床听力图使用的 dB HL 又经过频率特异的正常听阈校准，不能与 dB SPL 直接互换。年轻健康人在适当声级下常能听到约 20 Hz 至 20 kHz 的声波，这只是近似范围，上限尤其会随年龄、噪声暴露和测量条件下降。[^sound-metrics]

耳郭、头部和外耳道先对来自不同方向的频谱作选择性滤波。声波推动鼓膜，经锤骨、砧骨和镫骨把振动送到卵圆窗；鼓膜与镫骨底板的面积差及听小骨杠杆作用提高卵圆窗处的压力，减少空气与耳蜗液体之间的阻抗失配。这个过程重新分配力和位移，并未凭空增加机械能。圆窗为耳蜗液体提供顺应性出口，咽鼓管在吞咽等动作时开放，参与中耳通气、分泌物清除和鼓膜两侧压力平衡。[^middle-ear]

镫骨肌反射能在强声后降低部分低频能量传递，也参与发声时的听觉调节；它存在潜伏期，无法可靠保护耳蜗免受突然爆炸或持续强噪声损伤。气导声依次经过外耳和中耳，骨导则由颅骨振动直接驱动两侧耳蜗。比较气导与骨导有助于区分外／中耳传音障碍和耳蜗—听神经感音障碍，但两耳骨导、交叉听取和混合性损伤使临床判断不能只靠一句“哪条更响”。

## 耳蜗把复合声机械分解为频率地图 { #cochlear-mechanics }

耳蜗横断面包含充满外淋巴的前庭阶和鼓阶，以及其间充满内淋巴的蜗管。镫骨推动卵圆窗后，压力差使基底膜和包含毛细胞的螺旋器运动，并最终由圆窗释放。基底膜从蜗底到蜗顶逐渐变宽、变软；行波虽然沿耳蜗向前传播，不同频率却在不同位置达到最大响应，高频峰靠近刚硬的蜗底，低频峰靠近柔顺的蜗顶。耳蜗由此在神经放电之前就把复合声部分分解成沿轴排列的频率成分。[^cochlear-mechanics]

频率位置图并非被动膜片的固定共振。三排外毛细胞的膜蛋白 prestin 把受体电位转换为快速长度变化，将机械能反馈给螺旋器，使低声级下的局部振动增大、频率调谐变尖，而在较高声级下增益下降。这种非线性“耳蜗放大器”扩展了可用动态范围，也会产生能够从耳道记录的耳声发射；外毛细胞受损时，听阈升高、频率选择性变差，耳声发射常减弱或消失。单排内毛细胞承担绝大多数传入输出，外毛细胞的核心角色则是主动调节耳蜗机械。[^cochlear-amplifier]

## 毛束偏转开启机械换能通道 { #hair-cell-transduction }

成熟耳蜗毛细胞顶端的 stereocilia 按高度阶梯排列，较短 stereocilium 顶端以 tip link 连到相邻较高者。毛束向最高一排偏转时，tip link 张力增大并打开由 TMC1／TMC2 等蛋白组成的机械换能复合体；反向偏转使张力下降、通道关闭。耳蜗成熟毛细胞没有保留一根用于定向的 kinocilium，不能把所有 stereocilia 统称为运动纤毛。tip link 的主要分子 CDH23 和 PCDH15 以及换能复合体蛋白的遗传缺陷都能破坏听觉，说明纳米尺度连接承受的力直接控制离子通道。[^hair-transduction]

毛细胞顶端浸在高 K$^+$、低 Na$^+$ 的内淋巴中，基底外侧接近低 K$^+$ 的外淋巴。血管纹的边缘、中间和基底细胞协同维持内淋巴离子组成及约 +80 mV 的耳蜗内电位；这一正电位和毛细胞负膜电位共同形成很强的电化学驱动力。通道开放时主要由 K$^+$ 并伴随 Ca$^{2+}$ 流入，毛细胞去极化；基底外侧电压门控 Ca$^{2+}$ 通道随之开放，在 ribbon synapse 触发 glutamate 释放，兴奋螺旋神经节传入纤维。K$^+$ 再从基底外侧流出并经周围细胞与液体通路回收。内淋巴是由专门上皮主动维持的区室，不是外淋巴的简单滤过液。[^endocochlear-potential]

毛细胞产生分级受体电位，听神经才以动作电位传出。耳蜗微音器电位主要反映许多毛细胞换能电流的合成，波形可跟随声刺激极性；听神经复合动作电位则取决于许多轴突在声起始附近的同步放电。二者来自不同电信号，不能用复合动作电位振幅独立推回声音的频率或全部耳蜗功能。

## 听神经以位置、时序和群体活动编码声音 { #auditory-coding }

| 声音维度 | 外周与中枢使用的主要线索 | 重要边界 |
| --- | --- | --- |
| 频率与音高 | 基底膜峰值位置形成 place code；低频时听神经放电还可与声波周期 phase-lock | 音高也受谐波关系、包络和上下文影响；单根纤维只能覆盖有限强度范围 |
| 声级与响度 | 单纤维放电率、不同阈值纤维募集及跨频带群体活动 | dB 是刺激物理量，响度是知觉；背景声与适应会改变二者关系 |
| 时间结构 | 声起始、包络、相位锁定和神经群同步 | 高频载波不能被每个动作电位逐周期追随，但包络和位置线索仍可保留 |
| 声源方位 | 两耳到达时间差、两耳声级差及耳郭造成的单耳频谱线索 | 时间差和声级差的权重随频率变化；垂直方位与前后辨别尤其依赖个体耳郭频谱 |

同一频率对应的空间排列从耳蜗延续到蜗核、下丘、内侧膝状体和初级听觉皮层，形成 tonotopy。低频声音还能使一群听神经纤维在不同周期交替放电，以群体 phase-lock 保留时间信息；声级升高则同时提高部分纤维放电率并募集阈值不同的纤维。所谓“一个频率对应一根神经”或“振幅只由单纤维频率表示”都无法容纳自然声的宽频谱和大动态范围。[^auditory-coding]

水平声源定位需要尽早比较两耳输入。较低频率下，到达时间和相位差较有用；较高频率下，头影造成的两耳声级差更明显。上橄榄复合体及相邻脑干回路利用精确兴奋—抑制时序完成这些比较，耳郭对不同入射角造成的频谱凹峰则为垂直方位和前后判别提供重要单耳线索。听觉空间不是由一侧通路简单代表对侧耳，而是由双耳差异和单耳频谱联合估计。[^sound-localization]

## 双侧听觉通路保留频率图并重组复杂声 { #central-auditory-pathway }

螺旋神经节轴突随蜗神经进入同侧背、腹侧蜗核。自蜗核起，纤维经斜方体、上橄榄复合体和外侧丘系等多条平行路线发生特定而非随机的交叉，也保留同侧投射；多数路线在下丘汇聚，再经内侧膝状体到达颞叶 Heschl 回的初级听觉皮层。不同蜗核亚区对频谱、起始、持续时间和双耳计算作不同变换，整条通路并非一个整齐的三级神经元链。[^auditory-pathway]

由于蜗核以上很快形成双侧输入，单侧脑干、丘脑或听皮层损伤通常不会造成一只耳的完全失聪，却可破坏声源定位、噪声中言语辨认或特定复杂声分析。原发听皮层及相邻 belt／parabelt 区通过多幅频率图和分布式连接处理音高、时间、空间及声源身份；语言理解还依赖颞叶、额叶和顶叶网络。外／中耳、耳蜗—听神经和中枢网络受损可分别形成传导性、感音神经性和中枢听觉障碍，这些机制分类比把所有听力下降归结为“耳聋”更有定位价值。

## 前庭迷路以两类机械装置采样头部运动 { #vestibular-sensors }

前庭毛细胞的换能复合体与耳蜗相近，但其毛束保留 kinocilium 作为极性标志：stereocilia 向 kinocilium 偏转时通道开放增多、细胞去极化，反向偏转时超极化。前庭传入在静息时已有持续放电，因此两个方向的毛束偏转能分别把放电率推高或压低。左右两侧近共面的半规管以 push–pull 方式协作，一侧兴奋通常伴随伙伴侧抑制，使共同噪声较易抵消，也使单侧功能丧失产生明显不平衡。[^vestibular-transduction]

| 感受装置 | 惯性结构 | 输入与编码 |
| --- | --- | --- |
| 三对半规管的壶腹嵴 | 毛束嵌入 cupula，内淋巴惯性使 cupula 暂时偏转 | 感受各自平面内的头部角加速度，动态响应可表示旋转速度变化；持续匀速旋转时外周响应逐渐衰减，停止时出现反向偏转，左右共面管成对比较 |
| 椭圆囊与球囊的 macula | 含 CaCO$_3$ 耳石的 otolithic membrane 对惯性和重力产生剪切 | 感受线加速度与头部相对重力的倾斜；毛束极性在 macula 内多向排列，群体活动表示二维加速度。椭圆囊偏水平、球囊偏垂直，但两者响应范围重叠 |

半规管的 cupula 与内淋巴密度接近，静态倾斜不会持续压弯它；旋转开始时内淋巴相对滞后，旋转恒定后逐渐跟上，突然停止又产生相反偏转。耳石膜因含高密度耳石，会持续响应重力，也会响应平移加速度。单个瞬间的耳石信号不能判定剪切来自头部倾斜还是直线加速，中枢必须结合半规管、视觉、本体感觉和随时间变化的内部模型解除这项 gravito-inertial ambiguity。将椭圆囊和球囊分别称为纯粹的水平、垂直传感器只是近似。[^otolith-canals]

## 前庭核把凝视、姿势、自主反应和知觉连接起来 { #vestibular-integration }

前庭神经把半规管和耳石信号送到脑干前庭核群，也有纤维直接进入小脑。前庭核经内侧纵束联系 III、IV、VI 脑神经核，以短潜伏期前庭—眼反射在头动时把眼球推向相反方向，稳定视网膜像；经前庭脊髓束和网状网络调节头颈、躯干与抗重力肌；经丘脑—皮层网络参与自运动、垂直方向和空间定向知觉。小脑以视觉误差和运动经验持续校准这些反射的增益与时序。相关束路见[神经系统传导通路](neuro_pathway.md#brainstem-descending)，眼动接口见[视觉系统](neuro_vision.md#oculomotor-reflexes)。

眼震由慢相和快相交替构成：慢相通常是前庭驱动的补偿性眼动，快相是重新定位的扫视样复位，临床以快相方向命名。姿势反应同样不是简单与刺激方向相反的一次收缩，而是在支持面、任务和其他感觉输入约束下重分配多关节肌力。晕动症常在视觉、前庭与本体输入彼此冲突或偏离既有内部模型时出现，恶心、苍白、出汗和呕吐来自脑干、自主及内分泌网络的联合反应；反复暴露后的适应说明它不是由“迷走神经单独兴奋”即可解释。[^vestibular-responses]

## 味蕾用不同分子机制识别五类基本味质 { #taste-transduction }

味蕾分布在舌的 fungiform、foliate 和 circumvallate papillae，也见于软腭、咽和会厌附近；覆盖舌面大部的 filiform papillae 主要承担机械作用，不含味蕾。每个味蕾由持续更新的多类上皮来源感受细胞和支持／前体细胞组成，顶端微绒毛经味孔接触溶于唾液的分子。甜、咸、酸、苦、鲜感受细胞以交错方式分布，人类舌头不存在把五种味质分隔到舌尖、两侧和舌根的“味觉地图”。[^taste-buds]

| 味质 | 代表性外周换能 | 向传入神经输出 |
| --- | --- | --- |
| 甜 | type II 细胞的 T1R2／T1R3 GPCR，经 PLCβ2—IP$_3$—Ca$^{2+}$—TRPM5 通路去极化 | 动作电位开启 CALHM1／CALHM3 channel synapse，非囊泡释放 ATP |
| 鲜 | type II 细胞的 T1R1／T1R3 检测 glutamate 等 L-amino acid 线索，共用 PLCβ2—TRPM5 级联 | 主要以 CALHM1／CALHM3 释放 ATP；核苷酸可增强部分鲜味响应 |
| 苦 | 多种 T2R GPCR 分别响应结构多样的化合物，共用 type II 细胞下游级联 | 主要以 CALHM1／CALHM3 释放 ATP；“苦”提示潜在风险但不等于所有苦味物都有毒 |
| 酸 | type III 细胞的 OTOP1 导入 H$^+$，胞内酸化和 K$^+$ 电导变化进一步促进去极化 | 电压门控 Ca$^{2+}$ 通道与经典囊泡突触参与递质释放 |
| 咸 | 低浓度 Na$^+$ 可经 ENaC 等通路进入感受细胞；高盐还募集 amiloride 不敏感及伤害／三叉通路 | 人体 ENaC 贡献存在个体差异，咸味换能尚不能压缩为唯一通道 |

甜、苦和鲜共享下游级联，却由不同受体和细胞群起始；酸味细胞具有经典突触，type II 细胞则通过可通透 ATP 的 channel synapse 激活感觉神经末梢。咸味尤其需要保留物种和浓度边界：啮齿类低盐 ENaC 证据很强，人类对 amiloride 的心理物理响应却不一致，高盐还会激活厌恶性味觉和一般化学感觉。味质因而是受体—细胞—神经群体的编码结果，不是某一种化合物与一个通道的永久一一映射。[^taste-molecular]

## 味觉通路把摄食信号接入内稳态和奖赏网络 { #taste-pathway }

味觉传入由三对脑神经承担：VII 的鼓索支主要来自舌前部，VII 的岩大神经来自腭部，IX 来自舌后部，X 来自会厌和咽部。其一级神经元胞体分别位于膝神经节、岩神经节和结状神经节，中枢突进入延髓孤束核头端。灵长类通路再经丘脑 VPM 的小细胞部抵达前岛叶和额叶岛盖的初级味觉皮层；孤束核与脑干口腔运动、自主网络以及下丘脑、杏仁核等联系，使味觉能迅速改变吞咽、唾液、食欲和回避行为。[^taste-pathway]

味觉皮层、orbitofrontal cortex、杏仁核和下丘脑还整合气味、口腔触觉、温度、内脏状态与学习经验。同样浓度的甜味可随饥饿、饱足和预期改变愉悦度，但外周感受器活动并不等同奖赏价值。苦味和酸味常促进回避，仍会受到浓度、情境和经验调节；鲜味也不是“蛋白质含量计”，因为天然食物的氨基酸、核苷酸和其他成分共同作用。

## 嗅觉感受神经元直接把化学信息送入嗅球 { #olfactory-transduction }

嗅上皮位于鼻腔顶部附近，包含 bipolar olfactory sensory neuron、支持细胞和基底干／祖细胞。感受神经元树突末端的纤毛伸入黏液，轴突则穿筛板进入嗅球；它本身既是感受器又是一级神经元，与味蕾的上皮感受细胞—传入神经二细胞结构不同。基底细胞可补充不断受环境损伤的嗅感受神经元，但再生能力仍会受年龄、炎症和组织结构破坏限制。[^olfactory-epithelium]

气味分子与纤毛膜上的 olfactory receptor GPCR 结合后，G$_{olf}$ 激活 adenylyl cyclase III，cAMP 开启 cyclic nucleotide-gated channel，使 Na$^+$ 和 Ca$^{2+}$ 内流；Ca$^{2+}$ 再开启 Ca$^{2+}$-activated Cl$^-$ channel。在嗅感受神经元较高的胞内 Cl$^-$ 环境中，Cl$^-$ 外流进一步去极化，最终在轴突起始段产生动作电位。Ca$^{2+}$—calmodulin 对通道和级联的反馈、受体磷酸化以及更高回路调节共同产生从秒到更长尺度的嗅觉适应。[^olfactory-transduction]

多数成熟嗅感受神经元主要表达一种 olfactory receptor 基因选择，同一受体可响应多种分子，一种气味分子也可按不同效力激活多种受体。表达同类受体的轴突汇聚到嗅球的一组 glomerulus，在此联系 mitral／tufted cell 和局部抑制性中间神经元。气味质量由跨受体、glomerulus 和时间模式的组合活动表示，而不是每种气味拥有一条专线；吸气流形、浓度、混合物相互作用和既往适应都会改变模式。[^olfactory-coding]

## 嗅球输出绕过强制性首级丘脑中继 { #olfactory-pathway }

mitral 和 tufted cell 轴突经 lateral olfactory tract 投向 anterior olfactory nucleus、piriform cortex、olfactory tubercle、部分 amygdala 和 entorhinal 区域。嗅球到 primary olfactory cortex 之间没有其他感觉系统常见的强制性首级丘脑中继；piriform cortex 又可直接或经 mediodorsal thalamus 联系 orbitofrontal cortex。嗅觉与杏仁核、entorhinal cortex 和 hippocampal network 的短连接，有助于解释气味为何容易获得情绪和情境记忆，但“嗅觉直接进入边缘系统”仍只是网络连接偏重，不表示它不受皮层反馈、注意和学习调节。[^olfactory-pathway]

气味到达嗅上皮有 orthonasal 和 retronasal 两条主要路线：吸气时从鼻孔进入的分子支持环境嗅闻，咀嚼和吞咽释放的挥发物则从鼻咽后方上行，成为食物风味的关键部分。鼻塞时基本味质可保留，食物身份和细腻风味却常显著变弱，正是 retronasal olfaction 受阻的结果。

## 风味是多种化学感觉与身体状态的联合知觉 { #flavor-integration }

日常所说的“味道”远大于五种基本味质。味觉提供甜、咸、酸、苦、鲜，retronasal olfaction 区分大量挥发性成分，三叉神经及其他躯体感觉末梢报告辣椒素灼热、薄荷醇清凉、CO$_2$ 刺激、温度和质地；咀嚼声音、视觉、饱足信号、期待与记忆还会改变最终体验。嗅觉下降常被误以为味觉丧失，是因为基本味质仍在，而用于辨认食物的组合气味大幅减少。[^flavor]

这些系统也以不同时间尺度适应。持续气味会在嗅感受神经元、嗅球和皮层多级减弱，味觉细胞和中枢响应也会随刺激与摄食状态改变；背景噪声则可能掩蔽目标声并改变听觉增益。适应使神经系统更强调变化和新信息，同时会受注意与行为目标调节，不能简单按“快适应／慢适应”给四种感觉永久分类。
