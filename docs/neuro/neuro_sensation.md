# 感觉编码与躯体感觉

感觉系统把外界和身体内部的能量变化转换为神经活动，并从中估计刺激的种类、强度、位置和时间过程。神经活动本身仍不是知觉：同一传入输入会随注意、运动状态、既往经验和上下文而获得不同意义，许多输入还只用于反射、姿势或内稳态调节而不进入清晰意识。感觉研究因此跨越三个相互衔接的层次：感受器完成换能，神经群体编码刺激，分布式中枢网络形成知觉并指导行为。

## 感受器把特定形式的能量转换为膜电位 { #sensory-transduction }

感受器可以是初级感觉神经元的外周末梢，也可以是与传入神经元形成突触的专门感受细胞。皮肤低阈机械感受器、肌梭和多数伤害性感受器属于前一种情形；视网膜感光细胞、耳蜗毛细胞和味觉感受细胞则属于后一种。感受器连同改变刺激传递的附属结构构成感觉器官，例如眼球的光学结构把光聚焦到视网膜，耳蜗结构把不同频率的机械振动分配到基底膜不同位置。

“适宜刺激”指以最低能量最容易激活某类感受器的刺激形式，并不表示其他刺激绝对无效。机械形变可开启机械敏感通道，温度或化学物质可改变 TRP 通道开放，光子使视蛋白启动信号级联。强压眼球产生光感，正是视网膜通路被非典型方式激活后仍被中枢解释为视觉的例子。伤害性感受器同样有适宜的高阈机械、热或化学刺激，不能因其刺激类型多样而称为“无适宜刺激”。[^adequate-stimulus]

换能产生的是幅度随刺激变化的感受器电位。若换能发生在神经末梢，这一局部电位扩布到触发区并改变动作电位频率；若换能发生在独立感受细胞，感受器电位先调节递质释放，再由传入神经元产生动作电位。动作电位的幅度近似全或无，刺激强度主要写入放电频率、时间模式和被募集神经元的数目，而不是写入单个动作电位的大小。感受器电位可以去极化，也可以像脊椎动物感光细胞那样在光照时超极化；换能也不必然“放大”能量，它首先是把物理或化学变量转换成可被神经系统读取的电信号。

## 神经群体同时编码模态、强度、空间与时间 { #sensory-coding }

感觉编码依赖神经元身份与活动模式的结合。特定受体、轴突、换元核团和皮层靶区构成相对稳定的“标记线”，使中枢能够把某组活动解释为触觉、冷觉或本体感觉；与此同时，一种自然刺激通常激活多类感受器，知觉来自不同标记线活动比例和时序的联合。辣椒素造成灼热感、薄荷醇造成清凉感，说明激活温度相关分子通路可以在温度未相应改变时产生特定感觉质量。

| 编码维度 | 主要神经变量 | 需要避免的简化 |
| --- | --- | --- |
| 模态与质量 | 感受器分子、感觉神经元类型及其稳定中枢连接 | 一条通路并非只响应一种现实刺激，知觉也不是单个“专属神经元”的输出 |
| 强度 | 单元放电率、脉冲时序、高阈单元募集和群体活动 | 频率不是唯一变量；高强度下会出现饱和、适应和不同受体群接力 |
| 空间 | 感受野位置与大小、感受器密度、拓扑映射和群体活动重心 | 中枢感受野不一定随换元机械变大，抑制和反馈可动态改变其边界 |
| 时间 | 起始／终止反应、持续放电、相位锁定及跨时间尺度适应 | “快适应／慢适应”是相对响应型，不等于感受器彻底停止或永不适应 |

一个感觉神经元的感受野，是刺激能够改变其活动的身体或感觉空间范围。手指和口唇的感受器密度高、感受野较小，能支持较精细的空间辨别；背部等区域则较粗。相邻通路的会聚、辐散和侧向抑制增强活动峰与周围背景的对比，但真实回路包含反馈抑制和状态依赖增益，并非固定的“中心兴奋、周边抑制”单层模板。两点辨别阈还取决于皮肤力学、刺激方法、注意和中枢整合，不能只用末梢密度解释。[^receptive-fields]

持续刺激下放电逐渐下降称为感觉适应。Meissner 小体和 Pacinian 小体相关传入突出响应刺激变化，适合检测滑动和振动；Merkel 细胞—神经突复合体等持续报告压陷，有助于保持形状与压力信息。适应可来自感受器包膜的机械滤波、换能通道和末梢电性质，也可发生在突触与中枢网络。它提高了对变化的敏感度，却不表示恒定刺激的信息必然全部消失。[^adaptation]

## 丘脑与皮层在循环连接中重组感觉 { #thalamocortical-processing }

躯干和四肢的主要躯体感觉经丘脑腹后外侧核（VPL），头面部感觉主要经腹后内侧核（VPM）抵达大脑皮层；精细触觉、本体感觉与痛温觉的上行路线和交叉位置见[神经系统传导通路](neuro_pathway.md#pathway-coordinates)。丘脑不仅转接输入，还受皮层、网状核和脑干状态系统调节，可改变传入信息的时序同步、增益和进入皮层的机会。传统“特异投射系统／非特异投射系统”有助于区分定位明确的感觉与广泛觉醒效应，但现代解剖显示中继、联合、板内和中线核团构成相互重叠的网络，不能分成互不联系的两套线路。

人类初级躯体感觉皮层位于中央沟后方，包含 3a、3b、1 和 2 区。3b 区主要接收皮肤输入，3a 区突出处理本体输入，1 区更进一步提取皮肤运动与纹理，2 区把皮肤和本体信息组合为形状、大小和手指协同等特征。每个区域都具有自身的身体拓扑图；从内侧的下肢到外侧的面部总体有序，却不是一幅边界静止、身体比例真实的“小人图”。手和口唇占据较大皮层面积，反映末梢取样、行为需求与中枢回路资源，而不是身体尺寸。[^somatosensory-cortex]

皮层感觉表征具有可塑性。训练、损伤或感觉输入改变后，神经元感受野和可测皮层响应可以重排；快速改变常来自原有弱输入的去抑制或增益变化，长期改变还涉及突触和结构重塑。邻近代表区“占领”失去输入的皮层只是简化图像，变化受原有连接、时间尺度、行为和测量方法约束。S2、后顶叶、岛叶、扣带回和运动区与 S1 双向连接，使触觉辨认、身体所有感、动作规划和情绪意义不被局限在中央后回的一条皮层带中。

## 皮肤机械感受器分解接触的不同特征 { #cutaneous-touch }

无毛皮肤的四类经典 Aβ 低阈机械传入，以适应速度和感受野大小形成互补取样。PIEZO2 是多类低阈机械感觉末梢的重要换能通道；人类 PIEZO2 功能缺失可显著损害辨别性触觉、振动觉和本体感觉，同时仍保留部分由其他传入介导的机械感觉，说明“触觉”本身也是多通道组合。[^piezo2]

| 传入类型与典型终末 | 适应与感受野 | 擅长表示的机械特征 |
| --- | --- | --- |
| SA1：Merkel 细胞—神经突复合体 | 慢适应、较小且边界清楚 | 持续压陷、边缘、曲率、粗糙纹理和形状细节 |
| RA1：Meissner 小体 | 快适应、较小 | 接触变化、低频颤动、物体开始滑动及握力调整 |
| PC：Pacinian 小体 | 极快适应、很大 | 远处传来的高频振动和细纹理引起的微小振动 |
| SA2：Ruffini 样终末 | 慢适应、较大 | 皮肤牵张和手形信息；人类终末形态及具体功能仍有不确定性 |

有毛皮肤还含围绕毛囊的多类 Aβ、Aδ 和 C 低阈机械传入。部分无髓低阈传入更偏向缓慢抚触等社会性触觉，其中央投射和知觉角色与辨别性触觉并不完全相同。日常触摸物体时，手指运动主动改变机械输入；纹理、硬度、温度和本体反馈再与视觉和运动副本整合，形成对物体的触知，而不是由某一个“触压觉感受器”单独完成。[^cutaneous-mechanoreceptors]

## 本体感觉连续估计身体构型与负荷 { #proprioception }

本体感觉来自肌肉、肌腱、皮肤和关节的联合输入。肌梭与梭外肌纤维并联，Ia 初级末梢对肌长变化速度和长度都敏感，II 次级末梢更突出地报告持续长度；γ 运动神经元调节梭内肌纤维张力，使肌梭在肌肉主动缩短时仍保有工作范围。Golgi 腱器官与肌纤维的力传递关系近似串联，Ib 传入反映由主动收缩和外力共同造成的肌腱张力。关节受体在接近活动范围极限和运动变化时贡献较明显，皮肤拉伸也能提供关节运动线索。[^proprioceptors]

这些输入既进入牵张反射和小脑回路，也经后索—内侧丘系参与有意识的位置觉与运动觉。中枢把多肌肉、多关节信号与运动指令、视觉和前庭输入结合，估计肢体构型；因此“肌梭测长度、腱器官测张力”是有用起点，却不是知觉与单一受体的一一映射。闭眼站立、指鼻和被动移动关节等任务减少视觉代偿，可暴露本体输入受损；具体反射回路见[反射与神经回路](neuro_reflex.md#stretch-reflex-circuit)。

## 温度感觉来自重叠且可调的分子通路 { #thermosensation }

皮肤温度主要由小直径感觉神经元的游离末梢检测，不由克氏终球和 Ruffini 小体分别充当固定的“冷点”和“热点”。TRPM8 对降温和薄荷醇敏感，是清凉感觉的重要换能通道；TRPV1 可被伤害性热、辣椒素和酸化激活，其他 TRP 通道及细胞机制也参与温暖、极端温度与组织状态的表示。不同神经元的响应范围彼此重叠，通道阈值还受膜电位、炎症介质和组织环境影响，所以不能用 10–30 °C、30–46 °C 之类固定区间把冷、暖、痛机械切开。[^thermosensation]

温度感受突出编码皮肤温度相对基线的变化。手先置于冷水或热水再接触同一杯温水，会产生不同温觉，反映外周适应与中枢比较共同作用。极冷和极热可募集伤害性感受器并产生疼痛；温度信息还通过下丘脑等网络参与体温调节，但内稳态控制与主观冷热感觉并非同一个输出，体温调节详见[能量代谢与体温](../physiology/energy.md#thermal-effectors)。

## 伤害性感受与疼痛是相关而不同的过程 { #nociception-pain }

伤害性感受（nociception）是神经系统对实际或潜在组织损伤刺激的编码，疼痛则是具有感觉和情绪维度的个体体验。伤害性感受可在未形成疼痛时驱动撤退反射和自主反应，疼痛也可能在外周伤害性感受器没有持续输入时存在；因此不能从某组感觉神经元放电直接推断一个人的疼痛，也不能因缺少可见组织损伤而否认疼痛。[^pain-terminology]

伤害性感受器多为高阈游离神经末梢，可响应强机械力、极端温度、酸、ATP 和炎症介质等刺激。细有髓 Aδ 纤维与无髓 C 纤维都包含多个分子和功能亚型：Aδ 活动常支持较早、较易定位的刺痛，C 纤维活动常参与较迟的灼痛或酸痛，但传导速度与“快痛／慢痛”、定位和情绪并非严格两栏对应。两类输入都可进入决定刺激强度、位置、回避、警觉和情绪意义的并行网络。[^nociceptors]

组织损伤释放 H$^+$、K$^+$、ATP、前列腺素、缓激肽、细胞因子和生长因子等，既可激活末梢，也可通过受体和离子通道调节降低阈值、增强反应，形成外周敏化。持续强输入还会改变脊髓背角和更高网络的突触效能、抑制平衡及感受野，形成中枢敏化。痛觉过敏指对通常有害刺激的疼痛反应增强，触诱发痛等异常性疼痛指通常不致痛的刺激引起疼痛；这些临床现象可提示敏化，却不能单凭主诉确定其精确细胞机制。[^sensitization]

## 痛觉在上行与下行回路中持续调制 { #pain-modulation }

脊髓背角在信号上行之前已整合伤害性、低阈机械和下行输入。揉擦受伤部位可通过大直径低阈机械传入募集局部抑制回路，短时减弱部分伤害性传递；这启发了经典闸门控制理论，但真实背角并非只有一个开关。中脑导水管周围灰质、延髓头端腹内侧区和蓝斑等区域把皮层、边缘系统及脑干状态转化为下行调节，在背角通过内源性阿片肽、去甲肾上腺素、5-HT、GABA 和 glycine 等信号产生抑制或易化。注意、预期、威胁、安慰和既往经验由此能够改变同一伤害性输入产生的疼痛。[^pain-modulation]

上行信号投向丘脑、脑干、岛叶、S1／S2、扣带回、杏仁核和前额叶等相互连接区域。S1／S2 较多约束位置、强度和身体表面特征，岛叶与身体内部状态整合，扣带和边缘网络参与不愉快、动机和行动选择；这些是相对功能偏重，而不是独立的“感觉痛”和“情绪痛”线路。不存在一个只要激活就等同全部疼痛体验的单一痛觉中枢或固定“疼痛矩阵”。

## 内感受与牵涉痛连接器官状态和身体表面 { #visceral-sensation }

内脏传入持续报告器官伸展、压力、化学环境、炎症和缺血等变量，参与饱腹、恶心、呼吸困难、心搏感与多种内稳态反射；大量输入不进入清晰意识，不能把内脏感觉缩减为痛觉，也不能说它同时具有“传出功能”。来自颈动脉窦、肺、消化道和膀胱等结构的传入可随 IX、X、盆内脏神经或交感周围路径进入中枢；随交感神经走行只描述解剖伴行，不会把感觉轴突变成交感传出轴突。

内脏伤害性输入往往稀疏、双侧并跨节段进入，扩张、牵拉、痉挛、炎症和缺血通常比切割内脏实质更容易产生痛；壁层腹膜等体壁来源组织受刺激时则可出现较锐利、定位较好的躯体痛。内脏与皮肤、肌肉传入在脊髓或脑干投射神经元上的会聚，使中枢有时把器官输入归因于更熟悉的体表区域，形成牵涉痛。节段会聚能够约束常见分布，但个体差异、发育和多节段投射使所谓 Head 区不是诊断器官病变的固定地图。[^visceral-referred-pain]

[^proprioceptors]: 肌梭 Ia／II 传入、γ 调节、Golgi 腱器官 Ib 传入与关节受体，参见 Purves 等 [Mechanoreceptors Specialized for Proprioception](https://www.ncbi.nlm.nih.gov/books/NBK10812/)；通路与小脑接口见[神经系统传导通路](neuro_pathway.md#spinocerebellar-pathways)。
[^thermosensation]: TRPM8 的冷与薄荷醇响应、温度响应范围及阈值的条件依赖性，参见 McKemy [TRPM8: The Cold and Menthol Receptor](https://www.ncbi.nlm.nih.gov/books/NBK5238/)；热、冷与伤害性温度由重叠神经元群及多个通道共同编码，故不采用固定温区和专门终球的一一对应。
[^pain-terminology]: 疼痛、伤害性感受、伤害性感受器及神经病理性／伤害感受性／伤害可塑性疼痛的现行术语，参见 IASP [Terminology](https://www.iasp-pain.org/resources/terminology/) 与 [Revised Definition of Pain](https://www.iasp-pain.org/publications/iasp-news/iasp-announces-revised-definition-of-pain/)。
[^nociceptors]: Aδ 与 C 伤害性感受传入的末梢、传导和多模态响应，参见 Purves 等 [Nociceptors](https://www.ncbi.nlm.nih.gov/books/NBK10965/)；本文不把纤维髓鞘、疼痛时间、定位和情绪维度机械绑定。
[^sensitization]: 外周／中枢敏化、异常性疼痛和痛觉过敏的操作性定义，参见 IASP [Terminology](https://www.iasp-pain.org/resources/terminology/) 与 [Mechanisms of Acute Pain](https://www.iasp-pain.org/wp-content/uploads/2022/10/3-Mechanisms.pdf)。
[^pain-modulation]: 低阈机械输入的节段调节以及导水管周围灰质—延髓—背角下行系统，参见 Purves 等 [The Physiological Basis of Pain Modulation](https://www.ncbi.nlm.nih.gov/books/NBK10985/)；经典闸门理论在正文中作为启发性模型而非单一开关机制。
[^visceral-referred-pain]: 内脏与躯体传入会聚、深部痛定位和牵涉痛的证据与多机制边界，参见 National Academies Press [The Anatomy and Physiology of Pain](https://www.ncbi.nlm.nih.gov/books/NBK219252/)。
