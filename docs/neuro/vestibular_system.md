# 前庭系统

前庭系统以半规管和耳石器持续估计头部旋转、平移及相对重力的姿态。它与听觉共用内耳毛细胞的机械换能原理，却把输出送入凝视稳定、姿势控制、自主反应和空间知觉网络；听觉的耳蜗频率分析与双耳编码见[听觉系统](neuro_auditory_vestibular.md)，视觉误差和眼动接口见[视觉系统](neuro_vision.md#oculomotor-reflexes)。

## 前庭迷路以两类机械装置采样头部运动 { #vestibular-sensors }

前庭毛细胞的换能复合体与耳蜗相近，但其毛束保留 kinocilium 作为极性标志：stereocilia 向 kinocilium 偏转时通道开放增多、细胞去极化，反向偏转时超极化。前庭传入在静息时已有持续放电，因此两个方向的毛束偏转能分别把放电率推高或压低。左右两侧近共面的半规管以 push–pull 方式协作，一侧兴奋通常伴随伙伴侧抑制，使共同噪声较易抵消，也使单侧功能丧失产生明显不平衡。[^vestibular-transduction]

| 感受装置 | 惯性结构 | 输入与编码 |
| --- | --- | --- |
| 三对半规管的壶腹嵴 | 毛束嵌入 cupula，内淋巴惯性使 cupula 暂时偏转 | 感受各自平面内的头部角加速度，动态响应可表示旋转速度变化；持续匀速旋转时外周响应逐渐衰减，停止时出现反向偏转，左右共面管成对比较 |
| 椭圆囊与球囊的 macula | 含 CaCO$_3$ 耳石的 otolithic membrane 对惯性和重力产生剪切 | 感受线加速度与头部相对重力的倾斜；毛束极性在 macula 内多向排列，群体活动表示二维加速度。椭圆囊偏水平、球囊偏垂直，但两者响应范围重叠 |

半规管的 cupula 与内淋巴密度接近，静态倾斜不会持续压弯它；旋转开始时内淋巴相对滞后，旋转恒定后逐渐跟上，突然停止又产生相反偏转。耳石膜因含高密度耳石，会持续响应重力，也会响应平移加速度。单个瞬间的耳石信号不能判定剪切来自头部倾斜还是直线加速，中枢必须结合半规管、视觉、本体感觉和随时间变化的内部模型解除这项 gravito-inertial ambiguity。将椭圆囊和球囊分别称为纯粹的水平、垂直传感器只是近似。[^otolith-canals]

## 前庭核把凝视、姿势、自主反应和知觉连接起来 { #vestibular-integration }

前庭神经把半规管和耳石信号送到脑干前庭核群，也有纤维直接进入小脑。前庭核经内侧纵束联系 III、IV、VI 脑神经核，以短潜伏期前庭—眼反射在头动时把眼球推向相反方向，稳定视网膜像；经前庭脊髓束和网状网络调节头颈、躯干与抗重力肌；经丘脑—皮层网络参与自运动、垂直方向和空间定向知觉。小脑以视觉误差和运动经验持续校准这些反射的增益与时序。相关束路见[神经系统传导通路](neuro_pathway.md#brainstem-descending)。

眼震由慢相和快相交替构成：慢相通常是前庭驱动的补偿性眼动，快相是重新定位的扫视样复位，临床以快相方向命名。姿势反应同样不是简单与刺激方向相反的一次收缩，而是在支持面、任务和其他感觉输入约束下重分配多关节肌力。晕动症常在视觉、前庭与本体输入彼此冲突或偏离既有内部模型时出现，恶心、苍白、出汗和呕吐来自脑干、自主及内分泌网络的联合反应；反复暴露后的适应说明它不是由“迷走神经单独兴奋”即可解释。[^vestibular-responses]
