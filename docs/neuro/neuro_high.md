# 脑状态与高级功能

同一感觉输入在清醒、困倦、慢波睡眠或快速眼动睡眠中会进入不同的皮层动力学；同一结果也可因预期、记忆和当前目标而具有不同意义。脑状态（brain state）描述全脑和局部网络在一段时间内相对稳定的活动格局，高级功能则从这些格局中形成选择、记忆、语言、情绪和目标导向行为。二者不是“背景”和“内容”的简单分工：觉醒系统改变信息进入皮层的机会，学习经验反过来塑造睡眠中的活动，动机与情绪又重设注意、自主和内分泌输出。

这些功能由相互连接的皮层、丘脑、基底神经节、海马、杏仁核、下丘脑和脑干网络共同产生。局部损伤仍可造成有规律的缺失，但“一个中枢对应一种心理功能”的地图不足以解释个体差异、任务依赖和损伤后的重组。本页以可测的脑电与睡眠状态为入口，再讨论注意与工作记忆、动机与奖赏、学习与长期记忆以及语言网络。

## 头皮脑电记录大尺度突触电流 { #eeg-biophysics }

脑电图（electroencephalogram, EEG）记录头皮不同电极之间随时间变化的电位差。信号主要来自方向相近的皮层锥体细胞群产生的跨膜突触电流：大量树突上的兴奋性和抑制性突触后电位在时间、空间上形成足够一致的电流偶极，经过脑组织、脑脊液、颅骨和头皮的传导后才可在头皮检出。单个动作电位太短、空间贡献太小，常规 EEG 因而不是神经元放电次数的直接总和。颅骨造成的空间扩散、脑沟方向和参考电极选择也使一个头皮波形不能唯一定位到某一皮层柱。[^eeg-basis]

EEG 可按频谱描述 delta、theta、alpha、beta 和 gamma 等活动。清醒闭眼时枕部常见约 8–13 Hz 的后部优势 alpha rhythm，睁眼、视觉注意或心算时常减弱；这类 alpha attenuation 过去称“阻断”。困倦常伴 alpha 消退和较多 theta 活动，深 NREM 睡眠突出高幅慢波。频段边界、空间来源和功能随年龄、任务及记录方法变化，gamma 范围还很容易混入眼肌和头皮肌电。把 alpha 等同放松、beta 等同思考、gamma 等同专注，会把统计偏重误写成一一对应的心理读数。

低幅、较快的 EEG 常被称为“去同步化”，高幅慢波则被称为“同步化”。前者表示许多偶极在慢时间尺度上的相位一致性降低，不表示皮层神经元整体停止协同，也不表示电活动更少；多个局部节律可以在同一时刻共存。频谱、相位耦联和空间传播比单独给波形贴状态标签更能表达真实网络活动。

## 诱发电位从持续脑电中提取时间锁定响应 { #evoked-potentials }

感觉刺激、动作或认知事件会在持续 EEG 上叠加较小的时间锁定变化。把同一类事件重复呈现，并按刺激或反应时刻对齐后平均，可削弱与事件无固定时序关系的背景波动，得到 evoked potential 或 event-related potential（ERP）。视觉、听觉和躯体感觉诱发电位可分别检验从感受器、周围神经到中枢通路的传导接口；注意、预期、冲突和语义处理也可改变较晚的 ERP 成分。[^erp-principles]

波峰以正负极性和大致潜伏期命名，但一个 P 或 N 成分通常来自多个同时活动的源，振幅又受参考方式、噪声、试次数和个体解剖影响。诱发电位具有毫秒级时间分辨率，却不能单凭一个头皮峰值断定某个心理步骤只发生在一个脑区。EEG、脑磁图、结构和功能影像、颅内记录以及损伤研究回答的是互补问题。

## 睡眠分期结合脑电、眼动与肌电 { #sleep-stages }

睡眠不是感觉输入减少后的均一静息，而是可逆、受调节并具有内部结构的脑状态。临床多导睡眠监测同时记录 EEG、眼电图和颏肌肌电，并按固定时间窗判定清醒、NREM 的 N1、N2、N3 以及 REM。现行成人分期把旧 Rechtschaffen–Kales 标准的第 3、4 期合并为 N3，旧材料中的 NREM Ⅰ–Ⅳ期不能与现行名称逐项并列。[^sleep-scoring]

| 状态 | 代表性多导特征 | 主要生理线索 |
| --- | --- | --- |
| 清醒 | 闭眼可见后部 alpha；睁眼时低幅混合频率活动增多，颏肌张力存在 | 对外界反应性和随意运动保持，注意水平仍可显著波动 |
| N1 | alpha 减少，低幅混合频率及 theta 增多，可见缓慢眼动 | 清醒到睡眠的过渡，容易被唤醒 |
| N2 | K complex 和 sleep spindle 是关键标志 | 丘脑—皮层回路形成特征性短暂事件，外界反应进一步降低 |
| N3 | 高幅、低频慢波占据足够比例 | 慢波活动最突出，通常在主要睡眠期前段较多 |
| REM | 低幅混合频率 EEG、快速眼动与低颏肌张力并存，可有短暂抽动 | 脑活动并非整体低下，梦境报告较多，自主和呼吸活动可较不规则 |

成年人一个主要睡眠期内会多次经过 NREM—REM 循环。N3 常偏重前半夜，REM episode 通常随夜程延长，但周期长度、阶段比例和觉醒次数随年龄、昼夜时相、既往清醒时间、药物和疾病改变。NREM 与 REM 都能直接转向清醒；“NREM 只恢复体力、REM 只恢复脑力”以及固定比例的功能分配没有充分证据。

## 昼夜时相与睡眠压力共同安排睡眠 { #sleep-regulation }

两过程模型把睡眠倾向分为随清醒累积、在睡眠中消散的 homeostatic process S，以及由内源性昼夜钟组织的 circadian process C。延长清醒后，随后 NREM 慢波活动常增强，说明睡眠深度不仅取决于时钟时间。SCN 接收视网膜内在光敏神经节细胞输入，并通过多条神经和体液通路同步行为与外周节律；它不会直接计算全部“睡眠债”。两过程模型是有预测力的现象学框架，真实睡眠还受运动、进食、温度、应激、社会时程和局部脑区使用历史影响。[^two-process]

腺苷在持续清醒后的某些脑区增加并可抑制觉醒相关活动，咖啡因拮抗腺苷受体是其促醒作用的重要机制；腺苷却不是唯一睡眠物质，也不能用一个全脑浓度解释 process S。夜间褪黑素主要传递生物学夜晚和相位信息，而非积累睡眠压力；视网膜—SCN—交感—松果体的路线及相位依赖作用见[松果体褪黑素与昼夜时相](../physiology/endo/endo_other.md#pineal-melatonin)。

## 觉醒、NREM 与 REM 由分布式状态网络切换 { #sleep-wake-circuits }

觉醒依靠多套相互重叠的上行系统维持。脑桥与延髓的 glutamate 神经元、locus coeruleus 的 norepinephrine、raphe nuclei 的 5-HT、tuberomammillary nucleus 的 histamine、basal forebrain 的 ACh／GABA 神经元，以及 lateral hypothalamus 的 orexin 神经元，以不同投射和放电模式调节丘脑、皮层及行为反应性。破坏其中一条通路往往由其他通路部分补偿，不能把 ascending reticular activating system 当作一条单线或一个递质开关。[^sleep-wake-circuitry]

视前区的 GABA／galanin 睡眠活跃神经元可抑制多套促醒群体，促醒系统又反向抑制睡眠活跃群体，形成能够快速转换状态的相互抑制网络。Orexin 输入广泛兴奋促醒系统并把代谢、情绪和行为需要带入状态控制，更突出的作用是稳定清醒与睡眠边界；orexin 缺失造成的状态不稳定是 narcolepsy 的重要机制接口，疾病表型留在[神经系统疾病](neuro_disease.md)。

REM 也不由一个“脑桥胆碱能中枢”独立生成。脑桥 sublaterodorsal region 的 glutamatergic 神经元、ventrolateral periaqueductal gray／lateral pontine tegmentum 的 REM-off 网络、medulla 和脊髓抑制通路以及 cholinergic、monoaminergic、MCH、orexin 调制共同参与。下降通路降低大多数骨骼肌张力，上行与局部回路形成 REM 的皮层活动和眼动；具体细胞证据大量来自啮齿动物，向人类睡眠逐细胞外推仍需保留边界。[^rem-circuitry]

## 睡眠改变记忆巩固而非承担单一功能 { #sleep-memory }

睡眠后多类记忆任务的保持或离线改善优于同等时长清醒，但效应取决于任务、编码质量、睡眠时相和干扰控制。NREM 中皮层 slow oscillation、丘脑 sleep spindle 与海马 sharp-wave ripple 的相位耦联，为近期海马表征的重放及海马—新皮层信息交换提供候选机制；人类头皮 EEG、颅内记录、动物干预和 targeted memory reactivation 共同支持这条主线，却没有证明每次振荡都搬运一条完整记忆。[^sleep-consolidation]

REM 的 theta 活动、较高 cholinergic tone 和特殊神经调质环境可能有利于部分程序、情绪和整合性学习；不同研究结果并不支持“学习记忆只在 REM 完成”。睡眠还参与突触稳态、代谢和免疫等过程，这些假说彼此不必排斥，但各自的细胞机制和人体因果证据强度不同。生长激素、皮质醇、呼吸和体温如何随睡眠状态改变，分别由相应生理页面展开。

## 注意与工作记忆维持当前任务模型 { #attention-working-memory }

注意使有限处理资源偏向与任务相关的外界或内部表征。空间定向、警觉维持、特征选择和冲突监控使用部分重叠的 frontoparietal、thalamic、basal ganglia 和 neuromodulatory networks；注意增强某类信息的可读出性，同时抑制竞争输入。它不是进入意识的唯一门槛，也不是前额叶单独向其余脑区发出的命令。

工作记忆（working memory）使当前不可见的信息短时保持、更新并用于比较、推理和行动。内容可由视觉、听觉、语言、运动或长期语义网络维持，lateral prefrontal cortex 更突出地控制选择、规则和抗干扰，parietal 与相应感觉皮层参与表示内容。持续放电、短时突触状态和活动静默机制都可能在不同延迟与任务中参与，所以工作记忆不等同一个固定容量的前额叶储藏箱，也不等同所有短时记忆。[^working-memory]

执行控制包含设定目标、抑制优势反应、切换规则、监测错误和分配努力。实验任务常同时要求注意、工作记忆、语言或运动，单项测验表现又受动机、速度和教育经验影响。前额叶损伤可显著破坏控制，但完整表现需要前额叶与顶叶、扣带、丘脑、基底神经节和小脑的动态协作。

## 动机把内部状态和结果价值转换为行动 { #motivation-reward }

动机使某些结果获得优先级，并决定个体愿意为其付出多少努力。摄食、饮水、性和防御行为具有进化形成的回路约束，却都受发育、激素、当前内环境、学习和社会情境改变，不能按“先天本能”与“后天行为”截然分开。下丘脑把能量、渗透和生殖状态接入效应系统，自主稳态接口见[自主神经与内脏调控](neuro_autonomic.md#hypothalamic-integration)；本页关注结果预测和行动选择。

奖赏可分为至少三个相互作用的过程：结果带来的 hedonic impact（liking），线索获得的 incentive salience（wanting），以及行为—结果关系的 learning。VTA／substantia nigra dopamine neuron 的 phasic activity 常随 reward prediction error 变化：未预期奖赏增强，完全预期的奖赏响应转向预测线索，预期奖赏缺失时活动下降。这类信号有助于更新价值和动作策略，但 dopamine 也参与 movement、vigor 和其他状态调节，不能把它称为“快乐分子”。[^reward-components]

Hedonic liking 依赖 nucleus accumbens、ventral pallidum 等区域内较小的 opioid／endocannabinoid-sensitive hotspots 及更广泛的感知网络；mesolimbic dopamine 对 cue-triggered wanting 的作用更突出。orbitofrontal cortex 表示状态依赖的结果价值，amygdala、hippocampus 和 striatum 分别把情绪显著性、情境与动作历史带入选择。结果价值会随饱腹、威胁和社会环境重估，而不是存放在一个永久“奖赏中枢”中。

## 情绪协调感觉评价、身体反应与行动准备 { #emotion-networks }

情绪包含主观体验、感觉评价、记忆、自主—内分泌反应、表情和行动倾向，这些成分可以同步，也可以部分分离。Amygdala 的多个核对威胁线索学习、显著性评估及向 hypothalamus、periaqueductal gray 和 brainstem 的防御输出十分重要；hippocampus 提供情境，insula 和 cingulate cortex 整合身体状态与行动价值，prefrontal networks 则按规则、可控性和长期目标调节响应。杏仁核活动不等同主观恐惧，下丘脑刺激引出的防御行为也不是“愤怒中枢”被直接打开。[^emotion-networks]

经典“假怒”实验在去除大部分前脑联系的动物中保留下丘脑—脑干防御输出，揭示皮层和下丘脑连接对反应阈值的调节。切断实验同时严重改变整个网络，不能据此断定正常情绪只是皮层持续压制一个皮层下程序。人类防御还随威胁距离、逃避可能性、社会信息和既往经验在 amygdala、prefrontal cortex、hypothalamus 与 midbrain 网络之间重配。情绪相关的心率、出汗、泪液、胃肠和激素变化同样按情境组合，不是交感或副交感整套单向切换。

## 成瘾重塑奖赏学习、压力与控制网络 { #addiction }

成瘾表现为物质或行为线索获得过强的动机控制、使用逐渐习惯化、戒断期负性情绪增加以及抑制和决策受损的组合。药物可通过不同分子靶点迅速改变 dopamine、opioid、GABA、glutamate 或其他系统；反复暴露后，ventral／dorsal striatum、extended amygdala、prefrontal cortex、hippocampus 与 interoceptive networks 的可塑性共同增加复吸易感性。并不存在一条对所有成瘾都相同的“奖赏回路劫持”路径。[^addiction-circuitry]

强烈 wanting 可以与实际 liking 分离，线索和情境在停止使用很久后仍可能引发寻求。负强化、压力、睡眠、社会环境、药代动力学和个体易感性又改变病程；这使成瘾既不能归为意志薄弱，也不能仅由 dopamine 峰值诊断。具体物质、耐受、戒断、治疗和精神共病属于疾病与药理专题，本页保留正常学习系统如何转为持续失调的机制边界。

## 学习改变刺激、行动与结果之间的关系 { #learning-forms }

非联合学习考察单一刺激反复出现后的改变。习惯化使对无害、重复刺激的响应下降，敏感化使强刺激后的广泛反应增强；两者都需排除感受器适应、运动疲劳等非学习因素。联合学习建立事件之间的预测关系：Pavlovian conditioning 使条件线索预测结果，instrumental／operant learning 使行动后果改变再次选择该行动的概率。时间接近有助于学习，contingency 和 prediction error 比单纯同时出现更能决定联系是否建立。

这些形式不是从“低级”到“高级”的单一路径。一个动物或人可以同时学习线索—结果、行动—结果和刺激—反应关系，goal-directed control 与 habit 会随训练、压力和结果贬值而竞争。消退是新安全或无结果关系的学习，不是原记忆被擦除；换情境、间隔一段时间或再次遭遇未预期结果后，已减弱反应可能恢复。

## 多套记忆系统并行保存经验 { #memory-systems }

记忆可按内容和表达方式区分，而不能只按保存时间排成三级仓库。Declarative memory 支持对事实和事件的灵活回忆，包括 semantic 与 episodic memory，形成新记忆尤其依赖 hippocampus、entorhinal／parahippocampal cortex 与分布式 neocortex 的相互作用。Nondeclarative memory 是技能、习惯、priming、条件化、习惯化和敏感化等多种形式的总称，分别偏重 striatum、cerebellum、amygdala 和相关 neocortical circuits；它不等同“反射记忆”，也不保证永久不忘。[^memory-systems]

患者 H.M. 双侧 medial temporal lobe 切除后出现严重的顺行性陈述记忆障碍，却仍能短时保持正在处理的信息并逐日改善镜描技能。这一经典分离证明记忆不是单一能力，也说明 hippocampus 对所有短时活动和所有技能学习都非必需。后续病例和实验进一步显示海马有助于迅速绑定跨时间、空间的项目关系；熟练技能、习惯和 priming 则依靠不同网络。[^hm-memory]

Working memory 描述当前任务中的主动保持与操作，long-term memory 描述可跨较长时间重新访问的改变；二者不由一个固定分钟阈值分开。Sensory memory 是感觉系统中极短暂、容量较大的痕迹。每种长期记忆又可强弱不同、受干扰或随线索改变，所谓“永久第三级记忆”不是可直接观察的独立仓库。

## 记忆在编码、巩固与提取中持续转化 { #memory-consolidation }

Encoding 选择并组织当时的信息，consolidation 使新形成的表征逐渐稳定和重组，retrieval 则由当前线索重建可用于行为的内容。Synaptic consolidation 在学习后数小时内涉及受体运输、激酶、基因表达和蛋白合成等细胞过程；systems consolidation 在更长时程改变 hippocampus 与 neocortex 对记忆检索的相对贡献。关于富含情境细节的远期 episodic memory 是否始终需要 hippocampus，标准模型与 multiple-trace／transformation hypotheses 仍有分歧。[^memory-consolidation]

NMDA receptor-dependent Ca$^{2+}$ 信号、AMPA receptor trafficking、long-term potentiation／depression 和结构可塑性为记忆提供候选细胞机制，详见[突触传递](neuro_synapse.md#long-term-plasticity)。LTP 能在特定突触形成持久效能变化，却不等同一段完整记忆；真实学习同时改变多个兴奋、抑制和调质突触，蛋白合成也是维持若干长期改变的必要条件之一，而不是记忆内容本身。

提取并非只读操作。某些已巩固记忆在带来 prediction error 或新信息的 reactivation 后会短暂不稳定，再经历 reconsolidation；另一些提取只加强原痕迹或形成并行的新痕迹。记忆强度、年龄、提示时长和情境都构成边界条件，所以不能说每次回忆都会完整重写记忆。顺行性遗忘指损伤后形成新记忆受损，逆行性遗忘指损伤前记忆的提取受损；两者均可有时间梯度和记忆类型差异，不对应固定的“第一级转第二级”故障。[^reconsolidation]

## 语言由双向皮层网络连接声音、意义与动作 { #language-networks }

语言把语音、文字或手势形式与词汇、句法、语义和交流意图连接。听觉语音在双侧 superior temporal cortex 接受早期分析，随后形成相互作用的 ventral 与 dorsal streams：ventral stream 经中、前 temporal regions 把声音映射到词汇和意义，dorsal stream 经 temporoparietal interface、premotor 和 inferior frontal regions 把声音映射到发音动作并支持重复与在线误差校正。两条通路都具双向连接，阅读、书写和手语还分别招募视觉、顶叶和运动系统。[^language-streams]

多数右利手和相当多左利手的语言产生网络偏左侧化，但侧化是连续分布，并不由惯用手绝对决定。右半球在 prosody、话语情境、比喻和社会语用等方面常有较大贡献，空间、音乐和面孔加工也不是右半球独占。把左脑列为语言逻辑、右脑列为空间艺术的两栏人格分类，没有可靠的网络依据。

Broca 与 Wernicke 的病例建立了局灶损伤可以选择性破坏语言的关键证据。现代 lesion-symptom mapping 显示，非流利表达、语音动作、句法、词义理解、命名和重复由不同但重叠的皮层与白质网络支持；Broca area 单独损伤通常不足以产生完整持久的 Broca aphasia，posterior temporal lesion 也不对应一个封闭的“感觉语言中枢”。Aphasia、alexia、agraphia、apraxia、neglect 和 prosopagnosia 的症状组合及病变定位将在[神经系统疾病](neuro_disease.md)按网络损伤展开。[^aphasia-networks]

## 高级功能的证据依赖任务与测量尺度 { #evidence-boundaries }

单神经元记录提供精细时序和细胞选择性，病灶研究接近必要性证据，刺激和药理干预可检验因果，EEG／MEG 提供毫秒尺度，fMRI 则以血氧动力学间接定位网络。每种方法都有取样边界：一个区域在任务中激活，不证明它只承担该功能；损伤后的缺失也可能来自白质断连、低灌注或远隔效应。跨物种研究能揭示保守回路，但语言和主观体验不能从啮齿动物行为逐项推断。

高级功能的可靠解释应把心理操作定义清楚，再比较网络活动、扰动与行为结果。睡眠阶段、奖赏误差、工作记忆负荷或语言任务都是操作性定义，不是脑中可直接指认的物体。分布式网络观点保留了局部结构的专业化，同时避免把一幅平均激活图、一次经典动物实验或一条病灶口诀当成全部机制。
