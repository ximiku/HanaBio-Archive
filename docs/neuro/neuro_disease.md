# 神经系统疾病

神经系统疾病把分子变化、细胞损伤和行为表型连接在同一条因果链上。一段肢体无力可以来自大脑皮层、内囊、脊髓前角、周围神经、神经肌肉接头或骨骼肌；记忆下降则可能由退行性病变、血管损伤、癫痫活动、炎症、代谢紊乱、药物或全身性疾病造成。疾病名称只有放回病变位置、起病速度和受损功能系统中才具有解释力。

本页不逐一罗列诊断标准和治疗方案，而以几个反复出现的病理过程为主线：供血中断与出血、异常同步放电、炎症和脱髓鞘、蛋白质稳态失衡、遗传与细胞器缺陷、突触传递阻断、感染及肿瘤。它们分别从细胞、递质、回路、束路和大尺度网络改变神经功能，也说明为什么同一种机制会产生不同综合征、同一种综合征又可能具有不同病因。

## 定位与时间进程共同限定病因 { #localization-tempo }

神经病学首先把症状还原为可检验的功能缺失。单侧面臂无力伴失语提示优势半球皮层网络，交叉性脑神经与躯体体征提示脑干，双下肢感觉平面伴膀胱功能改变提示脊髓；远端对称性感觉减退常指向长度依赖性周围神经病，易疲劳而感觉保存则把问题移向神经肌肉接头。具体束路、交叉和侧别见[神经系统传导通路](neuro_pathway.md)，周围神经检查与电诊断接口见[周围神经系统](neuro_pns.md#peripheral-localization)。

时间进程进一步收窄机制。数秒至数分钟达到高峰常见于血管事件或发作，数小时至数日可见于感染、炎症、中毒和代谢失衡，数周至数月可见于肿瘤、亚急性炎症和某些营养缺乏，持续多年进展则较符合退行性、遗传性或慢性代谢病。复发—缓解提示病理过程可间歇激活或传导可恢复；阶梯样恶化、固定进展和波动性疲劳又分别引向不同机制。这些只是概率线索，偏头痛先兆、短暂性脑缺血、局灶性癫痫和低血糖都可能短暂产生局灶症状，慢性病也可因急性并发症突然失代偿。

| 主要受损层级 | 表型与测量线索 | 代表性机制 |
| --- | --- | --- |
| 神经元与突触 | 发作、认知或特定递质相关运动异常；EEG、代谢／受体影像和分子标志物 | 兴奋性失衡、蛋白聚集、递质缺失、毒素阻断 |
| 髓鞘与轴突 | 传导阻断、长束征、远端感觉与无力；MRI、诱发电位、神经传导和肌电图 | 炎性脱髓鞘、轴突变性、机械或代谢损伤 |
| 局部回路与核团 | 帕金森综合征、共济失调、脑神经组合征；结构／功能影像、眼动和运动生理 | 选择性细胞易损、回路增益和节律改变 |
| 大尺度网络 | 失语、忽略、失认、意识或睡眠状态异常；病灶—症状映射、EEG 和认知检查 | 网络节点或连接离断、状态切换失稳 |

任何一项检查都只观察这条链的一层。MRI 显示结构和某些组织性质，EEG 记录大尺度电生理，脑脊液反映与脑和脊髓相通液体中的细胞及分子，遗传检测给出变异而非必然表型。诊断来自临床综合征、解剖定位、病程和相互独立证据的收敛。

## 脑血管事件把灌注变化转成局灶网络缺失 { #stroke }

卒中包括缺血性梗死和脑内或蛛网膜下腔出血。动脉闭塞使供氧、葡萄糖和代谢产物清除同时受限；ATP 耗竭后离子泵失效，膜去极化、谷氨酸释放、Ca$^{2+}$ 负荷、自由基和蛋白水解相互放大，并伴随细胞肿胀、血脑屏障破坏和免疫反应。严重低灌注区可迅速形成不可逆损伤的缺血核心，周围仍保留部分代谢和结构完整性的组织构成动态半暗带。侧支循环、温度、血糖、闭塞位置和再灌注时间共同决定核心是否继续扩展，因此半暗带不是固定的一圈组织。[^stroke-penumbra]

恢复血流能挽救尚存活的组织，也是急性缺血性卒中治疗的中心目标；再灌注同时可带来氧化反应、炎症、屏障通透性增加和出血性转化风险。这里的关键不是把再灌注写成单纯损伤，而是比较及时恢复底物供给的巨大收益与特定组织状态下的附加损害。脑内出血则以血肿造成的组织破坏和占位效应为起点，继发水肿、血液成分毒性和炎症继续扩大影响。

表型由血管供应区和网络结构共同决定。优势半球大脑中动脉区损伤可同时影响面臂运动、语言与视野；内囊小病灶可能因纤维密集而造成明显纯运动缺失；脑干病变可产生脑神经与对侧躯体的交叉体征。急性期软弱和反射降低可先于后来的痉挛、腱反射亢进和病理性跖反射，所以上运动神经元损伤并非从起病第一刻就表现为固定“硬瘫”。

## 发作与癫痫源于网络兴奋性的短暂失控 { #epilepsy }

癫痫发作（epileptic seizure）是脑内异常过度或同步神经活动造成的短暂症状事件；癫痫（epilepsy）则要求存在持续产生发作的易感性。一次由急性低血糖、高热、戒断或电解质紊乱诱发的发作，并不自动等于癫痫。现行操作定义还允许在一次非诱发发作后，若复发风险足够高或可诊断特定癫痫综合征，即建立癫痫诊断。[^epilepsy-definition]

异常放电可从局灶网络开始，也可从一开始就涉及双侧网络；发作表现取决于被招募的回路，而不只取决于放电强弱。运动皮层受累可出现节律性抽动，内侧颞叶网络可产生体验性、记忆性或自主症状，双侧丘脑—皮层网络快速受累则可能造成意识和全身运动改变。2025 年 ILAE 更新分类仍以局灶、全面性、不明起源和未分类为四个主类，并将意识状态与其他临床特征作为进一步描述维度。[^seizure-classification]

发作阈值由内在膜电流、兴奋与抑制突触、胶质细胞 K$^+$ 和递质稳态、网络连接以及调质状态共同决定。某些离子通道或突触蛋白变异可直接改变兴奋性，皮层发育异常、瘢痕、肿瘤和卒中则建立易于反复同步的局部网络。EEG 的棘波等癫痫样放电支持异常兴奋性，却可能在一次常规记录中缺失，也可能见于无临床发作的人；发作视频、病史、影像和病因检查仍须共同解释。

## 炎症与髓鞘损伤改变传导安全系数 { #demyelination }

多发性硬化（multiple sclerosis, MS）是中枢神经系统的慢性免疫介导疾病。病灶可累及白质、皮层灰质、视神经和脊髓，包含不同程度的炎症、少突胶质细胞与髓鞘损伤、胶质反应、轴突断裂和神经元丢失。脱髓鞘增加膜漏电并暴露原先集中在郎飞结的离子通道组织，使动作电位延迟或传导阻断；炎症消退、离子通道重分布和再髓鞘化可带来部分恢复，反复或持续轴突损伤则积累固定残疾。[^ms-pathology]

同一名患者的不同病灶可造成视神经炎、脑干眼动异常、感觉、运动、膀胱或认知症状。MRI 观察病灶在空间和时间上的分布，脑脊液寡克隆带反映鞘内免疫球蛋白合成，诱发电位可揭示临床不明显的传导延迟；三者测量的不是同一对象，也没有一种结果独自概括全部病理。免疫治疗可减少新的炎性活动，但已经断裂的长轴突和丢失的神经元不能仅靠抑制复发恢复。

外周神经的免疫性脱髓鞘具有不同靶结构。Guillain–Barré syndrome 常急性进展，免疫反应攻击周围神经或神经根，可形成脱髓鞘型或轴突型损伤；传导速度、远端潜伏期、传导阻滞和针电图把髓鞘功能与轴突丢失区分开来。中枢少突胶质细胞与外周 Schwann cell 形成的髓鞘在分子组成、修复环境和免疫靶点上不同，不能把 MS 与周围神经炎视为同一疾病发生在两个位置。

## 神经退行性疾病具有选择性易损与跨网络扩展 { #neurodegeneration }

神经退行性疾病常在症状出现前经历较长的分子和细胞变化。蛋白错误折叠、蛋白酶体与自噬—溶酶体负荷、线粒体与轴突运输障碍、RNA 代谢、突触失稳、胶质和免疫反应可以共同参与。某种聚集蛋白是病理标志，不表示所有聚集体同样有毒，也不表示它单独解释细胞选择性和临床异质性。不同疾病还可在同一脑内形成混合病理。

### Alzheimer 病连接淀粉样蛋白、tau 与网络衰退 { #alzheimer-disease }

Alzheimer 病的特征性病理包括细胞外 amyloid-$\beta$ 沉积和神经元内异常磷酸化 tau 聚集，并伴随突触和神经元丢失。Tau 在正常轴突中参与微管相关功能；疾病过程涉及构象、磷酸化、定位和聚集状态的一系列变化，而不是 tau 从微管解离这一个步骤。Amyloid 与 tau 可通过 PET、脑脊液和血液标志物从不同角度估计，结构影像和认知测验则分别描述组织萎缩与功能表现。[^ad-biomarkers]

生物标志物可在明显认知症状前出现，使 Alzheimer 病能够作为连续病理过程研究；临床上把无症状的标志物阳性者直接称为患病仍有定义和沟通争议。痴呆是认知下降已妨碍独立生活的综合征，不是 Alzheimer 病的同义词；血管病、Lewy body disease、frontotemporal degeneration、药物和多种全身状况都能产生痴呆表型。急性、波动的注意和意识改变更符合 delirium，需要寻找即时诱因。

### Parkinson 病改变基底神经节而不限于多巴胺 { #parkinson-disease }

典型 Parkinson 病以黑质致密部多巴胺能神经元丢失和纹状体去神经支配为重要病理基础，常伴富含 $\alpha$-synuclein 的 Lewy pathology。多巴胺减少改变直接、间接、超直接通路以及皮层—基底神经节—丘脑环的活动模式，产生运动迟缓、僵硬和静止性震颤等组合；具体回路见[躯体运动调控](neuro_movement.md#basal-ganglia)。[^pd-neuropathology]

病变也可累及嗅觉、自主、睡眠、边缘和皮层系统，非运动症状可能早于或晚于运动表型。左旋多巴补充多巴胺合成底物，能显著改善许多运动症状，却不等于替换已经丢失的神经元，也不能由疗效反推出所有症状均由单一递质缺乏造成。帕金森综合征（parkinsonism）是运动综合征，还可由药物、血管病和其他神经退行过程造成。

### Huntington 病和 ALS 显示基因、细胞类型与回路的交汇 { #hd-als }

Huntington 病由 *HTT* 基因 CAG 重复扩增引起，呈常染色体显性遗传；重复长度影响平均起病年龄但不能精确预测个体病程。纹状体中型多棘神经元和皮层—纹状体连接的进行性失调、随后更广泛的神经变性，共同造成舞蹈样运动、执行与认知下降以及精神行为改变。早期表型不能简化为“纹状体 GABA 减少”，因为不同投射细胞、皮层输入和疾病阶段的改变并不一致。[^huntington-circuits]

肌萎缩侧索硬化（amyotrophic lateral sclerosis, ALS）累及上、下运动神经元，可同时出现痉挛和病理反射、肌无力、萎缩及束颤。多数病例为散发性，部分与 *C9orf72* 重复扩增、*SOD1*、*TARDBP*、*FUS* 等变异有关；TDP-43 异常是大多数病例的重要病理标志，但 *SOD1* 和 *FUS* 相关亚型可呈不同蛋白病理。额颞叶认知行为改变与运动神经元病形成连续谱，说明“运动系统疾病”也可能扩展到更广网络。[^als-pathology]

## 遗传与细胞器缺陷通过选择性负荷表现 { #genetic-organelle }

单基因病最清楚地展示从分子缺陷到细胞表型的路径，却很少意味着“一基因一症状”。Tay–Sachs disease 中，双等位基因 *HEXA* 致病变异降低 $\beta$-hexosaminidase A 对 GM2 ganglioside 的降解，GM2 在神经细胞溶酶体中积累。残余酶活不同可形成婴儿、青少年和迟发型连续谱；这比“缺一种溶酶体酶便统一出现储积症”更能解释发病年龄和进展速度。[^hexa-disorders]

原发性线粒体病既可来自 mtDNA，也可来自核基因。异质性、突变负荷在组织间的分布、阈值效应和不同组织能量需求共同决定脑、视神经、肌肉、心脏等器官组合。MERRF 可表现肌阵挛、癫痫、共济失调和肌病，Leber hereditary optic neuropathy 则突出视网膜神经节细胞与视神经易损；母系传递适用于许多 mtDNA 变异，并不适用于核基因所致线粒体病。细胞器机制见[线粒体、叶绿体与过氧化物酶体](../cell/organelles.md#mitochondrial-quality-control)。[^mitochondrial-disorders]

重复扩增还说明遗传检测结果必须结合变异类型。Huntington 病的编码区 CAG 扩增产生 polyglutamine 蛋白；某些非编码重复可通过 RNA、异常翻译产物或基因表达改变致病。家系中的外显率、嵌合、亲本来源效应和修饰基因都会改变表型，分子确诊与个体预后预测不是同一件事。

## 周围神经与神经肌肉接头定位传递故障 { #peripheral-nmj }

周围神经病可主要损伤轴突、髓鞘或两者。长轴突的代谢与运输距离使许多毒性和代谢性轴突病先累及足部，形成长度依赖的“袜套样”感觉和远端无力；局灶压迫、血管炎或免疫损伤则可呈单神经或多灶分布。轴突断裂后 Wallerian degeneration 沿远端发生，外周神经在 Schwann cell 和基底膜通道支持下具有一定再生能力，但距离、错配、瘢痕和靶肌萎缩限制恢复。

重症肌无力多由针对突触后 ACh 受体、MuSK 或相关蛋白的自身抗体破坏受体数量与终板结构，安全系数下降，表现为活动后的波动性无力。Lambert–Eaton 肌无力综合征的主要靶点位于突触前 P/Q 型电压门控 Ca$^{2+}$ 通道，初始递质释放减少，而重复活动带来的末梢 Ca$^{2+}$ 积累可产生短暂易化。两者都发生在接头，却位于传递链的不同一侧。[^myasthenic-syndromes]

细菌神经毒素进一步揭示细胞靶点与综合征的关系。肉毒神经毒素在外周胆碱能末梢裂解特定 SNARE 蛋白，阻断 ACh 释放而造成弛缓性麻痹；破伤风神经毒素经运动末梢进入并逆行运输，在脊髓和脑干抑制性中间神经元中裂解 synaptobrevin，阻断 glycine 与 GABA 释放，去抑制运动输出而产生痉挛。两者的蛋白酶机制相近，临床方向相反来自进入的神经元与被阻断的递质不同。[^clostridial-toxins]

## 感染、异常蛋白与肿瘤改变神经环境 { #infection-tumor }

脑膜炎主要累及脑膜和蛛网膜下腔，脑炎则以脑实质功能障碍为核心，两者可重叠。病原体进入中枢后，直接细胞损伤、免疫反应、血脑屏障通透性改变、水肿、颅内压升高和血管并发症共同决定表型。脑脊液细胞、蛋白、葡萄糖、培养与核酸检测回答不同问题，取样时间和既往抗感染治疗会改变结果。

Prion disease 是特殊的快速进展性神经退行病：异常构象的 prion protein 可模板化促使宿主蛋白改变构象，形成可传播的蛋白质稳态故障。多数人类病例为散发性，也有遗传性和获得性形式；这里的“传播”具有严格生物学含义，不能据蛋白在细胞间扩散就把 Alzheimer 或 Parkinson 病归为传染病。

中枢神经系统肿瘤通过浸润、压迫、阻塞脑脊液、破坏屏障和诱发癫痫造成症状。颅腔容积受限使良性组织学肿瘤也可能因位置产生严重后果。现行 WHO 分类把组织形态与分子改变整合进诊断，例如不同弥漫性胶质瘤实体不能只凭显微镜外观命名；分子分类有助于估计生物学行为和治疗反应，但仍须与部位、年龄和临床状态结合。[^who-cns-tumours]

## 网络综合征由节点损伤与连接离断共同形成 { #network-syndromes }

感觉障碍也可能出现在感受器之后的不同层级。Glaucoma 是以视网膜神经节细胞轴突丢失和特征性视野改变为核心的进行性视神经病，眼压升高是重要且可干预的风险因素，却不是所有病例都必须具备的定义条件。单眼或不对称的传入损伤可形成 relative afferent pupillary defect；对光反射受损而近反射相对保存的 light–near dissociation 则可能来自中脑、视网膜或周围通路等不同病变，不能仅凭这一体征指定病因。眼压、视野、眼底结构与瞳孔回路的详细接口见[视觉系统](neuro_vision.md#refraction-aqueous)。

失语是语言理解或产生系统的获得性障碍，可影响语音、词汇、句法、语义、复述、阅读和书写的不同组合。经典 Broca 或 Wernicke 类型有定位价值，真实病灶常同时损伤皮层区域、深部白质和灌注边界，症状还随急性低灌注消退和网络重组而变化。失读与失写也不各自对应唯一脑回；它们需按视觉、正字法、语音、语义和运动输出环节分析，并与一般视力、注意和运动障碍区分。

Apraxia 指在基本肌力、感觉和理解不足以解释时，习得性目的动作的计划或执行受损；agnosia 指基本感觉输入尚可时不能识别对象。Prosopagnosia 突出面孔身份识别网络障碍。空间 neglect 则是对病灶对侧空间或身体信息的选择和行动偏置，常见于右半球注意网络损伤；它不同于初级视野缺损，二者可以并存。网络表型的可靠定位依靠一组任务中的一致分离，而不是单个床旁题目对应一个“中枢”。[^network-deficits]

状态网络也可选择性失稳。Narcolepsy type 1 的核心病理是外侧下丘脑 orexin／hypocretin 神经元显著丢失，清醒维持及 REM 边界因而不稳定，可出现日间过度嗜睡、猝倒、睡眠瘫痪和入睡期 REM 现象。HLA 关联和 T 细胞证据强烈支持免疫介导假说，但触发和选择性杀伤的完整因果链尚未确定。Type 2 narcolepsy 通常没有同样明确的 orexin 缺乏，不能由一种机制统括。[^narcolepsy]

疼痛同样可成为疾病状态。Neuropathic pain 要求躯体感觉系统存在病变或疾病，异位放电、离子通道变化、中枢敏化和抑制减弱可使轻触诱发痛或疼痛持续；nociplastic pain 描述在没有足以解释疼痛的组织损伤或躯体感觉病变时，伤害感受加工发生改变。二者可与 nociceptive pain 重叠，术语是机制假设和临床分型工具，不是凭主观强度排序。

## 治疗与恢复作用于不同因果层级 { #treatment-recovery }

病因治疗试图移除或抑制起始因素，例如再通闭塞血管、控制感染、抑制致病免疫反应或校正特定代谢缺陷；疾病修饰治疗旨在降低后续损伤速率；对症治疗改变递质、离子通道或回路输出，使功能改善但未必改变原始病程。左旋多巴改善多巴胺依赖的运动功能、抗发作药降低网络兴奋性、AChE 抑制增强残余接头传递，分别展示了“功能可调”与“细胞已恢复”的差别。

神经恢复来自水肿和炎症消退、传导恢复、突触权重改变、剩余通路重组、策略学习以及有限的轴突和髓鞘修复。中枢长轴突再生受内在生长程序、髓鞘相关抑制信号和胶质瘢痕等限制，康复训练通过任务特异、重复和反馈利用尚存网络的可塑性。恢复曲线因此既不是受损细胞简单再生，也不是把功能任意“搬到另一半脑”。

生物标志物是否进入临床，还需依次验证分析准确性、与病理或预后的关系、对具体人群的增益以及据此改变决策能否改善结局。相关性、动物模型逆转和人体症状改善属于不同证据层级。把疾病放在分子—细胞—回路—行为链中，目的正是让每项证据落在它真正能够支持的位置。
