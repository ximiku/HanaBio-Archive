# 细胞命运决定与胚胎诱导

同一个受精卵产生肌细胞、神经元、肠上皮和生殖细胞，并不是因为卵裂时把不同基因平均分成了不同版本。多数体细胞保留大致相同的基因组，差异来自细胞质中的母源物质、细胞之间的信号、所在位置和既往状态共同改变基因表达。发育中的细胞也并非一步取得终末身份：它可能先偏向若干可选方向，随后在特定环境中收窄潜能，最后才出现可见的结构和功能。

“命运”因此既是正常胚胎中的观察结果，也是实验条件下的判断。命运图谱说明细胞通常会产生什么，分离培养检验它离开邻居后能产生什么，异位移植则检验新环境能否改变这一结果。只有把这些实验放在一起，才能区分细胞已经携带的内部信息、邻近组织提供的诱导和组织位置提供的坐标。

## 命运承诺由实验判据定义 { #commitment-assays }

细胞的预期命运（prospective fate）是它在未受扰动胚胎中的正常去向，发育潜能（potency）则是它在允许条件下能够产生的全部细胞类型。两者可以相等，也可以相差很大。海胆早期卵裂球在完整胚胎中只贡献一部分组织，分离后却可能调整发育并形成相对完整的幼体，说明它的潜能大于正常命运。

命运承诺（commitment）通常分成指定与决定两个操作阶段。把细胞放进不推动其他命运的中性环境，如果它仍按原方向分化，就称该命运已被指定（specification）；若把它移入会推动另一命运的胚胎区域，它仍保持原方向，则称已经决定（determination）。分化（differentiation）是随后可检测的结构、代谢和功能状态，例如肌节组装或神经递质合成。指定和决定描述的是在某种实验强度下测得的稳定程度，不是细胞内部突然落下的两道闸门。更强的重编程、损伤或实验干预仍可能改写通常被视为“已决定”的状态。[^commitment-definitions]

中文教材有时把 specification 译为“特化”，也把整个承诺过程称为“定型”。这些译法容易与 specialization 混淆；“指定—决定—分化”更能保持三个实验概念的边界。判断时还应注明物种、阶段、移植位置和培养条件；缺少这些条件的“不可逆”并不是可复现实验结论。

## 三种指定方式在同一胚胎中接力 { #specification-modes }

自主指定、条件指定和合胞体指定描述信息进入命运决定的三种典型方式。它们不是把动物分成三个互不相交的类别。一个胚胎可以先依靠母源定位物质建立差异，再由细胞间信号细化区域，之后继续用相互抑制和反馈稳定单细胞命运；同一细胞也可能在不同阶段先后接受多种机制。

### 自主指定依赖继承的内部差异 { #autonomous-specification }

自主指定（autonomous specification）发生在卵或早期胚胎的某些调控分子分布不均，并在卵裂中进入特定子细胞时。孤立这样的卵裂球，它仍产生在完整胚胎中原本会产生的组织；从胚胎移除它，剩余部分则缺少相应组织。海鞘、软体动物和线虫的部分早期谱系提供了经典例证。许多母源 mRNA 在卵母细胞中与蛋白组成核糖核蛋白颗粒，其定位、储存和定时翻译都能造成早期差异。所谓细胞质决定因子可以是定位的 mRNA、转录调节蛋白或其他调控组分，其身份必须通过定位、缺失和异位转移共同证明，不能仅凭“某物质在该区域较多”命名。[^specification-mechanics]

自主指定产生的缺失表型常被称为镶嵌式发育，但这不表示胚胎由完全独立的砖块拼成。海鞘早期肌肉谱系可以显示强烈自主性，其他组织仍需要细胞接触；线虫的谱系高度可重复，其中也包含多次诱导。自主程度是具体细胞、阶段和性状的属性，而不是“无脊椎动物”的统一性质。

### 条件指定由邻居和位置收窄潜能 { #conditional-specification }

条件指定（conditional specification）中，细胞最初具有多个可能去向，邻近细胞、细胞外基质和组织位置逐步限制其选择。移走某个卵裂球后，其余细胞可能改变贡献并补足缺失部分；把一个细胞换到新位置，它也可能采取与新邻居相符的命运。这种调整能力称为调节发育。它解释了早期胚胎分离后形成同卵多胎的可能性，却不意味着任何阶段、任何细胞都能重建整个个体。[^specification-mechanics]

位置效应在这里指细胞读取胚胎中的空间信息，而不是遗传学中基因落入不同染色质邻域所产生的“染色体位置效应”。位置可以通过接触对象、配体浓度、基质硬度、力学应力和代谢环境被细胞读取。细胞的正常命运只是这些输入在未受扰动胚胎中的一次实现；改变位置后是否改变命运，取决于它当时仍保留多大的响应能力。

海胆动物极和植物极片段的经典分离与重组实验说明卵沿动物—植物轴已不对称，植物侧组织还能诱导相邻细胞形成内中胚层。早期文献曾用“动物极化物质”和“植物极化物质”两种对立梯度概括结果，这些名称并不是已经鉴定的两种形态发生素。现代研究显示，植物侧核内 β-catenin 启动内中胚层基因调控网络，随后局部 Delta—Notch 等信号继续分开细胞命运；极性、内部调控状态和细胞间诱导共同建立各区域，而不是两种假想物质的简单平衡。[^sea-urchin-axis]

### 合胞体指定先在共同细胞质中产生位置差异 { #syncytial-specification }

许多昆虫早期胚胎先进行核分裂而不立即完成胞质分裂，多个细胞核因而共享同一片细胞质。定位于卵两端的母源 mRNA 及其蛋白梯度可直接影响不同位置的细胞核；细胞膜形成后，先前的核位置差异便转化为细胞间的基因表达差异。这种合胞体指定同时具有内部定位物质和位置依赖梯度的特征。

果蝇前端的 Bicoid 蛋白梯度既调控合子基因转录，也抑制前端 *caudal* mRNA 的翻译；后端定位的 Nanos 与 Pumilio 抑制母源 *hunchback* mRNA 的翻译。因此后端体系不是有时被误写为“Candal”的单一转录因子，正确名称是 Caudal，且其梯度还依赖翻译调控。这里的要点是共享胞质如何在细胞化之前赋予细胞核不同输入；母体效应、分节级联和轴形成的完整机制见后续[胚轴、分节与位置身份](axis_patterning.md)。[^drosophila-syncytium]

## 胚胎诱导需要发送者与感受态组织相遇 { #induction-and-competence }

胚胎诱导（embryonic induction）是一个细胞群改变另一个细胞群行为或命运的相互作用。诱导组织提供信号，响应组织必须具有接收并解释信号的能力。诱导可以是指令性的：响应组织由此启动原本不会启动的命运程序；也可以是许可性的：组织已经具备相应程序，只需要基质、营养或其他环境允许它表现。区分二者需要同时比较有无诱导组织，并用其他组织或介质排除“任何支持环境都能产生同样结果”。

感受态（competence）是响应组织在特定时间对某种诱导作出特定反应的能力。它由受体、胞内信号装置、谱系转录因子和染色质可及性共同建立。相同配体遇到不同细胞可以产生不同结果；同一组织在较早阶段能够响应，稍后也可能关闭受体或靶增强子而失去感受态。先锋转录因子预先接近核小体包裹的调控区，是建立某些响应能力的一种机制，但感受态并不能简化为单一“感受态基因”。[^developmental-competence]

晶状体发生展示了诱导的连续性。经典移植实验中，视泡能够在头部外胚层诱导晶状体样结构，却不能使躯干部外胚层产生同样结果；差异来自响应组织的感受态。后续研究又表明，头部外胚层在接触视泡之前已接受咽内胚层、前部神经板等早期输入，视泡信号继续推进和维持晶状体程序。器官发生中的“诱导者”因而常是接力链中的一环，而非单个组织独自发布完整说明书。[^induction-competence]

邻近细胞之间还可以通过相互限制把近似等价的群体分成不同命运。Notch—Delta 侧向抑制中，细胞间微小差异经反馈放大：配体较高的细胞成为主要发送者，邻细胞的 Notch 活性升高并采取另一命运。这是神经前体选择等过程的常见逻辑，但并不支持“所有完成分化的细胞都会抑制邻居做同样分化”的一般规则。Notch 在其他情境还可促进相邻细胞采用相似状态，具体结果取决于配体、反馈和预先图式。[^lateral-inhibition]

## 形态发生素把连续输入转换为区域命运 { #morphogen-interpretation }

形态发生素（morphogen）是能够在组织中形成空间分布，并直接使响应细胞按局部信号水平产生两个或更多不同结果的信号分子。证明一个分子具有这种作用，需要显示它在体内的空间或活性梯度，改变剂量或分布会移动命运边界，响应细胞直接接收该信号，而且不同水平确实引出不同命运。仅有扩散、梯度外观或一种浓度下的诱导活性，都不足以完成证明。[^morphogen-rules]

“法国国旗”模型用多个浓度阈值说明连续梯度怎样产生离散区域，是理解位置值的起点。真实胚胎还会读取暴露持续时间、信号变化速率和既往状态。受体周转、抑制物、正负反馈与下游转录因子之间的交叉抑制能够移动或锐化边界，组织生长又要求图案随尺度调整。因此，成熟的命运边界通常是梯度给出的初始偏向与基因调控网络动态共同形成的结果，不是每个细胞对某个瞬时浓度作一次孤立测量。

非洲爪蟾动物帽实验是剂量解释的经典例子：孤立的动物极外胚层在培养中趋向表皮命运，接受不同水平的 TGF-β 家族输入时可表达不同中内胚层标志。外加 Activin 曾清楚展示浓度和暴露时间如何改变响应，但外源 Activin 的效力不等于它就是胚胎内唯一的生理诱导物；遗传和拮抗实验支持 Nodal 相关信号在体内中内胚层诱导中的核心作用。外植体的剂量—反应、体内分布、缺失表型和救援必须共同解释。[^xenopus-mesoderm]

形态发生素与细胞质决定因子也不是“定量”和“定性”两类物质的简单对立。定位决定因子的剂量可以影响结果，形态发生素又必须被具有特定内部状态的细胞解释。两者描述的是信息来源和传播情境：前者随细胞质继承，后者跨一定空间作用；最终都通过调控网络改变基因表达。

## 细胞记忆稳定命运而不取消可塑性 { #cell-memory }

短暂信号要产生持续命运，细胞必须在信号消失后维持新的调控状态。转录因子自激活、两个命运程序之间的交叉抑制、Polycomb／Trithorax 等染色质调节、DNA 甲基化以及细胞与环境的反馈，都可以参与这种记忆。不同机制维持的时间尺度不同，也没有一种表观标记单独等同于命运决定；稳定身份来自调控网络、染色质和细胞生理的共同延续。

果蝇成虫盘的连续移植实验提供了直观证据。未终末分化的盘组织在成体宿主体内多轮增殖后，通常仍能在变态时形成其来源对应的翅、足或其他结构，表明决定状态可以跨许多细胞代保持。少数组织在损伤和再生条件下发生转决定（transdetermination），例如由足盘命运转向翅盘命运，又说明这种记忆稳定却并非绝对不可改写。[^cell-memory]

大多数发育性命运变化依靠可逆或可维持的基因表达调节，并不需要改变 DNA 序列。B、T 细胞的 V(D)J 重排是免疫受体多样化的谱系特异过程，不是一般细胞分化的共同机制；其发生阶段与功能见[淋巴细胞发育与受体多样性](../immunology/lymphocyte_development_repertoire.md#vdj-recombination)。温度、营养和其他外部环境对发育轨迹的系统影响则在[发育时序、性别决定与环境可塑性](environmental_evo_devo.md)展开。

## 证据组合决定机制解释的边界 { #evidence-boundaries }

判断命运机制时，表达相关性只能提出候选。分离实验检验自主性，异位移植检验决定程度和感受态，消融检验必要性，异位表达或局部加珠检验条件性充分性，谱系标记则确认最终组织来自供体还是宿主。若扰动同时改变细胞存活、增殖或位置，表型可能是间接结果，还要用时序控制、剂量系列和救援缩小解释范围。各类操作的完整逻辑见[模式生物与发育研究方法](models_methods.md#perturbation-logic)。

细胞命运最终表现为一条动态轨迹：内部不对称提供初始偏向，邻居和远距离信号按位置与时间改变选择，感受态决定哪些输入可被读取，反馈与染色质再把暂时差异稳定下来。下一页[发育信号与基因调控](developmental_signaling.md)将进一步解释少数信号通路如何借助受体、增强子和基因调控网络，在不同组织反复产生不同结果。
