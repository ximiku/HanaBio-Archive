# 细胞外基质、黏附与连接

多细胞组织的秩序建立在三类连续界面上：细胞以黏附分子识别邻居，以连接复合物把膜两侧的骨架接成受力网络，又以细胞外基质（extracellular matrix, ECM）规定组织的材料性质。连接因此不只是把细胞固定在一起；它们同时控制旁细胞通透性、膜蛋白分区、机械负荷传递和局部信号。ECM 也不是细胞之间的惰性填料，而是一套由细胞合成、装配并持续改造的蛋白质—多糖网络。[^cell-interactions-overview]

动物组织、植物组织和无脊椎动物使用的分子元件并不完全相同，却都面对同一组物理问题：怎样形成选择性边界，怎样跨细胞传递力，怎样允许受控的物质交换，以及怎样让细胞感知周围材料的组成和力学状态。本页据此把动物细胞连接、黏附分子、ECM、糖萼和植物细胞壁放在同一组织尺度下讨论；结构安排参考并实质性改编自 osm.bio 的同题页面，同时按教材和原始研究重组、补充并校正。[^osm-cell-junctions-ecm]

## 连接复合物的功能分工 { #junction-systems }

细胞连接的名称来自其超微结构、跨膜分子和胞内骨架耦联方式。一个上皮细胞可以同时拥有多类连接，它们沿顶端—基底轴呈有偏向但可变的分布，并在发育、损伤和迁移中重新组织。下表列出典型组合；“连接的骨架”指主要受力耦联对象，并不排除其他骨架或信号蛋白参与。

| 连接或结构 | 主要跨膜元件 | 胞内或胞外耦联 | 核心任务 | 常见分布 |
| --- | --- | --- | --- | --- |
| 紧密连接 | claudin、occludin、JAM | ZO 蛋白与 actin 皮层 | 调节旁细胞通路，维持膜域分隔 | 脊椎动物上皮、内皮细胞间隙的顶端侧 |
| 黏着连接 | classical cadherin | catenin、vinculin 与 actin | 细胞间黏附、张力传递与形态发生 | 上皮黏着带、组织重排界面 |
| 桥粒 | desmoglein、desmocollin | plakoglobin、plakophilin、desmoplakin 与中间丝 | 分散细胞间拉伸和剪切 | 表皮、心肌等高负荷组织 |
| 黏着斑 | integrin | talin、kindlin、vinculin、paxillin、FAK 与 actin | 细胞—ECM 黏附、牵引与机械感知 | 迁移细胞和多种基质接触面 |
| 半桥粒 | integrin $\alpha6\beta4$、collagen XVII | plectin、BP230 与角蛋白中间丝；胞外连 laminin-332 | 把上皮固定到基底膜 | 受摩擦上皮的基底面 |
| 缝隙连接 | connexin 组成的 connexon | 细胞骨架和调节蛋白；相邻半通道对接 | 离子和小分子的细胞间通道 | 多种脊椎动物组织 |
| 胞间连丝 | 连续质膜与 ER 来源的 desmotubule | 胞质套筒、壁颈部胼胝质和调节蛋白 | 植物细胞间共质体交换 | 穿过相邻植物细胞壁 |

无脊椎动物常以 septate junction 承担上皮封闭，并以 innexin 组成细胞间通道。pannexin 虽与 innexin 同源，在脊椎动物中通常形成向细胞外开放的单膜通道，不能一概视为标准缝隙连接。名称相近的连接因而要由跨膜蛋白、所接骨架和所在生物类群共同界定。[^cell-junctions-textbook]

## 上皮屏障与极性 { #epithelial-barrier-polarity }

### 紧密连接与选择性旁细胞通路 { #tight-junctions }

紧密连接把相邻细胞膜拉近成连续的带状网络。claudin 是形成连接索并决定离子选择性的核心成分，不同 claudin 组合可形成带电孔道，也可加强屏障；occludin、JAM 和 tricellulin 等则参与调节、三细胞角封闭和连接稳定。claudin-1 或 claudin-2 在缺乏内源紧密连接的细胞中即可重建连接索，直接支持其结构核心地位。[^claudin-strands]

上皮的“封闭”是可调的选择性，而不是对水、离子和溶质的绝对隔绝。肾小管、肠道和血管内皮表达不同 claudin，因而具有不同电导和分子通量；三细胞交界、炎症信号和细胞骨架张力还会改变有效通透性。血脑屏障的低旁细胞通量来自专门化内皮及周细胞、星形胶质细胞足突和基底膜共同组成的神经血管单元，不能只归于一条紧密连接带。

紧密连接还具有“栅栏”作用：它限制部分膜脂和膜蛋白在顶端域与基底外侧域之间自由混合，使定向转运和分泌可以长期维持。膜内扩散本就会受皮层、蛋白复合物与膜域限制，相关物理基础见[受限的侧向运动](membrane_transport.md#membrane-mobility)。

### 黏着连接与上皮张力 { #adherens-junctions }

classical cadherin 的胞外结构域在 Ca$^{2+}$ 存在时保持刚性并与邻细胞 cadherin 结合；胞内尾部通过 $\beta$-catenin、p120-catenin 和 $\alpha$-catenin 接入 actin 皮层。上皮细胞中的黏着带因此能把单个细胞的 actomyosin 收缩传到相邻细胞，使细胞顶端收缩、折叠、延伸和集体迁移成为组织尺度的协同行为。

$\alpha$-catenin 对 actin 的结合会随受力状态改变，vinculin 等蛋白也可在张力下被招募。黏着连接由此兼有黏附和机械响应，但其行为取决于 cadherin 聚簇、皮层流动、连接更新与组织几何，不能简化成一条静止的 cadherin—actin 锁链。力依赖的 $\alpha$-catenin—actin 结合已由单分子和细胞实验直接解析。[^alpha-catenin-force]

## 承载负荷的细胞—细胞与细胞—基质界面 { #load-bearing-adhesions }

桥粒把相邻细胞的 cadherin 家族蛋白接到角蛋白或 desmin 中间丝。desmoglein 与 desmocollin 在细胞外对接，plakoglobin、plakophilin 和 desmoplakin 在膜内侧形成致密斑。中间丝由此从一个细胞跨连接延伸到另一个细胞，在表皮受摩擦或心肌反复收缩时把局部应力分散到更大范围。桥粒蛋白也参与信号与组织分化，其功能不止于被动加固。

半桥粒位于上皮基底面。integrin $\alpha6\beta4$、collagen XVII、plectin 和 BP230 把角蛋白接到基底膜中的 laminin-332；它与桥粒都连接中间丝，但一端指向 ECM 而非相邻细胞。遗传缺陷或自身抗体破坏这一轴线时，组织可沿特定层面分离，这种“裂隙出现在哪里”的现象反过来证明连接的分层结构。

黏着斑则以 integrin 异二聚体为跨膜核心，把 fibronectin、collagen 或 laminin 等基质配体接到 actin。talin 和 kindlin 激活 integrin 并连接其胞质尾部，vinculin、paxillin、FAK 等随后组织受力和信号复合物。talin 杆状区受拉伸时可暴露隐藏的 vinculin 结合位点，为“分子构象记录受力状态”提供了直接证据。[^talin-mechanosensing]

这些界面与[迁移细胞的突出—黏附—牵引循环](cytoskeleton.md#migration-cycle)连续相接。黏附过弱时细胞难以获得牵引，过强又会妨碍后缘回收；三维基质中还要考虑孔隙、配体密度、纤维取向和细胞变形。黏着斑的数量或面积因而不能单独代表迁移能力或“黏附强度”。

## 黏附分子的识别语法 { #adhesion-molecules }

cadherin、integrin、selectin 和免疫球蛋白超家族（IgSF）构成常见的细胞黏附分子体系。它们可在稳定连接中长期驻留，也可产生短暂接触；同一种分子还可能在不同组织承担不同任务。

cadherin 多为 Ca$^{2+}$ 依赖的同类结合分子。细胞群分选既受 cadherin 类型和表达量影响，也受皮层张力、极性及其他黏附系统影响。发育或癌变中的上皮—间充质转变涉及转录、骨架、极性、ECM 和代谢的协调重排，E-cadherin 的升降只是其中一个读出，不能作为所有细胞状态的二元开关。

selectin 识别特定糖链，在血流剪切下形成快速生成又快速断裂的键，使白细胞能够捕获并沿血管内皮滚动。IgSF 成员通常不依赖 Ca$^{2+}$，可作同类或异类结合；NCAM、L1-CAM、ICAM 和 VCAM 等分别参与神经组织、免疫细胞与血管界面。滚动之后的活化和跨内皮迁移还需要趋化信号与 integrin 状态转换，完整免疫募集机制留给免疫栏目。

integrin 由 $\alpha$ 与 $\beta$ 亚基组成，既接受胞内 talin／kindlin 驱动的 inside-out 激活，也把配体结合和力学信息以 outside-in 方式传回细胞。不同 integrin 识别不同配体和序列；RGD 是 fibronectin 等若干配体的重要基序，却不是所有 collagen、laminin 和 integrin 相互作用的统一密码。细胞脱离适当基质后可触发 anoikis，但依赖程度随细胞类型、分化状态和培养环境而变，悬浮生长也不等同于恶性转化。[^cell-adhesion-textbook]

## 缝隙连接与直接胞质通讯 { #gap-junctions }

六个 connexin 亚基在一个细胞膜内组成 connexon，两个相邻细胞的 connexon 对接为连续水相通道。connexon 可由同一种或多种 connexin 构成，对接后又可形成同型或异型通道；组成差异改变电导、选择性、门控和周转。通道允许离子以及某些小代谢物和第二信使直接交换，使心肌、平滑肌、部分神经网络和代谢耦联组织同步活动。Cx26 通道的结构研究显示了贯穿两层膜的孔道及其亚基界面。[^connexin-channel]

膜电位、胞内 pH、Ca$^{2+}$、磷酸化和机械状态都可改变通道开放概率。可通过某个通道的分子取决于大小、形状、电荷和 connexin 组成，不能用一个固定分子量阈值概括全部缝隙连接。染料扩散、双细胞电压钳或局部光漂白恢复能够报告细胞间耦联，但荧光扩散还会受胞质结合、细胞体积和通道数量影响。

化学突触则以囊泡释放、细胞外扩散和受体响应跨越突触间隙，并不形成开放的胞质连续体。它属于高度专门化的细胞间通讯界面，突触前释放、受体动力学和可塑性将在神经栏目展开。

## 动物细胞外基质的材料组成 { #animal-ecm }

### 胶原与弹性蛋白 { #collagen-elastin }

collagen 家族为 ECM 提供抗拉骨架。单条 $\alpha$ 链采用左手 polyproline II 样构象，三条链再缠绕为右手三股螺旋；Gly-X-Y 重复使每第三位的 glycine 能容纳于螺旋中心，proline 和 hydroxyproline 则有助于稳定构象。高分辨率模型肽结构确立了这一几何，而“collagen 本身是一条左手螺旋”遗漏了链与三聚体两个层级。[^collagen-structure]

分泌型 fibrillar collagen 在粗面 ER 内完成信号肽去除、proline／lysine 羟化、部分 glycosylation 和从 C 端开始的三股螺旋装配，以 procollagen 形式经 Golgi 输出。胞外 N、C 前肽被切除后形成 tropocollagen，随后排列为原纤维并经 lysyl oxidase 催化共价交联。维生素 C 缺乏会影响羟化；某些 Ehlers-Danlos 综合征亚型涉及 collagen 加工或装配，但这一组疾病并非都源自同一种 procollagen peptidase 缺陷。I、II、III 型多形成原纤维，IV 型形成基底膜网络，VII 型组成锚定纤维，结构类别比单纯按组织罗列更能解释功能。

elastin 赋予大动脉、肺和弹性组织可逆伸展能力。细胞把 tropoelastin 沉积到 fibrillin 微原纤维支架上，lysyl oxidase 促成 desmosine 等交联；疏水区在拉伸后趋向回缩，使网络反复储存和释放机械能。elastin、fibrillin 与 collagen 的比例、交联和空间组织共同决定组织曲线，弹性不能只由某一种纤维的含量推断。[^ecm-textbook]

### 糖胺聚糖与蛋白聚糖的水合相 { #gag-proteoglycan }

glycosaminoglycan（GAG）由重复二糖组成，密集羧基和硫酸基吸引反离子与水，形成占据较大体积的水合相。多数 GAG 含 amino sugar 与 uronic acid，keratan sulfate 是重要例外；多数 sulfated GAG 在 Golgi 装配到 core protein 上，常经 xylose—serine 连接区起始，但 keratan sulfate 的连接方式又不完全相同。hyaluronan 不硫酸化，不共价连接 core protein，并由质膜上的 hyaluronan synthase 直接向细胞外合成。

core protein 与 GAG 链构成 proteoglycan。aggrecan 等可借 hyaluronan 形成巨大聚集体，使软骨抵抗压缩；perlecan 是基底膜的重要组分；细胞表面的 syndecan 还能与生长因子、黏附分子和骨架相接。水合、孔隙和配体结合三种性质使 proteoglycan 同时参与承载、过滤和信号呈递，而不是只作“黏液状填充物”。

### 纤维连接蛋白与层粘连蛋白的装配 { #fibronectin-laminin }

fibronectin 是由二硫键连接的二聚体，具有 integrin、collagen、heparan sulfate 等结合模块。可溶 fibronectin 与 integrin 结合后，细胞张力拉开部分模块并暴露自结合位点，促使其逐步装配为不溶纤维；Rho 驱动的 actomyosin 收缩可调节这一过程。[^fibronectin-assembly] ECM 纤维因此不是先由细胞外自行搭好再供细胞附着，而是在细胞施力、分泌和降解中持续生成。

laminin 是 $\alpha$、$\beta$、$\gamma$ 链组成的异三聚体，不同链组合形成具有组织特异性的 isoform。laminin 可聚合为网络，并通过 integrin、dystroglycan 等受体连接细胞；与 collagen IV、nidogen 和 perlecan 协同构成基底膜。不同 laminin isoform 的受体和功能不同，不能把所有作用归于一个 RGD 位点。

## 基底膜与细胞表面糖萼 { #basement-membrane-glycocalyx }

基底膜是高度组织化的薄层 ECM，主要由 laminin 网络和 collagen IV 网络构成，并以 nidogen、perlecan 等连接和调节。它位于上皮、内皮、肌细胞、Schwann cell 与 adipocyte 等细胞表面，既提供承载和极性线索，也参与肾小球过滤、干细胞 niche、轴突再生路径和组织修复。collagen IV 缺失小鼠可完成早期基底膜装配，却在组织受力增加后失去稳定性，说明“建立网络”和“赋予长期机械完整性”是可分的功能。[^collagen-iv-network]

糖萼位于质膜外侧，由膜 glycoprotein、glycolipid、proteoglycan 的糖链及其结合的可溶成分共同形成。它的厚度和组成随细胞类型、流体剪切与酶切动态变化；负电荷、空间排斥和水合作用调节分子接近，特异糖链又参与 lectin 识别。血管内皮糖萼还把流动环境与膜受体联系起来。糖萼不是一层与膜分离的均匀“黏多糖外套”，其读出必须结合固定方法和成像尺度。

## ECM 重塑与机械转导 { #ecm-remodelling-mechanotransduction }

ECM 的状态由合成、交联、纤维组装、蛋白水解和内吞回收共同决定。fibroblast 是许多结缔组织的重要基质来源，但 epithelial cell、endothelial cell、muscle cell、adipocyte 和 immune cell 也能产生或改造各自微环境。matrix metalloproteinase、ADAMTS 等蛋白酶可开放迁移通道或释放被基质束缚的信号；其抑制剂、局部活化和底物可及性共同限制降解范围。

细胞通过 integrin—talin—actin 轴向基质施力，并读取基质刚度、黏弹性、纤维取向和配体间距。整联蛋白怎样经 FAK／Src、Rho 和其他效应器把受力状态接入生化网络，见[整联蛋白信号](cell_signaling.md#integrin-signaling)。培养基质弹性可显著改变间充质干细胞的形态、张力和分化倾向，是机械微环境影响细胞状态的经典实验；这一结果描述特定培养系统中的偏向，而不是“一个刚度数值决定一种命运”的普遍定律。[^matrix-elasticity]

机械转导也存在反馈。张力可促进黏着斑成熟和 fibronectin 展开，细胞随后分泌、交联或降解更多 ECM，新的材料性质再改变细胞行为。组织中的应力还由邻细胞连接、液体压力和几何约束分担，所以只在二维硬基底上测得的铺展面积或黏着斑大小，不能直接替代体内机械状态。

## 脂肪组织中的细胞—基质界面 { #adipose-tissue-interface }

白色 adipocyte 通常由一个大脂滴占据主要胞质，细胞核和薄层胞质被推向周缘；棕色 adipocyte 含多个较小脂滴和丰富 mitochondria，细胞核多较居中。beige adipocyte 可在部分白色脂肪 depot 中被诱导，静息和受刺激状态会明显变化。经典棕色脂肪与部分 skeletal muscle 共享 Myf5$^+$ 前体谱系，PRDM16 可推动棕色脂肪—肌发生程序转换；beige adipocyte 则具有不同的前体和表达特征，因此不能把所有产热 adipocyte 都归入同一肌源谱系。[^brown-beige-lineage]

adipocyte 外围有 basement membrane，并处在 capillary、nerve、stromal progenitor、fibroblast 和 immune cell 构成的微环境中。脂滴增大要求外围 collagen、laminin 和 proteoglycan 同步重塑；成人脂肪组织也可通过细胞数目变化适应长期能量状态，不存在适用于所有 depot 的固定“先膨大到四倍、再增生”阈值。白、棕和 beige 脂肪的产热与全身能量作用见[器官分工与燃料选择](../physiology/energy.md#fuel-selection)。

重塑失衡时，pericellular collagen 和纤维束积累会限制细胞扩张并改变血流、氧扩散和免疫环境。人肥胖脂肪组织的组织学研究显示，皮下与网膜脂肪的纤维化分布和临床相关性并不相同，提醒我们不要把“ECM 增多”解释为单向、全身一致的结果。[^adipose-fibrosis] 脂肪肝则主要指 hepatocyte 内脂质异常积累，并非 adipocyte 浸润肝实质。

## 植物细胞壁与共质体连续性 { #plant-cell-wall }

### 初生壁的复合网络与生长 { #primary-cell-wall }

植物初生细胞壁由 cellulose microfibril、hemicellulose、pectin 和多种结构／调节蛋白构成。cellulose synthase complex 在质膜中移动并把 glucan chain 输出、结晶为 microfibril；活细胞成像表明其运动轨迹与 cortical microtubule 阵列相关，微管因此帮助组织纤维素沉积方向，但不是 cellulose polymerization 的模板。[^cellulose-microtubules] hemicellulose 和 pectin 主要在 Golgi 合成后经胞吐进入细胞壁。

初生壁应理解为相互穿插、局部接触且持续重排的复合网络。pectin 形成富水相并参与孔隙、黏附和离子交联，hemicellulose 与部分 cellulose 表面或 microfibril 接触区相互作用。传统“每条 microfibril 都由 xyloglucan 均匀系住”的图景不能代表所有植物和组织；遗传、固态 NMR 与酶学结果更支持少量关键接触和多聚物共同承载。[^primary-wall-model]

细胞膨压为扩张提供驱动力，壁的受控屈服决定扩张方向和速率。expansin 可促进特定承载接触处的滑移，XTH、pectin methylesterase 和多种 hydrolase／transferase 则按组织背景改变壁结构。中胶层富含 pectin，维系相邻细胞的胞外黏附。生长因此来自“膨压施力—壁选择性松弛—新材料沉积”的同步过程，而非先把细胞壁整体软化再被动撑大。

### 次生壁、木质化与胞间连丝 { #secondary-wall-plasmodesmata }

停止或减慢扩张后的细胞可在初生壁内侧沉积次生壁。次生壁通常含更高比例 cellulose、特定 hemicellulose，并可加入 lignin；多层 microfibril 取向和木质化提高抗弯、抗压与疏水性，支撑木质部输水和植物体。不同细胞类型的次生壁组成差异很大，“几乎没有 pectin”只能作为某些成熟壁的趋势，不能写成统一定义。

胞间连丝穿过细胞壁，外缘由相邻细胞连续的质膜包围，中央 desmotubule 源自紧密贴合的 ER，二者之间的 cytoplasmic sleeve 提供受调节的共质体通路。其孔径和形态可随发育和应激改变；颈部 callose 的合成与水解是重要门控机制，Arabidopsis 中不同 callose synthase 对机械损伤或病原刺激产生有区别的调节。[^plasmodesmata-callose] 可通行分子由孔道状态、货物性质和主动调节共同决定，不宜用一个固定直径或分子量界线概括。

## 实验证据与解释边界 { #interaction-methods }

连接和 ECM 横跨纳米结构、细胞力学与组织功能，单一实验通常只覆盖其中一层。可靠结论常来自结构定位、功能扰动和力学读出的组合。

| 证据路径 | 直接读出 | 主要解释边界 |
| --- | --- | --- |
| 薄片电镜、冷冻断裂与 cryo-ET | 连接带、桥粒致密斑、膜间通道与胞间连丝超微结构 | 固定、断裂面和取样可改变形态；结构存在不等于通道开放 |
| 免疫荧光、活细胞标记与 FRAP | 蛋白定位、连接周转、膜域和细胞间示踪物交换 | 共定位不证明直接结合；漂白恢复混合了扩散、结合和膜交通 |
| transepithelial electrical resistance 与溶质通量 | 离子电导和示踪物跨上皮速度 | 电阻主要反映离子通路，不能替代大分子通量；还受细胞面积影响 |
| traction force microscopy、AFM 与单分子拉伸 | 细胞牵引、局部刚度、蛋白受力构象 | 探针几何、加载速率和培养基底会改变结果，二维值不能直接等同体内组织 |
| 基因扰动、急性降解与 rescue | 某一元件对屏障、黏附或材料装配的因果贡献 | 发育补偿和旁系同源蛋白可掩盖效应；rescue 还需匹配表达量与定位 |
| decellularization 与 ECM proteomics | 组织基质组成及去细胞支架的功能影响 | 去细胞处理可丢失可溶组分、改变交联，并保留难以辨识的细胞残余 |

观察到连接蛋白聚集，应继续检验屏障、力传递或通道功能；观察到 ECM 刚度改变，也应区分成分、交联、孔隙与细胞施力的贡献。只有把分子身份、空间结构、动态和组织输出连接起来，才能判断一个界面是在黏附、封闭、通讯，还是同时承担几种任务。
