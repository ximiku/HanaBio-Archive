# 细胞器与能量转换

真核细胞把相互不相容的反应分置于膜包围的区室，也把电子传递、离子梯度和机械旋转接成可调节的能量转换系统。线粒体以内膜两侧的质子动力势驱动 ATP 合成；植物和藻类的叶绿体在类囊体膜上把光能转为还原力和 ATP；过氧化物酶体则把若干高氧化性的反应与胞质隔开，并用过氧化氢酶约束 H$_2$O$_2$。三者都会与其他细胞器交换脂质、蛋白质和代谢物，却具有不同的发生方式与遗传历史。

线粒体和质体保留了内共生祖先的一部分基因组及翻译装置，但维持它们所需的绝大多数蛋白质由核基因编码、在胞质中合成后输入。过氧化物酶体没有自身基因组和核糖体，其基质蛋白甚至可以折叠或装配后再跨膜进入。理解这些细胞器，因而需要把膜拓扑、蛋白质靶向、代谢物流和进化证据放在同一幅图景中。[^bioenergetic-organelles]

## 能量细胞器的共同分工 { #organelle-overview }

细胞器的名称并不对应一条孤立代谢途径。线粒体参与三羧酸循环、脂肪酸氧化、铁硫簇和血红素合成等过程，叶绿体同时承担光反应、碳同化以及多类合成反应，过氧化物酶体则依物种、组织和发育状态接入不同的脂质与活性氧代谢。它们通过膜接触位点和可溶性中间体交换形成协作网络；接触位点使两层膜近距离并置，可加快脂质、Ca$^{2+}$ 或代谢物传递，却不表示两个区室的腔面已经连通。

| 细胞器 | 边界与内部膜 | 自身遗传装置 | 主要能量关系 | 核编码蛋白的主要入口 |
| --- | --- | --- | --- | --- |
| 线粒体 | 外膜和内膜；内膜形成嵴，包围基质 | 有，大小、形态和基因组成随谱系变化 | 呼吸链建立质子动力势，ATP 合酶利用其合成 ATP | TOM 进入外膜或膜间隙入口，随后由 TIM、SAM、MIA、OXA 等路线分流 |
| 叶绿体 | 双层包膜；基质内另有类囊体膜和类囊体腔 | 有，保留光合与表达装置的一部分基因 | 光合电子传递在类囊体膜两侧建立质子动力势 | TOC／TIC 穿过包膜，之后由 Sec、Tat、cpSRP 等路线送往类囊体 |
| 过氧化物酶体 | 单层膜，无内膜褶皱 | 无 | 氧化反应可生成 H$_2$O$_2$，不建立用于 ATP 合成的呼吸链 | PEX5／PEX7 识别基质蛋白靶向信号，膜蛋白由多种 PEX 因子装配 |

这个比较也限定了“半自主性”的含义。线粒体和质体能够复制其 DNA、转录并翻译少量蛋白质，但不能脱离核基因产物而独立形成；过氧化物酶体的增长、分裂和从头发生同样依赖细胞其他区室，却没有内共生遗传装置。

## 线粒体的双膜区室与嵴 { #mitochondrial-architecture }

### 外膜、膜间隙、内膜与基质 { #mitochondrial-compartments }

线粒体外膜中的电压依赖性阴离子通道（VDAC）可通行多种小分子和离子，外膜仍通过蛋白质组成及状态调节交换。内膜对离子和多数极性代谢物高度不通透，特异载体分别交换 ADP／ATP、磷酸、丙酮酸、二羧酸等底物。两层膜的通透性差异使膜间隙在小分子组成上较易与胞质耦合，而基质能够维持独特的代谢物、蛋白质和离子环境。

内膜可分为与外膜相邻的内界膜和向基质内折的嵴膜。呼吸链复合体与 ATP 合酶在嵴膜中富集，嵴不是单纯为了增加面积的任意皱褶；狭窄的嵴连接部限制嵴腔与周围膜间隙之间的扩散，并参与细胞色素 *c* 的区室化。MICOS 复合体、OPA1、脂质组成和 ATP 合酶二聚体共同塑造嵴连接与膜曲率。不同物种、组织和代谢状态的嵴可呈板层、管状或其他形态，不能按“动物板层、植物管状”作固定二分。[^mitochondrial-membranes]

### 嵴结构与呼吸复合体组织 { #cristae-organization }

呼吸链复合体可以独立存在，也可形成不同化学计量的超复合体。超复合体会影响装配、稳定性和局部电子传递，但不构成所有电子都必须沿一条固定实体“流水线”移动的证据。泛醌在膜内、细胞色素 *c* 在膜表面充当可移动电子载体，膜脂特别是心磷脂参与多个复合体的稳定与组织。心磷脂很重要，内膜的选择性却来自整套脂质、蛋白质和载体，而非某一种脂质单独决定。

线粒体的尺寸、数量和位置随细胞需求变化。高耗能区域常富集线粒体，分支网络也可以在短时间内发生融合、分裂和定向运输。显微镜下的一个长管或一个小颗粒只是连续动态过程的瞬时截面，不等同一枚永久不变的线粒体个体。

## 质子动力势与代谢整合 { #mitochondrial-bioenergetics }

基质中的 NADH 把电子交给复合体 I，FAD 依赖反应可经复合体 II 或其他泛醌还原酶进入泛醌池；电子随后经复合体 III、细胞色素 *c* 和复合体 IV 传给 O$_2$。复合体 I、III 和 IV 促进 H$^+$ 从基质移向膜间隙，形成由膜电位和 pH 差共同构成的质子动力势。复合体 II 不泵质子，但它提供的电子仍可在下游复合体驱动质子转移，因此不能简单写成“经过复合体 II 不产生 ATP”。反应的精确化学计量和 P/O 比见[电子传递与氧化磷酸化](../biochem/oxp.md#electron-transport-chain)。

H$^+$ 沿 F$_\mathrm{o}$ 部分的跨膜通路回流，推动 *c* 环与中央轴旋转；F$_1$ 催化头中三个 $\beta$ 亚基依次改变核苷酸结合状态，生成并释放 ATP。每转一圈，*c* 环亚基数决定跨膜 H$^+$ 数，F$_1$ 生成三个 ATP。*c* 环大小随物种和细胞器而异，ATP 输出还要计入磷酸输入、ADP／ATP 交换和泄漏等成本，因而不存在适用于所有线粒体的固定“2 H$^+$／ATP”。[^energy-conversion]

氧化磷酸化与基质代谢通过底物和产物连续耦合。[三羧酸循环](../biochem/tca_cycle.md)提供 NADH 和 FADH$_2$，[脂肪酸分解](../biochem/lipid_catabolism.md#fatty-acid-mobilization-entry)产生乙酰 CoA 与还原当量；线粒体还参与氨基酸碳骨架、铁硫簇、血红素和一碳代谢。呼吸速率因此受 ADP、底物、氧供应、膜电位、载体通量和调控状态共同限制，不能由单一复合体数量推定。

## 线粒体动态、输入与质量控制 { #mitochondrial-biogenesis }

### 融合、分裂与细胞内定位 { #mitochondrial-dynamics }

哺乳动物线粒体外膜融合主要由 MFN1／MFN2 驱动，内膜融合需要 OPA1；DRP1 从胞质募集到外膜，在 MFF、MID49／MID51 等受体和细胞状态调节下形成收缩装置。Fis1 在酵母分裂中地位突出，在哺乳动物中并非所有 DRP1 招募的唯一受体。内质网接触、肌动蛋白和其他细胞骨架可标记或促进收缩，最终切割还会与膜张力和脂质重塑协作。融合有利于内容物混合与网络功能互补，分裂则服务于运输、增殖和受损部分的分离，两者不是健康与损伤的一一对应标签。[^mitochondrial-dynamics]

线粒体还参与 Ca$^{2+}$ 信号整形。外膜 VDAC 与内膜线粒体钙单向转运体复合物（MCU complex）构成摄取路径，NCLX 等系统参与外排；摄取依赖局部 Ca$^{2+}$ 微域和内膜电位。适量基质 Ca$^{2+}$ 可调节代谢酶，过量摄取会促进氧化应激、通透性转换和细胞损伤。线粒体因而是受驱动力和接触位点控制的动态缓冲区，而不是被动、无限容量的“钙仓库”。

### 核编码蛋白的输入与装配 { #mitochondrial-protein-import }

线粒体蛋白质组的绝大多数成员由核基因编码。带有 N 端基质靶向序列的前体通常先经外膜 TOM 复合体，再由 TIM23 穿过或侧向插入内膜；多跨膜载体常经膜间隙小 TIM 伴侣和 TIM22 插入内膜。外膜 $\beta$ 桶由 SAM 复合体装配，膜间隙富半胱氨酸蛋白可由 MIA 路线氧化折叠，一部分线粒体编码或已入基质的内膜蛋白由 OXA 路线插入。不同路线在前体是否保持未折叠、需要哪种膜电位或 ATP 驱动力以及终点区室上各不相同。[^mitochondrial-import]

线粒体 DNA 与蛋白质组成核样体，并与复制、转录、膜及嵴组织相联系。细胞器增殖不是在一个固定细胞周期时段复制一份圆形染色体再平均分配；不同物种的线粒体基因组可以是环状、线状或分段结构，同一细胞中也有多个基因组拷贝。核编码与线粒体编码亚基必须按比例装配，未装配亚基由伴侣蛋白和蛋白酶处理。

### 损伤隔离、线粒体自噬与遗传阈值 { #mitochondrial-quality-control }

线粒体质量控制从分子到细胞器逐层运行：伴侣蛋白帮助折叠，AAA 蛋白酶和其他蛋白酶清除异常亚基，融合与分裂重排网络，严重失能的部分可由线粒体自噬移除。PINK1—Parkin 是膜电位丧失时研究最充分的一条标记和泛素化路线，但许多细胞的基础线粒体自噬还使用其他受体与信号，不能把 Parkin 视作全部情境的必需开关。

线粒体病既可来自线粒体 DNA，也可来自核基因。一个细胞可同时含有不同线粒体基因组，称为异质性；突变比例、组织能量需求、核遗传背景和年龄共同决定何时越过功能阈值。线粒体 DNA 主要经母系传递不意味着所有线粒体病都呈母系遗传，也不意味着同一家系成员具有固定突变比例或严重度。细胞死亡中线粒体承担的进一步作用见[细胞损伤与缺血再灌注](../physiology/pathophysiology/cell_injury.md#calcium-mptp)。

## 叶绿体与质体分化 { #plastid-architecture }

### 质体家族与类囊体区室 { #plastid-compartments }

质体是一组可互相转化的细胞器。分生组织中的前质体可随细胞类型和环境分化为进行光合作用的叶绿体、富含类胡萝卜素的有色体、储存淀粉的淀粉体等形式；黑暗中形成的黄化质体在光照后也可重建类囊体系统。名称描述主要结构和功能倾向，不表示每一类只执行一种反应。

叶绿体包膜由外膜和内膜组成，包围基质。基质中的类囊体是第三套膜系统，其内腔称类囊体腔；高等植物的类囊体常堆叠成基粒，并由基质片层连接。类囊体腔与包膜间隙不连续，类囊体也不是内包膜向内折叠后仍保持连通的褶皱。基质含有 Calvin—Benson 循环所需酶，其中 RuBisCO 催化 CO$_2$ 加到核酮糖-1,5-二磷酸（RuBP）上；RuBP 是底物而不是酶。

### 光合电子传递与两类磷酸化 { #chloroplast-bioenergetics }

在线性电子流中，光系统 II 从水取得电子并释放 O$_2$，电子依次经质体醌、细胞色素 *b*$_6$f、质体蓝素到达光系统 I，随后经铁氧还蛋白和 FNR 还原 NADP$^+$。水氧化把 H$^+$ 释放到类囊体腔，*b*$_6$f 的 Q 循环进一步促进跨膜质子转移；H$^+$ 经叶绿体 ATP 合酶回到基质并驱动 ATP 生成。光照和两套光系统并不是把一个光子直接兑换为一个 ATP 或 NADPH，实际产额受天线分配、质子泄漏、ATP 合酶 *c* 环大小和旁路电子流影响。

当细胞需要调整 ATP／NADPH 供给比时，围绕光系统 I 的循环电子流可把电子送回质体醌／*b*$_6$f 通路，增加质子动力势而不净生成 NADPH或 O$_2$。这一路线受光强、碳同化、氧化还原状态和多套调控装置影响，不只在“NADP$^+$ 不足”时启动，也没有适用于所有条件的固定循环／线性流比例。光反应、Calvin—Benson 循环和光呼吸的完整计量由[光合作用](../botany/physiology/photosynthesis_respiration.md)承接。C$_4$ 和 CAM 植物同样进行碳固定，只是先由 PEP 羧化酶固定 HCO$_3^-$，再在空间或时间上浓缩 CO$_2$ 供 RuBisCO 使用。

### 蛋白输入、分裂与向光运动 { #chloroplast-biogenesis }

多数叶绿体蛋白以带 N 端转运肽的前体在胞质中合成，由外包膜 TOC 与内包膜 TIC 装置输入；TIC 的具体组成和马达模型仍有研究争议。进入基质后，蛋白质可留在基质、插入包膜，或借助 Sec、Tat、cpSRP 等彼此不同的路线到达类囊体膜和类囊体腔。输入、折叠、蛋白酶降解与核—质体逆行信号共同协调光合复合体装配，而不是细胞器基因组独自决定叶绿体形成。[^chloroplast-import]

叶绿体分裂同时使用来自细菌祖先与真核宿主的装置。FtsZ 在质体内部形成环状结构，ARC5／DRP5B 等动力蛋白样因子在外侧参与收缩，包膜两侧的连接因子协调位置与时序。分裂通常与细胞周期、叶片发育和细胞类型配合，却不受一个跨物种固定的“每个细胞多少叶绿体”数值约束。质体可伸出 stromule，与内质网、线粒体或细胞核建立动态近邻；这些结构支持物质交换和信号的假说，但不能仅凭接触影像推断质体之间发生大规模内容物融合。[^chloroplast-biogenesis]

叶绿体在细胞内的位置也会响应光照。弱光下的聚集反应增加受光面积，强光下的回避反应减少光损伤；蓝光受体 phototropin、叶绿体外膜蛋白和短寿命肌动蛋白结构共同参与运动。不同植物和藻类还可使用不同细胞骨架安排，因此叶绿体位置不是靠被动胞质流动单独决定。[^chloroplast-movement]

## 过氧化物酶体的氧化分工 { #peroxisome-metabolism }

### 脂质代谢与活性氧控制 { #peroxisomal-metabolism }

过氧化物酶体由单层膜包围，内部没有 DNA、核糖体或用于 ATP 合成的电子传递链。多种氧化酶把电子直接交给 O$_2$ 并生成 H$_2$O$_2$，过氧化氢酶再把 H$_2$O$_2$ 分解，或以其氧化其他底物。生成与清除在同一区室并置，既支持氧化代谢，也限制活性氧向胞质扩散；H$_2$O$_2$ 仍可参与信号并在失衡时造成损伤。

哺乳动物过氧化物酶体负责极长链脂肪酸的链缩短、支链脂肪酸的 $\alpha$ 氧化，并参与醚磷脂／缩醛磷脂和胆汁酸合成。其 $\beta$ 氧化首步把电子交给 O$_2$，所得还原当量和缩短后的酰基需要通过代谢物转移交给其他区室，不能把这一过程等同于线粒体呼吸链直接合成 ATP。脂肪酸活化和线粒体／过氧化物酶体分工见[脂肪酸分解代谢](../biochem/lipid_catabolism.md#fatty-acid-mobilization-entry)。

植物过氧化物酶体可承担脂肪酸 $\beta$ 氧化、茉莉酸合成和光呼吸反应；萌发油料种子的特化形式常称乙醛酸循环体，把脂肪酸碳流接入乙醛酸循环。功能组合随物种、器官和发育期变化。某些动物过氧化物酶体可见含尿酸氧化酶的结晶样核心，但人和其他高等灵长类缺乏功能性尿酸氧化酶，不能把这种形态或某个固定 pH、氧浓度当作所有过氧化物酶体的定义特征。[^peroxisome-overview]

### 蛋白输入、发生与更新 { #peroxisome-biogenesis }

许多基质蛋白带有 C 端 PTS1，经典序列为 Ser–Lys–Leu，但受体可识别多种变体；PEX5 在胞质中结合这些货物。较少见的 N 端 PTS2 由 PEX7 及物种特异共受体识别。受体—货物复合物在 PEX13／PEX14 等因子处对接，货物进入基质后，PEX5 被单泛素化并由 PEX1／PEX6 ATPase 回收。与线粒体、叶绿体常输入未折叠前体不同，过氧化物酶体可输入已经折叠甚至寡聚化的蛋白质。PTS 是具有上下文的识别信号，不是只要末端出现“SKL”就必然输入的机械口令。[^peroxisome-import]

过氧化物酶体膜蛋白可由 PEX19 等伴侣与 PEX3／PEX16 装配。新细胞器既可由已有过氧化物酶体增长后分裂，也可从内质网来源的前体膜结构从头形成；在哺乳动物等系统中，线粒体来源囊泡对部分发生路线的贡献也获得实验支持。不同模式可以共存，其权重取决于物种与细胞状态。过氧化物酶体还通过膜接触位点与内质网、线粒体、脂滴和溶酶体交换脂质或代谢物，受损细胞器可由选择性自噬即 pexophagy 清除。[^peroxisome-biogenesis]

糖鞘脂的逐步降解发生在溶酶体，需要酸性水解酶、辅助蛋白和膜转运协作；相应缺陷会形成溶酶体贮积病。它不属于过氧化物酶体脂肪酸氧化，也不宜笼统并入“能量细胞器”。溶酶体反应与分选装置将在[内膜系统、蛋白质分选与囊泡运输](endomembrane.md)展开，底物积累如何转化为组织损伤见[细胞器周转与贮积病](../physiology/pathophysiology/metabolic_disorders.md#organelle-storage-disorders)。

## 核—细胞器基因组协作 { #organelle-genome-cooperation }

线粒体和质体基因组只保留祖先基因组的一小部分。大量祖先基因已丢失或转移到细胞核，核基因还新增了输入、装配和调控因子。保留下来的基因常包括呼吸或光合膜复合体的核心疏水亚基以及细胞器表达装置的一部分，但具体清单、基因组大小和结构随谱系显著变化。细胞器核糖体保留细菌来源的同源关系，也经历了快速分化和核编码蛋白增补，不能用一个固定沉降系数或一张抗生素敏感性表概括全部真核谱系。

核编码和细胞器编码亚基需要同步供应。顺行调控让核基因产物控制细胞器复制、表达和装配，逆行信号则把氧化还原状态、代谢物、蛋白质稳态或损伤信息送回细胞核。RNA 编辑在某些线粒体和质体中广泛改变转录本，在另一些谱系很少或缺失；它是谱系特异的表达层，而不是所有细胞器转录都必须经历的统一步骤。

基因组保留也带来遗传上的特殊性。细胞器 DNA 可以独立于核 S 期复制，分配具有随机性和主动锚定等多种成分。内共生来源的细胞器因而既不是完全独立的细胞，也不是只受核基因控制的被动膜泡，而是由两个遗传系统和大规模蛋白输入共同维持的嵌合系统。[^bioenergetic-organelles]

## 内共生起源与证据层次 { #endosymbiotic-origin }

线粒体源自被早期真核祖先纳入的细菌，系统发育分析把其起源置于 $\alpha$-变形菌相关分支；初级质体则来自蓝细菌。现生取样和系统发育模型仍不足以把每次事件无争议地指向某一个现存“最近亲”类群，因此“来自某类现生细菌”应理解为与该谱系共享祖先，而不是一次可以用现代物种名称复现的吞噬事件。[^mitochondrial-origin] [^plastid-origin]

最有辨别力的证据来自多个相互独立层次：细胞器基因与细菌同源基因的系统树、核基因组中的内共生基因转移、细菌来源的核糖体和膜复合体、以及蛋白输入与细胞器分裂装置的同源关系。双层包膜、细菌尺度和分裂外观与这一模型相容，但单独都不足以确定亲缘。具有三层或四层包膜的复杂质体多与真核藻类被另一真核细胞摄入的次级或更复杂内共生历史有关，其蛋白靶向路线也随之增加。

内共生演化还产生了氢化酶体、mitosome 等线粒体相关细胞器。它们可能丢失经典呼吸链乃至基因组，却保留铁硫簇装配或其他线粒体祖传功能及部分输入装置，说明“没有有氧呼吸”不等于“不是线粒体同源细胞器”。[^mitochondria-related-organelles] 过氧化物酶体没有自身基因组，其蛋白输入和发生证据支持由真核内膜系统演化，而非另一场细菌内共生。

## 从形态到机制的实验证据 { #organelle-evidence }

透射电子显微镜和冷冻电子断层成像能显示双膜、嵴连接、基粒堆叠和膜接触位点，但固定、切片和平均处理可能改变尺度与连续性。活细胞成像适合追踪融合、分裂、运输和光定位；荧光标签或染料则可能依赖膜电位、pH 和表达水平。叶绿素具有显著红色自发荧光，线粒体没有可作为普遍识别标志的“红色自发荧光”：NAD(P)H 和黄素的内源荧光位于其他波段，常见红色线粒体信号多来自外加染料或荧光蛋白。

分离细胞器、渗透胀破和超声处理可暴露膜的不同表面，反向内膜囊泡等制备物曾帮助解析氧化磷酸化方向性；它们是人为产生的实验体系，不能直接当作细胞内线粒体的正常形态。蛋白酶保护、离体输入、免疫金标和亚细胞蛋白质组学可检验蛋白质拓扑与靶向，耗氧、电化学梯度、ATP 生成和代谢通量则分别报告能量转换的不同环节。

发生和进化问题还需要遗传学与系统发育证据。敲除输入受体后看到前体积累可定位装置需求，光漂白恢复和光激活追踪可检验内容物交换，基因树与共线性则检验祖先关系。任何单一显微图、抑制剂敏感性或固定比例都容易受到物种和实验条件影响；把相互独立的方法汇合，才能从“看见一个区室”推进到解释它怎样形成、怎样工作及怎样演化。
