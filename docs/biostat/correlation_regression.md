# 相关、回归与模型诊断

相关与回归都从成对或成组的观测出发，却回答不同的问题。相关系数用一个无量纲数概括两个变量共同变化的方向和线性或单调程度；回归则指定一个响应变量，建立它在给定预测变量时的条件均值模型，并据此估计效应、解释差异或作出预测。两者都可以用于观察性资料，也都不会仅凭一个显著系数产生因果结论。

一条拟合直线只是分析的中段。研究者还要确认观测单位是否独立、变量范围是否覆盖目标问题、均值结构和方差结构是否合适，以及少数观测是否主导了结果。模型诊断因此不是拟合失败后的补救程序，而是解释斜率、区间与预测误差之前不可分割的一步。

## 从变量关系到统计问题 { #questions-and-data }

### 成对观测与散点结构

相关和简单回归所用的基本数据单位是同一个对象上的一对数值 \((x_i,y_i)\)。若叶片氮含量与光合速率来自同一片叶，它们构成一对；若把一批叶片的氮含量任意配到另一批叶片的光合速率，边际分布仍在，成对关系却已被破坏。重复测量、同巢个体和同一培养皿内的细胞还共享上层单位，不能因数据表中每行都有一对数值就按独立样本处理。

散点图应先于相关系数和回归表。图中至少要辨认取值范围、方向、曲率、分组、离群点、重复值和方差随均值的变化。同一个总体相关可能由各组内部一致的趋势形成，也可能完全由组间差异驱动；把物种、批次或发育阶段用颜色或分面显示，常会改变对关系来源的理解。[生物数据整理与描述统计](data_description.md#distribution-first)已经建立了先看原始分布的原则，这里把它延伸到二维和多维结构。

横纵轴的选择也应对应问题。描述两个对称变量的线性关联时，交换 \(X\) 与 \(Y\) 不改变 Pearson 相关；预测或条件效应分析则必须明确响应 \(Y\) 和预测变量 \(X\)，交换二者会得到另一个回归问题。这里的“预测变量”只表示模型角色，可以是随机抽到的自然变量，并不要求研究者能够操控，也不保证测量无误差。

### 关联、预测与因果

素材把“因果关系”列为回归的条件，把“平行关系”列为相关的条件。更准确的区分是：相关描述联合变化，回归描述条件分布或条件均值，而因果推断还需要处理分派、时间顺序、混杂、选择和测量过程等设计依据。随机试验中，处理系数可在设计支持下具有因果解释；观察性回归即使拟合和预测都很好，系数通常仍是条件关联。

“控制其他变量不变”在多元回归中是一个模型对比：比较其他预测变量取值相同的两个观测所对应的拟合均值。它只有在模型形式、数据支持范围与因果识别条件都成立时，才可进一步解释为干预效应。共同原因可以产生很强的相关，选择样本也可以制造或反转相关；反过来，一个真实因果效应也可能因反馈、测量误差或效应异质而没有简单的边际线性相关。

回归还可以只服务于预测。预测模型关心新样本误差、校准和适用人群，可以采用没有因果含义但稳定可测的变量。解释、预测和因果是三个相关但不等价的目标，变量选择、验证方式和结果措辞都应先由目标决定。

## Pearson 相关及其推断 { #pearson-correlation }

### 协方差的标准化

总体 Pearson 相关系数为

\[
\rho=
\frac{\operatorname{Cov}(X,Y)}
{\sigma_X\sigma_Y},
\]

样本相关系数为

\[
r=
\frac{\sum_{i=1}^{n}(x_i-\bar x)(y_i-\bar y)}
{\sqrt{\sum_{i=1}^{n}(x_i-\bar x)^2
\sum_{i=1}^{n}(y_i-\bar y)^2}}.
\]

\(r\) 介于 \(-1\) 与 \(1\) 之间。符号给出线性共同变化的方向，绝对值衡量观测点接近某条非水平直线的程度；平移或正比例改变任一变量的单位不会改变其绝对值。\(r=1\) 或 \(-1\) 表示样本点精确落在斜率分别为正或负的直线上。

\(r=0\) 只表示样本线性协变为零，不表示两个变量“完全无关”。对称的 U 形关系可以具有 \(r=0\)，若只观察完整曲线的一小段又可能得到很大的正或负相关。独立变量在二阶矩存在时具有零总体相关，但零相关一般不能反推出独立。Pearson 相关还会受取值范围、混合亚群和离群点显著影响，因此不同研究中的相关系数只有在测量精度、人群和变量范围可比时才适合直接比较。Penn State 的回归教材也以零相关但完全弯曲的例子说明这一边界。[^psu-simple-regression]

### 检验与区间

对独立、来自二元正态总体的完整观测，检验 \(H_0:\rho=0\) 可使用

\[
t=
r\sqrt{\frac{n-2}{1-r^2}}
\sim t_{n-2}.
\]

素材先定义 \(s_r=\sqrt{(1-r^2)/(n-2)}\)，再写 \(t=r/s_r\)，代入后就是同一统计量。称 \(s_r\) 为普遍适用的“相关系数标准误”会过度概括：它属于零相关检验的代数表示，不直接给出任意 \(\rho\) 下对称而可靠的区间。

Pearson 相关的常用区间先作 Fisher 变换

\[
z=\operatorname{arctanh}(r)
=\frac12\ln\left(\frac{1+r}{1-r}\right),
\qquad
\operatorname{SE}(z)\approx\frac1{\sqrt{n-3}},
\]

在 \(z\) 尺度构造区间后再以 \(\tanh\) 变回相关尺度。R 的正式文档也以 Fisher 变换提供 Pearson 相关的渐近区间，并明确零相关的精确 *t* 参照依赖独立正态样本。[^r-cor-test] 非正态、离群、聚类或变量经结果驱动筛选时，可使用与抽样层级一致的 bootstrap、置换或稳健相关方法；简单重排单行数据不能保留配对、个体或空间结构。

显著性同时受效应大小和样本量影响。很小的相关在大样本中可能有很小的 *p* 值，而大相关在取值范围狭窄的小样本中可能区间很宽。结果应报告 \(r\)、区间、完整配对数、散点结构和预设检验方向，而不是只写“相关显著”。

## 秩相关与条件相关 { #rank-and-partial-correlation }

### Spearman 与 Kendall

Spearman \(\rho_s\) 是秩次上的 Pearson 相关，概括两个变量之间的单调关系。严格递增但明显弯曲的关系可有 \(\rho_s\) 接近 \(1\)，即使 Pearson \(r\) 较小；严格递减关系则接近 \(-1\)。它减少了极端数值距离的影响，却仍可能受极端秩、混合亚群和依赖观测影响。

无并列秩时，Kendall \(\tau\) 可写为

\[
\tau=\frac{C-D}{\binom{n}{2}},
\]

其中 \(C\) 与 \(D\) 分别是所有观测对中的一致对和不一致对。它可解释为随机抽取一对观测时，一致次序概率与不一致次序概率之差；存在并列值时需使用相应的并列校正版本。R 的相关检验文档把 Pearson、Kendall 与 Spearman 明确列为三个不同的关联量，并按样本量与并列情况选择精确或渐近参照。[^r-cor-test]

秩相关不等于“没有假设的 Pearson 替代”。它把目标从线性关联改为单调关联；若科学问题关心原单位上的斜率、均值变化或预测误差，仍需要回归模型。时间趋势、空间梯度和共同组别也能产生很大的秩相关，因果边界不因换成秩而消失。

### 偏相关与条件关联

偏相关考察在一组变量 \(Z\) 的线性部分被移除后，\(X\) 与 \(Y\) 剩余部分的线性相关。计算上可分别把 \(X\) 和 \(Y\) 对 \(Z\) 回归，再求两组残差的相关。只有一个控制变量时，

\[
r_{XY\cdot Z}=
\frac{r_{XY}-r_{XZ}r_{YZ}}
{\sqrt{(1-r_{XZ}^2)(1-r_{YZ}^2)}}.
\]

这保留了素材中“其余变量保持不变”的直观，但需要更精确地理解为线性调整后的关联。若 \(Z\) 与结果的关系非线性、存在交互或测量误差，简单偏相关可能没有充分调整；若 \(Z\) 是共同原因、碰撞变量或处理后的中介，是否调整还会改变因果问题。NIST 对部分回归图的说明也表明，两组调整残差的相关对应部分相关，并强调它与部分残差图用途不同。[^nist-regression-diagnostics]

## 简单线性回归 { #simple-linear-regression }

### 条件均值模型

简单线性回归写为

\[
Y_i=\beta_0+\beta_1x_i+\varepsilon_i,
\qquad i=1,\ldots,n,
\]

其中

\[
E(\varepsilon_i\mid x_i)=0,
\qquad
\operatorname{Var}(\varepsilon_i\mid x_i)=\sigma^2
\]

是经典等方差模型的条件。于是 \(E(Y_i\mid x_i)=\beta_0+\beta_1x_i\)：\(\beta_0\) 是 \(x=0\) 时的条件均值，\(\beta_1\) 是 \(x\) 每增加一个单位时条件均值的变化。若 \(x=0\) 远离数据范围，截距只是定位直线所需的参数，未必具有生物学解释；把 \(x\) 中心化到有意义的参照值可得到更可读的截距。

素材把 \(\varepsilon_i\) 与残差混为同义。误差是总体模型中不可观测的随机偏离，残差

\[
e_i=y_i-\hat y_i
\]

是拟合后可计算的样本偏差。残差受到参数估计约束，方差也随杠杆值变化，不能视为一组直接观测到的独立总体误差。素材还把每个 \(x\) 下的 \(Y\) 写成 \(N(0,\sigma_\varepsilon^2)\)；正确的正态模型是 \(Y\mid x\sim N(\beta_0+\beta_1x,\sigma^2)\)，等价地说误差均值为零。

预测变量可以在重复抽样中随机变化。经典条件回归把已观察到的 \(x_i\) 当作条件，要求主要落在误差结构和均值模型上；若 \(X\) 本身有不可忽略的测量误差，普通最小二乘斜率可能发生衰减等偏差，需要校准模型、重复测量或误差变量方法，而不是只扩大 \(Y\) 方向的标准误。

### 最小二乘估计

拟合直线

\[
\hat y_i=b_0+b_1x_i
\]

选择 \(b_0,b_1\) 使残差平方和

\[
SSE=\sum_{i=1}^{n}(y_i-\hat y_i)^2
\]

达到最小。令

\[
S_{xx}=\sum_i(x_i-\bar x)^2,
\qquad
S_{xy}=\sum_i(x_i-\bar x)(y_i-\bar y),
\]

则

\[
b_1=\frac{S_{xy}}{S_{xx}},
\qquad
b_0=\bar y-b_1\bar x.
\]

因此带截距的最小二乘直线通过 \((\bar x,\bar y)\)，残差和为零，残差与截距列和 \(x\) 列正交。这些是最小化和正规方程的代数结果，不是数据符合正态模型的证据。NIST 将线性最小二乘定义为最小化数据与模型之间的平方偏差，并强调“线性”是对未知参数而言；含 \(x^2\) 或 \(\log x\) 的曲线仍可在线性参数模型中拟合。[^nist-linear-least-squares]

平方损失会放大大残差，因而最小二乘对离群观测敏感。它的统计性质还取决于零条件均值、独立性和方差结构；只有一条数值上可计算的最小平方直线，并不自动使标准误、检验和预测区间有效。

### 平方和、斜率检验与 \(R^2\)

带截距的简单回归具有

\[
SST=SSR+SSE,
\]

\[
SST=\sum_i(y_i-\bar y)^2,\qquad
SSR=\sum_i(\hat y_i-\bar y)^2.
\]

素材分别称 \(SSR\) 为回归平方和 \(U\)、称 \(SSE\) 为离回归平方和 \(Q\)，这一经典记号可以保留，但“\(x\) 引起的变异”和“误差因素引起的变异”应改为模型分配的拟合变异与剩余变异，避免把代数分解写成因果分解。残差标准差为

\[
s=\sqrt{\frac{SSE}{n-2}},
\]

斜率标准误为

\[
\operatorname{SE}(b_1)=\frac{s}{\sqrt{S_{xx}}}.
\]

检验 \(H_0:\beta_1=0\) 时，

\[
t=\frac{b_1}{\operatorname{SE}(b_1)}
\sim t_{n-2}.
\]

回归 ANOVA 表的单自由度统计量

\[
F=\frac{SSR}{SSE/(n-2)}
\]

满足 \(F=t^2\)。使用同一批完整观测、带截距的简单回归时，斜率检验、Pearson 零相关检验和这个 F 检验给出完全相同的双侧结论，不只是“基本相等”。

决定系数为

\[
R^2=1-\frac{SSE}{SST}=\frac{SSR}{SST}.
\]

在带截距的简单回归中 \(R^2=r^2\)。它表示当前样本的 \(Y\) 校正总平方和中，线性拟合相对于仅用 \(\bar y\) 的模型减少了多少比例的平方误差。它不表示 \(X\) 在因果上“造成”了多少变异，也不表示模型在新数据上仍能解释同样比例。增加预测项通常不会降低训练集 \(R^2\)，所以多元模型还应同时考虑调整 \(R^2\)、区间、预测误差和外部有效性。

### 均值区间与个体预测

在 \(x_0\) 处的拟合均值为 \(\hat y_0=b_0+b_1x_0\)。经典模型下，其置信区间为

\[
\hat y_0
\pm t_{1-\alpha/2,n-2}\,
s\sqrt{\frac1n+\frac{(x_0-\bar x)^2}{S_{xx}}}.
\]

对同一 \(x_0\) 处一个新的独立观测，预测区间为

\[
\hat y_0
\pm t_{1-\alpha/2,n-2}\,
s\sqrt{1+\frac1n+\frac{(x_0-\bar x)^2}{S_{xx}}}.
\]

第二式多出的 \(1\) 表示新个体自身围绕条件均值的变异，因此预测区间比均值置信区间宽。二者都在 \(\bar x\) 附近最窄，离数据中心越远越宽。Penn State 的估计与预测章节和 R 的 `predict.lm` 文档都明确区分给定预测值处的平均响应与单个未来响应。[^psu-regression-prediction] [^r-predict-lm]

这些公式描述模型内不确定性，不覆盖错误函数形式、未建模批次、未来总体漂移或测量流程改变。外推到样本 \(x\) 范围之外时，区间可能仍被软件计算出来，但它依赖从未被数据检验的函数形状；NIST 也把外推性质和离群敏感性列为线性最小二乘的主要边界。[^nist-linear-least-squares]

## 多元线性回归与条件效应 { #multiple-regression }

### 设计矩阵与系数解释

有 \(p-1\) 个预测列时，模型写为

\[
\mathbf Y=\mathbf X\boldsymbol\beta+\boldsymbol\varepsilon,
\qquad
\widehat{\boldsymbol\beta}
=(\mathbf X^\mathsf T\mathbf X)^{-1}
\mathbf X^\mathsf T\mathbf Y,
\]

其中第二式要求设计矩阵满列秩。它与[方差分析的一般线性模型](anova_regression.md#general-linear-model)完全相同：连续预测变量、分类因素、区组和协变量只是设计矩阵中的不同列。

系数 \(\beta_j\) 表示其他模型列保持相同时，\(x_j\) 增加一个单位对应的条件均值变化。这个解释取决于模型中包括哪些变量、它们怎样编码，以及是否存在非线性或交互。遗漏与 \(x_j\) 和 \(Y\) 都有关的变量会改变系数；加入中介、碰撞变量或高度相关的替代指标也可能改变问题本身。因此“调整后系数”不是自动更接近因果真相。

部分回归图把 \(Y\) 对其余预测变量的残差与 \(x_j\) 对其余预测变量的残差相对作图；其斜率等于完整模型中的 \(b_j\)。它能显示某个预测变量在调整其他线性项后的增量关系，也能暴露少数点对该系数的影响。NIST 的诊断指南给出了这一构造及其与部分相关的联系。[^nist-regression-diagnostics]

### 交互、曲率与层级结构

若一个预测变量的效应随另一个变量改变，应加入交互项。例如

\[
E(Y\mid x,z)=
\beta_0+\beta_1x+\beta_2z+\beta_3xz,
\]

则 \(x\) 的斜率为 \(\beta_1+\beta_3z\)。有交互时，单个主效应系数只是在另一变量等于参照值时的条件效应；中心化连续变量或设置有意义的分类参照，可以改善解释而不改变拟合。

曲率可用多项式、分段线性、样条或经过生物学论证的变换表示。二次模型

\[
E(Y\mid x)=\beta_0+\beta_1x+\beta_2x^2
\]

虽然对 \(x\) 是曲线，对参数仍然线性。保留 \(x^2\) 时通常也保留 \(x\)，以维持层级结构；多项式系数本身依赖中心和量纲，导数、转折点与区间往往比逐项 *p* 值更有生物学意义。

### 共线性与正则化

共线性表示一个预测列接近其他列的线性组合。它不会在经典条件成立时自动使普通最小二乘有偏，却会放大系数方差，使符号和显著性对样本或模型细节敏感。第 \(j\) 个预测变量的方差膨胀因子为

\[
VIF_j=\frac1{1-R_j^2},
\]

其中 \(R_j^2\) 来自把 \(x_j\) 对其余预测变量回归。两两相关很小也不能排除多个列共同产生的高阶共线性；NIST 和 Penn State 的诊断资料都强调这种设计矩阵层面的不稳定。[^nist-regression-diagnostics] [^psu-multicollinearity]

VIF 没有脱离样本量、目标和设计的普适删除阈值。若变量代表预先规定的混杂因素或组成项，删掉它可能改变待估量；若目标是预测，相关变量的联合预测仍可能稳定，即使单个系数不稳定。可通过重新参数化、中心化结构性多项式、改进设计、增加有信息的观测或按科学意义合并指标处理。

预测变量很多或高度相关时，岭回归与 lasso 在平方损失上加入惩罚：

\[
\text{ridge:}\quad
SSE+\lambda\sum_{j=1}^{p-1}\beta_j^2,
\qquad
\text{lasso:}\quad
SSE+\lambda\sum_{j=1}^{p-1}\lvert\beta_j\rvert.
\]

岭回归连续收缩相关系数，lasso 还可能把部分系数压到零；elastic net 混合两类惩罚。它们以引入偏差换取方差下降，适合预测和高维稳定化，但惩罚强度、变量标准化与数据划分必须一并说明。Friedman、Hastie 与 Tibshirani 的算法论文系统描述了 \(L_1\)、\(L_2\) 及其混合惩罚。[^glmnet-paths] 在同一数据上选择变量或 \(\lambda\) 后再套用普通最小二乘 *t* 区间，会忽略选择不确定性。

| 原曲线 | \(y'\) | \(x'\) | \(a'\) | 直线化结果 |
| --- | --- | --- | --- | --- |
| \(\hat y=(a+bx)/x\) | \(yx\) |  |  | \(\hat y'=a+bx\) |
| \(\hat y=1/(a+bx)\) | \(1/y\) |  |  | \(\hat y'=a+bx\) |
| \(\hat y=x/(a+bx)\) | \(x/y\) |  |  | \(\hat y'=a+bx\) |
| \(\hat y=ax+bx^2\) | \(y/x\) |  |  | \(\hat y'=a+bx\) |
| \(\hat y=a+b\ln x\) |  | \(\ln x\) |  | \(\hat y=a+bx'\) |
| \(\hat y=a+b\lg x\) |  | \(\lg x\) |  | \(\hat y=a+bx'\) |
| \(\hat y=ax^b\) | \(\ln y\) | \(\ln x\) | \(\ln a\) | \(\hat y'=a'+bx'\) |
| \(\hat y=ae^{bx}\) | \(\ln y\) |  | \(\ln a\) | \(\hat y'=a'+bx\) |
| \(\hat y=axe^{bx}\) | \(\ln(y/x)\) |  | \(\ln a\) | \(\hat y'=a'+bx\) |
| \(\hat y=1/(ax^b)\) | \(\ln(1/y)\) | \(\ln x\) | \(\ln a\) | \(\hat y'=a'+bx'\) |

这张表保留了从散点形状、代数变换到直线拟合的学习路径，也暴露了每种方法的定义域。例如对数幂函数要求相应变量为正，含 \(y/x\) 或 \(\ln(y/x)\) 的变换还要求 \(x\neq0\) 并满足符号条件。数据不得为了套表而随意删去零值或负值。

直线化改变了最小化的残差。对 \(\ln y\) 做等权最小二乘，相当于在对数尺度设定加性同方差误差，通常更接近原尺度上的乘性误差；它不等同于在原尺度最小化 \(\sum(y-\hat y)^2\)。变换后的 \(R^2\) 衡量变换尺度上的平方误差，不能直接与原尺度模型的 \(R^2\) 排名。把 \(\widehat{\ln Y}\) 直接指数变回去通常估计条件中位数，若要估计原尺度条件均值还需考虑残差分布和回变换偏差。

### 原尺度非线性最小二乘与平滑

当机制给出参数非线性模型时，可直接拟合

\[
Y_i=f(x_i;\boldsymbol\theta)+\varepsilon_i
\]

并在与科学问题一致的尺度上最小化残差平方和。NIST 将非线性最小二乘定义为函数对未知参数不线性的模型，同时指出其估计思想仍与最小二乘相同。[^nist-nonlinear-least-squares] 直接拟合可以保留饱和值、增长率或半饱和常数等原尺度参数，也能显式指定异方差；代价是需要起始值、数值优化、可辨识性检查和可能的多极值诊断。

若目标是探索未知曲线形状，局部回归或样条可比枚举许多变换更灵活。平滑程度必须由独立验证、预设准则或足够数据决定；过度灵活会把随机波动当作结构。探索性平滑可帮助提出机制模型，却不应在同一数据上反复挑曲线后把普通置信区间当作预先规定的推断。

## 残差、杠杆与影响诊断 { #model-diagnostics }

### 条件与对应图形

经典线性模型的关键条件各自对应不同证据：

| 条件 | 主要来源 | 常用检查 | 违反后的方向 |
| --- | --- | --- | --- |
| 条件均值形式合适 | 变量关系与模型项 | 原始散点、残差—拟合值、部分残差图 | 加入有依据的曲率、交互或遗漏变量 |
| 误差方差结构合适 | 测量和生成过程 | 残差—拟合值、尺度—位置图、分组残差 | 变换、加权最小二乘、异方差稳健协方差或显式方差模型 |
| 误差独立或相关已建模 | 抽样、时间、空间与层级设计 | 按采集顺序、个体、地点和批次绘制残差 | 广义最小二乘、聚类稳健方法、时间模型或混合模型 |
| 小样本参照分布合适 | 条件误差分布 | Q–Q 图、尾部和异常观测溯源 | bootstrap、稳健模型或与分布相符的响应模型 |

残差图能发现模型未表达的模式，却不能证明随机化或独立抽样发生过。正态性主要关系到小样本 *t*、F 和预测区间的精确参照，不要求 \(X\) 或所有 \(Y\) 的边际分布各自正态。大样本下系数推断可以有一定稳健性，但强异方差、聚类、小有效样本和高杠杆会破坏简单近似。

若方差随预测水平变化，而相对方差函数有测量学依据，加权最小二乘以近似逆方差作权重；NIST 将其描述为针对非恒定误差方差的最小二乘扩展。[^nist-weighted-least-squares] 不知道方差函数时，异方差稳健标准误可以修正系数协方差，却不会修正错误均值函数、异常预测或相关误差。

### 异常响应、高杠杆与影响

异常响应、杠杆和影响是三个不同概念。异常响应在 \(Y\) 方向偏离模型，表现为大残差；高杠杆观测在预测变量空间远离其余数据；影响则表示删除或轻微改变该观测会明显改变系数、拟合值或结论。高杠杆点可以贴近拟合面而残差很小，也可以因为位置极端而决定斜率。

帽子矩阵为

\[
\mathbf H=
\mathbf X(\mathbf X^\mathsf T\mathbf X)^{-1}
\mathbf X^\mathsf T,
\qquad
\widehat{\mathbf Y}=\mathbf H\mathbf Y.
\]

对角元 \(h_{ii}\) 是杠杆值，若模型有 \(p\) 个参数（含截距），其平均值为 \(p/n\)。残差方差为 \(\sigma^2(1-h_{ii})\)，因此比较异常程度时常使用内部或外部学生化残差，而不只看原始残差。

Cook 距离同时结合残差与杠杆：

\[
D_i=
\frac{e_i^2}{p\,MSE}
\frac{h_{ii}}{(1-h_{ii})^2}.
\]

它概括删去第 \(i\) 个观测后整组拟合值或系数发生的变化。NIST 与 Penn State 的诊断资料都区分异常值、高杠杆和影响，并用帽子矩阵、学生化残差、DFFITS 与 Cook 距离连接这些概念。[^nist-regression-diagnostics] [^psu-influential-points]

经验阈值只是筛查线索，不是自动删除规则。应回到原始记录核对单位、录入、样本身份和实验事件，再比较含／不含该点、稳健拟合和有科学依据的替代模型。真实而罕见的生物状态可能正是研究对象；删除它会缩小适用总体。若结论依赖单个合法观测，应报告这种敏感性并收窄结论。

### 相关误差、测量误差与模型错配

时间序列、空间样点、同一个体重复测量和同一批次样本会使误差相关。普通最小二乘系数有时仍能计算，但标准误、有效自由度和预测区间通常不再有效；应按生成层级使用相关结构、聚类稳健协方差、广义估计方程或[混合效应模型](generalized_mixed_models.md)，并在相同层级做验证划分。

响应为计数、比例、发生／未发生或生存时间时，正态线性模型可能给出不可能的预测并错误描述均值—方差联系。此时应根据响应分布转入广义线性、生存或其他专门模型，而不是把每种问题都强行直线化。稳健标准误只能改变推断方差，不能使不合适的均值函数和支持范围变正确。

## 预测验证与完整报告 { #validation-reporting }

### 从样本内拟合到样本外性能

样本内 \(R^2\)、残差标准差和显著性描述的是用于拟合的同一批数据。评价预测必须让验证观测不参与模型拟合、变量筛选、变换选择、标准化或超参数选择；否则测试信息泄漏会使误差过度乐观。scikit-learn 的交叉验证指南同样强调训练和测试同源评估的过拟合问题，并要求预处理只在训练折学习。[^cross-validation]

\(k\) 折交叉验证在每轮用 \(k-1\) 折训练、留下一折评估，再汇总各折指标。折的单位必须跟独立信息单位一致：同一个体的多次测量应整体留出，空间样地、家系或批次需要分组划分，时间预测则要保持时间顺序。随机拆散相关行会让近乎重复的信息同时进入训练与验证。

模型选择与最终评估应分离。若交叉验证用于选择变量、曲线复杂度或惩罚强度，还需要独立测试集或嵌套交叉验证估计最终泛化误差。报告指标要匹配目标：RMSE 强调大误差，MAE 给出绝对误差的稳健尺度，预测区间还要检查覆盖率和宽度。训练集 \(R^2\) 高、系数显著或残差近似正态，都不能代替样本外验证。

### 结果报告

相关分析至少说明观测单位、完整配对数、缺失处理、变量范围、散点结构、所用 Pearson／Spearman／Kendall 指标、估计值、区间和检验方向。多个变量组成相关矩阵时，应说明比较家族和调整策略，不能从大量系数中只挑显著者叙述。

回归分析至少报告研究目标、响应与预测变量的单位、模型公式、变换和交互、系数估计及区间、残差标准差、\(R^2\) 与调整 \(R^2\)、均值或预测区间的对象、诊断和敏感性分析。用于预测时还要给出验证划分、预处理位置、评价指标、目标总体与适用范围；用于因果解释时要另行说明设计、时间顺序、混杂控制和识别假设。

可靠的回归结论最终落在原始尺度和研究对象上：斜率代表多大的生物变化，区间是否排除有意义的效应，预测误差是否足以支持用途，异常点是否属于目标总体。公式把关系压缩为系数，诊断与设计则决定这些系数能够代表多远。
