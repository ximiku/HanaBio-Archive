# 数量遗传学

同一物种的个体常在身高、开花期、产量、血压或行为倾向等性状上呈现连续差异。每个位点的等位基因仍按孟德尔规律分离，但许多位点的效应与环境差异叠加后，单个分离比不再直接显现在表型分布中。数量遗传学以群体中的均值、方差和亲属相似性为观察对象，在不知道所有因果位点时仍能估计遗传变异、预测选择反应，并为复杂性状定位提供统计框架。

这套方法描述的是一个明确群体在规定环境与测量方案下的变异。数量遗传参数用于分解群体中个体差异的统计来源；单个个体的性状形成过程仍需由具体发育机制解释，遗传率也属于群体统计量。

## 孟德尔分离汇成数量性状分布 { #polygenic-traits }

数量性状通常以可连续测量的数值记录，复杂性状则强调多个遗传和非遗传因素共同影响；两者高度重叠，却不是同义词。一个大效应座位也能使连续测量值明显分组，许多小效应位点又能通过潜在倾向影响“患病／未患病”“存活／死亡”等二分类结果。表型看起来连续或离散，取决于遗传架构、环境、测量精度和分类规则，不能仅凭直方图断定控制基因数。

### 多基因模型连接颗粒遗传与连续变异 { #polygenic-model }

若干独立座位各贡献相同的加性效应，亲本在这些座位上固定不同等位基因时，F$_2$ 表型类别可按二项式系数形成近似钟形的频数序列。这一“多基因学说”历史上说明了连续变异可以由离散遗传单位产生。真实性状中的位点效应大小通常不同，还可存在显性、上位作用、连锁、多效性和基因型—环境互作；位点数也不是无限。因此，杨辉三角只是等效、独立、完全加性模型的教学特例，不是由表型类别反推基因数的通用算法。[^quantitative-variation]

所谓无穷小模型进一步假定大量小效应因子共同决定遗传值，使后代遗传值能够围绕亲本均值形成可处理的分布；这里的“无穷小”是一种统计近似。这个近似对短期选择和育种值预测很有用；发现大效应数量性状座位（quantitative trait locus，QTL）、环境依赖效应或强烈非加性结构时，则要扩展模型，同时保留底层的孟德尔分离。

### 阈性状以潜在易感度产生离散观察 { #threshold-traits }

阈值模型把许多小效应因素汇总成不可直接观察的连续易感度（liability），当易感度越过一个或多个阈值时才进入相应表型类别。例如某些疾病状态、产仔数等级或发育转换可以在观察层面离散，在易感度层面却有连续差异。正态易感度是常用建模假设，并非已经测得的实体；阈值位置还受人群患病率、年龄、环境和诊断标准影响。二分类性状的“遗传率”若换算到易感度尺度，必须说明样本抽取、群体患病率和模型假设。[^heritability-guide]

## 表型值分解为可估计的统计成分 { #phenotypic-decomposition }

对某一性状，可把个体表型写成

$$
P = \mu + G + E,
$$

其中 $\mu$ 是指定群体和环境中的均值，$G$ 是该个体基因型相对于均值的效应，$E$ 是剩余偏差。若不同基因型对环境的反应不平行，还可显式加入 $G\!\times\!E$；母体效应、共同家庭环境、批次和测量误差也应按实验设计单独建模。符号相同不表示所有研究采用了同一测量尺度或同一随机效应结构。

### 遗传值的加性、显性与上位分量 { #genetic-value-components }

经典分解把基因型值写为

$$
G = A + D + I.
$$

$A$ 是加性遗传值或育种值，由各等位基因在当前群体背景下的平均替代效应相加而成；它描述一个个体作为亲本时可预测传给后代的平均偏离。$D$ 是同一座位两个等位基因组合相对于加性预期的显性离差，$I$ 是不同座位组合产生的上位离差。这里的“加性”是对群体数据的统计投影，并不要求蛋白质、通路和细胞过程在生理上互不作用。即使基因作用高度非线性，特定等位基因频率下的大部分遗传方差仍可能表现为加性方差。[^additive-variance]

后代会继承组成 $D$ 和 $I$ 的等位基因，却通常不会原样继承亲本的等位组合；分离和重组会重新组合这些状态。因此，随机交配群体中的短期选择反应主要由 $A$ 预测，而非简单声称显性和互作“不能遗传”。克隆繁殖、固定自交系之间的杂交以及特定配合力评价，可以利用完整基因型值中的非加性部分。

### 方差分解依赖群体与设计 { #variance-components }

在各分量正交且没有基因型—环境互作或相关时，表型方差可简写为

$$
V_P = V_A + V_D + V_I + V_E.
$$

实际数据还可能包含 $V_{G\times E}$、母体或共同环境方差，以及遗传与环境之间的协方差。选择、近交、群体分层、连锁不平衡和择偶偏好都会使某些分量不再正交；模型遗漏的效应也可能进入“环境”或残差项。方差分量因此不是基因或性状的固定物理常数，而是当前等位基因频率、亲缘结构、环境范围和统计模型共同产生的量。[^quantitative-variation]

经典杂交资料有时以遗传一致的亲本和 F$_1$ 方差估计 $V_E$，再用 F$_2$、回交世代的方差组合估计加性与显性方差。这个办法要求亲本和 F$_1$ 内部几乎没有遗传分离，各世代经历相同环境与误差结构，并符合所用的加性—显性模型。用亲本均值差和 F$_2$ 方差估计“最少基因对数”、或由 $V_D/V_A$ 推算平均显性度，也依赖等效位点、无上位作用和相近环境方差等强假设；现代 QTL 与混合模型分析不能被这些公式机械替代。

### 基因型—环境互作改变跨环境排序 { #genotype-environment-interaction }

同一基因型在一系列环境中的期望表型构成反应规范。不同基因型的反应规范不平行时存在 $G\!\times\!E$：它们可能只在差异幅度上变化，也可能在不同环境中交换优劣次序。后一种情形会显著限制一个环境中估计的育种值向另一环境外推。重复基因型、共同园实验或多地点多年度试验能够把环境主效应与互作分开；单次观测通常做不到这一点。[^genotype-environment]

## 遗传率度量群体差异中的遗传分量 { #heritability }

广义遗传率与狭义遗传率分别定义为

$$
H^2 = \frac{V_G}{V_P}, \qquad h^2 = \frac{V_A}{V_P}.
$$

$H^2$ 包含模型能够识别的全部遗传方差，在克隆或固定自交系能够重复测量时可用于比较完整基因型值；$h^2$ 只取加性方差，直接连接亲代选择与随机交配后代的平均反应。两者都必须附带研究群体、环境、年龄、性状定义和估计方法。同一性状在环境被标准化后可能因 $V_E$ 缩小而得到较高遗传率，在环境更异质的群体中则可能降低；等位基因频率改变也会改变 $V_A$ 和 $V_G$。[^heritability-concepts]

遗传率描述的是群体内变异，不能解释单个个体表型中“遗传占多少”。高遗传率不表示环境干预无效：营养、管理或治疗可以整体移动群体均值，而不必改变原有个体差异的排序。低遗传率也不等于缺少遗传变异，它可能来自较大的环境方差或测量误差。将不同群体的遗传率直接比较为“更受基因控制”，同样会混入不同的变异范围和研究设计。

### 亲属相似性与基因组相似性提供估计依据 { #heritability-estimation }

亲子回归、半同胞／全同胞比较、双生子与收养设计、克隆或自交系重复试验，都利用不同亲属共享遗传和环境的程度估计方差分量。亲子共享环境、母体效应、择偶同质性和间接遗传效应若未进入模型，可能混入遗传方差估计；全同胞同时共享加性、显性和家庭环境，仅凭一类亲属很难将它们完全分开。现代动物模型和 REML 可联合大量谱系关系，基因组关系矩阵则利用标记估计实际共享片段，但结果仍取决于样本、标记覆盖和模型假设。[^heritability-guide]

“单核苷酸多态性（single-nucleotide polymorphism，SNP）遗传率”通常只计算被所测标记直接或经连锁不平衡捕获的加性变异，和家系估计的狭义遗传率不必相等。两者的差距可能来自罕见变异、结构变异、标记覆盖、基因作用模型和偏倚，尚未解释的方差也可能分散在多类来源中。

## 亲缘与近交以同祖等位基因为尺度 { #relatedness-inbreeding }

两个个体 $X$ 与 $Y$ 的亲缘系数 $\phi_{XY}$，是在同一常染色体座位各随机抽取一个等位基因时，两者同祖同源（identity by descent，IBD）的概率。常用关系系数 $r_{XY}$ 在非近交二倍体的约定下等于 $2\phi_{XY}$。一个后代 $Z$ 的近交系数 $F_Z$，是其同一常染色体座位的两个等位基因 IBD 的概率；它等于双亲间的亲缘系数 $\phi_{XY}$。因此，“$R=2F$”只有在明确比较这对双亲的关系系数与其后代近交系数时才成立，不能作为任意亲属与任意个体之间的通式。[^kinship-coefficients]

通径法沿 $X$ 与 $Y$ 到同一祖先的独立路径求和。若一条路径从二者到共同祖先 $A$ 分别经历 $n_X$ 和 $n_Y$ 次亲子传递，该路径对亲缘系数的贡献为 $2^{-(n_X+n_Y+1)}(1+F_A)$。在创始祖先无近交的简单谱系中，亲子或全同胞的 $\phi$ 期望均为 $1/4$，一级表亲的两位共同祖父母各贡献 $1/32$，合计 $1/16$；一级表亲所生子女的 $F$ 因而也是 $1/16$。共享祖先、路径独立性和祖先近交必须逐项核对，不能按亲属称谓直接套用一个数。

谱系算法给出在创始个体互不相关且无近交等假设下的期望 IBD。有限减数分裂中实际传递的片段会围绕期望波动，基因组标记可以估计实现亲缘和连续纯合片段。X 染色体、单倍体和多倍体需要与常染色体二倍体不同的传递模型，不能用“伴性遗传计步不计男性”之类口诀替代路径概率。

### 近交改变基因型频率并可能引起衰退 { #inbreeding-depression }

近交提高同祖纯合概率并降低杂合度；在没有选择、漂变或迁移时，它本身不要求群体等位基因频率立即改变。若许多有害等位基因部分隐性，纯合增加会暴露其效应，使存活、繁殖等适合度相关性状的均值下降，形成近交衰退。衰退的大小依性状、等位基因频率、显性方向、既往近交史和环境而变；没有方向性显性时，某性状均值甚至可以不下降。近交也使家系间差异扩大，而不是简单让整个群体朝一个相同表型收敛。

近交可让选择清除一部分暴露的隐性有害等位基因，称为遗传净化，但强烈衰退可能先造成种群规模下降，有限群体的漂变又会固定有害变异。净化的速度和效果因群体历史而异，不能据此把近交视为安全的改良手段。

### 杂种优势是相对于参照亲本的特定比较 { #heterosis }

F$_1$ 遗传值与双亲遗传值平均数之差称中亲优势，正值表示超过中亲；相对于较优亲本或商业对照的差值是不同的应用指标。隐性有害等位基因在两亲本间互补可产生显性模型下的优势，某些座位的杂合体优于两种纯合体属于超显性，不同座位组合还可贡献上位效应。三类机制可在同一性状中并存，观察到一个高产 F$_1$ 不能单凭表型区分它们。[^heterosis-review]

杂交结果取决于亲本的等位基因组合、遗传距离、细胞质和亲本来源、环境以及所选参照，远缘杂交还可能破坏共适应组合或造成减数配对异常。骡与驴骡展示了种间杂交、正反交和不育，其染色体配对、生殖和家畜利用见动物栏目；这些性状本身不能区分普遍杂种优势的候选机制。

## 选择反应取决于可传递的差异 { #selection-response }

设选择前群体均值为 $\bar P$，获选亲本的表型均值为 $\bar P_s$，则选择差 $S=\bar P_s-\bar P$；下一代相对于选择前群体的均值改变为反应 $R$。在同一环境下依据个体表型进行一次定向选择，并满足加性回归近似时，育种者方程给出

$$
R \approx h^2 S.
$$

等价地，若截留选择强度为 $i$、选择前表型标准差为 $\sigma_P$，则 $S=i\sigma_P$。这个方程说明表型上领先的亲本只有其中与育种值相关的部分能稳定改变后代均值。实现遗传率 $R/S$ 是特定选择实验的回顾性估计，不能脱离该实验推广为性状常数。[^breeders-equation]

单代方程的预测依赖亲代与后代环境可比、表型与育种值近似线性、选择对象确实繁殖以及没有遗漏的相关性状。自然选择中，一个性状与真正影响适合度的其他性状相关时，单变量 $R=h^2S$ 可能把间接选择当作直接选择。多性状分析用加性遗传方差—协方差矩阵连接选择梯度与响应；其中遗传相关既可产生有利的相关反应，也可让一个性状的改良受到另一性状约束。

连续多代选择还会改变等位基因频率、连锁不平衡和 $V_A$。有限群体中的漂变与近交、选择造成的配子相位关联、基因型—环境互作和接近生理边界，都会使实际反应偏离首代预测。由此，育种方案应同时考虑选择准确度、强度、可用遗传变异和世代间隔；“高遗传率早选、低遗传率晚选”只是某些育种体系的经验倾向，不是跨物种通则。

## 从方差定位到位点与全基因组预测 { #qtl-gwas-prediction }

方差分解回答一个群体有多少可利用变异，定位分析则寻找哪些基因组区域与这些差异共同传递。两者尺度不同：一个性状可有很高的狭义遗传率，却由大量单个位点效应很小的变异共同造成；一个显著的大效应位点也未必解释不同环境或其他群体中的主要方差。

### 实验杂交中的 QTL 作图 { #qtl-mapping }

QTL 是与数量性状差异统计关联的基因组区间，不必等于一个基因。实验杂交通常选择表型和标记不同的亲本，建立 F$_2$、回交、重组近交系（recombinant inbred line，RIL）或双单倍体（doubled haploid，DH）群体，利用标记间重组定位影响性状的亲本等位基因。区间作图在相邻标记之间计算未观测 QTL 基因型的概率，再比较含与不含 QTL 的似然；它把 QTL 位置与效应同时置于连锁图框架，是从单标记比较迈出的关键一步。[^qtl-mapping]

作图群体只检验亲本间分离的等位差异。样本量、重组断点、标记密度、表型重复和环境范围决定功效与分辨率；小样本中只有估计效应偏大的位点容易越过阈值，位置区间也可能含多个紧密连锁因果变异。全基因组扫描还涉及许多相关检验，应以置换、显式错误率控制或预先规定的全基因组阈值校准，不能把每个标记的普通 $p<0.05$ 当作发现标准。独立群体复现、近等基因系、精细作图和扰动实验可逐步加强因果证据。

### GWAS 与基因组预测回答不同问题 { #gwas-genomic-prediction }

全基因组关联研究（GWAS）利用自然或育种群体中的连锁不平衡，检验标记与表型是否在群体中共同变化。显著标记可能只是与因果变异连锁，不直接指定因果基因；群体结构、亲缘、批次和环境相关性还会制造混杂。统计校正、独立复现、跨祖源精细定位与功能证据共同决定解释强度。实验 QTL 作图的等位范围受亲本限制而重组较少，GWAS 可调查更多历史等位变异并利用更多累积重组，但稀有变异、结构变异和小效应信号仍可能检出不足。[^gwas-discovery]

基因组预测把大量标记同时纳入模型，目标是预测未表型个体的育种值，而不要求先确认每个因果位点；对所有候选个体进行选择便形成基因组选择。预测准确度依训练群体规模、亲缘、连锁不平衡、环境和性状定义，训练群体与应用群体差异增大时通常下降。人类多基因评分同样是群体模型的个体预测量，与遗传率分属预测和方差分解两个层次；其临床效用、公平和伦理边界见[人类遗传学](developmental_human.md)。

[^quantitative-variation]: Hill 的[数量遗传变异综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC2842708/)说明数量遗传模型如何由多基因与非遗传因素解释连续、计数和二分类性状，并强调方差分解的群体假设。
[^heritability-guide]: Barry 等的[遗传率估计指南](https://academic.oup.com/ije/article/52/2/624/6847313)比较家系、双生子和基因组方法，并说明二分类性状需要潜在易感度、患病率与抽样假设。
[^additive-variance]: Hill、Goddard 与 Visscher 的[分析](https://journals.plos.org/plosgenetics/article?id=10.1371/journal.pgen.1000008)区分生物学上的基因互作与群体统计中的加性、显性和上位方差；等位基因频率可使强非加性作用主要投影为加性方差。
[^genotype-environment]: 不同基因型反应规范不平行以及幅度改变与排序交叉两类 $G\!\times\!E$，见 Saltz 等的[综述](https://onlinelibrary.wiley.com/doi/10.1002/ece3.4128)。
[^heritability-concepts]: 遗传率的群体与环境特异性及常见误解见 Visscher 等的[综述](https://www.nature.com/articles/nrg2322)；不同估计设计的偏倚见 Barry 等的[方法指南](https://academic.oup.com/ije/article/52/2/624/6847313)。
[^kinship-coefficients]: Vigeland 对[谱系 IBD 系数](https://pmc.ncbi.nlm.nih.gov/articles/PMC9911075/)的定义明确区分 $\phi_{XY}$ 与后代 $F$：后者等于双亲间亲缘系数，关系系数另按约定缩放。
[^heterosis-review]: 中亲优势、显性／超显性／上位模型、环境与参照依赖性见 Labroo、Studer 与 Rutkoski 的[杂种优势综述](https://www.frontiersin.org/journals/genetics/articles/10.3389/fgene.2021.643761/full)。
[^breeders-equation]: Walsh 与 Lynch 的[育种者方程章节](https://academic.oup.com/book/40062/chapter/340633226)给出单代 $R=h^2S$ 及其向不同性别、重叠世代和多性状选择的扩展；自然群体中遗漏相关性状的风险见 Morrissey 等的[评述](https://academic.oup.com/jeb/article-abstract/23/11/2277/7324660)。
[^qtl-mapping]: Lander 与 Botstein 的[区间作图论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC1203601/)把标记连锁、QTL 位置和效应纳入似然框架；全基因组相关检验及置换阈值见 Knott 等的[方法综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC1569507/)。
[^gwas-discovery]: Visscher 等的[GWAS 综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC3257326/)区分关联发现、因果解释和即时预测效用，并讨论小效应、多基因性与未解释遗传变异。
