# 石松类与蕨类植物

石松类和蕨类都是维管植物，也都以孢子而非种子完成远距离传播。传统教材因而常把它们合称为“蕨类植物”或“孢子维管植物”。这个合称便于描述生活史，却不代表一个排除种子植物后仍然完整的演化支：石松类是现生维管植物最早分出的一个大支；蕨类则与种子植物共同构成真叶植物支。木贼和松叶蕨看似偏离典型蕨形，分子系统学却把它们稳固地置于蕨类内部。因此，本文把“无种子的维管植物”当作生态与生活史范畴，再分别讨论石松类和单系的蕨类。[^ppg-i][^onekp]

与[苔藓植物](bryophytes.md)相比，这两类植物的孢子体已经形成真正的根、茎和叶，并由木质部和韧皮部连成连续的输导系统。受精后形成的胚最初仍从雌配子体取得物质，随后发育为能长期独立生活、在植被中最醒目的孢子体。配子体则缩小到毫米至厘米尺度，却没有像种子植物的花粉和胚囊那样被永久包在孢子体组织内。两个世代各自面对光照、水分、真菌伙伴与取食者，这种“双重生态”是理解石松类和蕨类分布的重要前提。[^gametophyte-ecology]

## 维管孢子体与游离配子体 {#vascular-life-cycle}

孢子体的根、茎、叶之间并非三个孤立部件。茎内的中柱把根吸收的水和无机盐送入叶，也把叶形成的同化物分配给生长点、地下茎和孢子囊。原生中柱中央主要是木质部；管状中柱的髓位于中央，维管组织围绕其外；叶隙增多时，管状中柱可呈网状分割。星状、板状、管状和网状等结构是不同器官尺度、叶迹配置和发育方式下的空间方案，不能排成从“低等”到“高等”的固定阶梯。根、茎和叶的组织发生及叶迹概念可与[植物营养器官](../morphology/vegetative_organs.md)对照阅读。

成熟孢子囊内的孢子母细胞经减数分裂产生单倍体孢子。孢壁上的三裂缝或单裂缝分别对应四面体形、两侧对称的减数分裂产物排列，但裂缝形态并不单独决定类群归属。孢子萌发为配子体，配子体上的精子器产生具鞭毛的精子，颈卵器内保留卵细胞。精子必须沿连续水膜游动到颈卵器，因此空气湿度、基质含水量和降雨时机都直接限制有性生殖；孢子能飘到一处，并不等于那里一定能建立孢子体。

多数石松和蕨类为**同孢型**：一种孢子通常发育成可产生精子器和颈卵器的配子体，具体性别表达又会受配子体年龄、密度和化学信号影响。卷柏、水韭以及水生蕨类中的槐叶苹目为**异孢型**：小孢子形成雄配子体，大孢子形成雌配子体，二者多在孢壁内完成大部分发育。异孢性改变了配子体的营养来源、性别分工和传播单位，却在维管植物演化中独立出现过多次；现生异孢石松也不是种子植物的祖先。

## 石松类 {#lycophytes}

现生石松类包括石松目、卷柏目和水韭目。它们共享石松叶（lycophyll），即通常只有一条不分枝叶脉、发育历史与真叶植物叶片不同的叶。传统“微叶”一词容易让人以为关键只是叶片很小，或把“没有叶隙”当成无例外的诊断；事实上古生代石松类可以长成乔木，叶迹与中柱的关系也有变异。用“石松叶”强调这套叶器官的独立演化来源更为准确。石松类根和茎常作二歧分枝，许多种的原生木质部在器官外侧先成熟，但这些性状仍须结合孢子叶、孢子囊位置和孢子类型判断。叶的多次独立起源也得到化石、发育和基因表达证据的共同支持。[^leaf-origin]

### 石松目：同孢与地下配子体 {#lycopodiales}

石松属（*Lycopodium*）及其近缘类群常有匍匐或直立、反复分枝的茎，螺旋排列的石松叶不具叶舌。孢子囊着生于孢子叶近轴面的基部；在许多石松属植物中，孢子叶聚集成枝端孢子叶球。孢子同型，萌发后的配子体可以埋在土中多年，缺少叶绿素，并依赖内生真菌输入碳和矿质。受精后幼孢子体先附着在配子体上，形成根与绿色枝条后才逐渐取得营养独立。

“石松”在旧的宽泛属概念中包含多种形态。现代分类把孢子叶球明显的狭义石松属与孢子囊散生在普通叶腋、枝端不形成紧密孢子叶球的马尾杉属（*Huperzia*）等分开。马尾杉所含石杉碱甲具有药理研究价值，但化合物用途并不能代替形态和系统证据来界定类群。

### 卷柏与水韭：两种异孢方案 {#selaginella-isoetes}

卷柏属（*Selaginella*）的石松叶基部近轴面有小型叶舌，许多种的叶呈四列并表现背腹差异。枝条分叉处腹侧可长出光滑、无根冠的轴状结构——根托；根托末端随后建立根冠和根毛，转变为根。根托究竟应称根、茎还是独特的过渡器官曾长期争论，比较转录组显示它具有不同于成熟根和茎尖的表达身份，同时在发育上更接近根。因而把它直接等同于一种“气生根”会丢失重要的发育信息。[^rhizophore]

卷柏的孢子叶球内同时具有小孢子囊和大孢子囊。小孢子数量多，内部形成高度简化的雄配子体；每个大孢子囊通常只保留少数体积很大的大孢子，雌配子体利用大孢子储藏物发育。两种配子体都以内生孢方式缩小了暴露在外界的阶段。不同种的小孢子囊产孢数、精子数和孢子叶球组织存在差异，不宜把某个物种观察到的固定数字当作全属通则。

水韭属（*Isoëtes*）多生活在浅水、季节性湿地或水位波动的基质中。短而肉质的球茎状茎顶部簇生细长石松叶，根从茎的基部发生；叶基部内侧的凹穴容纳孢子囊，叶舌位于其上方。外层叶通常形成大孢子囊，内层叶形成小孢子囊，雌雄配子体同样在孢子内发育。球茎状茎还保留一套特殊的侧生分生组织，可产生有限的次生组织；它与种子植物由典型维管形成层造成的木材增粗并不相同。水韭的水下碳同化、沉积物取碳和部分物种的景天酸代谢，说明矮小的现生形态本身包含高度特化的水生适应。[^isoetes-genome]

## 蕨类 {#ferns}

这里的蕨类对应现代系统学中的 Polypodiopsida，也常称 monilophytes。它包括松叶蕨目和瓶尔小草目、木贼目、合囊蕨目以及薄囊蕨类，而不是只指具有羽状大叶和叶背孢子囊群的“典型蕨”。不同基因组区段对蕨类最深分支的排列仍可能给出不同支持度，但木贼、松叶蕨和其余蕨类共同组成种子植物的姐妹群这一大框架已相当稳定。[^onekp][^horsetail-fern]

### 松叶蕨与木贼的特化体制 {#psilotum-equisetum}

松叶蕨属（*Psilotum*）的绿色地上轴二歧分枝，没有通常意义上的根，地下根茎以假根吸收并与真菌共生；小型附属物无叶脉，不能简单等同于典型蕨叶。三个孢子囊侧向合生为三室的聚合孢子囊，产生同型孢子。地下配子体也缺少叶绿素，靠真菌获得碳。它的器官简化一度被解释为“最原始维管植物”的残留，如今松叶蕨与瓶尔小草类的亲缘关系表明，这些形态应在蕨类内部的特化与次生简化背景下理解，不能拿现生松叶蕨替代泥盆纪维管植物祖先。

木贼属（*Equisetum*）具有地下根茎和明显分节的地上茎。节间中空，表面纵肋富集硅质；小叶轮生于节上并在基部合成叶鞘，光合作用主要由绿色茎完成。枝端孢子叶球由盾状孢囊柄构成，孢子囊悬生在盾片内侧。它产生同型、绿色而寿命较短的孢子，孢壁外层裂成四条吸湿弹丝：湿度降低时弹丝展开，能使孢子爬移或弹跳；湿度升高时又卷回，也能让孢子暂时成团。[^equisetum-elaters] 木贼配子体的雌、雄或两性表达会随营养、密度与建立顺序改变，这正是同孢不等于每个配子体都固定为两性的实例。

### 厚囊与薄囊发生 {#sporangium-development}

孢子囊的发生方式是认识蕨类形态演化的关键。厚囊型孢子囊由一群表皮初始细胞共同参与形成，成熟壁通常有多层细胞，体积较大并产生较多孢子。瓶尔小草科和合囊蕨科具有典型厚囊发生；前者的营养叶片与孢子囊穗常从同一叶基部发出，后者可形成粗壮根茎和大型羽状叶。它们都不应因“厚囊”而被当作现代薄囊蕨的活祖先。

薄囊型孢子囊从一个表面初始细胞开始，经过严格的细胞谱系形成细柄、单层成熟囊壁与相对有限的孢子数。囊壁上一列不均匀加厚的环带细胞失水收缩，使孢子囊在特定位置开裂；水柱中的张力骤然释放后，环带回弹并把孢子加速抛出。教材常用“每囊 64 个孢子”描述典型情况，但细胞分裂、败育和倍性变化会造成偏离。紫萁目位于薄囊蕨类较早分出的支系，孢子囊兼有较大的囊体、较多孢子和不完整环带等性状组合；这反映镶嵌式演化，而非一个停在厚囊与薄囊之间的固定“过渡纲”。

### 蕨叶、孢子囊群与散孢 {#fronds-sori}

多数薄囊蕨的茎为地表或地下根茎，叶常称蕨叶（frond）。幼叶常作拳卷式展开，叶轴、羽片和小羽片形成不同层级；树蕨能以直立茎形成树冠，水生蕨的叶形则可高度简化。拳卷、羽状分裂和大型叶都很常见，却各有例外，不能单独用作蕨类的定义。

孢子囊可沿叶缘或叶背的叶脉着生，聚集成孢子囊群。覆盖孢子囊群的膜质结构称囊群盖；有些类群没有真囊群盖，而由反卷叶缘形成保护。营养功能与产孢功能可以分布在同一叶片的不同部位，也可以由形态明显不同的营养叶和孢子叶承担。环带开裂、孢子囊群的位置、囊群盖形态和叶脉配置共同构成薄囊蕨分类的重要性状。

槐叶苹目是薄囊蕨中独立演化出异孢性的水生支系。蘋属（*Marsilea*）把小孢子囊与大孢子囊包入耐受干旱的孢子果；槐叶苹属（*Salvinia*）没有根，每个节上成对的漂浮叶之外还有一枚沉水、细裂而似根的叶；满江红属（*Azolla*）的叶腔容纳固氮蓝细菌共生体。水生生活、异孢性和孢子果因此不能被理解为通往种子的单一路线，它们是薄囊蕨内部形成的一组派生组合。蕨类基因组研究也显示，满江红与槐叶苹虽基因组紧凑，仍经历了蕨类特有的基因组演化历史。[^fern-genomes]

## 配子体的生态多样性 {#gametophyte-ecology}

常见教学图把蕨类配子体画成贴地、绿色、心形的原叶体。这适合表示许多陆生薄囊蕨，却只是众多形态之一。配子体可以是带状、舌状或分枝丝状；松叶蕨、瓶尔小草类和一些石松的配子体生活在地下，缺少叶绿素并依赖真菌；附生蕨和膜蕨类的配子体可通过营养繁殖长期延续。配子体薄、无维管束，水分和溶质主要在表面扩散，因而能进入孢子体无法建立的岩隙、树皮和微小湿润庇护所，也更容易受干燥与辐射影响。

在少数蕨类中，一个地区可长期只有配子体而没有成熟孢子体。这些“独立配子体种群”并不意味着生活史普遍倒回配子体占优势，而是说明配子体的耐阴、耐旱、无性繁殖和微生境需求可以与孢子体解耦。孢子传播范围、配子体实际分布和孢子体可见分布因此可能形成三套不同地图。研究者需用培养、DNA 条形码和生理测量辨认这些难以仅凭外形鉴定的配子体。[^gametophyte-ecology]

异孢类群采用另一种生态方案。小孢子把有限储备投入微型雄配子体，大孢子则为雌配子体及早期胚提供较多物质；两种配子体在孢壁内发育，减少了游离生长，却仍需水膜让有鞭毛精子完成最后一段运动。种子植物进一步把大孢子和雌配子体保留在大孢子囊内，并形成珠被、花粉传递与种子。由此可见，异孢性是种子习性的一项必要背景，不是单独足以产生种子的性状。

## 化石记录与器官演化 {#fossils-and-evolution}

早期维管植物化石帮助解释根、叶和孢子囊如何组合，但化石年代不能直接转写成现生类群的等级。早泥盆世莱尼蕨（*Rhynia*）具有分枝轴和顶生孢子囊，是理解早期多孢子囊植物的重要材料；它既不是已知最早的陆生植物，也不是现生松叶蕨。更早的孢子化石和其他轴状植物记录表明，陆地植物史在莱尼蕨之前已经展开。

石松叶与真叶植物的叶分别建立在两条深分化谱系中。经典顶枝学说用“超越、扁化、蹼化”描述分枝轴如何形成扁平叶片，为阅读化石提供了有影响力的形态模型；现代证据则显示，蕨类叶与种子植物叶本身也可能包含多次、不同发育机制的起源，不能把所有真叶压缩成一次线性事件。类似地，古生代木本石松、楔叶类和种子蕨留下的性状组合远比“苔藓→石松→蕨→裸子植物”阶梯复杂。

异孢性在石松类、若干已灭绝维管植物和水生蕨中分别出现。只有当大孢子数目减少、功能大孢子保留在大孢子囊内、雌配子体内生发育，继而出现珠被与传粉机制时，才形成胚珠和种子。晚古生代前裸子植物与种子植物茎干关系密切，现生石松、木贼或薄囊蕨则各自拥有漫长而独立的演化史。比较它们的价值，在于辨认可重复出现的发育解法，而不是寻找一串仍然存活的祖先。
