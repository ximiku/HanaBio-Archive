# 分类、命名与系统发育

面对一份植物标本，研究者至少在处理四个层次的问题：这份材料属于哪个类群，那个类群的边界怎样划定，它与其他类群有何演化关系，以及在既定分类处理下应使用哪个名称。鉴定、分类、系统发育和命名由此彼此衔接，却不能相互替代。形态和分子证据可以改变类群的范围与位置，命名法规负责在这种变化中保持名称可追溯；数据库给出的接受名则是某一套分类观点在特定更新时间的结果。

## 类群、分类与系统学 { #taxa-classification-systematics }

类群（taxon）是分类工作所承认的一组生物，可以处于种、属、科或其他等级。分类学研究材料、描述性状、划分类群、进行鉴定并安排等级；系统学的范围更广，还重建谱系关系，解释性状、地理分布和多样化的历史。分类系统把这些研究结果压缩成可交流的嵌套结构，但等级本身不表示起源年代、物种数或“进化程度”。两个科处于同一等级，也不意味着它们具有相等的年龄或形态差异。

传统植物学常按易见性状建立“种子植物—孢子植物”“维管植物—无维管植物”“显花植物—隐花植物”或“高等植物—低等植物”等分组。其中种子植物和维管植物对应可由共同祖先及其后代界定的谱系，另一些名称只是便利的形态级别。例如所谓“孢子植物”把生活史和亲缘关系不同的苔藓、石松、蕨类、藻类甚至真菌并在一起；“低等”与“高等”又把现生类群排成了进步阶梯。它们可以作为分类史术语或检索线索出现，不宜充当现代系统分类的主干。

现代系统分类优先识别单系群，即共同祖先及其全部后代。单个形态性状可能因共同祖先而共享，也可能由趋同、逆转或杂交产生；分子序列同样会受到基因树与物种树不一致、取样不足和分析模型的影响。因此，系统树是证据支持下的关系假说，分类则是在单系性、可诊断性、稳定性和实用性之间作出的表达。新证据可以改变树的拓扑，也可以在拓扑不变时改变科或属的划分方式。

## APG 系统与被子植物高阶分类 { #apg-classification }

被子植物系统发育组（Angiosperm Phylogeny Group, APG）把多项系统发育研究综合为目、科层级的协作分类。APG IV 于 2016 年正式发表，长期成为植物志、标本馆和教学中广泛采用的基线；截至本页写作时，APG V 已于 2026 年 6 月由 *Journal of Systematics and Evolution* 接收并在线列为最新录用论文。APG V 综合数百个核基因与质体基因的系统基因组研究，在明确杂交和祖先多态会造成基因树冲突的同时，仍支持 APG IV 的大部分结构，仅对少数类群作调整。[^apg-framework]

APG 处理的是被子植物的高阶分类，不是一套覆盖所有“植物”的界门纲目表，也不直接裁定每个属和种的接受范围。实际写作中可以用 APG V 跟踪最新的目、科框架，用专题系统学论文处理属种边界，再用植物名数据库核对名称、异名和发表信息。核基因与质体基因给出冲突信号时，应呈现证据范围和未决节点，而非把其中一个基因组自动视为真实物种树。

这一框架也改变了对旧分类系统的使用方式。林奈按花部数目建立的性系统本来就是便于鉴定的人工系统；恩格勒系统曾把无花被、单性花和柔荑花序置于较“原始”的位置，哈钦松、塔赫他间和克朗奎斯特等系统则以不同方式强调木本、离生花部及所谓真花演化路线。这些系统保存了重要的比较形态经验，却把若干性状预先排成了单向的原始—进化序列。现代分析把每个性状放到系统树上重建，祖先花、被子植物起源化石及幼态成熟等演化假说将在[被子植物的系统与多样性](angiosperms.md)中结合化石和发育证据讨论。

## 类群概念与名称状态 { #taxon-concepts-and-names }

名称依附于命名类型，类群则由分类学家给出范围、位置和等级。若两个研究者对一个属的范围持不同意见，同一个名称可以对应不同的类群范围；若研究者认为两个分别命名的种实际属于同一物种，两个名称又会进入异名关系。名称变化因此可能来自新的类群划分，也可能只是旧名称不符合命名规则，阅读数据库或论文时必须查看其采用的分类处理和日期。

几个常见状态需要分开。名称经过有效发表（valid publication）才在《国际藻类、真菌和植物命名法规》下成立；有效发表的名称仍可能因同名、发表时多余等原因成为不合法名称（illegitimate name）。在某一类群范围、位置和等级下，法规从可用名称中确定正确名称（correct name）；分类数据库所列的接受名（accepted name）则进一步包含编辑者对类群边界和异名关系的判断。名称进入 IPNI 说明其命名与书目信息已有记录，并不等于该名称是当前接受名。[^name-status]

同模异名共享同一个命名类型，常由属的转移或等级改变产生；异模异名具有不同类型，只有在分类研究认为这些类型属于同一类群时才成为异名。后者可以随物种概念和新证据而改变。中文名、地方名、药材名和商品名不受 ICN 约束，同一种可能有多个俗名，同一个俗名也可能指向多个物种；权威植物志可规范特定出版物中的中文名，却不会把俗名变成国际命名类型。

## Madrid Code 的命名框架 { #madrid-code }

现行 ICN 是 2025 年出版的第 18 版 Madrid Code，取代 2018 年的 Shenzhen Code。它适用于被作为藻类、真菌或植物处理的类群名称，并与动物和原核生物的命名法规相互独立。法规的核心原则包括类型法、发表优先权，以及在给定类群范围、位置和等级下通常只有一个正确名称；这里的“一个”带有明确的分类前提和法规例外，并不表示全世界对物种边界只有一种意见。[^madrid-code]

### 有效发表与合法性 { #valid-publication }

新名称要在法规下成立，首先必须有效发表。电子或纸质材料须达到有效出版要求，名称须具有符合等级的形式，并按相应条款提供描述或鉴别特征、等级和类型等信息。自 2012 年 1 月 1 日起，新类群的描述或鉴别可以使用拉丁文或英文，也可以引用先前有效出版的拉丁文或英文描述；“新植物必须用拉丁文描述”已不是现行通则。自同一日期起，在具有 ISSN 或 ISBN 的出版物中在线发布符合条件的 PDF，也可构成有效出版。[^valid-publication]

有效发表只说明名称在命名学上成立，不保证名称合法，更不证明所描述的类群独立存在。分类研究仍需比较模式、其他标本、形态变异、分布和分子数据。裸名（*nomen nudum*, `nom. nud.`）通常指缺少法规所要求的描述、鉴别或相应引用而未有效发表的称呼；未刊名（`ined.`）则提示名称尚未正式发表。两者都不应像接受名一样直接用于正式物种记录。

### 命名类型 { #nomenclatural-types }

命名类型固定名称的应用，不负责概括类群的全部特征。一个物种可以性别二型、季节变异或分布广泛，模式标本也可能只保存其中一个状态；分类描述来自对大量材料的综合，名称却通过一个确定的类型保持可追踪。种及种下名称的类型通常是永久保存在标本馆或其他公共收藏中的一个标本，特定情形可为图像；活体植物本身不能充当这类永久类型。[^typification]

正模（holotype）是在原始发表材料中指定或按法规确定的一个标本或图像；等模（isotype）是正模的复份，必须来自同一采集事件。没有正模时，原始发表中引用的标本可构成合模（syntype）。后选模式（lectotype）是在没有正模、正模遗失毁坏或类型混杂等情形下，按规定从原始材料中选出的名称承载者；只有原始材料不存在或缺失时，才可另选新模式（neotype）。若现有正模、后选模式或新模式不足以精确解释名称，可指定辅助解释的附加模式（epitype），但原类型并未因此被替换。

副模（paratype）是原始发表引用而不属于正模、等模或特定合模范围的其他标本，可帮助理解变异，却不承担名称的最终固定作用。“模式产地标本”或 topotype 只说明材料后来采自模式产地，并不是 ICN 中自动具有替代权的模式类别；它若要成为新模式，仍须满足没有原始材料等条件并被正式指定。属名通常由一个种名的类型固定，科名则由一个属名的类型固定，类型关系由此沿等级向上连接。

### 优先权、保留名与拒绝名 { #priority-conservation }

在相同类群范围、位置和等级下，正确名称通常追溯到最早的合法名称或可用的最早合法种加词。种子植物和蕨类植物在属及以下等级的主要命名起点是林奈 *Species plantarum* 第一版被视为出版的 1753 年 5 月 1 日；更早的多词描述名称并不自动取得现代优先权。优先权解决同一分类处理下名称竞争的次序，不判断哪一种物种概念更符合生物学证据。

绝对追随最早名称可能破坏长期稳定使用，ICN 因而允许经规定程序保留名称（`nom. cons.`）、拒绝名称（`nom. rej.`）或压制著作。保留不是由单个数据库编辑者临时决定，而要经过提案、专业委员会与法规治理程序。命名数据库还可能标注不合法名（`nom. illeg.`）、无效发表名（`nom. inval.`）或拼写变体；这些缩写描述的是不同问题，不能统一翻译成“旧异名”。

## 学名的构成与作者引证 { #scientific-name-form }

种名采用二名组合，由属名和种加词构成，例如 *Arabidopsis thaliana*。属名首字母大写，种加词小写，二者作为学名整体使用斜体；种加词可以源自形容词、名词、地名或人名，不一定直接描述最醒目的性状。首次写出全名后，在不引起混淆时可把属名缩写为首字母。`sp.` 表示属内一个未确定或未指明的种，`spp.` 表示多个种，二者是说明性缩写，不属于斜体学名本身。

学名也可纪念人物。忍冬科北极花属 *Linnaea* 即以 Linnaeus 命名；这样的献名说明名称的历史来源，不意味着类群由受纪念者发现，也不承担形态描述功能。

种下名称在种名之后加入等级标志和种下加词，例如亚种 `subsp.`、变种 `var.` 和变型 `f.`。这些都是 ICN 可处理的种下等级，亚种并非唯一被承认的种内分类单位。法规列出的主要等级由低到高为种、属、科、目、纲、门和界；族位于科与属之间，组和系位于属与种之间，各等级还可加 `sub-` 等前缀形成次级等级。植物科名通常以 `-aceae` 结尾，目名通常以 `-ales` 结尾，亚科和族常分别使用 `-oideae` 与 `-eae`。这些词尾帮助识别等级，却不能据此推断类群是否单系。

作者引证放在学名之后，不使用斜体，也不是名称本身的一部分。作者缩写应按 IPNI 的标准形式核对，而不是任意截短；`L.` 是 Linnaeus 的标准缩写。物种转入另一属或改变等级时，原名称作者通常置于括号内，新组合作者列在括号后，括号因而记录名称的命名历史，不代表作者对该物种的发现顺序。`A ex B` 表示 A 曾提出名称而由 B 完成有效发表；`A in B` 中的 `in B` 通常是发表载体的书目信息，不属于名称作者本身。[^author-citation]

## 栽培植物名称 { #cultivated-plant-names }

野生或自然类群的植物名称主要受 ICN 管理，栽培品种、栽培群和兰科杂交群等栽培植物类别另由《国际栽培植物命名法规》（ICNCP）规范。当前可用的正式版本为 2016 年第 9 版。栽培品种（cultivar）是因栽培选择而具有可识别性状、并能通过适当繁殖保持这些性状的植物集合；它不是 ICN 中 `var.` 所表示的植物学变种。[^cultivated-code]

现代栽培品种加词使用现代语言，首字母大写，以单引号括起而不使用斜体，例如 *Rosa* 'Peace'。加词前可接属名、种名或适当的杂交名称，取决于其分类背景。国际栽培品种登录机构（ICRA）为特定植物类群维护名称和亲本等记录，登录有助于避免重名并形成可检索依据；并非所有栽培品种名称都以完成 ICRA 登录作为成立的统一前提，仍须核对 ICNCP 对发表日期、可接受加词和建立方式的要求。

## 检索表与鉴定证据 { #identification-keys }

检索表把可观察性状组织成连续选择，用来从给定候选集合中鉴定材料。最常见的二歧检索表把每一组互斥选项称为一个 couplet：等距式检索表逐级缩进，直接显示选择路径的层次；平行式或括号式检索表把同一 couplet 的两个选项相邻排列，并用编号引向下一步。两种版式可以编码同一判断过程，差别主要在阅读和排版方式。

可靠选项应在检索范围内尽量互斥，采用同一器官和发育阶段可比较的性状，并说明测量位置、性别、季节或是否需要解剖。花果缺失、幼体性状未成熟、标本受损或物种超出检索表的地理范围，都可能让材料在某一步无从选择。得到一个名称后还应对照描述、分布、图像和必要的模式资料复核；检索表给出的是鉴定假说，不是系统树，也不会自动证明两个相邻选项互为最近亲缘类群。

## 名称数据库的分工 { #name-databases }

IPNI 收录维管植物名称的拼写、作者、首次发表地点与日期以及部分类型信息，适合回答“这个名称是否发表过、怎样引证”。Kew 的 World Checklist of Vascular Plants（WCVP）以 IPNI 的命名数据为基础，经过编辑和专家评议，在 Plants of the World Online（POWO）中给出接受名、异名、分类参考和分布，适合回答“当前这套数据库接受哪一种分类处理”。WCVP 持续更新，最新发表名称进入 IPNI 后也可能需要编辑审核时间才出现在 POWO。[^plant-name-databases]

实际鉴定可先保存标本号、地点、日期、照片和关键性状，用区域植物志或检索表获得候选名称，再到 IPNI 核对作者与原始发表，到 POWO/WCVP 查看接受状态、异名和所依据的分类文献。若数据库与最新专著意见不同，应同时记录所采用的分类来源和访问日期。高阶被子植物位置再与 APG V 对照，便能把个体鉴定、名称历史、当前分类观点和系统发育框架保持在各自正确的层次。
