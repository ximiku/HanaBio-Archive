# 单子叶植物

单子叶植物是被子植物中稳定的单系大支。胚通常只有一枚子叶，叶脉常平行，初生茎维管束常散生，根系常由不定根组成，花部常为三数；这些都是频率很高的组合而不是没有例外的定义。单子叶植物内部从最早分出的菖蒲目，到水生泽泻目，再到棕榈类、鸭跖草类、百合类和兰科，已经产生木本、藤本、水生、附生和菌异养等多种生活型。[^monocot-framework]

## 菖蒲目与泽泻目 { #acorales-alismatales }

石菖蒲所在的菖蒲科构成菖蒲目，是其余现生单子叶植物的姐妹支。植株具芳香根状茎和剑形叶，细小花密集成肉穗花序，但没有天南星科典型的佛焰苞。旧材料把石菖蒲列入天南星科，现代系统必须单列；“肉穗花序”是趋同或较广分布的花序结构，不能独自界定亲缘。

泽泻目包含许多水生或湿生植物。泽泻科多有根状茎、基生叶和具鞘叶柄，花排列成总状或圆锥状花序；萼片与花瓣通常各三枚，雄蕊和离生心皮可为六枚至多数，果实常为聚合瘦果且种子胚乳很少。慈姑属常有箭形挺水叶和单性花，泽泻属常有卵形至箭形叶和两性花，叶形还会随沉水、浮水或挺水状态变化。

天南星科多为具根状茎、块茎或攀援茎的草本和藤本，叶基部有鞘，微小花密集在肉穗花序上，外有佛焰苞；果实多为浆果。半夏、芋、魔芋、天南星和灯台莲主要以地下器官越冬，龟背竹为攀援植物，马蹄莲的白色显著部分是佛焰苞而非单朵花的花瓣。科内花可两性，也可在花序上分成雌花区、雄花区与不育区，花被可存在或完全缺失，固定的“雄花六雄蕊、雌花十五心皮”不能覆盖全科。

## 棕榈目 { #arecales }

棕榈科多为乔木或灌木，也有省藤等攀援植物。茎通常不依靠普通维管形成层进行连续次生增粗，巨大羽状或掌状叶集中于茎顶，叶柄基部形成包茎叶鞘并可残留纤维。花小，多为三数，可两性或单性，常密集成大型分枝肉穗花序，花序幼时由大型佛焰苞包围；果实为核果或浆果状果。

棕榈、蒲葵和王棕展示掌状或羽状冠叶，椰子和油棕的果实富含油脂，槟榔和假槟榔的名称相近却分属不同属，省藤以具刺叶鞘和延长攀援器官进入林冠。单干、顶生叶冠和大型花序是常见组合，但棕榈科并非全为不分枝的直立乔木。

## 禾本目：莎草科与禾本科 { #poales }

莎草科与禾本科都把小花组织成小穗，风媒花常花被退化，却可由秆、叶鞘和小穗结构区分。莎草科秆常实心而呈三棱形，叶常三列，叶鞘通常闭合；禾本科秆常节间中空、圆柱形，叶二列，叶鞘通常开口并在叶片交界处具有叶舌。两科均有大量例外，例如荸荠具有圆柱形秆，一些禾草秆实心，所以“莎草有棱、禾草中空”只适合作为起始线索。

### 莎草科 { #cyperaceae }

莎草科花被常缺失，或退化为刚毛、鳞片；雄蕊一至三枚，子房上位、单室而具一枚基生胚珠，果实为三棱或双凸的小坚果。苔草属的雌花及果实被特化先出叶包成囊状果囊，是重要属级特征。莎草与香附子、咸水草、苔草、乌拉草、藨草和荸荠分别代表根状茎杂草、湿地与草甸成员及具可食球茎的水生作物。鳞片在小穗上的螺旋或二列排列、花柱分枝数和果实横切面可进一步区分属种。

### 禾本科 { #poaceae }

禾本科小穗通常由一对颖片及一至多朵小花组成；每朵小花外有外稃、内稃，花被缩减为浆片，雄蕊常三枚，稻属通常六枚，子房一室而有一枚胚珠，柱头多羽毛状。成熟果实多为果皮与种皮紧密贴合的颖果。外稃、内稃和颖片是花序苞片系统的一部分，不能统称为萼片；小麦“三雄蕊”和水稻“六雄蕊”是不同支系的常见式，并非同一花的变动范围。

针茅、燕麦、高粱、玉米、粟（小米）、黍、甘蔗、薏苡、芦苇、稻、小麦和大麦覆盖旱生草原、湿地与主要作物。小麦小穗在穗轴每节一个，大麦每节有三枚小穗，六棱与二棱类型取决于侧生小穗结实；青稞是颖果与稃片易分离的裸粒大麦。稻的圆锥花序常下垂，稃片是否具芒依品种而异。玉米雄穗顶生、雌穗腋生，果穗的“须”是伸长的花柱—柱头。鼠尾粟、穇等少数禾草的果皮与种皮结合方式不同于典型颖果，果实术语需按具体属核对。菰茎被菰黑粉菌侵染后膨大形成茭白，这一食用器官是宿主茎与真菌互作的产物。

竹类属于禾本科竹亚科。竹秆木质化而节间常中空，秆箨由箨鞘、箨耳和箨叶等组成，形态与普通营养叶不同；普通叶常有明显叶柄样结构并在叶鞘连接处形成关节，容易脱落。竹、凤尾竹等通过地下根状茎形成克隆，开花周期、同步程度和开花后是否死亡在物种间差异很大。

## 姜目与姜科 { #zingiberales }

姜目植物常有大型叶、封闭叶鞘和由叶鞘重叠形成的假茎，花多为下位子房并具有两侧对称性。姜科多为芳香的多年生根茎草本，叶二列，叶鞘顶端常有叶舌。六枚祖先雄蕊中通常只有内轮一枚保持能育，花柱从其花药两室之间的槽穿出；其余雄蕊消失或瓣化，内轮两枚退化雄蕊合成显著唇瓣。蒴果或浆果状果常有带假种皮的种子。

姜、蘘荷、姜黄、益智、砂仁、郁金、海南三七和草豆蔻分别以根茎、嫩花序、果实或种子等不同器官被利用。“花冠三裂、唇瓣一枚”只描述外观，真正用于理解姜科花的是三数花被与五枚退化雄蕊围绕一枚能育雄蕊的发育关系。

## 百合目与天门冬目 { #liliales-asparagales }

传统广义百合科把许多具有六枚花被片、六枚雄蕊和三心皮的草本放在一起。分子系统学表明这套“三数花”在单子叶植物中分布很广，旧百合科成员现分散到百合科、天门冬科、石蒜科、菝葜科、阿福花科等多个科。科界改变不抹去共同的识别经验，而是要求加入子房位置、花序苞片、地下器官、叶和化学性状。

### 百合科及拆出的近缘科 { #liliaceae-allies }

狭义百合科多为具鳞茎或根状茎的多年生草本，叶基生或茎生，花被片六枚、常离生而显著，雄蕊六枚，子房通常上位、三室而中轴胎座，果实多为蒴果或浆果。百合、卷丹、贝母和郁金香仍属百合科。菝葜因木质或草质攀援茎、叶柄卷须和单性花归入菝葜科；这类性状比“六被片”更能说明其独立支系。

黄精、玉竹、天门冬、文竹、石刁柏（芦笋）、麦冬和知母现属于广义天门冬科的不同亚科。黄精与玉竹具根状茎和腋生下垂花，天门冬属常以叶状枝代替真正叶片，麦冬具块根和穗状总状花序。葱、洋葱、蒜和韭属于石蒜科葱亚科，常有含硫气味、鳞茎或根状茎和伞形花序。阿福花属归阿福花科。旧材料中的茯苓不是植物，而是多孔菌类真菌的菌核，其结构应在真菌页面理解，不能保留为百合科代表。[^lily-circumscription]

### 石蒜科与鸢尾科 { #amaryllidaceae-iridaceae }

石蒜科石蒜亚科多为鳞茎草本，叶基生，花序由无叶花葶承载，数朵花组成有膜质总苞片包围的伞形花序；花被片六枚，雄蕊六枚，子房通常下位，果实为蒴果或浆果状。石蒜、忽地笑、水仙、君子兰、朱顶红、水鬼蕉和文殊兰展示单花葶、伞形花序、副花冠及不同鳞茎类型。葱亚科的子房常上位，提醒广义石蒜科内部不能只靠子房位置识别。

鸢尾科多具根状茎、球茎或鳞茎，叶剑形、二列并常为等面叶；花被片六枚，只有三枚雄蕊，子房通常下位、三室，中轴胎座，果实为室背开裂蒴果。鸢尾属的花柱分枝可呈花瓣状覆盖雄蕊，香雪兰、唐菖蒲、射干、番红花和虎皮花展现不同对称性和花序。三雄蕊、下位子房及剑形叶的组合有助于将鸢尾科与六雄蕊的百合科、石蒜科区分。

### 兰科 { #orchidaceae }

兰科为陆生、附生或菌异养草本。附生种的气生根常有多层死细胞构成的根被，许多种具贮水的假鳞茎；叶通常互生并有鞘。花两侧对称，内轮一枚花瓣特化为唇瓣，雄蕊与花柱、柱头合成合蕊柱；花粉可形成花粉块，并由蕊喙、黏盘和花粉块柄组成适应特定传粉者的携粉结构。子房下位、常一室而具侧膜胎座，胚珠可在传粉后继续大量发育。

许多兰花在花梗或子房发育时发生约 180° 扭转，使唇瓣转到下方，但不扭转或二次扭转也存在，因而“兰花必倒置”不是定义。蒴果产生数量巨大的微小种子，种子通常缺乏胚乳，胚在自然萌发时需要菌根真菌提供碳和矿质。兰属、白及、石斛、绶草、香荚兰、天麻分别包括地生、附生、药用、香料和全菌异养类型。天麻没有普通绿色叶，仍由花、种子和分子性状确认其兰科身份。

麦冬属于天门冬科并常有块根，兰草若指兰科植物则可有根状茎或假鳞茎；中文俗名“兰草”还可指菊科佩兰等其他植物，不能用名称直接判科。香荚兰的香料来自发酵果实，兰科果实在植物学上是蒴果而非“豆荚”。兰科与菊科物种数都极多，二者排名随接受种和科界更新而变化，不宜固定称某科为第一或第二大科。[^orchid-biology]
