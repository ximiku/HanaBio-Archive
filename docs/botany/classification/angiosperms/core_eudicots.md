# 核心真双子叶植物及其早期分支

真正双子叶植物以三沟型花粉为重要共同衍征，包含毛茛目、山龙眼目等较早分支和核心真正双子叶植物。传统“木兰亚纲”中的毛茛科、罂粟科和莲科，传统“石竹亚纲”中的石竹科、藜科和蓼科，在这里才找到各自的现代系统位置。两枚子叶、网状脉或维管束环列在许多成员中常见，却都有例外，鉴定仍需把花粉、花与果实结构结合起来。[^eudicot-framework]

## 毛茛目 { #ranunculales }

### 毛茛科与旧置芍药属 { #ranunculaceae-paeoniaceae }

毛茛科以草本为主，也有铁线莲等藤本；叶常基生或互生，掌状分裂、羽状分裂或复叶，无托叶者居多。花多为两性和辐射对称，也可如乌头、翠雀和飞燕草那样形成两侧对称的盔状或距状花。萼片与花瓣的形态和数目变化很大，雄蕊通常多数，心皮多离生；毛茛、白头翁、铁线莲常形成聚合瘦果，乌头、黄连、翠雀和耧斗菜常形成聚合蓇葖果。花瓣状萼、蜜叶和花瓣之间存在多种同源变化，不能用固定的“萼五瓣五”概括全科。

牡丹属现归芍药科，而非毛茛科；芍药科位于虎耳草目，在系统上应转入[超蔷薇类](superrosids.md#paeoniaceae)理解。牡丹为木本或基部木质化，芍药为宿根草本；二者都具有大型花、许多雄蕊和由肉质花盘包围的数枚蓇葖。园艺品种的花瓣数、叶色和花期受遗传背景与栽培环境影响，“牡丹花必单生而大、芍药花必簇生而小”不是稳定科属鉴别。木质茎是否越冬是区分常见牡丹与芍药更可靠的整株特征。

### 罂粟科 { #papaveraceae }

罂粟科多为草本，叶互生或基生，常有乳汁或有色汁液。罂粟、虞美人和绿绒蒿的花通常有两枚早落萼片、四枚或更多花瓣及多数雄蕊；合生心皮形成单室子房，胚珠着生于侧膜胎座，果实多为蒴果。罂粟属蒴果可由柱头盘下的孔散种，虞美人、绿绒蒿则展示不同开裂方式。延胡索属位于荷包牡丹亚科，花两侧对称并常具距，雄蕊组合也明显特化；这并不影响其乳汁系统、花部发育和分子证据所支持的罂粟科归属。

## 山龙眼目中的莲科 { #nelumbonaceae }

莲科是山龙眼目的一支，仅含莲属。植株以地下根状茎扩展，叶盾状，乳汁道发达；大型花具许多花被片和雄蕊，离生心皮嵌入膨大的海绵质花托，每个成熟为一枚坚果状小果。莲与睡莲的水生生活型相似，却分属真正双子叶植物和被子植物早期分支。莲藕是根状茎，莲子是果实内的种子，莲蓬则主要由膨大花托及嵌入其中的小果组成。黄花莲等名称需落实到具体接受种，不能只凭花色另立科属关系。

## 石竹目 { #caryophyllales }

石竹目包含形态与生态差异极大的支系。甜菜色素存在于石竹目核心支的许多科，却在石竹科和部分近缘科中由花青素取代；弯曲胚、外胚乳、特立中央胎座和耐盐性也分别只覆盖其中部分成员。旧“石竹亚纲”的性状组合因而适合做识别线索，不是目内每一科共有的定义。

### 石竹科 { #caryophyllaceae }

石竹科多为草本，茎节常膨大，单叶对生而全缘。花常单生或组成二歧聚伞花序，多为四数或五数；萼片离生或合生，花瓣常分成狭窄的爪和展开的瓣片，雄蕊通常与花瓣同数或为其两倍。子房由二至五心皮合成而常为单室，胚珠着生于特立中央或基生胎座，果实多为齿裂或瓣裂蒴果；弯曲胚环绕富含淀粉的外胚乳。石竹、康乃馨、瞿麦、王不留行、繁缕和孩儿参分别展示合萼与离萼、显著花瓣与小花等科内变异。

### 苋科与旧藜科 { #amaranthaceae }

APG 框架把传统藜科并入广义苋科。许多旧藜科成员是盐生、旱生草本或灌木，叶表可有储盐或储水的泡状毛，花小而单被，雄蕊常与花被片对生；果实常为胞果，种子具有环形或马蹄形弯曲胚和外胚乳。藜、菠菜、甜菜、地肤（旧称扫帚菜）、碱蓬和梭梭保留了这套生态—形态组合。甜菜色素可呈红、紫或黄色，但“有甜菜色素”既不能覆盖全科，也不能与耐盐性画等号。[^family-circumscriptions]

### 蓼科 { #polygonaceae }

蓼科多为草本或藤本，茎节常膨大，互生叶的托叶合成包茎托叶鞘，是重要营养器官特征。花小，花被片通常三至六枚，子房一室而有一枚直生胚珠，果实为三棱或双凸的瘦果状坚果，宿存花被常参与传播。蓼属、大黄属、荞麦属、酸模属以及何首乌所在的何首乌属或虎杖所在的虎杖属，体现直立草本、藤本和大型根茎草本等生活型。大黄食用或药用部位、荞麦颖果和何首乌块根属于不同器官，不能用“蓼科根药”统一概括。

## 常见混淆与器官比较 { #common-confusions }

玫瑰与月季同属蔷薇科蔷薇属，叶面光泽、刺的密度和一年开花次数在野生种与园艺杂交品种间连续变化，不宜用一组绝对二分特征鉴定。梨和苹果都形成梨果，食用主体包括花托与子房组织；梨果肉中常有成群石细胞，苹果花柱基部合生程度和果顶凹陷常见，但仍应结合花、萼宿存和栽培品种核对。萝卜、玛咖和胡萝卜的俗名相近，却分别属于十字花科萝卜属、十字花科独行菜属和伞形科胡萝卜属；“玄参（水萝卜）”是把商品俗名误作科属证据的旧记录。
