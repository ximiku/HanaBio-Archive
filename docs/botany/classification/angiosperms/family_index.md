# 被子植物科级特征索引

被子植物的科级鉴定很少依靠一个孤立性状。叶序、托叶、乳汁或芳香气味先限定候选范围，花序和花部结构进一步缩小范围，子房位置、胎座与果实类型通常才给出更稳定的判断。本页把本地分类学素材出现的全部被子植物科，以及因现代系统修订而必须区分的科，按系统位置列成索引。每一行只承担快速定位，科内变异、例外、代表属和旧分类纠正仍在链接的详细页面中展开，不能用表中几个高频性状替代完整检索。[^family-index-scope]

## 旧名称与现行科界 { #historical-circumscriptions }

旧分类中的“木兰亚纲、金缕梅亚纲、石竹亚纲、蔷薇亚纲、五桠果亚纲、菊亚纲”保留为分类史线索，不作为现代自然类群。旧藜科并入广义苋科，萝藦科成为夹竹桃科萝藦亚科；旧广义百合科、玄参科、忍冬科、大戟科和虎耳草科都发生了显著拆分。绣线菊亚科和苹果亚科在现代蔷薇科内也不再作为与蔷薇亚科、李亚科（旧资料亦称梅亚科）完全对应的四个自然亚科；豆科则采用六个单系亚科框架。旧资料的“白花菜科（五桠果科）”括注并非现代异名关系：白花菜科属于十字花目，五桠果科属于五桠果目，原条目所举山柑又属于独立的山柑科。页面组在保留原素材全部代表植物的同时，把牡丹、青檀、骆驼蓬、柿、石菖蒲、葱蒜、麦冬、知母、泡桐、地黄、婆婆纳、荚蒾和接骨木等放回现行接受科。[^apg-family-framework]
