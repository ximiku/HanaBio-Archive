# 植物体的结构与发育

植物的身体是在原位生长出来的。多数细胞被细胞壁固定在邻接关系中，形态建成主要依靠细胞分裂方向、局部扩张、分化和受控死亡来改变组织；根端、茎端与侧生分生组织又在个体生活史中持续产生新细胞和新器官。因而，植物形态不能只看成熟切片中的结构名称，还要追踪一个结构从何处发生、怎样与其他组织连通，以及它在发育到哪个阶段时承担何种功能。[^plant-body-framework]

本页面组以种子植物，尤其是被子植物为主要参照，从细胞与组织逐步进入根、茎、叶和花，再沿孢子发生、配子体形成、受精、胚与果实发育走向下一代。不同植物谱系对这些基本过程有大量变体；相关结构只有放回生活史和系统发育背景中，才能判断哪些是同源关系，哪些只是相似功能形成的趋同结果。

## 结构层级与持续发育 { #structural-levels }

[植物细胞与组织](plant_cells_tissues.md)是本组的尺度起点。细胞壁的材料与取向限定膨压驱动的扩张，细胞板建立新的邻接边界，胞间连丝和维管细胞则把局部组织接入跨细胞与长距离运输网络。表皮、基本组织和维管组织不是三个彼此分离的部件，而是在器官发生中共同分化、彼此衔接的组织系统。阅读后续页面时，可反复追问某种成熟细胞来自哪个分生组织区域、何时退出增殖，以及其壁、细胞器和邻接关系怎样随分化改变。

分生组织使植物在胚发生结束后仍保留开放式的器官发生。根端沿既有轴线向土壤推进，茎端在维持自身的同时从侧面产生叶和腋芽；花分生组织则转为有限生长，在形成一组生殖器官后终止。这些发育系统都涉及细胞身份、位置、信号和组织力学，但本组聚焦它们产生的植物结构。跨动物与植物的发育概念、谱系追踪和时空扰动证据见[发育生物学](../../development/index.md#time-space-scale)，植物激素与环境怎样改变生长速率和器官命运则留待本学科的调控页面组。

## 营养体的器官轴与输导连续性 { #vegetative-body }

[根的结构、发育与共生界面](roots.md)从根尖、径向组织和侧根发生进入地下器官，[茎、叶与营养器官](vegetative_organs.md)则从芽与枝条模块进入茎的初生结构、叶片发生和变态器官。两页应连在一起阅读：根与茎形成连续的轴向输导系统，叶脉又从茎的维管束分出；与此同时，根的内皮层、叶的表皮与气孔、各器官的机械组织分别重设物质交换和受力边界。器官名称由发生来源、位置和连接关系共同确定，块根、块茎、鳞茎等相似外形因此可能来自不同器官。

根和枝条的加长主要来自顶端附近产生的初生组织，许多木本植物还会建立侧生分生组织。[次生生长与维管形成层](secondary_growth.md)沿径向追踪形成层向内产生次生木质部、向外产生次生韧皮部，以及周皮怎样替代被增粗过程撑裂的表皮。这样形成的木材、树皮、射线和生长轮不是成熟茎上额外添加的静态层次，而是多年持续分裂、分化、运输与季节响应留下的发育记录。[^vegetative-development]

形态结构为生理过程提供通道与界面，却不单独决定实际通量。根毛、凯氏带、导管、筛管、叶脉和气孔说明水、离子、同化物与气体可能经过何处；水势梯度、膜转运、源—库关系和环境调节决定这些通路当时如何运行。结构页先建立空间基础，植物的资源获取与物质代谢页面组再展开过程动力学。

## 生殖器官与世代转换 { #reproductive-cycle }

生殖部分首先区分孢子体器官和其中短暂存在的配子体。[花与生殖器官](reproductive_organs.md)说明花分生组织如何产生花被、雄蕊和心皮，以及花序怎样组织多朵花；[孢子、配子体与胚囊](gametophytes.md)随后进入花药与胚珠内部，追踪减数分裂形成小孢子和大孢子，再形成雄、雌配子体。这样安排可以避免把雄蕊等同于雄配子体，或把胚珠等同于雌配子。

[传粉、花粉萌发与受精](pollination_fertilization.md)把两个空间分离的发生路线重新连接起来。传粉把花粉送到柱头，花粉水合和花粉管顶端生长把不运动的精细胞带向胚囊，双受精分别建立胚与胚乳的起点。[种子、果实与无性繁殖](flowers_seeds_fruits.md)再追踪合子、胚乳、珠被和子房周围组织的不同命运，并把种子和果实视为保护、供养与传播新一代的复合结构。营养繁殖则利用既有器官或再生能力延续个体，不经过上述完整的配子体—受精路线。[^plant-reproduction-framework]

这四页可沿“花的空间结构—孢子与配子体发生—配子传递与融合—胚、种子和果实形成”顺序阅读。开花诱导、休眠与萌发、果实成熟和器官衰老虽然同样属于生活史转换，但其核心问题是信号、代谢和环境条件，分别在后续调控页面展开；这里保留转换发生时所依托的结构与组织来源。

## 形态证据的阅读尺度 { #morphological-evidence }

宏观观察适合描述器官位置、分枝方式、叶序、花序和果实类型，连续切片与透明化成像可重建组织连接，活体成像、细胞谱系和分子标记则用来判断结构从何处发生。成熟形态相同不保证发生过程相同，单个发育切面也不能代表完整的时间序列。比较不同物种时，还要把观察阶段、器官位置和系统发育关系同时记录，才能区分发育阶段差异、环境可塑性和稳定的类群性状。

初次阅读可先完成细胞组织、根与茎叶三页，建立从细胞到营养体的空间框架，再进入次生生长；随后依次阅读花、配子体、传粉受精和种子果实，恢复完整的世代转换。若从具体材料出发，也可按结构反向追踪：从木材回到形成层，从叶脉回到茎尖器官发生，从种皮、胚乳和胚回到受精前的珠被、中央细胞与卵细胞。这样的追踪比背诵孤立术语更能说明植物体为何具有当前结构。
