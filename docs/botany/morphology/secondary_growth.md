# 次生生长与维管形成层

初生生长把根和枝条向前延伸，次生生长则在已经建立的轴上增加新的径向组织。它持续扩充输水通道、同化物运输能力和机械骨架，同时用周皮替代无法随周长无限扩展的表皮。树干横切面上由内向外可见的木材、形成层、内树皮和外树皮，因而不是几层静止的套筒，而是两个侧生分生组织长期活动、组织分化与外层脱落留下的时间记录。

## 次生生长从初生维管系统中建立 { #secondary-growth-origin }

裸子植物和许多真双子叶植物的茎在完成初生伸长后，维管束内残留的原形成层细胞恢复活跃，束间薄壁细胞也获得分生能力，二者逐渐连接成连续的维管形成层。这个环在建立初期常随维管束轮廓而起伏，随后因不同部位分裂速率调整而趋于圆整。形成层向轴心一侧产生次生木质部，向外产生次生韧皮部；前者通常积累得更多，成为茎径增加的主体。[^secondary-growth-overview]

根中的起点与茎不同。初生韧皮部内侧的原形成层残余和原生木质部极附近的中柱鞘后代共同建立形成层，最初呈波浪状，随后围成连续圆环。下胚轴又可同时保留根、茎两端的发生特征。形成层的细胞来源因此具有器官和物种差异，不能把“束中形成层加束间形成层”套用于所有轴。根的起始过程见[根的结构、发育与共生界面](roots.md#secondary-growth-storage-roots)，初生茎的维管束排列见[茎、叶与营养器官](vegetative_organs.md#primary-stem-anatomy)。[^cambium-organ-origins]

维管形成层一旦连成环，原有的初生木质部和髓仍留在内侧，初生韧皮部、皮层和表皮则被不断推向外方。轴的周长随之增加，外侧组织必须通过薄壁细胞扩张、射线区域的径向增生或新的周皮形成来适应；不能继续扩展的细胞层会被压缩、撕裂或脱落。所谓“次生结构”描述的是这一发育状态，不意味着初生组织立即全部消失。

## 维管形成层是双面的侧生分生组织 { #vascular-cambium }

形成层横切面上可见一段由扁平、薄壁细胞组成的形成层区。严格意义的形成层原始细胞只是其中能长期自我更新并持续贡献两侧组织的细胞；它们刚产生、尚未明显分化的木质部或韧皮部母细胞在普通切片中很难与原始细胞逐一分开。谱系追踪表明，一个径向细胞列可由具有双面产物的干细胞维持，但不同物种、器官、年龄和季节中的形成层区厚度并不相同。因此，“形成层理论上只有一层、切片中多层只是母细胞”的旧式表述过于僵硬，更合适的做法是区分功能上的原始细胞与形态上可观察的形成层区。[^cambium-stem-cells]

### 梭形原始细胞与射线原始细胞 { #cambial-initials }

梭形原始细胞沿茎轴伸长，其后代构成轴向系统，包括木质部的导管分子、管胞、纤维和轴向薄壁细胞，以及韧皮部的筛分子、伴胞或蛋白细胞、纤维和薄壁细胞。射线原始细胞较短，产生横贯木质部与韧皮部的径向细胞列。两类原始细胞不是完全封闭的谱系：形成层发育和树干增粗过程中可以发生转换，射线的高度、宽度和细胞组成也会随物种与年龄改变。成熟木本植物中射线原始细胞所占比例可相当可观，而幼小模式植物的形成层常主要表现为轴向细胞列，二者不宜用同一张简化图概括。[^ray-initials]

形成层原始细胞平周分裂时，新壁大致平行于器官表面，增加内外方向的衍生细胞；垂周分裂则增加形成层圆周上的细胞数，使形成层环能追上不断扩大的周长。梭形原始细胞还可通过斜向的假横分裂和顶端侵入生长调整长度与邻接关系。这些分裂与生长不是单纯的几何动作：周围组织的机械应力、激素、糖和水分状态都能改变形成层细胞周期及衍生细胞的命运。

### 信号维持增殖与径向身份 { #cambium-signaling }

形成层两侧既是产物，也是信号来源。韧皮部产生的 TDIF 肽可在形成层细胞表面的 PXY/TDR 受体被识别，促进 WOX4 等调控因子的活动，帮助维持增殖并协调木质部—形成层—韧皮部的径向模式。生长素在形成层及分化中的木质部附近形成分布梯度，细胞分裂素、赤霉素、乙烯和脱落酸则依器官与环境参与调节。EPFL–ERECTA 等肽—受体途径、糖信号和机械反馈共同作用，所以形成层活动不是由某一种“形成层激素”独立启动。[^cambium-signals]

温度、光周期、水分和碳供应会通过这些网络改变形成层何时恢复、活跃多久以及产生何种细胞。多年生温带树木可在休眠后重新启动形成层，热带或湿度季节性地区则可能由降水、叶物候或其他资源周期控制。环境留下的解剖信号还受树龄、冠层位置、竞争和遗传背景影响，不能把一圈木材的宽窄直接归因于单一气候变量。

## 次生木质部形成木材 { #secondary-xylem-wood }

形成层内侧的木质部母细胞先分裂和扩张，随后建立导管、管胞、纤维或薄壁细胞身份。输水细胞与许多纤维沉积富含纤维素、半纤维素和木质素的次生壁，形成纹孔或穿孔板，成熟时再经历程序性细胞死亡。轴向薄壁细胞和射线薄壁细胞仍可长期存活，参与淀粉、脂质和水的贮藏、伤口反应以及轴向—径向物质交换。木材是次生木质部的整体，不能等同于一团全部死亡的木质化细胞；细胞壁材料与纹孔结构见[植物细胞与组织](plant_cells_tissues.md#cell-wall-material-system)和[维管组织](plant_cells_tissues.md#vascular-tissues)。

被子植物木材通常把输水、支撑和贮藏分配给多类细胞：导管承担大部分轴向水流，纤维提高机械强度，管胞、轴向薄壁组织和射线的比例随谱系与生态策略变化。导管口径、密度、壁厚和纹孔结构共同决定水力效率与栓塞风险，不能只凭“木材坚硬”推断其输水能力。形成层还会在枝条倾斜、风载或重力作用下产生反应木；被子植物常在上侧形成富纤维素的应拉木，针叶树常在下侧形成木质素较多的应压木，这种不对称生长帮助轴恢复或维持姿态。

### 早材、晚材与生长轮 { #growth-rings }

当形成层活动和细胞分化在一个生长周期内系统改变，木材横切面会留下生长轮。典型温带针叶树的早材管胞腔大、壁相对薄，晚材管胞腔小、壁较厚；两者都主要是管胞，并非晚材才突然“增加管胞”。被子植物的变化更复杂：环孔材在生长季初形成一带大导管，散孔材的导管口径沿生长轮较均匀，另一些木材介于二者之间。轮界还可由纤维壁厚、轴向薄壁组织或导管排列变化标出。[^wood-anatomy]

在形成层活动每年停顿一次且轮界完整的树木中，一轮通常对应一年，可以用于测年和重建环境变化。干旱、霜冻、虫害或二次抽梢可能在一年内造成额外的密度界线，形成假轮；不利年份也可能形成局部缺轮。许多热带树木仍可因旱季、洪水或叶片更新形成周期性生长轮，但轮界可能不连续、呈楔形或难以辨认。研究者需要用已知年龄材料、形成层物候、交叉定年或同位素等证据确认周期，不能见到同心纹理便直接把圈数当树龄。[^growth-ring-concept]

### 边材、心材与导管封闭 { #sapwood-heartwood }

靠近形成层、仍参与输水且保留生活薄壁细胞的次生木质部称边材。较内侧的旧木质部逐渐退出输水，薄壁细胞耗尽或转运营养物质并死亡，常伴随酚类、萜类、色素等抽提物沉积，形成心材。心材通常颜色较深、含水率较低，并可能因抽提物而提高天然耐腐性，但颜色、气味、耐久性和心材出现年龄都有强烈的物种差异；有些树种的心材与边材肉眼并无清楚界线。[^heartwood-formation]

在许多被子植物中，导管旁生活薄壁细胞可通过纹孔对向导管腔膨出，形成气球状侵填体；胶质等物质也可沉积并封闭导管。这些过程减少旧木材中的水流，并可能限制病原扩展。侵填体来自薄壁细胞，而不是导管自身重新长出生活原生质；典型发生位置是导管腔，也不能泛化为所有管胞。边材宽度由树种、树龄、树冠需求和环境共同决定，不是每年固定把最内一圈边材转换为心材。

## 次生韧皮部维持源—库运输 { #secondary-phloem }

形成层向外产生次生韧皮部。被子植物中，轴向系统可包含筛管分子—伴胞复合体、韧皮薄壁细胞、纤维和石细胞；裸子植物则以筛胞和蛋白细胞等承担相应运输与代谢支持。刚形成、靠近形成层的传导韧皮部把糖、氨基酸、信号分子和其他溶质连接到生长点、根、果实及贮藏组织。不同细胞类型常沿径向重复出现，但周期和组合具有明显的物种特异性。[^secondary-phloem-pattern]

随着木质部不断把形成层推向外方，较老筛分子失去功能并被压缩，薄壁细胞、射线和纤维却可能继续存留。外侧韧皮部可通过射线薄壁细胞切向扩张和分裂形成扩张组织，以适应周长增加；继发的石细胞化、晶体和分泌结构又使成熟树皮呈现复杂层次。因此，横切面上次生韧皮部通常比多年积累的木材薄，不表示形成层从未产生大量韧皮部，而是反映传导寿命、压缩、扩张和外层脱落的共同结果。

## 射线连接轴向系统与径向运输 { #vascular-rays }

射线由径向排列的薄壁细胞构成，可从次生木质部跨过形成层延伸到次生韧皮部。它们在木材与韧皮部之间运输水、糖和矿质元素，贮藏碳氮资源，并在创伤后参与封闭与再生。木材弦切面显示射线的高度和宽度，径切面显示其沿半径延伸，横切面则呈从中心向外的带状结构；三种切面是理解木材三维结构的互补窗口。

初生器官中髓与皮层之间的薄壁区域常称髓射线，连续形成层建立后又产生新的次生射线。实际发育中，原有射线可延长、加宽、分裂或终止，新射线也可在形成层中建立；把“髓射线数目永远不变、维管射线只会增加”作为诊断规则，会忽略原始细胞转换和射线重组。射线的排列还打断轴向细胞连续性，使木材在径向、弦向和纵向具有不同的力学与裂解性质。

## 周皮与树皮重建外部边界 { #periderm-bark }

表皮通常不能无限适应轴的径向扩张。木栓形成层又称栓形成层或 phellogen，是较外侧建立的侧生分生组织；它向外产生木栓层，向内产生栓内层，三者合称周皮。木栓细胞成熟时通常死亡，细胞壁沉积木栓质和蜡，显著限制水分散失和许多溶质穿透；栓内层则多由生活薄壁细胞组成。周皮由此成为机械、化学和生物防御边界，而不只是树干表面的一层“硬壳”。[^periderm-development]

第一层木栓形成层可从茎的表皮下层、皮层、初生韧皮部或其他外层生活细胞发生；根中常由中柱鞘或其后代发生。木栓形成层活动一段时间后可能被更内侧新生的形成层替代。每一层周皮切断其外方组织与内部水分、矿质和同化物的联系，使这些组织死亡；多层周皮及夹在其间的死皮层、韧皮部和皮层共同构成落皮层。树皮在植物解剖学中指维管形成层以外的全部组织，包含生活的内树皮和多为死亡组织的外树皮；周皮只是其中的保护组织，落皮层也不等于全部树皮。[^bark-anatomy]

### 皮孔维持气体扩散 { #lenticels }

周皮的木栓质屏障限制气体扩散，皮孔则在局部形成胞间隙较多的填充组织，使内部生活细胞与外界交换氧和二氧化碳。许多茎的第一批皮孔位于原气孔附近，但皮孔的发生位置、形状和内部细胞排列随物种和器官而变，不能把“每个气孔都变成皮孔”当作普遍规律。部分植物在生长季末形成排列紧密、木栓化较强的关闭层，下一生长季再产生疏松组织；这种周期也并非所有皮孔共有。皮孔改善通气但同时削弱连续屏障，水分损失、病原进入和低氧耐受之间由组织结构共同权衡。[^bark-anatomy]

## 裸子植物木材采用另一组细胞配置 { #gymnosperm-wood }

多数针叶树的次生木质部主要由轴向管胞构成，同一种细胞同时承担输水和机械支撑；射线薄壁细胞以及少量轴向薄壁细胞负责贮藏和径向交换。早材与晚材主要表现为管胞腔径和壁厚的连续变化。与之相比，典型被子植物木材常以导管分子高效输水、纤维支撑并配置更丰富的轴向薄壁组织。无导管的典型针叶材与具有导管的典型阔叶材是有用对照，但买麻藤类裸子植物具有导管，被子植物木材内部也有大量例外，不能据单一细胞判断整个大类。[^wood-anatomy]

松科等类群可具有由分泌上皮包围的正常树脂道，创伤还可诱导新的树脂道；另一些裸子植物缺少这类管道。被子植物中同样存在树脂道、乳汁管或其他分泌结构。因此，树脂道适合用作特定谱系和物种的解剖性状，不是“裸子植物有、双子叶植物无”的界标。裸子植物的次生韧皮部以筛胞而非筛管分子为主要传导细胞，筛胞与蛋白细胞的关系也不同于被子植物筛管—伴胞复合体。

## 单子叶植物以多种路线增粗 { #monocot-thickening }

多数单子叶植物的维管束在初生基本组织中散生，束内不保留能连接成连续圆环的典型维管形成层。棕榈在靠近茎尖处通过初生加厚分生组织建立较粗的轴，后期还可由薄壁细胞扩张、分裂和纤维壁增厚继续增加直径；竹秆主要在节间伸长前就确定粗度，并靠密集维管束和木质化基本组织取得强度。这些高大、坚硬的茎证明树形和“木质感”不必由成圈的次生木质部产生。

龙血树、丝兰、芦荟等天门冬目植物则在初生维管束外建立单子叶植物形成层，也称次生加厚分生组织。它向内产生埋在薄壁组织中的次生维管束和结合组织，向外主要产生薄壁细胞；其原始细胞类型、产物排列和发生来源均不同于裸子植物和真双子叶植物的双面维管形成层。某些地下茎和肉质根还会建立连续形成层或额外维管分生组织。传统“异常次生生长”概括了偏离典型真双子叶茎的切面，但比较发育时应逐项说明分生组织来自哪里、向两侧产生什么，而不把所有增粗都叫作同一种形成层活动。[^monocot-secondary-growth]

## 木质与草质构成连续的生活史策略 { #woody-herbaceous }

木本植物通常具有多年存活的地上轴和持续活动的维管形成层，木材逐年积累；草本植物的地上轴较柔软，常在一个生长季结束后死亡，次生木质部较少。然而许多草本真双子叶植物在根、下胚轴或茎基部仍有明显次生生长，一些多年生草本还形成相当厚的木质部。木质藤本依赖其他植物获得高度，却可产生大量木材；棕榈和竹类外形似树，也不采用典型木本双子叶的形成层路线。

木本与草本因而不是高等与低等、完整与退化的两极，而是轴寿命、机械投资、输导需求和季节策略的组合。观察一个成熟切片时，可沿“分生组织来源—径向细胞谱系—成熟组织功能—器官寿命”追踪证据，才能把形态名称还原为真实的生长过程。
