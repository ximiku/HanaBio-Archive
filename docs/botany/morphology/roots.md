# 根的结构、发育与共生界面

根把植物体固定在异质而不断变化的基质中，并把土壤中的水、无机离子和微生物活动接入全株。它既是吸收与输导器官，也是感知水分、养分、重力、机械阻力和生物信号的发育系统。根尖持续产生细胞，内皮层和外皮层建立选择性边界，侧根与不定根改变探索范围，菌根和根瘤又把吸收表面扩展成跨物种的交换界面。根的功能因此不能由一段“根毛区”单独承担，而是由整套根系的空间架构、组织成熟度和周围环境共同决定。

## 根系架构与发生来源 { #root-system-architecture }

胚根发育形成种子植物的初生根，初生根上内生地产生侧根；由茎、下胚轴、叶或老根的非典型位置发生的根统称不定根。侧根与不定根都可继续分枝，但二者的发生位置不同。初生根长期占优势时，根系常呈直根型；大量不定根形成相近粗细的主轴时，常呈须根型。真双子叶植物和裸子植物中直根系较常见，禾本科等单子叶植物中须根系较常见，这是一种类群趋势而不是判定规则。根系还会随土层、机械阻力、水分和养分斑块改变分枝角度、延伸深度和细根周转，不能仅凭一次挖取的外形给物种指定永恒的“深根”或“浅根”属性。[^root-overview]

根系架构由轴的数目、级次、长度、直径、分枝角度和空间分布共同构成。少量向深处延伸的轴有利于接近深层水源，密集浅根可快速利用表层短暂资源；同一植株往往同时采用几种策略。局部硝酸盐、磷酸盐或水分供应会改变侧根发生和伸长，但响应还受全株碳氮状态、激素与土壤物理结构限制。根系不是预先展开的固定模板，而是在生长过程中持续取样和重分配资源的三维网络。

## 根尖把细胞产生转化为轴向生长 { #root-tip-development }

根尖最前端通常由根冠覆盖。根冠细胞在土粒摩擦中不断脱落，由近端的起始细胞补充；其分泌的黏液、脱落的边缘细胞或边缘样细胞与多种蛋白、多糖和胞外 DNA 共同形成根—土接触层。这一层可润滑根尖、黏结颗粒，并参与微生物招募和防御，不只是被磨掉的“保护帽”。[^root-cap-interface] 根冠柱状细胞中的富淀粉体会随重力方向沉降，随后经信号转导改变 PIN 等生长素转运蛋白的分布，使根两侧伸长速率不同而发生向重性弯曲；淀粉体位移是重力感受链的一部分，不等于它以机械压力直接推动根弯曲。[^root-gravitropism]

### 干细胞 niche 与发育区连续体 { #root-stem-cell-niche }

在 Arabidopsis 等模式植物中，根端分生组织的静止中心由少量较少分裂的细胞构成，周围起始细胞分别贡献根冠、表皮、皮层—内皮层和中柱等谱系。静止中心既向邻近细胞提供维持未分化状态的位置信号，也可在起始细胞受损后参与补充。PLETHORA 蛋白的浓度分布、SHORTROOT–SCARECROW 轴、局部生长素与细胞分裂素互作共同维持干细胞 niche 和径向分层。不同植物的根端大小、起始细胞排列和静止中心明显不同，有些根还会在生命周期或环境作用下终止分生；模式植物的细胞图谱不能直接当作所有根的固定剖面。[^root-quiescent-center]

从根端向基部观察，可依次看到以细胞分裂为主的分生区域、快速体积增加的伸长区域和细胞身份逐渐清晰的分化区域。三者相互重叠，没有适用于所有物种和生长条件的厘米界线。原表皮、基本分生组织和原形成层分别向外层组织、皮层—内皮层和中柱分化，原生木质部与原生韧皮部在根仍伸长时已经开始成熟。根的长度增加主要来自新细胞产生与伸长的连续配合，而不是整个成熟根段同步拉长。

根毛是根表皮细胞的管状顶端生长产物。它们在分化区形成，寿命、密度和长度随物种、根龄与磷、铁、水分等条件改变。根毛把吸收表面延伸进根轴难以接触的微孔，并显著促进磷等在土壤中扩散较慢的养分获取；其对整株吸水的贡献则取决于根毛长度、存活、土壤质地和干燥时是否萎缩，不能一概写成根吸水的唯一或恒定主要部位。[^root-hairs] 移栽时保留根际土团的意义也不只在“保护根毛”，还包括减少细根断裂、维持根—土接触和降低水力传导骤降。

## 初生根的径向组织 { #primary-root-radial-anatomy }

成熟区横切面通常可由外向内辨认根表皮、皮层、内皮层和中柱。根表皮一般角质层较薄或缺少连续角质屏障，适合与土壤交换；部分附生兰科和其他气生根在外侧形成多层根被。根被由成熟时常失去原生质体的细胞构成，可迅速吸水、减缓水分散失并影响光和气体环境，但其实际功能随物种和湿度改变，不能仅解释为“多层表皮”。

皮层多由薄壁细胞组成，可贮藏、通气并承担径向运输。靠外的若干细胞层在不少植物中分化为外皮层，形成凯氏带或木栓质层；Arabidopsis 缺少典型外皮层，因此从这一模式植物得到的结论不能覆盖许多作物和多年生植物。外皮层与内皮层的屏障强度会随根龄、干旱、盐分和缺氧改变，水生根、气生根和土生根之间也可不同。[^root-exodermis]

### 内皮层与凯氏带 { #endodermis-casparian-strip }

内皮层位于皮层最内侧，环绕中柱。幼根内皮层细胞的径向壁和横向壁形成连续的凯氏带，局部质膜通过 CASP 等膜域蛋白与该壁域紧密配合。Arabidopsis 的功能性凯氏带主要由木质素构成，木栓质层在稍后的发育阶段沉积于质膜与壁之间；把凯氏带统一定义为“栓质带”会混淆两个发生时间、空间分布和可塑性均不同的屏障。[^casparian-lignin]

凯氏带阻断沿细胞壁连续扩散的质外体通路，使进入中柱的水和溶质至少在某处跨越生活细胞的质膜，接受通道、转运体和泵的选择。它并非能识别并排除一切毒物的绝对过滤器：屏障完整性、跨膜转运特异性、离子浓度和旁路结构共同决定最终通量。内皮层进一步木栓化后，部分物种可保留相对少木栓化的通道细胞，但其位置和功能受营养状态与物种影响，不应固定写成“总位于木质部脊外侧”。侧根穿出时屏障会发生局部重塑并在新器官周围重新封闭，这是一段受调控的发育过程，而不是永久开放的漏口。

### 中柱与外始式维管分化 { #stele-vascular-pattern }

内皮层以内为中柱，其最外层通常是中柱鞘。中柱鞘细胞保留较强的发育可塑性，可参与侧根、维管形成层或木栓形成层发生，但具体贡献随类群和根龄不同。初生木质部与初生韧皮部在根中多呈辐射状相间排列；木质部由外侧原生木质部向内侧后生木质部成熟，称为外始式。二原、三原、四原或多原描述横切面上原生木质部极的数目，不是稳定到可以仅凭“单子叶／双子叶”判定的性状，同一植株的主根与侧根也可能不同。

许多真双子叶植物幼根中央由木质部占据或只有很小的髓，许多单子叶植物根具有明显的中央髓和较多木质部极，但木本真双子叶植物、草本类群和特殊根均有例外。横切面上“星形木质部”和“环状维管组织”适合描述典型标本，不应替代对中柱鞘、原生／后生木质部、韧皮部和髓的逐项识别。根内输导细胞的成熟状态与壁结构见[植物细胞与组织](plant_cells_tissues.md#vascular-tissues)。

## 水与离子从土壤进入木质部 { #radial-water-ion-transport }

土壤水到达根表后，可沿细胞壁和胞间隙构成的质外体移动，经胞间连丝连接的共质体移动，也可反复跨越质膜和液泡膜形成跨细胞路径。这三种描述是并行且相互转换的路径模型，不是三条互不相通的管道。水孔蛋白改变细胞膜的水力导度，离子通道、载体与 H$^+$-ATPase 建立选择性摄取；各路径的相对贡献随根龄、外皮层和内皮层成熟、蒸腾、盐分与缺氧而变。[^root-radial-transport]

径向进入中柱的水和离子随后装入木质部，沿根轴向地上部运输。白天蒸腾旺盛时，土壤—根—叶—大气水势梯度通常是吸水和上升液流的主要驱动力；蒸腾较弱而根仍主动积累离子时，木质部渗透吸水可产生正的根压，并表现为伤流或吐水。根压不能解释高大植物日间的大部分长距离输水，蒸腾也不意味着所有离子都按水流比例被动进入。根表转运、内皮层筛选、木质部装载和地上部需求使矿质吸收与吸水既耦联又可分离。完整水势与木质部水力学见[植物水分关系与木质部运输](../physiology/water_minerals.md)，离子选择性、营养元素和根际化学见[矿质营养、氮同化与根际互作](../physiology/mineral_nutrition.md)。

根吸收受根—土接触面、土壤导水率、氧供应、温度和溶液渗透势共同限制。土壤干燥时，根表附近的水力阻力可能比根内阻力更快上升；淹水时，缺氧会限制呼吸与膜运输，并促使某些植物形成通气组织或新的不定根。因此，“根毛区是主要吸收区”只是幼根在适宜条件下的概括，木质化程度较低的侧根、菌根菌丝以及某些较老根段都可能参与全株资源获取。

## 侧根发生与根系可塑性 { #lateral-root-development }

侧根从母根内部发生。以 Arabidopsis 为例，靠近木质部极的中柱鞘细胞接受周期性预设信号，其中少数细胞在局部生长素响应增强后成为创始细胞。创始细胞先发生有序的不等分裂，形成侧根原基；原基建立新的顶—基轴和根端分生组织，并通过内皮层、皮层与表皮出土。上覆组织主动改变水分状态、细胞壁和细胞间黏附，为原基让出通路，所以侧根穿出不是一团细胞把母根组织被动“顶破”。[^lateral-root-development]

不同维管植物的侧根起源细胞和相对于木质部极的位置并不完全相同。中柱鞘是种子植物中最常见的主要来源，某些类群还需内皮层等邻近细胞参与；二原、三原或多原根中侧根与维管极的几何关系也有物种差异。旧式“某一原型必定对向木质部或韧皮部”的口诀适合有限教学材料，不能当作普遍发育规则。

水分斑块、硝酸盐、磷状态、盐分和机械阻力可以影响侧根起始、出土或伸长，局部信号还与来自地上部的碳氮状态和肽信号整合。主根伸长、侧根密度和侧根角度因此可能分别响应。由茎或下胚轴产生的不定根也常受生长素、创伤和缺氧诱导，但它们在原器官内部重新建立根原基，不是侧根从母根中柱鞘发生的简单延续。

## 次生生长与贮藏根 { #secondary-growth-storage-roots }

许多裸子植物和真双子叶植物的根会发生次生生长。初生韧皮部内侧的原形成层残余与原生木质部极附近的中柱鞘细胞相继恢复分裂，连接成起初起伏、随后趋于圆整的维管形成层。形成层向内产生次生木质部，向外产生次生韧皮部，射线承担径向贮藏和运输。周皮常从中柱鞘或其后代发生并逐步取代表皮、皮层；随着根增粗，早期外层组织被撑裂、压缩或脱落。形成层细胞谱系、木材与树皮结构将在[次生生长与维管形成层](secondary_growth.md)详述。

贮藏根的肥大并非只有一种解剖路线。胡萝卜等肉质直根由主根及邻近下胚轴共同增粗，次生木质部和次生韧皮部的比例随物种、品种和发育期改变；萝卜的食用部分也常跨越下胚轴与根，不能把整件器官视为单一根组织。甘薯块根来自不定根或其分枝，围绕导管及维管束形成额外分生组织并积累大量薄壁组织；甜菜则形成多轮连续的形成层及其维管组织。传统“次生韧皮部根／次生木质部根／三生生长”可描述切面特征，现代比较更常把后两类归入异常次生生长或连续形成层，并追问每轮形成层的来源。

块根与块茎也应按发生来源区分。甘薯和木薯的贮藏器官是根，马铃薯块茎则是具有芽眼的地下茎；大丽花的块根与萝卜肉质直根又来自不同根轴。贮藏功能相似不能证明器官同源。

## 根—土—微生物共生界面 { #root-soil-symbiosis }

根际是受根分泌、吸收和脱落细胞显著影响的邻近土壤。糖、有机酸、氨基酸、黏液和其他根际沉积物改变局部 pH、碳源与矿物可利用性，微生物又可竞争这些资源、产生代谢物或侵入根组织。植物基因型、根段年龄、土壤和营养状态共同筛选根表与根内群落；检测到一个“促生菌”属名并不能证明它在当前土壤中促进宿主。群落层面的筛选和证据边界见[微生物生态与应用](../../micro/ecology_applications.md#plant-microbiomes)。

### 菌根的交换结构 { #mycorrhizal-interfaces }

丛枝菌根真菌的菌丝进入根皮层并在生活细胞内形成高度分枝的丛枝。真菌壁与菌体始终位于植物质膜之外，植物新生的丛枝周膜包围每个分枝，二者之间的界面空间进行磷、氮、水和植物碳源／脂质的双向交换。外生菌根则通常在细根外形成菌套，菌丝在表皮或皮层细胞之间形成 Hartig net，而不穿入这些生活细胞的原生质体。杜鹃类菌根、兰科菌根等具有不同的宿主谱系、真菌伙伴和交换结构，不能全部压入旧式“内生—外生—内外生”三分法。[^mycorrhiza-types]

菌丝把探索尺度延伸到根毛以外并能进入细小土壤孔隙，但宿主需要向真菌分配碳。交换结果随磷、氮、水分、真菌与植物基因型以及其他微生物而改变，净效应可从明显互利到接近中性甚至对植物生长不利。跨许多宿主—真菌组合的分析显示，共生结果具有强烈的谱系和伙伴特异性，不能把“形成菌根”直接等同于增产。[^mycorrhiza-context]

### 固氮根瘤是新生器官 { #nitrogen-fixing-nodules }

豆科—根瘤菌共生从双方信号识别开始。许多模式系统中，根毛弯曲包围细菌，植物壁和膜内陷形成感染线，细菌沿这条仍拓扑位于细胞外的通路进入正在发生的根瘤；另一些宿主可经裂隙或不同细胞路径感染。与此同时，根皮层或邻近组织重新进入分裂，建立具有自身分生区、维管连接和感染区的新侧生器官。根瘤并不是细菌刺激根组织形成的一团无序肿大，感染与器官发生需要精确协调。[^nodule-organogenesis]

细菌从感染线释放后被植物来源的共生体膜包围，并分化为固氮的类菌体。宿主供应碳源并调节氧通量，豆血红蛋白帮助维持既保护固氮酶又允许呼吸的低自由氧环境；固定的氮再以可同化形式交给植物。固氮反应和氧保护机制见[微生物营养与代谢](../../micro/nutrition_metabolism.md)。结瘤与固氮消耗大量碳和矿质资源，植物还通过全株反馈限制根瘤数目，故有根瘤不等于当时具有高固氮速率。

豆科以外，一些放线根植物与 *Frankia* 形成固氮根瘤，例如桤木、木麻黄和杨梅所属的若干谱系。苏铁的珊瑚状根可容纳固氮蓝细菌，但其共生器官和伙伴均不同于 *Frankia* 根瘤；罗汉松等根部瘤状结构也不能仅凭外形归入放线根共生。根瘤、菌根和普通根际定殖代表不同的组织改造程度，应分别由伙伴身份、空间位置和物质交换证据确认。

## 特化根与生态功能 { #specialized-roots }

气生根把根的功能带到土壤以外。附生兰科根被可快速吸收降水并缓冲干湿交替；榕属的支柱根从枝条下垂、接地后增粗并参与承重，玉米茎基部的不定支柱根兼具固定和吸收。常春藤等攀援根以短小根或根毛状结构附着基质。名称来自主要功能，但这些根仍可能同时输导、贮藏和感知环境。

缺氧基质中的根可形成通气组织，并借地上或近地表结构缩短氧扩散路径。红树类群和落羽杉等植物的呼吸根常由地下侧根向上生长，表面皮孔及内部连通气腔把氧送往淹水组织；并非所有湿地植物都形成同一种“呼吸根”，许多物种采用茎基膨大、不定根更新或径向氧损失屏障等其他方案。

寄生植物以吸器连接宿主组织。列当等根寄生植物从根产生吸器，槲寄生类的幼根状结构进入宿主枝条，而菟丝子的吸器由缠绕茎产生，不应统一称为“寄生根”。吸器穿过宿主外层并与木质部、部分物种的韧皮部建立连续性；全寄生或半寄生描述寄生植物自身光合和碳获取程度，不能替代对吸器起源和输导连接的判断。

## 根结构的证据与解释边界 { #root-evidence }

连续横切和纵切可重建根尖分区、维管极数、侧根起源和共生结构；木质素、木栓质、淀粉及活性染料则帮助区分壁屏障和生活细胞。切片显示的是某一根段和发育时刻，不能用单个横切面推断整个根系。透明化、共聚焦和光片显微镜可追踪原基出土，细胞类型特异报告基因、克隆标记和激光消融可检验谱系与 niche 信号，但 Arabidopsis 的规则需要在作物和其他谱系中独立验证。

水和溶质示踪、根压探针、压力室与水力模型可估算不同根段的通量；染料在中柱外停止只证明当时存在质外体扩散屏障，不直接给出跨膜转运选择性。根箱、透明根管、X 射线 CT 和磁共振成像把二维切片扩展到土壤中的三维根系，但观测窗、基质和分辨率都会改变可见根的范围。

共生界面还需联合显微定位、伙伴分离或序列鉴定、宿主与微生物遗传扰动以及同位素通量。真菌结构出现支持“发生定殖”，根瘤形成支持“器官发生成功”，只有 $^{15}$N、$^{33}$P 等示踪或物质收支才能证明在给定条件下发生了多少交换。根的解释因此必须把形态、发育时间、分子身份和实际通量放在同一证据链中。
