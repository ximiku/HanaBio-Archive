# 植物的信号、发育与环境响应

植物在原位完成一生，环境变化不能只引起短暂的行为反应，还会改变新细胞在何处产生、器官何时转换命运以及有限资源如何分配。光照方向可在数小时内改变胚芽鞘伸长，日长和持续低温却要经过多个昼夜才推动开花；一次伤害能在局部诱导防御，也能使远端叶片进入预警状态。植物调控因而是一组跨越细胞、器官与全株，覆盖秒、季节乃至世代的动态过程。

本页面组从信号的一般语法进入环境感知和生长协调，再沿种子、营养体、生殖体与衰老阶段追踪发育转换，最后讨论植物怎样承受非生物胁迫并识别病原和植食者。五个正文页共享激素、Ca²⁺、活性氧、蛋白磷酸化、转录和长距离运输等节点，却不把某一信号固定为单一功能。阅读时要同时说明信号来自何处、靶组织处于什么状态、响应持续多久，以及这种响应对存活、生长或繁殖造成何种后果。

## 感知与信号网络建立调控入口 {#sensing-signaling}

[植物激素与信号网络](hormones_growth.md)是本组的机制入口。生长素、赤霉素、细胞分裂素、ABA、乙烯、油菜素甾醇、茉莉酸、水杨酸和独脚金内酯分别通过合成、运输、受体、信号开关和失活过程形成时空分布；分泌肽、多胺、糖、活性氧和小 RNA 又把营养、损伤与细胞身份接入网络。激素名称只指出一种信号分子，不能脱离受体丰度、浓度范围、组织背景和其他通路预测最终效应。

环境信息也由专门感知系统进入。光敏色素比较红光与远红光状态，隐花色素、向光素和 UVR8 读取不同波段，平衡石细胞帮助重力感受，膜张力、水势、温度和病原分子则通过各自的通道、受体或代谢状态被检测。信号随后由磷酸化、离子通量、第二信使和基因表达放大、整合并终止。通用的受体—开关—反馈原理可与[细胞信号转导](../../cell/cell_signaling.md#spatiotemporal-coding)交叉阅读；植物页关注这些原理如何落实到器官生长和生活史。

## 生长把信号转成空间变化 {#growth-environment}

[光形态建成、生物钟与运动](light_clock_movement.md)先区分细胞增殖、扩张、分化与程序性死亡，再说明长度、面积、鲜重、干重、相对生长率和异速关系为何回答不同问题。器官生长来自分生组织产出、膨压驱动的细胞扩张、细胞壁重塑和资源供应的共同作用；根、茎、叶之间还通过顶端优势、源—库关系和长距离信号协调。这里的“生长”不是某一种激素浓度的同义词，而是多个细胞过程在空间上累积的结果。

同一页继续追踪环境怎样改变生长位置与时刻。暗中萌发的幼苗在见光后完成去黄化，生物钟使光合、气孔、伸长和开花通路保持相位，向光、向重、向水、向化与向触反应把刺激方向转为不对称生长；叶枕运动、捕虫和感震运动则可更多依靠离子与水的快速转移。把这些反应放在时间轴上，才能区分立即的运动、数小时的转录重编程、日周期节律和长期形态可塑性。[^plant-response-framework]

## 种子在等待与启动之间设置门槛 {#seed-transition}

[种子休眠、萌发与幼苗建成](germination_dormancy.md)从母株上的晚期成熟开始。种子获得耐脱水性和不同储藏行为后，生活力、活力、休眠与静止共同决定它能否保存以及何时萌发。休眠可以来自胚、包被组织、形态成熟度或多种机制的组合，解除方式必须与实际阻碍相匹配；水、温度、氧和光则限定萌发窗口，而非为所有物种提供一组固定条件。

吸胀后的膜修复、线粒体恢复、储存 mRNA 利用和新转录使代谢重新启动，淀粉、脂质、蛋白质与植酸中的资源随后被动员。胚根突破包被标志萌发终点，出土、子叶展开和光合系统建立则把幼苗从依赖储藏物带向自养。种子结构、胚乳与种皮来源见[种子、果实与无性繁殖](../morphology/flowers_seeds_fruits.md#seed-tissue-origins)，本组页面集中解释这些结构何时允许或阻止生长恢复。

## 生殖转换连接季节、资源与器官命运 {#reproductive-transitions}

[开花、成熟、衰老与脱落](reproduction_stress.md)沿生活史后半段组织多个转换。年龄途径先建立成花能力，春化记录持续低温，叶片中的光周期—生物钟系统再产生长距离成花信号；茎尖取得生殖命运以后，花器官身份、性别表达、配子育性和授粉受精共同决定结实。果实建立和生长依赖种子信号与源—库输入，成熟过程重塑色泽、质地、气味和传播性状，跃变型与非跃变型果实采用不同的乙烯—呼吸动力学。

器官完成功能后，衰老程序拆解叶绿体、蛋白质和核酸并把氮、磷等资源再动员到幼嫩或生殖器官；离层随后在特定细胞区解除组织连接并封闭创面。芽和地下器官的休眠又把多年生植物带过不利季节。这些过程会受到温度、水分、营养和病虫害影响，却不能把所有提前落叶、落花或休眠都直接归为“逆境伤害”：发育程序是否正常启动、器官是否已经完成作用以及资源是否成功回收，需要分别判断。

## 胁迫响应在保护、牺牲与恢复之间取舍 {#stress-defense}

[逆境响应与植物免疫](stress_immunity.md)把低温、冻害、高温、干旱、淹水、盐分和污染放入暴露—感知—稳态重设—损伤／恢复的连续过程。Ca²⁺、活性氧、MAPK、ABA、蛋白稳态、抗氧化和渗透调节提供部分共享能力，CBF—COR、HSF—HSP、ERF-VII 以及 SOS／HKT／NHX 等模块又分别处理结冰、蛋白错误折叠、低氧和离子失衡。逃避、避逆、耐受与恢复是不同策略，抗性评价还须区分存活、继续生长和保住产量。

生物胁迫要求植物辨认对手。质膜模式识别受体感知微生物或损伤分子，胞内 NLR 监视效应子活动，两类入口在下游相互增效；局部细胞壁加固、抗菌代谢和防御性死亡与水杨酸—NHP 系统获得性抗性、根际诱导抗性及远距离信号共同限制病原。RNA 沉默针对病毒核酸，茉莉酸网络则组织对植食者的直接毒害、消化抑制和挥发物间接防御。免疫有代谢成本，也会与生长、衰老和共生发生权衡，不能只用防御基因表达量判断整株获益。[^systemic-stress-defense]

## 两条阅读路径 {#reading-paths}

沿生活史顺读时，可先由[植物激素与信号网络](hormones_growth.md)建立共同语言，再进入[光形态建成、生物钟与运动](light_clock_movement.md)，理解环境怎样调整日常生长；随后依次阅读[种子休眠、萌发与幼苗建成](germination_dormancy.md)和[开花、成熟、衰老与脱落](reproduction_stress.md)，追踪从种子到下一代传播体的阶段转换，最后以[逆境响应与植物免疫](stress_immunity.md)检验这些阶段在不利环境和生物互作中如何重新配置。

从现象逆向追踪时，可先确定变化发生在哪个器官和时间尺度。幼苗徒长、弯曲或节律异常，应从光受体、生物钟、激素分布和细胞扩张回查；出苗不齐要区分生活力、休眠、吸胀环境和幼苗建成；花期错乱、落花落果或成熟异常需要核对年龄、春化、日长、源—库和乙烯状态；萎蔫、黄化、坏死、病斑或虫害则先判断水力、温度、氧、盐、污染物与病原识别。一个表型常同时跨越多个页面，逆向路径的作用正是逐层排除限制环节，而不是为症状寻找唯一“对应激素”。

## 与结构、代谢和生态页面的边界 {#interfaces}

本组讨论信息怎样改变过程。[植物体的结构与发育](../morphology/)说明分生组织、根、茎、叶、花、种子和果实从何处形成，[植物的资源获取与物质代谢](../physiology/)说明水、离子、碳和专门代谢物怎样流动；本组在这些结构和通量之上解释时序、响应与命运转换。阅读气孔、源—库或防御代谢时，应在相邻页面之间往返，而不把结构、物质通量和信号调节压成同一层叙述。

病原、病毒、根际伙伴及其生活史见[微生物学](../../micro/)，群落中的竞争、互利、植食和环境筛选见[生态学](../../ecology/)，跨动物与植物的诱导、形态发生和时空证据见[发育生物学](../../development/)。植物页面保留宿主一侧的感知、资源权衡和表型后果，并通过这些接口把细胞机制接回真实环境。
