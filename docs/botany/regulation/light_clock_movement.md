# 光形态建成、生物钟与运动

植物固着生活，却不断重定向自身的生长。分生组织产生细胞，细胞扩张和分化塑造器官；光、重力、水分和温度又改变这些过程发生的位置与时刻。光受体和生物钟把环境信息转化为基因表达、激素分布、离子通量与水力状态，最终表现为去黄化、节律、弯曲或迅速的叶片运动。

## 生长连接细胞增殖、扩张与分化 { #growth-cell-processes }

生长通常指体积、长度、面积或干物质等量的不可逆增加。细胞数目增加依赖[细胞周期与胞质分裂](../../cell/cell_cycle.md#cycle-states)，但器官变大还取决于单个细胞扩张。液泡吸水形成膨压，细胞壁在酸化、壁松弛蛋白和多糖重排作用下允许伸展，皮层微管引导纤维素微纤丝的沉积方向，因此伸长往往具有明显的各向异性。胚芽鞘伸长区以细胞扩张为主，根尖则把细胞产生、伸长和分化排列成连续的空间梯度；两者都不能只用“细胞分裂更快”概括。[植物细胞壁与骨架](../morphology/plant_cells_tissues.md#cell-wall-material-system)分别提供了承压材料和方向约束。

细胞分裂的位置、方向和对称性同样参与形态建成。花粉第一次有丝分裂产生大小和命运不同的营养细胞与生殖细胞，气孔谱系也含有不对称分裂；花粉管和根毛的延长则属于细胞顶端生长，并非不均等分裂本身。生长素、细胞分裂素、赤霉素和脱落酸可以调节细胞周期入口、分生组织活性或扩张能力，但其效应取决于组织状态，不能换算成适用于所有外植体的固定激素比例。

分化使细胞获得相对稳定的结构和功能。组织培养中的外植体仍可能经历去分化样转变、愈伤组织形成或直接器官发生；培养基中的生长素—细胞分裂素平衡、糖、矿质和光照都会影响结果，而且植物材料自身也能合成和代谢这些信号。切段保留的顶—基极性常使形态学上端较易形成芽、下端较易形成根，但再生方向还受创伤信号、维管连续性和培养条件控制。

程序性细胞死亡可以是分化程序的终末步骤，例如木质部导管分子清空原生质、根冠细胞脱落、绒毡层退化以及某些种子的胚乳或糊粉层被动员；缺氧诱导通气组织和病原触发超敏反应则发生在环境应答中。不同事件的执行机制并不完全相同，不宜全部套用动物细胞凋亡的形态标准。表皮毛是活细胞分化形成的结构，其分布可在上表皮、下表皮或两面，功能也包括防御、减少水分散失、反射辐射、分泌和吸收，不能作为植物程序性死亡的通例。[^plant-pcd]

## 生长量随尺度和时间改变 { #growth-measurement-periodicity }

株高、叶面积、鲜重与干重回答的问题不同。绝对生长速率可写成 $\Delta X/\Delta t$，反映单位时间增加的量；相对生长速率常写成 $\Delta \ln X/\Delta t$，用于比较初始大小不同的植株。若要解释叶片或根尖何处正在伸长，还需要标记点位、连续成像或细胞运动学分析。单一终点值无法区分细胞产生加快、细胞扩张增强和生长持续期延长。[^growth-measurement]

许多器官在有限生长期内呈慢—快—慢的 S 形累积曲线：早期可用的细胞和同化面积较少，中期迅速增加，后期受成熟、资源和衰老限制。它是常见经验形态，不是所有器官必须遵循的定律；其导数也只在理想模型下呈单峰钟形，不能笼统称为抛物线。同一植株的根、叶、茎、花和果实进入快速生长期的时刻各异，整株曲线因此是多个器官过程叠加的结果。

昼夜温差会改变茎伸长、叶片展开和干物质配置。温室园艺常用日温减夜温的差值（DIF）描述形态效应，但反应随物种、发育期、平均温度、光周期和水分而变；“夏季一律夜长、冬季一律日长”不是普遍的温周期规律。季节性次生生长还可在木材中留下年轮：一个年轮通常包括同一生长季形成的早材与晚材，清晰的年轮界线位于前一生长季晚材和下一生长季早材之间。

## 整株器官通过资源与信号协调 { #whole-plant-coordination }

根向地上部输送水和矿质，并产生或转化细胞分裂素、脱落酸前体和多种肽信号；叶和其他源器官则向根供应光合碳。根冠比因此是地下部与地上部生物量配置的结果，不是一个固定的“根与茎叶竞争指数”。缺水、氮限制或光照变化常使植物改变根系投资，但方向和幅度受个体大小、物种、共生关系及限制因子强弱制约。根源 ABA 与水力变化参与干旱时的气孔调节；乙酰胆碱虽然在植物中可被检测到，目前没有证据支持它作为普适的根尖—叶片蒸腾激素。[^biomass-allocation]

主茎与侧枝的关系体现了局部信号和资源供给的共同作用。[顶端优势](hormones_growth.md#auxin-development)涉及顶芽产生的生长素、节点处独脚金内酯—细胞分裂素网络、糖供应和芽自身状态；摘心后侧芽能否萌发还取决于位置与环境。侧根发生同样由局部生长素峰、营养斑块和根系发育阶段调节，切根或外施生长调节剂不会在所有作物中产生相同结果。

营养生长为花、果实和种子提供结构与资源，强大的生殖库又会重新分配碳、氮和矿质。果树大小年、作物徒长与贪青均可由这种源—流—库关系理解，但还会受到花芽形成、授粉、果实负载、天气和管理史影响。施肥、打顶、疏枝和疏果应围绕具体物种与生产目标设计，不能由“营养器官多施氮、生殖器官后期施磷钾”一条规则推出。相关运输基础见[源—库转换与整株配置](../physiology/transport_metabolism.md#source-sink-transitions)。

## 光把幼苗从暗形态建成切换到去黄化 { #photomorphogenesis }

暗中萌发的典型双子叶幼苗常有较长的下胚轴、闭合子叶和顶端弯钩，质体保持黄化体状态；这些特征有利于幼苗穿过土壤。受光后，下胚轴伸长受抑，子叶展开，叶绿体和光合装置形成，花色素苷及光保护系统被诱导，这一组转换称为去黄化。单子叶植物、地下子叶型幼苗和已经绿色的器官具有不同的形态背景，不能把某一种黄化苗外形当作所有植物的暗生长模板。

光合作用提供能量和还原力，光形态建成则由感光蛋白读取波长、方向、强度、持续时间与昼夜时刻。光照对伸长的影响也并非简单来自生长素被破坏：光受体可改变 COP1／SPA、PIF 等转录调控模块，进而重排细胞壁、激素合成与运输以及叶绿体发育。以下受体框架保留了本地材料与 osm.bio 整理中的有效知识，并按现代受体研究重新划分其功能边界。[^osm-growth-substances]

## 红光与远红光由光敏色素读取 { #phytochrome }

植物光敏色素由蛋白质与线性四吡咯生色团组成，可在主要吸收红光的 Pr 与主要吸收远红光的 Pfr 状态间光转换。Pfr 常是许多反应中的信号活性状态，但 phyA 的稳定性、暗逆转和不同成员的作用方式并不相同。拟南芥有 phyA 至 phyE；phyA 对极低辐照度和连续远红光特别重要，phyB 是红光、遮阴与温度响应的核心成员。光激活后，一部分光敏色素进入细胞核，改变 PIF 的稳定性和 COP1／SPA 复合体的作用，从而使 HY5 等调控因子重塑转录网络。光敏色素蛋白具有磷酸化相关活性，但其生理作用不能简化为普通丝氨酸／苏氨酸激酶的一条线性通路。[^phytochrome-network]

红光促进、随后远红光撤销效应的经典实验显示，两种状态之间的光转换可以保存“最后一次照光”的信息。低辐照度反应常在一定范围内符合 Bunsen–Roscoe 互易关系，即辐照度与照射时间的乘积相近时反应相近；极低辐照度反应可由极少量活性态触发，通常不显示简单的远红光逆转；高辐照度反应需要较长时间的持续照射，对光强和时长分别敏感，不能只按总光量预测。种子萌发、幼苗去黄化、茎伸长、遮阴回避、开花与部分叶运动可以属于这些不同反应域。

历史上的 Tanada 根尖黏附效应也显示了红光—远红光可逆性：在特定离子溶液和带负电的玻璃表面，离体绿豆或大麦根尖经红光处理后迅速黏附，远红光可使其脱离。实验支持光敏色素能快速改变根冠细胞表面电荷，却不能据此把光形态建成统一解释为膜电荷变化；后来的核内转录机制揭示了大多数较慢发育反应的主要路径。[^tanada-effect]

光敏色素并非植物特有，细菌、藻类、真菌与其他真核生物中也存在具有不同结构和功能的 phytochrome 家族，演化过程中还发生过基因丢失与水平转移。干种子也不等于没有光敏色素反应：莴苣等种子的可光转换状态可在干燥期保存，吸水则改变后续信号执行的能力。因而，暗逆转需要分子运动与代谢条件，并不能推出“所有干种子不感受红光”。[^phytochrome-evolution] [^dry-seed-phytochrome]

## 蓝光、UV-A 与 UV-B 使用不同受体系统 { #blue-uv-receptors }

隐花色素以 FAD 为主要生色团，参与去黄化、抑制下胚轴伸长、花色素苷形成、成花时间和生物钟校时。向光素具有两个结合 FMN 的 LOV 感光结构域和蛋白激酶区，是向光弯曲、气孔开放、叶绿体定位以及叶片展平的重要蓝光受体。Zeitlupe（ZTL）、FKF1 和 LKP2 则把 LOV 感光结构域与 F-box 蛋白的受控降解功能结合起来，分别接入生物钟与光周期调节。这些系统会相互影响，但不存在“低强度只由隐花色素、高强度只由向光素”或由固定光强决定受体接管的通则。[^flavoprotein-receptors]

UV RESISTANCE LOCUS 8（UVR8）以蛋白质中的色氨酸残基直接吸收 UV-B，不需要另接小分子生色团。吸光使 UVR8 同源二聚体分开，单体与 COP1 结合并促进 HY5 等因子的转录输出；在较低剂量下，这条通路诱导黄酮、花色素苷、DNA 修复与其他驯化反应。较高 UV-B 剂量还会直接造成 DNA、蛋白质和光合装置损伤，不能把所有植株矮化或气孔变化都解释为 UVR8 的适应性信号。UV-C 大多被平流层臭氧和氧吸收，地表通常极少，但“全部吸收”仍取决于波长和大气条件。[^uvr8]

## 生物钟把环境周期转化为内源节律 { #circadian-clock }

昼夜节律具有约 24 小时周期，并可在恒定条件下自由运行。光暗和温度周期是主要授时因子，它们调整振荡的相位；周期、相位和振幅是不同性质，温度补偿则使生理温度范围内的周期对温度变化相对不敏感。自由运行、可被校时和温度补偿共同帮助区分内源时钟与对环境昼夜变化的直接响应。

拟南芥的中央振荡器是一组相互连接的转录、翻译与蛋白降解反馈网络。黎明附近的 CCA1 与 LHY、白天依次表达的 PRR9／PRR7／PRR5 和 TOC1、傍晚发挥作用的 ELF3／ELF4／LUX evening complex，以及 RVE 与 LNK 激活模块共同形成连续的时相结构。光敏色素、隐花色素和 ZTL 家族把光输入接入其中，温度、糖状态和代谢反馈也能校时；因而植物钟并不是三条彼此独立的简单负反馈环。[^plant-clock-core]

时钟输出覆盖光合能力、气孔运动、胚轴伸长、香气释放、免疫、激素敏感性和开花季节。它常以“门控”方式改变同一刺激在一天中不同时刻的响应幅度。不同组织可以具有相位和周期略异的局部时钟，又通过糖、光、温度和长距离信号发生耦合。叶片、维管组织、根和分生组织因此既共享全株昼夜秩序，也保留符合局部功能的节律。光周期诱导开花的详细输出将在生殖调控页面展开。

## 向性运动把刺激方向写入生长差 { #tropisms }

向性是器官相对于定向刺激发生的方向性生长，正向性朝向刺激，负向性背离刺激。其弯曲通常来自器官两侧伸长速率不同，因此比由叶枕膨压造成的快速运动缓慢且较难立即逆转。叶片保持特定角度可同时受向光、生长重力反应、叶枕运动和生物钟控制，不能仅凭最终姿态指定一种机制。

### 向光性 { #phototropism }

幼苗茎与胚芽鞘的向光弯曲主要由 phot1 和 phot2 感受定向蓝光。NPH3、RPT2、PKS 等信号组分以及 ABCB 和 PIN 类生长素转运蛋白改变器官横向的生长素分布，使背光侧细胞通常伸长较快。光敏色素和隐花色素还会调节反应幅度。这里的方向信息来自受体激活和极性运输网络，而不是向光侧产生正电后静电吸引 IAA 阴离子。根可表现弱负向光或避光生长，但其结果受重力、组织损伤和培养条件显著影响。[^phototropism]

### 向重性 { #gravitropism }

根冠柱细胞与芽中内皮层样淀粉鞘细胞含有可沉降的淀粉体。淀粉体位置变化经膜接触、细胞骨架和 LAZY／RLD 等信号过程重定向 PIN 蛋白，建立横向生长素差。较高生长素在茎的伸长区常促进下侧伸长，在根的伸长区则抑制下侧伸长，于是茎向上、根向下弯曲。钙信号参与响应，但不足以替代重力感受—极性运输—差异伸长这条空间链路。根尖能够局部合成和维持生长素稳态，来自地上部的生长素只是可能来源之一；根冠受损对向重性影响很大，是因为感受组织和信号组织被破坏。根部结构背景见[根尖发育与根系可塑性](../morphology/roots.md#root-tip-development)。

### 向水、向化与向触 { #hydro-chemo-thigmotropism }

根向较湿区域弯曲称向水性。MIZ1、脱落酸和细胞分裂素的不对称分布参与水势梯度的读取，向水信号还要与通常更强的向重性竞争；现有研究并不支持把它完全归结为与向光性相同的生长素横向运输。土壤中的养分斑块可以改变侧根发生和伸长，但“深施肥后根向肥料生长”同时含有局部营养促进、毒害或盐胁迫等效应，只有在定义了化学梯度和方向性弯曲时才宜称向化性。[^hydrotropism]

花粉管朝胚珠生长是细胞顶端生长对珠孔附近短程肽信号的定向响应，详见[传粉与双受精](../morphology/pollination_fertilization.md)；根、菌丝或其他细胞对特定化合物也可表现向化性。卷须接触支撑物后产生差异生长，属于向触性。它们共同说明“刺激有方向”只定义了现象，受体、信号和运动器官仍需逐例确定。

## 感性与自主运动改变器官姿态 { #nastic-autonomous-movements }

感性运动由刺激触发，但运动方向主要由器官自身结构决定，而非由刺激来自哪一侧决定。偏上生长（epinasty）是器官上侧生长较快而使叶或花向下弯，偏下生长（hyponasty）则是下侧生长较快而使其上举；乙烯、淹水、光竞争和高温都可能通过不同网络改变叶角。感热性开花常由花被两侧差异生长或膨压变化产生，具体机制随物种而异。

豆科植物的睡眠运动由生物钟和光暗信号调节叶枕。叶枕屈侧与伸侧运动细胞改变 K$^+$、Cl$^-$ 等溶质通量，水随渗透势变化进出，使两侧膨压交替占优。这里的离子与水流是直接执行环节，生长素并非一条能解释所有昼夜叶运动的固定上游开关。花瓣开闭、太阳追踪和某些叶片摆动也可能含有生长、膨压或两者组合，应通过速度、可逆性和运动组织来区分。[^nyctinasty]

含羞草受触碰、振动或损伤后，机械感受引发电信号和 Ca$^{2+}$ 信号传播；叶枕运动细胞发生离子与水分重新分配，膨压迅速下降，导致小叶合拢和叶柄下垂。信号可沿维管组织传播，动作有助于降低食草动物取食，但反复运动也消耗能量并暂时减少光合面积。捕蝇草的快速闭合具有不同的感受毛、动作电位积分和叶片弹性结构，不能与含羞草视为同一器官机制。[^mimosa]

旋转生长（circumnutation）是在缺乏单向外界刺激时，器官伸长区因生长速率和方向周期变化而形成的摆动或螺旋轨迹。攀援茎、卷须、根和幼苗器官均可出现，其节律受内源生长过程影响，也会被重力、触碰与生物钟调制。它与向性反应可以叠加，却不等同于围绕刺激方向弯曲。[^circumnutation]

## 实验与栽培中的判读原则 { #experimental-interpretation }

研究光反应时，需要分别记录光谱、光子通量密度、照射时间、入射方向和处理发生的昼夜时相，并设置暗对照、等总光量对照或末次远红光处理。持续光还会改变光合作用、叶温和蒸腾，不能把所有差异直接归给光受体。使用受体突变体、组织特异表达、活体成像和转录输出，可把感受位置、信号传递与生长执行逐步拆开。

温室补光、日夜温差、控水、修剪和生长调节剂都会同时改变资源供应与信号网络。可靠的栽培判断应明确物种、品种、发育期和目标性状，并同时测量生长量、形态、开花或产量，而不是只依据“促进”或“抑制”标签。植物的可塑性来自多个输入在特定时间与组织中的整合，这也是同一处理在不同环境中可能产生相反结果的原因。
