# 休克与器官功能障碍

休克是急性循环衰竭造成的组织灌流不足：细胞获得的氧和底物、清除的代谢产物与当时需求不再匹配，器官功能因而受到威胁。血压降低是常见表现，却既不是休克最早期的必要条件，也不能独自说明组织灌流；代偿性血管收缩可以暂时维持动脉压，恢复平均动脉压也不保证毛细血管内的营养性血流已经均匀恢复。休克的识别因此要同时追踪压力、流量、氧输送、微循环和器官功能，而不能把其中一个读数当作疾病本身。[^circulatory-shock][^shock-guideline]

休克也不是失血性低容量的同义词。循环内容物不足、血管张力与分布异常、心脏泵血衰竭以及血流受到机械性阻断，都可使有效组织灌流下降；感染、创伤、手术或基础心肺疾病还常使这些机制叠加。持续的低流量只是器官损伤的一条入口，内皮屏障破坏、炎症—凝血耦联、代谢重编程以及器官间反馈可以在宏观循环改善后继续推动多器官功能障碍。

## 组织灌流的多变量框架 { #perfusion-framework }

### 压力、流量与氧含量 { #pressure-flow-oxygen }

在简化的体循环模型中，平均动脉压（MAP）约由心输出量（CO）与全身血管阻力（SVR）的乘积决定：

$$
\mathrm{MAP}-\mathrm{RAP}\approx \mathrm{CO}\times \mathrm{SVR}
$$

右心房压（RAP）通常远低于 MAP，但在右心衰竭、机械通气或回流受阻时不能随意忽略。这个关系说明，同样的低血压可以来自流量不足、血管过度舒张或两者并存；也说明提高 SVR 虽可升高压力，却可能没有增加 CO。器官实际血流还取决于局部入口与出口压力、血管阻力、自身调节和静脉淤血，不能从 MAP 单独推出，相关正常生理见[器官灌流的共同原则](../blood/blood_organ.md#organ-perfusion-principles)。

全身氧输送量（$\mathrm{DO_2}$）则近似为心输出量与动脉血氧含量（$\mathrm{CaO_2}$）的乘积：

$$
\mathrm{DO_2}=\mathrm{CO}\times \mathrm{CaO_2}
$$

因此，血压尚可时，低心输出量、贫血或严重低氧血症仍可限制氧输送；反之，氧含量正常也不能弥补极低血流。全身平均的 $\mathrm{DO_2}$ 还可能掩盖区域分流和毛细血管流量异质性。氧含量、输送与提取的完整账本见[缺氧的氧平衡框架](hypoxia.md#oxygen-balance)。

### 休克的四类机制模型 { #shock-mechanisms }

| 主导机制 | 首要循环缺陷 | 常见血流动力学倾向与边界 |
| --- | --- | --- |
| 低容量性 | 出血、体液丢失或血管内容量外移使静脉回流和心室充盈不足 | 每搏量和 CO 常下降，代偿性 SVR 常升高；毛细血管渗漏造成的“相对血管内容量不足”可与总水量增加并存 |
| 分布性 | 血管张力、容量血管分布与微循环调节失常，代表情境包括脓毒症、严重过敏和神经源性机制 | SVR 常降低，早期 CO 可高、低或正常；温暖皮肤和高 CO 都不是必然表现，也不证明组织氧合充分 |
| 心源性 | 心肌收缩、舒张、节律或瓣膜功能使泵血不能匹配回流和代谢需求 | CO 下降而充盈压可能升高，但左右心受累、前负荷和机械通气会改变表型；外周血管收缩可能进一步增加后负荷 |
| 梗阻性 | 心脏充盈或射血通路被心包填塞、张力性气胸、大块肺血管阻塞等机械因素限制 | CO 下降，静脉压常升高；解除阻断才针对上游原因，单纯补液或升压不能替代病因处理 |

这种分类帮助定位可逆环节，不是要求每位患者只能落入一格。脓毒症可同时出现血管舒张、毛细血管渗漏、心肌抑制和右心负荷增加；严重出血也可继发炎症、酸血症和心肌功能下降。随着病程与支持措施改变，主导机制会移动，床旁判断需要反复重建而不是一次命名。[^circulatory-shock]

## 循环代偿与器官储备 { #compensation }

低有效循环充盈和动脉压力下降可通过压力感受性反射、交感—肾上腺髓质系统、RAAS 与非渗透性 AVP 释放提高心率、收缩性、静脉张力和水钠保留，并将部分皮肤、肾和内脏血流转向心脑。短时反应有助于维持回心血量和关键器官灌流，却会增加心肌氧耗与后负荷，并压缩肾和内脏的血流储备。心脏能否把增强的静脉回流转成输出，还取决于[心—血管工作点](../blood/blood_heart_pump.md#cardiac-vascular-working-point)而非“前负荷越高越好”。

这解释了为何早期休克可以在接近正常的血压下出现四肢温度、毛细血管再充盈、意识、尿量或乳酸趋势异常，也解释了为何心率快、皮肤湿冷并非所有类型共有。教材常用“代偿期—进展期—不可逆期”描述循环储备逐渐耗竭，但真实过程受病因、速度、既往器官储备与干预影响，是可回转也可跳跃的连续谱；不存在跨病因通用的三段时限或单一不可逆阈值。

中心静脉压（CVP）同样不能独立判断血容量或输液反应。它同时受右心泵功能、静脉张力、胸腹腔压力、瓣膜病变和机械通气影响；低值不自动等于需要补液，高值也可能来自静脉淤血而不代表左心获得足够前负荷。现代血流动力学评估因此强调把病史、体征、超声、CO／每搏量和动态液体反应性连在一起，并连续观察干预后的组织灌流变化。[^shock-guideline]

## 宏观—微循环一致性 { #hemodynamic-coherence }

正常毛细血管网把红细胞流量按局部代谢需求分配，并通过薄而选择性的内皮屏障完成交换，基础结构见[微循环与毛细血管交换](../blood/blood_vessel.md#microcirculation)。休克时，低灌流和炎症可损伤内皮糖萼及细胞连接，增加黏附分子表达和屏障通透性；白细胞、血小板、红细胞变形性、周细胞张力与微血栓又共同改变单根毛细血管的开放和流速。部分通路过快而来不及充分提取氧，邻近毛细血管却停流，于是平均血流尚可而组织内仍并存高流、低流与无流区。[^sepsis-endothelium]

屏障漏出使富含蛋白质的液体进入间质，扩大氧和底物的扩散距离；淋巴回流不足时，水肿又压迫低压微血管。肺内这一过程可破坏气血屏障和 V/Q 匹配，其他器官则出现间质压升高与细胞交换受限。它与低容量并不矛盾：全身总水量可以增加，血管内容量和有效回流却仍不足。修订后的 Starling 交换与水肿机制见[毛细血管交换](../blood/blood_vessel.md#capillary-exchange)和[水肿](water_electrolyte.md#edema)。

当升压和补充流量恢复了 MAP、CO 等宏观变量，毛细血管异质性仍可能持续，这种脱耦常称为血流动力学不一致性。相反，局部微循环读出也不能脱离全身压力和器官差异解释。休克评估需要寻找宏观目标、皮肤和器官灌流、代谢趋势是否朝同一方向变化，而不是宣告其中某一层“更真实”。

## 脓毒症的感染、宿主反应与器官功能 { #sepsis }

Sepsis-3 将脓毒症定义为感染引起的宿主反应失调所致、危及生命的器官功能障碍；它不是“感染加发热”，也不等同于所有炎症性休克。脓毒性休克是其中循环、细胞和代谢异常尤其显著、死亡风险更高的亚群。临床研究常以充分容量复苏后仍需血管活性药维持 MAP 至少 65 mmHg 且血乳酸高于 2 mmol/L 作为操作性识别标准，但这是用于人群界定的临床标准，不是对全部分子机制的定义，也不能用来排除标准形成前正在发展的脓毒性低灌流。[^sepsis-three][^septic-shock-criteria]

病原相关信号、受损细胞释放的 DAMP、补体和炎症介质可激活内皮与髓系细胞；同时，淋巴细胞凋亡、抗原呈递降低、抑制性受体上调和细胞功能耗竭可削弱抗感染能力。促炎、抗炎与免疫抑制并非所有患者依次经过的三个纯相位，而可在不同组织和时间窗并存。脓毒症因而不能简化为单向“细胞因子风暴”：宿主反应的强度、位置、持续时间和能否清除感染共同决定净后果。[^sepsis-immunity]

## 微血管炎症与凝血放大 { #immunothrombosis }

组织因子表达、凝血酶生成、血小板活化、补体和中性粒细胞胞外诱捕网可以把病原限制在局部微血管，这种免疫性血栓形成具有防御意义。休克和脓毒症中，内皮抗凝表型、蛋白 C 等调节通路与纤溶平衡受损，局部反应便可能扩展为广泛微血栓，进一步减少营养性灌流；凝血酶和血小板释放的介质又反过来增强炎症。正常止血系统的细胞表面组织方式见[凝血与抗凝边界](../blood/blood_hemostasis.md#anticoagulant-boundaries)。[^sepsis-dic]

弥散性血管内凝血（DIC）是这一失衡的系统性极端表现：广泛凝血活化和纤维蛋白形成可造成微血管阻塞与器官缺血，凝血因子和血小板消耗、纤溶改变又可增加出血。它不是每一种休克必经的固定晚期，也不能仅凭一个凝血检验定型；病因、动态实验组合、出血和血栓表型须共同判断。

## 灌流指标的机制与趋势判读 { #perfusion-assessment }

### 乳酸的生成、清除与判读 { #lactate }

组织氧输送低于需要时，丙酮酸氧化受限和细胞氧化还原状态改变可增加乳酸；然而应激性肾上腺素信号加速有氧糖酵解、炎症与线粒体代谢改变、肝肾清除下降以及某些药物同样会升高血乳酸。乳酸升高及其持续不降通常提示病情较重，连续变化也可帮助判断整体方向，但一个数值不能证明全身都在无氧代谢，机械地追求“乳酸正常化”还可能造成不必要的液体或循环支持。[^lactate-marker]

乳酸与 H$^+$ 的生成、缓冲和清除受不同通量控制；“乳酸性酸中毒”所见酸血症还取决于强离子、CO$_2$、肾脏调节与缓冲系统。严重酸血症会抑制心肌功能、改变血管对儿茶酚胺的反应，却又可能只是上游低灌流仍未解除的读出。应优先恢复病因相关的流量、氧合和代谢物清除，碳酸氢盐等处理取决于具体酸碱机制与严重度，并非所有休克的统一步骤，完整判读见[代谢性酸中毒](acid_base.md#metabolic-acidosis)。

### 静脉氧、皮肤、意识与尿量 { #multimodal-assessment }

混合静脉或中心静脉血氧饱和度反映全身氧输送与提取后的综合结果。低值可见于 CO 或氧含量不足而组织提取增加；正常或偏高却不能排除分布性休克，因为微循环分流、提取障碍和局部高低流量相抵可留下看似充足的平均静脉氧。两种采样位置也不能无条件互换，相关测量边界见[组织氧合评估](hypoxia.md#assessment)。

毛细血管再充盈、皮肤温度与花斑、意识变化和尿量提供不同器官与时间尺度的信息。少尿可由肾灌流和 GFR 下降、交感—RAAS—AVP 保水共同造成，也可受既有肾病、药物、梗阻和已经形成的急性肾损伤影响；脑功能变化还可能来自低氧、低／高碳酸血症、感染介质、药物或原发神经病变。单点“正常”不能否定休克，串联的变化及其对机制性干预的响应更有解释力。[^shock-guideline]

## 多器官功能障碍的耦合网络 { #mods }

多器官功能障碍综合征（MODS）描述的是急性病程中多个器官不能在没有支持的情况下维持稳态的动态状态，而不是若干器官彼此独立、同步完成不可逆坏死。低灌流与静脉淤血提供共同的循环压力；内皮漏出、免疫失调和微血栓跨越器官边界；代谢物、细胞因子、神经内分泌信号及细胞外囊泡又把一个器官的损伤传给另一个器官。[^organ-crosstalk]

例如，肺屏障损伤和通气支持可改变右心负荷、气体交换与肾血流；肾功能下降使酸、K$^+$、水和尿毒性溶质累积，反过来增加心肺负担；肠屏障、肝清除与免疫耐受改变会重塑全身炎症和代谢；脑病与镇静又影响自主调节、呼吸和活动。器官支持由此既能争取病因控制和修复的时间，也可能因正压通气、过高氧暴露、液体过负荷、肾毒性暴露或长期制动带来“第二击”。因此，支持技术的净效应具有明显的场景和剂量依赖性。

线粒体呼吸受抑、氧化还原和底物利用改变时，细胞可下调蛋白合成、离子转运和专门功能以压低 ATP 需求。这种代谢性停工可能暂时保存细胞，也会表现为器官功能下降；损伤持续则走向膜破坏和细胞死亡，恢复期又需要线粒体生物发生和组织重建。因而“器官功能差”不等于所有细胞已经坏死，“氧输送正常”也不能证明细胞能量转换已经恢复。[^mitochondrial-sepsis]

SOFA 评分用呼吸、凝血、肝、心血管、中枢神经和肾六个领域的可测变量描述器官功能障碍及其变化，适合把复杂病程压缩成可追踪的严重度轨迹。它不是休克或脓毒症的分子机制，也不是单个患者全部生理状态的替代物；机械通气、血管活性药、镇静以及既有慢性器官病都会影响得分。动态变化通常比脱离背景的单次总分更有意义。[^sofa]

## 休克逆转与上游机制检验 { #reversal }

休克处置的共同目标是尽快识别并解除可逆原因，同时维持足够的器官灌流：控制出血并补回实际丢失，控制感染源，解除机械梗阻，纠正严重氧合或血红蛋白不足，支持不能维持输出的心脏。升压药、正性肌力支持、机械循环支持、输血和液体都只在对应生理缺口中获得意义；它们改变的是压力、流量、氧含量或容量分布中的特定变量，不能互相替代。[^circulatory-shock][^shock-guideline]

“除心源性休克外都应快速大量补液”并不成立。任何类型都可能存在液体反应性，也都可能在追加液体后出现肺和组织水肿、静脉淤血或右心负荷增加；静态 CVP 不能预测这一反应。合理过程是提出一个明确的循环假设，以动态试验或实时每搏量／CO 变化判断能否增加有效流量，再用血压、皮肤灌流、尿量、意识、乳酸和静脉氧等多层读出确认净效果。没有单一终点能取代病因控制与反复评估。

同样，糖皮质激素不是所有休克的“膜稳定剂”，碱化治疗也不能替代恢复灌流和处理病因。任何支持若只改善监测数字而未恢复营养性血流、细胞代谢和器官功能，都需要重新审视；而即使宏观目标尚未完全正常，器官趋势持续改善也提示应避免无止境地把参数推向同一个固定值。
