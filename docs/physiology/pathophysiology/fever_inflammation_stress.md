# 炎症、发热与应激

感染、无菌性损伤、热负荷、失血、疼痛和心理威胁都可能打破原有稳态，却不会触发同一套固定反应。炎症首先在受累组织内组织识别、血管变化和细胞募集；当炎症信号进入循环并作用于脑、肝和内分泌系统时，可出现发热、病感行为和急性期反应；应激反应则按被威胁的变量重新分配注意、血流、底物和免疫活动。细胞内部还有处理蛋白质错误折叠、营养缺乏和氧化还原失衡的“细胞应激”。这些层次相互连接，但不能用“应激导致炎症、炎症导致发热”一条单线互相替代。

| 反应层次 | 主要输入与输出 | 适应意义与失代偿边界 |
| --- | --- | --- |
| 局部炎症 | PAMP、DAMP 或组织失衡；血流、通透性、白细胞和修复程序改变 | 限制威胁并清除受损成分；过强、持续或消退失败时损伤正常组织 |
| 发热与急性期反应 | 炎症介质传至脑和肝；体温效应器阈值、行为与血浆蛋白谱改变 | 重排宿主防御资源；同时增加能量、氧和水的需求 |
| 整合性应激 | 感觉输入、中枢评估和内环境误差；自主神经、HPA 轴及行为输出 | 应付现实或预期需求；反应不当、不能终止或反复失配时累积代价 |
| 细胞应激 | 蛋白质、营养、氧化还原、DNA 或细胞器稳态受威胁；翻译与转录重编程 | 暂时降低负荷并修复损伤；超过恢复能力时转向衰老、炎症或细胞死亡 |

## 局部炎症的识别、清除与修复 { #local-inflammation }

### 组织识别与血管反应 { #recognition-vascular-response }

组织驻留巨噬细胞、树突状细胞、肥大细胞、上皮和内皮等细胞通过模式识别受体感知病原体相关分子模式（PAMP），也能识别坏死细胞、细胞外基质破坏或代谢失衡产生的损伤相关分子模式（DAMP）。这些输入并不自动等于感染：微生物可引起炎症，无菌性梗死、创伤或晶体沉积同样可以；反过来，检测到一种炎症介质也不能单独确定刺激来源或组织损害程度。炎症反应的共同目标，是把血浆蛋白和效应细胞带到局部、限制威胁、清除受损结构并为修复创造条件。[^inflammation-concept]

组胺、前列腺素、白三烯、缓激肽、NO、细胞因子和补体片段等介质以不同时间尺度改变微血管。小动脉舒张提高局部血流，内皮连接和跨细胞转运改变使富含蛋白质的液体进入组织，血浆蛋白参与补体、凝血、抗体和蛋白酶抑制等反应。血管通透性增加造成的渗出液不同于单纯静水压升高形成的低蛋白漏出液；红、热、肿、痛和功能改变也只是多个机制汇合后的表现，并非每个组织都必须完整呈现五项经典体征。

### 白细胞募集的多步调节 { #leukocyte-recruitment }

炎症内皮表达选择素配体、黏附分子并呈递趋化因子，使循环白细胞依次经历捕获和滚动、趋化因子激活、整合素依赖的牢固黏附、腔内爬行与跨内皮迁移。不同组织、刺激和时相募集的细胞组合不同，不能把“先中性粒细胞、后单核细胞”当作所有炎症的固定钟表。循环白细胞的边集与组织迁移还会改变血常规，因此一次外周计数同时反映生成、储备释放、重新分布和消耗，不能直接换算为组织内细胞数。正常区室关系见[白细胞迁移](../blood/blood_cell.md#leukocyte-trafficking)。[^leukocyte-recruitment]

### 炎症消退的主动转换 { #inflammation-resolution }

清除刺激后，成功的急性炎症不会只靠促炎介质自然耗尽。继续募集受到抑制，中性粒细胞进入凋亡，巨噬细胞以 efferocytosis 清除凋亡细胞和碎片，脂质介质、细胞因子和代谢状态随之转向屏障恢复、基质重塑和组织修复。抑制炎症启动与推动炎症消退并非同义：前者减少反应输入，后者还要完成清除、修复和功能回归。刺激持续、清除不足或修复失衡时，反应可转成慢性炎症、纤维化或反复组织损伤。[^inflammation-resolution]

## 前列腺素介导的发热通路 { #fever-pathway }

发热由炎症信号改变体温调节网络。感染和组织损伤诱导 IL-1、IL-6、TNF 等信号，其中经充分验证的一条路径是细胞因子作用于脑血管内皮相关受体，诱导 COX-2 和微粒体 PGE 合酶-1 产生 PGE$_2$。PGE$_2$ 作用于视前区 EP3 受体相关神经元，解除对下游交感产热回路的抑制，于是皮肤血管收缩、寻热、战栗和非战栗产热被重新招募。TLR 参与上游先天识别，T 细胞受体属于适应性免疫识别，两者在发热通路中的层级和作用不同。[^fever-neural]

传统“调定点上移”能够简洁解释畏寒，却不应被理解为下丘脑保存并改写一个单独温度数字。更接近真实的表述是，多条体温效应器回路的阈值和增益被炎症—PGE$_2$ 信号移动。体温上升期，当前温度相对新阈值偏低，机体减少散热并增加产热；接近新的平衡区后，产热与散热重新匹配；炎症信号消退或前列腺素合成受抑时，阈值回落，皮肤舒张和出汗有助于退热。三阶段是常见轨迹而非每次发热必经的疾病分期，完整正常回路见[能量代谢与体温](../energy.md#fever-hyperthermia)。

## 发热、急性期反应与全身资源分配 { #systemic-inflammatory-response }

### 发热的情境依赖性效益与代价 { #fever-benefit-cost }

发热范围温度可以改变部分病原体复制、铁可用性、白细胞迁移和免疫细胞效应，并在多种动物感染模型中表现出宿主防御价值。然而“受调节”不等于“温度越高越有利”。升温、战栗、心肺活动和免疫合成增加能量与氧需求，出汗和通气增加水分丢失；幼儿、老年人、孕妇以及心肺或神经系统储备有限者的收益—代价关系也不同。发热不能因为在实验中影响免疫或肿瘤细胞，就被外推为普遍抗肿瘤治疗。[^fever-immunity]

发热时的高血糖、脂解和蛋白质周转由细胞因子、儿茶酚胺、糖皮质激素、进食减少和原发疾病共同塑造。升温、平台和退热各阶段的心率、通气、食欲、警觉与血压表现，均受容量、疼痛、药物、神经内分泌和原发病共同影响，其组合具有情境依赖性。发热相关失水与容量变化可回到[容量丢失](water_electrolyte.md#volume-depletion)判读，代谢通量接口见[糖与能量代谢紊乱](metabolic_disorders.md#glucose-flux)。

### 肝脏急性期合成与血浆蛋白谱 { #acute-phase-response }

局部炎症经 IL-6 等信号驱动肝细胞重排蛋白合成，并与发热、白细胞变化、食欲下降、铁隔离和内分泌反应共同构成急性期反应。CRP、血清淀粉样蛋白 A、纤维蛋白原、铁调素和多种补体／蛋白酶抑制因子属于常见正急性期反应物；白蛋白、转铁蛋白和转甲状腺素蛋白等可下降，称为负急性期反应物。“负”只描述浓度方向，并不表示这些蛋白具有促炎作用或缺乏生理价值。[^acute-phase]

急性期蛋白的浓度由合成、分布容积、毛细血管外漏、消耗、清除和肝功能共同决定。CRP 上升说明存在相应炎症信号，却不能单独区分细菌感染、无菌损伤、自身免疫病或肿瘤；白蛋白下降也不等于短期内必由营养摄入不足造成。判读应追踪病程和干预前后的变化，并与感染部位、器官功能及其他证据合并。

## 发热与高体温的干预边界 { #fever-hyperthermia-management }

高体温（hyperthermia）来自外界热输入、内源产热或散热障碍超过调节能力，或者调节效应器被药物、麻醉或神经损伤破坏；机体往往仍在尝试散热，并没有先经 PGE$_2$ 把温度效应器阈值上移。发热和高体温可以并存，也不能只靠一次体温读数区分，但二者的机制差异决定了处理方向：退热药抑制前列腺素通路，主要降低发热时被移动的阈值；真正高体温则必须尽快减少热输入和促进散热，单纯退热药不能解除上游热负荷。

发热阈值仍高时强行冰敷或酒精擦浴，可能诱发血管收缩、战栗、不适和额外产热；糖皮质激素虽可抑制多种炎症通路，也不是常规退热药。是否需要缓解发热应结合病因、痛苦程度、水合、年龄和器官储备，而不是只追逐一个体温数字。儿科发热处置共识通常强调以患儿的不适程度而非单独的体温读数决定对症退热，并反对为降温而常规擦浴；这一原则不能替代对低龄婴儿或严重疾病征象的及时评估。[^fever-guidance]

## 整合性应激的效应器募集 { #organismal-stress-response }

### 交感与 HPA 轴的重叠时间窗 { #sam-hpa-integration }

生理学中的 stress 不是刺激物本身，也不是“紧张”的同义词，而是系统感知到现实或预期需求与当前调节能力不匹配时形成的状态。低血糖、失血、寒冷、疼痛、感染、运动和心理威胁通过不同感觉通路与中枢评估网络进入调节系统；蓝斑参与觉醒和去甲肾上腺素能调制，却不是所有应激反应的唯一中枢。现代系统概念因此强调应激原特异的效应器模式，而不是 Selye 式无差别“全身总动员”。[^stress-concept]

交感神经和肾上腺髓质可在数秒内改变心率、血管张力、通气与底物动员。HPA 轴由下丘脑室旁核 CRH／AVP 输出、垂体 ACTH 和肾上腺皮质醇组成，通常在随后数分钟至小时显著改变转录、底物供给与免疫活动；两条通路在中枢、肾上腺和靶器官交叉，时间窗也重叠。低血糖常产生较突出的肾上腺素反应，直立、寒冷或主动防御可更偏向交感神经去甲肾上腺素；各类应激原也可同时募集交感与 HPA 轴，其相对权重和时间过程各异。正常效应器差异见[应激原特异性反应](../endo/endo_ad_medulla.md#stressor-specific-responses)与[HPA 轴](../endo/endo_ad_cortex.md#hpa-axis)。[^stress-human]

### 内分泌与免疫输出的背景依赖性 { #stress-effectors }

应激时的葡萄糖、脂肪酸和氨基酸通量由儿茶酚胺、皮质醇、胰高血糖素、胰岛素、生长激素以及当前进食和活动状态共同决定。AVP 的变化还受容量、渗透压、恶心和疼痛影响；β-内啡肽可随 POMC／ACTH 系统一同变化，其作用取决于具体受体、组织和时相。单次皮质醇、儿茶酚胺或血糖测量只能捕捉特定相位，也不能单凭一个升高值判断整个应激系统功能。

感染和损伤产生的细胞因子可激活病感行为、交感输出和 HPA 轴；糖皮质激素通过受体依细胞类型、剂量、时相和染色质背景调节免疫基因表达、迁移与反应终止。药理剂量糖皮质激素常有强抗炎和免疫抑制作用；内源脉冲则可能限制失控炎症，也可能在持续暴露、节律破坏或受体敏感性改变时造成防御与修复失配。[^glucocorticoid-immunity]

## 恢复、短期适应与累积负荷 { #allostatic-load }

短时应激反应通过改变工作点和资源分配维持关键变量，这正是变稳态（allostasis）所强调的“以变化取得稳定”。适应的成本不只来自反应很强，也可来自反应不足、启动过频、不能及时终止，或不同系统之间长期失配。反复暴露可以出现习惯化、敏化、昼夜与超日节律压平、受体敏感性改变或行为补偿，所以慢性应激不能定义为皮质醇始终高于某个阈值。[^allostasis]

变稳态负荷（allostatic load）是描述多系统长期代价的框架，而不是由一项化验直接诊断的疾病。睡眠、能量收支、社会环境、既往经历、遗传、年龄和当前疾病都会改变响应与恢复轨迹；同一应激原对不同个体或同一个体在不同阶段可以产生不同后果。判断适应还是失代偿，需要比较刺激前基线、反应幅度、持续时间、恢复速度和功能结局，这与[内环境运行范围](../internal_env.md#operating-range)的动态稳态框架一致。[^hpa-regulation]

## 细胞应激的负荷控制与修复 { #cellular-stress }

细胞应激描述的是细胞内稳态受威胁，不要求个体感到紧张，也不必伴随 HPA 激活。热和蛋白质变性可激活 HSF1，诱导 heat-shock protein 等分子伴侣以限制聚集并协助折叠；内质网错误折叠蛋白积累触发 IRE1、PERK 和 ATF6 三条 unfolded protein response（UPR）分支，分别改变 RNA 处理、翻译负荷、伴侣蛋白和降解能力。氨基酸缺乏、病毒双链 RNA、血红素不足及内质网应激还可经不同 eIF2α kinase 汇入 integrated stress response（ISR），暂时抑制总体翻译，却选择性促进 ATF4 等应激程序。[^cellular-stress-networks]

这些网络首先降低新负荷、回收受损成分并扩大修复能力；损伤持续、能量不足或蛋白稳态无法恢复时，UPR、ISR、氧化还原与线粒体信号才可能转向炎症、衰老、凋亡或其他死亡方式。局部细胞应激也能通过 DAMP、细胞因子和代谢物反过来放大组织炎症；不可逆损伤和再灌注机制由[细胞损伤与缺血再灌注](cell_injury.md)继续展开。
