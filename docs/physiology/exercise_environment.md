# 运动生理与整体适应

运动把一个明确的外部任务施加给全身：骨骼肌需要在特定时间内产生力、位移或功率，同时还要维持脑和心脏灌流、动脉压、血气、体温与体液组成。收缩肌的 ATP 周转可在数秒内增加许多倍，响应却不能只靠肌细胞完成。肺把 O$_2$ 带到交换面，循环输送 O$_2$ 与燃料并带走热和代谢产物，肝与脂肪组织调节循环底物，肾和内分泌系统在较慢时间尺度上守住容量与离子环境。运动因而是观察[动态稳态](internal_env.md#dynamic-homeostasis)的典型窗口：被调节的变量并非毫无波动，而是在不断改变的通量中仍保持可工作的范围。[^integrative-exercise]

同一项运动不会触发一套固定反应。绝对功率、相对强度、持续时间、参与肌群、动作方式、训练状态、营养、温湿度和海拔都会改变限制环节。以下讨论以健康人的急性运动和训练适应为主；疾病诊断、运动处方与急救处置不由本页承担。

## 供能途径从运动开始便共同工作 { #parallel-energy-systems }

ATP 是横桥解离、Ca$^{2+}$ 回收和膜离子梯度恢复的直接能量来源，但肌内 ATP 池很小，必须随消耗不断再生。磷酸肌酸在肌酸激酶反应中快速缓冲 ATP／ADP；糖原或血糖经糖酵解产生 ATP 和丙酮酸／乳酸；线粒体则氧化糖、脂肪酸、乳酸和部分氨基酸来源的碳。三条路线从收缩起始就并行运行，只是响应速度、容量和相对通量不同，不能按“短跑用磷酸原、中跑用糖酵解、长跑才有氧氧化”理解为依次接力。细胞内的反应位置与纤维表型见[肌细胞生理](muscle.md#muscle-energetics)。

运动功率突然升高时，ATP 需求立即出现，而肌 O$_2$ 摄取和线粒体氧化通量需要一段时间才能达到新的水平。其间的“氧亏”不是肌肉完全无氧，而是所需能量中较大部分暂由磷酸肌酸净分解和底物水平磷酸化补足；氧摄取动力学越快，这一缺口越小。停止运动后，O$_2$ 摄取也不会瞬间回到静息值：磷酸肌酸恢复、离子梯度重建、体温与儿茶酚胺尚高、乳酸和其他底物继续周转，共同构成运动后过量氧耗，不能把它全解释为“偿还乳酸氧债”。[^oxygen-kinetics]

### 燃料选择是连续变化的通量 { #exercise-fuel-selection }

较低至中等强度、持续时间较长的运动通常允许脂肪酸氧化承担较大比例；功率升高时，ATP 生成速率和快速募集纤维的需要通常提高肌糖原与血糖的相对贡献。训练可增加线粒体、毛细血管和脂肪酸氧化能力，使相同绝对功率下糖原消耗较慢；但同一人随时间延长、糖原降低、进食或禁食也会继续改变燃料组合。肌糖原因缺少葡萄糖-6-磷酸酶而主要服务本肌纤维，肝糖原与糖异生才可向血液输出葡萄糖，详见[糖原合成与分解](../biochem/glycogen.md#tissue-fates)。氨基酸氧化在多数运动中不是主力，却会随时程、能量和糖供应、训练与营养状态改变，不能写成恒为零。[^exercise-metabolism]

乳酸由乳酸脱氢酶可逆生成，即使供氧充足也持续产生和利用。快糖酵解纤维释放的乳酸可被氧化型肌纤维、心肌等摄取并氧化，也可到肝和肾参与糖异生；血乳酸浓度只是全身产生、交换、氧化和清除的净结果。强度增加时乳酸上升提示通量分配发生变化，却不证明局部“没有氧”，也不能把运动终止、迟发性肌肉酸痛或所有疲劳都归咎于乳酸。[^lactate-shuttle]

## 氧运输链连接肺、血液、心脏与肌肉 { #oxygen-transport-chain }

全身 O$_2$ 摄取可用 Fick 原理表示：

$$
\dot V\mathrm{O}_2=\dot Q\left(C_a\mathrm{O}_2-C_v\mathrm{O}_2\right),
$$

其中 $\dot Q$ 是心输出量，$C_a\mathrm{O}_2-C_v\mathrm{O}_2$ 是动静脉氧含量差。这个式子把空气到线粒体的串联系统压缩为两个可测项：心脏和血管要把含氧血送到活动肌，毛细血管—肌纤维界面及线粒体又要从血中提取和利用 O$_2$。最大摄氧量因此既可能受最大心输出量和动脉氧含量限制，也可能受肺气体交换、血流分配、肌毛细血管化与氧化能力影响；不能只凭一个器官的储备推断整体上限。泵血储备见[心脏的泵血功能](blood/blood_heart_pump.md#cardiac-output-reserve)，氧含量与组织卸载见[气体交换与运输](respiratory/gas_exchange.md#tissue-oxygen-exchange)。[^exercise-hyperemia]

递增运动中常见的几个“阈值”并不是同一个生物开关。气体交换转折和血乳酸转折来自不同测量，结果还受方案与判定法影响；临界功率则来自功率—可持续时间关系，近似分开可达到代谢稳态的重强度域与多项变量持续漂移的极重强度域。最大摄氧量描述可达到的最高整合氧通量，运动经济性描述完成给定外部任务所需的 O$_2$ 或能量。它们回答的问题不同。

| 指标 | 直接描述 | 判读时不能省略 |
| --- | --- | --- |
| 外部功率、速度或做功 | 任务输出 | 动作模式、坡度、阻力校准和技术效率 |
| $\dot V\mathrm{O}_2$ 与 $\dot V\mathrm{O}_{2\max}$ | 当前与最高整合氧摄取 | 测试方案、是否达到平台或其他终止标准、体型归一化方式 |
| 血乳酸、通气或气体交换转折 | 代谢与通气响应曲线的转折区 | 采样时点、判定算法、营养与训练背景；彼此不必完全重合 |
| 临界功率／临界速度与 $W'$ | 稳定域边界及其上的有限功容量模型 | 需要多次足量测试；参数依运动方式，$W'$ 不是独立的单一能量仓库 |
| 心率、主观用力与恢复曲线 | 内部负荷和感觉—自主反应 | 温度、血容量、药物、睡眠、情绪与既往负荷 |

临界功率之上，肌磷酸肌酸、无机磷酸、pH、血乳酸和 $\dot V\mathrm{O}_2$ 等可随时间继续改变，直至任务无法维持；其下并不等于“轻松”或可以无限持续，只表示一组关键变量有机会接近动态稳态。用单一“最大心率百分比”给不同个体划出同样的代谢域，常会把实际内部负荷混在一起。[^critical-power]

## 循环在肌灌流与动脉压之间分配有限能力 { #exercise-circulation }

运动开始前后，运动皮层与脑干的中央指令、肌机械与代谢感受传入共同提高交感活动并撤减心脏迷走影响。心率与收缩性增加，肌泵和呼吸泵促进静脉回流；搏出量的变化则取决于充盈、收缩性、后负荷、体位和训练状态。心输出量是心率与搏出量的乘积，两者彼此耦联，不能把“心率储备”和“搏出量储备”当成两份可直接相加的容量，也不存在超过某个通用心率后心输出量必然下降的固定阈值。

活动肌释放 K$^+$、腺苷相关代谢物和其他局部信号，并通过内皮、红细胞、机械压迫与传导性舒张共同扩大灌流。局部环境削弱交感缩血管效应，形成“功能性交感逸脱”，但交感作用没有关闭：大肌群运动时，若所有活动肌血管都达到最大舒张，心脏可能不足以同时供应并维持压力。保留一定缩血管能力，正是肌血流、其他器官灌流和动脉压之间的折中。[^exercise-hyperemia]

压力感受性反射在运动中继续工作，只是围绕升高的运行点调节；内脏和肾血流通常可相对减少，心肌血流随做功增加，活动肌获得更大份额。热负荷升高时皮肤也需要大量血流，于是散热与肌灌流进一步竞争。各器官份额随功率、肌群、体位、环境和血容量改变，不宜给出脱离条件的固定百分比。具体回路见[心血管活动调节](blood/blood_regulation.md#integrated-states)与[骨骼肌循环](blood/blood_organ.md#skeletal-muscle-circulation)。

## 通气追随运动状态而不只是追随血气 { #exercise-ventilation-integration }

运动开始后数次呼吸内通气便迅速增加，早于动脉血气出现足以解释全部变化的偏移。中央指令、肢体运动及Ⅲ／Ⅳ组肌传入提供前馈与快速反馈；随后 CO$_2$ 生成、H$^+$、K$^+$、体温、儿茶酚胺和化学感受反射共同微调输出。轻至中等强度的稳态运动中，肺泡通气常能使动脉 $P_\mathrm{O_2}$ 与 $P_\mathrm{CO_2}$ 接近静息范围，这不是呼吸系统“没有响应”，而是通气与代谢相互匹配的结果。[^exercise-ventilation]

心输出量增加使更多肺毛细血管开放并扩张，肺弥散能力随之提高；通气与灌流分布也会因深呼吸、体位和肺容积改变。较高强度时，乳酸相关 H$^+$ 由 HCO$_3^-$ 缓冲产生额外 CO$_2$，通气可陡增，口鼻处测得的 RER 也可能超过 1。此时 RER 不再是细胞底物呼吸商的简单镜像，不能据它计算一张精确的糖脂供能表。呼吸控制的时相与反馈详见[运动性通气](respiratory/regulation.md#exercise-hyperpnea)，间接测热的假设见[能量代谢测量](energy.md#energy-expenditure-measurement)。

## 热与体液约束会逐渐转化为循环负担 { #heat-fluid-strain }

肌肉把化学能转成外功的效率有限，其余能量主要成为热。同一外部功率下，动作经济性较低意味着代谢产热更多；环境温度接近或高于皮温时，辐射、传导和对流甚至可能向人体输入热，蒸发便成为主要散热途径。体热平衡的完整账本见[能量代谢与体温](energy.md#body-heat-balance)。

温热环境中，皮肤舒张把更多心输出量引向体表，出汗又从细胞外液带走低渗液体。若摄入不足，血浆容量下降、静脉回流和搏出量受限，维持同一心输出量需要更高心率，形成常称为心血管漂移的时间趋势；高湿、弱风或不透气衣物还会使大量汗液不能有效蒸发。反过来，过量饮用低溶质液体也可能使血 Na$^+$ 下降。汗率与汗 Na$^+$ 受个体、功率、热习服和环境影响很大，因此补液与盐摄入应依据具体暴露和实测趋势，而不是把一个固定体重下降百分比当作所有人的性能或危险分界。[^heat-acclimation]

## 疲劳是任务中多层限制的汇合 { #exercise-fatigue }

生理学上的疲劳至少要区分两件事：可测输出能力下降的“表现易疲劳性”，以及继续完成任务所需努力和不适不断增加的“感知易疲劳性”。两者会相互影响，却不是同一个指标。运动皮层驱动、脊髓运动神经元兴奋性、神经肌接头、肌膜与横管传导、Ca$^{2+}$ 释放、肌丝对 Ca$^{2+}$ 的反应、底物、无机磷酸和 H$^+$、局部灌流、体温及感觉反馈都可能贡献；相对权重取决于任务。[^fatigue-framework]

短时最大冲刺与长时间恒定功率运动由不同组合限制，单关节实验也不能直接代表全身运动。乳酸可周转并作为燃料，ATP 浓度通常也在彻底耗尽前受到保护；“乳酸堆积使肌肉酸痛”和“ATP 用完所以停下”都把多层系统压成了单因果。人在自定节奏任务中还会根据剩余距离、热感、呼吸困难、既往经验和目标调整输出，因此表现下降既包含器官能力，也包含对继续投入的调节。

## 训练把反复的短时扰动积累为结构适应 { #training-adaptation }

一次运动产生机械张力、Ca$^{2+}$、能量状态、氧化还原变化、代谢物和激素信号，并暂时改变转录、翻译与蛋白周转。只有这些急性脉冲反复出现且恢复与底物供应允许，才逐渐积累为可测结构和功能。骨骼肌在收缩时还释放 myokine／exerkine；其谱取决于运动方式、强度、时程、肌糖原和训练背景。运动中的短暂 IL-6 脉冲不等同于慢性炎症中的持续 IL-6 暴露，也不能把任何一个候选分子写成训练全部效应的单独信使。肌—器官通信的证据边界见[松果体、组织激素与器官内分泌](endo/endo_other.md#muscle-secretome)。[^myokine-crosstalk]

| 反复刺激的主要特征 | 常见适应方向 | 对相同绝对任务的意义 | 不能据此推出 |
| --- | --- | --- | --- |
| 持续或间歇的耐力负荷 | 线粒体与氧化酶增加、毛细血管化和燃料调节改善 | 氧摄取动力学可加快，乳酸与通气响应可右移，糖原使用更节省 | 所有纤维变成单一“慢肌”，或最大能力只由线粒体决定 |
| 反复大机械张力与渐进负荷 | 神经募集、协调、肌原纤维蛋白合成与肌纤维横截面积增加 | 最大力及一定范围内的功率提高 | 肌肥大与力量增长比例恒定，或只由一个激素控制 |
| 反复大肌群有氧训练 | 血浆容量、心室充盈与搏出量储备等改变 | 相同绝对功率下心率和相对循环负荷通常降低 | 静息心率足以代表所有心肺适应 |
| 反复技能和专项动作 | 感觉—运动预测、肌群协同与机械经济性改善 | 同一速度或动作的代谢成本可下降 | 适应会完整迁移到不同姿势、速度或收缩方式 |

训练遵循超负荷与特异性，也受恢复、营养、睡眠和停训影响。耐力与抗阻并非互斥开关，间歇训练也只是把功率和恢复按时间重新编排；实际表型由剂量、顺序、既往状态与个体反应塑造。因而比较训练计划时，应同时说明频率、强度、持续时间、动作类型、总量和恢复，而不只贴一个名称。[^training-adaptation]

## 环境改变同一任务的相对强度 { #environmental-exercise }

环境不是运动之外的附加变量，而会改变氧运输、热交换、浮力、压力和感觉输入。相同速度或功率在不同环境中可以对应完全不同的内部负荷。

### 热、冷与反复暴露 { #heat-cold-adaptation }

连续数日到数周的运动—热暴露可逐步形成热习服：血浆容量常先扩张，皮肤血流和出汗可更早、更有效地启动，汗液保盐增强，相同任务下心率与体温负担下降。适应程度取决于是否反复获得足够的体热和出汗刺激，停止暴露后又会逐渐衰减；它不是“习惯炎热”这一种感觉变化。[^heat-acclimation]

寒冷时，行为保温、皮肤血管收缩与战栗是主要防线，持续运动还可能让汗湿衣物和风冷增加后续热损失。人体反复冷暴露可出现冷觉和应激反应减弱的习惯化，也可能在某些方案下出现保温型或代谢型变化，但结果强烈依温度、介质、持续时间、体组成和既往暴露而异。不能把热习服的整齐模型原样套给冷适应，也不能把冷水浸泡与冷空气运动视为相同刺激。[^cold-adaptation]

### 高海拔与水下环境改变运输边界 { #altitude-diving-exercise }

高海拔气压降低，使吸入气和肺泡 O$_2$ 分压下降。急性暴露时，同一绝对功率需要更高通气和心率，动脉氧合及最大摄氧量通常下降，所以原本的“中等强度”可能变成更高相对强度。数日到数周的通气习服、体液调整与红细胞生成可改善氧运输，却不能立即恢复海平面表现；低氧训练对返回低海拔后的增益还受低氧剂量、铁状态、训练质量和个体反应影响，不应承诺统一效果。正常高原习服见[呼吸调节与环境适应](respiratory/regulation.md#high-altitude-acclimatization)，高原病与严重缺氧由[缺氧](pathophysiology/hypoxia.md)承接。[^altitude-performance]

水下运动同时引入浸水静水压、浮力、热传导和呼吸装置阻力；屏息潜水还受有限体内 O$_2$ 储备和 CO$_2$ 累积约束，压缩气体潜水则另有环境压、气体密度与减压相关问题。两者不能合并成一套“潜水反应”。本页只指出这些环境如何重排任务负荷，储氧、肺压缩和循环重分配见[潜水生理](respiratory/regulation.md#diving-physiology)。
