# 消化生理总论

消化系统把一餐食物从形态不一、分子复杂的外界材料，转化为能够跨上皮进入血液或淋巴的水、离子和小分子。这个过程不是一条只负责“分解食物”的流水线：消化管必须在推进与停留之间调节时间，在分泌与吸收之间调节腔内体积，在允许营养物通过的同时阻挡多数微生物与有害分子，还要把局部信息传给胰腺、肝胆系统、脑和其他代谢器官。

本页从这些共同约束出发，说明消化管的基本结构、功能通量与调节层级。各器官如何运动和分泌，见[消化道运动与分泌](motility_secretion.md)；食物分子如何被水解并跨上皮转运，见[消化与吸收](digestion_absorption.md)；胰液、胆汁和肝脏的门静脉后处理，见[肝胆与胰腺外分泌](hepatobiliary.md)。

## 消化管的上皮界面 { #alimentary-interface }

口腔、咽、食管、胃、小肠、大肠和肛管首尾相接，构成消化管；唾液腺、胰腺、肝脏和胆道则通过导管把分泌物送入其中。牙和舌参与机械加工，腺体提供水、电解质、黏液、酸、HCO$_3^-$、消化酶或胆汁成分。把后者称为“附属器官”只说明它们不属于连续管壁，并不表示功能次要。[^digestive-architecture]

消化管腔经口和肛门与外界相通，在拓扑上位于上皮屏障之外。食物已经吞入胃内，并不等于其中的营养物已经进入[内环境](../internal_env.md#fluid-compartments)；只有跨过上皮、进入组织间液、血液或淋巴，才完成对机体有意义的吸收。这个边界也解释了为什么消化管需要同时处理营养物、环境抗原、毒素和密集的微生物群。

从腔面向外，胃肠管壁可概括为黏膜、黏膜下层、肌层和浆膜或外膜。黏膜上皮直接面对内容物，固有层容纳毛细血管、淋巴管和免疫细胞，黏膜肌层可局部改变表面形态；黏膜下层提供较大的血管、淋巴和神经通路；外层环行肌与纵行肌改变管腔直径和长度。咽、食管近端及肛门外括约肌等部位含骨骼肌，使吞咽和排便的部分阶段能够接受随意控制；其余大部分管壁运动由平滑肌、间质细胞和神经网络共同组织。

区域差异是在这套共同壁层上形成的。食管重在快速、受保护的转运；胃兼具储存、酸化和研磨；小肠以环形皱襞、绒毛和微绒毛扩大反应与交换界面；结肠没有小肠式绒毛，主要回收剩余水盐、处理微生物发酵产物并形成粪便。共同壁层由此形成连续的区域特化，吸收通量也沿肠轴呈梯度分布。

## 运动、分泌、消化与吸收的通量耦联 { #coupled-fluxes }

运动改变内容物的位置、粒径和与上皮接触的时间。推进太快，酶解和吸收来不及完成；停留过久，又可能造成过度发酵、内容物脱水或微生物负荷改变。混合运动让底物接触消化液和刷状缘，括约肌与储库则把连续管道分成可配时的功能区。运动的意义因此不只是“把食物向下推”，而是在空间和时间上安排化学反应与跨膜运输。

分泌为这些反应建立液体和化学环境。水使内容物保持可流动，黏液降低摩擦并参与屏障，HCl、HCO$_3^-$ 和离子运输塑造区域 pH 与渗透条件，酶及酶原完成特定键的水解，胆盐和磷脂则帮助疏水性脂质分散。不同分泌液不具备同一套功能：胆汁不是消化酶液，结肠也不靠分泌一组重要食物水解酶完成吸收。所谓“消化液”应理解为来源、组成和流量均可调的一组分泌物。[^integrated-processes]

消化把大分子加工为可被转运的产物，吸收再把这些产物以及维生素、水和电解质送过上皮。多数糖、氨基酸等水溶性产物经毛细血管进入门静脉，长链脂质多先装入乳糜微粒并经乳糜管和淋巴回到循环。结肠微生物还能把宿主酶不能降解的部分底物转化为短链脂肪酸等可吸收产物，但这不意味着微生物替代了宿主消化系统。

未吸收食物残渣、微生物量、脱落细胞和消化道分泌物最终随粪便排出。这个过程可称排便或未消化物的清除，却不宜与肾脏清除血中代谢终产物的“排泄”完全等同；胆红素、胆固醇衍生物等经胆汁进入粪便，才体现消化系统参与全身物质净清除的一面。

## 肠神经系统的局部感觉—效应回路 { #enteric-control }

消化管壁不是被中枢神经逐次遥控的被动效应器。肠神经系统由神经元和胶质细胞组成，肌间神经丛更直接连接平滑肌、括约肌与间质细胞，黏膜下神经丛更接近上皮、腺体和局部微循环。内在感觉神经元接收牵张、腔内化学和黏膜状态，中间神经元沿肠轴传播信息，兴奋性或抑制性运动神经元再改变肌肉、分泌细胞和血管。局部反射因此可以在不绕行脑和脊髓的情况下调节一段肠管。[^enteric-system]

“能够独立形成局部反射”并不等于肠道脱离中枢。迷走和盆神经副交感通路、交感通路、脊髓感觉通路以及脑干和前脑网络共同构成长反射。食物的视觉和气味可在食物到达胃以前预调分泌，吞咽、胃扩张和十二指肠负荷又不断更新反馈；疼痛、应激、睡眠和行为状态也能改变胃肠输出。副交感活动常提高运动或分泌，交感活动常抑制肠神经传递并收缩内脏血管，但两者均可依部位、受体和回路产生兴奋或抑制效应，不能概括成沿全消化道等幅反向的两只开关。[^extrinsic-control]

局部神经、外来神经、肠内分泌信号、免疫介质和肌源性节律在同一组织中相互作用。所谓“脑—肠轴”正是这些双向通路的总称，而不是某一种肽或一条迷走神经；它连接感觉、情绪与摄食行为，也连接消化运动、上皮屏障、微生物生态和代谢状态。

## 肠内分泌信号 { #enteroendocrine-signaling }

肠内分泌细胞散在于胃肠上皮，只占上皮细胞的一小部分，却沿消化管形成广泛的感知网络。开放型细胞的顶端微绒毛可接触腔内容物，闭合型细胞不直接到达腔面，更多接收旁分泌、神经或血侧信息。葡萄糖、氨基酸、肽、脂肪酸、胆汁酸和微生物代谢物可通过营养物转运体、G 蛋白偶联受体和离子通道改变细胞内 Ca$^{2+}$ 或 cAMP，促使基底侧释放肽或胺类信号。[^enteroendocrine-sensing]

传统教材常按主要分泌物把这些细胞命名为 G、I、K、L、S、D、M 等类型。这套名称便于定位经典激素，却不是互不重叠的细胞名册：单个肠内分泌细胞可共表达多种肽，同一标志细胞在不同肠段也可具有不同转录与分泌谱。APUD 强调摄取胺前体和脱羧的历史分类，“脑—肠肽”强调某些信号在肠道与神经系统双重分布；两者都不能替代现代的细胞谱系、区域和受体—靶器官关系。胰岛 A、B、PP 等细胞则属于[胰岛内分泌](../endo/endo_islet.md)，不应因为同样使用字母命名就全部并入胃肠上皮细胞。[^enteroendocrine-classification]

| 主要信号 | 典型来源与释放线索 | 主要生理接口 | 调节条件与限制 |
| --- | --- | --- | --- |
| 胃泌素 | 胃窦为主的 G 细胞；肽、氨基酸、胃扩张及迷走—GRP 通路 | 经 ECL 细胞组胺放大泌酸，并支持胃黏膜生长和餐后运动 | 腔内酸化通过 D 细胞生长抑素等形成负反馈，净运动效应不能压成单向箭头 |
| CCK | 十二指肠、空肠 I 细胞；长链脂肪酸和蛋白消化产物 | 加强胰酶分泌、胆囊排空，协调胃排空并参与饱腹信号 | 人胰腺腺泡的直接受体作用与迷走介导效应需区分 |
| 促胰液素 | 十二指肠 S 细胞；酸性食糜是主要刺激 | 加强胰管和胆管 HCO$_3^-$／液体分泌，协助中和胃酸 | 不是把全部胃肠运动无条件关闭的“抑制激素” |
| GIP | 近端小肠 K 细胞；葡萄糖、脂质等营养物 | 作为肠促胰素增强葡萄糖依赖性胰岛素分泌 | 现代名称为葡萄糖依赖性促胰岛素多肽，不能用旧称预设其主要作用是抑胃 |
| GLP-1、PYY | L 细胞在远端肠道较丰富但并非只存在于回肠、结肠；营养物及部分微生物代谢物 | GLP-1 参与肠促胰素效应；二者共同参与远端肠制动、食欲和胃排空调节 | 来源沿肠段呈梯度，不能把一个细胞标签等同一种唯一肽 |
| 胃动素 | 十二指肠、空肠的胃动素细胞（传统 Mo／M 细胞）；空腹期呈周期性变化 | 参与人类消化间期移行性运动复合波 | 这里的 M 不是淋巴滤泡相关上皮的微皱褶细胞；进食后胃动素受到抑制，MMC 也不是由它单独生成 |
| 生长抑素 | 胃肠道和胰岛 D 细胞；局部酸、营养与神经信号 | 以旁分泌和内分泌方式抑制多种腺体及内分泌细胞 | 不同部位、分子形式和靶细胞不同，不能视为全消化道统一刹车 |
| 胃饥饿素 | 胃底 X/A-like 细胞为主；空腹与进食状态相关 | 参与摄食、GH 释放和胃肠运动的全身协调 | 浓度与餐食的关系受营养组成和代谢状态影响，不是单一“饥饿开关” |

这些信号可经血液到达远处靶器官，也可在邻近细胞、迷走感觉末梢或肠神经元处先行作用。5-羟色胺、组胺、前列腺素、NO、VIP 和许多神经肽又跨越“激素、旁分泌介质、神经递质”的简单双分。判读一个信号需要同时明确来源细胞、释放状态、传播范围和靶受体。[^gut-hormone-map]

## 进餐后的重叠调节 { #meal-response }

头期、胃期和肠期可以描述进餐信号首先出现的位置，但真实调节在时间上广泛重叠。看见、闻到和咀嚼食物时，脑干自主回路已经预调唾液、胃和胰腺分泌；食团进入胃后，扩张、肽类和腔内酸度改变局部反射与胃泌素—组胺—生长抑素网络；食糜进入十二指肠后，酸、脂肪、氨基酸和渗透负荷又通过促胰液素、CCK、神经反射等，把胃输出与中和、酶解和吸收能力匹配起来。

营养物到达更远端的肠段后，GLP-1、PYY、神经与局部信号可减慢近端输入，给尚未处理完的负荷留出时间。餐后状态还伴随内脏血流增加、胰岛素及其他全身代谢信号变化；门静脉把多数水溶性吸收产物先送到肝脏，淋巴则把乳糜微粒绕过肝门静脉首过送入体循环。进食结束后，消化管不会完全静止，而会逐渐切换到包括移行性运动复合波在内的空腹程序。[^meal-integration]

因此，一餐后的消化反应不能分割成互不相干的“神经期”和“激素期”，也不能给各阶段分配跨食物、跨个体不变的百分比。它更接近一组沿消化管逐步展开的反馈域：上游准备和释放，下游测量负荷并回控上游，同时把吸收速度报告给胰岛、肝脏和脑。

## 黏膜的选择性吸收与防御 { #mucosal-barrier }

消化管上皮必须允许大量营养物、水和电解质定向通过，却限制微生物、毒素和多数完整抗原进入组织。黏液与糖萼在腔面形成空间缓冲，紧密连接、黏着连接和桥粒维持细胞间封闭与组织强度，极性转运体决定经细胞路径，紧密连接蛋白则调节选择性的细胞旁通路。上皮细胞持续更新，杯状细胞提供黏蛋白，潘氏细胞等释放抗菌分子，固有层免疫细胞和分泌型 IgA 参与识别与隔离。屏障不是一堵完全不透的墙，而是具有分子选择性、能够感知和修复的动态界面。[^intestinal-barrier]

共生微生物与宿主在这层界面两侧持续交换代谢物和信号。它们可竞争生态位、改造胆汁酸、发酵复杂碳水化合物并影响上皮和免疫反应；宿主则以运动、分泌、氧化还原环境、黏液和免疫选择塑造其栖息地。健康稳态不是“免疫系统不理会肠菌”，也不是把一切微生物信号都解释为炎症，而是在隔离、取样、耐受与清除之间保持条件性的平衡。具体免疫效应由[免疫学](../../immunology/index.md)承接，屏障破坏、感染和炎症的病理后果见[病理生理学](../pathophysiology/index.md)。
