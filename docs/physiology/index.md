# 生理学

生理学研究生命活动怎样发生、怎样被协调，以及生物体怎样在变化的环境中继续工作。离子通道为何产生电信号，心脏怎样把压力转化为血流，肾脏如何凭借滤过和选择性转运调节体液，运动时多个器官又怎样重新分配氧、底物和热量——这些问题跨越分子、细胞、组织、器官和整体，不能由一张“正常值”表或一组器官名称回答。生理学的辨识度正在这种跨层级整合：它既追踪局部机制，也检验这些机制放回完整生物体后能否解释可观察的功能。[^physiology-scope]

本栏目以人和其他动物的共同生理原则为主。人体生理提供临床和健康问题的接口，比较生理则让不同体型、生活史和环境中的解决方案彼此映照；两者共享结构—功能、通量、反馈和系统整合等解释框架。具体疾病机制进入[病理生理学总论](pathophysiology/index.md)，神经回路、免疫效应和细胞器装置分别由神经、免疫和细胞栏目展开，避免把“与生理有关”误作一个没有边界的收纳箱。

## 功能问题需要落实为可检验的机制 { #function-and-mechanism }

“某个结构有什么功能”可以是研究的起点，却不是机制解释的终点。完整解释至少要说明参与者、相互作用、方向、条件和时间顺序：例如心输出量增加可以由心率、每搏量或两者改变造成；每搏量又受充盈、收缩性和射血负荷影响。只观察结果，无法知道是哪条路径改变；只找到一个相关分子，也不能证明它足以解释完整器官的输出。

结构与功能的关系是双向的。肺泡和毛细血管形成面积大、距离短的交换界面，使气体扩散成为可能；长期机械负荷、激素或活动方式又会改变组织结构，从而移动此后的功能边界。分子构象、细胞极性、组织几何和器官连接方式都可能成为机制的一部分，不能把解剖当作生理之前已经结束的静态背景。[^core-concepts]

生理量还必须附带测量定义。血压是压力，心输出量是单位时间的容积流量，血容量是存量，氧输送则同时依赖血流和动脉氧含量；这些指标彼此关联，却不能互换。浓度也不等于全身总量：血浆 Na$^+$ 浓度主要反映水与可交换钠、钾的相对关系，不能单独报告体内钠储量。先问“测到的究竟是什么”，通常比先背数值更接近生理推理。

## 层级之间既有还原关系也有涌现性质 { #levels-and-integration }

生理过程可以沿层级向下拆解。动作电位可还原到膜电容、离子梯度以及电压门控通道的电导变化；肌肉产生的力可继续追到 Ca$^{2+}$ 信号、调节蛋白和横桥循环。这种还原帮助定位必要环节，也让药理或遗传扰动有明确靶点。

向下拆解却不能自动给出整体答案。心肌细胞的收缩性并不单独决定全身血流，后者还取决于静脉回流、血管阻力、器官床的并联分配以及神经—体液调节；血糖也不是胰岛素一个变量的直接读数，而是摄入、肝脏输出、组织摄取和肾脏处理共同形成的净结果。组织间耦联、空间结构和反馈回路会在较高层级产生新的约束。美国生理学会据此把组织层级、质量守恒、梯度驱动、细胞通信、稳态和系统整合列为贯穿不同器官的核心概念。[^core-concepts]

比较不同动物时，这一框架尤其重要。相同任务未必只有一种结构方案：气体交换可以借助鳃、肺或气管系统，体温和渗透调节也会随环境与生活史采用不同组合。比较生理的价值不是把人类机制换成更多物种名录，而是借自然差异检验哪些物理约束普遍存在，哪些调节方式只在特定谱系和生态条件下成立。

## 通量与守恒连接体内各区室 { #flux-and-balance }

动物是持续与环境交换物质和能量的开放系统。把研究边界画成一个区室后，其中某物质的变化可先写成最简单的账本：

$$
\frac{dQ}{dt}=\sum \dot Q_{\mathrm{in}}-\sum \dot Q_{\mathrm{out}}+\dot Q_{\mathrm{production}}-\dot Q_{\mathrm{consumption}},
$$

其中 $Q$ 是区室内的量，各项分别表示进入、离开、生成与消耗速率。稳态时左侧可接近零，但右侧每一项仍可能很大；这正是“动态稳定”与“没有流动”的区别。质量守恒可用于体液、气体、离子和底物，能量与热量也需要相应的收支边界。[^mass-balance]

通量由驱动力与通路性质共同决定。溶质沿化学势或电化学势移动，气体沿分压梯度扩散，容积流克服阻力由压力差驱动；膜、上皮和血管网络则决定可用路径、面积、距离和阻力。由此可以从[跨膜转运与渗透](membrane_dynamics.md)一路连接到[血液与循环](blood/index.md)、[呼吸](respiratory/index.md)、[消化](digestive/index.md)和[泌尿](urinary/index.md)：器官名称不同，反复出现的仍是区室、梯度、通量与守恒。

## 稳态调节的是动态运行范围 { #homeostatic-regulation }

多细胞动物把多数细胞置于相对受控的细胞外液环境中。Claude Bernard 在十九世纪强调内部环境对自由生命的重要性，Walter Cannon 随后以 *homeostasis* 概括维持这种稳定的协调过程；William Harvey 更早对血液循环作出的定量与实验论证，则展示了怎样用整体物质账本反驳“血液被器官不断消耗”的旧模型。这些工作不是三句孤立的名人标签，而是把生理学逐步转向可测量的循环、调节和系统因果。[^physiology-history]

稳态并不要求变量恒定在单一数值。体温有昼夜变化，动脉压随姿势和运动改变，餐后血糖和激素水平也会按状态有组织地移动。更准确的问题是：哪些变量受到调节，允许在什么范围和时间尺度内变化，感受器实际读取什么信号，效应器怎样改变通量，系统又付出了什么代价。[内环境与稳态](internal_env.md)将进一步区分受调变量、设定点或运行范围、负反馈、正反馈与前馈。

负反馈能够减小扰动后的偏差，但真实回路存在延迟、增益限制和多个目标之间的冲突。运动时维持动脉压、活动肌灌流和散热会争用有限循环能力；禁食时守住血糖又会改变脂肪和蛋白质通量。生理调节因此常是有优先级的折中，而非所有指标同时回到静息值。

## 观察、扰动与模型共同建立因果证据 { #experimental-evidence }

生理学是一门实验科学。连续记录可以揭示变量的时间关系，选择性扰动则检验某一环节是否必要或足以改变结果；药物、神经刺激、基因改变、负荷变化和环境暴露都可成为扰动，但其特异性、剂量、代偿和脱靶效应必须同时评估。模型与方程把隐含假设写出来，预测若机制成立应当观察到什么，再由新数据修正模型。Harvey 对循环的论证便结合了解剖观察、结扎实验、流向证据与数量估算，而不只是一次“看见血液流动”的发现。[^harvey-systems]

研究层级改变能回答的问题。在体研究保留循环、神经、内分泌和行为的耦联，却较难隔离单一机制；离体器官或组织保留部分空间结构，同时失去许多全身输入；体外细胞和分子体系便于控制条件与解析局部反应，却可能远离生理浓度、力学环境和成熟表型。计算模型、无创人体测量和临床自然实验又提供其他证据窗口。不同模型不是从“低级”到“高级”的固定阶梯，而是以不同代价换取控制度、可测性与整体相关性。[^experimental-models]

急性与慢性设计也不能只按持续时间贴标签。快速扰动常暴露已有蛋白、离子储备和反射回路，长期负荷还会募集转录、细胞更新和结构重塑；麻醉、手术创伤、昼夜相位、营养状态和取样过程本身都可能改变被测系统。具体实验操作、动物伦理和研究设计规范由实验栏目承接，本页只保留判读模型边界所需的概念。

## 时间尺度把即时响应连接到适应与生命历程 { #time-scales }

同一生物体内并行着相差许多数量级的过程。离子通道门控和动作电位发生在毫秒至秒，神经反射和快速分泌在秒至分钟改变器官输出，水盐平衡、代谢状态和基因表达可跨越小时至数日，训练、妊娠、发育和衰老则继续改变数月至数十年的结构与储备。一个时间点上的“正常”读数，可能来自尚未受扰、正在代偿或已经建立新状态三种完全不同的过程。

因此，生理结论必须附着在时相上。运动开始前的前馈动员、运动中的反馈调节、停止后的恢复以及反复训练后的结构适应不能合并成一个箭头；出生、青春期、妊娠和衰老也不宜仅用成人参考范围加以判断。[运动生理与整体适应](exercise_environment.md)和[生长、发育与衰老](growth_development.md)分别展示短时任务与生命历程怎样重写系统工作点。

## 正常生理提供机制参照而非固定模板 { #normal-and-pathophysiology }

生理学常研究健康状态，却不意味着存在一个适用于所有个体和情境的“标准人体”。年龄、遗传背景、体型、训练、昼夜节律、海拔、饮食和测量方法都会改变分布；实验样本的平均值也不等于每个个体的最佳值。参考区间描述特定人群和方法下的统计分布，生理机制则解释一个数值如何形成、何时改变以及系统还能否应对额外负荷。

病理生理学在这条机制链上继续追问原发扰动、补偿、储备和失代偿。静息值落在参考区间内并不能证明储备完整，偏离一次参考区间也不能单凭数值确定疾病。药理学关注外源分子怎样改变这些机制，解剖学提供结构边界，细胞与分子生物学解析装置，临床医学则需要把机制与个体证据、风险和处置结合。边界清楚以后，跨学科连接才不会沦为重复抄写。
