# 生理学

## 写之前的碎碎念

生理学是第二个开的新坑。实际上的原因是博主大二上的专业课只报了生化和生理（逃）。生理学的教材种类非常多，国内的优秀教材基本上分成以下2类：

- 一类是**医学的人体生理**，如人卫的五年制/八年制《生理学》，也是生物竞赛的一般参考用书；
- 另一类是**综合的（动物）生理学**，代表有早年梅岩艾老师翻译的《生理学原理》、陈守良老师的《动物生理学》，及一脉相传的101新教材《生理学原理》，是北大生理学课程的参考用书。（当然还有四不像的王左《人体与动物生理学》orz）

我的笔记会尝试综合这两类各自的优势，以补充背景或增强理解。

医学的生理会有很多药理与病理的交叉，在神经生理上解剖的内容会更强，因此我会在一些相关部分引入医学其他领域的专业内容，如在受体和神经递质等部分引入「药理学」知识，在神经开篇引入神经系统的「系统解剖学」知识等。

综合的尤其是北大版的生理会有很大篇幅讲解前序的电生理，会有比较多的数学部分，也会讲很多有趣的知识发现的时代背景，我会选择性加入这部分内容。
