# 肾上腺髓质内分泌

肾上腺髓质位于皮质包围的腺体中央。它不依靠一条“下丘脑—垂体—靶腺”轴等待促激素，而由交感节前神经直接把中枢状态传给嗜铬细胞，再把肾上腺素和较少的去甲肾上腺素释放入血。于是同一类儿茶酚胺可在交感神经末梢充当局部递质，也可从髓质进入循环成为激素；两种路线在到达距离、浓度时程和靶组织上并不等价。

本文以人体正常生理为主，从髓质的神经内分泌结构、儿茶酚胺合成和颗粒胞吐展开，再说明受体组合如何协调循环、通气与燃料供应。肾上腺皮质的类固醇轴见[肾上腺皮质内分泌](endo_ad_cortex.md)，交感神经对心血管的直接调节见[循环调节](../blood/blood_regulation.md#circulating-hormones)。

## 髓质是接受节前交感输入的神经内分泌组织 { #neuroendocrine-organization }

嗜铬细胞与交感神经元都属于神经嵴衍生的交感—肾上腺谱系。把嗜铬细胞称为“改造的交感节后神经元”有助于理解它们为何接受胆碱能节前纤维、具有可兴奋膜并以 Ca$^{2+}$ 依赖方式胞吐，却不是完整的发育结论。现代谱系追踪显示，哺乳动物相当一部分嗜铬细胞来自沿节前神经迁移的、神经嵴来源的 Schwann 细胞前体；它们形成无长轴突的内分泌细胞，把分泌物交给丰富的窦状毛细血管。[^chromaffin-development]

髓质接受腹腔神经等内脏神经中的交感节前纤维。每个嗜铬细胞可直接获得胆碱能突触输入，因此肾上腺内没有必要先经过一枚普通的交感节后神经元。皮质毛细血管的血液又向心流入髓质，使嗜铬细胞暴露于较高的局部皮质醇浓度；皮质与髓质的相邻关系由此成为调节儿茶酚胺表型的功能结构，而不只是解剖分层。[^adrenal-organization]

| 输出路线 | 主要化学信号 | 空间与时程特征 |
| --- | --- | --- |
| 交感节后神经末梢 | 以去甲肾上腺素为主 | 在神经—效应器接头形成较高局部浓度，主要由神经元再摄取终止 |
| 肾上腺髓质 | 以肾上腺素为主，兼有去甲肾上腺素 | 随血到达多器官，受稀释、组织摄取和代谢影响，作用短暂但分布广 |

血浆去甲肾上腺素相当一部分来自交感末梢释放后的溢出，不能把血中两种儿茶酚胺都当作髓质分泌量的直接读数。反过来，人体循环肾上腺素主要来自肾上腺髓质，因此它更能代表髓质的激素输出。[^catecholamine-secretion]

## 儿茶酚胺合成在胞质与分泌颗粒之间往返 { #catecholamine-biosynthesis }

儿茶酚胺路线从 Tyr 开始。胞质中的酪氨酸羟化酶（TH）以四氢生物蝶呤和 O$_2$ 为辅因子生成 L-DOPA，这是通量控制最重要的入口；芳香族 L-氨基酸脱羧酶随后以 PLP 为辅酶生成多巴胺。多巴胺经囊泡单胺转运体进入分泌颗粒，颗粒腔内的多巴胺 $\beta$-羟化酶再以铜和抗坏血酸参与反应，生成去甲肾上腺素。各步反应及辅因子的生化关系见[氨基酸及其衍生物的合成](../../biochem/aa_synthesis.md#neurotransmitters-hormones-pigments)。[^catecholamine-biosynthesis]

生成肾上腺素还要多一次跨膜往返：去甲肾上腺素离开颗粒进入胞质，苯乙醇胺 *N*-甲基转移酶（PNMT）用 S-腺苷甲硫氨酸提供甲基，产物再由囊泡单胺转运体装回颗粒。皮质血流带来的高浓度皮质醇维持 PNMT 表达，使多数人肾上腺髓质以肾上腺素为主要终产物；不同嗜铬细胞的酶表达仍有异质性，不能说每个细胞都按同一比例共同分泌三种儿茶酚胺。

颗粒以嗜铬粒蛋白、ATP、Ca$^{2+}$ 及多种共存肽缓冲和浓缩儿茶酚胺。TH 的磷酸化可在较短时间内解除部分终产物抑制，反复或持续神经输入还可提高 TH、DBH 等酶的表达，从而补回已释放的储备。原素材所说“ACTH 促进儿茶酚胺合成”应拆开理解：ACTH 首先作用于皮质，皮质醇再支持 PNMT 等髓质表型；它不是每次急性颗粒释放所必需的直接促分泌激素。[^catecholamine-secretion]

## 神经输入把膜去极化转成颗粒胞吐 { #stimulus-secretion-coupling }

节前末梢释放的 ACh 主要激活嗜铬细胞烟碱型胆碱受体，引起阳离子内流和膜去极化；电压门控 Ca$^{2+}$ 通道开放后，局部 Ca$^{2+}$ 升高驱动 SNARE 等融合装置，使致密芯颗粒胞吐。毒蕈碱型受体、PACAP 等共递质和细胞间缝隙连接会调节响应，尤其在高频或持续输入时帮助维持分泌与合成，但不能取代“ACh—烟碱受体—去极化—Ca$^{2+}$—胞吐”这条主线。[^stimulus-secretion]

低血糖、动脉压力或有效循环容量明显下降、缺氧、较强运动、疼痛、寒冷和情绪性威胁都可能招募交感—髓质输出。中枢并非只测量一个“应急强度”：来自下丘脑、脑干和边缘系统的不同网络按代谢、循环、温度与行为情境组织节前神经元，所以不同刺激可产生不同的肾上腺素、交感去甲肾上腺素和 HPA 轴组合。

儿茶酚胺对自身合成酶和嗜铬细胞受体确有局部调节，但不能据此画成一条类似垂体—靶腺轴的简单循环负反馈。一次分泌终止主要依赖上游节前活动减弱、颗粒释放停止，以及循环中的快速摄取和代谢；这与皮质醇经受体反馈 CRH、ACTH 的机制不同。

## 肾上腺素能受体把共同信号译成不同效应 { #adrenergic-receptors }

肾上腺素和去甲肾上腺素都能结合多类肾上腺素能 G 蛋白偶联受体，但相对效力、局部浓度和受体分布不同。下表只给出解释正常整体反应时最常用的近似，不能把每一行当成某种儿茶酚胺独占的器官清单。

| 受体与主要耦联 | 代表性靶点 | 生理响应线索 |
| --- | --- | --- |
| $\alpha_1$—G$_{q/11}$ | 血管及部分内脏平滑肌、肝细胞 | 平滑肌收缩；促进肝糖原分解等代谢信号 |
| $\alpha_2$—G$_{i/o}$ | 神经末梢、胰岛细胞、部分血管 | 限制递质释放和 cAMP；抑制胰岛素分泌等 |
| $\beta_1$—G$_s$ | 心脏、肾小球旁颗粒细胞 | 增加起搏、传导与收缩；促进肾素释放 |
| $\beta_2$—G$_s$ | 支气管、部分血管、骨骼肌与肝 | 平滑肌舒张；促进糖原分解和燃料动员 |
| $\beta_3$—G$_s$ 等 | 脂肪细胞、膀胱逼尿肌 | 参与脂解、产热和逼尿肌舒张，物种及脂肪库差异明显 |

受体表不能单独预测血压。例如肾上腺素可同时用 $\beta_1$ 增强心脏泵血、用 $\beta_2$ 舒张部分骨骼肌血管，并在浓度更高或某些血管床中显出 $\alpha_1$ 收缩；压力感受反射和局部代谢又会改变净结果。去甲肾上腺素通常更显著地增加外周阻力，但循环水平、神经释放位置和已有血管张力仍决定实际响应。[循环调节](../blood/blood_regulation.md#circulating-hormones)将这些受体效应放回压力反馈与器官血流背景。

## 循环、通气与燃料通量被同时重排 { #integrated-effects }

心脏 $\beta_1$ 信号提高心率、房室传导、收缩和舒张速度，静脉与阻力血管的 $\alpha_1$ 信号则有助于维持中心充盈和动脉压力；支气管平滑肌 $\beta_2$ 信号降低气道阻力。人体气道平滑肌的直接交感神经支配较稀疏，循环肾上腺素因而是重要的 $\beta_2$ 输入，但完整通气仍由呼吸神经驱动、气道力学和局部介质共同决定，见[呼吸生理总论与肺通气](../respiratory/index.md#airway-resistance)。

肾上腺素在肝脏促进糖原分解并支持糖异生，在骨骼肌经 $\beta_2$ 信号加快糖原分解。肌糖原生成的葡萄糖-6-磷酸主要在肌内糖酵解供 ATP，骨骼肌缺少向血液大量释放游离葡萄糖的葡萄糖-6-磷酸酶；部分乳酸可进入肝脏再利用。因此“肝糖原维持血糖”和“肌糖原支持收缩”虽受同一激素动员，物质去向不同。[糖异生](../../biochem/gng.md#regulation)说明肝肾生成葡萄糖的底物和能量约束。

脂肪组织中，$\beta$ 受体—cAMP—PKA 信号通过 PLIN1—ABHD5—ATGL 和 HSL 等装置提高净脂解，释放脂肪酸和甘油；胰岛素及 $\alpha_2$ 信号可抵消这一方向。人脂肪细胞的 $\beta_1$、$\beta_2$ 作用不可忽略，$\beta_3$ 的表达和贡献与啮齿动物及脂肪库不同。原素材把“骨骼肌 $\beta_3$ 受体加强脂肪分解”连成一条箭头，既混淆储脂组织，也把物种差异很大的受体写成普适主轴；完整脂滴机制见[脂质分解代谢](../../biochem/lipid_catabolism.md#adipose-lipolysis)。[^adipose-lipolysis]

儿茶酚胺还可经胰岛 $\alpha_2$ 等信号压低胰岛素释放，并按受体和背景影响胰高血糖素；这使燃料生成增加的同时，外周储存信号减弱。整体结果不是“所有组织代谢都加快”，而是把心肺工作、活动肌和脑的即时供给置于优先位置，同时暂缓部分储存过程。[胰岛内分泌](endo_islet.md#fed-fasted-integration)讨论餐间、运动和低血糖时的多激素通量整合。

## 低血糖反调节体现了防线的先后与冗余 { #hypoglycemia-counterregulation }

血糖下降时，最早的防线是胰岛素分泌减弱；随后胰高血糖素和肾上腺素增加，前者主要促进肝糖输出，后者同时促进肝糖输出、限制胰岛素、动员脂肪并产生心悸、震颤等促使个体进食的神经源性警告。皮质醇和生长激素也会增加，但其代谢作用更慢。几条路线相互补偿，不能把低血糖时的髓质分泌写成孤立于胰岛、交感神经和行为反应的单一反馈。[^hypoglycemia-defense]

反调节阈值不是每个人固定的一枚血糖数字。既往血糖水平、近期运动、睡眠和反复低血糖都能移动响应阈值；在糖尿病等背景下，胰高血糖素与肾上腺素防线还可能先后受损，造成低血糖相关自主神经功能衰竭和警告减弱。这属于正常防线失配后的病理接口，诊断与治疗留在[糖与能量代谢紊乱](../pathophysiology/metabolic_disorders.md)。

## 应激效应器按刺激性质形成不同组合 { #stressor-specific-responses }

“应急反应由髓质负责、应激反应由皮质负责”抓住了神经胞吐与类固醇生成的时间差，却容易误导。一次威胁可在数秒内改变交感神经和髓质输出，也可在随后数分钟至小时改变 ACTH—皮质醇轴；两者互相耦联且时间窗重叠。皮质醇既维持 PNMT 表达，又允许血管充分响应儿茶酚胺，髓质与皮质因此不能被视为两个互不往来的开关。

更重要的是，生理系统不会把所有“伤害性刺激”译成同一比例。一项汇总 60 份报告、15 类刺激的分析显示，低血糖时肾上腺素响应相对突出；未致低体温的寒冷、直立和主动逃避等情境则更偏向交感神经去甲肾上腺素输出。肾上腺素、去甲肾上腺素与 ACTH 的变化有相关性，却不足以支持一套无差别的普遍应激综合征。[^stressor-patterns]

因此，剧烈运动、失血、寒冷、疼痛和心理威胁不能只按“突变性”列成同一诱因表，手术、感染、饥饿和紧张也不能一概归作较温和、较慢的皮质反应。应按被威胁的变量、感觉输入、中枢评估、效应器模式和恢复过程分别解释；慢性应激、炎症与适应失衡将在[发热、炎症与应激](../pathophysiology/fever_inflammation_stress.md)展开。

## 快速清除使髓质输出保留脉冲特征 { #clearance-metabolism }

循环儿茶酚胺的半衰期通常只有约 1～2 min。它们被肝、肾及其他组织摄取，并由单胺氧化酶（MAO）和儿茶酚-*O*-甲基转移酶（COMT）按所在区室代谢；甲氧基肾上腺素、甲氧基去甲肾上腺素、3-甲氧基-4-羟基苯乙二醇与香草扁桃酸等产物再经进一步转化和排泄。交感突触中的去甲肾上腺素主要依赖神经元转运体再摄取，而血中肾上腺素缺少同样紧邻释放点的回收路线，不能把两者的终止机制画成同一条酶降解箭头。[^catecholamine-metabolism]

短半衰期使血中浓度紧跟神经输入的起落，但靶细胞的第二信使、磷酸化和代谢通量不必在激素消失的瞬间完全复原。快速分泌、快速清除与组织响应的不同复位速度共同决定一次应急过程的起始和恢复。

## 肾上腺髓质素不是髓质专属激素 { #adrenomedullin-boundary }

肾上腺髓质素（ADM）因最初从人嗜铬细胞瘤中分离而得名，并不表示它主要由正常肾上腺髓质承担全身分泌。ADM 属于降钙素／CGRP 肽家族，在血管内皮和平滑肌、心、肺、肾、脂肪等多种组织表达；它通过 CALCRL 与 RAMP2 或 RAMP3 组成的受体复合物参与血管舒张、内皮屏障和体液调节，作用常具有旁分泌和病理状态依赖性。[^adrenomedullin]

原素材的“利水、利 Na、降压、护心”把实验与病理背景不同的效应压成了四个无条件标签。ADM 的发现史可在本页说明，广泛组织来源、受体及器官内分泌网络则迁往[松果体、组织激素与器官内分泌](endo_other.md)，不与儿茶酚胺主线混写。

[^hypoglycemia-defense]: 低血糖时胰岛素、胰高血糖素、肾上腺素、皮质醇与生长激素的分层防线及反复低血糖后的响应减弱，参见 Endotext [Hypoglycemia](https://www.ncbi.nlm.nih.gov/books/NBK279137/) 与 [Hypoglycemia During Therapy of Diabetes](https://www.ncbi.nlm.nih.gov/books/NBK279100/)。
[^stressor-patterns]: 不同刺激下肾上腺素、去甲肾上腺素和 ACTH 的差异化组合，参见 Goldstein 与 Kopin 的[应激效应器荟萃分析](https://pubmed.ncbi.nlm.nih.gov/18999898/)及 Goldstein 的[肾上腺应激综述](https://pubmed.ncbi.nlm.nih.gov/21061156/)。
[^catecholamine-metabolism]: 神经元再摄取、组织摄取以及 MAO／COMT 的区室化代谢，参见 Eisenhofer 等的[儿茶酚胺代谢综述](https://pubmed.ncbi.nlm.nih.gov/15317907/)。
[^adrenomedullin]: ADM 的发现史、广泛组织表达与 CALCRL—RAMP 受体背景，参见 Spoto 等的[生理与病理综述](https://pubmed.ncbi.nlm.nih.gov/38891025/)。
