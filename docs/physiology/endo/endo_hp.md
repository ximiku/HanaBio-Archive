# 下丘脑—垂体内分泌

下丘脑把来自昼夜节律、睡眠、应激、能量状态、渗透压和生殖状态的信息转译为神经内分泌输出，垂体则把其中一部分信号放大并分配到外周组织。这个系统常被画成“下丘脑→垂体→靶腺”的三级箭头，但真实结构并不只有一条通路：腺垂体接受门脉血中的释放或抑制信号，神经垂体则是下丘脑大细胞神经元轴突在外周循环端的延伸；外周激素、代谢物和感觉传入又不断改写两条通路的输出。

本文先说明两条解剖通路，再讨论腺垂体的五类主要内分泌细胞、生长激素和催乳素，最后回到神经垂体的血管加压素与催产素。激素受体和反馈的一般原理见[内分泌生理总论](index.md)，各靶腺和疾病诊疗则由相邻页面展开。

## 下丘脑以两条解剖通路控制垂体 { #hypothalamic-pituitary-routes }

### 门脉把正中隆起的局部信号送到腺垂体 { #portal-system }

下丘脑弓状核、室旁核、视前区等处的小细胞神经分泌神经元把轴突投向正中隆起。动作电位到达末梢后，神经肽或多巴胺释放到由垂体上动脉供血的初级毛细血管丛；血液随后经垂体门静脉进入腺垂体的次级毛细血管丛，使局部信号在未被全身血量稀释前就接触靶细胞。门脉血的主要流向是正中隆起至腺垂体，不能把它理解成下丘脑与垂体之间对等、双向的循环管道。[^functional-anatomy]

腺垂体细胞接收的分子按功能称为释放激素或抑制因子，并不因能否人工合成而改变身份。促甲状腺激素释放激素（TRH）、促肾上腺皮质激素释放激素（CRH）、促性腺激素释放激素（GnRH）和生长激素释放激素（GHRH）提供主要的刺激输入；生长抑素（SST）抑制生长激素，并参与抑制 TSH；结节漏斗多巴胺能神经元释放的多巴胺则对催乳素细胞施加持续抑制。它们不是彼此独立的“专用导线”：例如小细胞神经元释放的血管加压素可与 CRH 协同促进 ACTH，TRH 也能刺激催乳素释放。[^functional-anatomy]

### 神经垂体把下丘脑轴突直接接到全身循环 { #neural-route }

另一条通路不经过腺垂体细胞。视上核和室旁核的大细胞神经分泌神经元在胞体内合成血管加压素（AVP）或催产素（OT）的前体，分泌颗粒沿下丘脑—垂体束向下运输，在运输途中完成加工，并在神经垂体轴突末梢释放入血。神经垂体主要由轴突、末梢、垂体细胞等胶质样支持细胞和毛细血管组成；它储存并释放这些肽，却不是它们的合成部位。[^neurohypophysis]

| 通路 | 下丘脑输出端 | 到达垂体的方式 | 垂体承担的作用 |
| --- | --- | --- | --- |
| 正中隆起—门脉—腺垂体 | 小细胞神经分泌神经元末梢 | 初级毛细血管丛、门静脉、次级毛细血管丛 | 内分泌细胞整合刺激与抑制信号，合成并分泌前叶激素 |
| 大细胞神经分泌—神经垂体 | 视上核、室旁核神经元胞体 | 轴突运输至神经垂体末梢 | 储存并按放电模式释放下丘脑合成的 AVP 或催产素 |

这两条路线也不是把下丘脑截然分成两套互不相干的细胞。室旁核同时含有大细胞和小细胞群；AVP 除了由大细胞神经元送往神经垂体，也可由小细胞神经元释放到门脉床参与应激轴调节。区分路线时应追踪特定神经元的投射终点，而不能仅凭核团名称判断功能。

## 腺垂体以五类主要细胞分配内分泌输出 { #anterior-pituitary-cells }

腺垂体的远侧部是主要的内分泌组织。传统染色中的嗜酸、嗜碱和嫌色分类有助于辨认组织，却不足以代表细胞的分子身份；现代分类更看重谱系转录因子和所合成的激素。五类主要细胞及其上游、下游关系如下：

| 腺垂体细胞 | 主要下丘脑输入 | 主要分泌物 | 主要作用方向 |
| --- | --- | --- | --- |
| 生长激素细胞 | GHRH 促进，SST 抑制；生长素释放肽增强 | GH | 肝与多种局部组织的 IGF-I 生成，并直接调节底物代谢 |
| 催乳素细胞 | 多巴胺持续抑制；吸吮解除部分抑制，TRH 等可促进 | PRL | 乳腺分化与乳汁合成，并影响生殖轴 |
| 促肾上腺皮质激素细胞 | CRH 与 AVP 协同 | POMC 加工产生的 ACTH | 肾上腺皮质糖皮质激素生成 |
| 促甲状腺激素细胞 | TRH 促进，SST 抑制 | TSH | 甲状腺激素合成与释放 |
| 促性腺激素细胞 | 脉冲式 GnRH | LH、FSH | 性腺类固醇生成、配子发生和局部肽类分泌 |

TSH、LH 和 FSH 都是由共同 α 亚基与激素特异 β 亚基组成的糖蛋白；胎盘 hCG 也属于这个结构家族。ACTH 则来自阿片黑素皮质素原（POMC），并不共享这套 α 亚基。GH 和 PRL 是同源蛋白家族成员，但也不是糖蛋白促激素。把所有“促某腺激素”归入同一化学类别，会掩盖受体、加工和清除方式的差异。[^pomc-processing]

成人垂体没有其他哺乳动物那样发达而独立的中间部。促肾上腺皮质激素细胞主要把 POMC 加工为 ACTH 和 β-脂促素，进一步生成 α-MSH 所需的加工酶组合则更常见于下丘脑、皮肤及具有发达中间部的物种。人类色素调节涉及皮肤局部 POMC—黑皮质素受体系统，也会受高 ACTH 状态影响；不宜把“垂体中叶分泌 MSH”列成人体腺垂体的一条并列主轴。[^pomc-processing]

## 促激素轴用反馈与节律组织靶腺活动 { #tropic-axes }

CRH—ACTH—糖皮质激素、TRH—TSH—甲状腺激素和 GnRH—LH/FSH—性腺激素构成三条常见促激素轴。靶腺激素既作用于全身组织，也对垂体和下丘脑形成长反馈；垂体激素和下丘脑信号还可形成短反馈或局部自分泌、旁分泌调节。因此，血中某一垂体激素的高低只有与靶腺激素、采样时相和生理背景一起看才有意义。

| 轴 | 关键时间组织 | 反馈中还需考虑的信号 | 详见 |
| --- | --- | --- | --- |
| 下丘脑—垂体—肾上腺皮质轴 | ACTH 与皮质醇有昼夜和脉冲变化，应激会重塑其振幅 | AVP、炎症介质、睡眠与代谢状态 | [肾上腺皮质内分泌](endo_ad_cortex.md) |
| 下丘脑—垂体—甲状腺轴 | TRH、TSH 与甲状腺激素的节律叠加于较慢的合成和储备过程 | 温度、营养状态、疾病及脱碘酶调节 | [甲状腺内分泌](endo_thyroid.md) |
| 下丘脑—垂体—性腺轴 | GnRH 必须以脉冲方式驱动，频率与幅度会改变 LH/FSH 输出 | 性腺类固醇、抑制素、激活素及生命阶段 | [生殖生理](../reproductive.md#hpg-axis) |

下丘脑还接收视交叉上核及其他脑区的节律和状态信息，垂体细胞自身也会改变受体数量、分泌颗粒和细胞间通讯。轴系的“逐级放大”因而不是固定增益：持续的同一种输入可能使受体减敏，脉冲频率改变可以选择性调整输出，慢性应激、禁食、睡眠改变或炎症也可能让多个轴同时换挡。

## 生长激素以脉冲连接生长与底物代谢 { #gh-igf-axis }

GHRH 促进生长激素细胞合成和释放 GH，SST 提供抑制，胃和下丘脑来源的生长素释放肽（ghrelin）经 GHSR 增强垂体反应并与 GHRH 协同。GH 以离散脉冲分泌，夜间睡眠尤其慢波睡眠起始附近常出现较大脉冲；年龄、青春期、雌激素暴露、体成分、运动、禁食和疾病都会改变模式。一次随机测得的 GH 浓度可能恰在脉冲峰或谷，不能代表全天分泌量，也不能把“入睡一小时后最高”当成所有人的固定时刻。[^gh-physiology]

GH 结合受体后可经 JAK2—STAT 等通路直接改变脂解、蛋白质代谢和胰岛素敏感性，也促进肝脏及骨、软骨等局部组织产生 IGF-I。IGF-I 通过内分泌和旁分泌作用支持软骨细胞增殖、肥大和组织生长，并在下丘脑与垂体参与负反馈。所谓 GH 的“直接作用”和 IGF-I 的“介导作用”不是互斥替代：纵向生长依赖两者与营养、甲状腺激素、胰岛素及性腺类固醇共同作用，成人 GH 的代谢意义也不会因骨骺闭合而消失。[^gh-physiology]

儿童期 GH—IGF-I 轴不足可限制生长，骨骺闭合前长期过量可造成巨人症样生长，闭合后过量则形成肢端肥大相关改变；但身材矮小有遗传、营养、慢性疾病、甲状腺、生长板和社会环境等多类原因，不能与垂体性 GH 缺乏画等号。GH 过量可促进脂解和胰岛素抵抗，也不应另命名为一种独立的“垂体性糖尿病”。生长板与青春期协同详见[生长、发育与衰老](../growth_development.md#childhood-growth)，疾病诊断和治疗留在病理生理与临床页面。

## 催乳素以持续多巴胺抑制为基线 { #prolactin-control }

催乳素轴与三条典型促激素轴不同：静息时最突出的下丘脑控制不是释放激素刺激，而是结节漏斗多巴胺能神经元经门脉递送多巴胺，激活催乳素细胞的 D2 受体并持续限制 PRL 合成、释放和细胞增殖。垂体柄或门脉联系受损时，其他前叶激素常因释放信号中断而降低，PRL 却可因失去多巴胺抑制而升高，这一“柄效应”正好显示了控制方向的不同。PRL 还能增强结节漏斗多巴胺能神经元活动，形成短反馈。[^prolactin-regulation]

妊娠期雌激素等信号促进乳腺发育和催乳素细胞活动，但高水平孕酮、雌激素使大量乳汁分泌受到限制；胎盘娩出后这些类固醇迅速下降，PRL 才能有效推动分泌活化。吸吮的感觉传入降低多巴胺抑制并引发 PRL 脉冲，为后续乳汁合成提供信号；同一感觉传入还促使神经垂体释放催产素，引起肌上皮收缩和射乳。因而 PRL 主要维持“合成”，催产素主要帮助“排出”，两者不能互换。[^breastfeeding]

持续升高的 PRL 会通过 kisspeptin—GnRH 等下丘脑网络抑制生殖轴，降低 LH/FSH 脉冲并影响排卵或睾丸功能。产后月经恢复的时间还取决于吸吮频率、夜间喂养、能量状态和个体差异，不能化约成“β-内啡肽单一路径导致闭经”，也不能把哺乳本身当作恒定可靠的避孕条件。TRH 可刺激 PRL，原发性甲状腺功能减退时 PRL 可能升高，所以“甲状腺激素抑制催乳素”不能替代对整条轴的分析。[^prolactin-regulation]

## 神经垂体按神经放电释放两种九肽 { #posterior-pituitary }

AVP 与催产素都是含二硫键的九肽，序列仅有两个氨基酸位置不同。它们各自以前体形式与神经垂体素共同合成，分泌颗粒沿轴突运输；轴突局部膨大及末梢可形成 Herring 体样颗粒聚集。动作电位使末梢电压门控 Ca$^{2+}$ 通道开放，Ca$^{2+}$ 内流触发胞吐，把成熟肽和相应神经垂体素释放到体循环。这个过程是神经元的调节性分泌，而不是腺垂体门脉对后叶的控制。[^neurohypophysis]

### 血管加压素连接渗透与容量稳态 { #vasopressin-interface }

AVP 神经元整合前脑渗透感受网络、压力和容量感受传入，以及恶心、疼痛等状态信息。升高的有效血浆渗透压通常增强 AVP 与口渴，显著下降的有效循环血量则可压倒渗透调节并加强保水、血管反应。AVP 经肾集合管 V2 受体调节 AQP2，必须与髓质渗透梯度配合才能浓缩尿；较高浓度下经 V1a 受体产生血管作用。肾脏机制、渗透清除率和自由水清除率见[尿液浓缩、清除率与排尿](../urinary/concentration_clearance.md#vasopressin-water-balance)。

### 催产素参与射乳与分娩放大 { #oxytocin }

乳头机械刺激的感觉传入可使催产素神经元同步爆发放电，脉冲式催产素使乳腺腺泡和小导管周围肌上皮细胞收缩，将已合成的乳汁推向较大导管。射乳反射会受感觉和情绪状态影响，但乳汁生成、储存和移出还受到 PRL 与乳房局部供需反馈控制，不能用单个催产素浓度解释整个泌乳过程。[^breastfeeding]

临近分娩时，子宫肌催产素受体、细胞间连接和前列腺素系统共同增强组织反应性。规律宫缩建立后，胎先露牵张宫颈可经 Ferguson 反射进一步促进催产素释放，形成放大宫缩的正反馈；这一回路有助于分娩推进，却不证明自然分娩由催产素单独启动。人类分娩还涉及胎儿、胎盘、蜕膜、宫颈和子宫肌的协同转换，详见[生殖生理](../reproductive.md#parturition)。[^neurohypophysis]

催产素及其受体也分布于中枢神经系统，并参与多类社会和情绪过程；但外周浓度、脑内释放与行为之间不存在可直接换算的单向关系。人类研究受取样介质、检测方法、情境和个体差异影响，系统综述并未得到“社会互动必然引发固定催产素反应”的一致结果。把催产素称为“信任激素”会把条件依赖的神经调节误写成普适的人格开关。[^oxytocin-social]

## 下丘脑—垂体轴是整合网络而非孤立总开关 { #integrated-control }

所谓“垂体主腺”强调它能通过促激素影响多个外周腺体，却容易遮蔽三个事实。第一，垂体输出依赖下丘脑神经回路，后者接收脑干、边缘系统、视交叉上核和感觉器官的信息；第二，胰岛、甲状旁腺等许多内分泌系统主要由血糖、Ca$^{2+}$ 等被调变量直接控制，并不经过垂体；第三，靶腺激素、代谢物、细胞因子和局部信号可以在轴的多个层级反馈。因此，内分泌稳态不是一座单向命令塔，而是神经、血液和外周组织共同构成的闭环网络。

这种网络观也决定了阅读化验和实验结果的方式。应先问样本处于哪个昼夜时相、脉冲相位和生命阶段，再判断刺激、抑制、反馈、运输或靶器官响应中的哪一层发生变化；只把一个激素与一个功能配对，往往无法解释同一浓度为何在禁食、青春期、妊娠或应激时产生不同意义。

[^breastfeeding]: 妊娠类固醇撤退、催乳素介导乳汁合成、催产素介导射乳及吸吮感觉传入，见世界卫生组织的[母乳喂养生理基础](https://www.ncbi.nlm.nih.gov/books/NBK148970/)。
[^oxytocin-social]: 人类内源性催产素与社会互动研究的方法异质性和不一致因果结果，见 Burenkova 等的[系统综述与 Meta 分析](https://europepmc.org/article/PMC/11077008)。
