# 钙磷调节

钙和磷同时构成骨矿物，却不是只为骨骼服务的两种“结构材料”。细胞外游离 Ca$^{2+}$ 参与兴奋—收缩耦联、递质释放、凝血和细胞信号，必须在很窄的范围内调节；磷酸盐则连接 ATP 周转、核酸、磷脂、缓冲体系和骨矿化。机体因此面对两个相关而不相同的任务：一面维持细胞外液中的即时浓度，一面管理膳食摄入、尿和粪便排出以及骨矿物储量所构成的长期收支。

这套调节并不服从单一“主腺”。甲状旁腺激素（PTH）优先保卫游离钙，活性维生素 D 建立肠道吸收能力，骨细胞来源的成纤维细胞生长因子 23（FGF23）限制磷负荷和活性维生素 D，降钙素则在钙负荷升高时提供较弱而快速的缓冲。四类信号在肠、肾和骨之间闭合反馈，因此读图或分析实验时应追踪矿物流量，而不能只背诵某激素“升钙”或“降磷”。[^mineral-homeostasis]

## 血浆浓度与全身矿物收支不是同一个变量 { #concentration-balance }

血浆总钙由游离 Ca$^{2+}$、与白蛋白等蛋白结合的钙以及与磷酸盐、柠檬酸盐等阴离子形成的复合物组成。真正被甲状旁腺 Ca$^{2+}$ 感受受体（CaSR）直接读取、并承担多数快速生理作用的是游离部分。白蛋白浓度改变时，总钙可随之改变而游离钙未必同向变化；pH 升高会增加白蛋白对 Ca$^{2+}$ 的结合，因而可能在总钙变化不大时降低游离钙。由此可见，“血钙”若不说明所测组分和酸碱背景，并不是一个充分明确的变量。[^mineral-homeostasis]

绝大多数体内钙以及大部分磷储存在骨矿物中，血浆只是一小段交换通道。血浆无机磷还会随年龄、进餐、昼夜时相、细胞内外转移和肾排泄而波动，调节紧密程度也低于游离钙。更重要的是，浓度稳态可以暂时以牺牲储量为代价：肠道净吸收不足时，PTH—维生素 D 系统仍可能借减少尿钙并动员骨矿物维持血浆游离钙。因此，正常的瞬时浓度不能证明长期钙收支平衡或骨矿化充分。

## 肠、肾与骨构成连续的矿物流量网络 { #organ-fluxes }

膳食矿物先在肠腔与体内之间完成选择性吸收，进入细胞外液后才能用于骨矿化或由肾排出。小肠 Ca$^{2+}$ 既可走受调节的跨细胞路线，也可沿浓度梯度走细胞旁路线；这些上皮转运细节见[消化与吸收](../digestive/digestion_absorption.md#calcium-absorption)。磷酸盐吸收也兼有主动和被动成分，并受活性维生素 D 和膳食负荷影响。

| 器官 | 主要通量 | 可调环节 | 在稳态中的位置 |
| --- | --- | --- | --- |
| 肠 | 食物进入体内，未吸收部分及内源性分泌随粪便排出 | 上皮跨细胞／细胞旁转运，尤其受 1,25(OH)$_2$D 调节 | 决定外源矿物能否进入交换池 |
| 肾 | 滤过后分段重吸收，余量随尿排出 | 远端 Ca$^{2+}$ 精细回收、近端磷酸盐回收及维生素 D 代谢 | 是分钟至日尺度上最灵活的净输出端 |
| 骨 | 成骨细胞形成类骨质并矿化，破骨细胞吸收骨组织 | 重塑耦联、矿物沉积与动员 | 是最大储库，也是 FGF23 的内分泌来源 |

肾脏并非只在“缺乏时保留、过量时排出”。滤过的大部分 Ca$^{2+}$ 和磷酸盐在近端小管与 Henle 袢等处随整体转运被回收，激素主要改写末端可调份额；远端 Ca$^{2+}$ 转运和近端磷酸盐转运的区段机制见[肾小球滤过与肾小管转运](../urinary/filtration_transport.md#loop-distal-tubule)。骨也不是一袋随取随放的盐：骨吸收与骨形成在重塑单位中相互耦联，持续改变矿物流量还会改变基质结构和力学质量。[^mineral-homeostasis]

## PTH 以 CaSR 读取游离钙并优先保卫钙浓度 { #pth-control }

### CaSR 把游离钙变化转成 PTH 分泌 { #pth-secretion }

甲状旁腺主细胞表面的 CaSR 是 G 蛋白偶联受体，细胞外游离 Ca$^{2+}$ 是其激动剂。游离钙升高时，CaSR 信号抑制 PTH 释放和合成；游离钙下降时，这一抑制解除，预先储存的 PTH 可在数分钟内增加释放，较慢的转录、合成和细胞增殖反应则支持持续需求。PTH 分泌具有脉冲和昼夜组织，但进餐、钙磷摄入、睡眠和维生素 D 状态都会改变波形，不能把某个清晨时刻写成固定峰值。[^pth-secretion]

Mg$^{2+}$ 与这一系统的关系也不是简单的单向箭头。轻度、短时下降可像低 Ca$^{2+}$ 一样促进 PTH；严重而持续的镁缺乏却会妨碍 PTH 合成、分泌及靶细胞信号，形成“低钙但 PTH 反应不足或作用减弱”的状态。磷负荷、FGF23 和 1,25(OH)$_2$D 还可直接或间接改写 PTH 合成，说明甲状旁腺读取的是多信号背景中的游离钙，而不是孤立的浓度开关。[^magnesium-pth]

### 肾脏让 PTH 的升钙与排磷作用分开 { #pth-kidney }

PTH 在远端肾单位增强 Ca$^{2+}$ 的精细重吸收，从而减少尿钙损失；同时使近端小管顶端 NaPi-IIa、NaPi-IIc 等钠—磷酸盐协同转运体内化，降低磷酸盐重吸收并增加排磷。骨矿物吸收会同时释放钙和磷，肾脏的选择性排磷正可避免两者在细胞外液中同步累积，并使 PTH 的净效应表现为保钙、排磷。

PTH 还促进近端小管 CYP27B1 将 25(OH)D 转为 1,25(OH)$_2$D，并限制 CYP24A1 介导的失活，从而间接增强肠道钙磷吸收。PTH 对肠道的直接作用很弱；所谓“PTH 促进肠吸收”主要经过肾脏生成活性维生素 D 这一步。旧笔记中同时列出的 Na$^+$、HCO$_3^-$ 和水转运变化可以作为近端小管信号的伴随效应研究，但不是理解正常钙磷稳态的主线，酸碱后果留给相应病理生理页面。

### 骨细胞把持续信号与间歇信号解释成不同结果 { #pth-bone }

PTH 并不主要通过直接刺激成熟破骨细胞发挥作用。PTH1R 丰富表达于成骨细胞谱系和骨细胞；这些细胞改变 RANKL、骨保护素（OPG）等信号后，才调节破骨细胞的形成与活性。较高而持续的 PTH 暴露通常使骨吸收占优，帮助释放矿物；低剂量、间歇式药理暴露则可使骨形成占优。二者不是“PTH 既成骨又溶骨”的任意矛盾，而是暴露模式、细胞状态和重塑耦联共同决定的不同净结果。[^pth-bone]

## 维生素 D 把皮肤与膳食输入转成吸收能力 { #vitamin-d-axis }

### 活化与失活在多个器官间接力 { #vitamin-d-metabolism }

皮肤中的 7-脱氢胆固醇经 UVB 光化学反应生成维生素 D$_3$，膳食则可提供 D$_3$ 或 D$_2$。它们先在肝脏主要经 CYP2R1 形成 25(OH)D；25(OH)D 是血中主要循环库和通常用于评估维生素 D 状态的代谢物，却不是主要的高效应激素。肾近端小管 CYP27B1 再生成 1,25(OH)$_2$D（骨化三醇），CYP24A1 则启动 25(OH)D 和 1,25(OH)$_2$D 的分解。完整的分子来源、转运和营养学边界见[维生素与辅酶](../../biochem/vitamin_and_coenzyme.md#vitamin-d-activation)。[^vitamin-d-metabolism]

肾脏是循环 1,25(OH)$_2$D 的主要来源，但不是唯一表达 CYP27B1 的组织。胎盘、巨噬细胞、角质形成细胞等也能在局部生成活性代谢物，其调节更常受细胞因子和组织状态影响，主要服务于自分泌或旁分泌需求。把这些局部反应与受 PTH—FGF23 控制的肾脏内分泌输出等同，会误判炎症或妊娠背景下活性维生素 D 的来源。[^vitamin-d-metabolism]

### VDR 调节上皮运输，也受矿物供应条件约束 { #vitamin-d-action }

1,25(OH)$_2$D 与维生素 D 受体（VDR）结合，VDR 通常与 RXR 形成异源二聚体并调节靶基因。肠上皮中，相关转录程序提高 Ca$^{2+}$ 跨细胞转运能力，并促进磷酸盐吸收；这使充分的膳食矿物进入细胞外交换池，为骨矿化提供底物。维生素 D 还能作用于甲状旁腺、肾和骨细胞，但其结果依赖 Ca$^{2+}$／磷酸盐供应、PTH、FGF23 和重塑状态，不能概括成“低钙时溶骨、高钙时成骨”的直接切换。[^vitamin-d-metabolism]

佝偻病和骨软化是类骨质矿化不足的表型，维生素 D 缺乏只是其中一类原因；钙或磷供应不足、肾脏活化障碍、磷酸盐丢失等也能走向相似终点。正常生理页只用这一关系说明“维持血浆浓度”与“获得足够矿化底物”的区别，病因鉴别和治疗不在此展开。

## FGF23 让骨向肾报告磷负荷 { #fgf23-axis }

骨细胞和成骨细胞产生 FGF23。完整的 FGF23 与肾脏富含 αKlotho 的 FGFR 受体复合物结合后，降低近端小管 NaPi-IIa、NaPi-IIc 的膜表达，使磷酸盐重吸收减少；同时抑制 CYP27B1、促进 CYP24A1，降低 1,25(OH)$_2$D 的生成与作用时间。结果是尿磷排出增加，肠道对新磷负荷的吸收能力也受到间接限制。[^fgf23]

1,25(OH)$_2$D 可促进 FGF23 生成，FGF23 又反向限制 1,25(OH)$_2$D，构成骨—肾反馈。磷摄入和细胞外磷状态会影响这条轴，但 FGF23 产生还受骨矿化、铁状态、炎症以及蛋白加工等因素调节，不能把骨细胞描写成只用一个线性受体直接读取“血磷”。FGF23 与 PTH 对肾磷回收的方向相同，对活性维生素 D 的方向相反；二者在慢性肾功能改变等背景中的相互作用更复杂，留待病理生理页面处理。

## 降钙素是快速缓冲而非 PTH 的对称主轴 { #calcitonin }

甲状腺滤泡旁 C 细胞分泌由 32 个氨基酸组成的降钙素。细胞外 Ca$^{2+}$ 升高通过 CaSR 促进其释放；降钙素受体在破骨细胞上高度表达，可迅速降低破骨细胞活动，肾脏也有较弱的促钙、磷排泄效应。餐后胃肠信号能够调节降钙素，但“胃泌素是最强刺激物”多来自特定剂量或刺激试验，不能替代高 Ca$^{2+}$ 这一主要生理信号。[^calcitonin]

降钙素的快速效应并不意味着它与 PTH 构成力量相等、方向相反的一对总开关。成年人在甲状腺切除后缺少降钙素，或在 C 细胞疾病中长期浓度升高，常不会出现与 PTH 缺失或过量相称的钙稳态紊乱；正常成人中，PTH—维生素 D—FGF23 网络承担更主要的持续控制。生长、妊娠或高钙负荷等矿物流量较大的状态可能提高降钙素缓冲的相对意义，但“儿童强、成人弱”应理解为状态依赖，而不是两套截然不同的调节系统。[^calcitonin]

## 多条反馈环在不同时间尺度上闭合 { #integrated-feedback }

游离 Ca$^{2+}$ 突然下降时，最快的响应是 PTH 释放增加：肾脏减少 Ca$^{2+}$ 丢失、增加磷排出，骨重塑信号逐步偏向矿物动员。随后 PTH 促进肾脏生成 1,25(OH)$_2$D，肠道吸收能力增强；升高的游离 Ca$^{2+}$ 和 1,25(OH)$_2$D 又抑制 PTH，使回路收敛。若磷负荷和 1,25(OH)$_2$D 上升，骨源 FGF23 增加排磷并压低活性维生素 D；若 Ca$^{2+}$ 短时升高，降钙素可快速抑制破骨细胞。这里的“稳态”是多个通量持续调整后的动态状态，而不是四种激素互相抵消后静止不动，控制系统的一般含义见[内环境与稳态](../internal_env.md#dynamic-homeostasis)。

同一血液结果也可能由不同层级造成。例如低钙可来自肠道输入不足、肾脏丢失、维生素 D 活化不足或 PTH 分泌／作用异常；低磷可来自摄入与吸收不足、细胞内转移或 PTH／FGF23 驱动的肾性丢失。分析时应依次区分被调浓度、净收支、激素来源、靶器官响应和时间尺度。甲状旁腺主要由被调离子直接控制，正体现了[下丘脑—垂体整合网络](endo_hp.md#integrated-control)之外仍有多种外周闭环。
