# 肾上腺皮质内分泌

肾上腺皮质把胆固醇转化为三组功能不同的类固醇：糖皮质激素维持基础代谢并参与应激适应，盐皮质激素把有效循环容量和血钾变化接到远端肾单位，肾上腺雄激素则形成一条有别于性腺轴的发育信号。它们来自同一器官，却不是由同一个上游开关等比例释放。皮质各带的酶表达、血中运输和靶组织内代谢共同决定某一种类固醇在哪里生成、到达何处以及能否激活受体。

本文以人体生理为主，先从皮质分区和类固醇生成说明三类输出的来源，再分别讨论皮质醇、醛固酮和肾上腺雄激素。CRH、ACTH 与其他垂体轴的一般结构见[下丘脑—垂体内分泌](endo_hp.md#tropic-axes)，儿茶酚胺介导的交感—髓质反应见[肾上腺髓质内分泌](endo_ad_medulla.md)，Addison 病、Cushing 综合征和原发性醛固酮增多症的诊断与治疗留在[糖与能量代谢紊乱](../pathophysiology/metabolic_disorders.md)。

## 皮质分区把同一胆固醇导向三类类固醇 { #cortical-zonation }

成人肾上腺皮质从被膜向髓质依次为球状带、束状带和网状带。三带细胞都具有丰富的线粒体和光面内质网，适合完成细胞色素 P450 酶参与的氧化反应；但它们表达的末端酶不同，因此不能把一条完整的合成通路平均分配给每一层。皮质血流大体从外向内穿过有窗毛细血管，细胞又可在更新过程中向心迁移，使解剖分层与局部信号、细胞状态相互联系，而不是三圈永久不变的细胞边界。[^adrenal-zonation]

| 皮质区域 | 关键酶表达与主要输出 | 占优势的控制 |
| --- | --- | --- |
| 球状带 | 缺少 CYP17A1，表达 CYP11B2，生成醛固酮 | 血管紧张素 II、细胞外 K$^+$；ACTH 只有短暂调节 |
| 束状带 | 表达 CYP17A1、CYP21A2 和 CYP11B1，主要生成皮质醇 | ACTH |
| 网状带 | CYP17A1 的 17,20-裂解活性较强，CYB5A、SULT2A1 丰富而 HSD3B2 相对较低；生成 DHEA、DHEAS、雄烯二酮等 C$_{19}$ 类固醇 | ACTH 提供必要刺激，发育成熟还受带区自身变化控制 |

球状带缺少 17α-羟化酶活性，因而不能沿 17-羟化中间物生成皮质醇和肾上腺雄激素；束状带和网状带则缺少有功能的 CYP11B2，不能完成醛固酮最后几步反应。网状带并非只分泌“雄激素”：它也可产生少量糖皮质激素和多种 11-氧化 C$_{19}$ 类固醇。反过来，DHEA 和 DHEAS 对雄激素受体的直接激动很弱，更准确的身份是可在外周组织转化的雄激素前体。[^adrenal-androgens]

## 胆固醇跨入线粒体是急性类固醇生成的共同入口 { #steroidogenesis }

皮质细胞可从循环脂蛋白摄取胆固醇，也可动用胆固醇酯储备或自行合成胆固醇。急性刺激到来时，类固醇生成急性调节蛋白 StAR 促进胆固醇从线粒体外膜一侧到达内膜；内膜上的 CYP11A1 随后切断胆固醇侧链，生成孕烯醇酮。这一步把通用脂质原料送入类固醇通路，是 ACTH 或血管紧张素 II 在分钟尺度提高合成速率的重要控制点。长期刺激还会改变脂蛋白摄取、StAR 和多种类固醇生成酶的表达。[^human-steroidogenesis]

孕烯醇酮及其后续中间物要在线粒体与光面内质网之间往返，经过羟化、脱氢和侧链裂解，才分别形成皮质醇、醛固酮或 C$_{19}$ 类固醇。类固醇疏水，合成后可跨膜离开细胞，皮质细胞没有像肽类内分泌细胞那样储存大量成熟激素的致密分泌颗粒。因此，“释放”在很大程度上跟随即时合成；改变底物转运和酶活性，比打开一个预存颗粒库更能解释数分钟至数小时的输出变化。

不同酶缺陷造成的结果也不能只按“下游产物减少”理解。某条支路受阻时，上游中间物可积聚并被导向仍然开放的支路，ACTH 负反馈解除又会扩大整个皮质的合成驱动。先天性肾上腺皮质增生的具体分型属于病理生理，但这种“共同入口—分支限速—底物改道”的框架，是理解其激素组合的基础。

## 皮质醇的运输和组织内转换共同限定有效信号 { #cortisol-availability }

循环皮质醇大部分与肝脏合成的皮质类固醇结合球蛋白（CBG）结合，另有一部分低亲和力地结合白蛋白，只有较小的游离部分可迅速跨膜并被代谢。CBG 不是恒定容器：雌激素暴露和妊娠可提高其浓度，严重肝病、蛋白丢失和炎症状态则可能改变浓度或结合性质。因而，总皮质醇、游离皮质醇和组织实际暴露并不总是平行，一次血样还叠加了昼夜相位与脉冲相位。[^cortisol-binding]

皮质醇进入细胞后主要结合糖皮质激素受体 GR。未结合配体时，GR 与热休克蛋白等伴侣形成胞质复合物；结合皮质醇后，受体构象改变并进入细胞核，可直接结合糖皮质激素反应元件，也可与其他转录因子和共调节因子相互作用。不同细胞的染色质开放状态、GR 亚型和伴随信号不相同，所以不能把所有代谢效应归为“转录激活”、所有抗炎效应归为“转录抑制”两只互不重叠的开关。较快的非基因组效应也存在，但正常皮质醇作用的大部分时间组织仍来自受体介导的基因调节。[^glucocorticoid-receptor]

靶组织还会在受体之前重新解释激素。11β-羟类固醇脱氢酶 1 型（11β-HSD1）在肝、脂肪和中枢神经系统等处多以还原方向工作，把活性较低的可的松再生为皮质醇；2 型酶（11β-HSD2）则在肾脏等盐皮质激素靶组织把皮质醇氧化为可的松。皮质醇在循环中的浓度远高于醛固酮，且能高亲和力结合盐皮质激素受体 MR，11β-HSD2 因而构成保护 MR 选择性的“受体前闸门”。[^prereceptor-metabolism]

## 糖皮质激素重排底物供给而不只是“升高血糖” { #glucocorticoid-metabolism }

在夜间空腹、较长时间禁食和急性应激中，皮质醇帮助维持可供肝脏利用的底物，并使胰高血糖素、儿茶酚胺等信号充分发挥作用。它提高肝脏多种糖异生酶和氨基酸代谢酶的表达，支持丙氨酸、甘油等底物进入糖异生；同时降低部分外周组织的胰岛素敏感性，使葡萄糖更多留给依赖葡萄糖的组织。它不是像胰高血糖素那样以分钟尺度直接打开肝糖原分解，也不能在缺少碳骨架与能量时“制造”葡萄糖。糖异生的反应和底物约束见[糖异生](../../biochem/gng.md#regulation)。

骨骼肌和结缔组织中的 GR 信号可在较长时间尺度抑制蛋白质合成并促进蛋白质分解，为肝脏提供氨基酸；脂肪组织中的作用则与胰岛素、儿茶酚胺和部位特异性共同决定脂解、脂肪细胞分化和脂质再分配。短期内促进底物动员，与长期过量时出现肌肉萎缩、皮肤变薄、胰岛素抵抗和脂肪向躯干重新分布，是同一套调节在不同剂量和时间背景下的结果。旧笔记所说“促进肝内所有蛋白质合成、抑制肝内蛋白质分解”过于绝对；肝脏实际是选择性增加代谢酶和部分血浆蛋白，同时仍按营养与炎症状态重排蛋白周转。[^glucocorticoid-metabolism]

皮质醇对循环的关键意义之一是允许作用。正常水平的糖皮质激素维持血管平滑肌对去甲肾上腺素、血管紧张素 II 等缩血管信号的反应，并支持心血管系统在容量下降或应激时保持灌注。这里的“允许”不是皮质醇本身等同于强缩血管剂，而是缺少它时，同样的血管活性输入不能产生充分反应。

## 免疫重分布和组织保护具有时间与剂量边界 { #immune-tissue-effects }

糖皮质激素通过 GR 改变炎症介质、黏附分子、细胞迁移和淋巴细胞功能。急性升高后，外周血中性粒细胞常因边集池脱离、离开血管受阻和骨髓成熟细胞释放而增多；淋巴细胞和嗜酸性粒细胞常减少，其中相当部分来自细胞在血液与组织之间重新分配。血细胞计数变化不能直接读成相同方向的细胞生成或死亡，也不能把旧口诀中的“抑碱”当作稳定的人体规律。持续高水平或药理剂量会更广泛地抑制免疫反应，并可减慢成纤维细胞、胶原和伤口修复过程。[^glucocorticoid-immune]

抗炎作用在急性损伤中可限制反应失控，却不等于免疫系统被整体关闭。皮质醇既压低部分促炎通路，也参与免疫细胞迁移、分化和反应终止；适宜的时相和脉冲能让同一组织周期性读取 GR 信号。长期外源糖皮质激素的感染风险、骨质疏松和消化道不良反应属于药理和病理问题，不能反推为正常基础分泌的主要目的。

糖皮质激素还参与胎儿肺成熟，可促进肺泡上皮分化和表面活性物质系统准备，因此产前糖皮质激素有明确的临床生理基础。这个发育效应不宜缩写成成人日常分泌“促进二棕榈酰磷脂酰胆碱合成”。皮质醇也会影响觉醒、情绪、记忆及食欲，但效应取决于昼夜相位、持续时间和既往状态；“维持神经兴奋性”不足以概括这些相互异质的作用。

## HPA 轴以脉冲和昼夜相位组织皮质醇输出 { #hpa-axis }

下丘脑室旁核小细胞神经分泌神经元向正中隆起释放 CRH，并可释放血管加压素（AVP）与 CRH 协同；两者经垂体门脉到达促肾上腺皮质激素细胞，促进 POMC 加工和 ACTH 释放。ACTH 结合束状带、网状带细胞的黑皮质素 2 受体（MC2R）；该受体需要辅助蛋白 MRAP 才能正常到达细胞表面并响应 ACTH，随后主要经 cAMP—PKA 通路提高 StAR 活性和类固醇生成。较长时间的 ACTH 还维持这些带区的酶表达和组织量。[^acth-signaling]

ACTH 和皮质醇不是平滑的日曲线。HPA 轴以约小时尺度的超昼夜脉冲反复出现峰谷，脉冲振幅又被昼夜系统和睡眠—觉醒状态调制。按常见日间作息，皮质醇在后半夜开始上升，觉醒前后及觉醒后的早晨较高，随后总体下降并在生物学夜间较低；轮班、跨时区、睡眠剥夺和个体作息会移动或压平这一模式。因此，不能把“CRH 清晨最高、午夜最低”当作用任意一次采血就能验证的固定时刻表，也不能只凭随机皮质醇判断整条轴。[^hpa-rhythms]

皮质醇经 GR 和 MR 在垂体、下丘脑及相关脑区形成多时间尺度反馈，限制 CRH／AVP 和 ACTH 输出；反馈与垂体—肾上腺之间的动态耦合也参与生成脉冲。疼痛、低血糖、感染、运动和心理威胁等应激输入可从脑干、边缘系统、代谢感受和免疫介质等多处改变轴的振幅或相位，却未必都表现为“CRH 大幅增加”。急性反应、反复暴露后的适应和慢性应激中的节律破坏应分开讨论。[发热、炎症与应激](../pathophysiology/fever_inflammation_stress.md)将承接这些病理生理边界。

## 醛固酮把循环容量和血钾接到远端肾单位 { #aldosterone-control }

醛固酮合成主要受血管紧张素 II 和细胞外 K$^+$ 控制。有效循环容量下降、肾灌注减少、致密斑 NaCl 递送下降或交感输入增强时，肾小球旁器释放肾素，依次生成血管紧张素 I 和 II；血管紧张素 II 经球状带 AT$_1$ 受体提高胞质 Ca$^{2+}$，促进 StAR 和 CYP11B2 活动。所谓“低血钠刺激醛固酮”多数是通过容量、肾灌注和致密斑 NaCl 间接进入 RAAS，而不是球状带直接测量一个固定的血钠阈值。[^aldosterone-regulation]

血 K$^+$ 升高则可直接减少球状带细胞 K$^+$ 外流、使膜去极化，开放电压依赖性 Ca$^{2+}$ 通道并促进醛固酮合成。血管紧张素 II 和 K$^+$ 可独立作用又相互增强；ACTH 可短暂提高醛固酮，却不是其长期稳态的主要控制变量。这既解释了旧笔记中“受 ACTH 影响”和“几乎不受 ACTH 影响”的表面冲突，也说明没有必要把含量低、情境依赖的血管紧张素 III 排在血管紧张素 II 之前。

醛固酮在血中没有类似 CBG 的高亲和力专一载体，主要以游离和松散结合白蛋白的形式运输，半衰期比皮质醇短。进入远端肾单位的主细胞后，它与 MR 结合并提高 SGK1 活性，减少 Nedd4-2 对 ENaC 的移除，使顶端膜 ENaC 增多；基底外侧 Na$^+$/K$^+$-ATPase 和顶端 ROMK 等转运环节也受到调节。Na$^+$ 从管腔进入细胞并被泵入间质，管腔负电位和细胞内 K$^+$ 供应共同有利于 K$^+$ 分泌。醛固酮还可增强 α 闰细胞的 H$^+$ 分泌，因而同时参与酸碱稳态。[^aldosterone-action]

Na$^+$ 重吸收是否带来等量水重吸收，取决于 AVP、集合管水通透性、髓质渗透梯度和饮水等条件；醛固酮不是直接打开 AQP2 的“保水激素”。在汗腺、唾液腺和结肠，MR—ENaC 系统也有助于保存 Na$^+$。心脏和血管同样表达 MR，但正常醛固酮生理的主线是上皮电解质转运；高盐背景下不恰当的持续 MR 激活所致炎症、纤维化和重构属于病理作用，不能简单写成正常醛固酮“促进缩血管”。

## 同一醛固酮信号可分别服务于容量或血钾稳态 { #aldosterone-paradox }

容量不足和高血钾都能提高醛固酮，却不应造成完全相同的肾脏结果。容量不足时，血管紧张素 II 同时增强近端 Na$^+$ 重吸收和远曲小管 NCC 活性，送抵集合管的 Na$^+$ 和流量较少，系统偏向保存 Na$^+$、恢复有效循环容量，而不会按醛固酮浓度机械地大量排 K$^+$。高血钾时，肾素—血管紧张素活性可以不高，K$^+$ 对 NCC 的抑制增加下游 Na$^+$ 递送，醛固酮增强 ENaC 和 ROMK 后便更有利于排 K$^+$。这种由伴随信号和远端底物供应区分输出的现象称为“醛固酮悖论”。[^aldosterone-paradox]

因此，“保 Na、排 K”是正确的方向性摘要，却不是对每种状态都固定配对的化学计量命令。肾血流、GFR、不同肾段转运、管腔流量和酸碱状态都会改变最终尿液。完整的肾单位分工见[肾小球滤过与肾小管转运](../urinary/filtration_transport.md#aldosterone-sensitive-distal-nephron)，AVP 与水平衡见[尿液浓缩、清除率与排尿](../urinary/concentration_clearance.md#vasopressin-water-balance)。

## 肾上腺雄激素形成独立于性腺成熟的发育信号 { #adrenal-androgens }

网状带主要生成 DHEA、DHEAS、雄烯二酮和一组 11-氧化 C$_{19}$ 类固醇。CYB5A 增强 CYP17A1 的 17,20-裂解活性，使 17-羟孕烯醇酮更多转向 DHEA；SULT2A1 再把 DHEA 硫酸化为水溶性更高、循环半衰期更长的 DHEAS。DHEA、DHEAS 和雄烯二酮本身对雄激素受体的作用较弱，却可在毛囊、皮肤和其他外周组织中转为睾酮、双氢睾酮或雌激素；局部有哪些酶，决定了前体最终产生何种效应。[^adrenal-androgens]

儿童期网状带逐渐成熟，DHEAS 等输出开始上升，这一过程称为肾上腺功能初现（adrenarche），通常在外观上的性成熟之前启动。其组织基础包括网状带扩大、CYB5A 和 SULT2A1 增加以及 HSD3B2 相对下降；确切的近端启动信号仍未完全确定。ACTH 是网状带正常类固醇生成所必需的，但儿童 adrenarche 并不伴随 ACTH 和皮质醇同步升高，所以不能把它解释成 HPA 轴整体被进一步打开。[^adrenarche]

肾上腺雄激素有助于阴毛、腋毛、皮脂腺和顶泌汗腺活动，对女性的外周雄激素来源尤其重要；其相对贡献随年龄、性别和性腺功能而变。adrenarche 可在没有功能性性腺或促性腺激素升高时发生，不负责启动性腺成熟，也不能替代 GnRH—LH/FSH 轴。旧笔记中的“性激素不能促进性腺发育”应改成更精确的边界：肾上腺雄激素前体能影响若干外周性征，但 adrenarche 与 gonadarche 是可分离的过程。

## 三类皮质输出按不同控制变量协同 { #integrated-control }

皮质醇主要由 CRH—ACTH 轴按脉冲、昼夜和应激背景控制，醛固酮主要由 RAAS 与血 K$^+$ 控制，肾上腺雄激素依赖 ACTH 的基础支持并受网状带发育状态调节。三类激素都来自胆固醇，也都能通过核受体或作为外周前体产生较慢而持久的效应，但“同源”不等于同步。判断肾上腺皮质功能时，必须同时追踪上游控制、带区酶、运输蛋白、受体前代谢和靶组织响应。

应激也不是“髓质只管快、皮质只管慢”的二分过程。交感神经可在数秒内改变心血管和底物动员，ACTH—皮质醇在随后数分钟至小时内重排转录与底物供给，两者的时间窗重叠；皮质血流带入髓质的高浓度皮质醇还支持 PNMT 表达和肾上腺素合成。把这两页连起来，才能理解一次应激反应怎样从快速神经内分泌输出过渡到较长时间的代谢与免疫适应。
