# 胰岛内分泌

胰岛是散布在胰腺外分泌腺泡和导管之间的内分泌微器官。每个胰岛都把营养物、肠源信号、自主神经活动和局部细胞间通信汇入同一微循环，再以胰岛素、胰高血糖素、生长抑素等脉冲式输出改变肝、骨骼肌和脂肪组织的底物流量。它由此调节葡萄糖的出现与清除、脂肪酸的储存与动员，以及氨基酸的摄取与肝脏处理所构成的动态平衡。

这套系统包含三个相互衔接的层级：胰岛细胞感知底物并释放颗粒，几类细胞在局部互相调节，外周器官读取门静脉中的胰岛素—胰高血糖素组合。具体代谢反应见[糖原代谢](../../biochem/glycogen.md#tissue-specific-regulation)、[糖异生](../../biochem/gng.md#regulation)与[脂质分解代谢](../../biochem/lipid_catabolism.md#fatty-acid-oxidation-regulation)；糖尿病分型、酮症酸中毒和药物治疗见[糖与能量代谢紊乱](../pathophysiology/metabolic_disorders.md)。

## 胰岛的细胞与微血管组织 { #islet-microorgan }

胰岛内分泌细胞贴近有窗毛细血管，细胞极性、细胞接触和细胞外基质共同决定分泌颗粒朝血管侧释放的效率。血流把葡萄糖、氨基酸和循环激素带入胰岛，也迅速带走局部释放的肽；交感、迷走和感觉神经末梢又可在进餐、运动与低血糖等状态下改变分泌增益。人胰岛中的 α、β、δ 细胞较为交错，并常围绕血管组成重复的小单元；这一结构不同于啮齿类常见的“β 细胞核心、非 β 细胞外套”，还会随胰区而变化。[^islet-architecture]

| 细胞类型 | 主要分泌物 | 主要系统作用 | 重要局部作用 |
| --- | --- | --- | --- |
| β 细胞 | 胰岛素、C 肽、胰淀素 | 促进餐后底物利用和储存，抑制肝糖输出与脂肪动员 | 胰岛素、Zn$^{2+}$、胰淀素等共同参与 α 细胞调节 |
| α 细胞 | 胰高血糖素 | 维持空腹、运动和低血糖时的肝糖输出，促进肝脏氨基酸周转 | 胰高血糖素可通过环磷酸腺苷（cyclic adenosine monophosphate，cAMP）信号增强 β、δ 细胞分泌 |
| δ 细胞 | 生长抑素 | 循环内分泌作用有限 | 经不同 SSTR 抑制邻近 α、β 细胞，限制分泌波动的幅度 |
| γ／PP 细胞 | 胰多肽 | 参与胰—肠—脑轴，效应具有状态和剂量依赖性 | 可能调节胰岛及胰腺外分泌，人体正常生理意义仍未完全厘清 |
| ε 细胞 | ghrelin | 在胚胎和新生期更显著 | 成人胰岛中稀少，不宜与前四类并列为主要输出 |

现代人体胰岛通常以 α、β、δ 和 γ／PP 四类主要细胞为基本框架。D1／H 细胞—血管活性肠肽（VIP）配对缺乏稳定的现代人体胰岛分类依据；VIP 在胰腺中还主要来自神经纤维等来源，功能上更适合作为神经—旁分泌调节因子理解。各类细胞的比例随胰头、体、尾部和胰岛大小变化，尤其 γ／PP 细胞在胰头腹侧来源区域富集，因而需要按取样区域解释比例。[^islet-architecture]

## 胰岛素合成与颗粒成熟 { #insulin-biosynthesis }

β 细胞在粗面内质网上翻译前胰岛素原（preproinsulin）。信号肽引导新生链进入内质网腔后即被切除，所得胰岛素原（proinsulin）折叠并形成正确的二硫键。胰岛素原随后通过 Golgi 体进入未成熟分泌颗粒；随着颗粒酸化和成熟，PC1/3、PC2 和羧肽酶 E 在颗粒内依次切开连接区，产生由二硫键相连的 A、B 链胰岛素和 C 肽。加工可从反式 Golgi 网络开始，主要完成于持续酸化和成熟的分泌颗粒。[^insulin-biosynthesis]

成熟颗粒中的胰岛素可在 Zn$^{2+}$ 参与下形成稳定六聚体，以便高浓度储存；颗粒释放并稀释到循环后，单体才是与受体结合的主要形式。胰岛素和 C 肽由同一前体等摩尔生成，但胰岛素先经门静脉到达肝脏并被大量首过清除，C 肽的清除动力学则不同，所以 C 肽可帮助估计内源性 β 细胞分泌。C 肽参与前体正确折叠，但缺乏胰岛素样受体激动活性；实验报道的 Na$^+$ 泵、一氧化氮（nitric oxide，NO）等效应，目前也未确立其在正常底物分配中的主调节地位。[^insulin-biosynthesis]

## 葡萄糖刺激的胰岛素分泌 { #glucose-stimulated-secretion }

### 代谢耦联的 Ca$^{2+}$ 触发通路 { #triggering-pathway }

葡萄糖经易化扩散进入 β 细胞，并由葡糖激酶磷酸化后进入代谢。人 β 细胞主要表达 GLUT1，并有 GLUT3、少量 GLUT2 等参与；小鼠和大鼠 β 细胞则更依赖 GLUT2。葡糖激酶与后续代谢是葡萄糖浓度感知的关键限制环节，人 β 细胞的感知因此由多种转运体与代谢装置共同完成。[^beta-cell-glucose-transport]

葡萄糖氧化提高胞质三磷酸腺苷（adenosine triphosphate，ATP）／二磷酸腺苷（adenosine diphosphate，ADP）比，促使由 Kir6.2 和 SUR1 组成的 ATP 敏感性 K$^+$ 通道关闭。K$^+$ 外流减少使膜去极化，电压门控 Ca$^{2+}$ 通道开放，Ca$^{2+}$ 内流触发已具释放能力的胰岛素颗粒与质膜融合。精氨酸可借正电荷促进去极化，亮氨酸等氨基酸可通过代谢加强分泌；脂肪酸也能在特定营养背景下放大反应。营养物的急性分泌放大与长期过剩引起的受体减敏、内质网压力和细胞功能受损发生在不同时间尺度；酮体的作用也取决于浓度和代谢状态。

### 代谢放大通路 { #amplifying-pathway }

Ca$^{2+}$ 内流构成颗粒胞吐的触发信号，葡萄糖代谢还提供独立的放大成分。在已有相近 Ca$^{2+}$ 信号时，多种代谢信号会改变颗粒准备、细胞骨架重排和胞吐装置，使同一 Ca$^{2+}$ 输入释放更多胰岛素。这个放大通路依赖营养物代谢和触发通路，其中参与的代谢物和效应蛋白仍有未决之处。[^insulin-amplification]

当实验把葡萄糖浓度突然阶跃升高时，常见第一相快速峰和第二相持续释放。第一相主要动用已停靠或迅速到达膜面的高释放能力颗粒，第二相则持续募集储备颗粒，并受代谢放大、细胞骨架和新来颗粒影响。两相曲线反映颗粒可用性、募集和放大能力的变化。在体内，进餐输入渐变、肠促胰素和神经信号叠加，多个胰岛还会产生分钟尺度的胰岛素脉冲，因此离体阶跃实验的波形具有明确的实验条件边界。

## 肠促胰素与自主神经调节 { #incretin-neural-control }

相同的血糖轨迹下，口服葡萄糖常比静脉葡萄糖引起更强的胰岛素反应，这一差值反映肠促胰素效应。十二指肠和空肠 K 细胞释放葡萄糖依赖性促胰岛素多肽（glucose-dependent insulinotropic polypeptide，GIP），肠道 L 细胞释放胰高血糖素样肽 1（glucagon-like peptide 1，GLP-1）；“抑胃肽”是 GIP 的历史名称，现代名称强调其促胰岛素作用。两者经 G 蛋白偶联受体提高 β 细胞 cAMP，并通过蛋白激酶 A（protein kinase A，PKA）、交换蛋白直接激活的 cAMP 效应蛋白（exchange protein directly activated by cAMP，EPAC）等途径放大葡萄糖依赖的颗粒释放。这种增益需要 β 细胞先获得葡萄糖代谢所提供的许可。[^incretin-signaling]

GLP-1 还可减慢胃排空，并在适当血糖背景下降低胰高血糖素输出；这些肠—胰反馈与营养物抵达速度共同组织餐后曲线，详见[消化生理总论](../digestive/index.md#enteroendocrine-signaling)。肠 L 细胞主要以 PC1/3 加工胰高血糖素原并生成 GLP-1，α 细胞则主要以 PC2 生成胰高血糖素；组织特异的前体加工决定了两种产物。

进餐前后的迷走传入—传出回路可通过胆碱能等信号增强 β 细胞反应，也能促进胃肠肽释放；这种控制不限定于“右迷走神经”。交感神经释放的去甲肾上腺素经 α$_2$ 肾上腺素能受体抑制 β 细胞分泌，经 β 肾上腺素能受体又可产生促进成分，整体结果取决于受体组成和生理状态。在运动、低血糖或急性应激时，减少胰岛素而动员燃料通常比单独背诵某一受体箭头更能解释净效应。

## 胰岛素的组织特异性作用 { #insulin-action }

胰岛素受体是预先组装并由二硫键连接的受体酪氨酸激酶。胰岛素结合细胞外 α 亚基后解除胞内激酶区的自抑制，受体自磷酸化并招募 IRS 等底物，随后分出 PI3K—AKT、ERK 等信号支路。支路之间有交叉，持续时间和空间定位也不同；受体激活只是入口，完整效应还取决于下游网络。[^insulin-receptor]

| 组织 | 胰岛素的关键作用 | 对全身底物流量的结果 |
| --- | --- | --- |
| 肝 | 抑制糖原分解和糖异生输出，促进糖原合成与糖酵解；抑制酮生成 | 降低门静脉营养输入后的肝糖输出，把碳流转向储存和合成 |
| 骨骼肌 | 促 GLUT4 转位和葡萄糖摄取，促进糖原与蛋白质合成，并促进 K$^+$ 摄取 | 承担大部分胰岛素刺激的餐后葡萄糖清除，补充运动所需储备 |
| 脂肪组织 | 促 GLUT4 转位，提供甘油-3-磷酸与脂质储存条件；强力抑制脂解 | 降低游离脂肪酸进入肝脏，限制空腹型脂肪氧化和酮生成 |

肝细胞的葡萄糖跨膜转运主要经双向 GLUT2，胰岛素通过酶活性、转录和底物供应改变肝脏净摄取或净输出。脑、红细胞等组织也具有胰岛素非依赖的基础葡萄糖摄取，骨骼肌和脂肪组织则依赖胰岛素调节 GLUT4 转位。胰岛素还促进氨基酸摄取和蛋白质合成，抑制蛋白质分解，并使 K$^+$、Mg$^{2+}$、磷酸盐更多进入细胞；这些变化在餐后和生长中与 GH—IGF 轴及营养供应共同作用。[^insulin-receptor]

## 胰高血糖素的分泌与肝脏效应 { #glucagon-control }

α 细胞用 PC2 从胰高血糖素原加工出 29 个氨基酸的胰高血糖素；肠 L 细胞和部分脑区则主要用 PC1/3 从同一前体生成 GLP-1、GLP-2、氧调节素等肽。胰高血糖素受体是以 G$_s$—腺苷酸环化酶—cAMP—PKA 为主要通路的 G 蛋白偶联受体，生理作用最明确的靶器官是肝脏。它迅速促进肝糖原分解，并在较长时间尺度支持糖异生、抑制糖原合成；肝糖原储量会限制同一浓度胰高血糖素能够产生的糖输出幅度。[^glucagon-physiology]

低血糖时，α 细胞本身的电活动和代谢感知、β 细胞胰岛素／Zn$^{2+}$／胰淀素信号的下降、δ 细胞生长抑素抑制的解除，以及自主神经输入共同促进胰高血糖素释放。高糖通常抑制输出，但离体单细胞、完整胰岛和在体研究所得的曲线存在差异，显示人体调节由 α 细胞直接感知与胰岛旁分泌网络共同完成。生长抑素是重要的局部抑制信号；胰岛素的直接作用及其经血糖变化形成的间接反调节，由葡萄糖背景、旁分泌信号和细胞状态共同决定。[^glucagon-crosstalk]

多种氨基酸，尤其在富含蛋白质的进餐后，会同时刺激胰高血糖素和胰岛素。胰高血糖素促进肝脏摄取与处理氨基酸、糖异生和尿素生成；血中氨基酸下降后又减弱 α 细胞刺激，形成肝—α 细胞反馈轴。这个回路既处理膳食氮，也借助肝糖输出降低餐后低血糖风险。空腹时氨基酸底物的外周供应则由低胰岛素、糖皮质激素和组织状态等共同决定。[^glucagon-crosstalk]

胰高血糖素还抑制肝脏新生脂肪合成，并在低胰岛素背景下支持脂肪酸氧化和酮生成；其人体生理作用最明确地集中于肝脏。增强心肌收缩、肾血流和胆汁分泌等效应多见于外源高剂量或特定实验条件，属于与维持空腹肝糖输出不同证据层级的观察。

## 胰岛局部细胞网络 { #local-islet-network }

δ 细胞的树突样突起可接触多个邻近细胞。葡萄糖、氨基酸、胰高血糖素和神经信号都能促进生长抑素释放；生长抑素再通过 SSTR 抑制 α、β 细胞的电活动和胞吐，限制胰岛素或胰高血糖素脉冲的幅度。α 细胞释放的胰高血糖素则可经胰高血糖素受体和 GLP-1 受体提高 β 细胞 cAMP，帮助进餐时的葡萄糖依赖性胰岛素释放。胰岛素和胰高血糖素在肝糖输出上方向相反，在胰岛内部则通过旁分泌网络相互调节。

γ／PP 细胞在蛋白质进餐、迷走兴奋和低血糖等情境下可增加胰多肽释放。外源胰多肽能够改变胃肠运动、胰腺外分泌和摄食，但内源浓度下各效应在人体中的权重仍不确定。把 PP 细胞列入胰岛网络有助于理解胰头区域的细胞组成和迷走标记；内源 PP 的人体全身反馈仍缺少闭合证据。[^islet-architecture]

局部信号的先后次序还会随细胞排列、毛细血管流向和物种而变。人胰岛细胞沿血管交错分布，其血流次序需要依据具体物种、胰区和微血管结构判断。分析旁分泌实验时，应同时说明完整胰岛还是分散细胞、物种、葡萄糖背景和刺激时间。

## 餐后与空腹的通量转换 { #fed-fasted-integration }

混合餐进入小肠后，吸收中的葡萄糖和氨基酸、GIP／GLP-1 以及迷走信号共同提高 β 细胞分泌。门静脉胰岛素首先作用于肝，抑制内源葡萄糖输出；外周胰岛素随后促进肌肉、脂肪的摄取和储存。碳水化合物餐常使胰高血糖素降低，蛋白质或混合餐则可使其维持甚至升高，以支持肝脏氨基酸处理并避免血糖过度下降。餐后两种激素的组合随膳食成分而变化。

两餐之间、夜间禁食、长时间运动或低血糖时，胰岛素下降会解除脂解和肝糖输出的抑制，胰高血糖素及交感—肾上腺等反调节信号则提高可用燃料。禁食早期肝糖原分解贡献较大，随后糖异生、脂肪酸氧化和酮生成的相对份额增加。真正被调节的是葡萄糖出现率与清除率的差额及组织燃料选择，而血液中的葡萄糖只是这个连续通量网络中的小型交换池；动态稳态的一般框架见[内环境与稳态](../internal_env.md#dynamic-homeostasis)。

正常胰岛可以通过分泌量、脉冲和细胞间增益适应一次进餐，慢性营养过剩、自身免疫破坏或持续胰岛素抵抗则可能超过其补偿能力。糖尿病诊断依据规范时点和条件下的血糖或糖化血红蛋白等指标；尿糖还取决于滤过负荷和肾小管转运阈值。1 型、2 型及其他特异类型的区分需要综合病因和生理特征，而非单凭发病年龄或是否使用胰岛素。这些病理机制、酮症酸中毒及治疗问题见[糖与能量代谢紊乱](../pathophysiology/metabolic_disorders.md)。

[^insulin-biosynthesis]: 前胰岛素原进入内质网、胰岛素原折叠、颗粒内 PC1/3／PC2／羧肽酶 E 加工、Zn$^{2+}$ 储存和 C 肽共同释放，见 Weiss 等的[胰岛素合成与结构综述](https://www.ncbi.nlm.nih.gov/books/NBK279029/)。
[^beta-cell-glucose-transport]: 人和啮齿类胰岛中 GLUT 表达的物种差异，以及人 β 细胞以 GLUT1 为主、GLUT3 和少量 GLUT2 共同参与的证据边界，见 Berger 与 Zdzieblo 的[胰岛葡萄糖转运体综述](https://link.springer.com/article/10.1007/s00424-020-02383-4)。
[^insulin-amplification]: Ca$^{2+}$ 触发、代谢放大、颗粒募集与双相分泌的实验框架，见 Kalwat 与 Cobb 的[β 细胞分泌放大通路综述](https://europepmc.org/article/PMC/PMC7269041)。
[^incretin-signaling]: GIP、GLP-1 的现代命名和葡萄糖依赖性促胰岛素作用，见 Hammoud 与 Drucker 的[肠促胰素作用综述](https://www.nature.com/articles/s41574-022-00783-3)。
[^insulin-receptor]: 胰岛素受体结构、IRS—PI3K／ERK 信号及肝、肌、脂肪组织的差异化效应，见 De Meyts 的[胰岛素受体信号综述](https://www.ncbi.nlm.nih.gov/books/NBK378978/)。
[^glucagon-physiology]: 胰高血糖素原的组织特异性加工、受体信号、肝糖输出和肝脏脂质／氨基酸代谢，见 Rix 等的[胰高血糖素生理综述](https://www.ncbi.nlm.nih.gov/books/NBK279127/)。
[^glucagon-crosstalk]: α 细胞的直接感知与胰岛素、生长抑素旁分泌调节，以及肝—α 细胞氨基酸反馈，见 Hædersdal 等的[胰高血糖素综述](https://www.nature.com/articles/s41574-023-00817-4)。
