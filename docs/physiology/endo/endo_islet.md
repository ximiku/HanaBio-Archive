# 胰岛内分泌

胰岛散布在胰腺外分泌腺泡和导管之间，却不是几类内分泌细胞的松散集合。每个胰岛都把营养物、肠源信号、自主神经活动和局部细胞间通信汇入同一微循环，再以胰岛素、胰高血糖素、生长抑素等脉冲式输出改变肝、骨骼肌和脂肪组织的底物流量。它调节的因而不只是某一时刻的“血糖值”，而是葡萄糖进入血液与被组织清除、脂肪酸储存与动员、氨基酸摄取与肝脏处理之间的动态平衡。

理解这套系统需要同时追踪三个层级：胰岛细胞怎样感知底物并释放颗粒，几类细胞怎样在局部互相调节，以及外周器官怎样读取门静脉中的胰岛素—胰高血糖素组合。具体代谢反应见[糖原代谢](../../biochem/glycogen.md#tissue-specific-regulation)、[糖异生](../../biochem/gng.md#regulation)与[脂质分解代谢](../../biochem/lipid_catabolism.md#fatty-acid-oxidation-regulation)；糖尿病分型、酮症酸中毒和药物治疗属于[糖与能量代谢紊乱](../pathophysiology/metabolic_disorders.md)，不在正常生理页展开。

## 胰岛是多细胞、多血管的内分泌微器官 { #islet-microorgan }

胰岛内分泌细胞贴近有窗毛细血管，细胞极性、细胞接触和细胞外基质共同决定分泌颗粒朝血管侧释放的效率。血流把葡萄糖、氨基酸和循环激素带入胰岛，也迅速带走局部释放的肽；交感、迷走和感觉神经末梢又可在进餐、运动与低血糖等状态下改变分泌增益。人胰岛中 α、β、δ 细胞较为交错，并常围绕血管组成重复的小单元，不能把啮齿类常见的“β 细胞核心、非 β 细胞外套”当作所有物种和所有胰区的固定结构。[^islet-architecture]

| 细胞类型 | 主要分泌物 | 主要系统作用 | 重要局部作用 |
| --- | --- | --- | --- |
| β 细胞 | 胰岛素、C 肽、胰淀素 | 促进餐后底物利用和储存，抑制肝糖输出与脂肪动员 | 胰岛素、Zn$^{2+}$、胰淀素等共同参与 α 细胞调节 |
| α 细胞 | 胰高血糖素 | 维持空腹、运动和低血糖时的肝糖输出，促进肝脏氨基酸周转 | 胰高血糖素可通过 cAMP 信号增强 β、δ 细胞分泌 |
| δ 细胞 | 生长抑素 | 循环内分泌作用有限 | 经不同 SSTR 抑制邻近 α、β 细胞，限制分泌波动的幅度 |
| γ／PP 细胞 | 胰多肽 | 参与胰—肠—脑轴，效应具有状态和剂量依赖性 | 可能调节胰岛及胰腺外分泌，人体正常生理意义仍未完全厘清 |
| ε 细胞 | ghrelin | 在胚胎和新生期更显著 | 成人胰岛中稀少，不宜与前四类并列为主要输出 |

传统笔记中的 D1／H 细胞—血管活性肠肽（VIP）配对并不是现代人体胰岛的稳定主细胞分类。VIP 在胰腺中主要还来自神经纤维等来源，功能上应作为神经—旁分泌调节因子理解。各类细胞的比例也随胰头、体、尾部和胰岛大小变化，尤其 γ／PP 细胞在胰头腹侧来源区域富集；因此，不用一组百分比概括整个胰腺。[^islet-architecture]

## 胰岛素在分泌颗粒成熟过程中形成 { #insulin-biosynthesis }

β 细胞在粗面内质网上翻译前胰岛素原（preproinsulin）。信号肽引导新生链进入内质网腔后即被切除，所得胰岛素原（proinsulin）折叠并形成正确的二硫键。胰岛素原随后通过 Golgi 体进入未成熟分泌颗粒；随着颗粒酸化，PC1/3、PC2 和羧肽酶 E 在颗粒内依次切开连接区，产生由二硫键相连的 A、B 链胰岛素和 C 肽。加工可以从反式 Golgi 网络开始，却主要在不断成熟的颗粒中完成，不能写成“胰岛素原在 Golgi 体内一次水解为成品”。[^insulin-biosynthesis]

成熟颗粒中的胰岛素可在 Zn$^{2+}$ 参与下形成稳定六聚体，以便高浓度储存；颗粒释放并稀释到循环后，单体才是与受体结合的主要形式。胰岛素和 C 肽由同一前体等摩尔生成，但胰岛素先经门静脉到达肝脏并被大量首过清除，C 肽的清除动力学则不同，所以 C 肽可帮助估计内源性 β 细胞分泌。C 肽对于前体正确折叠不可缺少，却不具有胰岛素样受体激动活性；实验报道的 Na$^+$ 泵、NO 等效应尚不足以把它改写成正常底物分配的主调节激素。[^insulin-biosynthesis]

## β 细胞把底物代谢转成 Ca$^{2+}$ 依赖的胞吐 { #glucose-stimulated-secretion }

### 触发通路把 ATP 变化接到颗粒融合 { #triggering-pathway }

葡萄糖经易化扩散进入 β 细胞，并由葡糖激酶磷酸化后进入代谢。人 β 细胞主要表达 GLUT1，并有 GLUT3、少量 GLUT2 等参与；小鼠和大鼠 β 细胞则更依赖 GLUT2。葡萄糖浓度感知的关键限制环节是葡糖激酶与后续代谢，而不是把人 β 细胞简单写成一只“GLUT2 血糖感受器”。[^beta-cell-glucose-transport]

葡萄糖氧化提高胞质 ATP／ADP 比，促使由 Kir6.2 和 SUR1 组成的 ATP 敏感性 K$^+$ 通道关闭。K$^+$ 外流减少使膜去极化，电压门控 Ca$^{2+}$ 通道开放，Ca$^{2+}$ 内流触发已具释放能力的胰岛素颗粒与质膜融合。精氨酸可借正电荷促进去极化，亮氨酸等氨基酸可通过代谢加强分泌；脂肪酸也能在特定营养背景下放大反应。短时促进分泌与长期营养过剩造成的受体减敏、内质网压力和细胞功能受损不是同一个过程，酮体也不是在所有浓度和状态下都能独立启动胰岛素释放。

### 代谢放大通路提高同一 Ca$^{2+}$ 信号的释放效率 { #amplifying-pathway }

关闭 K$_{ATP}$ 通道所形成的 Ca$^{2+}$ 触发并不能解释葡萄糖的全部效应。在已有相近 Ca$^{2+}$ 信号时，葡萄糖代谢还会产生多种放大信号，改变颗粒准备、细胞骨架重排和胞吐装置，使同一 Ca$^{2+}$ 输入释放更多胰岛素。这个代谢放大通路依赖营养物代谢和触发通路，却不等同于继续升高 Ca$^{2+}$，其中参与的代谢物和效应蛋白仍有未决之处。[^insulin-amplification]

当实验把葡萄糖浓度突然阶跃升高时，常见第一相快速峰和第二相持续释放。第一相主要动用已停靠或迅速到达膜面的高释放能力颗粒，第二相则持续募集储备颗粒，并受代谢放大、细胞骨架和新来颗粒影响。它不是“储存颗粒全部耗尽后回落—等待新合成—β 细胞立即增殖”的四阶段过程；在体内，进餐输入渐变、肠促胰素和神经信号叠加，多个胰岛还会产生分钟尺度的胰岛素脉冲，波形不能由离体阶跃实验机械外推。

## 肠促胰素与自主神经标记进餐情境 { #incretin-neural-control }

相同的血糖轨迹下，口服葡萄糖常比静脉葡萄糖引起更强的胰岛素反应，这一差值反映肠促胰素效应。十二指肠和空肠 K 细胞释放葡萄糖依赖性促胰岛素多肽（GIP），肠道 L 细胞释放胰高血糖素样肽 1（GLP-1）；“抑胃肽”是 GIP 的历史名称，不能代表其主要生理身份。两者经 G 蛋白偶联受体提高 β 细胞 cAMP，并通过 PKA、EPAC 等途径放大葡萄糖依赖的颗粒释放。它们提供的是进餐背景下的增益，而不是在 β 细胞缺乏代谢许可时无条件打开分泌。[^incretin-signaling]

GLP-1 还可减慢胃排空，并在适当血糖背景下降低胰高血糖素输出；这些肠—胰反馈与营养物抵达速度共同组织餐后曲线，详见[消化生理总论](../digestive/index.md#enteroendocrine-signaling)。肠 L 细胞的 GLP-1 与 α 细胞的胰高血糖素来自同一胰高血糖素原基因，却由不同前体转化酶加工，不能把 GLP-1 写成胰岛 α 细胞把胰高血糖素“再切一次”的产物。

进餐前后的迷走传入—传出回路可通过胆碱能等信号增强 β 细胞反应，也能促进胃肠肽释放；这种控制不限定于“右迷走神经”。交感神经释放的去甲肾上腺素经 α$_2$ 肾上腺素能受体抑制 β 细胞分泌，经 β 肾上腺素能受体又可产生促进成分，整体结果取决于受体组成和生理状态。在运动、低血糖或急性应激时，减少胰岛素而动员燃料通常比单独背诵某一受体箭头更能解释净效应。

## 胰岛素按组织职责重排餐后底物 { #insulin-action }

胰岛素受体是预先组装并由二硫键连接的受体酪氨酸激酶。胰岛素结合细胞外 α 亚基后解除胞内激酶区的自抑制，受体自磷酸化并招募 IRS 等底物，随后分出 PI3K—AKT、ERK 等信号支路。支路之间有交叉，持续时间和空间定位也不同，所以“胰岛素受体是酪氨酸激酶”只是作用的入口，而不是全部机制。[^insulin-receptor]

| 组织 | 胰岛素的关键作用 | 对全身底物流量的结果 |
| --- | --- | --- |
| 肝 | 抑制糖原分解和糖异生输出，促进糖原合成与糖酵解；抑制酮生成 | 降低门静脉营养输入后的肝糖输出，把碳流转向储存和合成 |
| 骨骼肌 | 促 GLUT4 转位和葡萄糖摄取，促进糖原与蛋白质合成，并促进 K$^+$ 摄取 | 承担大部分胰岛素刺激的餐后葡萄糖清除，补充运动所需储备 |
| 脂肪组织 | 促 GLUT4 转位，提供甘油-3-磷酸与脂质储存条件；强力抑制脂解 | 降低游离脂肪酸进入肝脏，限制空腹型脂肪氧化和酮生成 |

肝细胞的葡萄糖跨膜转运主要经双向 GLUT2，并不依赖胰岛素招募 GLUT4；胰岛素通过酶活性、转录和底物供应改变肝脏净摄取或净输出。脑、红细胞等组织也具有胰岛素非依赖的基础葡萄糖摄取。因此，“胰岛素促进全身所有细胞摄糖”会同时错写肝脏方向性和脑、红细胞的转运条件。胰岛素还促进氨基酸摄取和蛋白质合成，抑制蛋白质分解，并使 K$^+$、Mg$^{2+}$、磷酸盐更多进入细胞；这些变化在餐后和生长中与 GH—IGF、营养供应共同作用，不意味着胰岛素单独决定组织生长。[^insulin-receptor]

## α 细胞把低糖与氨基酸负荷转成肝脏输出 { #glucagon-control }

α 细胞用 PC2 从胰高血糖素原加工出 29 个氨基酸的胰高血糖素；肠 L 细胞和部分脑区则主要用 PC1/3 从同一前体生成 GLP-1、GLP-2、氧调节素等肽。胰高血糖素受体是以 G$_s$—腺苷酸环化酶—cAMP—PKA 为主要通路的 G 蛋白偶联受体，生理作用最明确的靶器官是肝脏。它迅速促进肝糖原分解，并在较长时间尺度支持糖异生、抑制糖原合成；当肝糖原已经耗竭时，同样浓度的胰高血糖素不能凭空产生同等幅度的糖输出。[^glucagon-physiology]

低血糖时，α 细胞本身的电活动和代谢感知、β 细胞胰岛素／Zn$^{2+}$／胰淀素信号的下降、δ 细胞生长抑素抑制的解除，以及自主神经输入共同促进胰高血糖素释放。高糖通常抑制输出，但离体单细胞、完整胰岛和在体研究所得的曲线并不完全相同，说明“葡萄糖直接作用于 α 细胞的唯一离子通道开关”尚不足以概括人体调节。生长抑素是重要的局部抑制信号；胰岛素的直接抑制与其降低血糖后的间接反调节也应分层理解，不能写成低浓度抑制、高浓度固定促进的简单双相关系。[^glucagon-crosstalk]

多种氨基酸，尤其在富含蛋白质的进餐后，会同时刺激胰高血糖素和胰岛素。胰高血糖素促进肝脏摄取与处理氨基酸、糖异生和尿素生成；血中氨基酸下降后又减弱 α 细胞刺激，形成肝—α 细胞反馈轴。这个回路既处理膳食氮，也防止只有胰岛素上升时出现餐后低血糖。它不要求胰高血糖素直接分解骨骼肌蛋白：空腹时氨基酸底物的外周供应由低胰岛素、糖皮质激素和组织状态等共同决定。[^glucagon-crosstalk]

胰高血糖素还抑制肝脏新生脂肪合成，并在低胰岛素背景下支持脂肪酸氧化和酮生成；人体脂肪组织并不是其最确定的直接脂解靶器官。旧笔记所列增强心肌收缩、肾血流和胆汁分泌，多来自外源高剂量或特定实验条件，不宜与维持空腹肝糖输出并列为正常生理主效应。

## 局部细胞网络调节分泌增益 { #local-islet-network }

δ 细胞的树突样突起可接触多个邻近细胞。葡萄糖、氨基酸、胰高血糖素和神经信号都能促进生长抑素释放；生长抑素再通过 SSTR 抑制 α、β 细胞的电活动和胞吐，使胰岛素或胰高血糖素的脉冲不至于无限放大。α 细胞释放的胰高血糖素则可经胰高血糖素受体和 GLP-1 受体提高 β 细胞 cAMP，帮助进餐时的葡萄糖依赖性胰岛素释放。由此，胰岛素和胰高血糖素虽在肝糖输出上方向相反，在胰岛内部却不只是彼此抵消。

γ／PP 细胞在蛋白质进餐、迷走兴奋和低血糖等情境下可增加胰多肽释放。外源胰多肽能够改变胃肠运动、胰腺外分泌和摄食，但内源浓度下各效应在人体中的权重仍不确定。把 PP 细胞列入胰岛网络有助于理解胰头区域的细胞组成和迷走标记，却不应把尚未闭合的结果写成固定的全身反馈环。[^islet-architecture]

局部信号的先后次序还会随细胞排列、毛细血管流向和物种而变。人胰岛细胞沿血管交错分布，不能依据一张啮齿类剖面图规定“血液必先流过 β 细胞再到 α、δ 细胞”。分析旁分泌实验时，应同时说明完整胰岛还是分散细胞、物种、葡萄糖背景和刺激时间。

## 餐后与空腹是两套连续转换的通量状态 { #fed-fasted-integration }

混合餐进入小肠后，吸收中的葡萄糖和氨基酸、GIP／GLP-1 以及迷走信号共同提高 β 细胞分泌。门静脉胰岛素首先作用于肝，抑制内源葡萄糖输出；外周胰岛素随后促进肌肉、脂肪的摄取和储存。碳水化合物餐常使胰高血糖素降低，但蛋白质或混合餐可使胰高血糖素维持甚至升高，以支持肝脏氨基酸处理并避免血糖过度下降。因此，餐后状态不能写成“胰岛素开、胰高血糖素关”的二元开关。

两餐之间、夜间禁食、长时间运动或低血糖时，胰岛素下降会解除脂解和肝糖输出的抑制，胰高血糖素及交感—肾上腺等反调节信号则提高可用燃料。禁食早期肝糖原分解贡献较大，随后糖异生、脂肪酸氧化和酮生成的相对份额增加。真正被调节的是葡萄糖出现率与清除率的差额及组织燃料选择，而血液中的葡萄糖只是这个连续通量网络中的小型交换池；动态稳态的一般框架见[内环境与稳态](../internal_env.md#dynamic-homeostasis)。

正常胰岛可以通过分泌量、脉冲和细胞间增益适应一次进餐，却不保证在慢性营养过剩、自身免疫破坏或持续胰岛素抵抗下仍能补偿。糖尿病的诊断不能化约成“每次测量都高血糖”，尿糖还取决于滤过负荷和肾小管转运阈值；1 型、2 型及其他特异类型也不能用发病年龄、是否终生用胰岛素或粗略族群标签相互替代。这些病理机制、酮症酸中毒及二甲双胍、α-葡糖苷酶抑制剂等治疗问题统一留给病理生理页面。
