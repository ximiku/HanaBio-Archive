# 松果体、组织激素与器官内分泌

内分泌功能并不只属于垂体、甲状腺或肾上腺这类形态清楚的腺体。松果体把环境光暗转换成有昼夜相位的褪黑素信号；脂肪、骨骼肌和骨根据能量储备、收缩负荷与矿物状态释放信号；心、肾和胃肠等功能器官也把自身承受的机械、化学或代谢变化报告给远处组织。它们共同说明，判断一种分泌信号时，比“它是否来自一枚腺体”更重要的是细胞来源、释放条件、传播距离、受体位置和作用时程。

本文先讨论松果体的时间信息，再说明前列腺素等局部介质、脂肪—肌肉—骨之间的代谢通信，以及心、肾和胃肠等器官的内分泌接口。各系统页已经完整展开的轴只在这里建立联系；肾上腺髓质素则承接自[肾上腺髓质内分泌](endo_ad_medulla.md#adrenomedullin-boundary)，放回广泛组织来源的背景中。

## 分泌距离而非器官名称界定信号方式 { #distributed-endocrine-signaling }

经典内分泌信号进入循环，在低浓度下到达远处表达相应受体的靶细胞；旁分泌信号主要影响邻近细胞，自分泌信号反馈于分泌细胞本身。三种方式是传播尺度，不是互斥的分子身份：同一种分子可以在一个组织内构成旁分泌回路，又有一部分进入血液形成内分泌作用。肠肽、细胞因子、脂质介质和器官来源的肽尤其常跨越这些边界。

“组织激素”或 autacoid 是历史上对局部生成、作用短暂的生物活性物质的概括，并不是与肽类、类固醇或胺类平行的化学类别。要证明某组织是某种循环信号的生理来源，至少需要区分组织内表达、向细胞外释放、循环中可达浓度和远端受体效应；仅在组织匀浆中检出免疫反应性物质，不能自动建立一条人体内分泌轴。

## 松果体把光暗周期编码为褪黑素时相 { #pineal-melatonin }

人松果体位于第三脑室顶部后方，是血供丰富的神经内分泌器官。哺乳动物松果体细胞不直接感光，光信息由含 melanopsin 的视网膜神经节细胞经视网膜—下丘脑束送入视交叉上核（SCN）。SCN 作为内源性昼夜振荡器，即使在恒暗条件下仍能产生接近 24 h 的节律；环境光暗则把这一节律同步到外界昼夜，而不是每日从零启动一只时钟。[^pineal-physiology]

### 多突触交感通路把中枢相位送到松果体 { #pineal-neural-route }

从 SCN 到松果体的输出依次经过下丘脑室旁核、上胸段脊髓中间外侧柱和颈上交感神经节，最后由节后去甲肾上腺素能纤维支配松果体。夜间交感末梢释放去甲肾上腺素，主要激活松果体细胞的 $\beta_1$ 受体，并由 $\alpha_1$ 信号增强响应；光照可经视网膜—SCN 通路抑制这一输出，使夜间褪黑素合成迅速下降。这里的交感活动传递的是时相信息，与[肾上腺髓质](endo_ad_medulla.md#stimulus-secretion-coupling)在低血糖、失血或威胁时的快速动员不能合并成同一反应。

### 合成、释放与受体共同构成时间信号 { #melatonin-synthesis-action }

褪黑素是 tryptophan 的吲哚胺衍生物。松果体细胞先由 serotonin 生成 *N*-acetylserotonin，这一步由芳烷基胺 *N*-乙酰转移酶（AANAT）催化；乙酰血清素 *O*-甲基转移酶（ASMT）再生成 melatonin。它不大量储存在分泌颗粒中，合成后即进入血液和脑脊液，因此循环浓度能紧随夜间合成通量。肝脏主要经 CYP1A2 生成 6-hydroxymelatonin，再结合为尿中 6-sulfatoxymelatonin；后者可作为有时间延迟的分泌指标。[^melatonin-synthesis]

夜间升高的 melatonin 通过 MT$_1$、MT$_2$ 等 G 蛋白偶联受体向 SCN、垂体结节部、视网膜及外周组织传递“生物学夜晚”。MT$_1$ 可降低 SCN 神经元放电，MT$_2$ 更突出地参与相位移动；具体结果取决于信号出现的昼夜相位，因而褪黑素更准确的定位是 chronobiotic（节律定时信号），不是不分时刻、剂量和个体都产生同一强度镇静的“天然安眠开关”。夜间分泌持续时间还能编码季节性光周期，这在季节繁殖动物中作用明确；人类青春期、生殖和月经周期的相关资料却不支持“统一抑制性腺”或“经前最高、排卵最低”的固定规律。[^melatonin-timing]

褪黑素节律在出生后逐渐建立，儿童期振幅较高，随后总体下降，但年龄、光照史、睡眠时相、眼部感光能力、药物和个体差异都会改变测量结果。原素材把“自青春期起递减”写成单向年龄曲线，也把镇痛、抗惊厥、抗抑郁和免疫效应并列成已确定的日常生理作用；这些方向包含实验与临床研究线索，却不能替代人体中最稳固的光暗—昼夜相位功能。旧资料所谓松果体“8-精缩宫素”来自 arginine vasotocin-like 免疫反应性材料和早期候选研究，尚不足以把 AVT 列为人松果体与褪黑素并列的已确立循环激素。[^pineal-avt]

## 前列腺素在生成部位附近重排局部反应 { #prostanoids }

前列腺素不是由前列腺专门分泌。细胞受到机械、炎症、激素或其他刺激后，磷脂酶 A$_2$ 可从膜磷脂释放 arachidonic acid；COX-1 或 COX-2 依次生成 PGG$_2$、PGH$_2$，不同末端合酶再产生 PGE$_2$、PGD$_2$、PGF$_{2\alpha}$、prostacyclin（PGI$_2$）和 thromboxane A$_2$（TXA$_2$）。PG、PGI 和 TX 合称 prostanoids；经典 PG 具有环戊烷骨架和两条侧链，但“组织激素”并不由这一结构定义。[^prostanoid-review]

这些脂质通常按需合成、局部释放并快速失活，通过 EP、DP、FP、IP、TP 等受体形成组织和状态依赖的效应。血管内皮来源 PGI$_2$ 经 IP—cAMP 信号舒张血管并抑制血小板活化，活化血小板来源 TXA$_2$ 则经 TP 促进聚集和收缩；这对方向相反的信号构成止血边界的一部分，却不能推导出“不同前列腺素总是彼此拮抗”。PGE$_2$ 的不同 EP 受体可参与发热、痛觉敏化、胃黏膜保护、肾血流和生殖过程，PGF$_{2\alpha}$ 又可参与子宫与其他平滑肌反应。同一分子在不同受体和组织中甚至可以改变方向，详见[循环的内皮调节](../blood/blood_regulation.md#endothelial-and-kinin-control)、[生理性止血](../blood/blood_hemostasis.md#vascular-boundary)和[分娩](../reproductive.md#parturition)。

## 脂肪组织向脑和代谢器官报告储能状态 { #adipose-endocrine }

脂肪组织包含脂肪细胞、内皮、免疫细胞、前体细胞和细胞外基质，分泌蛋白、脂质、细胞因子、细胞外囊泡及小 RNA。一个分泌物被称为 adipokine，不表示它只由成熟脂肪细胞产生；例如人 resistin 的重要来源是单核细胞／巨噬细胞，而小鼠主要由脂肪细胞表达。把整块组织的表达量直接归给脂肪细胞，会混淆细胞来源与物种差异。[^adipose-endocrine-review]

### Leptin 报告能量储备是否足以维持长期投入 { #leptin }

Leptin 主要由白色脂肪细胞分泌，循环水平总体随脂肪量增加，也会受进食、禁食、胰岛素、炎症和昼夜节律影响。长型 leptin receptor 属 I 类细胞因子受体，经 JAK—STAT 等通路作用于弓状核及其他脑区：POMC 神经元与 AgRP/NPY 神经元网络共同改变摄食、自主输出和神经内分泌状态。Leptin 下降尤其像“储备不足”信号，可在禁食或低脂量时提高食欲、降低能量消耗，并压低生殖和甲状腺等长期投入；它不是只在脂肪细胞内直接“抑制合成、促进分解”的局部开关。

高脂量常伴高 leptin，但肥胖状态可出现选择性 leptin resistance，所以分泌更多并不保证摄食继续等比例下降。先天 leptin 缺乏时补充可恢复缺失信号，也不能据此推断给所有高 leptin 肥胖者增加 leptin 都能降低体重。能量储备、摄食与体温的全身收支见[能量代谢与体温](../energy.md#whole-body-energy-balance)。

### Adiponectin 把健康脂肪储存能力连接到胰岛素敏感性 { #adiponectin }

Adiponectin 由脂肪细胞大量分泌，却常在脂肪量增加和代谢功能障碍时降低。它以三聚体、六聚体和高分子量复合物等形式存在，AdipoR1、AdipoR2 与 T-cadherin 对不同形式的结合和组织分配并不相同。AdipoR1／R2 虽是七次跨膜蛋白，却与经典 GPCR 拓扑和信号方式不同；AMPK、PPAR$\alpha$、ceramide 代谢等是其多条下游联系，不能概括成“不与 G 蛋白偶联，所以只由 AMPK 介导”。[^adiponectin-signaling]

在人和动物研究中，adiponectin 与肝、骨骼肌的脂肪酸氧化、肝糖输出抑制和胰岛素敏感性相关，但具体作用随分子形式、组织和代谢背景变化。原素材进一步写成“促进胰岛素分泌、抑制脂肪合成、促进脂肪分解”的统一箭头，混合了直接作用、相关性和不同实验系统；本页保留的是它作为脂肪组织状态信号与代谢器官之间的接口，而非跨组织通用反应式。

## 收缩的骨骼肌形成状态依赖的分泌谱 { #muscle-secretome }

骨骼肌分泌的蛋白质和肽常称 myokines；运动还可改变代谢物、脂质和细胞外囊泡等更广义 exerkines。分泌谱取决于收缩方式、强度、持续时间、糖原状态和训练背景，同一因子也可能由脂肪、免疫细胞或其他器官产生。收缩时升高的 muscle-derived IL-6 是重要范例，可在肌内及远端参与底物供应和免疫—代谢通信，但它的短时脉冲不能与慢性炎症中持续升高的 IL-6 简单等同。许多候选 myokines 在细胞或啮齿动物中有清晰作用，而人体来源、循环增量和必需性仍未完全确定。[^myokine-review]

Myostatin（GDF8）是 TGF-$\beta$ 超家族成员，对骨骼肌生长施加负向约束；基因缺失可在小鼠中造成显著肌量增加。它确实“高度保守”并抑制肌肉生长，但原素材同时赋予“降血糖、降脂肪”标签，容易把抑制 myostatin 后肌量或体成分变化倒写成该分子的直接日常效应。更稳妥的主线是肌肉生长制动，代谢后果则受物种、发育和干预背景影响。素材中的“肌肉素”没有对应稳定、唯一的分子名称；应以 myokine 类群理解，不把 irisin、myonectin 等候选物合并成一个激素。[^myostatin]

## 骨以局部重塑信号和远端矿物轴参与通信 { #bone-endocrine }

骨不是只存放 Ca$^{2+}$ 的惰性仓库。骨细胞和成骨细胞产生的 FGF23 可经循环作用于肾脏 αKlotho—FGFR 复合物，降低磷重吸收并限制 1,25(OH)$_2$D，是证据较完整的骨—肾内分泌轴，详见[钙磷调节](endo_capi.md#fgf23-axis)。另一方面，RANKL 与 osteoprotegerin（OPG）的主要意义在骨微环境：成骨细胞谱系的 RANKL 促进破骨细胞形成，OPG 作为诱饵受体截获 RANKL。将 OPG 简写成“护骨素抑制骨溶解”保留了净方向，却遗漏了细胞来源、配体竞争和局部重塑条件。

| 骨来源分子 | 已确认的主要身份 | 需要保留的证据边界 |
| --- | --- | --- |
| FGF23 | 循环磷调节激素 | 骨—肾轴明确；产生量还受矿化、铁、炎症和蛋白加工影响 |
| Osteocalcin | 成骨细胞产生的骨基质蛋白、骨形成指标 | 小鼠研究提出未羧化形式调节胰岛、睾丸、肌肉和脑；人体关联尚不足以确认同等强度的统一内分泌轴 |
| OPG／RANKL | 骨重塑中的配体—诱饵受体系统 | 虽可在循环中检测，核心生理解释仍是局部控制破骨细胞发生 |
| Osteopontin、bone sialoprotein | 矿化基质中的黏附性／调节性蛋白 | 可影响细胞黏附、矿化或吸收，不应仅凭名称列为“促进骨吸收／形成”的循环激素 |
| Osteocrin／musclin 等候选 osteokines | 实验性骨—肌—血管信号 | 来源并非总是骨专属，人体系统作用与定量贡献仍在研究 |

Osteocalcin 的代谢、生殖和神经效应在基因改造小鼠中形成了影响广泛的模型，也有不少人体观察性关联；但羧化状态、检测方法、肾清除、骨转换速度和混杂因素会改变循环测量，人体因果证据尚未把这些关联统一成一条确定轴。因此不能把“骨钙素维持骨钙”当作它的主要作用，也不能把实验性远端效应写成既定人体定律。[^osteocalcin-evidence]

## 功能器官以专门信号报告自身负荷 { #organ-endocrine-interfaces }

许多器官既完成运输、消化或机械做功，又从执行状态中生成反馈信号。这里的共同结构是“局部变量—感知细胞—分泌物—远端效应器”，而不是把一串器官重新命名为内分泌腺。

| 报告器官与局部变量 | 代表性输出 | 主要远端接口 |
| --- | --- | --- |
| 心脏：心房牵张、心室压力或容量负荷 | ANP、BNP | NPR-A—cGMP 促进排钠并抑制保钠通路；见[循环体液调节](../blood/blood_regulation.md#circulating-hormones) |
| 肾脏：灌注／NaCl 递送、局部氧合、矿物状态 | Renin、EPO、calcitriol | 分别连接 RAAS、骨髓红系和肠—骨矿物流量；见[泌尿生理总论](../urinary/index.md#renal-homeostasis)与[肾源 EPO](../blood/blood_cell.md#epo-axis) |
| 胃肠上皮：营养物、酸、胆汁酸和微生物代谢物 | Gastrin、CCK、secretin、GIP、GLP-1、PYY 等 | 协调消化道、胰腺、胰岛、脑和摄食；见[肠内分泌信号](../digestive/index.md#enteroendocrine-signaling) |
| 肝脏：营养、铁、炎症与生长状态 | IGF-I、angiotensinogen、hepcidin、thrombopoietin、FGF21 等 | 分别接入生长、循环、铁稳态、造血和能量代谢；不同产物受完全不同的上游控制 |

这种分工也解释了为什么“由某器官产生”不等于“只作用于该器官”。EPO 的效应主要在骨髓，ANP 的关键靶点包含肾脏和血管，肠促胰素到达胰岛，而肝源 angiotensinogen 还需肾素和血管酶系逐级加工。反之，同一器官内部也常有局部信号而不构成显著循环输出。[^organ-endocrine-reviews]

## 肾上腺髓质素主要体现广泛组织的血管旁分泌 { #adrenomedullin }

肾上腺髓质素（ADM）因最初从人嗜铬细胞瘤中分离而得名，但正常人体中并非肾上腺髓质专属。血管内皮和平滑肌、心、肺、肾、脂肪组织及多类免疫细胞都可表达其前体。成熟 ADM 通过降钙素受体样受体（CALCRL）与 RAMP2 或 RAMP3 组成的 AM$_1$、AM$_2$ 受体，引发 cAMP、NO 等信号；RAMP 既参与配体选择，也影响受体转运和组织分布。[^adrenomedullin-review]

在血管床中，ADM 可促进舒张并维持内皮屏障；在肾和心血管系统中还会与灌注、滤过、Na$^+$ 转运、交感和 RAAS 相互作用。循环浓度常在心衰、感染和其他应激状态升高，但这既可能反映代偿，也可能是疾病严重度标志，不能由相关性直接推出“护心”。原素材的“利水、利 Na、降压、护心”应拆回剂量、来源、受体、器官和病理背景；在正常生理中，ADM 更适合作为局部血管—组织稳态网络的一员，而不是另一条单腺体主轴。
