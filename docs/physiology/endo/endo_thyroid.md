# 甲状腺内分泌

甲状腺滤泡把激素合成安排在一个很不寻常的位置：滤泡上皮将甲状腺球蛋白分泌到腔内胶质，碘化和偶联也在细胞顶端—胶质界面完成。由此形成的碘化蛋白可以在细胞外保存较大的激素储备，待需要时再被内吞、裂解释放。这套缓慢而有库存的分泌方式，与垂体促甲状腺激素（TSH）的持续调节、血中结合蛋白的缓冲和组织内脱碘酶的局部加工共同决定甲状腺激素信号。

甲状腺主要释放甲状腺素（T$_4$）和少量三碘甲状腺原氨酸（T$_3$）。T$_4$ 更像循环中的前体和储备，许多组织把它转为受体亲和力更高的 T$_3$；反三碘甲状腺原氨酸（rT$_3$）则主要是 T$_4$ 失活产生的代谢物，不能与 T$_3$ 并列为活性输出。因而理解这一系统需要依次追踪滤泡合成、血中运输、跨膜进入、组织内活化和核受体响应，而不能只看一次血液中的总 T$_4$ 浓度。

## 滤泡把合成反应组织在细胞—胶质界面 { #thyroid-follicle }

滤泡由单层、具有顶端—基底外侧极性的上皮细胞围成，腔内胶质以甲状腺球蛋白（thyroglobulin, Tg）为主要成分。Tg 在粗面内质网和高尔基体中合成、糖基化，随后从顶端分泌入滤泡腔；它既提供可被碘化的 Tyr 残基，也把尚未释放的 T$_4$、T$_3$ 残基保存在大分子骨架上。甲状腺因此拥有远大于即时分泌量的细胞外激素库存，但“胶质很多”不等于当前释放一定很多：库存形成、回收和血中输出是不同步骤。[^synthesis-endotext]

滤泡外侧紧邻有窗毛细血管。基底外侧膜面对血液，承担碘离子摄取并接收 TSH；顶端膜面对胶质，承担 Tg 分泌、碘的顶端转运、氧化碘化和胶质内吞。极性一旦被忽略，常会把原本分隔在两侧膜和细胞外腔隙的反应误写成细胞质中的一条均相合成路线。

## 碘离子依次经历摄取、碘化、偶联与回收 { #hormone-synthesis }

### 基底外侧摄碘与顶端转运建立原料通路 { #iodide-transport }

血浆中的 I$^-$ 先由基底外侧 Na$^+$／I$^-$ 同向转运体 NIS（SLC5A5）摄入滤泡细胞。NIS 利用 Na$^+$ 电化学梯度，梯度本身由 Na$^+$／K$^+$-ATPase 维持；因此它属于继发性主动转运，而不是直接水解 ATP 的“碘泵”。I$^-$ 随后跨过顶端膜进入胶质，pendrin（SLC26A4）参与这一过程，但顶端碘转运并非只由一个载体完成。TSH 可在多个时间尺度上增强 NIS 表达、定位以及后续合成装置的活动。[^synthesis-endotext]

高氯酸根和硫氰酸根对 NIS 的竞争性抑制，以及硫脲类药物对甲状腺过氧化物酶反应的抑制，常被用来辨认合成链的不同位置；它们是药理干预或机制探针，不是正常反馈回路中的生理信号。把“抑制 TPO”写成“阻止 TPO 蛋白合成”，也会混淆酶活性与表达量。

### 顶端氧化、碘有机化和偶联发生在 Tg 上 { #organification-coupling }

顶端膜附近的双氧化酶 DUOX2 及其成熟因子 DUOXA2 提供 H$_2$O$_2$，含血红素的甲状腺过氧化物酶（TPO）则利用 H$_2$O$_2$ 催化 I$^-$ 氧化，并使 Tg 上合适的 Tyr 残基发生碘有机化，生成单碘酪氨酸（MIT）和二碘酪氨酸（DIT）。这个反应由酶和局部界面约束，不宜把产物描写成在滤泡腔内自由游走的中性“碘原子”。[^synthesis-endotext]

TPO 还催化 Tg 内碘酪氨酸残基的氧化偶联：两个 DIT 的组合形成 T$_4$ 残基，MIT 与 DIT 的组合可形成三碘产物；残基的供体—受体方向决定形成 T$_3$ 还是 rT$_3$。新形成的碘甲状腺原氨酸此时仍嵌在 Tg 中，只有在 Tg 被水解后才成为可分泌的游离激素。生化反应与 Tyr 前体关系另见[氨基酸及其衍生物的合成](../../biochem/aa_synthesis.md#neurotransmitters-hormones-pigments)。

### 胶质内吞和溶酶体水解释放激素 { #colloid-release }

TSH 刺激时，滤泡细胞从顶端内吞含碘 Tg，内吞体与溶酶体融合后由蛋白酶释放 T$_4$、T$_3$ 以及未偶联的 MIT、DIT。T$_4$ 和 T$_3$ 经基底外侧膜转运进入血液；MIT、DIT 通常不直接分泌，而由碘酪氨酸脱卤酶 IYD（DEHAL1）回收 I$^-$ 与 Tyr。由摄取、储存到回收的闭环使有限的膳食碘能够反复利用。[^synthesis-endotext]

## 循环储备与组织内加工共同决定有效信号 { #hormone-access }

### 结合蛋白缓冲血中激素 { #serum-binding }

T$_4$ 和 T$_3$ 是带电取代基与疏水芳香环并存的碘化氨基酸衍生物，在血浆中绝大部分与甲状腺素结合球蛋白（TBG）、转甲状腺素蛋白（transthyretin, TTR）和白蛋白可逆结合。TBG 浓度较低而亲和力高；TTR 和白蛋白亲和力较低，却提供更大的、交换更快的结合容量。结合池延缓肾滤过和代谢清除，并缓冲短时分泌波动，所以循环 T$_4$ 的周转慢于 T$_3$。[^serum-transport]

只有游离激素能够离开血浆结合池、进入细胞并参与反馈。结合蛋白数量或亲和力改变时，总 T$_4$、总 T$_3$ 可以明显改变，而游离浓度和组织作用仍被反馈维持在接近原来的范围；因此“总量增加”不能自动解释为甲状腺作用增强。结合也不是永久封存，游离激素被组织摄取后，结合池会按平衡继续解离补充。

### 跨膜转运使组织获得不同的底物 { #cellular-transport }

甲状腺激素不能仅凭脂溶性自由穿过所有细胞膜。MCT8、MCT10、OATP1C1 以及部分 LAT 家族转运体在不同组织、细胞类型和膜面承担摄取或外排；它们的底物偏好和表达位置不同，使同样的血浆游离浓度不必产生相同的细胞内底物供给。MCT8 对脑内甲状腺激素分布尤其重要，说明“有激素到达血液”与“靶细胞获得激素”之间还隔着可调的运输层。[^membrane-transport]

### 三类脱碘酶调节局部 T$_3$ 可用性 { #deiodinases }

碘甲状腺原氨酸脱碘酶是含硒代半胱氨酸的膜结合酶。D1 和 D2 能从 T$_4$ 外环脱碘生成 T$_3$；D1 还参与循环 rT$_3$ 的清除，D2 则在脑、垂体、棕色脂肪和骨骼肌等组织中调节细胞或局部组织获得的 T$_3$。D3 进行失活方向的内环脱碘，把 T$_4$ 转为 rT$_3$、把 T$_3$ 转为 T$_2$，在胎儿组织和成人中枢神经系统尤为重要。[^deiodinase-metabolism]

| 形式 | 主要来源 | 受体活性与生理角色 | 常见后续去向 |
| --- | --- | --- | --- |
| T$_4$ | 甲状腺分泌的主要碘甲状腺原氨酸 | 对经典核受体的效力较低，作为循环前体和储备 | 经 D1／D2 生成 T$_3$，或经 D3 生成 rT$_3$ |
| T$_3$ | 甲状腺少量分泌；多数由组织内 T$_4$ 外环脱碘形成 | 经典甲状腺激素受体的主要高亲和力配体 | 经 D3 等进一步脱碘，并可经结合反应后排泄 |
| rT$_3$ | T$_4$ 内环脱碘形成，主要来自外周失活 | 缺乏重要的经典受体激动活性 | 主要经 D1 等继续清除 |

运输体、D2／D3 与受体表达可以在一个组织内组成“前受体调节层”。例如脑组织能够摄取 T$_4$，由胶质细胞或特定前体细胞的 D2 生成 T$_3$，同时由 D3 限制某些区域和发育阶段的暴露。血中 T$_3$ 只是这个局部信号的一部分，不能替代对组织内生成和失活的理解。

## T$_3$ 受体把局部供应转为基因表达程序 { #thyroid-receptor-action }

T$_3$ 主要结合由 *THRA*、*THRB* 编码的核受体 TRα、TRβ。受体常与视黄酸 X 受体形成异二聚体并结合 DNA 上的甲状腺激素反应元件；配体结合改变共抑制因子、共激活因子及染色质调节复合物的招募，从而上调或下调不同靶基因。受体亚型、反应元件、共调节因子和原有转录状态均依组织而异，所以甲状腺激素不是把全身所有代谢基因同时推向同一方向。[^cellular-action]

膜和细胞质信号也可产生较快的非基因组效应，并与核受体通路相互作用；不过全身发育和代谢效应的大部分可由转运—脱碘—核受体这一主线解释。描述某个快速反应时，应先区分其受体、时间尺度和证据，不能把所有分钟级变化都归给 TR 直接启动转录。

## 甲状腺激素协调发育、产热与器官工作量 { #systemic-effects }

### 发育作用具有严格的时间和组织窗口 { #developmental-effects }

甲状腺激素参与神经发生、神经元迁移与分化、突触形成、髓鞘化以及耳蜗和骨骼成熟。胎儿自身甲状腺建立功能前，母体 T$_4$ 已可经胎盘提供底物；此后母体供给、胎儿甲状腺、胎盘转运以及胎儿脑内 D2／D3 共同决定局部 T$_3$。在关键窗口严重缺碘或母体—胎儿甲状腺功能共同不足，可造成不可逆的神经发育损害；但不能把任何程度的母体甲状腺功能减退都写成必然导致同一结局。[^brain-development]

出生后，甲状腺激素继续支持脑、骨骺和生长板成熟，并与 GH—IGF-I、胰岛素、性腺类固醇及营养状态协同。它不是 GH 的简单上游，也不是独立决定身高的“生长激素”。生命阶段和生长板接口见[生长、发育与衰老](../growth_development.md#childhood-growth)。

### 代谢效应来自底物循环和组织工作量的重排 { #metabolic-effects }

在适宜范围内，甲状腺激素提高许多组织的氧耗与基础能量周转，影响线粒体生物发生和呼吸、Na$^+$／K$^+$-ATPase 等离子泵、底物动员与无效循环；棕色脂肪中的交感信号、D2 和解偶联蛋白还可协同增强适应性产热。产热不是“氧化磷酸化被一律解除偶联”的单一结果，肝、肌、脂肪和心脏贡献的机制与时相并不相同。全身能量消耗和体热收支见[能量代谢与体温](../energy.md#whole-body-energy-balance)。[^deiodinase-metabolism]

糖原分解与合成、糖异生、葡萄糖利用，脂解与脂质合成，蛋白质合成与分解都可能同时加快；净效应取决于激素暴露程度、营养和胰岛素状态、组织及持续时间。因而把甲状腺激素概括为单纯“升血糖”“降脂”或“促蛋白合成”，都会把通量增加误当成净库存必然沿一个方向变化。

### 心血管和其他器官效应维持与代谢需求的匹配 { #organ-effects }

T$_3$ 调节心肌收缩蛋白、Ca$^{2+}$ 循环、离子通道和 β-肾上腺素能反应性，通常提高心率、收缩速度和心输出量；外周组织代谢和局部血管舒张又可降低全身血管阻力，使循环供给与氧耗相匹配。所谓对儿茶酚胺的“允许作用”是受体与下游装置改变，不表示交感神经是甲状腺激素效应的唯一中介。[^cellular-action]

甲状腺激素还影响胃肠运动、骨重建、骨骼肌蛋白周转、通气需求和生殖功能。信号不足与过量都可能损害肌力、骨量或生殖能力，只是路径不同；不能据此给每个器官列一个永远向上或向下的固定箭头。心悸、怕热、黏液性水肿、甲状腺肿和突眼等属于疾病表现或病因线索，正常生理页只用相应机制解释其接口，不在此展开诊断与治疗。

## HPT 轴用反馈调节库存形成与释放 { #hpt-axis }

下丘脑室旁核小细胞神经分泌神经元释放 TRH，经垂体门脉到达促甲状腺激素细胞；TRH 促进 TSH 合成与分泌。TSH 结合滤泡细胞基底外侧的 TSH 受体后，经 G 蛋白偶联信号在不同时间尺度促进 NIS 摄碘、Tg 和 TPO 系统、胶质内吞与激素释放，并维持滤泡细胞的生长和分化。它既调节即时输出，也调节将来可用的合成能力和库存。HPT 轴在共同促激素轴中的位置见[下丘脑-垂体内分泌](endo_hp.md#tropic-axes)。[^hpt-axis]

循环 T$_4$、T$_3$ 对垂体和下丘脑形成负反馈。垂体和相关脑区的 D2 可把 T$_4$ 转为 T$_3$，使中枢能够把 T$_4$ 供应转化为受体信号；因此反馈不能只理解成血中 T$_3$ 对 TSH 的一条直接抑制箭头。TRH、TSH 还呈脉冲与昼夜变化，TSH 常有夜间上升，睡眠、能量状态、急性疾病、糖皮质激素和生长抑素等会改变波形。不存在适用于每个人、每种条件的“午夜固定最大值”。[^hpt-axis]

这一闭环也解释了为何要同时看调节信号和靶腺输出：原发性甲状腺激素不足时，负反馈减弱可使 TSH 上升，并可能因 TRH 作用伴随 PRL 升高；中枢驱动不足时，甲状腺激素和 TSH 的组合则不同。但化验判读还受测定方法、结合蛋白、药物、妊娠和疾病状态影响，完整诊断不应由正常反馈示意图直接代替。

## 碘供给存在不足与过量两侧的边界 { #iodine-autoregulation }

碘不足时，能进入 Tg 的碘减少，甲状腺激素合成受限，反馈性 TSH 刺激可增强摄碘和滤泡生长，长期可形成甲状腺肿；腺体还会相对偏向生成需碘较少的 T$_3$，并加强碘回收。这些补偿可以维持一段时间，却不能在严重缺乏时创造不存在的原料。胎儿和婴幼儿神经发育对供应不足尤其敏感。[^iodine-ods]

突然的大量碘负荷可暂时抑制碘有机化和激素合成，即急性 Wolff–Chaikoff 效应。多数正常甲状腺随后通过降低 NIS 等机制减少细胞内碘负荷并“逃逸”，恢复合成；但逃逸不是对所有人都可靠，易感者也可能出现碘诱导的功能减退或亢进。碘既是必需原料又能扰动系统，因此不能从“缺碘有害”推出补充越多越好。[^iodine-ods]

自主神经纤维可调节甲状腺血流和局部细胞活动，但 HPT 轴、碘供应和腺内自调节才是人类甲状腺长期输出的主要框架；把交感与副交感写成直接控制 T$_3$／T$_4$ 分泌的对抗开关，证据不足且会遮蔽反馈主线。

[^hpt-axis]: TRH—TSH—甲状腺的正向调节、甲状腺激素负反馈及 TSH 的脉冲／昼夜变化，见 Mariotti 与 Beck-Peccoz 的 [HPT 轴生理综述](https://www.ncbi.nlm.nih.gov/books/NBK278958/)。
[^iodine-ods]: 碘作为 T$_4$／T$_3$ 必需成分、缺乏时的 TSH—甲状腺肿反应及过量碘风险，见美国国立卫生研究院膳食补充剂办公室的[碘专业资料页](https://ods.od.nih.gov/factsheets/Iodine-HealthProfessional/)；Wolff–Chaikoff 效应和逃逸机制另见 Rousset 等的[合成综述](https://www.ncbi.nlm.nih.gov/books/NBK285550/)。
