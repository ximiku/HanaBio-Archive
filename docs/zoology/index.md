# 动物学

动物以摄取现成有机物获得物质和能量，细胞没有植物式细胞壁，多数谱系在生活史中形成由细胞外基质连接的组织，并借助肌肉、纤毛或其他效应结构主动改变自身与环境的相对位置。这样的共同基础产生了极不相同的身体：海绵以水沟系维持滤食，刺胞动物把消化腔、神经网和刺细胞组织在同一个辐射体制中，软体动物、环节动物与节肢动物各自改造了两侧对称身体，脊椎动物则以头部、内骨骼和高度集中的感觉—运动系统形成另一套整合方式。动物学研究这些身体怎样形成、运作和分化，也研究动物如何感知环境、作出行为并进入种群和生态系统。[^animal-scope]

动物的共同性状不能化成一张对所有类群都没有例外的检查表。组织、神经、肌肉、消化腔、两侧对称、体腔和分节都只在生命树的特定节点出现，某些谱系还会发生简化或丢失。学习动物学因而需要同时保留三种坐标：系统树说明比较对象之间的亲缘，体制与器官说明身体如何组织，生活史和行为说明结构在时间与环境中怎样实际工作。

## 系统树取代从简单到复杂的阶梯 {#phylogeny-not-ladder}

[动物多样性与无脊椎动物](invertebrates/)从动物起源、体制和系统发育进入多孔动物、扁盘动物、刺胞动物、栉水母动物以及庞大的两侧对称动物。传统教材中的“原生动物”分散在多个真核大支，并不属于动物界；“假体腔动物”描述一种体腔状态，也不是共同祖先所限定的自然类群；旧“触手冠动物”则位于螺旋动物范围，不应与棘皮动物和半索动物一并当作后口动物。栏目保留这些名称所携带的形态、生活史和鉴别知识，同时把它们放回现代系统树中。

现生动物早期分支通常涉及多孔动物、栉水母动物、扁盘动物、刺胞动物和两侧对称动物五条主线，但最先分出的究竟是栉水母还是多孔动物仍受取样、演化模型和系统发育性状影响。染色体尺度的古老基因连锁为栉水母最早分支提供了新证据，采用位点异质模型和重编码的序列分析却曾得到多孔动物最早分支的结果。这里的分歧会改变我们对神经、肌肉和复杂细胞类型起源次数的推断，所以[多孔动物、扁盘动物与早期动物演化](invertebrates/early_animals.md)会把不同拓扑及其证据并列呈现，而不把一棵树写成已无争议的事实。[^early-animal-tree]

进入两侧对称动物以后，原口动物中的螺旋动物与蜕皮动物、后口动物中的棘皮动物—半索动物和脊索动物构成阅读主干。环节、软体、甲壳、昆虫等熟悉名称代表共同祖先上分出的支系，不是逐级通往脊椎动物的过渡阶段。每一条现生支系都经过同样长的演化时间；所谓“原始性状”只表示某个性状接近所讨论共同祖先的状态，并不表示携带它的物种停留在过去。

## 身体结构是在约束中形成的功能系统 {#body-form-function}

动物体制首先规定物质交换和运动能够怎样发生。身体尺寸增大后，表面积与体积的比例下降，单靠体表扩散难以满足全部细胞；褶皱、分支、管道、循环液和通气结构由此反复出现。对称性和头部化改变感受器与运动方向的配置，体腔为内脏和体壁提供相对运动空间，分节能够产生重复单位并允许不同区段专门化，骨骼与流体静力结构则把肌肉收缩转换成支撑和位移。这些关系需要结合几何、材料性质、栖息介质和代谢需求理解，不能由“有或无某器官”单独排出高低顺序。[^form-function]

[脊索动物与脊椎动物多样性](vertebrates/)沿脊索、背侧中空神经管、咽部结构和尾部进入尾索动物、头索动物与有头类，再从圆口类、有颌类、软骨鱼、硬骨鱼、四足动物和羊膜动物追踪关键衍征。传统“鱼类”和“爬行类”在日常教学中仍有辨识价值，但若把鸟类排除在爬行动物之外、把四足动物排除在肉鳍鱼类之外，它们便不是完整的单系支系。类群页面会同时给出传统称呼、现代亲缘边界、代表类群及可观察特征，使名称服务于比较，而不遮蔽系统关系。

[脊椎动物比较形态与解剖](comparative_anatomy/)采用另一种切面：不逐类群重复介绍完整身体，而是沿胚胎、皮肤、骨骼、肌肉、消化、呼吸、排泄、生殖、循环、神经、感觉与内分泌系统纵向比较。鳃弓如何参与颌和中耳形成，偶鳍骨骼怎样与四肢同源，动脉弓、肾脏和胚膜如何在不同生活环境中改造，都只有把发生来源、成年结构、功能和系统树合在一起才可解释。类群页面负责说明一种动物“拥有什么”，比较页面则追问这些结构“从哪里来、怎样改变、哪些部分真正同源”。

## 行为把感知、内部状态与环境接在一起 {#behavioral-integration}

动物行为不是结构之后附加的一串例子，而是感觉输入、内部状态、神经与激素调节、运动输出及经验共同形成的时间过程。同一次觅食、求偶或迁移可以从不同层次解释：眼前由什么刺激和神经—内分泌机制触发，个体一生中如何发育和学习，这种行为在亲缘支系中怎样演变，以及它对存活和繁殖可能产生什么后果。Tinbergen 将机制、个体发育、系统发育和生存价值并列为行为学的四类核心问题；一个层次的答案不能替代另外三个层次。[^tinbergen]

[动物行为学](behavior/)因此先从行为谱、取样和记录进入定向、刺激过滤、动机和先天行为，再展开学习、认知、文化、遗传、生理和发育。取食、防御、争斗、求偶、育幼、社会组织与通讯页面保留可观察的动作序列、感官通道和类群差异；生物节律、迁移与导航则把内在时钟、太阳／星空／地标／磁场／气味等线索放入移动过程。行为会随情境、经验、性别、年龄和个体状态改变，经典“固定行为型”或关键刺激模型是有边界的解释工具，不是把所有复杂行为写成刚性程序的理由。

行为与[行为生态学](../ecology/behavioral_ecology/)共享大量对象，但提问重点不同。本栏目主要解释行为怎样被观察、产生和组织；行为生态学进一步用最优化、资源与风险权衡、性选择、亲缘选择、博弈和信号利益冲突检验行为在生态与演化条件下的后果。两边会互相链接，避免把同一组觅食、婚配或领域实例重复成两篇近似文章。

## 多样性与比较解剖需要往返阅读 {#comparative-reading}

按系统树学习时，可以先阅读[动物起源、体制与系统发育](invertebrates/body_plans.md)，再沿螺旋动物、蜕皮动物、无脊椎后口动物和[脊索动物](vertebrates/chordates.md)向各主要支系展开。每到一个类群，先确认共同衍征和亲缘边界，再观察身体分区、摄食、运动、气体交换、体液运输、排泄、生殖和感觉系统，最后用生活史与生态位置检验这些结构怎样协同。

按结构—功能学习时，可从[胚胎发生与基本组织](comparative_anatomy/embryology_tissues.md)建立发生坐标，再选择一个系统纵向比较。例如呼吸页从体表、鳃与鳔进入肺和鸟肺—气囊系统，循环页追踪单循环、双循环与动脉弓重组，骨骼页面组则从脊索、椎体和咽颅进入颌、听小骨、带骨及附肢。随后返回鱼、两栖、爬行、鸟或哺乳类页面，才会看到多个系统怎样在同一种生活方式中共同受到约束。

按观察对象学习时，可以从一个动物反向定位问题。昆虫的翅、气管、马氏管、变态和复眼分别连接节肢动物体制、呼吸／排泄比较、发育与感觉；鸟类迁徙同时连接飞行结构、能量收支、生物钟、导航、地理区系和行为生态；寄生蠕虫的吸附器官、体表、繁殖量和多宿主生活史则需要形态、生理、免疫、生态和演化证据共同解释。动物学的价值正在于让这些分散机制重新回到完整动物身上。

## 与相邻学科的分工 {#interfaces}

[生理学](../physiology/)主要以人体和哺乳动物机制展开稳态、循环、呼吸、消化、泌尿、生殖与内分泌；动物比较解剖保留跨脊椎动物的结构来源和系统改造。[神经生物学](../neuro/)深入神经元、突触、回路、感觉编码和高级功能；动物栏目比较神经系统与感觉器官在不同支系中的配置，并把这些结构接回行为。[发育生物学](../development/)处理命运决定、信号、图式和形态发生的一般机制；动物栏目用胚胎类型、幼体、变态和器官同源关系组织类群比较。

[生态学](../ecology/)研究个体与环境、种群、种间关系、群落和生态系统，[进化生物学](../evolution/)处理选择、漂变、系统发育、性状演化和物种形成。动物学以具体动物的结构、生活史和行为为中心，使用生态与演化原理解释多样性，却不把群落过程或一般演化理论全部复制进来。[实验技术](../exptech/)承接采集、麻醉、固定、解剖、制片、鉴定和行为观察流程；正文只在证据解释需要时说明方法能观察到什么、不能证明什么。
