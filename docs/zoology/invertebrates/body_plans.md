# 动物起源、体制与系统发育

动物的起源包含两个彼此相连却不能混为一谈的问题。一个问题是单细胞真核生物怎样演化出能够黏附、通讯、分工并共同繁殖的多细胞个体；另一个问题是早期动物怎样分化出不同的身体轴、细胞层、消化结构、神经—肌肉系统和生活史。前者发生在动物共同祖先之前，后者贯穿动物系统树的早期分支和两侧对称动物辐射。现生生物比较、基因组、胚胎、化石与地球化学分别保留了这段历史的不同侧面，没有任何一种现生“简单动物”可以单独充当祖先模型。

“体制”（body plan）是描述身体组织规则的比较概念，包括细胞怎样形成上皮与细胞外基质，身体沿哪些轴建立，消化腔和体腔怎样布置，肌肉如何获得支点，以及重复单位、附肢和器官怎样连接。体制不是一套永不改变的门级模板：同一支系内部可以出现增加、丢失、融合和重复，远缘动物也可能在相似环境中独立形成相似结构。把体制性状映射到系统树，才能区分共同祖先留下的同源、独立产生的趋同和继承后发生的特化。

## 单细胞近缘类群揭示多细胞化的材料来源 { #unicellular-relatives }

动物属于后鞭毛生物，其最近的单细胞亲缘类群包括领鞭毛虫，丝足虫类、鱼孢菌类和珊瑚壶菌类等也位于动物附近的全动物总群中。领鞭毛虫的一个鞭毛被微绒毛领环包围，水流中的颗粒可被领环截获；这一结构与海绵领细胞相似，但现生领鞭毛虫是动物的姐妹群成员，不是未经改变保存至今的“动物祖先”。真正的共同祖先只能由多个现生支系的共有和差异性状反推。[^unicellular-origin]

比较基因组表明，许多后来用于动物细胞黏附、信号传递和转录调控的分子家族，在单细胞亲缘类群中已经存在。钙黏蛋白结构域、整合素相关黏附系统、酪氨酸激酶和多种转录因子并非都在第一个动物中凭空出现；动物演化的重要变化还包括基因家族扩张、结构域重组、顺式调控增加，以及把原先在生活史不同阶段依次出现的细胞状态组织为同一个个体内同时存在的细胞类型。多细胞化由此既利用旧部件，也产生新的调控关系和细胞外环境。

一些领鞭毛虫能够由连续细胞分裂形成克隆性玫瑰状群体，其他动物近缘单细胞生物也有聚集、多核或复杂的阶段转换。这些现象说明黏附和分化在动物出现以前已有多种演化材料，却不能证明动物必然经过与某种现生群体完全相同的阶段。一个可繁殖的动物个体还需要控制细胞数和空间位置，处理细胞间利益冲突，建立内外边界，并使体细胞工作与生殖传递协调起来。

旧教材把菱形虫和直泳虫合称“中生动物”，曾据其少量细胞和寄生生活推测它们位于单细胞与多细胞动物之间。菱形虫生活在头足类肾附器内，外层纤毛体细胞包围轴细胞；直泳虫寄生于多种海生无脊椎动物，具有纤毛体细胞和生殖细胞。现代分子证据把两者放入螺旋动物范围，具体位置以及二者是否组成单系群仍受长枝吸引和取样影响。它们的简化身体是寄生演化的结果，不是动物多细胞化的中间台阶。[^mesozoa]

## 化石记录的是多阶段辐射而非瞬时出现 { #fossil-record }

软体、微小和没有矿化骨骼的动物很难保存，古老沉积也会经历变形、侵蚀和不完整采样。分子钟依据序列变化与化石校准估计分歧时间，能延伸到形态化石之前，却依赖演化速率模型和校准选择；宏体化石、微体化石、遗迹化石和有机分子标志则各有自己的归属不确定性。判定“最早动物”时必须区分可能属于动物的结构、能够诊断某个干群的性状，以及已经落入现生类群冠群的证据。

晚埃迪卡拉纪已经出现大型复杂生物、移动和取食留下的遗迹，以及部分较可靠的动物候选。寒武纪早期约 5.4 亿至 5.2 亿年前，矿化结构、掘穴活动、捕食关系和多个动物冠群在化石记录中迅速增多，这一现象构成“寒武纪大爆发”的核心。它没有把所有动物门在某个瞬间同时创造出来：前寒武纪已有动物演化，寒武纪内部也包含连续的辐射与灭绝，后续古生代仍继续建立新的生态结构。将化石、地球化学和分子钟合并后，更合适的图景是从晚埃迪卡拉纪延伸到早古生代的多阶段转变。[^ediacaran-cambrian]

氧化还原条件、营养盐供给、颗粒食物、捕食、底质扰动、生态位构建和发育调控能力都可能影响早期动物辐射。氧气提高并非一枚自动启动复杂动物的开关，遗传工具箱的存在也不保证宏观体制立即出现；环境允许范围、生物间相互作用和可遗传的发育改变共同作用，才可能产生化石记录中观察到的生态扩张。不同地点和时期的保存窗口又会放大某些阶段，因此“为什么辐射”不能由单一原因或一条全球同步曲线回答。

## 身体轴改变动物接触环境的方式 { #axes-symmetry-cephalization }

身体没有固定对称面的动物仍可形成稳定水流和局部功能区；多孔动物的水沟系便按照入水孔、领细胞室和出水孔组织流体。围绕口—反口轴排列的辐射或旋转对称，使固着、漂浮或缓慢游动的动物能够从多个方向接收刺激和食物。两侧对称建立前后、背腹和左右坐标后，持续向前运动的一端首先遇到环境，感觉器官、摄食结构和神经组织因而常在前端集中，形成头部化。

对称是身体各部分相互对应的几何关系，不等于所有内部器官都镜像成对。许多两侧对称动物发生稳定的不对称，腹足动物扭转、招潮蟹螯足差异和脊椎动物内脏偏位各有独立的发生机制；棘皮动物幼体为两侧对称，成体则在变态中建立次生五辐结构。讨论对称性时必须标明生活史阶段和观察尺度，也要区分规则被改变与整个支系失去两侧对称祖先。

体型增大使体积相对表面积增长，细胞离外界和消化表面的距离增加。身体变薄、形成褶皱或分支，建立消化道、循环液和呼吸表面，都能缩短交换距离或增加有效面积。肌肉必须对抗某种支撑系统才能产生位移：体腔液和身体组织可形成流体静力骨骼，外骨骼与内骨骼提供固体支点，纤毛则适合驱动较小尺度的个体或表面水流。这些方案在特定尺寸、介质和生活方式下各有约束，不能仅凭有无骨骼或循环系统排列“高等”和“低等”。

## 卵裂与原肠形成把一个细胞转成空间结构 { #cleavage-gastrulation }

受精卵早期分裂称为卵裂。卵裂增加细胞数，常在总体积尚未明显增长时把卵细胞质分配给越来越小的卵裂球。卵黄数量和分布、细胞骨架取向及细胞间相互作用共同影响卵裂几何：少卵黄或分布较均匀的卵可发生完全卵裂，富含卵黄的鱼、爬行动物和鸟类常在胚盘发生盘状不完全卵裂，昆虫则可先进行表面核分裂再细胞化。完全卵裂内部又可见辐射、螺旋、两侧或旋转等模式；这些模式有系统发育信息，却都存在支系内改造，不能当作不容例外的门类定义。具体细胞周期与母合子转换见[卵裂、母合子转换与胚泡形成](../../development/cleavage_gastrulation.md)。

原肠形成把早期细胞层重排为具有内外关系和身体轴的胚体。成片细胞向内折入称为内陷，细胞层沿边缘翻入称为内卷，单个或成群细胞脱离上皮进入内部称为内移，一层细胞分为平行层可称分层，外层扩展包围深层组织称为外包。真实胚胎常同时使用多种运动，并伴随细胞极性改变、上皮—间充质转换、细胞间插和汇聚延伸。相近物种也可因卵黄、胚胎几何或少数调控变化采用不同内化方式，原肠形成的结果比某一种固定动作更保守。[^gastrulation-evolution]

外胚层、内胚层以及两侧对称动物的中胚层是发生坐标，不是成熟组织的简单薄层。外胚层通常参与体表和神经系统，内胚层参与消化道内衬及相关器官，中胚层产生肌肉、结缔组织和许多内脏结构，但具体贡献需要按支系和器官核对。多孔动物的细胞层与真后生动物胚层不能直接一一等同；刺胞动物和栉水母通常按两胚层框架描述，却仍有位于两层之间的多种细胞和细胞外基质。

## 体腔、消化道与分节是可演化的性状组合 { #coelom-gut-segmentation }

动物内部空间包括消化腔、由组织间隙形成的腔隙，以及由中胚层上皮围成的真体腔，三者的来源和功能不同。真体腔可容纳器官、允许体壁与消化道相对运动，并在一些动物中参与流体静力支撑、物质运输或配子成熟。“无体腔”“假体腔”和“真体腔”适合描述切面与发生，却没有把两侧对称动物分成三个依次进步的自然类群；线虫和轮虫等具有不完全中胚层衬里的腔隙，分别属于蜕皮动物和螺旋动物，已经直接说明所谓“假体腔动物”是多系集合。

中胚层内部裂开形成腔隙常称裂体腔，原肠壁向外形成体腔囊常称肠体腔。传统教材把裂体腔与原口动物、肠体腔与后口动物整齐对应，但动物实际发育更为多样：体腔可能由不同细胞群和多种形态运动形成，也可能在成体显著缩小或转变为血腔。胚孔形成口、肛门或暂时闭合的命运同样存在变体。“原口”和“后口”如今首先是系统支系名称，不能仅凭一个胚胎开口的最终位置为陌生动物定类。

消化结构从细胞内吞噬、只有一个开口的消化循环腔，到口与肛门分开的贯通消化道，带来不同的食物处理方式。贯通消化道允许摄入与排出同时进行，并让咽、胃和肠段专门化，却也可在寄生支系中再次简化或完全丢失。分节则通过重复单位支持运动和区域分工，在环节动物、节肢动物和脊索动物中采用不同的发生网络与成年结构；这些相似性中既有古老调控部件的重复利用，也有独立演化，不能恢复旧“环节—节肢”最近亲假说。

## 系统树用于重建性状变化 { #phylogenetic-inference }

系统发育分析比较可以同源化的形态、发育、分子和基因组性状，并在明确模型下寻找最能解释数据的分支关系。一个支系由共同祖先及其全部后代组成；只有这样的单系群才适合直接承载共同衍征。并系群漏掉部分后代，例如排除鸟类的传统“爬行类”；多系群则把彼此远缘、因相似形态或生活方式聚在一起的成员合并，例如旧“原生动物”和“假体腔动物”。传统名称可以保留教学价值，但页面会同时标出它在系统树上的边界。

系统树的分叉顺序也不表示一支停留在过去、另一支继续前进。现生海绵、栉水母、线虫和昆虫从各自与其他动物分开的共同祖先至今都经历了持续演化。“基部分支”只描述树上相对于某一节点的位置，“祖征”和“衍征”也必须针对指定共同祖先判断。器官简化可能来自次生丢失，复杂性还可以由重复、分区和旧结构改作新用产生，因此性状数目不是衡量演化程度的通用标尺。[^animal-phylogeny]

动物、两侧对称动物、原口动物、螺旋动物和蜕皮动物等深层节点得到多类证据支持，早期动物根部、异无腔动物的位置以及螺旋动物内部若干分支仍受模型和取样影响。可靠的页面会把稳定节点作为组织主干，把争议节点写成可区分的备选假说，并说明哪些观察会随拓扑改变，而不是用一棵没有不确定性的树覆盖全部知识。

## 起源学说保存的是问题史 { #historical-models }

19 世纪的动物起源学说主要从胚胎和现生形态构造可想象的过渡。海克尔的原肠虫学说设想球形群体的一侧内陷，形成具有两层和原肠腔的祖先；梅契尼科夫的吞噬虫或实球虫学说强调细胞先进入群体内部并进行细胞内消化，之后才形成消化腔；扁囊胚虫学说从扁平、具上下表面的两层身体出发；合胞体学说则设想多核纤毛虫样祖先的胞质逐步分隔成多个细胞。这些模型分别抓住内陷、内移、上下面分化和细胞化等真实过程，却缺少现代意义上的系统树、基因组和化石检验，不能把某一种胚胎动作直接宣布为动物起源的完整重演。

现有证据更支持从单细胞全动物类祖先出发，在克隆或聚集、细胞黏附、阶段性分化和调控创新之间重建多步转变。它仍不能恢复那个祖先的精确外形，也不能排除早期演化中出现过后来绝灭的组织方式。历史学说适合作为问题生成器：原肠形成是先由内陷还是内移建立，细胞内与细胞外消化怎样转换，空间分工如何从生活史阶段分化产生，都可以被比较发育和实验重新表述；学说名称本身不再充当证据。

海克尔还以“个体发生重演系统发生”概括胚胎与演化的关系。严格重演律会要求胚胎依次经过祖先的成年形态，这与胚胎自身持续演化、早期阶段对卵黄和亲代环境的适应，以及不同器官以不同速率改变的事实不符。胚胎性状仍能提供亲缘证据：咽裂、幼体类型或同源基因网络可能保留共同祖先的信息，某一性状的发生顺序也可能呈现有限的历史痕迹；这些证据必须逐性状检验，不能把完整个体发育压缩成一部祖先成年形态史。[^recapitulation]

本页建立比较动物体制所需的起点。[多孔动物、扁盘动物与早期动物演化](early_animals.md)继续处理早期分支和动物根部争议，[刺胞动物与栉水母动物](cnidarians_ctenophores.md)展开神经—肌肉、捕食和生活史，[原肠形成与胚层建立](../../development/gastrulation_germ_layers.md)则深入细胞命运、信号和组织力学。动物各门页面会把这里的轴、胚层、体腔、消化道、分节和支撑系统重新组合到完整动物中。
