# 动物多样性与无脊椎动物

“无脊椎动物”把没有脊柱的动物放在一起，是观察和教学中方便的集合名称，却不是由一个独有共同祖先限定的支系。海绵、水母、涡虫、蚯蚓、蜗牛、昆虫与海星之间的差异远大于它们共享的“无脊椎”状态；脊椎动物也只是动物系统树中的一个分支，不能作为其余动物的默认参照。这个页面组因此沿动物系统树组织内容，同时保留传统门类名称所承载的形态、生活史、鉴别和生态知识。[^invertebrate-scope]

本站把多孔动物、扁盘动物、刺胞动物、栉水母动物以及非脊索的两侧对称动物放在本组，把尾索动物和头索动物与脊椎动物一起放入[脊索动物与脊椎动物多样性](../vertebrates/)。这是一条服务阅读的栏目边界，并不意味着“无脊椎动物”与脊索动物互为两个自然类群。进入各门专题前，先建立亲缘、体制与生活史三条坐标，才不会把外形相似误当成近缘，也不会把现生支系排成从简单到复杂的阶梯。

## 从性状表回到系统树 { #characters-and-tree }

动物分类曾大量依赖对称方式、胚层数、体腔状态、卵裂、胚孔命运、分节和附肢等性状。这些性状仍是理解身体结构的重要入口，但单个性状可以独立获得、反复丢失或因寄生和微型化而显著简化。分节见于环节动物、节肢动物和脊索动物，却不据此把三者合为最近亲；体腔的有无与衬里适合说明器官如何安置，也不能把所有“假体腔动物”组成一个支系；螺旋卵裂和担轮幼虫集中出现在部分螺旋动物中，却不是螺旋动物每个成员都必须保留的检查项。现代分类以共同演化历史为主线，再把这些性状映射到树上，判断它们何时形成、怎样改造和是否发生趋同。[^phylogeny-framework]

[动物起源、体制与系统发育](body_plans.md)会详细处理细胞层次、对称性、头部化、胚层、消化道、体腔、分节、骨骼和发育方式。[动物学史中的原生生物](protists_boundary.md)则解释旧“原生动物”为什么分散在多个真核支系，并保留鞭毛虫、变形虫、纤毛虫和寄生原生生物的形态与生活史知识。前者建立动物体制的比较语言，后者划清单细胞真核生物与动物的边界；两页合读，可以理解早期动物起源假说为何常从领鞭毛虫、细胞黏附和群体生活谈起，却不能把某个现生单细胞生物直接称为动物祖先。

## 早期分支展示不同的多细胞组织方式 { #early-branching-animals }

[多孔动物、扁盘动物与早期动物演化](early_animals.md)从水沟系、领细胞、细胞外基质和高度可塑的细胞协作进入多孔动物，再比较体形极薄、依靠腹面纤毛运动和体外消化的扁盘动物。这些动物不只是“缺少器官”的性状清单：海绵通过持续泵水把摄食、气体交换和排出废物组织在同一水流中，扁盘动物则让身体厚度、表面积和运动方式共同适应贴附基质的生活。它们各自拥有专门化细胞、发育过程和完整生活史，现生形态不能直接当作远古祖先的未变样本。

[刺胞动物与栉水母动物](cnidarians_ctenophores.md)进入具有明显身体轴、神经—效应整合和捕食结构的支系。刺胞动物以刺细胞、消化循环腔和水螅型／水母型生活史形成多种珊瑚、水螅与水母；栉水母依靠栉板列运动，许多种以黏细胞捕食。两者外形都可能透明而辐射，但其细胞类型、对称结构、发育和系统位置不同。多孔动物还是栉水母最先从其余动物分出仍有证据和模型依赖性，这一争议会影响神经、肌肉和复杂细胞类型起源次数的解释，专题页会把竞争拓扑与证据边界并列处理。

## 两侧对称动物形成三条主要阅读路线 { #bilaterian-routes }

两侧对称动物通常具有前后、背腹和左右轴，定向运动促使感觉结构与神经组织向前端集中；中胚层又为肌肉、结缔组织和多种内脏系统提供了新的发生来源。这里的“通常”很重要：成体棘皮动物形成次生辐射对称，寄生类群可能丢失消化道和感觉结构，固着或微型类群也会重塑身体轴。幼体、胚胎和分子性状常能保留仅看成体时不明显的亲缘线索。

原口动物的两条大支构成本组的大部分内容。**螺旋动物**包含颚胃动物、轮形动物、扁形动物、纽形动物、环节动物、软体动物，以及具有触手冠的外肛动物、腕足动物和帚虫动物等支系；**蜕皮动物**包含线虫、线形动物、鳃曳动物、动吻动物、铠甲动物、缓步动物、有爪动物和节肢动物等。螺旋卵裂、担轮幼体或触手冠只分布在螺旋动物的部分支系，蜕皮动物共有的核心过程则是周期性脱去由表皮分泌的角质层，但角质层材料、蜕皮控制和附肢结构在不同支系中已经高度分化。系统发育研究对螺旋动物和蜕皮动物等深层支系已有广泛共识，支系内部若干小型门类的位置仍会随取样和模型更新。[^bilaterian-phylogeny]

螺旋动物路线可从[扁形动物、纽形动物与寄生性蠕虫](flatworms_parasites.md)和[轮虫及其他小型螺旋动物](gnathiferans_spiralians.md)进入，再分别阅读[环节动物](annelids.md)、[软体动物](mollusks.md)与[触手冠动物及其他冠轮动物](lophophorates.md)。这些页面会保留涡虫再生、吸虫和绦虫生活史、轮虫轮盘与咀嚼器、环节动物分节和疣足、软体动物外套膜—足—内脏团，以及触手冠滤食等经典知识，同时纠正把体腔类型、寄生简化或单一幼体性状直接等同于自然类群的旧框架。

蜕皮动物路线先在[线虫及其他蜕皮动物](nematodes_ecdysozoans.md)比较线虫的高压体腔液、纵肌运动和表皮角质层，并以缓步、鳃曳等支系扩展对蜕皮动物的理解；随后进入[节肢动物体制、螯肢动物与多足动物](arthropods.md)，再分别展开[甲壳动物](crustaceans.md)和[六足动物与昆虫](insects.md)。节肢动物的分节身体、关节附肢、外骨骼和变态共同产生了极大的形态空间，但螯肢、触角、口器、步足、游泳足和翅都必须结合体节来源与支系关系比较，不能只按用途认定同源。

后口动物路线在本组只展开[棘皮动物与半索动物](echinoderms_hemichordates.md)。海星、海胆、海参等棘皮动物成体的五辐结构建立在两侧对称幼体和独特的水管系统之上；半索动物具有吻、领、躯干三段身体和咽裂。两门共同组成步带动物，是脊索动物的重要比较对象。它们与[脊索动物](../vertebrates/chordates.md)之间的关系，使咽裂、体腔分区、幼体形态和神经系统的比较能够离开“通往脊椎动物”的线性叙事，回到共同祖先之后各自发生的改造。

## 同一身体要沿多个系统观察 { #integrated-body-plans }

类群页面会反复采用一组相互连接的观察维度。体表既划定渗透和防御边界，也可能形成纤毛、角质层、外骨骼、贝壳或刺；摄食结构决定食物如何取得，消化腔或消化道决定物质在身体内怎样处理；气体交换、循环与排泄共同受到体型、表面积、扩散距离和生活介质约束；肌肉、骨骼或体腔液把收缩转为运动；感觉和神经系统再把环境变化接到效应器。生殖方式、幼体和变态则让同一物种在生活史不同阶段占据不同空间、使用不同资源。

比较时应先确认结构所在的身体区域、发生来源和连接关系，再讨论功能。昆虫气管把空气直接送入组织，甲壳动物鳃依赖水流与血淋巴运输，环节动物可由体表或鳃完成交换，许多小型扁形动物则依靠较短扩散距离；这些方案都适合特定尺度与环境，不能排成从低效到高效的固定次序。同样，开放式循环并不意味着体液无方向流动，神经网也不意味着行为没有组织，寄生动物结构减少也常与吸收、附着和高繁殖输出等专门化同时发生。

无脊椎动物的许多性状会在[脊椎动物比较形态与解剖](../comparative_anatomy/)中再次出现，但比较范围和问题不同。本组追踪各动物门的整体体制及其类群差异；比较解剖页面集中处理脊椎动物器官系统的发生来源和纵向改造。[动物行为学](../behavior/)继续展开感觉、学习、通讯、繁殖和迁移如何在时间中组织，[生态学](../../ecology/)与[进化生物学](../../evolution/)则分别承接种间关系、群落过程、选择和性状演化的一般模型。

## 标本、生活史与分子证据相互校正 { #evidence }

动物鉴定从可重复观察的性状开始。外形、对称、身体分区、附肢、口器、刚毛、贝壳、骨片和生殖结构可在野外、实体镜或显微镜下记录；连续切片、组织染色和成像揭示内部连接；胚胎与幼体补充成体形态中丢失的信息；基因序列、基因组结构和稀有基因组变化则检验深层亲缘。化石能够为性状出现提供最低年代，并展示现生类群没有保留的组合。任何一类证据都可能受到保存、取样、比对和模型的限制，可靠的系统假说来自多类证据的相互检验。

阅读一个陌生动物时，可先定位它在系统树上的最近大支，再记录身体轴、体表、消化道、运动和生活史，随后进入对应门类页面核对衍征。若名称来自旧教材，还要区分它指的是形态型、传统分类等级还是现代支系。按这一路径，“蠕虫”“原生动物”“假体腔动物”和“触手冠动物”等名称仍可作为知识入口，却不会重新变成遮蔽亲缘关系的分类框架。
