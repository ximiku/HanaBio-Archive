# 多孔动物、扁盘动物与早期动物演化

海绵附着在水底，体表散布进水孔，体内却有持续运转的水流；扁盘动物薄得近乎透明，沿基质滑行，把消化酶释放到腹面覆盖的食物上。两者都没有集中的脑、贯通消化道和由成束肌细胞组成的肌肉，却以专门化细胞、细胞外基质和整体协调构成能够摄食、生长、繁殖和应对环境的动物。它们展示的是两种完整而不同的现生体制，不是从单细胞生物到“高等动物”的两个未变阶段。

多孔动物、栉水母动物、扁盘动物、刺胞动物和两侧对称动物在动物系统树根部附近依次怎样分支，直接影响神经细胞、肌细胞、消化腔和上皮等性状的祖先状态重建。这个问题至今仍有竞争假说。理解早期动物演化，因而要把现生形态、发育、基因序列和染色体结构分别当作证据，再判断它们支持哪一种历史，而不能先把结构较少的类群指定为祖先。

## 动物树的根部仍有竞争假说 { #root-of-animal-tree }

“多孔动物是最原始的多细胞动物”把系统位置、结构复杂程度和祖先形态混成了一个判断。现生海绵属于从共同祖先延续至今的冠群多孔动物，拥有本支系长期演化形成的水沟系、骨针、幼体和共生体系；即使多孔动物最终被确认是其余动物的姐妹群，也只表示它与其余动物的分支在动物树根部最早分开，并不表示任何现生海绵就是动物共同祖先。

基于大量蛋白质序列的系统基因组分析，在采用不同位点模型、氨基酸重编码、物种取样和异常长枝处理时，可能分别得到“多孔动物先分”和“栉水母先分”。前一种拓扑较容易把神经和肌肉的起源放在多孔动物分出以后；后一种拓扑则要求考虑这些细胞类型在栉水母与刺胞动物—两侧对称动物中独立形成，或者动物祖先已有部分相关系统而多孔动物后来丢失。拓扑改变的是对性状演化次数的解释，并不会由树形本身证明哪种细胞类型一定独立起源或丢失。

2023 年的研究把古老染色体连锁关系用作性状：栉水母与动物的单细胞近缘类群保留若干祖先连锁组合，而海绵、扁盘动物、刺胞动物和两侧对称动物共享染色体融合及融合后基因混合，据此支持栉水母先分。序列模型研究仍有支持多孔动物先分的结果，后来也有研究质疑上述连锁组的统计显著性。2025 年一篇宣称以整合系统基因组学强力支持多孔动物先分的论文，又因物种数不平衡和内部节点处理错误于 2026 年撤稿，不能继续作为有效支持证据。当前最稳妥的表达仍是：两种根部拓扑的证据、方法假设和反驳需要并列检验，尚不能用“海绵最原始”或“栉水母一定最早”结束讨论。[^animal-root]

扁盘动物通常与刺胞动物和两侧对称动物一起落在 ParaHoxozoa 范围内，但它在这一范围中的具体位置也会随数据和模型改变。页面后文讨论海绵或丝盘虫的身体时，只把它们当作重建祖先性状的比较对象。[动物起源、体制与系统发育](body_plans.md)进一步说明共同祖先、祖征、衍征和历史起源学说的区别；下一页的[刺胞动物与栉水母动物](cnidarians_ctenophores.md)将具体比较神经—肌肉系统。

## 多孔动物以水流组织身体 { #poriferan-body-organization }

多孔动物门（Porifera）绝大多数生活在海洋，淡水中也有淡水海绵科等支系。成体通常固着，形态随水流、底质和生长空间变化，多数不具严格对称性，管状或杯状种类可近似辐射对称。它们没有由口通入的消化腔，身体的主要内部空间是输水通道、领细胞室和出水区域。体形看似不规则，进水面与出水口之间仍有明确的流动方向和区域分工。

海绵外表面的扁平细胞统称外被细胞，构成外被层。它们覆盖体表和部分水道，调节表面积与孔口；其中一些细胞能收缩，出水口附近还有专门的收缩细胞。旧教材常把这些细胞写成“有肌丝、可变成肌细胞”，更准确的说法是它们利用肌动—肌球蛋白等收缩装置改变体形和水流，却没有组成真后生动物式的肌肉组织。进水孔在一些石灰海绵中由单个管状孔细胞贯穿，在其他海绵中也可由多细胞孔区或水道入口形成，因而“一个孔必由一个细胞内孔构成”不是全门通则。

体表层与领细胞区域之间是中胶层或中质，主体为胶原、蛋白聚糖等细胞外基质，埋有骨针、海绵质纤维和多种游走细胞。原细胞或古细胞能够迁移、吞噬和运输营养，在许多种类中还可形成其他细胞类型或参与配子发生；成骨针细胞分泌无机骨针，成海绵质细胞分泌海绵质纤维。它们的可塑性很高，却不能据此把全门所有细胞都称为全能，也不能把中质理解成没有结构的胶冻。

水流经过的特定区域由领细胞排列。每个领细胞有一条鞭毛，外围微绒毛组成领圈；鞭毛摆动产生压差，领圈截留细菌和微小有机颗粒，细胞再通过吞噬完成细胞内消化。食物可转交给古细胞并运送到身体其他区域。领细胞的外形和摄食方式与领鞭毛虫相似，提示动物祖先已有领圈—鞭毛摄食装置的深层历史，但现生领鞭毛虫是动物的单细胞姐妹群，海绵领细胞也是多细胞动物发育产生的专门细胞，二者都不是另一方的直接祖先。

连续泵水同时完成多项交换。溶解氧从水中扩散进入细胞，二氧化碳和含氮废物随水流带走，颗粒食物则在领细胞室被截留。海绵不需要把呼吸、排泄和循环分别集中成器官，原因不只是“结构简单”，还在于大部分活细胞靠近水道或体表，交换距离很短。淡水种的一些细胞具有显著的伸缩泡，以周期收集和排水参与细胞渗透调节；伸缩泡仍是细胞器，不能比作整个个体的肾。

海绵没有神经元和突触，也没有集中神经系统。它们仍能在机械刺激、沉积物或水质变化后缩小孔口、收缩水道，甚至让全身泵水暂停。淡水海绵 *Ephydatia muelleri* 的实验显示，谷氨酸、GABA 和一氧化氮等扩散信号可改变收缩行为；不同种类还利用钙信号和局部细胞传导。旧称“芒状细胞”的星形细胞不应直接命名为原始神经细胞，因为形状或传递信号的能力都不足以证明它与神经元同源。海绵的协调说明多细胞身体可以在没有突触网络的条件下整合行为，也为研究神经系统出现以前的细胞通信提供了比较材料。[^sponge-signalling]

海绵细胞之间并非一概没有连接。多数海绵的细胞层与典型真后生动物上皮在基膜、封闭连接和细胞极性上存在差异，但细胞可由黏附分子、细胞外基质和局部连接稳定排列。寻常海绵、六放海绵和石灰海绵通常没有连续基膜；同骨海绵却具有含 IV 型胶原的基膜和带状黏着连接。把所有海绵统一写成“无组织、无细胞连接、无基膜”会抹去这一门内部真实的组织差异。[^sponge-epithelia]

## 水沟系从管腔扩大到领细胞室网络 { #aquiferous-systems }

鞭毛只在微小尺度推动邻近水体，海绵通过增加领细胞表面积并缩短局部流路，把许多领细胞的泵水效应汇入同一出水口。传统动物学把水沟系分为单沟型、双沟型和复沟型，现代文献常分别称 asconoid、syconoid 和 leuconoid。三种名称描述水沟系的建筑方式，不是三个由低到高依次演化的自然类群；同一类群的个体在生长和分枝时还可能改变局部复杂度。

### 单沟型 { #asconoid }

单沟型常见于小型管状石灰海绵。水由体壁的入水孔进入中央海绵腔，腔壁直接排列领细胞，再从顶端出水口排出，即“入水孔 → 海绵腔 → 出水口”。白枝海绵属（*Leucosolenia*）是经典例子。中央腔半径增大时，腔壁面积与容积的比例下降，单层领细胞较难维持大体积身体所需的泵水和滤食，因此这种构型通常体型较小或以反复分枝增加有效表面积。

### 双沟型 { #syconoid }

双沟型的体壁向内外折叠，形成流入管与辐射管。水依次经过入水孔、流入管、前幽门孔进入由领细胞衬里的辐射管，再经后幽门孔汇入中央腔并由出水口排出。前、后幽门孔分别对应领细胞区的入、出口，中央腔本身通常不再由领细胞覆盖。毛壶属（*Sycon*，旧教材也常写 *Scypha*）及樽海绵式标本常用于观察这一构型。体壁褶皱让相同外形尺度内容纳更多领细胞表面，却仍把水流汇入较大的中央腔。

### 复沟型 { #leuconoid }

复沟型把领细胞区进一步分割成数量众多的小型领细胞室。水从入水孔进入分枝的流入管，经前幽门孔进入领细胞室，再由后幽门孔进入流出管，最后汇往一个或多个出水口；中央海绵腔可能缩小或不再显著。淡水海绵、浴海绵以及绝大多数大型寻常海绵采用这类网络。许多微小泵水单元并联，既扩大领细胞总面积，也让身体能够形成厚块、薄壳、枝状或钻孔等多种外形。对活海绵的测量表明，领细胞室的尺寸、领圈排列和出水阻力共同决定泵水率，水沟系是经过尺度匹配的流体系统，不是被动充水的孔洞。[^sponge-pumping]

水流还把海绵与微生物连接起来。领细胞截留游离微生物，一些海绵体内又长期容纳细菌、古菌、蓝细菌或微藻共生者；共生者可参与碳、氮和硫代谢，并影响宿主营养与化学防御。绿色、褐色或红色体色有时来自共生藻或蓝细菌的色素，也可能来自海绵自身或其他共生微生物，因而“体色由共生藻引起”适合解释部分种类，不能作为全门规律。含大量微生物与含少量微生物的海绵在水道密度、泵水和营养交换上还可形成不同策略。

## 骨针与海绵质构成支撑系统 { #skeleton-and-classes }

骨针是由成骨针细胞形成的矿化骨骼成分，材料为碳酸钙或水合二氧化硅；海绵质是胶原样纤维蛋白，可单独形成网架，也可把骨针连接起来。它们支撑水道、防止身体在水流中塌陷，也可提高捕食者取食的机械成本。海绵骨针不是脊椎动物的骨，却仍属于骨骼系统，旧讲义在“骨针”后注明“不是骨骼”并不准确。骨针材料、轴数、射线数、大小与表面纹饰是重要鉴定性状，但相似形态可能趋同，现代分类还需结合软体结构、幼体和分子证据。

| 现代纲 | 骨骼和组织特征 | 水沟系与环境 | 代表性认识 |
| --- | --- | --- | --- |
| 石灰海绵纲 Calcarea | 碳酸钙骨针，可为一、三或四射；没有海绵质 | 单沟、双沟或复沟型均可见，多为浅海小型种 | 白枝海绵、毛壶；并非全部“无鞭毛室”，复沟型成员仍有领细胞室 |
| 六放海绵纲 Hexactinellida | 典型硅质六射骨针，骨针可融合成网；大部分软体构成多核合胞质的梁网 | 多为深海，水沟系高度分枝 | 偕老同穴属（*Euplectella*）和拂子介；旧称“无皮层”可由特殊合胞体组织解释，不能理解成身体没有外部边界 |
| 寻常海绵纲 Demospongiae | 硅质但非典型六射骨针、海绵质，或二者兼有；也有完全缺少矿化骨针者 | 绝大多数为复沟型，海洋与淡水均有 | 浴海绵、针海绵、淡水海绵；占现生海绵物种的大多数 |

## 生殖和发育连接固着成体与扩散幼体 { #reproduction-and-development }

海绵能够出芽、断裂和再生。芽可留在母体上形成群体，也可脱落并附着生长；身体碎片只要保留足够的细胞类型和水沟重建能力，也可能形成新个体。淡水寻常海绵在季节性低温、干旱或缺氧来临前常形成芽球：古细胞等储备细胞聚集成内含细胞团，外围由海绵质、气腔层和特化骨针加固。环境恢复后，细胞从芽球孔口逸出并重建海绵。芽球在淡水海绵中尤其普遍，少数海产种也有功能相近的耐受结构，但外膜不能一概称为几丁质，也不能把同一芽球构造套到所有种类。

有性生殖既见雌雄同体，也见雌雄异体；许多雌雄同体种通过配子成熟时间错开减少自体受精。精子和卵可由古细胞、领细胞或其他前体形成，来源因支系而异。在许多体内受精海绵中，精子随水流进入另一只海绵，由领细胞或专门运输细胞摄取后带往中质中的卵；另一些种把卵和精子释放到水中体外受精。“领细胞吞噬精子、失去领圈后携精入卵”是一些种类的生殖机制，不是所有海绵唯一的异体受精路线。

胚胎在母体内或外部发育为有纤毛、能短期游泳的幼体，随后选择底质、附着并变态成固着幼体。石灰海绵的一部分形成两囊幼虫或半囊胚幼虫，其一半为小型具鞭毛细胞，另一半为较大无鞭毛细胞；南瓜海绵等许多寻常海绵形成外层具纤毛而内部富含细胞的实胚幼虫；同骨海绵形成中空的 cinctoblastula，六放海绵则有 trichimella 等独特幼体。幼体类型和细胞命运能够提供分类与系统发育信息，却没有一套适用于全门的“囊胚翻转”。

旧教材所谓“胚层逆转”，来自观察一些石灰海绵幼体在变态时鞭毛细胞内移、无鞭毛细胞外展，或寻常海绵幼体外层纤毛细胞形成成体领细胞。现代谱系追踪显示，不同海绵的幼体细胞可经历内移、上皮—间充质转换、转分化或被其他细胞替代；这些细胞层也不能直接与刺胞动物和两侧对称动物的外胚层、内胚层逐层同源。因此，半囊胚幼虫和实胚幼虫应按具体支系描述，“动物极形成内层、植物极形成外层”的公式不宜推广为多孔动物共同规律。[^sponge-development]

## 再生与细胞重聚揭示可塑性的条件 { #regeneration-and-reaggregation }

海绵受伤后会封闭创面、重建外被层和水道；较大碎片的再生与把身体完全解离成细胞后的重聚并不是同一个过程。经典实验把海绵组织机械或化学解离，活细胞先形成小团块，再建立内外区域和水沟结构。不同物种细胞混合时常优先与同种细胞聚集，这与物种特异的聚集因子、细胞表面受体、钙镁离子和细胞外基质有关。肌动蛋白微丝参与细胞移动、形变和连接重建，但“糖蛋白和微丝”只是机制的一部分。

重聚能力还受物种、生活史阶段、解离方法、细胞组成和培养条件限制。有些聚集体能够恢复完整泵水个体，有些只形成短期存活的细胞团；缺少关键细胞类型或混入不同种细胞时，结果也会改变。海绵的实验价值正在于可以分别观察细胞识别、重新分区、转分化和形态发生，而不是把一次成功重聚概括成“任意海绵细胞都能自动复原”。[^sponge-reaggregation]

## 扁盘动物以薄片身体完成摄食与协调 { #placozoan-organization }

扁盘动物门（Placozoa）成员是直径通常以毫米计、轮廓不断改变的海生动物。模式种丝盘虫 *Trichoplax adhaerens* 长期是唯一正式描述的代表，基因组比较后来揭示形态相近个体之间存在很深的遗传分化，*Hoilungia hongkongensis* 等物种的建立使“一个形态等于一个物种”的认识失效。扁盘动物的外形与变形虫相似，旧名“多细胞变形虫”描述了轮廓变化，却不能把它们移出动物或变成单细胞—多细胞之间的中间类型。[^placozoan-diversity]

身体始终保持背腹方向。背面由扁平、具纤毛的上皮细胞覆盖，可含折光球样包涵体；腹面由单纤毛的柱状上皮细胞构成，纤毛共同驱动个体沿基质滑行。腹面还散布腺细胞和富含大型脂质颗粒的嗜脂细胞（lipophil cell），前者释放多肽等信号，后者在食物上方释放消化分泌物。两层之间没有体腔或消化腔，分枝的纤维细胞伸出长突起，与邻近细胞接触并参与身体形变、内部运输和损伤反应；靠近边缘的晶体细胞含碳酸钙晶体，被认为参与重力方向感知。旧讲义把星形纤维细胞说成由腹层产生并直接负责取食和运动，今天可以拆开为纤维细胞参与力学整合、腹面上皮与分泌细胞直接承担滑行和摄食。

丝盘虫遇到藻膜后减慢运动并覆盖食物，腹面与基质之间形成暂时封闭的小空间。嗜脂细胞释放消化酶使藻细胞破裂，腹面上皮再吸收溶解产物和微小颗粒，这是一种发生在体外、位置受身体控制的消化。没有永久消化腔并不等于没有消化过程；身体很薄、腹面紧贴食物，让分泌、吸收和扩散能够在短距离内协作。腹面纤毛决定滑行，身体边缘不断伸展和收缩，使个体能改变方向、分裂或包围不规则食物斑。

扁盘动物没有神经元、突触和肌细胞，也没有集中感觉器官。不同分泌细胞表达不同神经肽样信号，信号可调节纤毛停止、身体收缩、转向和摄食；邻近细胞之间的机械耦合与钙活动也参与协调。实验中，丝盘虫能够在没有突触网络的条件下让多个嗜脂细胞按食物位置先后分泌，并让整个身体停留在食物上方。它说明分泌信号和行为整合可以先在非神经细胞网络中实现，不能把这些细胞直接称为“原始神经元”。[^placozoan-feeding]

常见无性生殖方式是身体分裂，也可从背面或边缘产生小型游走体，旧文献把这些过程概括为出芽。基因组、减数分裂相关基因和群体遗传结构都支持有性生殖存在，实验培养中也观察到卵母细胞和早期胚胎；完整有性生活史、环境诱因和不同物种之间的差异仍没有像无性分裂那样得到全面描述。早期研究以少数标本概括“DNA 含量很少、染色体小”，现代基因组显示扁盘动物拥有复杂的黏附、转录调控和肽信号工具箱，基因组大小或染色体数也不是衡量动物进化等级的标尺。

## 现生类群不是祖先形态的陈列 { #living-lineages-not-ancestors }

海绵把领细胞泵、分枝水道、细胞外骨骼和可塑细胞结合为滤食身体；扁盘动物把背腹轴、极薄体形、腹面纤毛和外部消化结合为贴附基质的身体。二者都缺少某些真后生动物器官，却各有在自身支系中演化的专门结构。用“有无神经、肌肉、肠”制作缺失清单，只能描述一部分性状；把水流怎样穿过身体、食物怎样进入细胞、信号怎样协调运动和生活史怎样延续加入比较，才能看见这些体制的完整性。

海克尔的原肠虫学说、梅契尼科夫的吞噬虫学说、扁囊胚虫学说和合胞体学说，分别从内陷、细胞内移、扁平两层身体与多核体细胞化设想动物起源。海绵领细胞、扁盘动物背腹层和领鞭毛虫群体曾被用来为其中某些模型寻找现生类比，但类比不是祖先身份证明。动物共同祖先可能具有后来在不同支系中拆分、改作或丢失的细胞功能，也可能拥有现生类群未保存的性状组合。历史模型与卵裂、原肠形成及“重演律”的证据边界已在[动物起源、体制与系统发育](body_plans.md#historical-models)展开，本页不再把它们排成线性阶梯。

早期动物研究最终依靠多类证据互相约束。活体和超微结构揭示细胞连接、泵水与摄食，胚胎谱系说明相似细胞是否来自相同发生过程，基因组显示调控元件和细胞类型工具箱的得失，染色体连锁与序列模型检验分支顺序，化石则限定某些体制出现的最低年代。任何一种证据都可能受保存、物种取样或模型假设限制。把不确定性明确写入系统树，并不会削弱已知的海绵和扁盘动物生物学，反而能防止用一幅暂定树形覆盖可直接观察的结构与功能。
