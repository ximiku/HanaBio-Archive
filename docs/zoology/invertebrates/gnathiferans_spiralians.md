# 轮虫及其他小型螺旋动物

一滴池水、一撮潮间带细沙或龙虾口器表面的狭小空间，都可能容纳具有完整消化、排泄、神经和生殖结构的动物。轮虫、颚胃动物、微颚动物、腹毛动物、内肛动物和圆环动物多数体形微小，历史形态分类曾将它们归入“假体腔动物”或若干“附门”。现代系统发育则把这些体腔状态不同的动物分散到多个支系中。

现代系统发育把这些动物分散在螺旋动物的若干支系中。轮虫、颚胃动物、微颚动物和寄生性的棘头动物以咽部颚器的精细同源结构组成颚动物；腹毛动物常与[扁形动物](flatworms_parasites.md#flatworm-systematics)相邻；内肛动物和圆环动物则与其他冠轮动物有更密切的联系。毛颚动物虽然体长可达毫米至厘米级，近年的系统基因组研究也把它置于颚动物一侧。体表、咽、消化管、排泄器官和生活史呈现各门的结构组合，系统树则说明这些结构在支系间的分布。

## 假体腔的体制含义与分类历史 { #pseudocoelom-historical-concept }

传统所称假体腔或原体腔，是体壁与消化管之间没有完整中胚层体腔膜包围的含液空间。许多教材把它解释为胚胎囊胚腔的保留：中胚层肌肉主要位于体壁一侧，肠壁外缺少成对体腔上皮。液体空间能容纳肠、生殖腺和排泄管，也可传递压力、参与物质分配并形成流体静力支撑。这些功能在轮虫等动物中依然值得逐项理解。

体腔性状在多个支系中形成不同组合。轮虫有宽窄不等的假体腔，腹毛动物的器官间隙很小，内肛动物和圆环动物通常被描述为无体腔，棘头动物的体内又有韧带囊和腔隙系统等寄生性专化。历史上的“假体腔动物”还包括线虫、线形动物、动吻动物、兜甲动物和曳鳃动物；这些具有蜕皮角质层的类群属于[蜕皮动物](nematodes_ecdysozoans.md)。

“完全消化管、雌雄异体、体细胞数恒定和原肾管”是在部分成员中常见的性状组合。棘头动物缺少消化管，颚胃动物和微颚动物缺少永久肛门，轮虫不同支系的性别系统差异很大；恒定细胞数或恒定核数也依物种和组织而异。这些组合呈现了微小体形的多条实现路径。

## 颚动物的咽部硬质构件 { #gnathifera }

颚动物（Gnathifera）的核心成员包括颚胃动物门（Gnathostomulida）、微颚动物门（Micrognathozoa）和广义轮虫门（Rotifera）。它们的咽部含成对或不成对的硬质构件，构件内部由电子致密的杆束组成，并以相似的肌肉和上皮关系完成夹取、研磨或泵吸。颚胃动物的颚与基板、微颚动物的多组小骨片、轮虫咀嚼器的砧基和槌枝外形差别很大，超微结构和构件对应关系却提供了同源证据；系统基因组分析随后从独立的分子数据支持了这个类群。[^gnathifera-phylogenomics]

棘头动物过去独立成门。分子、精子和合胞体表皮超微结构均表明，它们是寄生化后嵌入轮虫内部的一支，因此广义轮虫同时包含单巢类、蛭态类、海旋类和棘头类。2024 年的全基因组和微共线性分析支持蛭态类与“海旋类＋棘头类”组成 Hemirotifera，但颚动物内部的深层次分支仍会随取样和模型改变。[^rotifer-phylogenomics]

## 颚胃动物的单纤毛表皮与咽球 { #gnathostomulida }

颚胃动物是海洋沉积物间隙中的细长动物，常生活在富有机质、氧浓度较低的沙泥层。身体没有宽阔体腔，也没有角质外被；表皮细胞通常各具一根纤毛，纤毛推动虫体在颗粒表面滑行。表皮还含黏液腺和杆状分泌物，头部可由感觉毛、刚毛或感觉小窝辨认。气体交换依靠体表，没有循环和呼吸器官。

腹面的口通入肌肉发达的咽球。咽球含横纹肌、分泌上皮和神经成分，内部的成对颚与不成对基板抓取并刮取细菌、真菌菌丝及沉积物表面的有机物。颚的齿列、基板形状和咽部硬片，是传统两大类群 Filospermoidea 与 Bursovaginoidea 及属种鉴别的重要依据。肠为简单盲囊，多数种缺少永久肛门，摄入与排出沿同一消化通路完成。

原肾管由单纤毛末端细胞、管细胞和肾孔细胞组成，常以数对独立单位分布在身体后部。脑位于咽前，数条纵行神经与表皮感觉器相连。多数种雌雄同体并行体内受精，不同类群可有交接刺、阴道、贮精结构或较简单的生殖管道；受精卵经螺旋型卵裂直接发育，省略独立的浮游幼体。单纤毛表皮、咽部颚器和单细胞原肾管共同构成显微形态的识别路径。[^gnathostomulid-morphology]

## 微颚动物的微型身体与复杂颚器 { #micrognathozoa }

微颚动物最初由格陵兰迪斯科岛冷泉中的湖沼颚虫 *Limnognathia maerski* 建立。成体最大约 150 µm，身体可辨圆钝的头部、带横褶的胸段和腹部。背侧与两侧表皮细胞没有连续外角质层，细胞内的支撑板使体表形成可弯曲的小片；腹面两列多纤毛细胞负责爬行，后端的纤毛黏附垫可暂时固定在基质上。长感觉毛伸出体表，脑和纵行神经联系这些感觉区。

口后咽部包含数十个可动或支撑性小骨片，能够依次张开、夹取和处理细菌等微小食物。主要颚、纤维状颚片、背侧颚和腹侧颚可以在扫描电镜与共聚焦重建中分辨；其中若干构件可与轮虫咀嚼器和颚胃动物颚器对应。消化管为盲端，排泄物积累后可经短暂形成的后开口排出，属于“无永久肛门”的体制。躯干部有两对原肾管，末端细胞和管细胞各具单纤毛。[^micrognathozoa-morphology]

现有观察记录了雌体、卵母细胞和不同外被的卵，尚未发现雄体、输卵管或固定生殖孔，因此其生殖通常推测以孤雌生殖为主。2025 年单个体转录组和形态复核把克罗泽群岛种群命名为第二个物种 *Limnognathia desmeti*；它与格陵兰、比利牛斯种群形态近乎不可分，遗传数据却显示深度分化。这项证据扩展了物种数，受精和卵裂过程仍待直接观察。[^micrognathozoa-second-species]

## 轮虫的头、躯干与足 { #rotifer-body-plan }

典型轮虫身体分为头部、躯干和后端足。头部可伸缩，前端纤毛冠的形状随取食方式变化；躯干部包容消化、生殖和排泄器官；足由表皮特化形成，末端常分为一至数个趾，足腺分泌物使动物暂时黏着水草、沉积物或宿主。自由游泳种的足可缩短，固着种则以足固定并分泌胶质管。躯干表面可柔软，也可因胞质内支撑层增厚而形成有棱、棘或板片的兜甲。

轮虫体表由合胞体表皮及其内部的致密蛋白层构成，后者称胞质内板（intracytoplasmic lamina）。这种结构区别于线虫周期性整体蜕去的胶原角质层。表皮核数常较稳定，部分器官也由恒定数量的细胞或合胞体构成，各器官的细胞组织仍需分别描述。[^rotifer-epidermis]

体壁内主要为纵行和环行肌束，器官悬置在充液的假体腔中。体腔液传递肌肉收缩产生的压力，参与体形伸缩和物质分配。轮虫没有循环和专门呼吸器官，气体经体表扩散；这要求身体保持较小尺度，也解释了表面积、体形和水环境之间的紧密联系。

## 纤毛冠、咀嚼囊与摄食机械 { #corona-mastax-trophi }

纤毛冠的环列纤毛依次摆动产生后生波，在显微镜下呈现轮缘滚动的外观。水流把细菌、藻类和有机颗粒送向口，同时可推动浮游种前进；爬行的蛭态轮虫则交替使用纤毛冠与足，如伸缩测量。冠上的感觉刚毛、眼点和触角使摄食流同时成为感知水流与化学环境的界面。

口后是肌肉质咀嚼囊（mastax），其中的硬质咀嚼器称 trophi。不成对的砧基（fulcrum）与成对砧枝（rami）组成砧骨，左右槌骨又各含槌柄（manubrium）和槌钩（uncus）；这些构件在肌肉牵引下相互咬合。滤食种、刮食种、捕食种和吸食种具有不同的咀嚼器型式，硬片形态在清透明标本中保存良好，是轮虫分类和食性推断的重要依据。咀嚼囊之后依次为食道、胃、肠和后肠，多数雌体以泄殖腔通向背侧泄殖孔；若干雄虫消化道显著退化或缺失。

成对原肾管沿身体两侧延伸，焰球产生的滤液经集合管进入膀胱，再通向泄殖腔。淡水种持续排出进入体内的水，膀胱可有节律地收缩。咽上脑神经节发出通往眼点、背触角、侧触角、纤毛冠、咀嚼囊和足的神经；感觉器的数量和位置是活体鉴别的重要辅助性状。

## 单巢轮虫的孤雌与有性生殖循环 { #monogonont-reproduction }

传统“单巢纲”大致对应单巢类（Monogononta），雌体只有一套卵黄生殖腺；卵巢与卵黄组织紧密联合，卵母细胞在形成过程中获得卵黄。种群处于适宜条件时，非混交雌体以非减数的孤雌生殖产生二倍体卵，卵直接发育成新的非混交雌体，连续多代迅速扩增。

种群密度、食物、温度、盐度或光周期等信号可诱导混交雌体。混交雌体经减数分裂产生单倍体需精卵：未受精时发育成单倍体雄虫；受精后恢复二倍性，并形成外壳厚、可休眠和扩散的受精卵。休眠卵在合适条件下孵出非混交雌体。未受精卵与受精卵由此分别进入雄体发育和休眠卵形成两条路径。[^monogonont-cycle]

雄虫通常小于雌虫，寿命短，咀嚼囊和肠道可退化，而精巢、输精管和可外翻交接器发达。交配可经雌体泄殖孔完成，一些种也进行皮下受精：雄性交接器刺穿雌体体壁，把精子送入假体腔。生殖方式和雄体简化是单巢类中的常见模式，不代表所有广义轮虫。

## 蛭态类、海旋类与生殖方式差异 { #bdelloidea-seisonidea }

蛭态类（Bdelloidea）通常有成对的卵巢—卵黄腺复合体，传统上因此与部分成员合称“双巢类”。身体能像望远镜般伸缩，纤毛冠常分成两叶，足部具趾或黏附突。长期观察几乎只见孤雌生殖雌体；基因组中仍保留许多与减数分裂有关的基因，但在自然生活史中尚无获得广泛接受的常规雄体和有性周期证据。

海旋类（Seisonidea）附生于海洋叶虾 *Nebalia* 的鳃足或体表，以宿主附近的食物和附着生活为主。其雌雄均正常发育，进行有性生殖；纤毛冠和咀嚼器形态也与典型浮游轮虫不同。海旋类的附生与有性生殖、蛭态类的孤雌生殖、单巢类的混交周期共同构成广义轮虫多样的生活史。

## 失水隐生的可逆低含水状态 { #rotifer-anhydrobiosis }

生活在苔藓、水膜和暂时性水体中的许多蛭态轮虫遇到缓慢干燥时，会收回头足、缩成紧密的干缩体并大量失水，代谢活动降到难以检测的程度；重新获得水后，膜、蛋白质和核酸修复完成，动物可恢复活动。这种失水隐生或脱水休眠是可逆生理状态，耐受能力随轮虫种类和干燥速率变化。

甘油和海藻糖可在某些耐旱生物中保护大分子，但两个经典蛭态轮虫种在干燥状态下未检出海藻糖及其他二糖。蛭态轮虫的耐受涉及收缩包装、晚期胚胎发生丰富蛋白样保护因子、抗氧化体系以及复水后的脱氧核糖核酸（deoxyribonucleic acid，DNA）与蛋白质修复；单巢类休眠卵则可能使用不同的糖和胚胎休眠机制。隐生机制由此表现出明显的支系差异。[^rotifer-anhydrobiosis]

干燥与电离辐射都能产生活性氧、损伤蛋白并造成 DNA 断裂。蛭态轮虫的辐射耐受与蛋白质抗氧化保护及复水后仍可工作的修复系统有关；有些长期生活在稳定水体的蛭态种已经失去强脱水耐受，说明这一能力也会发生次生改变。[^bdelloid-damage]

## 棘头动物的吻、腔隙系统与营养吸收 { #acanthocephala-anatomy }

棘头动物成虫寄生脊椎动物肠道，身体分为带钩的可翻出吻、短颈和躯干。吻收在肌肉质吻鞘中，牵引肌使其内翻，吻鞘压力和肌肉作用使其外翻；成排吻钩刺入宿主黏膜，维持长期附着。吻鞘两侧的吻腺囊（lemnisci）与表皮内腔隙相通，参与吻的液压调节，但其精确作用随类群而异。

合胞体体被表面有大量微孔，体内完全没有口和消化管，糖、氨基酸等营养物质直接跨体被吸收。表皮内部的纵行腔隙和横向交通支构成腔隙系统，液体在其中分配物质；体壁肌也形成含液管道。多数种没有典型排泄器官，少数类群具有原肾管。神经节位于吻鞘附近，纵行神经通向吻、体壁和生殖器官。

棘头动物雌雄异体。雄体通常有成对精巢、输精管、黏合腺和交配囊；雌体幼年卵巢随后分裂为许多卵巢球，游离在韧带囊或体腔样空间中。卵成熟并受精后，带幼虫的成熟卵由子宫钟筛入子宫和阴道，未成熟卵回到体内继续发育。吻钩排列、腔隙主干位置、韧带囊是否持续、雄性黏合腺数目和虫卵形态，构成传统纲、目和种鉴别的重要组合。

## 棘头虫从节肢动物转入脊椎动物 { #acanthocephalan-life-cycle }

含棘头蚴（acanthor）的厚壳卵随终宿主粪便排出，被甲壳类、昆虫或多足类等适宜节肢动物吞入。棘头蚴穿过中间宿主肠壁进入血腔，发育成棘头体（acanthella），再形成具有内翻吻的感染性囊棘头体（cystacanth）。鱼、鸟或哺乳动物吞食中间宿主后，囊棘头体在肠内伸出吻、附着并成熟；某些生活史还利用鱼、两栖类或爬行类作为转续宿主。[^acanthocephalan-life-cycle]

寄生适应使现生棘头动物失去纤毛冠、咀嚼器和消化管，却保留与轮虫相联系的合胞体表皮、胞质内板、精子构造和发育特征。2025 年研究者把中侏罗世道虎沟标本解释为棘头动物 *Juracanthocephalus daohugouensis*；标本同时具有带钩吻和分立的咽颚构件，在该研究的形态分析中连接了有颚的自由／附生轮虫与无颚的现生棘头动物，为“寄生化过程中颚器丢失”提供了罕见而仍待更多化石检验的证据。[^jurassic-acanthocephalan]

## 腹毛动物的腹纤毛与双腺黏附管 { #gastrotricha }

腹毛动物是海洋沙隙、淡水底泥和水生植物表面的微型动物。头端常有感觉毛或纤毛簇，腹面成带纤毛驱动滑行，背面角质层形成鳞片、棘或硬毛；尾端多分成两个叶或叉。角质层也包被运动与感觉纤毛，却不发生蜕皮。身体不同部位伸出的黏附管含双腺系统：一个腺细胞分泌黏着物，另一个释放解除黏附的物质，使动物能在水流和沙粒间迅速固定、脱离。

口通入强壮的肌上皮咽，随后是直行肠和肛门，形成完全消化管。大型腹毛类咽侧可有开向体表的咽孔，摄食时帮助排出多余水。没有循环和呼吸器官；原肾管、脑和一对腹外侧纵神经索分布在狭小器官间隙中。表面鳞棘、咽孔、黏附管数量与位置、尾叉形状和生殖器构造，都是显微鉴别的稳定入口。[^gastrotrich-morphology]

海生大鼬虫类多为雌雄同体，常先雄后雌并通过交接器或精包转移精子；淡水毛轮虫类许多种以孤雌生殖为主，也有精子和两性生殖记录。卵直接发育，部分种形成耐受不良环境的厚壳卵。系统基因组研究把腹毛动物置于螺旋动物，常恢复其与扁形动物组成 Rouphozoa，但其确切位置仍有分析差异。[^gastrotrich-phylogeny]

## 内肛动物的触手冠包围口与肛门 { #entoprocta }

内肛动物又称曲形动物，成体由杯状萼部和细柄构成，柄基附着于贝壳、藻体、岩石或其他动物表面。萼部边缘的一圈触手向内弯曲，触手侧面的纤毛产生水流，把食物颗粒送入口。消化管呈 U 形，口和肛门都开在触手冠内侧，这正是“内肛”名称的形态依据；外肛动物的肛门则位于触手冠之外。

萼部没有宽阔体腔，体内有一对原肾管、神经节、生殖腺和纵行平滑肌。单体内肛类可借足腺样基部缓慢移动，群体种通过匍匐枝连接并出芽增加个员。多数种海生，淡水湖萼虫 *Urnatella gracilis* 则形成分枝群体。许多种雌雄同体，胚胎可在萼内育囊发育，具纤毛幼体离开母体后附着变态。

内肛动物与外肛动物长期因触手冠和群体生活被合并、拆分。2022 年采用较完整基因集并清除污染的系统基因组分析再次支持内肛、圆环和外肛动物组成 Polyzoa，但研究者仍需扩大圆环动物等稀有类群的基因组取样。[^polyzoa]

## 圆环动物的宿主附生与个体更替 { #cycliophora }

圆环动物门由 1995 年发现的共生虫属 *Symbion* 建立。摄食期个体以末端黏着盘固着在海螯虾或龙虾口器刚毛上，顶端圆形口漏斗围有纤毛，通入 U 形消化管；直肠以外的消化表面多具纤毛。它们摄取宿主进食时产生的碎屑和水流颗粒，通常视为附生或共栖者。体腔很小，器官间充有液泡细胞；原肾管只在弦索幼体中确认。

摄食期个体的口漏斗和消化系统会老化，体内干细胞形成内芽，内芽发育成新的摄食结构并替换旧结构。无性周期中，潘多拉幼体在母体内包裹一个新摄食期个体，释放后在同一宿主口器上附着。宿主即将蜕皮时进入有性周期：普罗米修斯幼体附在摄食期个体上并产生矮雄，雌体受精后附着于宿主，体内形成具纤毛和纵行液泡细胞“弦索”的弦索幼体；弦索幼体在旧外骨骼脱落前逸出，扩散到新外骨骼上建立摄食期。各游动阶段寿命短且不摄食。[^cycliophora]

圆环动物的生活史包含功能不同的阶段：潘多拉幼体持续补充同一宿主上的种群，弦索幼体利用宿主蜕皮窗口扩散，矮雄则来自普罗米修斯幼体。阶段转换会新建或舍弃整个消化系统，形成多个个体交替而非单个成体连续变形。

## 毛颚动物的抓握棘与浮游捕食 { #chaetognatha }

毛颚动物全部海生，箭虫、太平洋箭虫等是海洋浮游食物网中的主动捕食者。身体分头、躯干和肛后尾三部分，头—躯干与躯干—尾之间有隔膜；躯干部有一至两对侧鳍，尾端有尾鳍。鳍由表皮形成并由鳍条支撑，结构不同于具有肌肉和关节的附肢。头部平时由头罩覆盖，捕食时头罩后缩，口两侧成束的抓握棘和前方小齿抓住桡足类等猎物，肌肉咽把食物送入直行肠，肛门开在躯干与尾的交界附近。

体壁由薄表面层、表皮和发达纵行横纹肌构成；部分种的特定表皮区域呈多层，层数随物种和身体部位而变。头、躯干和尾各有体腔区室，躯干部左右体腔容纳卵巢，尾部体腔容纳精巢。没有专门循环、呼吸和排泄器官，体液与海水间的气体和代谢物交换主要经体表完成。

脑位于咽背侧，经围咽连接与躯干部大型腹神经节相连；体表感觉毛扇、眼和纤毛冠状感觉器共同检测水流、接触和光。毛颚动物雌雄同体，卵巢导管通向躯干侧面的雌性生殖孔，尾部精子经输精管、贮精囊和尾侧雄孔释放，通常以精包转移。受精卵直接发育，省略独立摄食幼体。

早期胚胎的辐射样卵裂、原口命运和体腔形成方式曾使毛颚动物长期被列为后口动物。系统基因组数据把它们置于螺旋动物的颚动物一侧，2025 年染色体尺度基因组和细胞图谱也支持这一位置。隔膜分区体腔、直接发育和特殊胚胎过程仍是这个支系自身的重要性状。[^chaetognath-phylogeny]

## 各门的形态性状组合 { #comparative-characters }

| 类群 | 体表与运动 | 咽或摄食结构 | 消化与体内空间 | 生殖或生活史 |
| --- | --- | --- | --- | --- |
| 颚胃动物 | 单纤毛表皮，在海洋沙隙滑行 | 咽球、成对颚与基板 | 盲肠；无宽阔体腔；单纤毛原肾管 | 多雌雄同体，体内受精，直接发育 |
| 微颚动物 | 背侧细胞内板、腹面多纤毛带与后黏附垫 | 多组复杂颚片 | 无永久肛门；两对原肾管 | 仅见雌体，推测孤雌生殖；现知两种 |
| 狭义轮虫 | 合胞体表皮与胞质内板；纤毛冠、足和趾 | 咀嚼囊与咀嚼器 | 多为完全消化管；假体腔；原肾管与膀胱 | 单巢类混交周期、蛭态类孤雌、海旋类有性 |
| 棘头动物 | 合胞体被、带钩可翻出吻 | 成体颚器和口均丢失 | 无消化管；腔隙系统与韧带囊 | 节肢动物中间宿主、脊椎动物终宿主 |
| 腹毛动物 | 腹纤毛、背侧鳞棘、双腺黏附管 | 肌上皮咽 | 完全消化管；器官间隙小；原肾管 | 雌雄同体或孤雌生殖，直接发育 |
| 内肛动物 | 具柄固着，触手纤毛滤食 | 口位于触手冠内 | U 形肠，肛门也在冠内；无宽阔体腔 | 单体或出芽群体，常有具纤毛幼体 |
| 圆环动物 | 摄食期固着龙虾口器，口漏斗具纤毛 | 环形口漏斗 | 摄食期有 U 形肠，游动期不摄食 | 潘多拉、普罗米修斯、矮雄、雌体和弦索幼体交替 |
| 毛颚动物 | 侧鳍、尾鳍和纵行肌游泳 | 抓握棘、小齿与肌肉咽 | 完全消化管；头、躯干、尾体腔分区 | 雌雄同体，精包转移，直接发育 |

体腔、角质层、纤毛、颚器和消化管需作为组合性状使用。轮虫体表保留胞质内板而不蜕皮，腹毛动物位于螺旋动物，毛颚动物的系统位置也由基因组证据支持在颚动物一侧。历史名称可用于检索旧文献和辨认标本，各门的结构组合与生活史则提供当前分类和比较的基础。
