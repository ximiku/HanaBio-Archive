# 动物学史中的原生生物

池水中的草履虫、海水中发光的甲藻、在红细胞内繁殖的疟原虫和伸出伪足的变形虫，曾被动物学教材合称为原生动物（protozoa）。这个名称概括了它们多为单细胞、能够主动运动或吞食颗粒的一面，所含成员却来自亲缘相隔很远的真核支系。分子系统学把纤毛虫、甲藻和顶复门置于囊泡虫（Alveolata），裸藻和锥虫置于盘嵴类（Discoba），部分变形虫置于变形虫类（Amoebozoa），有孔虫和放射虫置于根足类（Rhizaria），领鞭毛虫则与动物同属后鞭毛生物（Opisthokonta）。传统原生动物因而是跨越多个共同祖先的描述性集合。[^eukaryote-tree]

原生生物（protists）今天仍可作为描述性集合名，泛指未归入动物、植物或真菌的真核生物；“原生动物”也仍见于医学寄生虫学、生态监测和显微鉴定语境。使用这些名称时同时说明具体支系，便能把鞭毛、伪足、纤毛、包囊和裂殖等经典观察知识放回各自的演化背景。

## 形态分类与真核系统树 { #from-morphology-to-eukaryote-tree }

早期分类首先依据显微镜下可见的运动方式：用鞭毛游动的归入鞭毛纲，以伪足运动的归入肉足纲，缺少明显运动器而形成传播体的寄生者归入孢子纲，密布纤毛的归入纤毛纲。这套框架适合描述标本，但其中许多性状容易趋同或反复丢失。鞭毛和纤毛都以真核细胞的微管轴丝为核心；伪足是肌动蛋白细胞骨架形成的临时突出；寄生生活又能让运动结构、线粒体代谢和摄食装置大幅简化。相同形态因而可以在不同祖先背景中独立出现。

| 传统名称 | 原先依据 | 现代承接 |
| --- | --- | --- |
| 鞭毛虫 | 一至多条鞭毛 | 裸藻、动质体虫、领鞭毛虫、毛滴虫和若干绿藻分属盘嵴类、后鞭毛生物、后滴门及其他支系 |
| 肉足虫 | 叶状、丝状、网状或轴状伪足 | 大变形虫和内阿米巴主要在变形虫类；有孔虫、放射虫在根足类；传统“太阳虫”分散于多个支系 |
| 孢子虫 | 寄生、缺少成体运动器、形成孢子或卵囊 | 疟原虫、弓形虫、球虫、隐孢子虫和焦虫属于顶复门；微孢子虫与真菌相联，黏孢子虫属于刺胞动物 |
| 纤毛虫 | 体表纤毛及其特化 | 纤毛虫门是囊泡虫中的一个自然支系，与甲藻和顶复门近缘 |

囊泡虫名称来自质膜下方成列的扁平膜囊。纤毛虫的表膜泡参与构成稳定而可变形的皮层，甲藻的膜囊可承载纤维素板，顶复门成员则把这一皮层体系与滑行和侵入宿主的装置结合起来。现代分类由膜囊结构和分子性状共同界定这一支系，普遍运动或具有表膜等宽泛特征只提供辅助信息。

## 单细胞真核生物的功能整合 { #unicellular-organization }

单个真核细胞可以同时维持边界、取得能量、感受环境、定向运动、调节水盐、排出未消化物，并在适当条件下复制或完成有性过程。外质和内质、泡状核和致密核等传统术语描述光镜下的质地与染色外观，适合认读特定标本；不同原生生物共同依靠细胞膜、细胞骨架、膜性细胞器和细胞核的协作维持生命活动。

营养方式常在同一物种内随环境改变。吞噬细菌、藻类或碎屑属于吞噬营养，溶解的小分子可由膜转运吸收，带叶绿体的种类可以光合；裸藻和许多甲藻还能把光合、吞噬或溶解有机物吸收组合成混合营养（mixotrophy）。传统“植物性、动物性、渗透性”三分法描述物质进入细胞的方式，系统分类则依据共同演化历史。食物泡在胞吞后依次酸化、融合消化酶并沿细胞内运输，未消化残渣再由胞吐排出。气体和许多小分子可跨膜交换，含氮废物的处理则随代谢和环境而异。

淡水中的细胞持续因渗透作用吸水，伸缩泡复合体（contractile vacuole complex）把胞质中的过量水收集后周期排出，首要作用是渗透调节；海水种类常不具同样显著的伸缩泡。收集管、储蓄泡和排水孔的形态因类群而异，这套细胞器系统与多细胞动物肾脏的组织层级和功能范围不同。纤毛、鞭毛和肌动蛋白骨架还把感觉信号转化为转向、避光、趋化或捕食动作。某些肽类信号和第二信使早在单细胞真核生物中已参与细胞调节，神经系统则是动物多细胞组织中的另一层级。

无性生殖可以是纵二分裂、横二分裂、出芽或一次产生许多子细胞的复分裂；方向往往受既有口器、鞭毛基体和皮层轴控制。裂殖通常先发生多轮核分裂，再由细胞质分隔出子细胞；多核细胞直接分成若干多核部分的质裂又是另一过程。有性过程包括同形或异形配子融合和纤毛虫接合等形式，主要作用是重组核基因组，个体数量可在随后的分裂中增加。许多种在干燥、缺食、温度变化或离开宿主时形成包囊，降低代谢并获得耐受性；包囊既可能是休眠阶段，也可能是传播或感染阶段。二分裂、包囊和有性过程在不同物种中形成各异的生活史组合。

## 鞭毛生物的多支系来源 { #flagellated-lineages }

### 裸藻的混合营养与团藻的群体生活 { #euglenids-and-volvocines }

传统所称眼虫是裸藻属成员，位于盘嵴类的裸藻支系。以纤细裸藻为例，细胞膜下由蛋白质条带组成的表膜允许身体发生蠕动样变形，表膜相关黏液体可向外释放物质；细胞前端的储蓄泡与伸缩泡复合体相通，通常有一条鞭毛伸出储蓄泡，另一条较短的鞭毛留在细胞内部。鞭毛基体发出的微管根系帮助定位储蓄泡、细胞核和鞭毛装置，传统称为根丝体，其功能涉及整个鞭毛装置的空间组织。叶绿体进行光合作用，产物以副淀粉粒形式储存在胞质中，遇碘不呈淀粉的典型蓝色反应。缺光时，一些裸藻可利用外源有机物维持异养代谢，属于混合营养生物。

橙红色眼点由类胡萝卜素颗粒构成，主要形成定向遮光；邻近鞭毛基部的副鞭毛体含光感受装置。细胞一边绕自身长轴旋转、一边沿螺旋轨迹前进，使感光结构周期采样入射光，随后通过改变鞭毛运动调整方向。眼点与副鞭毛体共同参与趋光，而光合作用仍由叶绿体完成。裸藻通常纵二分裂，表膜条带、鞭毛基体和细胞器随细胞轴复制；某些种在不利条件下可形成休眠细胞。裸藻及其他微型真核生物会随有机负荷和水体状态改变，可用于特定条件下的生态毒理与群落监测。[^euglena-phototaxis]

盘藻、实球藻和团藻属于绿藻，与裸藻分属不同真核支系。它们从少数细胞群体到具有体细胞—生殖细胞分工的大型球状群体，细胞间可由胞质桥连接，是研究绿藻多细胞化的重要比较对象；不同成员还展示从形态相近的配子到大小异形配子乃至卵式生殖的变化。这些性状在绿藻支系内独立演化，为多细胞性提供平行比较，而非动物祖先链上的中间梯级。

### 甲藻的鞭毛、膜囊与水华 { #dinoflagellates }

典型甲藻具有一条横向鞭毛和一条纵向鞭毛，分别位于横沟和纵沟中，传统也称腰鞭毛虫，两者共同产生旋转前进。部分种的质膜下膜囊承载甲板，角甲藻等形成角状突起；夜光藻的细胞和鞭毛系统高度特化，可在机械扰动下产生生物发光，并在适宜条件下形成大规模水华。甲藻包括光合、捕食、混合营养和寄生种，分裂方向与生活史也随支系而变。

海洋和半咸水有害藻华常由甲藻或硅藻形成，淡水有害藻华则常涉及蓝细菌。水色、生物发光、产毒和缺氧是彼此可以分离的现象：亚历山大藻等甲藻产生的毒素可经贝类滤食富集并进入捕食者，另一些水华通过耗氧、损伤鱼鳃或遮蔽底栖植被影响生态系统，夜光藻水华则可以在机械扰动下发光。[^harmful-blooms]

### 动质体虫、毛滴虫与领鞭毛虫 { #kinetoplastids-and-choanoflagellates }

利什曼原虫和锥虫属于动质体虫，其单一大型线粒体内有富含脱氧核糖核酸（deoxyribonucleic acid，DNA）的动质体。利什曼原虫在白蛉消化道中以具游离鞭毛的前鞭毛体增殖，在哺乳动物组织中则以无游离鞭毛的无鞭毛体寄居于巨噬细胞内；杜氏利什曼原虫复合群可导致内脏利什曼病，犬等动物可参与部分地区的传播循环。这一生活史适合用“媒介—脊椎动物宿主”描述；中间宿主和终宿主的称呼需要有性生殖位置等生活史依据。[^kinetoplastid-life-cycles]

非洲锥虫在采采蝇与哺乳动物之间循环，波动膜与鞭毛帮助其在血液、淋巴和组织液中运动，进入中枢神经系统后可造成睡眠节律和神经精神症状。克氏锥虫则主要由锥蝽传播，虫体随昆虫粪便污染叮咬处后进入组织，引起美洲锥虫病。不同锥虫还可感染马、牛和鱼类；鳃隐鞭虫等鱼类寄生者也有与鞭毛或波动膜相关的运动结构。每种疾病均需对应具体锥虫、媒介、宿主和传播路线。

阴道毛滴虫和许多传统称为“多鞭毛虫”的厌氧种类属于后滴门相关支系，细胞内的氢化酶体等结构适应低氧代谢。白蚁和蜚蠊后肠中的多鞭毛共生生物能与细菌协作分解木质食物，传统超鞭毛虫也分散在多个后滴门支系。鞭毛数量与单核、多核状态适合形态描述，高阶分类则结合超微结构和分子证据。

领鞭毛虫以单条鞭毛驱动水流，周围微绒毛领截留细菌，既有单细胞种也有形成群体的种。原绵虫等成员的领细胞样与变形细胞样状态适合研究细胞可塑性；领鞭毛虫与海绵领细胞的外形相似也曾启发动物起源研究。领鞭毛虫是动物最近的现生单细胞亲缘类群之一，其基因组中已存在若干后来参与动物细胞黏附和信号传递的蛋白结构域。动物与领鞭毛虫共享祖先，动物多细胞性还增加了稳定发育、细胞外基质、细胞类型分化和整体繁殖等组织层次。[^choanoflagellate-genome]

## 伪足运动的多支系来源 { #amoeboid-lineages }

### 伪足运动的细胞骨架 { #amoeboid-motion }

大变形虫没有坚硬表膜，形状随运动不断变化。传统上把透明致密的外周称作外质，把颗粒较多、流动明显的内部称作内质，并用“溶胶—凝胶转换”描述胞质流动。现代观察进一步显示，肌动蛋白聚合、皮层肌动—肌球蛋白收缩、膜张力、黏附和胞内压力共同参与伪足伸展；大变形虫还可由皮层收缩产生压力，推动膜泡样突起。微丝装配、肌球蛋白和皮层收缩因而共同构成运动机制。[^amoeboid-motion]

叶状伪足宽而钝，丝状伪足细长，网状伪足反复分支并融合，轴足内部有规则微管束。这些形态描述适合识别运动和摄食方式，却跨越多个支系。大变形虫用伪足包围颗粒形成食物泡，也可胞饮溶液；淡水种常以伸缩泡排水，海水种的渗透调节形式不同。二分裂、出芽、包囊或生活史中的鞭毛阶段需要逐种判断；常用的大变形虫在通常培养条件下不形成典型耐久包囊，其他变形虫的包囊性状不能直接外推到该种。

表壳虫分泌壳体，砂壳虫把外界颗粒胶结成壳，壳口只让伪足伸出。有孔虫多形成钙质或胶结质壳室，以网状伪足摄食和固定；不少种在单倍体与二倍体阶段之间交替，配子可具鞭毛。放射虫多有硅质内骨骼和轴足，传统“太阳虫”则是外形相似的多系集合。有孔虫和放射虫化石可用于地层对比和古环境重建，在油气勘探中帮助判断岩层时代与沉积环境；其作用来自微体化石记录，而非直接感知地下油藏或矿体。[^foraminifera-record]

### 溶组织内阿米巴在包囊与滋养体之间转换 { #entamoeba-histolytica }

溶组织内阿米巴的成熟四核包囊能够耐受外界环境，是经受污染食物、水或手传播的主要感染阶段。包囊在小肠脱囊，释放的滋养体进入大肠并以二分裂增殖；许多感染停留在肠腔内，滋养体再形成包囊排出。发生组织侵袭时，滋养体破坏肠黏膜，并可经门静脉到达肝等器官；组织中吞噬红细胞的滋养体是重要形态线索。腹泻粪便中可见滋养体，成形粪便中较常见包囊，但离体滋养体很快失活。

小滋养体、大滋养体等名称描述溶组织内阿米巴在不同宿主环境中的形态状态，与包囊之间构成可逆的生活史转换。显微镜难以可靠区分致病的溶组织内阿米巴与形态相近的迪斯帕内阿米巴等种，现代诊断常需抗原或分子方法。阿米巴性痢疾与细菌性痢疾的鉴别也不能只依赖血、脓比例，病原确认需要规范的临床和实验室证据。[^amebiasis-life-cycle]

## 顶复门的侵入结构与生活史 { #apicomplexa }

顶复门成员都是寄生真核生物。其侵入阶段在细胞前端集中微管骨架和棒状体、微线体等分泌细胞器，依次完成宿主识别、附着、主动侵入和寄生泡建立；许多成员还保留失去光合作用的质体——顶质体（apicoplast）。成熟阶段常缺少显著纤毛或鞭毛，但雄配子或某些传播阶段可以具鞭毛，侵入阶段则依靠肌动—肌球蛋白系统滑行。传统“孢子虫”名称概括传播体形态，完整生活史则在无性增殖、有性生殖和传播体形成之间精细切换。

### 疟原虫的人—按蚊生活史 { #plasmodium-life-cycle }

感染雌按蚊吸血时将子孢子注入人体，子孢子首先侵入肝细胞并形成裂殖体，释放裂殖子进入血液。裂殖子主动侵入红细胞，在由宿主膜内陷形成的寄生泡内依次经历环状体、滋养体和裂殖体，随后红细胞破裂释放新一代裂殖子。血红蛋白消化产生的游离血红素有毒，虫体把一部分转化为疟色素；成批红细胞内期成熟与破裂造成周期性发热和贫血，恶性疟还可因感染红细胞黏附微血管而损伤脑等器官。

一部分血液期虫体分化为雌、雄配子体。按蚊再次吸血后，配子在蚊中肠完成受精，合子变成长形动合子并穿过肠壁形成卵囊；卵囊内产生的子孢子释放后迁入唾液腺。按发生有性生殖的一方命名，按蚊是终宿主，人是中间宿主。传统四种人疟原虫为间日疟原虫、恶性疟原虫、三日疟原虫和卵形疟原虫，今天还需纳入可由猕猴宿主溢出的诺氏疟原虫。恶性疟原虫成熟配子体呈新月形，是血涂片鉴别线索之一。不同疟原虫具有相对特定的宿主范围，鸡疟原虫等不能因生活史相似便视为人疟病原。[^malaria-life-cycle]

间日疟原虫和卵形疟原虫可在肝内形成休眠子，日后重新进入血液造成复发；血液期虫体未被清除而重新增殖称为再燃；新的蚊虫叮咬则造成再感染。不同抗疟药分别作用于血液期或肝内休眠子，选择需要考虑虫种、耐药性和患者安全条件。奎宁来自金鸡纳树皮，青蒿素来自黄花蒿；青蒿素类在虫体内经血红素相关活化后引发多靶点损伤，其他药物也具有各自的代谢和细胞靶点。

### 球虫、焦虫与传统“孢子虫” { #other-apicomplexans }

艾美球虫多在一个宿主内完成无性和有性阶段，卵囊排出后在外界孢子化；不同种的孢子囊和子孢子数是鉴定性状。隐孢子虫的厚壁卵囊排出时已经具有感染性，薄壁卵囊可参与宿主体内自体感染，主要寄生消化道上皮刷状缘。它可导致水源性腹泻，并在免疫抑制者中造成重症；隐孢子虫感染与艾滋病的诊断分别需要各自的病原和临床证据。

弓形虫只在猫科动物肠上皮完成有性生殖并排出卵囊，鸟类和哺乳动物可作为中间宿主形成组织包囊；人可由环境卵囊、未熟肉中的组织包囊或母胎传播感染。焦虫类中的巴贝虫在硬蜱与脊椎动物之间循环并侵入红细胞，不同种是否经卵传播不同；泰勒虫则可先在白细胞中增殖再进入红细胞。寄生部位、媒介和传播阶段均需按属种分别描述。[^other-apicomplexan-life-cycles]

传统“孢子虫”中的若干类群已归入其他支系。微孢子虫是高度简化的真菌或真菌近缘支系，以极丝把感染内容物注入宿主细胞，其代谢途径缺失来自寄生适应。黏孢子虫虽微小并形成孢子样传播体，却保留刺胞动物特有的小胶原等证据，是寄生性刺胞动物。肉孢子虫仍属于顶复门球虫类，常在捕食—被捕食关系连接的两个宿主间完成生活史。相似传播体由此具有不同的发生来源。[^misclassified-sporozoans]

## 纤毛虫的皮层与核二型 { #ciliates }

### 草履虫的细胞轴与功能分区 { #paramecium-cell }

草履虫属于囊泡虫中的纤毛虫。质膜下的表膜泡、纵向排列的基体和纤维结构共同构成皮层，既维持外形，也协调成千上万根纤毛的节律摆动；轴丝中的动力蛋白以三磷酸腺苷（adenosine triphosphate，ATP）驱动微管相对滑动，皮层纤维负责排列和协调。纤毛拍动使细胞一边旋转一边前进，遇到机械或化学刺激时可改变膜电位、逆转纤毛摆动并重新定向。刺丝泡等胞吐细胞器分布在皮层，可参与防御、附着或其他种间作用，功能随类群而异。

口沟的纤毛把细菌和小型颗粒送向胞口与胞咽，末端膜内陷形成食物泡。食物泡在胞质中沿相对稳定的环流路线成熟，融合溶酶体后完成胞内消化，残渣从固定胞肛区域排出。淡水草履虫常有前、后两个伸缩泡复合体，放射状收集管先汇集过量水，再经固定孔道排出；这一系统主要维持细胞体积与离子平衡。表膜泡构成柔性的皮层结构，伸缩泡则通过专门孔道排水。

纤毛虫最鲜明的特征之一是核二型（nuclear dimorphism）。二倍体小核保存生殖系基因组，在营养生长中转录较少；多倍体大核承担日常基因表达，维持代谢和细胞结构。横二分裂时小核有丝分裂，大核通常以无丝分裂方式分配，口器和皮层结构按既有前后轴重建。大核与小核经过不同发育加工，在同一细胞内分别承担体细胞与生殖系功能。

### 接合、基因组重组与大核重建 { #ciliate-conjugation }

饥饿等条件可使相容交配型的草履虫进入接合。两个细胞暂时贴合，各自小核减数分裂，保留下来的单倍体核再形成迁移核和静止核；双方交换迁移核并与对方静止核融合，形成新的合子核。接合双方随后分开，合子核后代分别发育为新小核和新大核，旧大核逐步降解。新大核形成时还会发生染色体断裂、扩增、端粒添加和生殖系限定序列删除等程序化基因组重排。核分裂次数和最终子细胞数在草履虫种间有差别，“八核—一分为四”只适用于相应物种和条件。[^ciliate-nuclear-dimorphism]

接合主要完成遗传重组和核更新，两个配对细胞随后分开，种群数量则主要通过无性横二分裂增长。吸管虫成体固着并以吸管样触手摄食，幼体仍具纤毛；一些种以外出芽或内出芽产生有纤毛幼体，成体外形简化与纤毛虫祖征由此可在不同生活史阶段并存。

纤毛虫的生活型远多于草履虫。四膜虫是细胞与分子研究模型，喇叭虫体形巨大并可收缩，游仆虫、棘尾虫等把腹面纤毛束合成棘毛用于爬行，钟虫以可收缩柄固着并用围口小膜带滤食，栉毛虫等捕食者可吞食其他纤毛虫。小膜、波动膜和棘毛都是纤毛成束或成列后的功能特化；动质体虫的波动膜则由一条鞭毛与细胞表面连接形成。绿草履虫与小球藻共生，另一些草履虫含细菌性内共生者；小瓜虫是鱼类皮肤和鳃的重要寄生虫，车轮虫类多附着于水生动物体表，致病性随种类、宿主和负荷改变。全毛、腹毛、旋毛、缘毛和吸管虫等传统分组保存了纤毛分布与口器形态，现代分类还结合超微结构和分子系统证据。

## 动物的系统与发育边界 { #animal-boundary }

单细胞真核生物能够感光、捕食、逃避、形成群体，甚至在同一细胞内建立体细胞核与生殖系核的分工。这些能力说明许多细胞黏附、信号传递、运动和基因调控元件早于动物出现。动物则是具有特定共同祖先的多细胞后鞭毛生物，其生活史把细胞增殖、分化、细胞外基质和胚胎发育整合成可重复的个体建成过程。团藻的体—殖分工、领鞭毛虫群体和纤毛虫核二型分别提供独立演化的比较实例，展示多细胞化与功能分工的平行路线。

观察传统“原生动物”时，需要同时说明结构如何支持单细胞生活，以及该生物在真核系统树上属于哪条支系。前一视角保留显微动物学的形态与生活史传统，后一视角区分趋同结构与共同亲缘。[多孔动物、扁盘动物与早期动物演化](early_animals.md)进入动物的多细胞组织，[动物起源、体制与系统发育](body_plans.md)则把领鞭毛虫等单细胞亲缘类群与化石、基因组和动物体制证据连接起来。
