# 动物学史中的原生生物

池水中的草履虫、海水中发光的甲藻、在红细胞内繁殖的疟原虫和伸出伪足的变形虫，曾被动物学教材合称为“原生动物”。这个名称抓住了它们多为单细胞、能够主动运动或吞食颗粒的一面，却把亲缘相隔很远的真核生物装进了一个“门”。分子系统学表明，传统原生动物分散在真核树的多个大支：纤毛虫、甲藻和顶复门属于囊泡虫，裸藻和锥虫属于盘嵴类，变形虫的一部分属于变形虫类，有孔虫和放射虫属于根足类，领鞭毛虫则与动物同在后鞭毛生物中。它们没有一个排除植物、真菌和动物后仍可成立的共同祖先范围。[^eukaryote-tree]

“原生生物”今天仍可作为描述性集合名，泛指不归入动物、植物或真菌的真核生物；“原生动物”也仍见于医学寄生虫学、生态监测和显微鉴定语境。使用这些名称时，需要同时说明具体支系。这样既能保存鞭毛、伪足、纤毛、包囊和裂殖等经典观察知识，又不会把现生单细胞生物排成通往动物的进化阶梯。

## 从形态纲目回到真核系统树 { #from-morphology-to-eukaryote-tree }

早期分类首先面对显微镜下可见的运动方式。用鞭毛游动的归入鞭毛纲，以伪足运动的归入肉足纲，缺少明显运动器而形成传播体的寄生者归入孢子纲，密布纤毛的归入纤毛纲。这套框架便于描述标本，却把容易趋同或反复丢失的性状当成了亲缘标志。鞭毛和纤毛都以真核细胞的微管轴丝为核心；伪足是肌动蛋白细胞骨架形成的临时突出；寄生生活又能让运动结构、线粒体代谢和摄食装置大幅简化。相同形态因而可以在不同祖先背景中独立出现。

| 传统名称 | 原先依据 | 现代承接 |
| --- | --- | --- |
| 鞭毛虫 | 一至多条鞭毛 | 裸藻、动质体虫、领鞭毛虫、毛滴虫和若干绿藻分属盘嵴类、后鞭毛生物、后滴门及其他支系 |
| 肉足虫 | 叶状、丝状、网状或轴状伪足 | 大变形虫和内阿米巴主要在变形虫类；有孔虫、放射虫在根足类；传统“太阳虫”分散于多个支系 |
| 孢子虫 | 寄生、缺少成体运动器、形成孢子或卵囊 | 疟原虫、弓形虫、球虫、隐孢子虫和焦虫属于顶复门；微孢子虫与真菌相联，黏孢子虫属于刺胞动物 |
| 纤毛虫 | 体表纤毛及其特化 | 纤毛虫门是囊泡虫中的一个自然支系，与甲藻和顶复门近缘 |

囊泡虫名称来自质膜下方成列的扁平膜囊。纤毛虫的表膜泡参与构成稳定而可变形的皮层，甲藻的膜囊可承载纤维素板，顶复门成员则把这一皮层体系与滑行和侵入宿主的装置结合起来。传统分类偶然把其中几类放得较近，但“都能运动”或“都有表膜”本身仍不足以定义这一支系。

## 一个细胞可以组织完整生活 { #unicellular-organization }

单细胞真核生物不是“只完成一种功能的动物细胞”。同一个细胞必须维持边界、取得能量、感受环境、定向运动、调节水盐、排出未消化物，并在适当条件下复制或完成有性过程。外质和内质、泡状核和致密核等旧术语描述的是光镜下的质地与染色外观，可以帮助认读标本，却不是所有原生生物共有的固定层次。它们真正共享的是由细胞膜、细胞骨架、膜性细胞器和细胞核协作维持的真核细胞组织。

营养方式常在同一物种内随环境改变。吞噬细菌、藻类或碎屑属于吞噬营养，溶解的小分子可由膜转运吸收，带叶绿体的种类可以光合；裸藻和许多甲藻还能把光合、吞噬或溶解有机物吸收组合成混合营养。旧教材的“植物性、动物性、渗透性”三分法适合描述物质入口，却不应变成固定分类。食物泡在胞吞后依次酸化、融合消化酶并沿细胞内运输，未消化残渣再由胞吐排出。气体和许多小分子可跨膜交换，含氮废物的处理则随代谢和环境而异。

淡水中的细胞持续因渗透作用吸水，伸缩泡复合体把胞质中的过量水收集后周期排出，首要作用是渗透调节；海水种类常不具同样显著的伸缩泡。收集管、储蓄泡和排水孔的形态因类群而异，不能把伸缩泡简单称作肾脏，也不能把所有代谢废物都归给它。纤毛、鞭毛和肌动蛋白骨架还把感觉信号转化为转向、避光、趋化或捕食动作。某些肽类信号和第二信使早在单细胞真核生物中已参与细胞调节，但这不表示它们拥有神经系统。

无性生殖可以是纵二分裂、横二分裂、出芽或一次产生许多子细胞的复分裂；方向往往受既有口器、鞭毛基体和皮层轴控制。裂殖通常先发生多轮核分裂，再由细胞质分隔出子细胞；多核细胞直接分成若干多核部分的质裂又是另一过程。有性过程包括同形或异形配子融合和纤毛虫接合等形式，作用是重组核基因组，并不必然伴随个体数立即增加。许多种在干燥、缺食、温度变化或离开宿主时形成包囊，降低代谢并获得耐受性；包囊既可能是休眠阶段，也可能是传播或感染阶段。不同物种的生活史组合差别很大，因此“二分裂加包囊”只能作为观察线索。

## 鞭毛形态分散在多个支系 { #flagellated-lineages }

### 裸藻与团藻各自记录了混合营养和群体生活 { #euglenids-and-volvocines }

旧动物学所称眼虫就是裸藻属成员，位于盘嵴类的裸藻支系。以纤细裸藻为例，细胞膜下由蛋白质条带组成的表膜允许身体发生蠕动样变形，表膜相关黏液体可向外释放物质；细胞前端的储蓄泡与伸缩泡复合体相通，通常有一条鞭毛伸出储蓄泡，另一条较短的鞭毛不伸出细胞表面。鞭毛基体发出的微管根系帮助定位储蓄泡、细胞核和鞭毛装置，旧称根丝体，却不能简单解释成鞭毛的单一“控制纤维”。叶绿体进行光合作用，产物以副淀粉粒形式储存在胞质中，不呈现淀粉遇碘的典型蓝色反应。缺光时，一些裸藻可利用外源有机物维持异养代谢，因而混合营养比“白天植物、黑夜动物”更准确。

橙红色眼点由类胡萝卜素颗粒构成，主要形成定向遮光；邻近鞭毛基部的副鞭毛体含光感受装置。细胞一边绕自身长轴旋转、一边沿螺旋轨迹前进，使感光结构周期采样入射光，随后通过改变鞭毛运动调整方向。眼点不是独立的眼睛，趋光也不是简单的“遮住感受器便切断能量”。裸藻通常纵二分裂，表膜条带、鞭毛基体和细胞器随细胞轴复制；某些种在不利条件下可形成休眠细胞。裸藻及其他微型真核生物会随有机负荷和水体状态改变，可用于生态毒理与群落监测，但单一物种不能充当所有污染或放射性物质的通用净化指标。[^euglena-phototaxis]

盘藻、实球藻和团藻属于绿藻而非裸藻近亲。它们从少数细胞群体到具有体细胞—生殖细胞分工的大型球状群体，细胞间可由胞质桥连接，是研究绿藻多细胞化的重要比较材料；不同成员还展示从形态相近的配子到大小异形配子乃至卵式生殖的变化。这样的分工和配子差异在绿藻支系内独立演化，不能作为单细胞“原生动物”直接变成动物的中间梯级。

### 甲藻把两条鞭毛、膜囊和水华联系起来 { #dinoflagellates }

典型甲藻具有一条横向鞭毛和一条纵向鞭毛，分别位于横沟和纵沟中，因而在旧教材中也称腰鞭毛虫，两者共同产生旋转前进。部分种的质膜下膜囊承载甲板，角甲藻等形成角状突起；夜光藻的细胞和鞭毛系统高度特化，可在机械扰动下产生生物发光，并在适宜条件下形成大规模水华。甲藻既有光合种、捕食种和混合营养种，也有寄生种，分裂方向和生活史不能由“腰鞭毛”一项概括。

海洋和半咸水有害藻华常由甲藻或硅藻形成，淡水有害藻华则常涉及蓝细菌。水华不一定呈红色，也并非都产生毒素；反过来，水色不明显时也可能有毒。亚历山大藻等甲藻产生的毒素可经贝类滤食富集并进入捕食者，另一些水华通过耗氧、损伤鱼鳃或遮蔽底栖植被影响生态系统。夜光藻水华可以发光，却不能把“发光、赤潮和神经毒性”当作同一组甲藻的必然三联征。[^harmful-blooms]

### 动质体虫、毛滴虫和领鞭毛虫拥有不同历史 { #kinetoplastids-and-choanoflagellates }

利什曼原虫和锥虫属于动质体虫，其单一大型线粒体内有富含 DNA 的动质体。利什曼原虫在白蛉消化道中以具游离鞭毛的前鞭毛体增殖，在哺乳动物组织中则以无游离鞭毛的无鞭毛体寄居于巨噬细胞内；杜氏利什曼原虫复合群可导致内脏利什曼病，犬等动物可参与部分地区的传播循环。这里用“媒介—脊椎动物宿主”比套用中间宿主和终宿主更稳妥，因为生活史并不以哪一方发生显著有性生殖来命名。旧讲义所谓“中国或世界五大寄生虫”还把疟原虫、利什曼原虫或锥虫与血吸虫、丝虫、钩虫等多细胞动物并列，那是公共卫生记忆表，不是系统分类。[^kinetoplastid-life-cycles]

非洲锥虫在采采蝇与哺乳动物之间循环，波动膜与鞭毛帮助其在血液、淋巴和组织液中运动，进入中枢神经系统后可造成睡眠节律和神经精神症状。克氏锥虫则主要由锥蝽传播，虫体随昆虫粪便污染叮咬处后进入组织，引起美洲锥虫病。不同锥虫还可感染马、牛和鱼类；鳃隐鞭虫等鱼类寄生者也有与鞭毛或波动膜相关的运动结构。疾病名称、媒介和宿主必须对应到物种，不能把采采蝇、锥蝽及各种家畜锥虫病混成一条生活史。

阴道毛滴虫和许多旧称“多鞭毛虫”的厌氧种类属于后滴门相关支系，细胞内的氢化酶体等结构适应低氧代谢。白蚁和蜚蠊后肠中的多鞭毛共生生物能与细菌协作分解木质食物，旧称超鞭毛虫的成员也分散在多个后滴门支系；多鞭毛与单核、多核并不是可靠的高阶分类依据。

领鞭毛虫以单条鞭毛驱动水流，周围微绒毛领截留细菌，既有单细胞种也有形成群体的种。旧教材常以原绵虫说明群体内领细胞样和变形细胞样形态并存；这类形态转换适合研究细胞状态可塑性，却不是已经建立动物组织的证据。领鞭毛虫是动物最近的现生单细胞亲缘类群之一，与海绵领细胞的外形相似曾启发动物起源研究。基因组中已经存在若干后来参与动物细胞黏附和信号传递的蛋白结构域，但领鞭毛虫是与动物共享祖先的姐妹群，不是停留至今的动物祖先；动物多细胞性还涉及稳定发育、细胞外基质、细胞类型分化和整体繁殖等新的组织层次。[^choanoflagellate-genome]

## 伪足是运动方案而非亲缘标签 { #amoeboid-lineages }

### 细胞骨架在前缘、皮层和胞质之间重排 { #amoeboid-motion }

大变形虫没有坚硬表膜，形状随运动不断变化。传统上把透明致密的外周称作外质，把颗粒较多、流动明显的内部称作内质，并用“溶胶—凝胶转换”描述胞质流动。现代观察进一步显示，肌动蛋白聚合、皮层肌动—肌球蛋白收缩、膜张力、黏附和胞内压力共同参与伪足伸展；大变形虫还可由皮层收缩产生压力，推动膜泡样突起。把运动完全归于微丝装配而排除马达蛋白，会遗漏肌球蛋白和皮层收缩的作用。[^amoeboid-motion]

叶状伪足宽而钝，丝状伪足细长，网状伪足反复分支并融合，轴足内部有规则微管束。这些形态描述仍适合识别运动和摄食方式，却跨越多个支系。大变形虫用伪足包围颗粒形成食物泡，也可胞饮溶液；淡水种常以伸缩泡排水，海水种的渗透调节形式不同。二分裂、出芽、包囊或生活史中的鞭毛阶段要逐种判断，例如常用的大变形虫在通常培养条件下不形成典型耐久包囊，不能据“多数变形虫有包囊”反推每一种。

表壳虫分泌壳体，砂壳虫把外界颗粒胶结成壳，壳口只让伪足伸出。有孔虫多形成钙质或胶结质壳室，以网状伪足摄食和固定；不少种在单倍体与二倍体阶段之间交替，配子可具鞭毛。放射虫多有硅质内骨骼和轴足，传统“太阳虫”则只是外形相似的多系集合。有孔虫和放射虫化石可用于地层对比和古环境重建，因此在油气勘探中帮助确定岩层时代与沉积环境；它们提供的是微体化石证据，不是直接感知地下油藏或矿体。[^foraminifera-record]

### 溶组织内阿米巴在包囊与滋养体之间转换 { #entamoeba-histolytica }

溶组织内阿米巴的成熟四核包囊能够耐受外界环境，是经受污染食物、水或手传播的主要感染阶段。包囊在小肠脱囊，释放的滋养体进入大肠并以二分裂增殖；许多感染停留在肠腔内，滋养体再形成包囊排出。发生组织侵袭时，滋养体破坏肠黏膜，并可经门静脉到达肝等器官；组织中吞噬红细胞的滋养体是重要形态线索。腹泻粪便中可见滋养体，成形粪便中较常见包囊，但离体滋养体很快失活。

旧教材把小滋养体、大滋养体和包囊写成固定的单向阶梯，容易把宿主环境造成的形态差异当成独立世代。显微镜也难以可靠区分致病的溶组织内阿米巴与形态相近的迪斯帕内阿米巴等种，现代诊断常需抗原或分子方法。阿米巴性痢疾与细菌性痢疾的血、脓比例并非可靠判据，病原确认应依靠规范的临床和实验室证据。[^amebiasis-life-cycle]

## 顶复门把侵入结构编入生活史 { #apicomplexa }

顶复门成员都是寄生真核生物。其侵入阶段在细胞前端集中微管骨架和棒状体、微线体等分泌细胞器，依次完成宿主识别、附着、主动侵入和寄生泡建立；许多成员还保留不能光合的质体——顶质体。成熟阶段常看不到纤毛或鞭毛，但雄配子或某些传播阶段可以具鞭毛，侵入阶段则依靠肌动—肌球蛋白系统滑行。旧名“孢子虫”把缺少显著运动器视作简单，实际生活史在无性增殖、有性生殖和形成传播体之间进行精细切换。

### 疟原虫在人与按蚊之间转换增殖方式 { #plasmodium-life-cycle }

感染雌按蚊吸血时将子孢子注入人体，子孢子首先侵入肝细胞并形成裂殖体，释放裂殖子进入血液。裂殖子主动侵入红细胞，在由宿主膜内陷形成的寄生泡内依次经历环状体、滋养体和裂殖体，随后红细胞破裂释放新一代裂殖子。血红蛋白消化产生的游离血红素有毒，虫体把一部分转化为疟色素；成批红细胞内期成熟与破裂造成周期性发热和贫血，恶性疟还可因感染红细胞黏附微血管而损伤脑等器官。

一部分血液期虫体分化为雌、雄配子体。按蚊再次吸血后，配子在蚊中肠完成受精，合子变成长形动合子并穿过肠壁形成卵囊；卵囊内产生的子孢子释放后迁入唾液腺。按发生有性生殖的一方命名，按蚊是终宿主，人是中间宿主。传统四种人疟原虫为间日疟原虫、恶性疟原虫、三日疟原虫和卵形疟原虫，今天还需纳入可由猕猴宿主溢出的诺氏疟原虫。恶性疟原虫成熟配子体呈新月形，是血涂片鉴别线索之一。不同疟原虫具有相对特定的宿主范围，鸡疟原虫等不能因生活史相似便视为人疟病原。[^malaria-life-cycle]

间日疟原虫和卵形疟原虫可在肝内形成休眠子，日后重新进入血液造成复发；血液期虫体未被清除而重新增殖称再燃。二者均不同于新的蚊虫叮咬造成再感染。肝期并非“药物无效”：部分药物针对血液期，另一些用于清除肝内休眠子，但选择必须考虑虫种、耐药性和患者安全条件。奎宁来自金鸡纳树皮，青蒿素来自黄花蒿；青蒿素类在虫体内经血红素相关活化后引发多靶点损伤，不宜简化成只抑制线粒体，而抗疟药也并非大多只作用叶酸代谢。

### 球虫、焦虫和旧“孢子虫”需要逐类归位 { #other-apicomplexans }

艾美球虫多在一个宿主内完成无性和有性阶段，卵囊排出后在外界孢子化；不同种的孢子囊和子孢子数是鉴定性状。隐孢子虫的厚壁卵囊排出时已经具有感染性，薄壁卵囊可参与宿主体内自体感染，主要寄生消化道上皮刷状缘。它可导致水源性腹泻，并在免疫抑制者中造成重症，但不能把检出隐孢子虫写成艾滋病的诊断指标。

弓形虫只在猫科动物肠上皮完成有性生殖并排出卵囊，鸟类和哺乳动物可作为中间宿主形成组织包囊；人可由环境卵囊、未熟肉中的组织包囊或母胎传播感染。焦虫类中的巴贝虫在硬蜱与脊椎动物之间循环并侵入红细胞，不同种是否经卵传播不同；泰勒虫则可先在白细胞中增殖再进入红细胞。寄生部位、媒介和传播阶段必须按属种区分，不能用一条“血孢子虫生活史”替代。[^other-apicomplexan-life-cycles]

有些旧“孢子虫”已经移出顶复门。微孢子虫是高度简化的真菌或真菌近缘支系，以极丝把感染内容物注入宿主细胞；它们缺失许多代谢途径是寄生适应的结果，不是原始真核状态。黏孢子虫虽微小并形成孢子样传播体，却保留刺胞动物特有的小胶原等证据，是寄生性刺胞动物。肉孢子虫仍属于顶复门球虫类，常在捕食—被捕食关系连接的两个宿主间完成生活史。传统分类中相似的“孢子”其实有不同发生来源。[^misclassified-sporozoans]

## 纤毛虫以皮层和核二型组织复杂细胞 { #ciliates }

### 草履虫把游泳、摄食和渗透调节排列在固定细胞轴上 { #paramecium-cell }

草履虫属于囊泡虫中的纤毛虫。质膜下的表膜泡、纵向排列的基体和纤维结构共同构成皮层，既维持外形，也协调成千上万根纤毛的节律摆动；轴丝中的动力蛋白以 ATP 驱动微管相对滑动，皮层纤维负责排列和协调，并不是独立的“纤毛能源器官”。纤毛拍动使细胞一边旋转一边前进，遇到机械或化学刺激时可改变膜电位、逆转纤毛摆动并重新定向。刺丝泡等胞吐细胞器分布在皮层，可参与防御、附着或其他种间作用，功能随类群而异。

口沟的纤毛把细菌和小型颗粒送向胞口与胞咽，末端膜内陷形成食物泡。食物泡在胞质中沿相对稳定的环流路线成熟，融合溶酶体后完成胞内消化，残渣从固定胞肛区域排出。淡水草履虫常有前、后两个伸缩泡复合体，放射状收集管先汇集过量水，再经固定孔道排出；这一系统主要维持细胞体积与离子平衡。表膜泡并非阻止一切物质穿膜的硬壳，胞口也不是伸缩泡的常规排水口。

纤毛虫最鲜明的特征之一是核二型。二倍体小核保存生殖系基因组，在营养生长中转录较少；多倍体大核承担日常基因表达，维持代谢和细胞结构。横二分裂时小核有丝分裂，大核通常以无丝分裂方式分配，口器和皮层结构按既有前后轴重建。大核与小核不是“营养核”和“生殖核”两颗普通细胞核，而是同一细胞内经过不同发育加工、分别承担体细胞与生殖系功能的核系统。

### 接合会重组基因组并重建大核 { #ciliate-conjugation }

饥饿等条件可使相容交配型的草履虫进入接合。两个细胞暂时贴合，各自小核减数分裂，保留下来的单倍体核再形成迁移核和静止核；双方交换迁移核并与对方静止核融合，形成新的合子核。接合双方随后分开，合子核后代分别发育为新小核和新大核，旧大核逐步降解。新大核形成时还会发生染色体断裂、扩增、端粒添加和生殖系限定序列删除等程序化基因组重排。具体核分裂次数和最终子细胞数在草履虫种间有差别，不宜把某一种的“八核—一分为四”写成纤毛虫通则。[^ciliate-nuclear-dimorphism]

接合本身主要完成遗传重组和核更新，两个配对细胞不会当场合并成一个永久个体，也不直接使种群数量翻倍。无性横二分裂才是常见的数量增长方式。吸管虫成体固着并以吸管样触手摄食，幼体仍具纤毛；一些种以外出芽或内出芽产生有纤毛幼体，说明成体外形简化不等于失去纤毛虫祖征。

纤毛虫的生活型远多于草履虫。四膜虫是细胞与分子研究模型，喇叭虫体形巨大并可收缩，游仆虫、棘尾虫等把腹面纤毛束合成棘毛用于爬行，钟虫以可收缩柄固着并用围口小膜带滤食，栉毛虫等捕食者可吞食其他纤毛虫。小膜、波动膜和棘毛都是纤毛成束或成列后的功能特化，不应与动质体虫由一条鞭毛形成的波动膜混同。绿草履虫与小球藻共生，另一些草履虫含细菌性内共生者；小瓜虫是鱼类皮肤和鳃的重要寄生虫，车轮虫类多附着于水生动物体表，致病性随种类、宿主和负荷改变。全毛、腹毛、旋毛、缘毛和吸管虫等旧分组保存了纤毛分布与口器形态，但现代分类还结合超微结构和分子系统证据。

## 动物边界由共同祖先和发育组织限定 { #animal-boundary }

单细胞真核生物能够感光、捕食、逃避、形成群体，甚至在同一细胞内建立体细胞核与生殖系核的分工。这些能力说明许多细胞黏附、信号传递、运动和基因调控元件早于动物出现。动物的边界仍由共同祖先限定：动物是具有特定亲缘范围的多细胞后鞭毛生物，其生活史把细胞增殖、分化、细胞外基质和胚胎发育整合成可重复的个体建成过程。团藻的体—殖分工、领鞭毛虫群体和纤毛虫核二型分别提供独立演化的比较实例，并不依次构成动物祖先链。

因此，观察“原生动物”应同时提出两个问题：眼前结构怎样让一个细胞完成生活，它在真核系统树上又来自哪条支系。前一个问题保留显微动物学的形态与生活史传统，后一个问题防止把趋同结构误作亲缘。下一页的[多孔动物、扁盘动物与早期动物演化](early_animals.md)将进入真正的动物多细胞组织；[动物起源、体制与系统发育](body_plans.md)则把领鞭毛虫等单细胞亲缘类群与化石、基因组和动物体制证据接在一起。
