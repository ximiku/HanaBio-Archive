# 六足动物与昆虫

昆虫的身体把取食、运动和内脏容纳集中到三个清楚的体区：头部携带一对触角和多种口器，胸部的三对足支撑身体，中、后胸还可各生一对翅，腹部则容纳大部分消化、排泄和生殖器官。六条胸足是六足动物最稳定的共同图式，但原尾类、弹尾类和双尾类并不属于狭义昆虫；跳蚤、虱和工蚁虽然没有翅，却来自有翅祖先。辨认六足动物因而要把体区、口器、足、翅、腹部附器和胚后发育连在一起，而不能只数足或看成虫是否会飞。

本页沿传统动物学的观察路径，先比较非昆虫六足动物，再以东亚飞蝗说明昆虫外形和内部解剖，随后展开口器、触角、足、翅、感觉、生殖、变态以及各目鉴别。上一页讨论的[甲壳动物](crustaceans.md)与六足动物共同组成泛甲壳动物；系统基因组和发育研究将在形态旁说明这些结构的亲缘意义，但不取代标本上逐节辨认的过程。

## 六足体制与非昆虫六足动物 {#hexapod-body-plan}

### 头、胸、腹与六条胸足

六足动物通常分为头、胸、腹三部。昆虫头部传统上由六个发生单位组成：眼区、触角节、无成对附肢的间插节、大颚节、小颚节和下唇节。触角位于中脑支配的触角节，与甲壳动物第一触角同源；甲壳动物第二触角所在的后脑体节在六足动物中不再形成一对外露附肢。大颚、小颚和合并成下唇的一对附肢围绕口部，头壳内部的幕骨则为口器和咽部肌肉提供支点。

胸部依次为前胸、中胸和后胸，每节各有一对单枝型步足。典型足从近端到远端分为基节、转节、腿节、胫节、跗节和前跗节；跗节常再分若干跗小节，前跗节可具一对爪、爪间体或中垫。旧图中的“后跗”容易与蛛形动物步足术语混用，观察昆虫时应把多节的跗节与末端前跗节分清。有翅昆虫的前翅着生于中胸，后翅着生于后胸，飞行肌和相应胸节骨片随之发达。

昆虫腹部的基本图式可追踪到十一节及末端区，但成虫常因缩小、内陷或融合而只能看到八至十个外露体节。大多数腹节不具步足，仍可保留气门、尾须、产卵器、生殖突和幼虫腹足等附属结构。原尾类前三腹节的小附肢、弹尾类的腹管与弹器、昆虫生殖附器，说明“腹部无附肢”只是成虫外观的概括。

### 原尾类、弹尾类与双尾类

传统“内颚纲”把原尾、弹尾和双尾三类合在一起，因为它们的口器基部收在头壳形成的颚囊中。三者都是六足动物，却与外颚的昆虫纲分列；它们的体型、触角、腹部附器和发育方式差别很大，不能以“小型、无翅、土壤生活”相互替代。

| 类群 | 头部与感觉结构 | 腹部及运动结构 | 发育与识别要点 |
| --- | --- | --- | --- |
| 原尾类 Protura | 无触角和复眼，前足举向前方承担感觉，头部有伪眼器 | 初孵个体腹节较少，前三腹节保留短小附器 | 连续蜕皮增加腹节，称增节发育；体形细小，多见于湿润土壤和腐殖层 |
| 弹尾类 Collembola | 具四节触角，复眼退化为不等数小眼或完全消失 | 第一腹节有腹管，第三腹节有握弹器，第四腹节常有弹器 | 腹管参与黏附和水盐交换，弹器突然释放使身体跃起；仍可在性成熟后蜕皮 |
| 双尾类 Diplura | 具多节触角，无眼，口器内缩 | 腹末一对尾须可细长多节，也可钳状 | 不以弹器跳跃；捕食型铗尾类可用钳状尾须夹持，康尾类尾须细长而具感觉作用 |

旧材料把双尾类误写成“双翅目”，还把三者的触角和大颚关节概括成统一性状。实际上原尾类没有触角，弹尾和双尾触角鞭节内部仍有肌肉，三类颚的关节和运动方式也不同。2024 年系统基因组分析支持六足动物和其中四个主要支系各自单系，并提出原尾类最早分出、弹尾与双尾较近、二者再与昆虫纲互为姐妹的拓扑；其他数据集曾得到不同关系，因此“内颚类”可以继续作为形态接口，不宜未经说明就当作已经无争议的单系纲。[^hexapod-phylogeny]

## 代表动物：东亚飞蝗 {#oriental-migratory-locust}

动物学实验中的东亚飞蝗通常指迁飞蝗 *Locusta migratoria* 的东亚地理型或亚种 *L. m. manilensis*。它的咀嚼式口器、三对形态清楚的胸足、覆翅与膜质后翅、腹部鼓膜器和渐变态生活史，集中显示了直翅目昆虫的体制。群居相与散居相会在体色、体形比例、生理和行为上发生可逆变化，但两相仍属同一种，不能凭一项颜色性状定名。

### 头部与咀嚼式口器

飞蝗头壳由头顶、额、唇基、颊和后头等区域组成，骨片愈合和内陷形成坚固的头壳及幕骨。两侧各有一枚复眼，头顶还有三枚单眼；一对丝状触角由柄节、梗节和多节鞭部构成。触角能接受气味、接触、气流和自身运动信息，听觉则主要依赖腹部鼓膜器，不能把“触角司听觉”写成飞蝗唯一的听觉途径。

咀嚼式口器保留了各头部附肢最容易辨认的形态。上唇是与唇基相连的活动骨片；一对大颚坚硬不分节，切齿叶切断食物，臼齿叶研磨；一对小颚由轴节、茎节、内颚叶、外颚叶和五节小颚须组成，负责握持、刮取和感觉；一对附肢合并成下唇，其前颏携带内、外唇叶和三节下唇须。中央舌状的下咽不是成对附肢，它把口前腔分隔成食物通路与唾液通路，并具有感觉结构。

### 胸足、翅和腹部末端

前胸背板宽大如鞍，中、后胸承担两对翅和飞行肌。前足和中足主要步行，后足腿节粗大、容纳发达的伸胫肌，胫节细长而具刺，形成跳跃足。前翅狭长而革质，称覆翅或复翅，主要保护宽大的膜质后翅；后翅静止时沿纵褶折叠，起飞时展开。覆翅仍有翅脉，不能因质地较硬就与无翅脉的甲虫鞘翅等同。

腹部第一节两侧各有一枚椭圆形鼓膜器，外表可见鼓膜，内部的气囊和感音器把振动转为神经信号。多数腹节侧面有气门。第十一节附近可见一对尾须、肛上板和肛侧板；雄虫第九腹板向后形成下生殖板，雌虫第八、九腹节的三对产卵瓣共同形成短而坚硬的产卵器，适于把卵块置入土中。蜜蜂螯针来自同一套雌性产卵器构件的改造，但其形态和作用已经高度专化。

### 内部解剖的前后关系

打开背板后，背侧首先可见细长的背血管和扇形翼状肌；两侧及内脏表面分布银白色气管和气囊；消化道从前方嗉囊、前胃延伸到带胃盲囊的中肠，再进入后肠；中、后肠交界处着生大量细长马氏管；腹侧则是具有胸、腹神经节的腹神经索。成对卵巢或精巢位于消化道背侧和两旁，导管向后汇入生殖腔或射精管。

飞蝗腹部背血管可辨分节性的心脏区，教材和标本常按缩窄、心孔或翼状肌界线描述为若干心室。蝗科比较解剖可见八个腹部心室和多组流入、流出心孔；把某张图的“七心室”推广到全部昆虫并不可靠。标本观察时应分别记录心室界线、成对心孔与翼状肌，不用一个数字替代结构。[^insect-structure]

## 外部结构的功能分化 {#external-morphology}

### 口器方向与取食方式

昆虫头部可按口器朝向描述为下口式、前口式和后口式。下口式常见于取食植物或碎屑的咀嚼型，前口式常见于追捕或钻蛀型，后口式常见于半翅目刺吸型；朝向反映头壳与口器的空间关系，并不直接等于食性或“原始程度”。

| 口器类型 | 主要构件的改造 | 代表与读图要点 |
| --- | --- | --- |
| 咀嚼式 | 大颚切磨，小颚和下唇握持并感觉 | 飞蝗、蜚蠊、甲虫和许多膜翅目；螳螂虽捕食，仍用大颚咀嚼 |
| 刺吸式 | 多枚口针置于下唇形成的喙槽内，食物道与唾液道分开 | 蝉、蚜、蝽等半翅目；蚊的口针组合另行演化，雌雄和种间还会因食性而异 |
| 锉吸式 | 蓟马左右大颚不对称，保留左大颚针并与成对小颚针协作 | 缨翅目；先破坏表面细胞，再吸取渗出的液体 |
| 虹吸式 | 成对小颚外颚叶延长并扣合成可卷曲喙，大颚多退化 | 多数鳞翅目成虫；部分原始类群仍咀嚼，另有成虫口器退化不食 |
| 嚼吸式 | 大颚仍可咬合，下唇与小颚形成取食液体的喙 | 蜜蜂；工蜂以大颚加工蜡和花粉，以喙舐取花蜜 |
| 舐吸式 | 下唇末端形成有伪气管沟的唇瓣，液体被引入口前腔 | 家蝇等具唇瓣的蝇类；大颚退化，不适合刺穿完整皮肤 |
| 切舐式 | 刀片状大颚和小颚切开皮肤，唇瓣吸取渗出的血液 | 牛虻等；与蚊的细长口针式穿刺不同 |
| 捕吸式幼虫口器 | 大颚与小颚配合形成弯曲的刺吸钳 | 草蛉等脉翅目幼虫；先夹刺猎物，再吸取液化内容物 |

“上唇形成食物道”“下颚形成食物道”等说法必须对应具体横切面。食物道常由上唇、下咽或成对小颚针相互贴合的表面围成，并非一枚口器单独变成封闭管道。口器同源比较的重点是确认哪一对构件保留、延长、合并或退化，而不是只记一种喙的外形。

### 触角、足和翅的标本性状

触角的柄节和梗节相对稳定，鞭部变化最大。丝状、刚毛状、念珠状、锯齿状、栉齿状、双栉齿状、膝状、具芒状、环毛状、棒状、锤状和鳃片状等名称描述整体轮廓。蜜蜂、蚂蚁和象鼻虫常见膝状触角，雄蛾常见栉齿或双栉齿触角，雄蚊鞭部刚毛常形成环毛状外观，蝇类第三触角节常带芒，金龟子末端数节形成可开合的鳃片。相同轮廓可在不近缘类群中独立出现，定目时还要看节数、着生位置和其他结构。

| 足的类型 | 主要形态变化 | 代表与功能 |
| --- | --- | --- |
| 步行足 | 各肢节比例较均衡 | 飞蝗前、中足，步甲和瓢虫 |
| 跳跃足 | 后足腿节粗大，胫节长 | 蝗虫、蟋蟀和跳蚤；跳蚤的基节与胸部结构也共同储放弹性能量 |
| 捕捉足 | 前足基节、腿节延长，腿、胫节具相对的刺列 | 螳螂；折合时夹住猎物 |
| 开掘足 | 前足胫节宽扁并具齿 | 蝼蛄；推动土壤而非跳跃 |
| 游泳足 | 后足扁平，边缘有长游泳毛 | 龙虱、仰泳蝽等水生昆虫 |
| 攀援足 | 胫节末端与单爪形成夹持结构 | 虱类；扣住毛发或羽毛 |
| 抱握足 | 前足跗节或爪扩大、具吸附面 | 雄性龙虱等水生甲虫在交配时固定雌体 |
| 净角与携粉足 | 前足具触角清理器，后足胫节和第一跗节形成花粉筐、花粉刷及压粉结构 | 蜜蜂工蜂；不同蜂类携粉结构并不完全相同 |

昆虫翅是体壁与附肢基部演化关系最复杂的结构之一。翅膜由背、腹两层表皮及角质层构成，翅脉内可有气管、神经和血淋巴通道；翅基小骨片与胸部关节相接。发育遗传、甲壳动物附肢基因敲除和化石形态共同支持翅与背侧体壁、近基部附肢组织都有关的复合起源模型，但各组织贡献仍在讨论。[^wing-origin]

| 翅型 | 构造 | 常见类群与鉴别 |
| --- | --- | --- |
| 膜翅 | 两层透明翅膜由翅脉支撑 | 蜻蜓、蜂、白蚁有翅型等；名称不表示都属于膜翅目 |
| 覆翅或复翅 | 前翅革质而仍保留翅脉，后翅膜质 | 直翅目和蜚蠊目；静止时保护后翅 |
| 鞘翅 | 前翅高度骨化，左右通常在背中线相接 | 鞘翅目；主要保护后翅和腹部，后翅可退化或消失 |
| 半鞘翅 | 前翅基部较硬、端部膜质 | 多数异翅类蝽；与全翅均膜质的蝉、蚜等比较 |
| 鳞翅 | 翅面覆有由刚毛演化的鳞片 | 蝶和蛾；鳞片参与色彩、热调节与气动表面形成 |
| 毛翅 | 膜质翅面主要覆毛 | 石蛾；与鳞翅目互为近亲但翅被不同 |
| 缨翅 | 翅狭长，边缘排列长缨毛 | 蓟马；小型个体可借缨毛增加有效翼面 |
| 平衡棒 | 一对翅缩成具感觉作用的棒状器 | 双翅目前翅飞行、后翅成平衡棒；捻翅目则前翅成棒、后翅飞行 |

## 血腔、消化、呼吸与排泄 {#internal-systems}

### 开放式循环与脂肪体

昆虫成体的主要体腔是血腔，背膈和腹膈可将其分成围心窦、围脏窦和围神经窦，但隔膜并非完整密闭的腔壁。背血管后部是具心孔的心脏，前部为大动脉；翼状肌和背膈运动使血淋巴进入围心区，心脏蠕动把它推向头部，再流回各血窦。足、翅和触角基部还可有辅助搏动器官，身体运动也参与局部循环。

血淋巴运输营养物、离子、激素和代谢物，血细胞参与吞噬、包囊、凝血与创伤修复。多数昆虫的气管直接向组织输送氧，血淋巴不承担主要呼吸色素运输；“血液无色”也不是严格共同特征，色素、食物和生理状态可使血淋巴呈黄、绿或其他颜色。脂肪体散布在血腔中，承担糖原和脂质储存、氨基酸与含氮废物代谢、解毒、免疫蛋白合成等功能，并非只在所谓“低等昆虫”中堆积尿酸。

### 前肠、中肠与后肠

消化道依次分为前肠、中肠和后肠。飞蝗前肠包括咽、食道、嗉囊和具齿的前胃，储存并继续研碎植物材料；中肠前端的胃盲囊增加分泌和吸收面积；后肠的回肠、结肠和直肠回收水盐并形成粪便。前、后肠由外胚层内陷而来，内面有随蜕皮更新的角质内膜，中肠没有这种表皮内膜。

许多昆虫中肠分泌围食膜或围食基质，把食团与上皮隔开并允许消化酶和小分子通过。它含几丁质微纤维、蛋白和糖蛋白，却不是“中肠内的一层外骨骼”；部分吸液昆虫没有典型围食膜，而形成围微绒毛膜等替代结构。唾液腺和中肠酶完成胞外消化，肠道微生物又可参与纤维素、植物汁液或贫乏食物的利用，具体作用随类群而异。

### 气门、气管、微气管和气囊

气管系统从成对气门向内分支。较粗气管内壁有螺旋或环形角质加厚，称螺旋丝或环纹，用来抵抗塌陷；细小微气管深入肌肉和其他组织，末端与细胞间的气体交换距离很短。气囊是缺少或少有加厚环纹的薄壁扩张部，能随腹部和胸部运动改变容积。旧说把气囊写成“螺旋丝扩大而成”，混淆了管壁支撑与管腔扩张。

小型或静止昆虫可主要依靠扩散，飞蝗等大型活跃昆虫还以腹部泵动、飞行肌运动和气囊压缩形成对流。气门阀受神经和化学环境调节，可连续、周期或不连续开放；关闭会影响气体交换和呼吸失水，但不同昆虫采用的模式及其适应意义并不相同。[^insect-respiration] 水生若虫可以有封闭气管和气管鳃，也可携带气泡、利用物理鳃或以呼吸管接触水面，因此“昆虫固定有十对气门”只适合飞蝗等全气门式代表。

### 马氏管、后肠与水盐平衡

马氏管是中、后肠交界附近伸入血腔的盲管，管腔与后肠相通。上皮主动分泌钾、钠、氯等离子，水和小分子随之进入管腔，形成的初尿流入后肠；直肠垫和其他后肠区域再选择性回收水、盐和代谢物。许多陆生昆虫把含氮废物转为低溶解度尿酸或尿酸盐，但也有排氨、尿素或其他嘌呤产物占较大比例的种类。

毛虫和部分甲虫的马氏管末端贴近直肠形成隐肾系统，可从粪便和直肠腔高效回收水盐。蚜总科在演化中丢失了典型马氏管，水盐和含氮代谢由肠道、脂肪体等共同承担；这是一支系特化，不能反过来否定马氏管是多数昆虫的重要排泄—渗透调节器官。马氏管与后肠是一套功能连续的系统，管数本身不代表排泄能力高低。[^malpighian-tubules]

## 神经系统与感觉世界 {#nervous-sensory}

昆虫脑由前脑、中脑和后脑组成，前脑的视叶处理复眼信息，中脑接受触角输入，后脑联系口前区和交感系统。围食道神经连接咽下神经节，腹神经索沿腹侧延伸；相邻胸、腹神经节可分开，也可在蜂、蝇等类群中融合。食道神经系统调节前肠与心脏，神经分泌细胞又把感觉、代谢和发育状态接入内分泌系统。

体表毛状感器可感受触碰、气流、声音或化学物，钟形感器检测角质层应变，弦音器由体内成列的感觉单元感受关节位移和振动。触角梗节内的江氏器检测鞭部相对运动，在蚊虫求偶声、飞行速度和重力感受中有不同用途。鼓膜器的位置具有鉴别价值：蝗科多在第一腹节，蟋蟀和螽斯多在前足胫节，若干蛾类则在胸腹交界或腹部其他位置；不能把一个位置当作昆虫听器的统一位置。

复眼由许多小眼组成，每个小眼包括角膜、晶锥、感光细胞形成的感杆束及色素细胞。并列型常在强光下提供较高空间分辨率，光学叠加型可提高弱光灵敏度，但许多复眼会随适应状态改变光路，昼行与夜行也不构成绝对二分。成虫背单眼参与光强、地平线和飞行稳定等快速信息处理；幼虫侧单眼可以形成有限图像。把单眼一概写成“只能感光、不能成像”，会忽略不同单眼类型的结构差别。

## 生殖、胚胎与胚后发育 {#reproduction-development}

### 卵、卵裂与多样的生殖方式

多数昆虫卵富含中央卵黄，早期细胞核在共同细胞质中分裂并迁向周缘，随后形成细胞化胚盘，称表面卵裂。胚外的浆膜和羊膜包围胚胎并参与防护、水分和免疫功能；这些膜与羊膜脊椎动物的羊膜卵不是同一套分类标志。精子通常从卵前端或特定区域的受精孔进入，气体交换则还依赖卵壳上的气孔系统，不能把受精孔同时概括成主要“空气和水分通道”。

雌虫生殖系统常由成对卵巢、侧输卵管、总输卵管、受精囊和附腺组成；雄虫常有成对精巢、输精管、储精结构、附腺和射精管。许多种通过精荚转移精子。产卵器由腹部附肢构件演变，可成为插入土壤或植物组织的瓣片、寄生蜂的钻刺器，或蜜蜂与胡蜂的螯针；具体构件要按目和性别比较。

昆虫的孤雌生殖并非一种固定机制。蜜蜂未受精卵发育为单倍体雄蜂属于产雄孤雌生殖，受精卵产生雌蜂，因此整个生活史仍包含两性生殖；某些竹节虫和膜翅目可由未受精卵产生雌体；蚜虫则常在适宜季节连续孤雌胎生，并在温带年周期中恢复有性世代。寄主转换与有性世代是否出现都随蚜种和气候而变，旧“冬寄主—夏寄主”流程只适合异寄主全周期类型。[^aphid-life-cycle] 寄生性小蜂还可由一个卵形成多个胚，瘿蚊等少数双翅目可在幼虫期以幼体生殖产生后代。

### 无变态、渐变态与完全变态

“幼体”是胚后未成熟阶段的泛称；在形态描述中，渐变态昆虫通常称若虫，水生且具有临时呼吸或捕食结构的蜉蝣、蜻蜓和襀翅目幼期常称稚虫或水生若虫，完全变态昆虫才用狭义幼虫。各类型之间的关键不是变化“大小”，而是翅芽位置、是否有蛹期、成虫原基保存方式和末次蜕皮的组织重塑程度。

| 发育类型 | 胚后序列 | 形态特征与代表 |
| --- | --- | --- |
| 无变态或表变态 | 幼体 → 性成熟个体，成虫仍可继续蜕皮 | 石蛃和衣鱼；幼体与成体体制接近，触角、尾须等随龄期增长 |
| 增节发育 | 初孵九腹节 → 连续蜕皮增加至成体腹节数 | 原尾类；属于非昆虫六足动物的特殊胚后增节 |
| 原变态 | 水生若虫 → 亚成虫 → 成虫 | 蜉蝣；亚成虫已有功能性翅，仍要再蜕一次成为性成熟成虫 |
| 渐变态或狭义不全变态 | 卵 → 若虫 → 成虫 | 飞蝗、蜚蠊、螳螂、蝽；翅芽在体表逐龄增大，没有蛹期 |
| 水生不全变态 | 卵 → 水生若虫 → 成虫 | 蜻蜓、襀翅等；若虫可有气管鳃、可伸缩下唇等临时结构，蜉蝣因另有亚成虫而归入上一行的原变态 |
| 过渐变态 | 卵 → 活动若虫 → 静止的前蛹／蛹状期 → 成虫 | 蓟马、粉虱和雄性介壳虫等；静止期与完全变态昆虫的真正蛹并非同一演化起源 |
| 完全变态 | 卵 → 幼虫 → 蛹 → 成虫 | 甲虫、蜂、蝇、蝶蛾等；幼虫与成虫的取食和运动结构明显分开 |
| 复变态 | 不同幼虫龄期之间也发生显著体制改变，再化蛹 | 芫菁等；第一龄三爪蚴细长活泼，找到寄主后转为行动迟缓的蛴螬型幼虫，并可经历拟蛹期 |

完全变态昆虫的蛹还可按附肢贴合程度分型。离蛹或裸蛹的足、翅和触角与体表分离，见于多数甲虫、蜂和脉翅目；被蛹的附肢紧贴身体，常见于蝶蛾；围蛹是蝇类离蛹外包着末龄幼虫硬化形成的蛹壳，蛹壳不是“第三、四龄幼虫继续包住蛹”。蛹通常不取食，但呼吸、组织分解、成虫结构形成和神经行为重组持续进行，不能把它理解成完全静止的休眠袋。

### 蝶类的卵、毛虫、蛹和成虫

鳞翅目卵可单产或成块产在寄主植物、邻近基质或其他适宜位置，卵形、表面刻纹和排列方式具有类群差异。幼虫具有三对分节胸足，腹部通常有若干对不分节腹足；腹足末端细小趾钩排列成列或环，是区别毛虫与叶蜂幼虫的重要性状。下唇腺特化为丝腺，丝液经下唇吐丝器排出；幼虫食物并不限于种子植物叶片，也有蛀茎、食果、食藻、捕食或取食其他基质的支系。

末龄幼虫停止取食、排空肠道并寻找化蛹位置。蛹可裸露悬挂、以丝带固定、埋在土中或包在茧内，蝶类常见外露的被蛹，许多蛾类结茧，但例外很多。蛹期成虫结构由保留的成虫原基、组织重塑和部分幼虫组织转分化共同形成，并非幼虫“完全溶解后重新拼装”。成虫羽化后展开并硬化翅，开始扩散、取食和繁殖。

蝶类通常具末端膨大的棒状触角，许多种昼行，静止时常把翅竖起；不少蛾类触角丝状、栉齿或羽状，夜行种较多，静止时翅可屋脊状或平覆。颜色鲜暗、昼夜活动、是否结茧和静止姿势都有大量例外，蝶类本身嵌套在鳞翅目“蛾类”辐射中，并非与所有蛾平行的两个天然大支。[^lepidoptera-phylogeny] 休眠也不是卵—幼虫—蛹—成虫之后固定增加的第五期；不同物种可在卵、幼虫、蛹或成虫阶段进入滞育。

### 蜕皮激素、保幼激素与变态决定

蜕皮的启动来自神经、营养和内分泌信号的共同作用。脑神经分泌细胞可产生前胸腺促激素，许多种中经心侧体神经血器官释放；前胸腺合成蜕皮酮，外周组织再形成活性更高的20-羟基蜕皮酮。蜕皮甾体脉冲驱动表皮脱离、角质层更新及相应基因表达，但前胸腺还受到胰岛素样肽、TOR营养信号和其他神经肽调节，不能把心侧体理解成只储存一种“活化激素”的容器。

咽侧体合成的保幼激素是一类倍半萜类化合物。幼体阶段蜕皮甾体脉冲出现时，较高保幼激素水平通常维持幼虫或若虫身份；末龄保幼激素下降后，蜕皮甾体才可启动蛹或成虫程序。在完全变态昆虫中，Broad、Kr-h1、E93 等转录调控网络把激素信号转成幼虫—蛹—成虫的阶段选择。羽化激素、蜕壳触发激素和甲壳动物心活性肽等组织蜕壳行为，鞣化激素 bursicon 参与新角质层展开、硬化和着色；旧说把“鞣化激素”单独归给腹神经节，只保留了这一网络的一部分。[^insect-metamorphosis]

## 昆虫各目的形态鉴别 {#insect-orders}

现代昆虫系统以石蛃目和衣鱼目等原始无翅昆虫、有翅昆虫，以及有翅昆虫内部的古翅类、新翅类、多新翅类、准新翅类和完全变态类组织各目。目名为标本鉴别提供稳定入口，支系关系则解释翅折叠、变态和口器为何成组出现。全昆虫系统基因组研究建立了大多数目级骨架，但古翅类、准新翅类和完全变态类的少数深节点仍会随模型和取样改变。[^insect-phylogeny]

### 原始无翅昆虫与古翅类

| 目 | 翅、口器与腹末 | 发育和代表性状 |
| --- | --- | --- |
| 石蛃目 Archaeognatha | 无翅，咀嚼式口器仅具单髁大颚；腹末有一根中尾丝和一对尾须 | 体背隆起，复眼大而常相接，善跳；成虫可继续蜕皮。旧名缨尾目曾把它与衣鱼混在一起 |
| 衣鱼目 Zygentoma | 无翅，双髁大颚；腹末同样有三根长丝 | 身体背腹扁平、覆鳞，能快速爬行；衣鱼和土衣鱼为代表，属于双髁类并与有翅昆虫较近 |
| 蜉蝣目 Ephemeroptera | 前翅三角形，后翅较小或缺失，腹末二至三根长尾丝；成虫口器多退化 | 水生若虫腹部具气管鳃；出现昆虫中独特的有翅亚成虫，亚成虫再蜕皮为成虫 |
| 蜻蜓目 Odonata | 两对膜翅不能折叠覆于腹背，复眼发达，成虫咀嚼捕食 | 水生若虫下唇形成可伸缩捕捉器；蜻科与蜓科可结合复眼接合、翅三角室方向和翅斑支持脉等钥匙性状区分，但须使用对应地区和科级检索表 |

### 多新翅类 {#polyneoptera}

多新翅类大多保留咀嚼式口器和渐变态，前翅常革质，后翅可扇状折叠；“外生翅类”描述翅芽在若虫体表发育，却不是一个包含所有不完全变态昆虫的自然单系等级。系统基因组资料支持多新翅类及其中若干组合，也表明许多传统线性排列不能代表亲缘远近。[^polyneoptera-phylogeny]

| 目 | 关键形态 | 生活史与传统接口 |
| --- | --- | --- |
| 襀翅目 Plecoptera | 成虫两对膜翅平叠腹背，后翅臀区宽，腹末常有长尾须 | 若虫多水生，胸部或腹部可有气管鳃，是溪流生物监测常见类群 |
| 直翅目 Orthoptera | 前翅为覆翅，后翅扇状，后足常为跳跃足 | 蝗亚目触角较短、鼓膜多在第一腹节，雄虫常以后足摩擦前翅；螽亚目触角很长、鼓膜多在前足胫节，蟋蟀与螽斯常以前翅摩擦发声；蝼蛄属螽亚目，前足成为开掘足 |
| 竹节虫目 Phasmatodea | 身体枝状或叶状，胸节和足细长，部分种有翅 | 拟态显著，许多种可孤雌生殖；无翅并不是整个目的原始固定状态 |
| 革翅目 Dermaptera | 前翅短而革质，后翅复杂扇折，腹末尾须钳状 | 雌虫常护卵和幼体；“耳夹子”俗称不表示会主动钻入人耳 |
| 纺足目 Embioptera | 前足第一跗节膨大并含丝腺，雄虫常有翅而雌虫无翅 | 在丝廊中群居或独居，丝来自前足而非口器 |
| 蛩蠊目 Grylloblattodea | 无翅，身体细长，触角和尾须长 | 多生活在寒冷山地石隙；旧“蛩蠊目”不包括后来命名的螳䗛目 |
| 螳䗛目 Mantophasmatodea | 无翅，捕食，前足非螳螂式折叠捕捉足 | 非洲南部类群；以足部敲击和振动通讯，现代分类中与蛩蠊目组成近缘支 |
| 螳螂目 Mantodea | 前胸延长，前足为多刺捕捉足，头部活动范围大 | 渐变态捕食者；卵包在泡沫硬化的卵鞘中 |
| 蜚蠊目 Blattodea | 身体多背腹扁，前胸背板宽，前翅覆翅，尾须明显 | 包含蜚蠊和白蚁；旧等翅目白蚁的有翅型前后翅近等长、翅基有脱落缝，工蚁和兵蚁无翅。分子和形态证据把白蚁置于木食蜚蠊近缘内部，旧目名仍可作生态形态接口。[^termite-phylogeny] |
| 缺翅目 Zoraptera | 微小，常见无翅型无眼且色淡，有翅型具眼和单眼 | 群居于朽木、树皮下等微环境；两型差异曾使分类和名称混乱 |

### 准新翅类 {#paraneoptera}

准新翅类包括啮虫目、缨翅目和半翅目等支系，口器从咀嚼型多次转向锉吸或刺吸，足和翅也常因寄生或固着而退化。现有系统基因组研究稳定支持缨翅目与半翅目接近，但啮虫目相对位置仍会因分析方法变化。[^hemipteroid-phylogeny]

| 目 | 关键形态 | 旧分类的现代承接 |
| --- | --- | --- |
| 啮虫目 Psocodea | 头较大，非寄生型具咀嚼式口器，寄生型口器和足随宿主表面生活特化 | 包含旧啮虫目与虱目；书虱、树虱和寄生性羽虱、兽虱属于同一目，寄生虱可保留为 Phthiraptera 形态组。[^psocodea-phylogeny] |
| 缨翅目 Thysanoptera | 体形细小，左右不对称的锉吸式口器，狭翅边缘有长缨毛 | 若虫后可经历前蛹、蛹状静止期，属于过渐变态而非完全变态 |
| 半翅目 Hemiptera | 下唇成喙，成对大颚针和小颚针刺吸，若虫与成虫均可取液体食物 | 旧“同翅目”包含蚜、介壳虫、粉虱、叶蝉、飞虱和蝉等，但该组合并系，现分入胸喙亚目、头喙亚目等；异翅类蝽多有半鞘翅，喙自头前端伸出 |

蚜虫展示了半翅目生活史的高度可塑性。异寄主全周期种的越冬卵在主要寄主上孵化，春季孤雌世代产生迁移型有翅雌蚜，后代转到次生寄主连续孤雌胎生；日长、温度和寄主状态改变后，再产生返回主要寄主的性母与雄蚜，形成两性世代和越冬卵。同寄主全周期种不转寄主，无全周期种则长期缺少有性世代。拥挤、营养和天敌还可诱导有翅型，但并非所有种都按同一季节表切换。蚜和介壳虫排出的蜜露主要是经过滤和代谢后的富糖液体，不是“未消化的植物汁液”原样从肛门流出。

### 完全变态类 {#holometabola}

完全变态类的翅和许多成虫结构在幼虫体内以原基形式生长，蛹期完成大规模重塑。膜翅目通常是其余现生完全变态昆虫的姐妹群；脉翅、广翅和蛇蛉组成脉翅总目，甲虫与捻翅目较近，毛翅与鳞翅互为近亲，双翅、长翅和蚤等组成另一组关系复杂的支系。教学上的各目仍保留，不能把亲缘合并误作形态名称取消。

| 目 | 成虫形态 | 幼虫、蛹与代表性状 |
| --- | --- | --- |
| 膜翅目 Hymenoptera | 两对膜翅以翅钩列联结，后翅较小；产卵器可成锯状、钻刺器或螯针 | 叶蜂等传统“广腰类”胸腹连接宽，幼虫似毛虫但腹足数和趾钩不同；细腰类第一腹节并入胸部形成并胸腹节，其后体节形成细腰。广腰类是形态接口而非单系群 |
| 鞘翅目 Coleoptera | 前翅成鞘翅，后翅膜质并折叠；咀嚼式口器 | 幼虫通常有三对胸足，钻蛀型可退化；肉食亚目包括步甲、龙虱，多食亚目包括金龟、天牛、瓢虫、象甲和芫菁等，不能以食性名称概括所有成员 |
| 捻翅目 Strepsiptera | 雄虫前翅成平衡棒、后翅宽大飞行；雌虫常幼态化并寄生 | 第一龄幼虫活泼寻找宿主，后期在其他昆虫体内寄生，性二型极强 |
| 脉翅目 Neuroptera | 两对大小近似的膜翅，横脉多，咀嚼式口器 | 草蛉、蚁蛉幼虫具大颚—小颚捕吸钳；蛹多为离蛹 |
| 广翅目 Megaloptera | 两对宽大膜翅，静止时屋脊状，咀嚼式口器 | 鱼蛉、泥蛉幼虫水生，腹部有侧鳃丝，末龄上陆化蛹 |
| 蛇蛉目 Raphidioptera | 前胸细长，头部能上举，两对网脉膜翅 | 幼虫捕食并多生活在树皮下，蛹能活动；主要分布于北半球温带 |
| 毛翅目 Trichoptera | 翅被毛，触角常细长，成虫口器较弱 | 幼虫多水生，能吐丝结网或建携带式巢，腹末有一对带钩足；与鳞翅目近缘 |
| 鳞翅目 Lepidoptera | 翅被鳞，多数成虫具虹吸式喙 | 毛虫有胸足和带趾钩的腹足，下唇腺吐丝；蛹多为被蛹，蝶蛾的生活史见上文 |
| 长翅目 Mecoptera | 头部向下延长成喙状，咀嚼式口器，两对窄膜翅 | 蝎蛉雄性腹末上翘似蝎尾但无毒针；幼虫多似毛虫而具复眼原基 |
| 蚤目 Siphonaptera | 成虫无翅、侧扁，后足跳跃，刺吸式口器，体表刺梳向后 | 幼虫无足而自由生活，以有机碎屑为食；成虫寄生鸟兽。系统研究常把蚤置于长翅类近缘内部，但仍以蚤目保留其清楚形态 |
| 双翅目 Diptera | 仅前翅飞行，后翅成平衡棒；口器可刺吸、舐吸或切舐 | 幼虫多无足；蚊类幼虫头壳发达，蝇类蛆状幼虫头部和附肢高度退化；蛹为离蛹或被末龄幼虫皮包成围蛹 |

蚊科的卵、幼虫和成虫姿态是传统检疫鉴别的重要入口，但应先定到属群再讨论传播能力。库蚊卵常黏成漂浮卵筏，幼虫以呼吸管斜悬水面；伊蚊卵多单产在可能被水淹的湿润基质，幼虫也有呼吸管；按蚊卵单产水面且两侧常有浮器，幼虫无呼吸管而与水面近乎平行，成虫静止时腹部常与停落面成角度。按蚊可传播疟原虫，若干库蚊传播日本脑炎或西尼罗病毒，若干伊蚊传播登革、黄热、寨卡或基孔肯雅病毒；这些是特定媒介种与病原的关系，不能由“库蚊／伊蚊／按蚊”外形直接推定一只个体携带何种病原。[^mosquito-identification]

## 传统形态与现代昆虫树 {#traditional-modern-system}

旧教材把无翅昆虫排在“低等”、有翅昆虫排在“高等”，再把不全变态目线性接到完全变态目。现代亲缘树显示，原始无翅、继发失翅、翅不能折叠和翅可折叠是不同历史；跳蚤、虱、工蚁和寄生性雌捻翅虫的无翅状态各自从有翅祖先演化而来。变态方式也不是从“无变化”按强弱排成一条等级，而是胚胎程序、翅原基位置和激素响应在不同支系中的重组。

形态学仍然决定一枚标本能否被可靠识别。口针由哪些构件组成、跗节有几节、前后翅怎样相接、尾须和产卵器位于哪些腹节、幼虫有无胸足与趾钩，都是分子序列无法替代的现场证据。现代系统的价值在于把这些性状放回共同历史：旧等翅目成为蜚蠊目内的白蚁支系，旧虱目进入啮虫目，旧同翅目拆回半翅目内部，蝶与蛾则在同一鳞翅目树上理解。名称改变之后，原有的外形、解剖和生活史观察仍完整保留，并获得更准确的比较边界。
