# 脊索动物与脊椎动物多样性

脊索动物把文昌鱼、海鞘、盲鳗、鲨、鲤、蛙、龟、鸟和哺乳动物连接在同一条演化主线上。它们的成体外形可以相差极大，共同性状却会在胚胎或生活史的某个阶段出现：身体背侧形成脊索和中空神经管，咽部具有裂隙或与之同源的胚胎结构，消化道之后保留一段尾部。脊椎动物在这套体制上进一步形成头颅、分区脑、成对感觉器官、神经嵴与外胚层感觉板，并把内骨骼、循环、排泄和运动系统组织成高度整合的身体。

传统动物学按尾索动物、头索动物、圆口类、鱼类、两栖类、爬行类、鸟类和哺乳类依次展开，积累了大量外形、解剖、胚胎、生活史和标本鉴别知识。这条学习路径在本站完整保留，但不再被解释为现生动物从“低等”向“高等”排成的阶梯。现代系统树说明，海鞘在亲缘上比文昌鱼更接近脊椎动物，盲鳗不是脊椎动物形成前的残余类型，四足动物属于肉鳍鱼支系，鸟类也处在爬行动物的系统范围之内。分子、发育和化石证据用于解释这些关系、纠正具体旧说，而不是替代可以实际观察的形态结构。

## 脊索动物的共同体制 { #chordate-body-plan }

### 脊索、神经管与轴向运动

脊索是一条位于消化管背侧、神经管腹侧的纵向支持结构。脊索细胞常具有液泡，外面包围纤维性脊索鞘；内部膨压使脊索抗压，脊索鞘则限制横向膨胀，两者共同形成可弯而不易缩短的轴。分节排列的轴向肌在脊索两侧交替收缩时，身体能够产生向后传递的弯曲波。文昌鱼的脊索纵贯全身并终生保留，海鞘幼体的脊索局限于尾部，许多脊椎动物的脊索在胚胎期参与身体轴和周围组织的模式形成，随后被椎体包围或大部取代。

脊索、椎骨和头骨具有不同的发生来源。脊椎动物的椎体主要来自体节的生骨节细胞，它们围绕脊索和神经管迁移、凝聚并形成软骨或骨；脊索可在椎间区域、椎体中央或椎间盘髓核中留下不同程度的残余，头骨则由神经嵴和头部中胚层等多种细胞来源共同形成。圆口类、软骨鱼、硬骨鱼和四足动物的椎体构造并不相同，后续比较解剖会沿脊索—椎体—椎弓的连接关系逐项展开。

背侧中空神经管由胚体背侧神经板卷合形成，内腔在脊椎动物脑中成为脑室，在脊髓中成为中央管。文昌鱼的神经管前端只有有限的膨大和区域化；脊椎动物前端形成分区脑，后部形成脊髓，并与感觉神经节、自主神经节和周围神经相连。脊索动物还有明显的轴向分节：文昌鱼和脊椎动物的肌节是最直观的表现，脊椎动物的椎骨、肋骨、脊神经和部分血管排列也受体节发生影响。环节动物与节肢动物另有各自的分节历史，三者需要通过发生位置、基因调控和系统关系判断可比较层次。

### 咽部水流、内柱与甲状腺

咽裂是咽内胚层向外伸展并与外侧结构相接形成的成对开口。文昌鱼和多数被囊动物以大量咽裂让水穿过咽壁，纤毛与黏液共同完成滤食，气体交换只是水流通过薄壁结构时同时发生的过程。圆口类和鱼类把咽裂区域组织为鳃囊或鳃弓—鳃丝系统，水流、支撑和血流之间形成更紧密的交换界面。陆生四足动物胚胎仍形成咽囊、咽沟和咽弓，它们随后参与中耳、扁桃体、胸腺、甲状旁腺、喉部骨骼及头颈血管等结构的发生，并不会在胚胎中短暂长出能够呼吸的“鱼鳃”。

文昌鱼和被囊动物咽腹侧的内柱分泌黏液，并把捕获的食物颗粒送向消化道。内柱中部分细胞能富集碘并合成含碘化合物，其发生和分子特征支持它与脊椎动物甲状腺同源；七鳃鳗幼体变态时，滤食用内柱会重组为甲状腺滤泡。这个连续变化把一个咽部摄食结构同后来的内分泌器官联系起来，也提醒我们，同源结构可以在功能和外形上发生很大改变。

肛后尾指消化道末端之后仍有由脊索、神经管和肌肉支撑的身体区段。它为文昌鱼、海鞘幼体和多数脊椎动物提供主要推进面，在人和许多无外露尾的成体中则于胚胎期缩短或转化。腹侧搏动性血管或心脏、闭合程度不同的循环通路以及后口发育等性状也常见于脊索动物，但分布范围超出脊索动物。确定脊索动物身份需要综合一组发生位置和结构关系。

## 无脊椎脊索动物保留的比较线索 { #invertebrate-chordates }

头索动物以文昌鱼为代表，成体终生保留纵贯身体的脊索、背神经管、肌节、咽裂、内柱和肛后尾。它们在浅海沙质底中以身体前端露出，纤毛水流依次经过口笠、咽裂、围鳃腔和腹孔；肌节与脊索又支持短距离游泳和钻沙。文昌鱼缺少真正的头颅、神经嵴和典型脊椎动物感觉板，其肝盲囊、排泄肾管和前端神经区只能在限定层次上同脊椎动物结构比较，不能逐项直接命名为肝、肾或脑的缩小版。

被囊动物包括海鞘、樽海鞘和尾海鞘等差异显著的支系。海鞘蝌蚪状幼体具有尾部脊索、背神经管、肌肉和感觉泡，附着变态后吸收尾部，成体以巨大的咽笼滤食；樽海鞘类在水体中漂浮，常有复杂的出芽与有性世代；尾海鞘成体终生保留尾部，以分泌的透明住室过滤颗粒。被囊中的纤维素成分（旧称被囊素 tunicin）、可反转泵血方向的管状心脏、围鳃腔和群体出芽都要结合具体类群描述，固着海鞘只是其中一种生活型。

文昌鱼的成体体制看起来更接近脊椎动物，因此传统教材曾把头索动物放在脊椎动物最近邻的位置。核基因和基因组研究稳定支持另一种关系：头索动物较早分出，被囊动物与脊椎动物共同组成嗅球类（Olfactores）。[^chordate-phylogeny] 亲缘较近不要求成体更相似；被囊动物的快速序列演化、幼体缩短和成体滤食专门化产生了大量派生性状，文昌鱼则保留了较完整的轴向体制。比较二者能够把“接近共同祖先的性状”和“最近的现生亲属”分开。

## 脊椎动物身体的整合 { #vertebrate-body-plan }

### 头颅、感觉器官与神经嵴

脊椎动物的突出变化首先集中在头部。神经管前端扩展并分区，软骨或骨性的脑颅包围脑与嗅囊、眼和内耳，咽弓骨骼和肌肉组织口、咽与鳃的运动。头部外胚层形成嗅、晶状体、耳、侧线和若干脑神经感觉板；神经嵴细胞从神经板边界离开，迁移到身体不同区域，形成大量周围神经与胶质细胞、色素细胞、肾上腺髓质，并参与颅面软骨、骨、牙本质和咽弓结缔组织的形成。

“新头假说”把神经嵴和感觉板的扩展同主动定向、感觉整合及取食方式联系起来，是解释脊椎动物起源的重要框架。[^new-head] 现代发育比较显示，文昌鱼和被囊动物已经具有神经板边界、感觉细胞与迁移细胞的部分调控元件，脊椎动物创新更像是旧细胞类型、基因网络和组织相互作用的重新组合与扩展，而非突然出现一套毫无前身的器官。神经嵴也不是“第四胚层”的字面替代物；它源自外胚层，却能产生通常由中胚层承担的多种头部间充质衍生物。

### 轴向骨骼、附肢与内脏系统

头颅之后，椎弓和椎体在不同支系中逐步加强对神经管、脊索和躯干的支持。盲鳗没有典型椎体，七鳃鳗只具小型软骨性弧片，许多早期无颌脊椎动物却已有矿化真皮甲和复杂头部感觉系统。因此，“脊椎动物”不能按成体是否具有一串完整椎骨机械判定；有头类（Craniata）强调头颅及相关组织，在现生类群中与广义脊椎动物的范围基本重合。2024 年盲鳗基因组进一步支持盲鳗与七鳃鳗组成圆口类，并显示盲鳗许多看似简单的形态来自支系内的次生丢失或改造。[^hagfish-genome]

有颌脊椎动物形成可开合的颌、成对鼻囊、三对半规管和通常成对的胸鳍／腹鳍或前肢／后肢。颌与前部咽弓有深刻发生联系，但不能把任何一根现代鳃弓直接弯折成一副现成颌骨；颌弓、舌弓和后续鳃弓在共同祖先中已经历分区、关节、肌肉和神经控制的整体重组。成对附肢同样先经历体壁侧方结构、鳍褶和鳍骨的演化，再在肉鳍鱼支系中形成具有单一近端长骨、两个远端长骨和末端骨列的四足型附肢。

脊椎动物的肌性心脏、鳃或肺交换面、肝门与肾门通路、由肾单位组成的肾脏以及分区消化道共同维持较大而活跃的身体。神经嵴、感觉板、咽弓、体节和侧板中胚层把这些系统的发生连接起来，因而同一块骨、血管或神经必须同时从位置、胚层来源和邻接关系判断。早期比较基因组常把脊椎动物基因组概括为共同祖先中的两轮全基因组复制；盲鳗与七鳃鳗的染色体尺度分析现支持所有脊椎动物共享第一次复制，此后有颌类和圆口类各自发生后续多倍化。复制扩大了许多发育调控基因家族，随后大量副本丢失、分工或获得新调控；它为形态创新提供了材料，却不是复杂头部和器官自动产生的单一原因。[^vertebrate-genome]

## 现生支系是一组嵌套关系 { #vertebrate-tree }

下面的层级只画出现生主干，化石类群会分布在各节点的茎干和冠群之中。缩进表示共同祖先范围逐层收窄，并不表示上方类群“进化成”下方现生类群。

- **脊索动物 Chordata**
    - **头索动物 Cephalochordata**：文昌鱼等。
    - **嗅球类 Olfactores**
        - **被囊动物 Tunicata**：海鞘、樽海鞘、尾海鞘等。
        - **脊椎动物 Vertebrata**
            - **圆口类 Cyclostomata**：盲鳗与七鳃鳗。
            - **有颌类 Gnathostomata**
                - **软骨鱼类 Chondrichthyes**：全头类、鲨与鳐。
                - **硬骨脊椎动物 Osteichthyes**
                    - **辐鳍鱼类 Actinopterygii**：多鳍鱼、鲟形类、全骨鱼与真骨鱼等。
                    - **肉鳍鱼类 Sarcopterygii**：腔棘鱼、肺鱼及四足动物；现生肺鱼是四足动物最近的鱼形亲属。
                        - **四足动物 Tetrapoda**
                            - **现生两栖类 Lissamphibia**：蚓螈、有尾类与无尾类。
                            - **羊膜动物 Amniota**
                                - **合弓类 Synapsida**：哺乳动物及其灭绝近亲。
                                - **蜥形类 Sauropsida**：龟鳖、喙头与有鳞类、鳄类、鸟类及其灭绝近亲；鸟类位于兽脚类恐龙之内。

这棵树改变了若干习惯表达。“鱼类”若只指圆口、软骨鱼和水生硬骨鱼，就排除了由肉鳍鱼祖先产生的四足动物；“爬行类”若排除鸟类，就遗漏了主龙类内部的一支；把海鞘称为最原始脊索动物、把文昌鱼写成脊椎动物的直接祖先，也都把现生旁支误放进祖先位置。类群名称仍然可以服务野外识别和比较解剖，系统树负责标明这些名称的边界。

## 传统类群名称的教学接口 { #traditional-groups }

| 传统名称 | 应保留的形态与解剖内容 | 系统关系中的使用边界 |
| --- | --- | --- |
| 原索动物 | 文昌鱼、海鞘等无脊椎脊索动物的脊索、神经管、咽滤食、肌节、幼体与变态 | 头索动物和被囊动物并不组成排除脊椎动物的自然支系；名称只作传统集合入口 |
| 无颌类 | 口漏斗、角质齿、鳃囊、脊索、软骨性弧片、沙隐虫幼体及盲鳗特殊形态 | 现生盲鳗和七鳃鳗组成圆口类；灭绝甲胄鱼等分布在更广的脊椎动物茎干，不能全部并入现生圆口类 |
| 鱼类 | 鳍、鳃、鳞、侧线、鳔、渗透调节、洄游及软骨鱼／硬骨鱼的解剖比较 | 是有用的生态—形态集合；若排除四足动物，广义“鱼类”不是单系类群 |
| 两栖类 | 裸露而具腺的皮肤、幼体鳃与成体肺／皮肤交换、变态、五趾附肢和多样生殖 | 现生两栖类通常作为单系支系；旧“古两栖类”包含多个茎四足动物，不能视为现代两栖纲的同一范围 |
| 爬行类 | 羊膜卵、角质表皮、胸廓通气、颞孔、泄殖腔以及龟、喙头、鳞龙和鳄类鉴别 | 排除鸟类的传统爬行类为并系集合；广义蜥形类／爬行动物系统范围包含鸟类 |
| 鸟类 | 羽毛、翼、肺—气囊、叉骨、综合荐骨、卵与育雏、飞行和迁徙 | 是现生单系支系，同时属于兽脚类恐龙和主龙类；这一位置不削弱鸟类自身的形态诊断 |
| 哺乳类 | 毛、乳腺、三块听小骨、单一齿骨下颌、膈、异型齿、单孔／有袋／胎盘类生殖 | 是合弓类中存活至今的一支；“似哺乳爬行动物”宜在历史语境中使用，相关化石属于非哺乳合弓类 |

这些边界不是要求抛弃旧术语。解剖一条鲫鱼时，鳍式、鳞式、鳃弓、韦伯氏器、鳔和肾脏仍需按鱼类形态逐项观察；鉴别龟、蜥、蛇和鳄时，颞孔、方骨、甲板、泄殖孔与交接器仍是有效性状。系统发育所做的是说明这些性状在何种共同祖先上形成、在哪些支系发生改变，而不是用一张分子树替代标本。

## 化石记录中的性状组合 { #vertebrate-fossils }

寒武纪的皮卡虫、海口鱼、昆明鱼和海口虫等化石保存了不同组合的轴向结构、肌节、鳃区、头部和鳍褶。压扁、软组织保存方式和同源判断使某些结构仍有争议，因此这些属不能简单排成文昌鱼—海鞘—圆口类的直接祖先序列。它们的价值在于显示，脊索动物和早期有头类的性状曾以现生动物中看不到的方式组合，脊索、肌节、明确头区和感觉结构也不是在同一瞬间成套出现。

无颌脊椎动物在奥陶纪至泥盆纪形成多种骨甲和摄食方式。矿化组织最初广泛出现在体表、口咽和感觉相关结构，早于完整的有颌内骨骼；有颌类出现后，盾皮鱼、棘鱼样类群、软骨鱼与硬骨鱼的早期成员共同展示了颌、牙、成对附肢和骨组织的镶嵌演化。现代软骨鱼不是因“没有进化出骨”而停留在有颌类起点：它们有钙化软骨、盾鳞、牙和鳍棘，却在支系历史中缺少硬骨脊椎动物式软骨内成骨。象鲨基因组及化石比较帮助区分了真皮矿化、软骨钙化与软骨内成骨三类过程。[^gnathostome-evolution]

泥盆纪肉鳍鱼和早期四足形类把内鼻孔、肺或鳔、叶状偶鳍、颈部活动和承重附肢等性状以不同组合呈现。早期具有指趾的动物仍可高度水生，出现四肢并不等于一步完成陆生。羊膜、绒毛膜和尿囊把胚胎周围的水盐、气体交换和废物储存组织在卵膜系统中，使羊膜动物的繁殖不再依赖水中自由幼体；此后合弓类和蜥形类分别展开，哺乳动物从犬齿兽类等合弓支系产生，鸟类则从具羽毛的兽脚类恐龙中产生。化石记录提供的是连续分支和性状镶嵌，而不是鱼、两栖、爬行、鸟、哺乳五级阶梯。

## 比较形态与解剖的观察顺序 { #comparative-anatomy }

类群学习首先要把一只完整动物还原出来。外形观察记录身体轴、头躯尾分区、口鼻鳃孔、鳍或肢、泄殖孔和体表衍生物；解剖再依次确认皮肤与肌肉连接、骨骼关节、体腔与系膜、消化管和腺体、呼吸面与通气路线、心脏和主要血管、肾与生殖管、脑神经和感觉器官。器官的位置和连接关系往往比“有或无”更能鉴别类群，也能防止把不同来源但功能相似的结构误判为同源。

纵向比较时需要同时保留四个坐标。发生坐标追踪神经嵴、咽弓、体节、侧板和胚外膜的来源；拓扑坐标确认结构相对神经管、脊索、消化道和体腔的位置；功能坐标解释鳃盖泵、胸廓、气囊、膈或皮肤怎样维持交换；系统坐标判断共同性状来自共同祖先、平行改造还是趋同。鲨的盾鳞与牙、鱼鳔与四足动物肺、舌颌骨与耳柱骨／镫骨、麦氏软骨与哺乳动物锤骨的比较，都必须沿这些坐标逐层建立，不能只凭名称相似或功能相同下结论。

[脊椎动物比较形态与解剖](../comparative_anatomy/)会把胚胎、皮肤、骨骼、肌肉、消化、呼吸、排泄、生殖、循环、神经、感觉和内分泌分别纵向展开；本页面组的类群专题则把同一动物的各系统重新合在一起。前者回答一种结构在不同支系中怎样变化，后者回答这些结构如何共同支持某一生活方式。两种读法需要往返使用，现代细胞谱系和分子证据也应落回能够定位的组织与器官，而不能悬在解剖事实之外。

## 页面组的阅读路线 { #reading-route }

[脊索动物起源与无脊椎脊索动物](chordates.md)详细展开海鞘成体与幼体、逆行变态、文昌鱼外形和内部解剖、胚胎发生、被囊动物三大生活型及寒武纪化石。这里会保留内柱、围鳃腔、肝盲囊、原肾管、神经管和肌节等传统观察，同时区分功能类比、发生同源和系统位置。

[圆口类与有颌脊椎动物起源](cyclostomes_gnathostomes.md)从盲鳗和七鳃鳗的口器、鳃囊、软骨支架、感觉、排泄、生殖和幼体进入脊椎动物头部，再比较颌、牙、成对附肢与矿化组织的出现。盲鳗和七鳃鳗会分别描述，圆口类单系证据只补充解释两者共有与次生简化，不会抹平其生活史差异。

[软骨鱼类](cartilaginous_fishes.md)以鲨、鳐和银鲛比较盾鳞、软骨脑颅、颌悬挂、鳃间隔、螺旋瓣肠、尿素渗透调节、鳍脚和体内受精；[硬骨鱼类](bony_fishes.md)则沿辐鳍与肉鳍、鳞和鳍式、鳃盖、鳔、渗透调节、感觉、洄游和主要传统类群展开。两页会保留鱼类标本鉴别和内部解剖的细节，再以现代支系关系校准旧“总目—亚纲”边界。

[两栖类](amphibians.md)把蚓螈、有尾类和无尾类放在皮肤、呼吸、循环、骨骼、泌尿生殖、感觉和变态的完整生活史中；[爬行类与羊膜动物演化](reptiles_amniotes.md)从羊膜卵、角质表皮、胸廓和颞区进入龟鳖、喙头、有鳞和鳄类，并解释传统爬行纲同鸟类的嵌套关系。由水到陆不是单向增加“高级器官”，而是交换面、水盐平衡、承重、感觉与繁殖在不同环境中的协同改变。

[鸟类](birds.md)保留羽毛、骨骼、翼、肺—气囊、循环、消化、繁殖、巢与雏鸟类型、迁徙及传统目级鉴别，并以恐龙化石和现生鸟系统补充；[哺乳类](mammals.md)保留皮肤腺、毛、角、牙、颌与听小骨、膈、消化、生殖和单孔／有袋／胎盘类及传统目级特征，再按合弓类历史和现代支系重新核定范围。飞行、恒温、胎生或复杂行为都在多个支系中有不同前史，不能作为整类动物“更高等”的证据。
