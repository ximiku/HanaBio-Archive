# 圆口类与有颌脊椎动物起源

盲鳗和七鳃鳗是仅存的无颌脊椎动物。它们没有由上、下颌组成的咬合器，也没有胸鳍和腹鳍，却已经具有头颅、分区脑、成对感觉器官、神经嵴衍生组织、肌性心脏和脊椎动物式肾脏。传统动物学把二者合称圆口纲，依次观察口器、鳃囊、软骨支架、感觉、排泄、生殖与幼体；这些细节既能辨认两条现生支系，也能显示“无颌”之下并不是一个尚未分化的简单阶段。

有颌脊椎动物并非由某一种现生七鳃鳗继续进化而来。圆口类与有颌类从共同祖先分开后，各自经历了数亿年演化；古生代还有许多披覆骨甲、具有矿化组织而仍然无颌的脊椎动物，它们更接近有颌类干群。学习顺序因此从现生圆口类的完整身体出发，再把颌、牙、成对附肢和骨组织分别放回化石与发育证据中，避免把所有创新压缩成“一对鳃弓变成了颌”。

## 圆口类的共同体制 { #cyclostome-body-plan }

### 无颌头部与轴向运动

圆口类（Cyclostomata）包括盲鳗类和七鳃鳗类。两者身体细长、皮肤裸露而富黏液，终生保留粗大的脊索，没有真正的上、下颌和成对附肢。口周或口内具有角质齿，但角质齿由角蛋白样材料构成并周期更换，不含有颌脊椎动物牙齿的牙本质、牙髓和釉质或釉质样组织。所谓“圆口”概括的是口部形态，七鳃鳗有明显圆形口吸盘，盲鳗则是端位裂口和触须，并不都长成同一种圆盘。

脊索纵贯躯干，分节肌在两侧排列为向前开口的 W 形肌节，肌隔把相邻肌节分开。七鳃鳗脊索背外侧有成对小型软骨弧片，传统称髓弓或神经弧；盲鳗也在尾端神经管附近发现椎骨样软骨。它们都没有有颌鱼类那种由椎体、神经弓和脉弓组成的连续脊柱，脊索仍是主要承力轴。“有头类”曾被用来把有头颅而缺少典型椎骨的盲鳗纳入、同时把它与“脊椎动物”区分；在现生系统关系中盲鳗处在脊椎动物内部，椎骨样结构和发育资料也使这一术语边界不再等同于两个现生自然类群。

软骨性头颅包围脑、嗅囊和内耳，咽区有支撑鳃囊的软骨。七鳃鳗脑颅并非一枚封闭软骨盒，嗅囊、眼眶和耳囊周围软骨以梁、板相连，背侧缺少有颌鱼那样的完整软骨顶和真皮膜骨颅顶。圆口类没有颌弓形成的上、下颌，鼻与垂体发生区在头中线形成单一鼻—垂体复合体；有颌类则在发育中把鼻区与垂体入口分开，并形成成对鼻囊。圆口类的软骨细胞和细胞外基质具有自身特化，不能简单称为“尚未来得及骨化”的普通鱼软骨。

### 囊鳃、循环与免疫

咽部两侧形成袋状鳃囊，内壁长有内胚层来源的鳃丝。七鳃鳗通常有七对鳃囊，每个鳃囊经内鳃孔通向呼吸管，并由独立外鳃孔开向体表；盲鳗的鳃囊数目随属种变化，出鳃管可各自开口，也可汇入总鳃管后由较少外孔排出。鳃囊和外鳃孔是囊鳃型结构的观察核心，“七鳃”只适用于七鳃鳗稳定的七对外孔，不能反推所有圆口类都有七对鳃。

圆口类有静脉窦、单一心房、肌性心室和流出道组成的主心脏，血液含有核红细胞。七鳃鳗由腹主动脉把血送往鳃囊毛细血管，再经背主动脉输送到全身；盲鳗除主心脏外还有门静脉心、主静脉心和尾心等辅助泵，配合低压循环与大血窦。局部结构不能按有颌鱼类的血管名称机械一一套用，但鳃循环与体循环已形成明确的串联关系。

两类圆口动物都具有适应性免疫，却没有有颌类以免疫球蛋白和 T 细胞受体为核心的同一套受体。它们以可变淋巴细胞受体（VLR）在淋巴细胞样谱系中形成多样性，说明获得性识别早在圆口类与有颌类分开后沿两条支系建立了不同分子装置。这个差异不能据此称圆口类“没有免疫”，也不改变皮肤黏液、吞噬细胞和补体样成分等先天防御的重要性。

## 七鳃鳗的形态与内部结构 { #lamprey-anatomy }

### 外形、皮肤与鳍

东北七鳃鳗是传统教学常用代表，以下结构也以七鳃鳗共同体制为主，再注明种间差异。身体分头、躯干和尾，外形似鳗而不属于鳗鲡类。表皮多层，含大量黏液细胞和棒状细胞；薄鳞缺失，真皮以胶原纤维为主，色素细胞分布于表皮—真皮交界及更深层。黏液降低摩擦并保护皮肤，体表又是水盐和气体交换界面，不能只把“无鳞”理解为少了一件被覆物。

头部两侧有一对眼，头顶中线只有一个外鼻孔，鼻孔后方可从外表辨认松果区。每侧眼后依次排列七个圆形外鳃孔。头、躯交界没有胸鳍，腹面也没有腹鳍；背侧常有一枚或两枚背鳍，背鳍连续过渡到围绕尾端的尾鳍褶，鳍内只有辐鳍软骨等支条，没有肩带、腰带和成对附肢骨。不同属种的背鳍是否相连、成体体长和体色不同，产卵期雌性还可出现臀鳍样皮褶，不能把两背鳍和“雌性臀鳍”当作全部七鳃鳗恒定性状。

肛门后方另有泌尿生殖乳突，尿和配子经泌尿生殖窦及其开口排出。这里没有把消化、排尿和生殖三条通路合并成一枚典型泄殖腔；标本观察应区分肛门与泌尿生殖孔。体侧和头部有侧线感受器，活体可感受水流、振动和近场运动。

### 口漏斗、舌和消化道 { #lamprey-feeding }

成体七鳃鳗口部形成圆形或椭圆形口漏斗，漏斗缘有乳突，内壁和舌面排列角质齿。齿的形状、齿板位置和排列是七鳃鳗分类的重要性状。活的角质细胞在基部不断产生新齿，旧齿磨损后被替换；它们在功能上切割或刮削，却不是有颌类牙齿缩小后的遗留物。

舌由软骨和纵、环向肌构成，可像活塞一样前后运动。寄生摄食种先以口盘吸附宿主鱼，舌齿反复锉开表皮，口腔腺分泌物抑制凝血并帮助体液持续流入；“防凝血腺”是对这些口腔腺功能的旧称，并非独立悬置在体腔中的腺体。吸附也用于固定在石块、搬动筑巢材料或抵抗水流，所以看见口盘不能直接判断一只七鳃鳗正在寄生。

口后咽部在成体分成背侧食道和腹侧呼吸管。食物进入食道时，呼吸管前端缘膜关闭，减少血液或组织碎片进入鳃囊。消化道没有分化明显的胃，短食道接肠，肠黏膜形成纵向或螺旋状的内褶（typhlosole），增加吸收面积。肝脏存在，胰腺细胞散布在肠壁和邻近组织；海七鳃鳗等在变态期间胆管和胆囊系统会显著退化，具体保留程度需按种类和阶段描述。

七鳃鳗并非全部在成体取食宿主。海七鳃鳗、日本七鳃鳗等有寄生摄食阶段，吸食鱼体液和组织；许多溪流型种在变态后消化道萎缩，不再摄食，只依靠幼体积累的能量成熟和繁殖。传统“寄生或半寄生”抓住了部分常见种的生态，却遗漏了大量非寄生七鳃鳗。

### 鳃囊与潮汐式通气 { #lamprey-respiration }

口腔之后的咽腹侧形成盲端呼吸管，每侧七个内鳃孔分别进入七个球形或椭球形鳃囊。鳃囊内侧有许多鳃褶，褶上密布毛细血管，外侧各经一条短管通到外鳃孔。支撑结构不是有颌鱼那种位于鳃裂之间、分节清楚的内鳃弓，而是一套包在鳃囊外侧的软骨鳃篮；横向和纵向软骨条相连，并在腹侧邻近心脏处形成围心软骨支架。东北七鳃鳗教学图常把鳃篮辨作九组成对横软骨与四组成对纵软骨，实际计数受属种和连接软骨分段方式影响，标本鉴定应以具体图谱为准。

自由游泳而口部开放时，水可由口进入呼吸管，经鳃囊从外鳃孔排出。七鳃鳗吸附在宿主或石块上时，口被封住，鳃囊肌肉使水从外鳃孔吸入又由同一批外孔排出，形成潮汐式通气。独立鳃孔因此让动物在持续吸附和摄食时仍能换气；“口进、鳃孔出”和“鳃孔进、鳃孔出”是两种情境下的水路，不是彼此冲突的教材答案。

### 心脏、血管与水盐平衡

主心脏位于最后鳃囊后方的软骨围心结构内。静脉窦收集回流血，血依次进入心房、心室和流出道，再由腹主动脉送往入鳃动脉。鳃褶毛细血管完成交换，血液经出鳃血管汇入背主动脉。圆形或椭圆形红细胞有细胞核，血红蛋白承担主要氧运输；传统用“圆形有核红血球”鉴别标本是有效观察，但红细胞形态也会随发育阶段改变。

淡水生活期不断获得水并丢失盐，肾脏排出大量稀尿，鳃和皮肤的离子细胞主动吸收盐；洄游海生种进入海水后则减少尿量并改变鳃、肾离子运输。七鳃鳗没有软骨鱼依赖高尿素维持近等渗的同一策略。循环和渗透调节应随幼体淡水、海洋摄食和成体溯河三个阶段一起理解。

### 脑、脑神经与感觉器官 { #lamprey-senses }

神经管前端分化为端脑、间脑、中脑、小脑和延髓等区域，整体较直，脑弯曲不如多数有颌脊椎动物显著。端脑与巨大的嗅觉输入相连，中脑参与视觉和多感觉整合，小脑样结构较窄，延髓控制呼吸和运动。传统常按十对脑神经描述七鳃鳗，背根和腹根在离开脊髓后不合并成有颌类典型混合脊神经，背根附近具有感觉神经节。具体脑神经的同源、分支和编号仍要按发生与靶器官判断，不能只因数目相同就认定结构完全一致；视神经存在中线交叉投射，旧教材所谓“无视交叉”不能按字面理解为两眼信息从不跨越中线。

单一外鼻孔通入嗅囊，嗅囊后方的鼻—垂体管终于盲囊，不与咽腔相通。成体眼有角膜、晶状体、视网膜和眼外肌，能够成像；沙隐幼体眼被皮肤覆盖并在变态时显著发育。七鳃鳗内耳以两个主要垂直半规管为典型，另有对水平运动敏感的结构或小导管，其同源解释比简单的“完全没有水平半规管”更复杂。头顶部松果体与副松果体形成感光复合体，能感受明暗和昼夜信号，却不形成与侧眼相同的图像。

侧线感受器沿头和躯干分布，在不同种类可形成浅沟或成行感丘。部分七鳃鳗还有电感受壶腹器官。嗅觉、侧线、视觉和松果感光共同参与宿主定位、洄游、昼夜活动与产卵场选择；不能把端脑概括为只服务嗅觉，也不能把中脑称为全脑唯一“高级中枢”。

### 肾脏、性腺与排出生殖通道

七鳃鳗胚胎和幼体先建立前部肾单位，成长过程中后方肾单位不断加入，变态后形成延长的成体后肾型肾脏（常按传统比较解剖称中肾或后位中肾）。一对输尿管只输送尿液，末端汇入泌尿生殖窦。把成体直接写成一枚固定“中肾”便于和鱼类比较，却会遗漏幼体肾退化、成体肾新生以及沿体轴添加肾单位的发生过程。

雌雄异体，通常只有一枚不成对性腺，没有永久生殖导管。成熟精子或卵穿过性腺壁进入体腔，由体腔后部的生殖孔进入泌尿生殖窦，最后经泌尿生殖乳突排出。输尿管不兼作输精或输卵管，这是与许多有颌脊椎动物泌尿生殖通道关系的重要差别。

## 沙隐幼体、变态与繁殖 { #ammocoete-life-cycle }

### 沙隐幼体的滤食体制

七鳃鳗在淡水砂砾巢中体外受精，孵化后形成沙隐幼体（ammocoete）。幼体钻入河床细砂或淤泥，头部露出或以洞穴水流滤食。口不具成体吸盘和角质齿，而有口罩和触手；咽部内柱分泌黏液，纤毛把细菌、藻类和有机颗粒送入消化道。眼小而被皮肤覆盖，背鳍连续，鳃囊和内脏也保持幼体状态。

沙隐幼体的内柱、滤食、弱化眼和钻沙生活曾使它被比作文昌鱼，甚至一度被当作独立动物。二者共享的内柱—甲状腺同源和咽部滤食具有深层比较意义，沙隐幼体同时已经有圆口类的头部发生、鳃囊、肾脏和神经嵴衍生结构。它不是“具囊鳃的文昌鱼”，而是七鳃鳗支系专门化的幼体阶段。

### 变态与生活史分化

沙隐幼体可在河床生活数年，随后经历真正的变态。口罩重建为口吸盘，舌和角质齿形成；眼增大并穿出覆盖皮肤，鳍和色素改变；鳃、肠、肾、血液和感觉系统重组。滤食内柱解体并转化为封闭的甲状腺滤泡，建立成体内分泌器官。甲状腺激素在变态前下降而非像两栖动物那样升高，能量储备、体型、水温和其他内分泌信号共同决定变态启动，不能把过程简化成通用的“甲状腺激素开关”。[^lamprey-life-cycle]

变态后的生活史分成两种主要路线。寄生种的幼鱼进入湖泊或海洋，口吸盘和舌齿用于摄食，经过生长期后停止取食并洄游到淡水产卵；非寄生种不经历外寄生摄食阶段，变态后直接成熟。成熟个体常停止摄食，筑巢、求偶并体外受精，许多种产卵后死亡。海七鳃鳗常见的“多年沙隐幼体—一至两年摄食—一次繁殖”只是其中一型，不宜用同一固定年数套到所有约四十种七鳃鳗。

成体以口盘搬开石块，雄性和雌性用身体摆动清理砾石巢。产卵时一方吸附石块，另一方以口盘附着配偶头部附近并缠绕身体，精卵同步排出。水中受精、无生殖导管、筑巢与变态共同构成完整生活史；若只写“寄生吸血”，会遗漏七鳃鳗一生中持续最久的滤食幼体和最终繁殖阶段。

## 盲鳗的形态与生活方式 { #hagfish-anatomy }

### 外形、感官与支架

盲鳗全部海生，多栖于陆架到深海的海底。身体细长，无成对鳍和明显背鳍，尾端只有低矮鳍褶。头端有一枚外鼻孔，鼻孔周围和口缘排列数对触须；眼缩小并埋在皮下，不具七鳃鳗式发达晶状体和眼外肌。部分种仍能区分明暗，嗅觉、触觉和化学感觉则承担主要定向作用。体侧没有七鳃鳗那样完整的侧线系统。

鼻管经鼻—垂体通道与咽相通，水可由鼻孔进入咽部，这一点与七鳃鳗鼻囊盲端不同。咽部鳃囊通常为五至十六对，种间差异很大。黏盲鳗属（*Eptatretus*）常保留多对独立外鳃孔；盲鳗属（*Myxine*）的出鳃管汇合，体表每侧只见一个共同鳃孔。外孔数因而不等于鳃囊数，也是区分属种时必须解剖或追踪管道的例子。

脊索终生发达，软骨性头颅和舌器支撑头部，却没有七鳃鳗式完整鳃篮。躯干肌按肌节排列，松弛的皮肤只在背中线等少数位置紧密连接身体，皮下有很大的血窦。尾端神经管附近的软骨小体具有椎骨样位置和发生特征，但不足以形成连续承重脊柱。盲鳗的软骨、眼和鳃篮简化不是判定它位于所有其他脊椎动物之外的理由。

### 齿板、取食、黏液与打结 { #hagfish-feeding }

盲鳗没有圆形口吸盘，口内有两列可向外翻出再缩回的角质齿板。舌器向前伸出时，齿板张开钩住组织；缩回时两列齿合拢，把肉拉入口中。盲鳗取食鱼尸和其他大型动物尸体，也捕捉多毛类、甲壳类或穴居鱼等活猎物。钻入尸体内部取食不等于寄生，因为它不长期依附活宿主并从宿主营养维持连续生活史。

身体两侧有成列黏液孔，每个孔连接黏液腺。受到咬击时，腺体释放黏蛋白囊泡和高度卷曲的蛋白丝；海水流动使丝迅速展开，稀薄分泌物扩展为巨大纤维—黏液网络，堵塞袭击者口腔和鳃。野外录像直接记录到鲨和硬骨鱼咬住盲鳗后因鳃被黏液覆盖而放开，说明黏液首先是快速防御结构，而不是普通体表黏液的简单增量。[^hagfish-slime]

盲鳗能把身体打成结，并让结从头向尾或反向滑动。取食时，结抵住基底提供反作用力，使齿板能从尸体或猎物上撕下组织；黏液过多时，滑动的结又能刮去体表黏液，避免自身鳃孔被堵。打结、松弛皮肤、齿板和黏液腺是一套协同的机械系统，远比“无颌所以只能吸食”复杂。

### 消化、呼吸、循环与渗透调节

口后没有明显胃，食道接近直行的肠，肠内有纵褶或褶脊增加表面积。盲鳗摄食间隔可能很长，肝脏、肠和体壁共同储存并处理营养。已有实验显示皮肤和鳃能吸收部分溶解氨基酸，但主要食物仍由齿板获取并经肠道消化，不能据此写成盲鳗“主要靠皮肤吃尸体”。

呼吸水常由鼻孔进入鼻咽管，再流经咽和鳃囊，由独立或汇合的出鳃管排出；口也可参与进水。盲鳗能短时耐受低氧，但自身大量黏液同样可能妨碍水流，因此打结清除黏液有直接呼吸意义。鳃篮简化和缺少七鳃鳗式呼吸管反映不同取食—通气组合，不表示鳃囊本身消失。

主心脏之外的辅助心推动门静脉、主静脉和尾部血液，配合可容纳大量血液的血窦和极低循环压力。盲鳗体液渗透压接近海水，血浆中无机离子浓度也远高于大多数脊椎动物，是脊椎动物中少见的近等渗调节者；肾脏仍调节特定离子和排泄含氮废物。旧材料把肾概括为“前肾”过于简略，成体沿背侧有节段性肾单位与集合通路，前部肾组织、后部肾单位和生殖组织的关系还具有属种差异。

### 神经、生殖与直接发育

盲鳗脑具有与其他脊椎动物可比较的主要区域，嗅叶发达，视顶盖和小脑样区相对缩小；眼的晶状体、眼外肌和若干视觉发育基因发生丢失或弱化，头顶也没有七鳃鳗那样容易辨认的松果感光器。内耳只有一条环形半规管，是区别七鳃鳗两个主要垂直半规管的经典性状。听觉、前庭、嗅觉和触须机械感觉共同适应海底定向，不能用“脑不发达”覆盖具体感觉分工。

盲鳗通常雌雄异体，一枚细长性腺前后区域具有形成卵巢或精巢的潜能；部分个体可同时出现卵巢和精巢组织，但成熟时多表现一种性别。没有永久生殖导管，配子进入体腔后经后部开口排出。卵大、卵黄丰富，外有坚韧卵膜和能彼此勾连的丝状结构。胚胎孵化后已经接近小型成体，不经历七鳃鳗式沙隐幼体与变态。把盲鳗笼统写成“雌雄同体、前卵巢后精巢、择一退化”只代表传统对性腺潜能的概括，不宜当作所有个体固定生活史。

## 盲鳗与七鳃鳗的亲缘和差异 { #cyclostome-phylogeny }

成人形态曾支持另一种排列：盲鳗缺少典型椎骨、侧眼和七鳃鳗式鳃篮，似乎先于“真正脊椎动物”分开，而七鳃鳗与有颌类共享更多特征。核基因、微 RNA、胚胎头部发生和染色体尺度基因组均支持盲鳗与七鳃鳗互为姐妹，共同组成单系圆口类。2024 年盲鳗基因组显示两者共享一段不同于有颌类的基因组复制历史，同时盲鳗支系发生染色体融合以及多种眼、骨重塑相关基因丢失；这把许多“缺少”解释为圆口祖先之后的次生简化。[^cyclostome-genomes]

单系关系不会抹平二者差异。七鳃鳗的口吸盘、鳃篮、独立七对外鳃孔、发达眼、两条主要半规管、侧线和变态生活史彼此协同；盲鳗的触须、齿板、鼻咽通道、可变鳃孔、辅助心、近海水等渗体液、黏液防御和直接发育则组成另一套海底生活体制。共同性状要在两支长期独立演化后识别，差异也不能一律贴上“原始”或“退化”。

圆口类与有颌类共有的脊椎动物头部包括神经嵴、感觉板、脑神经、软骨性脑颅和复杂咽部。盲鳗胚胎研究显示腺垂体来自外胚层，并揭示鼻—垂体区与颅面软骨的圆口类共同发生格局；这纠正了过去以成体位置推断盲鳗腺垂体来自内胚层的说法。[^hagfish-development] 比较的重点因此从“盲鳗缺了多少器官”转向“共同头部发育程序在两支怎样改造”。

## 无颌脊椎动物的化石支系 { #jawless-fossils }

寒武纪海口鱼、昆明鱼和中寒武世 *Metaspriggina* 已经显示头区、眼、肌节、鳃区和鳍褶。*Metaspriggina* 的咽部保存成对鳃条，前方鳃条较粗并呈背腹分段，提示脊椎动物咽骨骼的区域化早于真正可咬合的颌；它的鳃架也不同于现生七鳃鳗包在鳃囊外的专门化鳃篮。[^metaspriggina] 这些化石接近脊椎动物早期干群，却不等于现生盲鳗或七鳃鳗的直接祖先。

奥陶纪至泥盆纪出现大量传统称“甲胄鱼”或“介甲类”的无颌脊椎动物。异甲类、花鳞鱼类、盔甲鱼类、骨甲类等拥有不同组合的头甲、躯干鳞片、感觉管、鼻囊、鳃孔和偶鳍样突起。“甲胄鱼”不是一个同圆口类并列的自然纲；现代形态系统把多数类群依次放在通向有颌类的干群上，彼此形成并系序列。它们比现生圆口类更接近有颌类，却仍没有可开合的上下颌。

这一排列改变了传统“甲胄鱼产生圆口类和鱼类”的树形。现生圆口类较早从脊椎动物主干分出，甲胄型无颌动物在有颌类干群上逐步获得真皮骨、牙本质、成对鳍、复杂内耳和头部感觉结构。许多支系后来灭绝，留下的形态间隙使盲鳗—七鳃鳗—有颌鱼看起来像三级阶梯。化石填入后，硬组织和感觉运动系统呈镶嵌出现，而非等待颌形成后一次性加入。

## 颌与咽弓的重组 { #jaw-origin }

有颌脊椎动物的第一咽弓称下颌弓，背侧主要软骨为腭方软骨，腹侧为麦氏软骨；第二咽弓为舌弓，后方才是一系列鳃弓。三类弓都由咽部神经嵴间充质、上皮、肌肉、血管和脑神经共同组织。鲨和匙吻鲟的命运追踪显示，下颌弓、舌弓和鳃弓的背侧、关节区与腹侧软骨来自相应的 Dlx 基因表达域，支持这些弓骨骼的序列同源。[^jaw-development]

序列同源不表示一根现成鳃弓向前移动、折弯就成了颌。颌的形成还要求第一弓建立背腹身份和关节，肌肉改为闭合与张开咬合器，三叉神经运动和感觉分支重新组织，口周上皮、脑颅与舌弓悬挂关系共同改变。七鳃鳗也有第一咽弓区域和背腹模式基因，但其口器、上唇软骨、舌器和鳃篮沿圆口类路线专门化；不能从成体七鳃鳗鳃篮中挑一对软骨直接指定为未来上下颌。

圆口类单一鼻—垂体复合体位于口前正中，有颌类把成对鼻囊与腺垂体入口分离，并扩展前脑和面部。发育比较提出，这种中线组织关系改变为下颌弓向前组织成可开合口器释放了空间。神经嵴与感觉板在圆口类已经存在，有颌类创新主要是细胞迁移、咽弓模式和组织相互作用的重排与扩展，不是先出现颌才突然产生整个头部。

## 矿化组织与牙齿 { #teeth-and-skeleton }

许多无颌干群脊椎动物在没有颌时已经有厚重头甲、鳞片和牙本质样组织，说明矿化皮骨早于上下颌。真皮骨由真皮内成骨形成，软骨周骨包围内骨骼软骨，软骨内成骨则以软骨模型为基础在内部置换；三种过程的出现和丢失各有历史。现生盲鳗与七鳃鳗缺少骨和牙本质，不能据此把所有无颌祖先都复原为完全无矿化组织的软体动物。

有颌类牙齿由牙本质主体、牙髓腔及表面的釉质或釉质样组织等构成，发生时牙上皮与神经嵴来源间充质相互诱导。圆口类角质齿只在功能上也能切割，材料、细胞来源和更换方式不同。有颌类牙齿与体表齿质小体（odontode）共享发育模块，由“体表齿移入口内”的外向内模型和“咽内齿扩展到口缘”的内向外模型长期争论；化石和发育资料支持口咽不同位置可反复调用共同牙发生网络，难以用一条鳞片直接搬入口中的故事概括。

盾皮鱼是早期有颌脊椎动物的传统集合，颌上可有切割性骨板、牙样小体或真正牙齿。同步辐射成像显示某些盾皮鱼颌缘小体具有牙本质、牙髓腔和按生长序列添加的结构，但其承载骨和更换方式未必与现代鲨、硬骨鱼完全同源。[^early-teeth] 因此，颌、牙和颌缘骨也不是一次出现后从未改变的固定组合。

## 成对附肢与运动控制 { #paired-fins }

圆口类只有背鳍、尾鳍等正中鳍褶，没有胸鳍和腹鳍。古生代无颌干群却展示了从体侧皮褶、硬棘样突起到有内骨骼胸鳍的多种状态。中国志留纪盔甲鱼 *Tujiaaspis* 保存从鳃后延伸到尾部的成对腹外侧连续鳍褶，水动力模型显示这种鳍褶能够产生升力；更接近有颌类的骨甲类在前部形成分离的胸鳍，真正腹鳍则在有颌类干群更晚出现。[^paired-fin-origin]

这些化石支持“侧鳍褶”假说的分区版本：体侧一段具有形成鳍的区域先产生连续褶，前部逐渐集中为胸鳍，后部潜能再局限为腹鳍。发育上，成对鳍由侧板中胚层形成主要内骨骼和结缔组织，外胚层鳍褶及轴向模式基因参与远近端和前后轴组织。它们不是把一对鳃隔或肋骨直接伸出体表所得，也不是和颌在同一瞬间捆绑产生。

胸鳍、腹鳍、颌和成对感觉器官共同提高定向运动、姿态控制和主动取食能力，但其化石出现顺序并不同步。把这些性状拆开观察，才看得见有颌体制是沿干群逐项装配；把它们统称“鱼类进步特征”会失去解剖路径。

## 有颌脊椎动物共同体制的形成 { #gnathostome-body-plan }

有颌脊椎动物（Gnathostomata）的现生冠群由软骨鱼类与硬骨脊椎动物组成。它们共同拥有可关节运动的上、下颌，通常有胸鳍和腹鳍两对附肢、成对鼻囊、三条半规管、髓鞘化更充分的神经系统，以及按共同模式组织的下颌弓—舌弓—鳃弓。具体支系可再次丢失颌骨、牙、鳍或骨，所以诊断要结合共同祖先而不是要求每个成体保留清单全部项目。

基因组复制扩大了 Hox、Dlx、信号通路和受体家族，为头部、咽弓和附肢调控网络提供了更多可分工副本。盲鳗染色体尺度比较表明，脊椎动物干群先经历一次共享复制，圆口类和有颌类分开后又各自经历复杂多倍化；不能再把“共同两轮复制”当作所有脊椎动物完全相同的单一步骤。复制提供遗传材料，组织拓扑、生态选择和大量基因丢失才决定具体形态，颌也不是由一次全基因组复制自动生成。

志留纪和早泥盆世化石显示，传统盾皮鱼和棘鱼样类群分布在有颌类干群及软骨鱼、硬骨鱼两条支系的早段，而不是两个整齐的自然纲。对这些化石的重新分析揭示，现代软骨鱼和硬骨鱼的共同祖先已经具有比“鲨样软骨鱼祖先”更复杂的皮骨与颌缘结构。[^gnathostome-origins] 下一页从[软骨鱼类](cartilaginous_fishes.md)进入第一条现生有颌主支，逐项观察脑颅、颌悬挂、盾鳞、鳃间隔、偶鳍、渗透调节和体内受精；这些特征将作为软骨鱼自身组合，而不会被当作有颌脊椎动物不加改变的起点。
