# 社会组织与群体生活

动物只要在同一地点出现，并不一定已经形成社会。潮水把水母推到岸边、灯光吸引许多飞虫、食物腐败使甲虫聚集，都可以产生高密度个体，却未必需要相互识别或协调。真正的社会组织来自反复的个体关系：成员彼此接近或回避，交换食物与信号，共同移动、防御、取食或育幼，也可能争夺地位、配偶和繁殖机会。群体的边界由谁能够加入、谁会离开、谁同谁保持联系以及哪些动作只在特定身份之间发生共同确定。

社会生活因身体和生活史不同而呈现迥异形态。鱼群靠侧线和视觉维持相邻距离，鸟群用鸣声与飞行姿势同步起落，哺乳动物以气味、面部、声音和长期记忆保持个体关系；蜜蜂、蚂蚁和白蚁的巢内则同时存在繁殖等级、职虫分工、幼体照料、食物交换和巢体建筑。本页沿这些可观察结构展开，保留传统动物行为学对等级、姿势、任务和生活周期的细致记录。亲缘选择、直接与间接适合度、合作稳定性和群居收益模型由[社会生活、合作与利他](../../ecology/behavioral_ecology/social_cooperation.md)继续推导；本页用这些模型校正解释，但不让抽象收益替代动物实际怎样共同生活。

## 聚集、群体与社会单元 { #aggregation-group-society }

**聚集**只要求多个个体在空间上集中，形成原因可以是共同响应温度、湿度、庇护处、食物或繁殖地点。**群体**进一步包含成员间的吸引、同步或稳定联系；鱼群、鸟群、兽群和繁殖群落都属于宽泛群体。**社会单元**则强调成员身份和互动有一定持续性，例如一对亲本及延迟扩散的后代、一个由数只雌象及幼象组成的母系家庭，或一窝由蜂王与工蜂构成的蜂群。相同物种可在一天或一年中跨越这些状态：独自取食的鸟夜间集群栖息，平时分散的蛙在繁殖池聚集，迁徙鱼群到达产卵地后又解散。

描述社会组织至少要记录四件事。第一是**群体组成**，包括各性别、年龄、亲缘和生殖状态；第二是**空间凝聚**，即成员是否同步移动、共享巢穴或重叠活动区；第三是**成员更替**，包括出生、死亡、迁入、迁出和群体分裂；第四是**关系结构**，即哪些个体经常接触、理毛、供食、攻击或结盟。只报告平均群体大小会把这些差异压平。十只临时共同饮水的羚羊，与十只多年共同迁移、由年长雌性维持联系的象，数字相同而组织完全不同。

群体边界也不总固定。**裂变—融合社会**中的大群会按食物、繁殖和风险不断分成小队再汇合，黑猩猩、斑鬣狗、象和部分海豚是常见实例；成员仍可长期识别彼此并保存等级与联盟关系。繁殖群落中的海鸟常各自守住巢旁很小的空间，离巢取食时却不作为同一队行动。群落、群、家族、队、氏族和巢群不是可以互换的文学称呼，而是对空间和关系尺度的不同描述。

## 社会关系、优势等级与扩散 { #relationships-dominance-dispersal }

两只动物的社会关系由多次互动累积形成。频繁亲近、理毛、并卧、互相供食和支持争斗可形成亲和关系；威胁、追逐、避让和优先取得资源则形成优势关系。**优势等级**描述一方在成对冲突中稳定使另一方退让的次序，不等于体形排行榜，也不表示高等级者在所有资源上总能获胜。食物、配偶、休息位和幼体附近的优先次序可以不同，年龄、健康、亲缘联盟和最近胜负还会使等级改变。

线性等级中，甲通常胜乙、乙胜丙，甲也多胜丙；许多群体却有环状、并列或情境依赖关系。研究者需根据有方向的威胁和屈服矩阵判断，不能从谁站在中央、谁先取食一次便指定“首领”。某些个体确能引导移动，却未必是争斗等级最高者；象群中年长雌象保存水源与危险信息，狼群的方向也可由繁殖、饥饿和社会关系共同决定。把每群动物都拟人成一名永久统帅，会遗漏分布式决策。

幼体成熟后留群还是扩散，深刻改变群体亲缘与合作。一个性别常比另一性别更易离开出生群，但模式随类群而异：许多鸟类雌性扩散较远，许多哺乳类雄性扩散较多，也有相反或两性都扩散的系统。留群可继承领域、获得帮手或照料亲属，扩散则能减少近亲繁殖、资源竞争并寻找新繁殖机会。扩散个体穿越陌生地带时面临捕食和没有空缺位置的风险，所谓“延迟独立”因而可能来自可用巢址少，而不是幼体缺乏成熟能力。

## 社会性昆虫的判据与等级 { #social-insect-criteria }

昆虫社会性常按三个可观察特征比较：多个成体合作照料幼体；同巢个体之间出现繁殖分工；亲代和已成年的子代世代重叠，使子代能够帮助抚养后来同胞。三项同时显著出现时称为**真社会性**或**全社会性**（eusociality），典型见于全部蚂蚁、白蚁，以及部分蜂类、胡蜂、蓟马、甲虫和蚜虫。裸鼹鼠等少数脊椎动物也常按繁殖分工、世代重叠与合作育幼称为真社会性，但其“职虫”可塑性和离群繁殖能力仍需单独说明。

只由母亲延长护卵或供食形成的母—子联系称为**亚社会性**路线；同代雌性共同筑巢则属于广义的**类社会性**路线。传统术语还把共同筑巢但各自照料自己幼体称为共同社会性，把共同育幼但所有雌性都能繁殖称为准社会性，把共同育幼且出现繁殖分工、却没有世代重叠称为半社会性。旧材料把“兰蜂仅合作育幼、泥蜂已有非生殖等级”作为固定例子过于粗糙：兰花蜂多为独栖或形成松散共巢，泥蜂类也横跨独栖、共同筑巢和不同程度分工。社会等级必须按具体种、巢内繁殖比例和世代关系判断，不能由中文类群名直接指定。

**生殖等级**在形态、生理和行为上负责主要繁殖，**职虫等级**则承担取食、筑巢、育幼、清洁和防御。蚂蚁和蜜蜂的工虫为雌性；白蚁的工蚁和兵蚁可来自两性。兵蚁不是独立性别，而是以大颚、头部、额腺或堵塞巢道的体形特化防御的职虫。某些蚂蚁工蚁连续变大，最大者习惯称兵蚁；另一些种有明显离散形态。把一切任务差异都称为“等级”也不准确，年龄、体况和眼前需要造成的短期分工可以没有永久形态差异。

## 蜜蜂的蜂群周期与繁殖分工 { #honeybee-colony-cycle }

西方蜜蜂的成熟蜂群通常有一只产卵蜂王、数万只雌性工蜂和繁殖季出现的雄蜂。蜂王与工蜂都由受精的二倍体卵发育，雄蜂多由未受精的单倍体卵发育。蜂王在产卵时是否释放储精囊中的精子，直接决定卵是否受精；较大的水平巢房通常用于雄蜂，工蜂会通过建造巢房、引导蜂王并清除幼虫调节雄蜂数量，却不能由“蜂王只在大巢房产卵，所以大房使卵变成雄蜂”解释性别。

雌性幼虫能成为蜂王还是工蜂，取决于工蜂提供的食物数量与组成、巢房结构和由此触发的内分泌及基因表达程序。蜂王幼虫在向下开放的王台中持续得到大量王浆型食物，发育速度、体形、卵巢小管数和成体结构与工蜂显著分化；工蜂幼虫早期也接受腺体分泌物，随后食物组成和供给量改变。巢房本身配合喂养，却不是独立决定命运的容器。营养感受、胰岛素样信号、TOR、保幼激素和表观调节共同把相同雌性基因型导向不同表型，是发育可塑性对传统等级观察的补充。[^honeybee-caste]

幼虫化蛹前，工蜂以蜂蜡封住巢房；成虫羽化后咬开蜡盖。蜂群准备分群或替换蜂王时建造多个王台，原蜂王带一部分工蜂离巢形成分蜂群，留下的处女蜂王相继羽化并竞争、分群或接管蜂巢。新蜂王婚飞后把精子长期储存在储精囊中。温带蜂群由蜂王和工蜂结团越冬，雄蜂在秋季资源紧张时常被拒绝喂食或赶出巢；雄蜂保留多久受季节、群体状态和失王风险影响，不是对“备用雄蜂”的有意识规划。

螯针由产卵器演化而来，所以雄蜂没有螯针。工蜂螯针有倒钩，刺入哺乳动物等弹性厚皮后常连同毒囊和部分腹部组织被扯出，工蜂随后死亡；面对其他昆虫时不一定发生这种自切。蜂王螯针较平滑，主要用于与竞争蜂王冲突，也能重复使用。螯针形态使工蜂的群体防御具有高个体代价，但是否出击还受报警信息素、守卫蜂反应和目标距离控制。

## 工蜂年龄分工与任务可塑性 { #honeybee-temporal-polyethism }

工蜂成虫生活中常出现**年龄多态分工**。刚羽化者梳理身体、清洁巢房并接受巢伴食物；咽下腺和大颚腺进入活跃期后，较年轻工蜂喂养幼虫并围绕蜂王形成侍从；随后蜡腺活跃，工蜂修筑巢脾、封房、接收并加工花蜜、压实花粉和清除废物；再后可在巢口守卫、扇风和进行定向飞行，最后更多转向采蜜、采粉、采水和采集树脂。传统的“清洁—育幼—筑巢—守卫—采集”顺序提供了良好观察框架，却不是按日龄自动触发的刚性时刻表。[^honeybee-labor]

群体需要能够改变分工比例。大量采集蜂死亡后，中龄工蜂可提前外出；育幼蜂被移走时，部分较老工蜂能够恢复腺体状态并回到巢内喂幼。幼虫、蜂王、采集蜂带回的花蜜量、食物储备、温度和工蜂之间接触共同影响任务阈值，保幼激素、卵黄原蛋白、神经递质和基因表达随转岗改变。现代分子证据解释工蜂为何可换任务，并没有取代对咽下腺、蜡腺、花粉篮、飞行肌和实际动作的观察。

每项任务也有空间位置。育幼蜂集中在育虫区，接收蜂在舞蹈区与蜜脾之间移动，守卫蜂检查巢口来者的气味，采集蜂离巢后返回特定入口。蜂群没有中央个体逐只发布命令；局部刺激、个体阈值和反馈使任务在群体层面保持。蜂王的主要作用是繁殖和释放与生殖状态有关的信号，称她“管理并激励所有工蜂工作”会把自组织误作脊椎动物式指挥。

## 蚂蚁的建群、职虫与行军生活 { #ant-colonies }

有翅雌蚁和雄蚁通常在特定气象条件下婚飞。交配后的雌蚁脱翅并寻找或开挖巢址；完全独立建群的蚁后可分解飞行肌、利用体内储备封闭育成第一批小型工蚁，随后主要产卵。另一些种由多个雌蚁共同建巢，或由蚁后带工蚁从原巢分出，甚至暂时寄生其他种蚁巢。雄蚁通常交配后不久死亡。工蚁成熟后承担育幼、觅食、巢建、搬运和防御，群体长到一定规模才投入产生新的有翅生殖蚁。

蚂蚁工蚁的亚等级可以按体形连续变化，也可以有明显的小工、大工和兵蚁。大头与强大颚适合切割和堵门，细长足适合远距离觅食，扩大的嗉囊可储存液体；形态倾向某些任务，却不保证个体终生只做一种事。部分工蚁产营养卵供幼虫、蚁后或巢伴食用，许多种还通过口对口液体交换传递食物和化学信息。蚁后死去后，一些种的工蚁会产未受精卵形成雄蚁，另一些种由具受精能力的工蚁或替代生殖者接管。

行军蚁不建固定的土石巢，却会由工蚁身体相互钩连形成临时**蚁团巢**。繁殖和幼虫发育使群体在定居期与游猎期之间转换；出猎时工蚁沿化学路形成密集纵队，前线捕获、肢解猎物，其他工蚁把食物和幼虫搬回，兵蚁在队列边缘防御。它们夜间或阶段性改变宿营地点，原因不只是附近食物耗尽，也受蜂王产卵和幼虫活动周期调节。社会结构由身体连接、路线信息素、搬运动作与生殖周期共同维持。

## 白蚁的家族群、伪工蚁与食物交换 { #termite-colonies }

白蚁是蜚蠊目内的社会性支系，与膜翅目的蜂蚁独立演化出真社会性。婚飞后，一雄一雌脱翅结对，成为持续共同生活的蚁王和蚁后；蚁王不像蜂类雄性那样交配后死亡，会在群体发展中反复授精。雌雄均为二倍体，工蚁、兵蚁和有翅生殖蚁也都可来自两性。这个系统说明单倍二倍性不是社会分工的必要条件。

白蚁不完全变态，幼体外形逐渐接近成虫。许多较原始支系没有不可逆的真工蚁，承担工作的未成熟个体常称**伪工蚁**；它们继续蜕皮，在群体失去生殖者或接收特定社会信号时可转为有翅生殖型、无翅补充生殖型或其他发育路径。较特化支系形成发育受限的工蚁，兵蚁则有大颚型、额腺喷射型等形态。把伪工蚁说成“滞留若虫且由成年虫退化”，会混淆可逆发育与成虫返幼；含伪工蚁的群体也不必因此短命。

纤维素食物依赖肠道微生物分解。工蚁或伪工蚁通过口对口的前肠食物交换和肛门到口的后肠食物交换喂养幼体、生殖蚁与巢伴；后者还能把共生原生生物或细菌重新传给蜕皮后失去部分肠道群落的个体。蚁王和蚁后可得到成分不同的专门食物。巢内化学物质、食物、保幼激素、个体发育阶段和现有等级比例共同调节分化，不能简化为“白蚁只靠信息素、蚂蚁只靠营养”。[^termite-castes]

白蚁群体早期先产生工型幼体，随后随巢群规模和资源出现兵蚁与有翅生殖蚁，是常见的群体发生顺序而非普遍固定表。原生蚁后和蚁王释放的化学信号通常抑制补充生殖者形成；它们死亡或隔离后，若虫型或工型个体可转成补充蚁王、蚁后，使群体延续。社会信号改变已有发育能力的表达，不表示生殖者用一种物质绝对控制所有成员。

## 从亲代照料到真社会性 { #routes-to-eusociality }

社会性昆虫的演化可从两类路径理解。**亚社会路径**始于母体筑巢、护卵和持续供食，后代延迟离巢并帮助照料下一窝；巢址耐久、独立筑巢困难和渐进式供食会提高留巢价值。**类社会路径**始于同代雌性共巢，成员可共同守巢和育幼，随后出现繁殖偏斜。这两条路径不是所有现生类群必须依次经过的阶梯，白蚁以一对雌雄及其后代组成家族群，膜翅目不同支系又多次从独栖祖先产生不同程度社会性。

亲缘选择说明帮助亲属也能传播与帮助者共同的基因。Hamilton 规则通常写作 \(rB>C\)：受益者增加的繁殖收益 \(B\) 乘双方相关度 \(r\)，若超过帮助者失去的直接繁殖 \(C\)，有利于帮助的等位基因可以增加。这里的收益和代价是对未来繁殖后代数的影响，不是主观善意。帮助者自己繁殖形成**直接适合度**，通过亲属多繁殖形成**间接适合度**，两者合成广义适合度。模型提供要测量的关系，不能用一次合作行为直接反推出动物已经计算亲缘系数。[^hamilton]

单倍二倍体膜翅目中，若蜂王只与一个雄蜂交配、所有姐妹同父同母，工蜂彼此平均相关度可达 0.75，高于母女的 0.5；这正是上一页旧材料“工蜂亲缘系数 0.75”的适用条件。蜂王多次交配、巢内多蜂王、工蜂产雄卵和群体混合都会降低或改变相关度，兄妹相关度也不是 0.75。白蚁、裸鼹鼠和真社会性虾均为二倍体系统，许多单倍二倍体蜂类仍独居。因此单倍二倍性可在某些条件下改变性比分配与帮助收益，却既非真社会性的必要条件，也非充分条件。

亲缘还不能独自回答后代为什么留下。可供建立新巢的地点、独立繁殖成功率、巢体防御、食物取得和亲本寿命共同决定成本与收益。祖先单配可使同胞相关度较高，有利于不可逆职虫分化起步；社会性形成以后，多次交配又可能通过增加遗传多样性、抗病和任务差异产生收益。演化路径必须区分“性状起源时的条件”和“成熟社会今天怎样运作”。[^eusocial-origins]

## 巢群中的合作、繁殖冲突与约束 { #insect-cooperation-conflict }

社会性昆虫巢群并非利益完全一致的超级个体。多个蚁后可争夺巢内地位，工蜂与蜂王可能对雄性和雌性生殖个体的投入比例有不同偏好，仍具卵巢的工虫可能产未受精卵，工虫之间也可能竞争成为补充生殖者。群体之间会争夺巢址、觅食区甚至掠夺幼虫和职虫。合作扩大了巢体和资源，繁殖集中又形成可以观察的冲突。

冲突可由攻击、食卵、阻止交配和化学信号调节。蜂王或蚁后释放的化合物既影响侍从、育王和工虫卵巢，也常随其生殖状态改变。旧材料把这统称为蜂王用信息素“抑制并激励工蜂”，容易混合两种解释：化学物质可能直接操纵接受者，也可能诚实表明巢内已有高产繁殖者，使工虫响应信号更符合自身间接收益。不同物种和化合物证据不一，不能把“蜂王控制”或“工虫自愿”当作全部系统的答案。[^queen-signals]

**工虫监督**包括攻击产卵工虫、破坏其卵或限制其接近繁殖区域。蜜蜂等单倍二倍体中，工虫通常与蜂王所生雄蜂的相关度高于与其他工虫所生雄蜂的相关度，监督可以减少工虫产雄；白蚁中也发现抑制额外生殖者的合作监督，却不依赖单倍二倍性。监督同时可能提高群体生产力。蜂王死亡后，原先的平衡改变，工虫卵巢、育王和等级争斗可迅速启动，证明“不繁殖”常是社会状态而不是解剖上绝对不育。

群体层面的有序结果由局部互动产生。个体在巢温升高时扇风或带水，在食物减少时提高采集，在尸体或病原出现时清除污染物；没有任何成员掌握全巢信息。把巢群称为“超个体”有助于比较繁殖系统、物质运输和稳态，却不能抹去成员间不同遗传利益，更不能把蜂王比作发号施令的大脑。

## 鱼群的队形、感觉与合作 { #fish-sociality }

鱼类个体彼此吸引而同向游动形成鱼群。行为学常把保持聚集但方向不完全一致称为 **shoal**，把速度和方向高度同步的群称为 **school**；中文均常译作鱼群，需要在具体描述中说明队形。鱼以视觉观察邻鱼位置和转向，侧线感受近距离水流与尾摆，听觉、嗅觉和电感受在一些类群中补充。个体持续调整排斥距离、对齐和吸引，使整个群无需领队也能转弯、压缩或分散。

群游可稀释单个个体被捕获的概率，增加发现捕食者的眼睛，并以同步转向造成混淆；鱼群还可汇总个体对食物斑块的零散信息，迁移时利用较有经验成员。特定队形和尾涡条件下，个体可能降低游泳能耗，但水动力收益随位置、速度和物种变化，不能把“集群一定省能”作为通则。群越大，食物竞争、错误信息、寄生虫传播和处在边缘或后方的风险分配也越不均。[^fish-shoals]

社会行为还可围绕繁殖和照料形成。守巢鱼驱逐接近卵和幼鱼的同类或捕食者，一些慈鲷由繁殖对和非亲本帮手共同守域、清洁卵、维护庇护处。帮手可能是延迟扩散的亲属，也可能通过共享安全地、积累繁殖经验或等待继承位置获得直接利益。清洁鱼与客户鱼的互动、石斑鱼与海鳗协同捕猎等则是跨物种合作，不应与同种社会组织混写，但说明稳定个体识别和重复互动不只存在于亲族群。

## 两栖类与爬行动物的隐蔽社会性 { #amphibian-reptile-sociality }

蛙和蟾蜍在繁殖地的鸣叫群可有固定叫位、卫星雄性和邻居识别；蝌蚪会集群游动，并能依据化学线索识别亲属、食物和捕食风险。有尾类可共享越冬地或繁殖水域，部分护卵种亲子接触持续很久。许多聚集由共同微环境触发，另一些则有主动同种吸引；只有操纵个体位置或线索，才能区分“都喜欢这块湿地”与“彼此喜欢靠近”。

爬行动物的体温和隐蔽生活曾使社会行为被低估。蛇可共同越冬、交配集结、在产仔地重复相遇，一些响尾蛇形成包含亲缘雌蛇和幼体的稳定联系；石龙子等蜥蜴可组成亲子家庭，识别亲属、共享庇护处并守护幼体。鳄类幼体以叫声保持群体并招引母体。旧材料把蛇称为爬行动物中社会行为最不发达，只反映早期观察偏差；社会结构的复杂度应由成员稳定性、识别和互动测量，而不是按纲或目排高低。[^reptile-sociality]

群居仍受温度和水分强烈影响。蛇穴中共同越冬可共享稀缺庇护并减少失水，蜥蜴并卧可能帮助维持微环境，却也增加竞争和传染。两栖类繁殖聚集提高找到配偶的机会，也吸引捕食者、寄生虫和干扰性雄性。生态条件解释何时聚集，亲缘和重复相遇则影响聚集后是否形成稳定社会关系。

## 鸟类群落、公共巢与巢中帮手 { #avian-sociality }

鸟类可以形成迁徙群、夜栖群、取食群和繁殖群落，成员稳定性差异很大。海鸟在悬崖或岛屿密集筑巢，每对仍守住巢旁距离；织布鸟可在共同外壳中建立多个巢室；犀鹃（ani，旧材料误作“犀鹊”）由多个雌雄组成繁殖群，共筑一个巢并共同孵育，但雌鸟之间也会移卵或弃卵。**公共巢**必须说明是多只雌鸟在同巢产卵、多个繁殖对共享结构，还是不繁殖个体帮助一对亲鸟，三者的亲子关系和冲突不同。

**巢中帮手**是亲本以外个体参与守域、警戒、孵卵、供食或护雏。多数合作繁殖鸟的帮手是延迟扩散的成年后代，照料弟妹能取得间接适合度，也可提高自身存活、继承领域、练习育幼或在群中取得未来繁殖机会；某些种的帮手与亲鸟无亲缘，直接利益更重要。要证明帮手真正提高繁殖成功，需比较移除或自然缺少帮手后的雏鸟存活，并区分优质领域本来就同时容纳更多帮手和更多幼体。[^avian-cooperation]

旧材料列举的北美松鸦需要校名。佛罗里达灌丛鸦生活在全年领域内，前一年或更早出生的子代常留在双亲旁，帮助警戒、围攻捕食者、守域和喂雏，是经典合作繁殖者；不是“加州松鸦无帮手”。墨西哥松鸦的稳定群体可含多个繁殖对和帮手。松果鸦高度群居、成群储藏松子并可集群营巢，其繁殖与食物周期密切相连，却与典型单对亲本加亲缘帮手的制度不同。蓝松鸦是否常规具有帮手没有同样充分证据。保留这些物种比较时，应比较群体领域、巢的分散程度、帮手身份和实际投喂，而不能只按名称排成合作程度序列。

## 哺乳动物社会组织的多条路径 { #mammalian-sociality }

哺乳动物社会组织包括独居、配对和群居三大状态，群居内部又有母系家族、多个雌雄的混合群、一雄多雌单元、多雄群、合作繁殖家族和裂变—融合社群。许多有蹄类雌兽与幼体成群，雄性季节性加入；象群以相关雌性和幼象为核心，成年雄象多离开但仍有自己的社会网络；狮群由亲缘雌狮、幼体和暂时控制繁殖的雄性联盟组成；狼群多是繁殖对与数窝不同年龄后代；灵长类跨越单雄、多雄多雌、配对和裂变—融合等多种组织；蝙蝠与鳍足类还形成从小型育幼群到巨大繁殖集群的状态。

因此“大多数哺乳动物是一雄多雌母系社会”混合了婚配制度、雌性亲缘和群体结构。哺乳类中一雄多雌确实常见，许多稳定雌群也以母系亲属为核心；但大量物种独居，社会单配、共同繁殖和多雄多雌也多次起源。婚配关系在上一页按社会和遗传层面描述，本页则记录谁共同移动、取食、休息和照料。一个母系群可以由多个雄性短期或长期加入，也可在遗传上由多个雄性产生后代。[^mammal-societies]

群体内合作常与亲缘相连，却不只由亲缘驱动。雌象共同保护幼象并利用年长成员记忆，雌狮协同防卫和捕猎，犬科成员把食物带回幼体，狐獴个体轮流警戒并帮助喂幼；海豚雄性联盟和灵长类结盟还可在非近亲间维持。理毛、食物分享和结盟能够交换即时收益、建立容忍或维护长期关系，但不能见到互相帮助便假定双方精确“记账”。

## 裸鼹鼠的繁殖等级与地下协作 { #naked-mole-rats }

裸鼹鼠在东非干旱地区挖掘长而封闭的地下隧道，群体常有一只主要繁殖雌性、少数繁殖雄性和数十只不繁殖成员。非繁殖者共同挖土、搬运块茎、守卫隧道、维护巢室和照料幼体；多个世代同居，繁殖高度集中，所以常称真社会性哺乳动物。群体成员以气味、叫声、身体接触和隧道内反复相遇保持识别，狭窄通道也使个体可用身体堵截蛇等捕食者。

“蜂王式”比喻有形态基础，也有界限。繁殖雌性开始连续妊娠后腰椎可伸长，使躯干加长并容纳大窝幼体，这是已量化的生殖形态分化；不繁殖雌雄的性腺活动受到社会状态抑制，离群配对后仍可能成熟繁殖。小型和大型非繁殖者在挖掘、搬运和防御上的平均投入不同，但任务有重叠并随年龄、体形和群体需要变化，不能像某些蚂蚁兵蚁那样视为完全不可逆形态等级。[^naked-mole-rat]

繁殖雌性通过推挤、优势互动和群体环境维持繁殖偏斜；她死亡后，大型雌性可能激烈争夺空缺，也有观察到较和平的交替。非繁殖者留群可分享隧道和食物、减少独自掘土的高成本，也可能通过照料亲属获得间接收益。达马拉兰鼹鼠同样常被称为真社会性或合作繁殖者，但野外资料显示独居或成对个体也能存活繁殖，帮手并非始终不可缺。把所有非洲鼹鼠群都直接等同蜂巢，会忽略扩散能力和职虫可塑性。

## 合作的直接收益、间接收益与互惠 { #cooperation-benefits }

合作行为可按收益来源区分。双方立刻因联合行动受益，例如鱼群同步防御、狼群共同制伏大型猎物，属于**相互受益**；个体帮助亲属育幼，自己的后代减少却使共享基因增加，属于亲缘选择可解释的间接收益；今天帮助伙伴、以后在角色互换时得到回报，才接近严格的**互惠合作**。重复相遇、个体识别、拒绝长期不回报者和未来机会，都是互惠稳定所需条件。很多看似互惠的例子其实每次都让双方立即获益，无需假定延迟偿还。

非亲个体也可通过群体成员资格取得直接收益。帮手等待继承巢址，低等级个体在群中降低被捕食风险，新加入者以守卫换取容忍，都是“现在不繁殖”仍可能增加以后直接繁殖的路径。个体也可能被优势者强迫工作或因离群代价太高而留下。判断帮助为何维持，应比较留下、离开、帮助与不帮助个体的后果，而不是把合作自动归为利他。

亲缘识别可以依赖共同巢味、熟悉性、表型匹配或位置线索。工蚁用体表碳氢化合物辨认巢伴，蝌蚪和鼠类可用气味区分亲属，鸟兽还借声音和长期记忆识别个体。动物不必知道谱系图；线索只要在通常环境中与亲缘相关，就能让帮助偏向亲属。巢群合并、寄生或环境气味改变会造成识别错误，社会系统因而同时包含接纳、排斥与误伤。

## 群居的防护、取食与信息收益 { #group-living-benefits }

群居可缓冲环境波动。企鹅、啮齿类和蜜蜂通过靠拢或结团减少热量散失，蜂群扇风、蒸发水分和改变聚集密度调节巢温；共同巢穴还能保持湿度并分担挖掘与修补。收益受群体大小和位置影响，边缘个体可能更冷，内部个体也可能过热或缺氧。把“减少气候损害”落实到靠拢姿势、巢材、空气流动和温度记录，才能判断合作是否真正改善微环境。

面对捕食者，群体可产生**稀释效应**、更多个体警戒、集体围攻和捕食者混淆。个体把自己放在同伴中央还可形成自私群效应，说明群体防御不要求每个动作都为大家牺牲。报警者可能暴露位置，哨兵却也常在高处较早发现危险并首先逃入安全处。鱼群、鸟群和有蹄类的同步运动能使捕食者难以锁定单体，集体驱赶则依赖成员朝向、攻击距离和武器。

群体也可提高取食和资源防御。个体从同伴移动、叫声、成功进食或返回路线获得食物信息，合作捕猎者分工包抄，巢群以大量工虫开发短时资源。信息会使过多个体拥向同一斑块，猎物又可能被快速耗尽；合作猎物过小或参与者过多时，每只分得反而下降。共同守住领域能排斥邻群，但群体越大所需食物越多。完整的净收益模型迁入生态栏目，本页保留寻找、招募、包围、分享和驱逐等可观察动作。

群体为幼体提供更多社会经验。幼体观察成体选择食物、辨认捕食者、使用路线和处理同类关系，多个照料者也可增加保护和供食。但“学习环境更好”不保证所有传统都正确；错误警报、低效路线和不适宜食物也会社会传播。区分学习与共同环境，需要比较有无示范者、控制食物和地形，并追踪行为能否在群体内持续。

## 资源竞争、疾病与繁殖冲突 { #group-living-costs }

同伴首先也是竞争者。群体增加发现食物的机会，同时让食物更快被取走；密集巢位带来庇护，也导致巢材、空间和配偶冲突。优势者可占据中心位置或先取食，低等级者承受驱逐和慢性压力。群体过大时可分裂、部分成员扩散或繁殖受抑，这些变化使实际群体大小围绕资源和成员关系浮动，而不是越大越有利。

近距离接触、共同粪场、食物交换和共享巢材增加病原体与寄生虫传播。社会性昆虫通过理毛、清除尸体、隔离污染物和树脂等巢材形成“社会免疫”，鸟兽可避开患病个体或改变接触网络；防御有成本，也不能消除流行。群体的遗传多样性、年龄结构和空间分区会改变传播路径，所以简单按成员数预测疾病风险并不充分。

密集繁殖还会出现误认、偷卵、巢寄生和照料错配。多个雌鸟共巢时可移走他者的卵，群落中幼体可能进入邻巢，哺乳动物育幼群中也会发生偷乳。另一方面，个体识别、巢位记忆和亲子叫声正是在这种风险下发展。旧材料的“群居容易错配”若不说明配偶、亲子还是巢位，便无法检验。

繁殖偏斜使杀幼、毁卵、强迫离群和抑制性腺成为严重代价。新雄接管、优势雌性压制下属、工虫监督和帮手争夺继承位的机制不同；欺骗也可利用报警、乞食、食物招募或繁殖信号。群体合作与冲突不是两套相反制度，而是同一成员同时共享部分利益、又在资源和后代上利益不完全一致的结果。

## 群体大小、成员身份与领域边界 { #group-size-membership }

最常观察到的群体大小是出生、死亡、迁入、迁出、分裂和融合共同形成的动态状态。增加一个成员可能提高警戒或防御，也会增加食物竞争；成员是有经验成体、依赖幼体、繁殖者还是病弱个体，影响远大于简单的数量。实验移除成员、长期个体标记和社会网络记录能把群体大小效应与栖息地质量分开。

群体还可共同占有活动范围，却只有实际排他防卫的部分称为领域。鱼、蛙、鸟、兽和多种无脊椎动物用巡逻、展示、叫声、气味与电信号维持边界；这些信号的产生和接收在下一页[动物通讯](communication.md)展开，领域大小、资源可防卫性与栖息地选择模型则由[栖息地、领域与捕食关系](../../ecology/behavioral_ecology/habitat_predation.md)承接。社会组织页只需先明确：共同活动区、核心活动区和排他领域不是同义词，群体内部合作防卫也仍可伴随成员之间的空间分区。

动物社会因此不能用“独居—群居—真社会”排成一条进步阶梯。鱼群的瞬时同步、鸟类亲缘帮手、象的母系记忆网络、裸鼹鼠的繁殖偏斜和白蚁的两性职虫各自解决不同生活史问题。沿成员身份、身体结构、互动动作和群体周期逐项观察，再用亲缘、收益和冲突模型解释条件，才能同时保存比较动物学的细节与现代社会演化的证据边界。
