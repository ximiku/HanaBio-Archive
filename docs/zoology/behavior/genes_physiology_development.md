# 行为的遗传、生理与发育

动物每一次完成觅食、求偶、鸣唱或逃避，都是一具在特定发育阶段、特定生理状态和特定环境中的身体所作的反应。基因影响感受器、神经回路、肌肉和激素系统的形成与运行，经验改变这些系统对线索的权重，当前的营养、昼夜时相和社会情境又决定已有能力是否表现出来。因此，遗传、生理、发育和学习不是四套彼此竞争的答案，而是行为在不同时间尺度上的形成条件。

传统行为学和行为遗传学提供了许多仍然重要的实验路径：比较近交品系、交换幼体的养育者、观察种间杂交、连续选择迷宫表现，或在鸣禽发育的不同阶段隔离声音。这些设计的价值在于逐步拆开变异来源，而不是给行为贴上“先天”或“后天”的标签。现代分子遗传学、神经内分泌学和发育神经科学则进一步追踪变异怎样进入细胞、回路与身体，并修正早期模型中把复杂行为归给单个基因或单个腺体的倾向。

## 行为表型与方差分解 { #behavioral-phenotype }

一个可测量的**行为表型**必须同时说明动作、情境和量尺，例如“在规定光照和饥饿程度下，十分钟内进入开放区的潜伏期”，而不是笼统的“胆小”。总表型变异常概念化为遗传效应、环境效应及基因型与环境互作。若用数量遗传学模型表示，可写成 $V_P=V_G+V_E+V_{G\times E}+V_\varepsilon$；具体实验还可能需要加入基因—环境协方差、母体效应、重复测量和社会群体效应。交互项表示不同基因型对环境改变的反应规范不同，并不等于把 $V_G$ 与 $V_E$ 相乘。

遗传方差还可在适当的亲缘和繁育设计中分为加性、显性与上位性成分。广义遗传率 $H^2=V_G/V_P$ 包含所估计的全部遗传方差，狭义遗传率 $h^2=V_A/V_P$ 只取加性方差，后者直接关系到群体对人工选择的短期响应。两种比值都属于特定群体、特定环境和特定测量条件；它们不是某个个体行为中“由基因决定的百分比”，高遗传率也不表示环境干预无效。环境范围缩窄会使 $V_E$ 下降，从而提高比值，而基因型本身并没有因此变得更强。[^quantitative-genetics]

## 品系比较与交叉养育 { #genetic-designs }

近交品系内个体在许多位点上较为相似。把多个品系置于共同环境，若它们仍在活动、攻击、交配或学习指标上稳定不同，可以检出与品系相关的遗传变异；同一品系在不同环境中的改变则显示表型可塑性。严格设计还要随机化笼位、操作者和测试顺序，统一胚胎期与哺乳期条件，并在多个家系和重复群体中检验，否则微生物群、母体状态或实验室历史也会随“品系”一起传递。

**交叉养育**把卵、胚胎或幼体交给另一亲本、品系或物种抚育。若后代趋近遗传亲本，说明遗传、产前环境或卵内母体效应仍有贡献；若趋近养育者，则可追踪食物、照料、声音、示范或社会地位的影响。双向交换、同窝内分配和未交换对照能够把这些解释逐步分开。交叉养育不会自动消除全部环境差异：胎生动物在出生前已经共享母体环境，卵黄激素和抗体在换巢前已经进入卵，养育者的反应还可能被幼体基因型诱发，这些都属于设计中要测量的路径。

## 杂交拆开行为序列 { #hybrid-behavior }

近缘种的杂交后代常把亲本行为的不同组成动作带到同一个体中，因而适合观察一个看似完整的行为怎样由定向、取材、搬运和放置等环节组成。桃脸牡丹鹦鹉把巢材撕成多条后插入腰背羽毛携带，费氏牡丹鹦鹉通常以喙逐条搬运。Dilger 观察到两者的杂交后代起初反复尝试把巢材插入羽毛，同时又以喙衔持，动作次序互相干扰；随着经验增加，许多个体逐渐提高用喙搬运的成功率。这个经典案例既显示亲本特有动作倾向可遗传，也显示动作的组织和效率会在练习中改变。[^lovebird-hybrid]

杂交个体的行为有时超出两个亲本的测量范围，过去会被称为“杂种优势”；有时出现亲本中不明显而被认为接近祖先的动作，又会被称为“返祖”。这两个名称都只是现象起点。前者要排除体型、健康、杂合度和测量上限造成的表面优势，后者则要凭系统发育比较证明该动作确为祖征。杂交还会打破原有基因组合并改变身体比例、感觉能力和亲本照料，不能只根据一个新动作就指定单一遗传机制。

## 人工选择与行为的可遗传变异 { #artificial-selection }

**人工选择**按一个行为指标挑选繁殖者，连续比较后代群体的均值变化。Tryon 从异质大鼠群体中分别繁殖迷宫错误较少和较多的个体，经过多代形成所谓“迷宫聪明”和“迷宫迟钝”系，说明该测试表现含有可传递的变异。后来的共同养育和环境操纵显示，丰富环境能明显改善“迟钝”系表现，贫乏环境也会损害“聪明”系表现；选择所得差异并没有把迷宫成绩固定成不可改变的命运。[^tryon-selection]

选择实验还会把与目标指标相关的感觉、运动、焦虑、食欲和探索倾向一起带走。某一系少犯错，可能因为更愿意进入开放臂、对电击或食物更敏感，或采用了与装置相合的路线策略。换一种迷宫、改变强化物或测试别的学习任务，原先的次序可能缩小甚至反转。因而，选择响应证明的是该群体在该指标上存在可遗传变异；只有结合交叉任务、感觉—运动对照、基因组定位和回路实验，才可能说明被选择的是哪一个行为过程。

## 从经典遗传模型到基因—回路机制 { #genes-to-circuits }

单基因突变可以产生清楚的行为缺陷。Brenner 建立秀丽隐杆线虫遗传学体系时，分离出许多身体波形、协调运动和趋化异常突变体；这些材料使研究者能够从离子通道、突触传递和感觉受体追踪到运动输出。不过，“一个突变使虫不能正常波动”不等于“波状运动由一个基因控制”。正常爬行需要多类神经元、肌肉、身体力学、感觉反馈和大量基因共同工作，单个突变只是在这条因果链上产生了可见断点。[^brenner-worm]

蜜蜂的**卫生行为**保留了从行为分解走向复杂遗传结构的另一条经典路径。工蜂先开启含病死幼虫或蛹的巢房盖，再把内容物移走。Rothenbuhler 根据卫生系、非卫生系、杂交一代及回交后代提出两个隐性位点模型：一个影响开盖，一个影响清除；若把两个独立位点按完全显隐性作理论上的 F2 组合，会得到 9∶3∶3∶1 的四类比例，而经典检验主要依靠杂交一代与卫生亲本回交后约 1∶1∶1∶1 的四类分离。它的重要贡献是把“清巢”拆成连续动作并用育种预测检验。[^hygienic-two-gene]

现代数量性状位点研究在卫生行为中找到多个效应区段，单个位点只解释部分变异；嗅觉灵敏度、病害线索、工蜂年龄、群体组成和病原类型都会改变表现。两基因模型因此应作为历史上极具启发性的简化模型，而不是所有蜂群、所有病害下的字面机制。一般而言，基因通过受体、神经发育、突触可塑性、代谢和身体结构改变行为概率，行为和社会环境又能反馈基因表达。把候选基因、细胞作用、回路变化与野外适合度连成同一证据链，比给复杂行为寻找一个“行为基因”更可靠。[^hygienic-qtl]

## 激素的组织效应与激活效应 { #hormone-effects }

激素把中枢神经系统、感觉器官、代谢、性腺和外周效应器联系起来。经典的**组织效应**指发育期激素对神经回路和身体结构产生较持久的塑造，**激活效应**指成熟个体在相应回路已经建立后，激素随季节、社会情境或生殖状态改变行为表达。两者是有用的时间尺度区分，但并非互斥：成年神经系统仍可发生结构可塑性，发育期激素也会产生短时作用。[^organizational-activational]

激素通常改变阈值、动机和反应概率，而不携带一条完整动作程序。睾酮可以在适宜光周期和社会背景下促进某些鸟类鸣唱、领域防御和求偶，却还要经过受体分布、局部代谢、听觉反馈与学习形成的鸣唱回路；糖皮质激素在不同浓度和时间尺度上调配能量、警觉与应激反应，长期升高又可能抑制生殖和认知。行为也反向改变激素：胜负、配偶出现、育幼和社会地位会调节分泌。因而，血液中一次激素浓度与一次行为的相关，不能单独证明激素是行为的上游原因。

## 蝗虫相变的多层调节 { #locust-phase }

飞蝗等相变蝗虫可随种群密度在散居型与群居型之间改变体色、体形、生理和行为。经典研究发现，散居条件下成虫前胸腺较大且维持较久，拥挤形成的群居型中前胸腺较早退化；切除、移植和激素处理一度使前胸腺与相型颜色、成熟和聚集行为相联系。这段实验史展示了怎样从内分泌器官寻找全身性状态转换的线索。[^locust-gland]

相变并不是由前胸腺单独拨动的开关。后足反复受到同类触碰等拥挤线索进入感觉与中枢网络，血清素参与数小时内的行为群居化；保幼激素、蜕皮激素、神经肽、代谢与表观遗传过程则在不同组织和发育阶段参与体色、形态、生殖及较慢的相型稳定。行为变化常先于完整形态变化，去拥挤后的逆转速度也因性状而异。前胸腺差异应保留为相变内分泌史上的真实观察，但它是多层调节系统的一部分。[^locust-serotonin]

## 睡眠的行为学判据 { #sleep-criteria }

许多动物无法像人一样报告主观睡意，也未必具有可直接套用的哺乳类脑电结构。比较研究因此先用行为学判据识别**睡眠或睡眠样状态**：动物持续保持物种特有的静止姿势，反应阈值升高但仍能迅速唤醒，剥夺后静止时间或深度出现补偿，并常受昼夜系统调节。静止本身不够；休息、蛰伏、麻醉、昏迷和低温造成的迟钝，需要通过可逆性、刺激反应和稳态调节区分。[^animal-sleep]

这种定义允许在不同身体结构上比较同一组功能特征。水母仙后属没有集中式脑，却表现夜间活动下降、刺激反应延迟和剥夺后的补偿；章鱼可在安静睡眠与短暂的活动睡眠之间转换，活动期伴随皮肤色纹、眼和吸盘运动。后者与脊椎动物某些睡眠状态有表面相似性，但现有证据不足以把它直接等同于快速眼动睡眠，更不能由体色变化推断梦的内容。[^jellyfish-sleep] [^octopus-sleep]

## 睡眠形态与生态约束 { #sleep-diversity }

动物的总睡眠时长、每次持续时间、姿势和昼夜分布差异很大。捕食风险、觅食所需时间、安全栖位、迁徙、生殖、幼体发育和系统发育历史共同塑造这种差异。草食动物若每天必须长时间摄食和反刍，可把睡眠分成短段；穴居或有可靠巢穴的动物能够维持更长的连续睡眠。不能把睡眠时长简单定义为“从其他活动剩下的时间”，因为剥夺后的补偿、神经与代谢变化说明它受主动的稳态过程调节。

海豚等鲸类可以让一侧大脑半球进入慢波睡眠，而另一侧维持呼吸和一定的环境监测；某些鸟也能出现单半球慢波睡眠，并随群体位置和风险调整两眼开闭。单半球睡眠不是完全清醒与完全睡眠各占一半的静态状态，而是脑区和时间上的动态安排。有关哺乳类慢波、快速眼动睡眠及昼夜调控的生理机制，可与[高级脑功能与睡眠](../../neuro/neuro_high.md#sleep-stages)对照阅读。[^unihemispheric-sleep]

## 行为发育的多层整合 { #behavioral-development }

行为发育既包括神经元产生、迁移、突触形成与髓鞘化，也包括激素状态、感觉器官和效应器成熟，以及个体取得的练习与社会经验。任一层次改变，都可能使同一神经命令产生不同动作。发育中的动物还会主动选择环境：开始游泳后遇见新的水流和猎物，开始离巢后接触新的鸣声与同伴，这些自发活动把身体成熟转化为新的经验来源。行为因而是发育过程的组成部分，而非发育完成后的附加输出。

匙吻鲟幼体提供了形态—感觉—摄食行为相互推进的例子。孵化后吻突逐渐伸长，表面的壶腹电感受器数目随之增加，幼鱼能更有效地在浑浊水中定位浮游动物；随着鳃耙和口咽结构继续形成，摄食方式又向高效悬浮滤食发展。这个转变不能只归因于“学会捕食”或“器官长成”：电感觉输入、游泳控制、猎物经验和过滤装置在不同阶段共同改变可行的行为。[^paddlefish-development]

## 鸟鸣发育中的模板、练习与反馈 { #birdsong-development }

鸣禽学习鸣唱常经历相互重叠的两个阶段。**感觉学习期**中，幼鸟听取同种成鸟的鸣声，形成或更新听觉记忆；**感觉—运动学习期**中，它产生亚歌、可塑歌和逐渐定型的歌，通过听觉反馈把自己的发声向记忆模板校准。两期不是所有物种都具有同一年龄界线，感觉记忆也不必等到发声练习开始才参与。先天的同种声偏好、实际导师的社会互动以及所听范例的数量和时序，都会决定哪些声音进入模板。[^birdsong-learning]

传统隔音和录音回放实验显示，白冠带鹀等幼鸟在敏感阶段接触同种歌，成年歌更接近正常；只听异种歌时，常仍保留同种声音偏向。活体导师有时能把学习窗口延长，幼鸟还可能选择父亲、邻近雄鸟或其他常互动个体作为范例。不同物种的窗口差异显著：斑胸草雀通常在青年期形成较稳定的成年歌，加那利等物种成年后仍可季节性更新音节；所谓“封闭式”和“开放式”学习者是连续谱上的端点，而非整齐的二分。

鸟鸣也不能预设为“只有雄鸟学习”。雌鸟鸣唱在鸣禽系统发育史上广泛存在并很可能是祖征，许多类群的雌鸟同样学习独唱或对唱。褐头牛鹂的经典实验还表明，不发声的雌鸟可用展翼等视觉反应即时反馈雄鸟，改变幼雄后来歌曲的形态和对雌鸟的效力；同伴组成、群养或隔离也会影响曲目与求偶效果。社会隔离有时使某些实验雄鸟的歌更容易诱发雌鸟反应，不能推广为“自然群体会压制雄性表现”的普遍规律，因为隔离同时改变练习对象、竞争、应激和选择压力。[^cowbird-feedback] [^female-song]

## 敏感期的形成与结束 { #sensitive-periods }

**敏感期**是在发育的一段时期内，某类经验对后续表型影响特别强。窗口的开始可由感官开放、运动能力、激素变化或神经回路达到可塑状态促成；窗口逐渐缩小，则可能涉及抑制性回路稳定、髓鞘化、受体和激素环境改变，以及已经形成的记忆对新输入产生干扰。历史上把结束解释为“内在时钟”或新旧经验的“竞争排除”，今天更适合把二者视为可以共同作用、且随类群与行为而异的机制。

有些敏感期不依赖亲本教学。鲑科鱼类在特定胚胎或幼鱼阶段记忆出生水体的气味，成年洄游时再利用这些线索；甲状腺轴、嗅觉系统成熟与开始迁移的生活史阶段相互联系。不同种和种群的记忆时段、气味来源及后来调用方式并不完全相同，所以“所有洄游鱼都有同一个出生后窗口”并不成立。敏感期表示学习效率的峰值，窗口外仍可能有较弱学习、再开放或替代线索。[^salmon-imprinting]

## 发育稳健性与行为可塑性 { #developmental-robustness }

动物在温度、营养、活动量和感觉输入有一定波动时，仍常形成可工作的动作系统，这种现象称为**发育稳健性**或管道化。稳健性可来自冗余通路、反馈调节、活动依赖的突触修整、身体生长与神经控制互相校准，以及后续练习的补偿。它不表示环境不起作用；同一系统可以对普通扰动有缓冲，却在关键剂量、关键阶段或特定任务中显露持久差异。

经典两栖类实验在胚胎自发运动出现前以麻痹剂长期固定非洲爪蟾和美西螈，待游泳阶段恢复活动后，幼体很快能产生总体协调的游泳。这一结果否定了“每一条正常运动连接都必须靠胚胎期练习才形成”的强版本。不过，定量测试仍发现恢复后最初一两天刺激诱发的游泳减少、自发运动增多，随后差异才消退。实验显示先天形成的网络结构与活动后的校准共同保障动作，而不是证明经验完全无关。[^amphibian-immobilization]

遗传变异、激素状态、形态生长和经验最终都在同一发育系统中相遇。稳健性使物种典型行为在普通扰动下可重复，可塑性又让个体根据局部环境调整阈值、对象和动作细节；二者并非反义词。下一页[行为演化与比较行为学](behavior_evolution.md)将进一步讨论这些发育机制怎样在同源结构、趋同适应、仪式化和生活史中产生类群间差异。
