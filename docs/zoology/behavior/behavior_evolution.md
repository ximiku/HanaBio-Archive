# 行为演化与比较行为学

动物的动作不会形成化石般完整的记录，却会在现生类群的行为序列、发育过程、神经和身体结构中留下可比较的差异。比较行为学据此询问：两个物种相似的动作是否来自共同祖先，同一种功能是否在不同支系中独立形成，一段原本用于取食、梳理或起飞的动作又怎样变成求偶和威吓信号。回答这些问题需要把自然史观察放到系统发育树上，并用发育、机制和实验结果限制解释。

行为容易随情境改变，不意味着它比形态更少受演化约束。感觉器官决定动物能取得什么信息，关节与肌肉决定可行的动作空间，神经回路和激素系统决定反应阈值，学习则在这些条件内调整对象、时序和局部形式。比较研究的任务不是把行为分成“遗传”与“学习”两类，而是重建产生差异的整套过程。

## 行为性状的比较单位 { #behavioral-characters }

比较的第一步是把笼统行为拆成可辨认的性状。鸟“攻击捕食者”至少可分为发现后的报警潜伏期、接近距离、盘旋、俯冲、接触、排遗、招募同伴和持续时间；求偶展示还要记录身体部位、左右次序、朝向、节律和发生情境。只有操作定义足够细，才可能判断两个物种是共享完整动作序列，还是只因达到同一功能而产生表面相似。

性状编码还要覆盖个体变异。某动作在一个物种中“存在”，可能表示所有成体都会做，也可能只见于一个性别、特定年龄、繁殖季或少数群体。研究者应记录缺失究竟是从未观察到、观察强度不足，还是在合适情境下确实不发生。学习形成的方言和地方传统也能稳定跨代，但群体差异不能未经共同环境、交叉养育或扩散记录便写成物种固定性状。

## 系统发育树上的证据 { #phylogenetic-comparison }

近缘物种继承了共同祖先的许多特征，因此不能把每个物种当成完全独立的数据点。若十种近缘海豹都具有雄性偏大的性二型，它们可能只代表祖先状态的一次继承，而不是十次独立关联。系统发育比较方法利用树的亲缘和枝长估计祖先状态、性状转变次数与相关演化，同时检验结果是否依赖树的不确定性、性状编码和演化模型。[^phylogenetic-methods]

哺乳类中，一雄多雌程度与雄性偏大的体型二型常呈正相关，雄性争夺配偶是重要机制；这条经典规律仍须按类群和性状限定。体重、犬齿、角和毛色可受不同选择压力，雌性体型也受繁殖和生态选择影响，同一物种还可能同时有社会配偶关系与不同的实际亲子关系。控制共同祖先、体型、食性、栖息环境和雄性育幼后，相关强度可以改变；性二型因此是婚配竞争的证据之一，不是仅凭外形反推婚配制的确定钥匙。[^dimorphism-mating]

## 行为同源与趋同 { #homology-convergence }

**行为同源**表示两个行为性状由共同祖先的相应性状延续而来。判断时可综合动作各组成部分的位置与次序、发生情境、个体发育、神经—肌肉机制和它在系统树上的分布。功能改变不取消同源：祖先的取食动作可在后代支系中转作求偶信号。外观不同也不必排除同源，因为同一祖传序列可被缩短、夸张或接上新的动作。[^behavioral-homology]

**趋同**或同功相似则是不同支系在相似选择压力下独立形成相近功能或形式。鸟和蝙蝠的飞行都需要升力，但作为飞行器官的翼分别演化；在更深层次，两者的前肢骨骼又是四足动物共同祖先遗留的同源结构。同一行为也可在不同层次同时包含这两种关系：捕食者接近时的逃逸功能可能趋同，控制转向的某些祖传运动回路仍可同源。

原素材把“从亲代或传统学到的知识”归为同源，把“个体亲历学到的知识”归为同功，这混合了性状的历史来源与个体取得方式。亲代传授的鸣声可以是一个支系内部的文化同源，也可以在不相关支系中独立出现；个体学习形成的动作同样可能调用祖传同源回路。学习、遗传和文化说明行为怎样在个体或世代间形成，同源与趋同说明性状的谱系历史，二者必须分别检验。

## 发育线索与重演说边界 { #ontogeny-phylogeny }

幼体有时先表现较广泛、较可变的动作，成年后才形成物种特有的序列。鸣禽从亚歌到可塑歌再到定型歌，某些鸟幼期与成体采用不同的搔头路径，这些现象能够提示发育时序怎样演化。异时性变化还可能使祖先的幼体性状延长到后代成体，或使原本较晚出现的动作提前；比较多个近缘种的完整发育序列，可以据此提出祖先状态假说。[^behavioral-ontogeny]

“幼年动物的行为等同于较原始物种的成体行为”却不能作为普遍规律。个体发育本身会演化，幼体面对的体型、捕食风险和社会环境也不同于祖先成体；现代物种更不应被称作另一物种的“原始阶段”。发育证据只有与系统树、外群比较和机制证据一致时，才能支持某个动作的历史转变，而不是让个体发育逐幕重演谱系历史。

## 行为遗存与祖先状态 { #behavioral-vestiges }

早期动物行为学把在当前情境中似乎失去原功能、却保留祖先动作轮廓的性状称为**遗痕行为**或行为遗存。这个概念能引导研究者寻找历史连续性，但“暂时不知道功能”不等于“已经没有功能”。舒适动作、胚幼期动作和低频动作尤其容易被误判；研究者要先测量它是否仍在清洁、体温调节、练习、社会信号或感觉取样中产生后果，再讨论功能减弱。

鸟类搔头是一个不断被重新检验的经典案例。鸟可把足从翼下直接伸向头部，也可先下垂一翼、再把足从翼上绕过。早期研究曾把翼上路径解释为四足祖先跨越前肢动作的保留，并尝试用两种路径重建鸟类亲缘。2025 年覆盖 1157 种、92% 鸟科的分析显示，至少在新鸟类中翼上搔头更可能是祖先状态，但两种路径在多个支系间反复转换，形态因素只能解释部分分布。搔头本身仍有清洁功能，路径则是高度易变的比较性状，不能简单称为返祖动作。[^bird-scratching]

把滚出巢外的卵取回也常被当作祖先行为。灰雁、骨顶鸡、秧鸡和其他地面营巢鸟可用喙或身体把卵移回巢中；穴巢鸟若卵只滚到巢杯边缘，同样可能保留这一反应。树上开放巢的卵一旦坠落通常已经破损或无法够到，取卵动作便较少有机会发挥原功能。某个树栖或高巢物种偶尔出现类似动作，只能成为祖先状态的候选线索；地面或湿地巢中的取卵仍直接减少繁殖损失，并非遗痕。位置、卵识别和巢寄生还会使取回与拒卵成为不同的决策。[^egg-retrieval]

## 信号的系统发生仪式化 { #phylogenetic-ritualization }

行为学中的**仪式化**是一个演化过程：原本主要承担机械或生理功能的动作，被选择改造成影响接收者的信号。变化常包括删去与通讯无关的部分、夸张关键幅度或颜色、增加重复、使节律和朝向更稳定，并把动作从原先的生理诱因中“解放”出来，转由社会情境触发。这些趋势提高可检测性和可辨别性，却不是每个信号都必须同时出现的检查表。[^ritualization]

**意向动作**是完整动作开始前的一小段，例如鸟起飞前屈腿和前倾，或取巢材前把喙伸向材料；接收者若能据此预判下一步，选择便可强化这段动作的显著性。**替代活动**是在相互冲突或受阻情境中出现的第三类动作，如威吓和逃避动机并存时突然梳理羽毛；若它稳定预示求偶或冲突状态，也可能被纳入展示。竖毛、竖羽等体温调节或自主反应会改变轮廓，护眼、缩颈和转头等保护动作会暴露醒目的色斑，取食、梳理和筑巢动作则提供已有的运动模块，它们都可能成为信号原料。

仪式化信号可能因大幅动作、鲜明结构或长时间展示而消耗能量并增加暴露风险，也可能只是把原动作缩短为低成本提示。能量消耗不是仪式化的定义。信号形式取决于传播环境、接收者感觉系统、双方利益和误判代价；有效而廉价的常规信号在利益大体一致时也能稳定存在。

原素材还把幼鸟多变叫声逐渐定型称作个体发育中的仪式化。发声**定型**是运动练习、听觉反馈和社会选择使变异减少的发育过程，本身不证明该叫声在谱系中由非通讯动作演化而来。另一个专门概念“个体发生仪式化”描述互动双方反复配合后，把完整动作的开端约定为手势；倭黑猩猩母幼携带手势提供了候选证据。它与跨世代自然选择造成的系统发生仪式化可以产生相似结果，但时间尺度和检验方法不同。[^ontogenetic-ritualization]

## 适应假说的竞争性检验 { #adaptation-testing }

观察到一项行为有利于存活或繁殖，只是提出适应假说的起点。研究者应同时列出可区分的解释，推导它们在季节、亲缘、繁殖阶段、捕食者类型和个体状态上的不同预测，再用模型捕食者、回放、移除或自然变异检验。结果还要测到接近行为的后果，例如捕食者离开概率、巢存活或繁殖成功；只见动物做出强烈动作，不能证明动作达成了推定功能。

比较证据和实验各自回答不同问题。跨物种关联可显示某行为是否随栖息环境或生活史反复演化，却容易受共同祖先和未测变量影响；单物种实验能识别即时因果，却未必说明该机制怎样起源。理想证据把系统树上的多次转变、野外自然史、操纵实验和适合度结果连接起来。有关选择、适应与约束的群体遗传学框架由[自然选择、适应与约束](../../evolution/selection_adaptation.md)展开，动物页在这里保留行为动作与比较方法。

## 鸥类围攻与群体防御 { #gull-mobbing }

繁殖群中的黑头鸥遇到狐、鼬、鸦或猛禽等潜在捕食者时，会报警、聚集、盘旋、俯冲，有时排遗或直接接触。随着捕食者接近巢区，参与者和攻击强度可增加；密集的声响与多方向俯冲能够促使捕食者离开，也可能帮助邻鸟及早发现危险。Kruuk 对黑头鸥捕食者和反捕食行为的长期观察与模型实验，使这种传统上称作“激怒反应”的现象成为可量化的**围攻**或集群驱赶。[^black-headed-gull]

围攻可能同时包含亲代防御、自身防御、配偶防御和群体信息效应，不能从群体表面协同行动直接推出群体选择。风险也不均等：靠近、叫喊甚至撞击的主动围攻者承担的危险高于在外围盘旋的被动参与者。检验时要记录个体身份、巢位、亲缘、繁殖状态、到捕食者的距离和捕食者实际反应，而不只比较群体大小。

## 家燕围攻的多假说检验 { #barn-swallow-mobbing }

家燕繁殖地附近出现人或鸮类模型时，个体可在外围安静盘旋，也可发声并在两米内俯冲甚至撞击。Shield 对标记种群的实验同时检验自身防御、旁系亲属防御、群体防御和亲代照料：被动参与者在性别、年龄和繁殖状态上接近当地种群构成，符合获取捕食者信息、降低自身风险的解释；主动围攻者中有配偶者，尤其有巢雏的亲鸟明显过多，围攻概率和强度也随幼体繁殖价值及危险程度改变。[^barn-swallow-mobbing]

这些结果支持被动围攻具有自身防御成分，主动围攻兼有亲代和配偶防御，却不意味着每次围攻只有一个功能。原素材用“没有季节变化”排除自身防御、用未配对成鸟是否参加排除异性广告、再把保护后代定为唯一正确答案，压缩了行为组成和连续变异。竞争假说应由彼此不同的定量预测检验；一个预测不符会削弱相应模型，但不能抹去该机制在另一行为成分、季节或种群中的作用。

## 信号、线索与双方利益 { #signals-cues-payoffs }

**信号**是因影响接收者而演化、且接收反应也因利用它而演化的性状；**线索**则能被动物利用，却不是主要为这种影响而形成。鸟的报警叫可成为同伴反应的信号，捕食者移动造成的草叶晃动则是猎物利用的线索。信号还可能被第三方窃听：求偶叫吸引配偶的同时暴露给捕食者，不会因此失去信号身份。[^biological-communication]

用发送者和接收者的净后果分析通讯，比把信号固定分成“伤害、附带和欺骗”三类更清楚。若一个动作平均使双方受益，选择可维持合作性通讯；若它直接限制或伤害接收者而发送者获益，更接近胁迫而非信息信号。若发送者和接收者都净受损，该动作难以仅靠这次互动维持，必须寻找对亲属、未来互动或未计入情境的收益。发送者付出即时成本也不等于净受损，因为它可能换得后代存活、亲属收益、配偶保护或捕食者退却。

报警叫因此不能一概称为“只利接收者、损害发送者”的附带信号。它可能警告亲属，向捕食者表明已经被发现，招募同伴围攻，或降低发声者被单独捕捉的风险；不同物种、叫型和社会结构中的主要收益可以不同。要证明利他，必须估计发声者的直接适合度成本和接收者亲缘收益，而不只是看到别人逃走。

**欺骗信号**使接收者在特定情境中的反应平均有利于发送者而不利于接收者，例如发出不可靠警报以夺取食物。欺骗若过于常见，接收者会降低反应或演化新的核验规则，通讯系统因而通常需要足够的平均可靠性。错误信号也可能来自感知噪声、个体能力不足或环境改变，并非都含有欺骗策略；“诚实”和“欺骗”在演化分析中描述可靠性及利益后果，不要求动物具有人类式道德意图。[^signal-deception]

行为演化研究由此把动作的历史来源、当前功能、个体发育和即时机制保持为可以连接但不可互换的证据层次。下一页[取食、防御与争斗行为](foraging_defense.md)将进入具体动作序列与感知机制；最适取食、风险权衡和捕食者—猎物模型则在生态栏目的[行为生态学](../../ecology/behavioral_ecology/index.md)中系统展开。
