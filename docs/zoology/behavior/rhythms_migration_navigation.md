# 生物节律、迁移与导航

动物必须把动作放在合适的时刻和方向上。招潮蟹随潮水出穴，蜜蜂在花蜜分泌前后到达花源，候鸟在一年中的特定阶段积累脂肪并起飞，鲑鱼则从海洋回到出生水系。这里同时包含三类问题：生物钟怎样预先组织活动，迁移动物为何离开一个生活区并到达另一个生活区，以及动物怎样估计方向、距离和当前位置。时间系统为太阳罗盘提供时刻，也决定迁徙冲动何时出现；感觉和运动系统则把这种内部准备转成一段真实路线。

[定向、先天行为与动机](orientation_innate_motivation.md#kinesis-and-taxis)已经讨论局部刺激场中的动性、趋性和横定向。本页把空间尺度扩展到归巢与迁移，并保留动物身体、感觉器官和可观察运动的比较路径。迁移的适合度权衡、栖息地质量、领域和散布模型由[栖息地、领域与捕食关系](../../ecology/behavioral_ecology/habitat_predation.md)承接，这里集中说明节律、运动准备与导航机制。

## 周期、振幅与相位 { #period-amplitude-phase }

一个节律由反复出现的状态变化构成。**周期**是相邻两个同名相位点之间的时间，例如两次活动峰之间的间隔；**振幅**描述相对平均水平的变化幅度；**相位**说明一个观测值在周期中的位置。峰值时间可以作为相位标记，却不等于整个振荡器的状态。活动量、体温、激素浓度和基因表达还可能具有不同相位，因此研究者必须先说明记录了哪一项输出。

环境本身也有周期。光暗、温度、湿度、食物、捕食者活动、潮汐和社会事件都可直接改变动物行为；即使没有内部时钟，白昼升温也会让某些外温动物开始活动。这种外界刺激直接压低或增强被观察节律的现象称为**遮蔽效应**。真正的内源节律在移除周期性线索后仍能持续一段时间，其周期通常略偏离环境周期，故称**自由运行节律**。把自由运行、环境同步和直接遮蔽分开，是判断“生物钟”是否存在的第一步。[^rhythm-principles]

## 从小时到一年以上的节律 { #rhythm-timescales }

短于一天的重复活动常称**超日节律**，包括摄食、反刍、潜水、休息和许多激素脉冲。某些约十二小时的节律可能由昼夜钟的两个峰形成，也可能来自独立振荡器，不能只凭周期长度判断机制。发生时间本来就不规则的事件则不属于严格意义的节律；沙漠昆虫在降雨后集中产卵，是对罕见环境事件的条件性反应，而不是具有固定周期的“间歇节律”。

约二十四小时的**昼夜节律**最为常见。蜜蜂可在每天固定时段到达曾被喂食的地点，取消食物后仍连续数日提前出现；鸟兽的活动、睡眠、体温、取食和激素释放也常保持日周期。昼行与夜行描述输出相位，二者可以使用相似的核心时钟装置。昼夜节律通常是对光、温度、湿度、食物和敌害日变化的综合适应，而不是只对“白天”或“黑夜”的单一反应。

潮间带动物还要面对平均约 12.4 小时一次的潮汐。滨蟹、招潮蟹、等足类和许多软体动物在恒定实验条件下仍可表现近潮汐活动峰；振动、水压、浸水、盐度和温度变化能够校时。约 14.8 日的半月节律与大潮—小潮周期相连，约 29.5 日的月节律则与朔望月相连。银汉鱼类的滩岸产卵、海洋摇蚊 *Clunio marinus* 的羽化以及若干多毛类的繁殖展示了月—潮周期怎样把成体集中到短暂窗口。潮汐钟、半月钟和月钟可与昼夜钟耦联，也有实验显示它们能够分离，不能把全部海洋节律都写成昼夜钟受到月光调节。[^marine-rhythms]

接近一年的内源振荡称为**年节律**。一些鸟在恒定光周期和温度下仍连续多年出现迁徙躁动、换羽和生殖腺变化，说明季节活动可以由年钟预排；自然界的日长、温度、降雨和食物再把相位校到当地季节。冬眠动物并非有意识地“预知冬季”，而是把光周期和内源年程序同体况、食物及温度信号整合，逐步完成脂肪沉积、代谢抑制和休眠地选择。[^circannual-clock]

## 自由运行、同步与相位重置 { #free-run-entrainment }

恒定条件实验常把连续活动记录绘成双日活动图。若活动起点每天逐渐提前或推迟，斜率给出自由运行周期；重新提供光暗周期后，活动相位稳定到环境周期，称为**同步**或**携带**。隔离饲养的鸟卵、爬行动物卵和无脊椎动物可用于排除先前日周期经验，移地或拨时实验则检验动物是保留原相位还是依据新环境重新校时。个体间自由运行周期不同也支持内源性，但这些证据都要排除设备温度、喂食和人员活动留下的隐蔽周期。

能为时钟提供周期信息的外部因素称为**定时因子**。光暗通常是陆生动物最强的昼夜定时因子，温度周期、进食、潮水、振动和社会互动也可在特定系统中同步相位。地磁、重力和背景辐射曾被列作普遍定时因子，现有证据并不支持这种泛化；它们是否参与同步，必须由控制强度、时相和其他伴随变量的重现实验决定。

相同刺激在不同内部时相可产生相反结果。研究者在自由运行周期的各相位给予短光脉冲，再测量随后峰值提前或延后的程度，可得到**相位反应曲线**。时钟利用每日小幅相位调整把自身周期锁到二十四小时，跨时区后则需若干周期逐步重新同步。刺激直接令动物暂时活动或静止，却没有改变后续自由运行相位时，只是遮蔽而非重置。

恒定光强对自由运行周期的影响常以**阿朔夫规则**概括：许多夜行种在恒光增强时周期趋于延长，许多昼行种则趋于缩短。它是跨物种统计倾向，存在明显例外、非线性反应和恒光导致节律破坏的情况；“日行／夜行”不能单独预测每一种动物在恒光或恒暗中的周期方向。

## 温度补偿与多振荡器系统 { #clock-organization }

普通化学反应随温度升高而加快，生物钟却能在动物正常生理温度范围内维持相对稳定的周期，这称为**温度补偿**。它不是在任意温度下都绝对精确，也不表示温度不能校时：温度脉冲可以依相位提前或延后时钟，温度周期也能成为定时因子。温度超出正常范围后，节律幅度、周期乃至细胞存活都会改变。

动物昼夜系统可以拆成输入、核心振荡器、耦联网络和输出。昆虫的复眼、单眼或脑内感光系统向时钟神经元提供光信息；哺乳动物视网膜内在光敏神经节细胞投向视交叉上核；鸟类还由视网膜、松果体和下丘脑时钟共同参与。核心细胞利用转录—翻译负反馈、蛋白修饰、降解、离子活动和代谢反馈产生振荡，输出再调节活动、睡眠、内分泌和外周器官。具体的视网膜—下丘脑通路与睡眠时相分别可回看[视觉系统](../../neuro/neuro_vision.md#central-visual-pathway)和[昼夜时相与睡眠压力](../../neuro/neuro_high.md#sleep-regulation)。[^clock-network]

多细胞动物通常拥有多个相互耦联的时钟。哺乳动物视交叉上核由许多细胞振荡器组成，并通过神经、激素、体温和进食节律协调外周组织；鸟类的视网膜、松果体和下丘脑节点权重随物种不同；昆虫触角、肠道和生殖系统也可保留外周钟。局部细胞节律存在，不意味着每个组织完全独立；中央与外周时钟之间的耦联决定它们能否保持一致相位。

代谢抑制剂、蛋白合成抑制剂和膜离子变化都可能改变节律的周期、幅度或相位，高剂量还会使振荡停止。早期膝沟藻实验中，抑制期间发光消失、洗脱后按某种相位恢复，并不能证明时钟“不受化学物质影响”；需要同时区分振荡器是否继续运行、输出是否被阻断以及洗脱后是否发生暂态。遗传突变和分子记录进一步表明，时钟是可受扰动的细胞网络，而不是藏在某一器官中不受代谢影响的机械表。

## 节律对行为的组织作用 { #rhythm-functions }

时钟的适应意义在于提前准备。蜜蜂在花源开放前后出现，潮间带动物在水流到来前进入安全位置，浮游动物在昼夜垂直迁移中把取食与视觉捕食风险错开，候鸟在出发前增加摄食和脂肪储存。若活动只在环境变化发生后才启动，消化、酶表达、肌肉供能或移动本身可能已经来不及。

时钟还为方向计算提供内部时间。太阳方位不断变化，动物只有把所见太阳位置与当前时相结合，才能保持固定地理方向；月亮的方位既在一夜内移动，也随月相逐日改变，需要日钟和月周期信息共同补偿。节律因此不是迁移之外的独立章节，而是导航装置的一部分。

## 迁移、散布与日常移动的边界 { #migration-dispersal-boundary }

迁移不限于动物群整体换区，也不限于每年往返。它通常表现为比日常觅食更持续、更定向的运动，迁移阶段会暂时压低使动物停留、摄食或繁殖的局地反应，到达目标区后这些反应重新增强。个体、种群的一部分或连续多个世代都可完成迁移；单程幼体迁移、垂直迁移和借助洋流或高空气流的主动“搭载”也在范围内。

**散布**通常强调个体离开出生地或原繁殖地并在新地点定居，从而影响基因流和种群建立；**迁移**强调生活史中不同功能区之间的定向移动，常有回程或代际闭环；**游荡**则随短期资源变化改变方向而没有稳定目的地。归巢是返回特定地点的能力，可能嵌在迁移中，也可发生在一次普通觅食后。类别之间有连续过渡，判断时要依据完整轨迹、行为状态和生活史后果，而不是只设一个距离阈值。[^migration-overview]

领域、巢域、核域和栖息地选择发生在迁移终点或驻留期，已迁交生态页。它们与本页仍有接口：领域气味和地标可成为归巢线索，资源质量影响是否继续移动，出生地散布会改变个体首次建立活动区的位置。旧材料把“不迁移→短途迁移→长途迁移”画成单向进步序列并不成立；迁移可以多次获得、缩短、延长或丧失，随资源季节性、地理屏障和运动成本共同演化。

## 迁移路线的研究方法 { #migration-methods }

季节普查可发现局地数量、年龄、性比或形态型突然改变，却不能单独证明离开的个体去了哪里。环志、颜色标记、耳标和标记—释放—再捕获把两个地点联系起来，但回收概率受观察努力、死亡和标记脱落影响。无线电发射器、声学标签、卫星标签、GPS 和光照地理定位器能够记录个体路线；装置重量、续航、定位误差和附着效应决定可研究的体型与时长。

雷达可连续记录大批鸟和昆虫的通过高度、方向与速度，却常难以辨认物种和个体。稳定同位素、微量元素、遗传和羽毛／组织化学可推断动物形成某段组织时所处地区，空间分辨率取决于基线地图和组织更新速度。定向笼、飞行磨、风洞和磁线圈实验适合隔离机制，仍需与野外轨迹相互验证。现代迁移研究由群体流量、个体路线、生理状态和环境遥感共同组成，不是用一种新标签替代旧式观察。[^tracking-methods]

## 出发时机、迁徙冲动与生理准备 { #migration-timing-physiology }

光周期为季节提供稳定预告，内源年程序规定可响应的时间窗，温度、降雨、风、气压、积雪、食物和体况再调节具体出发日。圈养夜迁鸣禽在迁徙季出现夜间跳跃、扑翅和朝迁徙方向活动的**迁徙躁动**，即使看不到自然路线也可持续；其发生时段和方向说明部分迁徙程序具有内源基础。野外个体仍会因天气和资源把起飞提前、推迟或中断，内源程序与环境诱发不是二选一。

长途迁移前，许多鸟和蝙蝠增加摄食并沉积脂肪，肌肉、肝、肠道和运输蛋白可发生可逆变化。飞行段消耗燃料，停歇地补充燃料、修复组织并等待合适风场；迁移总进度由飞行速度、每日飞行时长和停歇时间共同决定。鱼类还要完成海水—淡水渗透调节转换，昆虫可改变翅肌、燃料和生殖分配，陆生有蹄类则需要在行走和沿途取食之间调整。

迁移让动物在不同季节利用繁殖地、食物、水源、越冬地和临时资源，也可避开局地干旱、严寒或高捕食风险。代价包括运输能耗、免疫与繁殖机会转移、陌生环境、极端天气、捕食以及途中关键地点丧失。每千米每单位体重的代价受体型、速度、负载和行走／游泳／飞行方式影响，不能固定排序为“哺乳类＞鸟类＞爬行类”。飞行单位时间功率高，却能快速跨越长距离；游泳单位距离代价常低；陆地行走可边走边取食。[^migration-energetics]

## 哺乳动物的季节移动 { #mammal-migration }

非洲角马、斑马和其他有蹄类沿降雨、嫩草与水源形成移动波；北方驯鹿等在林地、苔原和产仔地之间季节迁移。捕食者可追随猎物，却也受巢穴、幼体、领域和竞争限制，不能把食肉动物路线简单当作猎物轨迹的复制。陆生迁移的廊道、河流和围栏会集中或截断运动，因此地形和人造屏障同资源变化一样重要。

许多须鲸在高纬海域摄食，并在另一季前往较低纬繁殖或产仔；正确的一般次序是高纬夏季摄食、低纬冬季繁殖，且不同种和种群存在不完整迁移、性别／年龄差异及中低纬摄食例外。海豹、海象和其他海洋哺乳动物也可在繁殖地、换毛地与摄食海域之间往返，路线受海冰和海流影响。

蝙蝠不能概括为迁移能力普遍很弱。温带蝙蝠既有繁殖地与冬眠地相距不足数十千米的留居型，也有数百千米区域迁移和超过一千千米的长途迁移型；红蝠属、长翼蝠和若干游离尾蝠提供典型实例。翼载荷、翼尖形状、回声定位、夜间昆虫资源、顺风、脂肪和短期蛰眠共同影响路线。长距离迁移与冬眠可以出现在同一年度，不是二选一的替代策略。[^bat-migration]

## 鸟类迁徙的路线、日程与高度 { #bird-migration }

鸟类迁徙可按纬度、经度或海拔改变，也可在同种内部形成留居、部分迁徙和全迁徙的连续变异。南北路线在温带显眼，东西向路线并不少见；山地鸟常在冬季下降、繁殖季上升，但积雪、食物和捕食风险可产生相反方向。路线具有种群传统和地形约束，又能因气候、城市资源和学习而改变，不会因“保守”便永远阻止新栖息地被占据。

许多小型雀形目在夜间飞行，鹰隼借日间热气流滑翔，燕、雨燕和部分水鸟白昼也可边迁边取食；雁鸭、鸻鹬和海鸟则会跨越昼夜。海角、山口、岛链和海岸线常形成聚集地，因为它们集中上升气流、地标或最短跨海路径。迁飞单位的空速、相对地面的速度和整季推进速度是三个量；早春或晚春谁推进更快取决于停歇资源、风和繁殖时间压力，不能用月份单独规定。

多数迁飞流量出现在离地数千米以内，但个体可在山脉、沙漠和强风层上升到更高高度。日迁或夜迁没有固定高低次序；风向与风速垂直剖面、云底、降水、温度、气压和地形共同决定选层。鸟会通过升降寻找有利顺风，低温与低压当然会改变空气密度、供氧、热平衡和天气系统，旧说“低温低压不影响迁飞”不能保留为通则。[^bird-weather] 鸟的飞行结构与迁徙前器官重塑见[鸟类](../vertebrates/birds.md#life-history-migration)。

## 爬行类、两栖类与鱼类的迁移 { #ectotherm-fish-migration }

蛇和蜥蜴可在越冬点、夏季活动区和繁殖地之间季节移动；海龟幼体既受洋流输送，也会主动选择游向，成体在摄食区与产卵海滩之间远距离往返。流场是运动载体而非完整导航说明：只有把游泳方向、流速和最终位置同时测量，才能区分被动漂移、补偿和主动选路。

许多蛙、蟾蜍和蝾螈在陆生栖息地与繁殖水体之间迁移，使用湿度、温度、降雨、地形、气味和磁场等线索。成体对繁殖池的忠实性、幼体出水后的散布和非繁殖季避难地各属不同运动阶段。道路与排水沟对这种短距离迁移也可构成高死亡率屏障，距离较短并不表示生态代价小。

鱼类按介质边界可区分溯河洄游、降河洄游、淡水内迁移和海洋内迁移。鲑科鱼在淡水孵化，幼鱼入海生长，成体再溯河繁殖；鳗鲡在淡水或近岸生长，成熟后降海到远洋产卵。季节性河流中的鱼可随洪水进入泛滥平原取食、繁殖和避敌，海洋鱼类则在产卵场、育幼场和摄食场之间移动。盐度转换、流速、温度和嗅觉印记必须与具体生活史阶段一起说明。

## 昆虫迁飞与繁殖分配 { #insect-migration }

昆虫迁飞常发生在羽化、表皮硬化之后到主要繁殖之前，也可夹在两个繁殖阶段之间。迁飞状态包含持续飞行、对局地寄主的暂时低反应、趋向有利高空气流和到达后的降落反应；雷达显示许多体形很小的昆虫会主动选择高度和顺风，而不是随风随机漂散。寄主衰败、拥挤、光周期、温度、年龄和体况都可改变进入迁飞状态的概率。

“卵发生—飞行综合征”描述一些种中保幼激素升高促进生殖、迁飞窗内保幼激素较低的关系，但并非所有昆虫都服从同一三档规则。有些种可边迁边成熟卵，有些依靠到达后的花蜜或寄主营养继续生殖，极低保幼激素也不必普遍导致翅肌溶解。激素效应必须限定到物种、性别、日龄和营养状态。[六足动物与昆虫](../invertebrates/insects.md)保留蝶类卵—幼虫—蛹—成虫和各阶段滞育的形态路径，本页只讨论成虫或特定发育阶段怎样进入迁飞窗口。[^insect-migration]

迁飞蝗的散居相与群居相在体色、形态比例、神经内分泌和结群倾向上可逆变化。群居相蝗群的同向运动由个体相互吸引、视觉和机械刺激以及局部风场共同维持；散居相也能迁飞，昼夜时段随种群、天气和阶段改变。具体相变机制见[蝗虫相变的多层调节](genes_physiology_development.md#locust-phase)，不能把“散居型只夜飞、群居型只日飞”当作全生活史定律。

## 定向、归巢与真正导航 { #orientation-homing-navigation }

**定向**是保持某一方向或身体姿态，动物可以朝光、逆流或沿固定太阳角运动，却不必知道目标在哪里。**归巢**表示返回巢、洞穴、出生河流或其他已知地点。**真正导航**通常指动物从陌生地点出发，仍能确定目标方向并纠正位移；这需要某种位置估计，而不只是沿熟悉路线前进。

地图—罗盘框架把任务拆成两步：**地图**提供当前位置与目标的空间关系，**罗盘**把目标方位转换为当前身体应保持的方向。地图可以是熟悉地标组成的局部结构，也可以利用大尺度磁场或气味梯度；罗盘则可来自太阳、星空、偏振光或地磁。两者是功能角色，不意味着动物脑中必有一幅人类式地图和一枚单独罗盘。[^navigation-framework]

动物还可通过**路径积分**累计自身转向与位移，形成从当前位置指向起点的返巢向量。不同种的蚂蚁分别利用步行距离、步数、视流和天空罗盘中的若干信息，啮齿动物与鸟类则利用前庭、本体感觉和运动副本。误差会随路程累积，所以路径积分常由地标、气味或目标附近的系统搜索校正。

## 地标学习与熟悉路线 { #landmarks-path-integration }

独居蜂和胡蜂初次离巢时会围绕巢口作逐渐扩大的学习飞行，反复回看巢与周围物体。经典掘地蜂实验在巢口围一圈松果，蜂离开后把整圈松果移到旁边；返巢蜂集中在被移动圆圈中央搜索，说明它学习的是巢与局部地标的空间关系。后续研究显示，动物还会记忆从特定朝向看到的景象，并在归途通过图像匹配、路线地标和路径积分共同接近目标。[^landmark-learning]

地标不必是孤立物体。海岸线、河谷、山脉、城市边缘、气味边界和水下声景都能形成路线；经验丰富的鸽子和候鸟可沿熟悉地形修正太阳或磁罗盘误差。移动实验地标只能证明该线索在当前尺度起作用，不能自动推断远距离迁移也完全由同一地标链完成。

## 太阳、偏振光与内部时钟 { #sun-polarization-compass }

太阳方位每天从东向西改变，太阳罗盘必须由内部时钟补偿。蜜蜂、蚂蚁、鱼、爬行动物和鸟类都可利用太阳或天空偏振图样保持方向。云层遮住太阳圆盘时，动物仍可能从局部蓝天偏振、亮度和光谱梯度估计太阳轴；完全阴天或视野受限时则转用磁场、地标等线索。

拨时实验把动物置于提前或延后的光暗周期，使其内部时间与当地太阳错开。六小时拨时在简单几何下可造成约九十度预期偏转，鸽和其他动物的实际偏转常较小，因为太阳方位速度随纬度、季节和时刻变化，地标与其他罗盘也会抵消误差。实验的核心证据是偏转方向随拨时方向可预测改变，而不是每次都精确达到九十度。[^sun-compass]

落日附近的偏振图样可帮助夜迁鸟校准磁罗盘或星空罗盘。它提供的是黄昏时的方向参照，不是“落日点自动提高所有夜间定向”。校准关系随物种和经验而异，天空线索彼此冲突时应由专门冲突实验判断哪个线索主导。

## 星空、月亮与银河 { #stellar-lunar-compass }

夜迁鸟不必识别一颗固定“北极星”或猎户座某颗恒星。靛蓝彩鹀的天象馆实验表明，幼鸟通过观察星空绕天球极旋转来建立方向参照；若幼鸟只看到围绕人为轴旋转的星空，迁徙季会把该假轴当作参照。这既保留了星空导航的经典观察，也说明方向系统包含发育期学习，而不是遗传一张完整星座图。[^star-compass]

月亮可以提供方位，却在一夜内移动，并以约 24 小时 50 分的月日周期逐夜改变出现时刻。沙滩跳钩虾等端足类会结合日钟、月相和月亮方位朝海陆方向移动；月光产生的偏振图样也可参与。无月夜并非没有天体线索，非洲滚粪甲虫在天象馆中只保留银河亮带时仍能维持直线滚动，说明低分辨率复眼也可利用大尺度星光图样。[^lunar-milky-way]

## 地磁罗盘与磁地图 { #magnetic-compass-map }

地磁场有多个可测参数。**磁强度**随地点变化；**磁倾角**是磁力线相对水平面的角度，并在南北半球改变倾斜方向；**磁偏角**是磁北与地理北之间的水平夹角。旧材料把“偏角”写成动物判断向极或向赤道的线索，实际描述的是倾角。倾角罗盘不必辨认磁极的正负，只需区分磁力线向下或向上倾斜以及倾斜方向；极性罗盘才直接区分磁北和磁南。

欧亚鸲等鸟类、海龟和部分两栖动物使用磁罗盘；鲑鱼、海龟、龙虾和候鸟的实验还支持利用磁强度与倾角组合形成位置线索。磁地图不是全球坐标在脑中的逐点复刻：动物可把某一参数范围与转向规则、出生地磁特征或熟悉区域联系起来。地磁场具有空间不规则和长期漂移，多线索校准能降低单一磁参数造成的误差。[^magnetic-navigation]

候选磁感受机制包括隐花色素相关的光依赖自由基对，以及磁性颗粒经机械或神经通路换能。前者适合解释某些鸟类罗盘对光谱与射频噪声的依赖，后者常被讨论为强度或地图感受候选；具体感受细胞、通路和不同类群是否共享机制仍未完全确定。[感觉器官](../comparative_anatomy/sensory.md#electroreception)因此只把磁行为证据与已见组织结构并列，不宣称所有动物具有同一种“磁器官”。

## 气味、水流、电场与声音 { #chemical-electric-acoustic-navigation }

鲑鱼幼鱼离开出生河流时会学习水体气味，成体回到近岸和河口后利用嗅觉辨认支流；同种分泌物可能补充群体信息，但岩石、土壤、植物和微生物共同形成的水系气味更符合主要印记证据。远洋阶段还可利用地磁与海流，因此“气味印记”和“磁地图”作用于不同尺度，并不互相排斥。[^salmon-homing]

信鸽嗅觉地图假说认为，幼鸟在巢区学习风向与空气气味的空间联系，被移到陌生地点后据当地气味估计返巢方位。嗅觉处理、运输方式和区域气象会显著影响实验结果，且不同地区证据强度不一。哺乳动物、爬行动物和昆虫也会沿气味梯度或间断气味羽流导航，但这类局部循迹不必等同于大尺度二维地图。

软骨鱼洛伦兹壶腹和弱电鱼电感受器擅长检测近距离电场。鱼在海水中运动时，导电水体切割地磁场可产生感应电场，因而电感受可能参与某些磁定向；现有行为证据仍需与直接电定位分开。旧材料所谓“电导航静止时模糊、游动时精确”只适用于特定感应情境，弱电鱼主动电定位和角鲨猎物检测的距离、频率与感受器结构并不相同。

蝙蝠、齿鲸和许多鼩鼱以回声定位估计附近物体的距离、方位与运动，猫头鹰利用双耳时差和强度差定位声源。这些是精确的局部定向机制，却不等同于已证明的洲际地理地图。海浪、瀑布、繁殖地群体声和水下声景可标记地点；鸟类利用次声作长距离地图的假说仍有争议，应与已经充分验证的回声测距分开陈述。

## 多线索整合、发育与误差校正 { #multicue-integration }

动物通常以线索层级和可靠性加权导航。近巢时地标可压过路径积分，远距离阴天时磁罗盘替代太阳，晴朗黄昏的偏振光又可重新校准磁方向；河口气味帮助鲑鱼完成磁地图只提供到区域尺度的路线。某条线索被遮蔽后表现正常，只能说明当时存在备份，不能证明该线索平时从不使用。

首次迁徙的幼鸟可以继承大致方向、距离和停止时间，成年个体再由地标、社会同伴和历年路线提高精度。被横向搬离正常路线的幼鸟常继续沿原方向飞，经验鸟则更可能补偿位移并朝目标修正；这种年龄差异把先天向量与学习地图区分开。海龟和鲑鱼的出生地回归也同时包含遗传反应规则、早期印记和成年感知。

导航实验应分别操纵地图与罗盘。拨时改变太阳罗盘，旋转磁场改变磁方向，模拟异地磁参数检验磁地图，阻断嗅觉检验气味线索，位移地标检验局部记忆；释放后的第一方位、完整轨迹和最终抵达率回答的问题并不相同。城市夜光、玻璃幕墙、通信噪声、风电设施、水坝、道路和气候变化还会分别干扰天体线索、磁感受、廊道和出发时机。只有把时钟、感觉、运动能力和沿途环境放在一条因果链上，才能解释一段迁移为何成功或失败。
