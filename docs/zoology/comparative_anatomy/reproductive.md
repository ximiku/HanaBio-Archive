# 生殖系统

脊椎动物的生殖系统由产生配子的性腺、输送配子的管道以及参与受精、卵被形成或交配的附属结构共同组成。比较解剖时，性腺的形状只是最先看到的一层；更有解释力的是性腺与体腔、肾和泄殖腔之间怎样连接。早期脊椎动物的泌尿管道与生殖管道关系密切，随后不同支系以不同方式重新分配了中肾小管、中肾管和副中肾管的功能。因此，生殖系统适合与[排泄与渗透调节系统](urinary_osmoregulation.md)对照阅读。

这里所说的“雌性”和“雄性”首先按产生大配子或小配子的性腺功能界定。染色体组成、性腺形态、输导管、第二性征和行为通常彼此协调，却并非在所有物种、所有发育阶段都由同一套开关同步决定。比较教材中的传统形态名称仍是辨认标本的重要语言，现代发生学和系统发育证据则帮助限定这些名称的适用范围。

## 生殖嵴、性腺与配子通路 { #gonad-pathway }

脊椎动物的性腺起源于胚胎体腔背侧、靠近中肾的**生殖嵴**。原始生殖细胞经过迁移进入生殖嵴，与来自体腔上皮和间充质的支持细胞共同组织成未分化性腺。此后，睾丸方向形成支持生殖细胞的精索和间质区，精索在多数脊椎动物中进一步形成曲细精管；卵巢方向则形成包围卵母细胞的卵泡。性腺的体细胞支架、类固醇分泌细胞和生殖细胞具有不同来源，成熟性腺因而不是单一组织的膨大物。性腺形态发生的共同框架及其类群差异可参见 DeFalco 与 Capel 的综述。[^gonad-morphogenesis]

配子离开性腺的方式与性腺内部结构相连。精子通常从曲细精管进入输出小管，再进入较长的输精管道；许多卵巢则在排卵时让卵母细胞先进入体腔，再由输卵管漏斗捕获。真骨鱼的管道关系变化很大：囊状卵巢常有与卵巢腔连续的卵巢管，卵不必先游离到一般体腔；裸卵巢型鱼类则可把卵排入体腔或特定腔隙，再经生殖孔排出。观察切片时，应先寻找生殖上皮、卵泡或精小叶，再追踪管腔，不能仅凭器官外形判断配子通路。

传统比较解剖常把卵巢概括为“空心状”“中实状”和“葡萄状”。这些名称可以保留为标本描述，却不构成从低等到高等的单线序列。许多硬骨鱼的囊状卵巢具有中央卵巢腔；两栖类卵巢常呈分叶囊状，成熟卵泡突出于表面；爬行动物和哺乳动物的卵泡分布在具有较明显基质的卵巢内；鸟类大量有卵黄卵泡按等级悬垂，肉眼下最接近“葡萄状”。这些外观反映排卵方式、卵黄积累和生殖周期，而不是性腺功能的完善程度。

性腺的成对程度也必须逐类辨认。七鳃鳗成体只有一条中线性腺，盲鳗也通常只有一枚长形性腺；部分鲨类出现左右不对称，但软骨鱼并不存在统一的“某侧永远退化”规则。鸟类最常见的是左卵巢和左输卵管在成体保持功能，右侧在胚后退化；几维鸟以及少数猛禽可保留程度不一的右侧组织。鳄类通常具有成对卵巢，单孔类和蝙蝠也不能作为“单侧性腺动物”笼统处理；某些蝙蝠的排卵、着床或子宫角可有明显侧偏，这是成对器官的功能不对称，而非一侧性腺普遍消失。鸟类生殖器官的不对称及其少数例外应按具体物种记录。[^avian-physiology]

## 雌雄异体、雌雄同体与性转换 { #sexual-systems }

多数脊椎动物为雌雄异体，即一个个体在一个繁殖阶段只产生一种功能性配子。**功能性雌雄同体**要求同一个体在生活史中具有产生两类配子的能力；两类配子同时成熟称同时雌雄同体，先雄后雌、先雌后雄分别称雄性先熟和雌性先熟。性腺中偶见两类组织、个体具有混合的外部性征，或激素处理后出现另一性别的第二性征，都不足以单独证明功能性雌雄同体。

鱼类提供了最丰富的性系统比较材料。石斑鱼等多种鮨科鱼表现雌性先熟；鲷科及其他类群可见雄性先熟、同时雌雄同体或双向性转换。黄鳝是经典的雌性先熟例子：个体先以雌性繁殖，性腺经过间性阶段后转为具有功能的精巢。鱼类中经过证实的功能性雌雄同体仍只占真骨鱼的一小部分，性转换会受社会结构、体型收益、温度和内分泌状态等因素共同影响。[^fish-sex-change] 鲫属中某些复合类群具有雌核生殖或倍性复杂的雌性谱系，但普通鲫不能因此列作雌雄同体。

圆口类幼体和有尾两栖类也曾在传统材料中被笼统列入“雌雄同体”。较准确的处理是分别检验性腺组织和生殖功能。某些盲鳗的单一性腺可同时出现前部卵巢样组织和后部精巢样组织，幼体或未成熟个体也可有暂时性混合组织；现有观察并不支持把整个圆口类视为通常能够以两种性别繁殖的功能性雌雄同体。少数两栖动物可能发生性反转或出现卵精巢，仍是物种、种群或发育条件层面的现象。母鸡在卵巢病变或左卵巢功能丧失后可能雄性化，右侧残余性腺甚至发育成精巢样组织，但羽色、鸣叫等雄性化表现与产生有受精能力的精子是两回事。

现代研究显示，脊椎动物决定性别的上游信号十分多样，可以是不同的主效基因、多个基因的剂量关系，也可以受到温度等环境条件强烈影响；进入卵巢或睾丸分化后的若干调控网络却较为保守。性别决定系统能够在演化中频繁转换，性腺分化又可在部分类群保留较高可塑性。[^sex-determination] 这一证据补充了性腺外形观察，使同一种形态结果能够放回不同的遗传和环境背景中解释。

## 雄性生殖管道与附属腺 { #male-ducts }

无颌类没有由性腺通出的永久性输精管，成熟配子由性腺释放入体腔，再经腹部孔进入泄殖腔或直接通向体外。软骨鱼雄性的前部中肾小管与中肾管参与输精，中肾管可分化为盘曲的输精管，后段形成储精或膨大区域；泌尿功能更多由后部肾小管及附加尿管承担。雄性蛙类也可见睾丸输出小管经肾脏接入中肾管，因此同一条中肾管兼有输尿和输精作用。不同两栖类之间存在变式，不能把蛙的结构直接套用于所有有尾类和蚓螈。

多数真骨鱼的精巢形成独立生殖管道，精子不再借中肾管远距离输送。羊膜动物胚胎的中肾小管与中肾管则构成另一条连续的形态线索：保留下来的中肾小管形成睾丸输出小管，中肾管依次特化为附睾管、输精管及其末端结构。精子在这些管段中成熟、储存和运输，输尿管已成为独立的后肾管道。由此可见，“泌尿生殖管共用”描述的是特定类群和特定管段，不是所有雄性脊椎动物的共同状态。

哺乳动物的输精管末端常与附属腺分泌物共同组成精液。可比较的主要结构包括精囊腺、前列腺、尿道球腺，以及某些物种明显的壶腹腺、凝固腺和包皮腺。各腺体的有无、分叶程度和分泌成分具有显著物种差异：犬缺乏典型精囊腺，猫的尿道球腺较发达，许多啮齿类具有独立凝固腺并可形成交配栓，人的凝固腺则不能照此类推。鸟类通常没有与哺乳动物同源、同形的精囊腺和前列腺，但输精管末端与泄殖腔局部仍能参与精液的储存和调节，因此“无大型附属腺”不等于没有任何生殖道分泌。

## 雌性生殖管与卵的包被 { #female-ducts }

多数四足动物的输卵管来自**副中肾管**，又称苗勒管。它不是把中肾管纵向剖开后分出的一半，而是从前部中肾附近的体腔上皮发生，形成漏斗开口后沿中肾管旁向尾侧延伸；中肾管提供重要的空间和信号条件。[^mullerian-development] 在雌性个体中，副中肾管形成输卵管及其后续结构；在许多雄性羊膜动物中，它在抗苗勒管激素作用下大部退化。大多数真骨鱼的卵巢管不属于典型副中肾管衍生物，是比较时必须单列的例外。

软骨鱼的副中肾管前端可形成共同或成对漏斗，管壁中的壳腺分泌卵壳物质；卵生种的后段参与卵壳形成和排出，卵胎生或胎生种的后段可膨大为子宫样区域，胚胎在其中滞留。两栖类输卵管通常长而盘曲，腺性管壁为卵添加胶质包被，末端可形成暂时储卵的子宫部。爬行动物输卵管不同区段完成受精、蛋白包被、壳膜和钙质壳形成；胎生支系中，相同管道的保留时间、交换界面和分泌功能发生改变。

鸟类的左输卵管是分区最清楚的教学标本之一。漏斗部接纳排出的卵母细胞，受精通常也发生在这里；膨大部添加大量卵白，峡部形成壳膜，壳腺部或“子宫部”沉积钙质卵壳并保留正在成壳的卵，阴道部参与排卵后的最终输送和排出。**排卵**发生在卵巢卵泡破裂时，不能写成“阴道完成排卵”。雌鸟生殖道还可在输卵管—阴道交界附近的精子储存小管中长期保存具有受精能力的精子。[^avian-sperm-storage]

哺乳动物的副中肾管依次形成输卵管、子宫、子宫颈和阴道上部，其左右融合程度产生一组连续变式。双子宫的两侧子宫和宫颈分离，见于许多兔形类、啮齿类和有袋类；分隔子宫或双角子宫具有长短不一的两个子宫角和不同程度的共同子宫体，常见于食肉类、猪、反刍类和马；单子宫的左右管道高度融合，以人和其他部分灵长类最典型。不同教材对“分隔”与“双角”的界线并不完全一致，辨认标本时应直接记录子宫角长度、子宫体和宫颈数目。蝙蝠在同一目内就具有多种子宫形态，显示子宫类型适合描述结构，不宜排列为固定的进步等级。哺乳动物子宫形态及其发生基础可参见 Machado 等的综述。[^uterus-morphogenesis]

单孔类的左右子宫保持分离，末端分别开入尿生殖窦；子宫腺分泌物和暂时形成的壳膜共同支持产卵前的胚胎，因而传统教材有时把其子宫称作“壳腺”，但它仍是副中肾管末端的特化区。雌性有袋类通常具有两个子宫和两个宫颈，并保留成对的侧阴道；许多种在分娩时还形成中位产道。真兽类的阴道、子宫颈和子宫融合程度更不一，单凭“有无阴道”不足以区分有袋类与真兽类。

## 交接器与输精方式 { #intromittent-organs }

体内受精并不要求各类脊椎动物具有同源、同形的阴茎。软骨鱼雄性的腹鳍内侧形成一对**鳍脚**，以骨骼和沟槽把精液导入雌体。全头类还可具有额部和腹鳍前的钩状附着器，这些结构帮助固定配偶，不能与鳍脚一起算作三套独立输精器官。少数胎生硬骨鱼把臀鳍鳍条改造成交接器，花鳉科常称生殖足；其骨骼来源仍是臀鳍，与四足动物外生殖器不同。

大多数无尾两栖类靠抱对和体外受精完成配子同步释放；有尾类常以精包实现体内受精；雄性蚓螈可使泄殖腔末端形成可外翻的交接结构。尾蛙的“尾”也是泄殖腔延伸形成的交接器。爬行动物内部仍有两种醒目的构型：有鳞类具有成对、外翻的半阴茎，龟鳖类和鳄类具有中线单一交接器，成年楔齿蜥没有可用的阴茎。楔齿蜥胚胎却出现短暂的生殖突起，说明成体缺失可以由共同胚胎原基的后期变化产生。[^amniote-phallus]

绝大多数鸟类以泄殖腔接触输送精子，没有可突出交接器；古颚类和雁鸭类等若干支系保留或重新特化了泄殖腔来源的阴茎样结构。哺乳动物通常具有单一阴茎，海绵体的充血使其勃起，部分食肉类、啮齿类、翼手类和灵长类还具有阴茎骨。阴茎骨的有无与交配时间、排卵方式和谱系历史相关，不能作为体内受精效率的简单等级指标。

羊膜动物的外生殖器在胚胎中共享泄殖腔周围的信号环境和一部分位置关系，但龟、鳄、鸟和哺乳动物生殖突起的具体起点、组织贡献和成体构型并不完全相同。泄殖腔位置改变与外生殖器位置演化之间的联系，为这些结构的深层同源性提供了发生学证据，也提醒我们把“来源相近”与“成体器官完全相同”分开表述。[^cloaca-genitalia]

## 泄殖腔 { #cloaca }

泄殖腔是消化道、泌尿道和生殖道末端汇合的腔室，见于圆口类以外的许多脊椎动物支系，并在软骨鱼、两栖类、爬行动物、鸟类和单孔类中尤为明显。许多真骨鱼的肛门、尿殖孔彼此分开；全头类也与典型鲨类不同，常有分离的开口。因此，有无泄殖腔应按类群和物种实际确认。

鸟类和许多爬行动物的泄殖腔可分为三段：前部粪道接纳直肠内容物，中部泄殖道接纳输尿管和生殖管，后部肛道通向泄殖孔。三段之间有黏膜褶，但内容物能够在一定条件下跨段移动。鸟类的法氏囊开口于肛道背侧，是幼鸟 B 淋巴细胞发育的重要淋巴器官，性成熟后通常退化；它不是储存精液或形成卵壳的生殖腺。

在哺乳动物胚胎中，早期泄殖腔随后分隔为腹侧尿生殖区域和背侧肛直肠区域，泄殖腔膜本身位于外胚层与内胚层相接处。分隔过程牵涉间充质生长、膜的重塑及末端管道位置改变，过去把它简单画成一块“尿直肠隔”向下直插并完全切开腔室，容易掩盖实际的三维变化。人胚泄殖腔研究显示，解释畸形或比较成体开口时需要同时追踪管腔、上皮和周围间充质。[^human-cloaca]

## 哺乳动物共同原基与性别特异衍生 { #mammalian-homologies }

传统胚胎学常用一张“未分化期—雄性—雌性”对照表帮助识别同源结构。这张表最适合用于哺乳动物，不能直接充当所有脊椎动物的衍生清单；鱼类生殖管道、鸟类成体右侧管道退化以及爬行动物外生殖器的差异都需要另行比较。

| 共同原基或早期结构 | 雄性常见衍生物 | 雌性常见衍生物 |
| --- | --- | --- |
| 生殖嵴的体细胞支架 | 睾丸支持组织与间质组织 | 卵巢支持组织、卵泡细胞及间质 |
| 中肾小管 | 睾丸输出小管；另有退化残迹 | 卵巢冠、卵巢旁体等残迹 |
| 中肾管（沃尔夫管） | 附睾管、输精管、精囊腺与射精管 | 卵巢冠纵管、加特纳管等残迹 |
| 副中肾管（苗勒管） | 大部退化，可留睾丸附件和前列腺小囊相关残迹 | 输卵管、子宫、子宫颈和阴道上部 |
| 尿生殖窦 | 尿道上皮、前列腺和尿道球腺等 | 尿道、前庭、尿道旁腺和前庭大腺，并参与阴道下部形成 |
| 生殖结节 | 阴茎背侧与龟头等组织 | 阴蒂 |
| 尿生殖褶 | 阴茎腹侧尿道与阴茎缝相关组织 | 小阴唇 |
| 阴唇阴囊隆起 | 阴囊 | 大阴唇 |
| 引带 | 睾丸引带 | 卵巢固有韧带和子宫圆韧带 |

表中的“同源”指这些结构分享胚胎原基，不表示成体大小、功能或调控完全对称。女性阴道的发生尤其涉及副中肾管尾端与尿生殖窦之间的连续重塑，不宜只用单一组织来源概括；男性前列腺小囊的来源也可能包含不同程度的副中肾管和尿生殖窦贡献。副中肾管形成、退化和分区的分子机制可参见 Mullen 与 Behringer 的综述。[^mullerian-genetics]

## 精巢下降、卵巢位置与精索 { #gonad-descent }

哺乳动物精巢位置可按成体解剖分为三类。**腹腔留睾**或 testicondy 指精巢终生位于腹腔内；**下降但无阴囊**指精巢移至腹壁后部、腹股沟附近或皮下区域，却没有悬垂的阴囊；**阴囊精巢**则经腹股沟区进入阴囊。旧式教材常把单孔类、象、蹄兔、鲸类、海牛、犀、河马、啮齿类和多数其他兽类排成固定序列，其中混合了彼此差异很大的状态。较稳妥的办法是对每个物种分别记录精巢位置、阴囊有无、腹股沟管是否开放以及季节性移动。

系统发育研究支持胎盘类祖先已经具有精巢下降能力，非洲兽总目若干支系后来独立丢失了参与下降的基因和结构；鲸类等其他支系也出现次生的腹腔位置。[^testis-descent-evolution] 一些啮齿类和食虫类的精巢在繁殖季进入阴囊或皮下位置，非繁殖季回缩，这种可逆移动应与胚胎期、出生前后发生的永久下降分开。位置变化与体温、附睾环境、运动方式和腹压等因素有关，但不能用一个单因子解释全部哺乳动物。

阴囊精巢由**精索**与腹腔相连。精索不只是“血管和神经”：其中包括睾丸动脉、蔓状静脉丛、输精管及其血管、淋巴管、自主神经、提睾肌纤维和结缔组织包膜；发育早期的腹膜鞘突闭合后可留下鞘膜。蔓状静脉丛与睾丸动脉形成逆流热交换，提睾肌和肉膜改变精巢与体表距离，共同调节局部温度。

卵巢也会从胚胎后腹壁附近移动，但通常被子宫的形成和引带附着所限制。引带在卵巢与子宫之间形成卵巢固有韧带，在子宫与腹股沟或大阴唇方向形成子宫圆韧带。不同哺乳动物的卵巢可位于腰区、盆腔入口或更靠后的盆腔内，位置差异与子宫角、卵巢囊和系膜共同决定标本中的相对关系。

## 标本与切片的观察次序 { #observation }

观察完整标本时，先确定前后轴和泄殖腔或尿殖孔，再寻找性腺与肾的相对位置。随后沿管道连续追踪：雄性从睾丸输出区追向中肾管、输精管或独立生殖孔，雌性从输卵管漏斗追向腺性管段和末端开口。只有把管道真正追到开口，才能区分输尿管、输精管、输卵管和肠管。对鸟类输卵管、鲨类壳腺和哺乳动物附属腺，还应记录管壁厚度、腺体分区与管腔内容物。

切片观察先判断组织单位。睾丸中辨认精小叶或曲细精管、支持细胞区和间质；卵巢中辨认卵母细胞、卵泡细胞层、膜层、黄体或排卵后结构。性腺处于繁殖季还是静止期会显著改变大小和组织外观，幼体的未分化性腺也不能套用成体标准。最后把性腺组织、管道连接、附属结构和生殖季节合在一起，才可判断个体的生殖状态。

配子发生、减数分裂和卵泡发育的细胞学过程见[配子发生](../../development/gametogenesis.md)，激素轴、妊娠和分娩的功能调节见[生殖生理](../../physiology/reproductive.md)。
