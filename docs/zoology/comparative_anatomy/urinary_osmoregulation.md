# 排泄与渗透调节系统

脊椎动物的排泄系统把蛋白质和核酸代谢产生的含氮物质送出体外，同时调节水、无机离子、酸碱和体液容量。肾脏是这套系统的中心，却从不单独工作：水生脊椎动物的鳃、皮肤和肠道直接面对外界水体，陆生类群还可借皮肤、泄殖腔、膀胱、后肠和盐腺改变最终的水盐收支。比较解剖所见的肾小球、肾小管、肾管和储尿囊，正是过滤血液、修饰滤液、运输尿液和在排出前再次交换水盐的不同层次。[^comparative-renal-texts]

排泄、渗透调节和尿液形成因而不能视作同义词。氨可以大量跨鳃排出，不一定先进入尿；软骨鱼将尿素保留为渗透物，又必须由肾脏反复回收；鸟类肾脏排出的液体进入泄殖腔和后肠后还会继续改变。阅读标本时应先找交换面和血流，再沿肾单位、集合通路与出口追踪，最后联系动物所处的淡水、海水或陆地环境。

## 肾单位的共同结构 { #nephron-structure }

典型肾单位由肾小体和肾小管构成。肾小体包括毛细血管球和包绕它的肾小囊；肾小囊的脏层细胞即足细胞，壁层围成囊壁，两层之间的囊腔接收滤液。入球小动脉把血送入毛细血管袢，血液再经出球小动脉离开。入、出球血管阻力、毛细血管压力、血浆胶体渗透压和可用滤过面积共同决定滤过，不宜只用“入球较粗、出球较细”解释肾小球高压。

血浆水从毛细血管进入囊腔时，依次跨过有窗内皮及其表面层、肾小球基底膜和足细胞足突间的裂隙膜。血细胞和大部分血浆蛋白被保留，小分子与水形成超滤液。原素材所说“原尿通过肾小囊脏层”抓住了足细胞的位置，却遗漏内皮和基底膜共同组成的滤过屏障；滤过选择性也由分子大小、形状、变形性和屏障状态共同决定。[^glomerular-barrier]

滤液随后进入近端小管，经中间段或髓袢、远端小管和连接段抵达集合系统。近端小管承担大宗重吸收和有机离子分泌，远端各段精细调整离子与酸碱；有亨利袢的肾单位还能把管液处理同髓质渗透梯度联系起来。严格按发生来源，集合管由肾管系统出芽形成，不属于肾单位本体，但它与肾单位连续并决定终尿组成。各段的定量转运见[肾小球滤过与肾小管转运](../../physiology/urinary/filtration_transport.md)，本页保留比较形态所需的基本通路。

肾排泄量可概括为滤过量减去重吸收量再加上分泌量。管壁并非被动水管：同一物质可在不同区段被取回或加入管腔，肾小管周围的毛细血管则接收重吸收物并提供待分泌物。肾小球滤过和小管转运的组合，使一枚外形相似的肾能够在不同盐度、饮水量和含氮代谢状态下产生很不相同的尿。

## 肾血流与肾门静脉系统 { #renal-blood-supply }

肾动脉分支形成入球小动脉和肾小球毛细血管，出球小动脉再形成管周毛细血管。哺乳动物的肾小球与管周血管均来自这一动脉通路；出球小动脉夹在两张毛细血管网之间，使前者适合滤过、后者适合重吸收。所谓“两次形成毛细血管网”应落实为这条连续血路，而不是由两套互不相干的血管分别完成。

多数真骨鱼、两栖动物、非鸟爬行动物和鸟类还保留肾门静脉系统。来自尾部、后肢或后躯的部分静脉血可进入肾脏并汇入管周血管，肾动脉仍是肾小球入球血管的来源。肾门静脉血因而主要影响小管周围灌流、分泌和血流分配，并不取代肾动脉向肾小球供血。分流支、瓣和门静脉系统的发达程度随类群而变；圆口类和哺乳动物缺少典型成体肾门静脉系统。[^vertebrate-renal-circulation]

## 前肾、中肾、后位肾与后肾 { #kidney-series }

脊椎动物肾脏由体轴两侧的中间中胚层或肾发生区建立，沿前后轴分批形成肾单位。传统“全肾”或“原肾”设想一列肾小管沿大部分躯干逐节排列，每条小管以纤毛肾口通向体腔，再汇入共同纵行肾管。这个模型有助于理解肾口、外血管球和肾管关系，却不是所有现生脊椎动物都曾具备的一枚完整成体器官，也不能直接拿盲鳗或蚓螈幼体充当未经变化的“祖型”。

### 前肾 { #pronephros }

前肾在肾发生区最前端形成，肾小管数目少，常保留开向体腔的纤毛肾口。某些幼体的毛细血管集中成突入体腔的外血管球或血管丛，滤液先进入体腔，再由肾口收集；另一些前肾已经把足细胞与毛细血管组织成较紧密的肾小体。前肾管向后生长并开入泄殖腔，后续肾小管可继续接入这条纵行管道。

鱼类胚胎和两栖幼体的前肾可以实际滤过和调节水盐，适合自由生活的早期阶段；在羊膜动物胚胎中，前肾常很短暂或不具明显泌尿功能。前肾不等于“低等成体肾”，同一套分段转运基因在蛙前肾、鱼前肾和哺乳动物后肾中仍表现出深层保守性。[^vertebrate-nephrogenesis]

### 中肾与后位肾 { #mesonephros-opisthonephros }

中肾小管在前肾后方形成并接入已建立的肾管。其近端形成肾小囊和内血管球，肾口可在早期保留，随后多缩小或消失；肾小管仍按体轴次序发生，并非一开始便“完全不分节”。羊膜动物的胚胎中肾在后肾建立前短期泌尿，之后大部分退化，部分小管和中肾管进入雄性生殖通路。

圆口类、多数鱼类和两栖动物的成体肾继续在典型胚胎中肾之后加入更靠后的肾小管，形成后位肾或后位中肾（opisthonephros）。传统教材常把它简称“中肾”，但后位肾包含更长的肾发生区和后续添加的肾单位；区分这两个名称，能够同时保留胚胎阶段和成体形态。

### 后肾 { #metanephros }

爬行类、鸟类和哺乳动物的永久肾是后肾。后肾间充质产生肾单位上皮，输尿管芽从中肾管尾端附近长出，反复分支形成输尿管、肾盂、肾盏和集合管系统，并以相互诱导使邻近间充质形成肾单位。原素材所称“后肾芽基”和“后肾管芽”可分别对应后肾间充质与输尿管芽；后者不是单纯排水导管，而是整套集合树的发生来源。[^metanephric-development]

后肾肾单位不再以开放肾口连通体腔，滤液由内血管球直接进入肾小囊。后肾与后位肾的差别也不只是肾单位数目增多：两者的体轴位置、集合系统、独立输尿管和成体生殖管分工均不同。用“前肾—中肾—后肾”描述羊膜动物发生很方便，但它不是现生类群由简单到高级的重复阶梯。

## 肾管、输尿管与生殖管的分工 { #urinary-ducts }

前肾管随中肾小管接入而成为中肾管、原肾管或沃尔夫管。它在水生无羊膜脊椎动物中常继续排尿；雄性软骨鱼和两栖动物的部分肾小管又与精巢输出小管相接，使同一历史管道进入精子运输。成熟雄鲨鳐通常以中肾管输精，后部泌尿肾则另由副输尿管排尿；许多真骨鱼的生殖管已经与输尿通路分开。具体分工应按性别和支系逐项观察，不能把“中肾管既输尿又输精”写成所有鱼和两栖动物的固定状态。

副中肾管或牟勒管沿中肾管外侧形成，在多数四足动物中由体腔上皮内陷并向后延伸，而不是简单由中肾管纵裂出一半。它主要形成雌性输卵管及其后续分化；雄性是否保留残迹、前端是否开向体腔以及末段怎样汇入泄殖腔均有类群差异。后肾出现后，输尿管芽形成独立输尿管，中肾管便可在羊膜动物雄性中专门化为附睾管、输精管等生殖通路。更完整的性别去向由下一页[生殖系统](reproductive.md)承接。

## 膀胱与排尿前的再次调节 { #urinary-bladder }

“膀胱”在比较解剖中指能暂存尿液的囊状结构，却不保证各类群同源。许多硬骨鱼由输尿管末段、共同尿管或尿生殖窦扩张形成导管性尿囊；两栖动物和部分爬行动物的膀胱从泄殖腔腹侧伸出；龟鳖、部分蜥蜴和哺乳动物的膀胱又与胚胎泄殖腔—尿囊柄系统密切相关。上皮多来自内胚层性泄殖腔区域，平滑肌与结缔组织来自中胚层，单用“内胚层膀胱”或“中胚层膀胱”概括整枚器官会混淆组织层次。比较资料支持脊椎动物储尿囊曾不止一次独立形成。[^vertebrate-bladder]

圆口类和软骨鱼通常没有独立大膀胱，尿可在尿生殖窦或管道末端短暂停留。许多鱼有导管性储尿扩张，肺鱼和两栖动物常有与泄殖腔相通的腹侧膀胱；龟鳖和许多蜥蜴有膀胱，蛇和鳄类没有。多数鸟没有独立膀胱，输尿管开入泄殖腔；鸵鸟能把尿储存在扩大的粪道，并与粪便分开排放，但粪道在组织和发生上仍不是哺乳动物式膀胱。[^ostrich-coprodeum]

储尿并非膀胱的唯一作用。鱼类膀胱样结构、两栖动物膀胱以及爬行动物泄殖腔和膀胱都可继续交换水与离子；脱水的蛙能把稀尿逆向送入膀胱并回收水。鸟类也可使泄殖腔尿逆向进入结肠或盲肠，进行排出后的水盐回收。下尿路是否存在、上皮通透性怎样以及尿能否回流，共同决定“肾形成的尿”和“最终排出的物”之间有多大差别。

## 氨、尿素与尿酸 { #nitrogenous-wastes }

氨、尿素和尿酸是三类主要含氮终产物。氨生成成本低，在水中以 NH$_3$／NH$_4^+$ 平衡存在，许多水生动物可借鳃或体表持续排出；高浓度氨会干扰酸碱和细胞功能，因此需要足够水量或专门转运。尿素由含氮基团和 CO$_2$ 合成，毒性较低、易溶于水，既可排泄，也能参与肾髓质浓缩或软骨鱼渗透调节。尿酸合成耗能较多、溶解度低，可连同 Na$^+$、K$^+$ 等形成尿酸盐沉淀，以较少水分储存在封闭卵的尿囊或排出体外。[^nitrogen-end-products]

把三种产物分别贴在“硬骨鱼—软骨鱼和哺乳类—爬行类和鸟类”上，只能作为入门轮廓。多数水生真骨鱼主要排氨，离水、缺氧、胚胎发育和食性可改变尿素比例；海生鲨鳐虽合成并保留大量尿素，仍需排出一部分含氮物。两栖幼体多排氨，许多陆生成体转向尿素。哺乳动物以尿素为主，仍排尿酸、铵和其他含氮物；许多爬行动物与鸟类以尿酸盐为主，水生龟鳖、鳄类及不同水状态下的个体可增加氨或尿素比例。排氮方式是可调的代谢组合，不是纲级单选性状。

含氮产物还与其他功能耦联。鱼鳃排 NH$_3$／NH$_4^+$ 同 H$^+$、Na$^+$ 转运相互作用，参与酸碱和离子调节；鲨鳐保留尿素提高体液渗透浓度，并以氧化三甲胺等有机渗透物稳定蛋白质；哺乳动物髓质尿素循环支持浓缩尿。判断一种产物的意义时，需要同时询问它在哪里合成、由哪一表面排出、是否被肾回收，以及动物需要保存多少水。

## 无颌与有颌脊椎动物的逐类比较 { #vertebrate-comparison }

### 文昌鱼的肾管与有管足细胞 { #amphioxus-nephridia }

文昌鱼在咽区背侧排列许多短肾管，肾管一侧与体腔或邻近组织相关，另一侧开入围鳃腔。传统所称有管细胞或管细胞具有足细胞样基部和伸入管腔的鞭毛—微绒毛装置，现代常称 cyrtopodocyte；其足突靠近血管并形成滤过裂隙，鞭毛帮助管腔液流动。幼体早期还有位于帽腔附近的 Hatschek 肾。

早期胚层判定曾把文昌鱼肾管归为外胚层。连续电镜重建与发生研究显示，肾管至少主要由中胚层性细胞形成，幼体期可见与邻近体腔相连的开口，成体连接又可能关闭。文昌鱼肾管同时呈现原肾管式末端细胞和足细胞式滤过结构，适合做形态比较，却不能直接当作一枚缩小的脊椎动物前肾。[^amphioxus-kidney]

### 圆口类 { #cyclostome-kidney }

七鳃鳗的沙隐幼体以功能性前肾开始生活，随后在后方添加肾单位，变态时建立延长的后位肾作为成体主要泌尿器官。成体前肾区可保留血管球、纤毛肾口和淋巴样组织，但常已退化，不能用“成体头肾就是前肾并承担全部排泄”概括。不同七鳃鳗的海水、淡水和洄游阶段还会改变肾小球滤过、尿量与鳃离子运输。

盲鳗成体肾沿体轴呈显著节段性，每个大肾小体与短肾小管接入纵行肾管，保留接近传统原肾模型的外观。其体液渗透浓度接近海水，无机离子组成仍受鳃、皮肤和肾脏选择性调节。圆口类肾脏内部差异说明“盲鳗与七鳃鳗都有终生前肾”并不准确；前部肾组织、后位肾和生活史阶段必须分别辨认。[^lamprey-kidney]

### 软骨鱼 { #chondrichthyan-kidney }

鲨鳐成体的后位肾沿背侧延伸。雄性前部肾区可形成与生殖相关的附睾肾或莱氏腺，分泌液进入输精通路；后部泌尿肾由副输尿管排尿。雌性管道分工不同。莱氏腺失去典型泌尿功能后仍有分泌作用，不能只记作“无功能的肾前端”。

海生鲨鳐在体液中保留高浓度尿素与氧化三甲胺，使总渗透浓度接近或略高于海水，而 NaCl 浓度仍低于海水。肾小管高效回收尿素，鳃限制尿素流失；直肠腺把富含 NaCl、尿素很少的分泌液送入直肠，排除扩散和食物带入的盐。淡水魟和广盐鲨会降低尿素池并重设鳃、肾与直肠腺运输，软骨鱼也并非只有一套恒定海水方案。[^elasmobranch-osmoregulation]

### 硬骨鱼 { #bony-fish-kidney }

成体躯干肾通常是后位肾，贴近脊柱腹侧。真骨鱼前端的头肾多已成为造血、免疫和内分泌组织，泌尿肾单位集中在躯干部；把头肾称作“退化前肾”会遗漏其成熟功能。输尿管末端可形成多种尿囊或膀胱样扩张，多数真骨鱼的生殖管又与泌尿管分开。鳃离子细胞有时旧称“泌氯腺”，它们是鳃上皮细胞系统，并非硬骨鱼肾脏内的一枚腺体。

淡水真骨鱼体液高渗于环境，水不断进入、盐不断丢失，通常以高滤过和大量稀尿排水，鳃主动吸收 Na$^+$、Cl$^-$、Ca$^{2+}$ 等离子。海水真骨鱼体液低渗于环境，需要饮海水，食管和肠道吸收水与单价离子，鳃排出多余 NaCl，肾以少量尿排出 Mg$^{2+}$、SO$_4^{2-}$ 等二价离子。广盐鱼迁移时改变肾小球滤过、肾小管转运、饮水、肠吸水和鳃离子细胞，同一器官网络可在两种状态间重塑。少数海生真骨鱼的肾小球显著缩小，甚至形成无肾小球肾；这类肾仍以小管分泌和重吸收排出二价离子与代谢物，不能把“没有肾小球”理解成没有功能性肾脏。[^teleost-renal-osmoregulation]

### 两栖动物 { #amphibian-kidney }

两栖动物幼体以功能性前肾开始，成体主要使用后位肾。蛙的成对扁长肾贴附体腔背壁，雄体前部肾小管可与精巢输出管相接，中肾管承担精子与尿的时空分流；雌体输卵管与泌尿通路分开。有尾类和蚓螈的肾单位分布、性区和管道分离程度各异，不能只用蛙的图谱代表全纲。

水分充足时，许多两栖动物排出大量低渗尿；脱水时降低滤过，并从膀胱、腹侧饮水区和皮肤回收水与离子。皮肤通透性、精氨酸加压催产素调节的水通道和膀胱容积共同决定水平衡。幼体常主要排氨，陆生成体多提高尿素合成，食蟹蛙等耐盐物种还可积累尿素提高体液渗透浓度。传统“水中排氨、陆上排尿素”保留为生活史主线，同时要看到种间和环境差异。[^amphibian-water-balance]

### 非鸟爬行动物 { #reptile-kidney }

爬行动物成体后肾位于体腔后部，输尿管独立开入泄殖腔。肾单位没有亨利袢，肾脏通常不能形成显著高渗于血浆的尿；降低滤过、肾小管回收、尿酸盐沉淀以及泄殖腔、后肠或膀胱的排出后调节共同节水。龟鳖和许多蜥蜴有膀胱，蛇和鳄类没有，水生龟鳖的含氮产物又可包含较多尿素或氨。

海龟眼眶盐腺、海鬣蜥鼻盐腺、海蛇舌下盐腺和鳄类舌盐腺可排出肾脏难以浓缩的盐负荷。盐腺、尿酸和低滤过率各自解决不同问题，不应合并成“爬行动物肾能高度浓缩尿”。雄性有鳞类的肾还可出现受雄激素调节的性区，提醒解剖者把泌尿组织与生殖季节联系起来。[^reptile-renal-physiology]

### 鸟类 { #avian-kidney }

鸟的后肾嵌在综合荐骨腹侧肾窝中，常分前、中、后三部分。每个肾小叶含大量无亨利袢的皮质型肾单位，以及比例较低、具有短袢或较长袢的髓质型肾单位；有袢肾单位和集合管束进入髓质锥，可使尿液一定程度高渗于血浆。原素材“鸟类无髓袢”只适用于无袢的爬行类型肾单位，遗漏了鸟肾特有的混合构造。[^avian-nephron-types]

输尿管直接开入泄殖腔，多数鸟无独立膀胱。尿酸盐在小管和泄殖腔内容物中形成白色半固体部分，泄殖腔—后肠逆流又回收水盐。海鸟和一些荒漠鸟以眶上盐腺排出高浓度 NaCl。鸟类的浓缩能力来自有袢肾单位、集合管、肾门静脉、泄殖腔后处理和盐腺的整体配合，不能用“尿酸省水”单独解释。

### 哺乳动物 { #mammalian-kidney }

哺乳动物后肾通常有清楚的皮质和髓质。肾门是肾动脉、肾静脉、神经、淋巴管和肾盂或输尿管进出的凹陷，门内的肾窦容纳肾盂、肾盏、血管、神经和脂肪。皮质因肾小体和盘曲小管丰富而呈颗粒状，肾柱伸入髓质；髓质因亨利袢、集合管和直小血管平行排列而呈条纹状。髓质灌流低于皮质却并非“缺少血管”，直小血管正是维持髓质梯度和组织供氧的重要组成。

集合管汇入乳头管，经肾乳头进入肾盏、肾盂和输尿管。牛肾外表分叶且为多乳头型，猪肾外表平滑但内部仍为多乳头型；马、犬和猫多为外表平滑、乳头融合为肾嵴的单乳头型，兔等许多小型哺乳动物也属于单乳头型，鲸类肾则常分成许多肾小叶。人体的“肾锥体—小盏—大盏—肾盂”是多乳头肾的一种具体构造，不能作为所有哺乳动物的统一外形。

亨利袢、集合管和直小血管建立逆流系统，袢长和髓质厚度影响最大浓缩能力。沙漠啮齿类长袢肾单位比例高、髓质厚，水生哺乳动物和大型兽类又有多种分叶方案。哺乳动物没有成体肾门静脉系统，输尿管进入真膀胱，尿道将尿排出；单孔类仍开入泄殖腔，兽类泌尿、生殖和消化出口的分隔则随性别和支系变化。尿素是主要含氮终产物，也参与髓质浓缩，完整机制见[尿液浓缩、清除率与排尿](../../physiology/urinary/concentration_clearance.md)。

## 标本、切片与示意图的观察次序 { #specimen-observation }

观察整枚肾时先确定它在脊柱或骨盆腹侧的位置，记录左右是否分开、前后延伸范围、表面是否分叶，并寻找与性腺、背主动脉、后主静脉或后腔静脉的关系。随后沿尿流寻找纵行肾管、输尿管、尿生殖窦、泄殖腔、膀胱或导管末端扩张。雄性标本须把输精管和副输尿管分别追到出口，不能只凭一根白色导管的外观命名。

观察切片时先找肾小体，再从血管极辨认入球、出球小动脉，从尿极追入近端小管。近端小管细胞高、刷状缘明显，远端小管腔较清楚；集合管边界整齐，管径沿汇合方向增大。前肾切片还要寻找体腔中的外血管球和具纤毛肾口，后位肾要结合沿体轴新增肾单位，后肾则需辨认肾单位与集合树的双重来源。只数“肾小球多少”不足以判断肾型。

比较渗透调节时最后把肾与肾外器官画在同一图上：鱼类加入鳃和肠，软骨鱼加入直肠腺，两栖动物加入皮肤和膀胱，爬行动物与鸟类加入泄殖腔、后肠和盐腺，哺乳动物加入亨利袢—直小血管系统。再标明水、单价离子、二价离子、氨、尿素和尿酸盐的主要方向，便能看出同一“排泄系统”怎样因环境而重组。
