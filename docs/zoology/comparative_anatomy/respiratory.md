# 鳃、鳔、肺与呼吸系统

脊椎动物把气体交换界面安置在咽部、前肠衍生的含气器官、皮肤或口咽黏膜上，再用颌、鳃盖、口底、肋骨、腹壁、膈和气囊等不同泵送结构更新交换介质。鳃、鳔和肺因此不能只按“水生—陆生”的顺序记忆：鳃同时承担离子与含氮废物交换，鳔兼有浮力、听觉和发声功能，肺在肺鱼、两栖动物、羊膜动物中也分别嵌入不同的体腔和循环系统。比较解剖首先追踪开口、导管、鳃弓或支气管、交换薄壁和血流，再讨论通气方式与演化意义。[^comparative-respiratory-texts]

水流或气流的方向、血液经过交换面的方向、推动介质的泵，以及真正发生扩散的组织，是四个彼此相关而不相同的层次。鱼鳃小片可形成水—血逆流，鸟的古肺旁支气管内维持单向气流而毛细血管构成横流交换，哺乳动物则以潮式气流更新盲端肺泡。它们都受表面积、屏障厚度、通气与灌流匹配以及介质物理性质限制；这些机制的定量分析见[气体交换与运输](../../physiology/respiratory/gas_exchange.md)，本页聚焦产生这些流路的形态结构。

## 咽鳃的共同构造 { #pharyngeal-gills }

咽鳃建立在一系列咽弓和咽裂上。相邻咽裂之间的组织柱构成咽弓，弓内包含软骨或骨性支架、肌肉、神经和血管；鳃丝从弓或鳃间隔表面伸出，鳃丝两侧再排列薄板状次级鳃小片。一个鳃弓一侧的鳃组织称半鳃，两侧半鳃合称全鳃。入鳃血管把低氧血送入鳃小片的柱细胞毛细血管网，出鳃血管汇集交换后的血。面向口咽腔的一侧常有鳃耙，负责阻挡大颗粒或参与滤食，不能与交换用鳃丝混称。

鳃上皮的发生曾是判断圆口类与有颌类鳃是否同源的争论核心。圆口类鳃长期被认为来自咽内胚层，而有颌类鳃被归为外胚层结构；对小鳐的咽内胚层谱系标记显示，内、外鳃丝都由内胚层上皮产生，支持脊椎动物咽鳃在圆口类与有颌类分开前已经出现。表面外胚层仍参与咽沟、裂口外侧和邻近信号，神经嵴与中胚层则形成鳃弓支架、结缔组织、肌肉和血管。因而“鳃来自内胚层”应理解为交换上皮的主要谱系结论，不是整枚鳃只含一种胚层。[^gill-origin]

### 圆口类的鳃囊

七鳃鳗咽腹侧形成一条前端为盲端的呼吸管，每侧通常有七个内鳃孔分别通入七个鳃囊，鳃囊内壁形成密集鳃褶，再由短管经七个外鳃孔开向体表。鳃囊外侧的软骨鳃篮支撑整个区域，却不形成有颌鱼那种每条咽弓内独立、清楚分节的鳃弓骨架。自由游泳时水可从口进入呼吸管并由鳃孔排出；吸附摄食时口被封住，鳃囊肌使水从外鳃孔吸入、再从外鳃孔排出，潮式水路保证持续附着时仍能换气。

盲鳗也有袋状鳃囊，但数目随属种变化，通常约五至十六对。黏盲鳗属的出鳃管可各自开口，盲鳗属则常汇入共同出鳃管，使体表每侧仅见一个外孔；外孔数不能直接代替鳃囊数。水常由正中鼻孔经鼻咽管进入咽，再流过鳃囊排出，口也可参与进水。传统“无颌类均有七对鳃囊和呼吸管”实际只完整对应七鳃鳗，不涵盖盲鳗的鼻咽水路和可变鳃孔。

### 软骨鱼的鳃间隔与独立鳃裂

板鳃类的鳃间隔很长，鳃丝沿隔的前、后面排列，游离端通常不超过鳃间隔外缘。多数鲨有五对鳃裂，六鳃鲨和七鳃鲨等可有六至七对；鳐类的鳃裂移到腹面。第一咽裂的残余可形成喷水孔，眼后喷水孔在底栖鲨鳐中常把较清洁的水引入咽腔，在高速游泳鲨类中可缩小或消失。喷水孔壁的假鳃保留鳃样组织，但血流与功能已经特化，常参与眼和脑部血供调节。

许多鲨以口—咽泵和鳃腔肌共同驱动水流；部分持续游泳种还利用前进造成的冲压通气。冲压通气和主动泵可随速度、溶氧及行为互相补充，并不是“鲨必须不停游，否则立刻窒息”的全类群通则。全头类的鳃间隔外侧覆有皮褶，水由共同鳃盖孔排出，显示有鳃盖外观并非真骨鱼独有。

### 硬骨鱼的鳃盖腔

多数真骨鱼有四对主要全鳃。鳃间隔缩短，鳃丝大部成为游离梳状结构，外侧由骨性鳃盖和鳃条膜围成共同鳃盖腔。口腔扩大时口阀开放、鳃盖后缘阀关闭，水进入口咽；随后口阀关闭，口腔和鳃盖腔的压力差把水连续推过鳃小片并从鳃盖后缘排出。口泵与鳃盖泵的相位重叠，使水流比“吸一口、停一下、再压出”的分段图式更连续。

非真骨硬骨鱼保留多种中间组合。鲟、雀鳝和弓鳍鱼有鳃盖，同时在喷水孔、鳃间隔长度、鳃数和空气呼吸器官上各不相同。非洲和南美肺鱼依赖肺呼吸，成体鳃瓣显著缩减，常只有部分鳃弓保留发达鳃丝；澳洲肺鱼的水呼吸鳃保留较完整。原素材“非洲肺鱼只有两对鳃瓣”可作为 *Protopterus* 的典型解剖线索，不能扩展成全部肺鱼的固定公式。

### 鳃小片中的逆流交换

次级鳃小片由很薄的上皮覆盖，内部柱细胞形成扁平血隙。水沿小片表面流动时，血液大体沿相反方向通过，使每一段血液都遇到氧分压较高的水，沿程维持扩散梯度。逆流描述的是局部水—血排列；整枚鳃内还有分流、短路、鳃丝间速度差和活动性灌流调节，因此不能把它理解成所有水与所有血完全平行、速度恒定的理想管道。[^gill-morphology]

鳃的薄屏障同时面对呼吸与内环境调节。富线粒体离子细胞传统上常称氯细胞，在海水鱼主要参与排出过量 NaCl，在淡水鱼则按细胞亚型吸收 Na$^+$、Cl$^-$ 和 Ca$^{2+}$；鳃上皮还交换 H$^+$、HCO$_3^-$ 和 CO$_2$，并排出大量氨或铵。黏液细胞保护表面， pavement cell 构成主要覆盖层。呼吸面积扩大有利于取氧，却也增加水盐和酸碱交换，鳃的形态与转运蛋白会随盐度、温度、缺氧和发育阶段重塑。把鳃旁细胞统称“泌氯腺”会遗漏淡水吸盐及酸碱、排氮功能。[^multifunctional-gill]

## 幼体鳃与体表交换 { #larval-external-gills }

外鳃从咽弓区域向体表伸出，中央有血管，外周分出细长鳃丝。它的基部仍与咽弓及相应主动脉弓相连，但伸出体外的交换枝缺少成体内鳃那种由完整鳃弓和鳃间隔包围的内部支架；“无支持骨”适合描述游离鳃丝，不能理解为整枚外鳃与骨骼、血管毫无联系。多鳍鱼和肺鱼幼体、许多有尾类幼体以及无尾类蝌蚪都能见到外鳃，这是不同支系在水生早期阶段反复保留或建立的交换形式。

典型无尾类幼体先在三对后部咽弓上长出羽状外鳃。若把颌弓、舌弓列入总序列，传统教材常称第 3、4、5 对咽弓；若只编号鳃弓，则是前三对鳃弓。随后舌弓后方的鳃盖褶向后覆盖外鳃，形成鳃腔，外鳃逐步被内鳃取代；多数蝌蚪最后只保留左侧出水孔。内鳃与相应血管在变态期退化，肺、皮肤和口咽交换承担成体呼吸。不同无尾类的鳃盖孔数、鳃保留时间和直接发育程度仍有变化。蟾蜍幼体的三维研究也显示外鳃被鳃盖褶覆盖、内鳃一直保留到变态高潮的连续过程。[^tadpole-gills]

有尾类幼体常保留三对明显外鳃，洞螈、泥螈和美西螈等终生水生或幼态持续种成体仍可保留。陆生蝾螈在变态时吸收外鳃，有些有肺，有些无肺螈科连肺也丢失，主要依靠湿润皮肤和口咽黏膜交换。胚胎或幼体具有咽囊不等于成体一定有鳃；哺乳动物咽囊与外侧咽沟接近但通常不贯通为功能性鳃裂，第一咽膜参与形成鼓膜，其他咽区组织迁移形成中耳、扁桃体、胸腺和甲状旁腺等结构。

皮肤交换在许多鱼和两栖动物中与鳃、肺并存。交换比例取决于皮肤厚度与湿润度、温度、溶氧、活动、潜水和季节。水下越冬的蛙类可显著依赖皮肤，肺通气频率降低；这不是“两栖类冬眠时一律只用皮肤”的器官开关。卵膜、卵黄囊或外鳃还可在胚胎期承担交换，说明同一物种一生中也会改变主要呼吸界面。

## 肺与鳔的前肠关系 { #lung-gas-bladder-homology }

肺与鳔都由咽后或前肠相关上皮出芽，具有可比较的平滑肌、弹性组织、血管和表面活性物质系统。现生分布、出芽方位和发育基因共同支持：肺是硬骨脊椎动物祖先已经具有的含气器官，辐鳍鱼中除多鳍鱼以外的 Actinopteri 支系把这一器官改造成背侧出芽的鳔。多鳍鱼的成对肺从前肠腹侧发生；肺鱼与四足动物的肺也总体腹侧出芽，弓鳍鱼和真骨鱼的鳔则从背侧发生。肺与鳔在器官层面同源，却不是一枚现生鱼鳔直接搬到腹侧便成为四足动物肺。[^lung-gas-bladder-evolution]

早期肺究竟是一枚正中囊还是一开始便成对，仍受现生取样、胚胎阶段和软组织化石稀缺限制。澳洲肺鱼只有一枚肺，非洲与南美肺鱼有成对肺；现生腔棘鱼胚胎形成一枚退化肺，成体还另有脂肪性含油器官。传统“肺由鱼鳔演化而来”的时间方向应改为共同前肠器官在不同辐鳍鱼支系中转成鳔，而肺在多鳍鱼、肺鱼和四足动物谱系中保留并各自专化。分子表达增强这套形态解释，但判断仍须结合出芽位置、导管和血供。

## 鳔的结构与多重功能 { #gas-bladder }

鳔通常位于消化管背侧、肾脏腹侧，可为一室、前后两室或分成更多区，形状随体腔、椎体和内脏布局改变。软骨鱼没有与硬骨鱼鳔同源的背侧含气囊；许多底栖鱼、持续高速游泳鱼和深海鱼也独立缩小或丢失鳔。鮟鱇、鲭、鲐和部分金枪鱼可作为常见例子，但同一科内也可能有差异，鳔的有无不能由“底栖”或“快速”单独推出。

### 开鳔、闭鳔与气体调节

开鳔类或管鳔类成体保留连接食管的鳔管，可到水面吞气充鳔，也可经口排气；鲱形、鲤形、鲑形、鲟、雀鳝和弓鳍鱼中可见这一状态。旧材料中的“喉鳔类”应校作管鳔类或开鳔类，肺鱼的器官则是肺，不应列作开鳔鱼。闭鳔类的成体鳔管关闭，常见于许多棘鳍类鱼；旧广义“鲈形目”包含大量已拆分支系，只能作为历史例举。部分鱼幼体有鳔管、成体关闭，开闭状态也不是两个永不转换的等级。

闭鳔鱼主要从血液向鳔腔分泌气体。气腺产生乳酸和 CO$_2$，使局部血液酸化并通过血红蛋白 Root 效应释放 O$_2$；成束折返的奇网以逆流倍增维持高分压，O$_2$ 才能进入深水高压下的鳔腔。放气时卵圆区血流增加，气体扩散回血液。气腺、奇网、血红蛋白和卵圆区共同工作，“红腺直接泵氧”漏掉了物理梯度与血液性质。部分开鳔鱼也能经血液调节鳔气，吞气与气体分泌并非绝对互斥。[^swimbladder-physiology]

### 浮力、空气呼吸、听觉与发声

鳔改变鱼体平均密度，使鱼在一定深度附近减少持续升沉所需的肌肉功。下潜时外压升高、鳔被压缩，鱼会暂时变得更重；上浮时鳔膨胀，闭鳔鱼若来不及吸收气体还可能发生过度膨胀。鳔调节的时间尺度和深度变化速率因此共同决定浮力，不能把它当成即时推动身体的升降舵。

一些开鳔鱼的鳔仍是重要空气呼吸器官。雀鳝、弓鳍鱼和巨骨舌鱼等可吞气进入富血管鳔，多鳍鱼使用真正的肺；泥鳅后肠、斗鱼迷器和弹涂鱼皮肤又是独立形成的空气呼吸界面。肺鱼、总鳍鱼和“有鳔鱼”不能仅凭都会吞气归作同一种器官。

鳔壁受鼓肌或邻近肌快速牵动可发出求偶、领域和警戒声，也能接收水中压力波。骨鳔类的韦伯氏器以一串特化前椎骨连接鳔与内耳，鲱形类等还有其他鳔—耳联系；听觉增强不限于旧称鲤形目。是否发声、怎样传声以及听觉频带取决于鳔形、前端突起、骨链和内耳连接，不能从鳔存在本身直接推断。

## 肺的共同组织框架 { #lung-organization }

肺的上皮由前肠内胚层建立，周围平滑肌、软骨、结缔组织、血管和胸膜主要来自侧板中胚层。肺芽经喉门与咽相通，向后形成喉气管区、气管、支气管或类群特有的肺内管道。肺入口、主气道分支、交换组织和末端储气区应分别观察；一枚外形似囊的肺，内部仍可有隔膜、肺小梁和分区血供。

传统教材常把两栖类称“囊状肺”、爬行动物称“蜂窝或海绵肺”、鸟称“管状海绵肺”、哺乳动物称“泡状海绵肺”。这些词能提示切面外观，却把不同尺度混在一起。两栖和多数非鸟爬行动物的肺壁小室称肺窝或 faveoli，通常向中央腔开口；鸟的交换单位是旁支气管周围的气毛细管；哺乳动物的终末交换单位才是肺泡。三者不宜全部翻成“肺泡”，也不构成从简单到高级的直线序列。

## 两栖动物的复合呼吸 { #amphibian-respiration }

两栖动物把鳃、皮肤、口咽黏膜和肺按生活史与环境组合。无尾类成体肺通常成对，内壁由一级、二级隔膜形成蜂窝状肺窝；有尾类肺常较细长、内部分隔较少，蚓螈类常因身体延长而左右不对称。无肺螈科完全丢失肺，部分水生有尾类保留外鳃，说明“有尾类均有简单囊状肺”只描述常见形态。

蛙的外鼻孔开启、口底下降时，空气进入口咽腔；鼻孔关闭、声门开启、口底上升时，口咽腔正压把空气送入肺。呼气可利用肺和体壁弹性，也可由轴下肌收缩提高体腔压力；新旧气体在口咽腔中的流路并非完全混匀。幼年虎纹钝口螈的 X 射线研究显示，吸气采用两冲程口腔泵，呼气则由四层轴下肌主动完成，说明“咽式呼吸”背后仍有不同肌群和相位。[^amphibian-ventilation]

皮肤毛细血管与湿润表面适合持续交换，口咽黏膜在口底小幅振荡时也可换气。肺更多承担空气中的 O$_2$ 摄取和浮力调节，皮肤对 CO$_2$ 排出的贡献常较大，但比例会随物种、温度、活动和水陆状态改变。变态、越冬和潜水是呼吸界面重新加权，不是按季节把某个器官完全关掉。

## 非鸟爬行动物的肺与通气泵 { #nonavian-reptile-respiration }

羊膜动物肺的主支气管入口通常位于肺前端以下，肺内大隔把器官分成若干腔，小隔再扩大交换面。比较发生资料显示，多室构造很可能已经存在于早期羊膜动物；许多蜥蜴、蛇和楔齿蜥成体看似单室，是生长时肺腔扩张、早期分支轮廓变浅后的专化状态。按单室、少室、多室记录肺内结构，比把“楔齿蜥和蛇蜂窝、蜥蜴龟鳄海绵”列成固定等级更能对应真实形态。[^amniote-lungs]

蜥蜴多以肋间肌改变躯干容积，形成负压吸气；部分种在运动或缺氧时还用口咽泵辅助。变色龙肺后部可形成细长囊状憩室，参与储气、体形展示和压力变化，但它们是肺的尾侧延伸，不具鸟类多组气囊—旁支气管系统。蛇体形延长后常由右肺承担主要交换，左肺在许多进阶蛇类缩小或消失；蚺、蟒等仍保留两肺，部分海蛇还形成沿气管延伸的交换区或后部气囊区。“蛇只有右肺”可作常见趋势，不能当作蛇亚目诊断。

龟鳖的肋骨并入甲壳，不能像多数羊膜动物那样以肋骨摆动扩张胸廓。背侧肺固定在背甲下方，腹斜肌、腹横肌等改变腹腔脏器和肢窝容积，使肺吸入、排出空气。化石与肌肉同源证据表明，这套腹肌泵在完整甲壳出现前已经形成。部分高度水生龟鳖还能利用咽部、皮肤或泄殖腔副膀胱进行水中交换；菲茨罗伊河龟的泄殖腔副膀胱有节律灌水和显著取氧能力，但这是一项物种或支系特化，不是所有龟都有的“泄殖腔鳃”。[^turtle-ventilation]

鳄类用肋骨—胸骨运动、耻骨旋转、腹壁和膈肌样肌共同通气。膈肌样肌从骨盆区域牵拉肝脏向尾侧移动，形成所谓肝活塞；肺后隔维持肺与腹腔之间的压力和支撑关系。它与哺乳动物膈在位置、附着和发生上不同，功能相似不等于同一块肌肉。

鳄类多室肺虽没有鸟类气囊，部分支气管内仍保持单向气流。随后草原巨蜥和绿鬣蜥也发现不同程度的净单向流，说明肺内气道几何本身可以整流，单向流既不以气囊为必要条件，也不是飞行出现后才有的鸟类专属性状。现有取样仍不足以断言所有爬行动物都采用同一流型；潮式更新、局部单向流和呼吸暂停可以在同一器官中并存。[^reptile-airflow]

## 鸟类的肺—气囊系统 { #avian-lung-air-sacs }

鸟肺体积变化很小，背侧嵌在胸椎与肋骨之间。气管分叉后，肺外主支气管进入肺内成为肺内主支气管，再发出背侧、腹侧和外侧次级支气管；次级支气管之间由大量旁支气管相连。旁支气管壁形成心房、漏斗和细密气毛细管，气毛细管与血毛细管交织成薄的气—血屏障。古肺区旁支气管在所有鸟中发达，新肺区的范围和流向随类群变化。

薄壁气囊从支气管系统伸出，常见九个：一枚不成对锁骨间气囊，以及成对颈、前胸、后胸和腹气囊。融合、缺失和分支在不同鸟中存在变化，气囊憩室还可进入椎骨、肋骨、肱骨等形成骨骼气腔化。气囊血管少、交换面积小，主要是改变容积的通气风箱和空气储库；真正交换面集中在刚性的肺。气囊参与蒸发散热、器官间隔和骨骼气腔化，但“减小比重、减少内脏摩擦、直接交换气体”都不足以单独概括其功能。[^avian-respiratory-system]

吸气时胸骨与肋骨运动扩大体腔，前、后组气囊同时扩张；呼气时气囊受压。经典“两次吸气、两次呼气”追踪的是一团示踪空气从尾侧气囊经过古肺旁支气管、进入头侧气囊再离体的平均路线，并不表示鸟完成一次有效换气后必须停等四个互不重叠阶段。连续呼吸时，新旧空气同时分布在肺和不同气囊，古肺旁支气管在吸、呼两相仍保持大体尾向头的单向流；新肺区则可有双向或更复杂流动。

旁支气管内气流与血毛细管总体近垂直，形成横流交换，多个毛细血管单位又沿气流逐级接触不同气体。单向通气、横流血气排列、薄屏障和高心输出共同支持飞行或高海拔活动，却不能用“鸟肺永远比其他肺高级”替代具体参数。鳄和蜥蜴的单向流、蝙蝠的肺泡肺以及企鹅等不会飞鸟的高代谢都显示，气流型、交换组织和运动方式可分别演化。

## 哺乳动物的支气管—肺泡系统 { #mammalian-lung }

哺乳动物气管由软骨环支撑，在肺门处分为左右主支气管，再经叶支气管、段支气管和更细支气管进入无软骨的细支气管。人类右肺三叶、左肺两叶，是人体的具体叶型；马、猪、反刍类、犬、啮齿类、灵长类和鲸类在叶裂、气管支气管、胸膜厚度和小叶间隔上都有差异。把人肺叶数当成哺乳纲通则会遮住这些重要的兽医和比较解剖性状。

在人和部分哺乳动物中，终末细支气管之后依次可见呼吸性细支气管、肺泡管、肺泡囊和肺泡。肺泡由极薄的Ⅰ型肺泡上皮与毛细血管构成主要交换屏障，Ⅱ型细胞分泌表面活性物质并参与上皮修复。鼠的终末细支气管可直接进入肺泡管，马缺少清楚的呼吸性细支气管，犬、灵长类和部分偶蹄类又有不同长度的过渡段；“三级—四级支气管—终末—呼吸细支气管—肺泡”的固定链条只适合某些代表，不能套用全部哺乳动物。[^mammalian-distal-airways]

膈收缩时穹隆下降，外肋间肌等使胸廓扩张，胸膜界面把压力变化传给肺，形成吸气；安静呼气主要依靠肺和胸壁弹性回缩，用力呼气再募集腹肌与内肋间肌。所谓胸式与腹式呼吸描述不同状态下胸廓、膈和腹壁运动的相对可见程度，不是两套互斥的哺乳动物呼吸器官。肺容积、顺应性、气道阻力和表面活性物质的力学关系见[呼吸生理总论与肺通气](../../physiology/respiratory/index.md)。

## 呼吸道与发声器 { #airways-vocal-organs }

呼吸道既传导介质，也控制吞咽时的开闭、清除颗粒、调节温湿度并为发声提供气流。咽、喉门、喉、气管、支气管的边界随类群变化；“支气管到爬行动物才出现”不准确，因为有肺两栖动物已经有从短气管或喉气管室通向左右肺的分支，肺鱼也有独特的肺入口与导管。

### 两栖动物与非鸟爬行动物的喉

无尾类喉位于口咽底部，声门由成对杓状软骨及环气管软骨支撑，喉肌控制开闭。许多蛙的声带、声膜或纤维组织在呼气气流中振动；雄蛙常有与口腔相通的单个或成对声囊，声囊使空气往返、增强辐射并能产生视觉信号。声囊的数目、位置、颜色和是否限于雄性均随支系变化，部分蛙无声囊，水生爪蟾还可用高度特化的喉盘在几乎没有往返气流时发声。传统“声带发声、雄蛙声囊共鸣”是重要观察入口，应保留这些真实例外。[^anuran-vocal-sac]

非鸟爬行动物喉通常含环状和杓状软骨，声门开口后接由软骨环支撑的气管，再分为左右支气管。鳄、壁虎、龟鳖以及许多蜥蜴和蛇都能发出嘶声、吼声或叫声，振动来源可包括喉内褶、声带样组织或喷出气流；形态远比“爬行动物无声带”统一。气管环可完整或不完整，支气管长度也受颈部和肺位置影响。

### 鸣管

鸟的头侧喉由环状、杓状等软骨围成声门，主要控制通气和吞咽；主要发声器是气管尾端或支气管起始处的鸣管。鸣管可按位置分为气管型、气管—支气管型和支气管型，常由扩大的鼓部、支气管半环、内外鼓膜、内外唇和鸣肌构成。左右两侧声源在许多鸣禽中可分别控制，气囊压力提供驱动力，舌、口咽和喙再塑造共鸣。

旧称“后喉”准确提示鸣管位于呼吸道尾侧，却容易误以为它是头侧喉整体后移。发生和组织比较显示，鸣管在气管—支气管拓扑位置上形成新的软骨、肌肉与振动软组织组合；真正喉仍位于舌后。多数鸟鸣管位于胸腔入口附近，蜂鸟等还可移到颈部，具体位置与类型均需按支系观察。[^syrinx]

### 哺乳动物喉与声道

哺乳动物喉以会厌软骨、甲状软骨、环状软骨和成对杓状软骨为主要支架。真声带或声襞从甲状软骨连向杓状软骨，声门裂位于两侧声襞之间；喉内肌改变声襞长度、张力和开度，呼气气流驱动声襞振动。前庭襞又称假声带，在人体位于真声带上方，在水平躯干的兽类宜说位于其口侧或头侧；“假声带在前、真声带在后”没有固定比较坐标，也忽略许多哺乳动物前庭襞缩小、参与发声或形成额外振动结构的差异。

大多数哺乳动物的交流声以喉为声源，咽、口腔、鼻腔、唇和舌构成声道滤波器。鹿可在吼叫时显著下降喉位，蝙蝠的一些支系以特化喉和声膜产生超声，齿鲸则把发声源重组到鼻道的声唇系统。哺乳类喉共同框架与多样声源可以同时成立，不能用人的语音器官作为全纲唯一模型。

## 标本、模型与切片的观察次序 { #specimen-observation }

观察鳃时先确定口、咽和体表开口，沿可能的水流方向寻找呼吸管、喷水孔、鳃盖腔或独立鳃裂。随后逐弓记录鳃耙、鳃丝、鳃间隔、半鳃与全鳃，最后在切片上辨认次级鳃小片、柱细胞血隙、离子细胞和黏液细胞。只有把入鳃、出鳃血管和水路同时画出，才能判断逆流关系；看见红色羽状组织本身还不足以确定流向。

观察鳔与肺时先保留器官原位，确认它在消化管背侧还是腹侧、是否有鳔管或喉门、左右是否成对、与肾、肝和体壁怎样连接。鳔要进一步寻找气腺、奇网、卵圆区和与内耳或椎骨相连的结构；肺要沿气管或主支气管切开，记录单室、多室、肺窝、旁支气管、气毛细管或肺泡等不同层级。鸟的气囊薄而易破，开胸前应先辨认水平隔、斜隔和气囊壁，不能把空瘪气囊当作缺失。

分析通气泵时把骨骼和肌肉动作与肺内气流分开记录。口底运动可驱动两栖动物正压泵，肋胸骨运动可驱动蜥蜴和鸟的吸气，龟腹肌与鳄肝活塞又通过脏器位移改变肺容积；这些动作并不直接决定肺内一定是潮流或单向流。最后从口咽向后追踪喉、气管、支气管与鸣管，标明声门、振动组织和共鸣囊，避免把声源、气流泵和声道混作一个“发声器官”。
