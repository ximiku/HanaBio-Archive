# 生物化学

生物化学（Biochemistry）是所有生物学科的前提必修。生物化学包括结构生物化学和代谢生物化学（当然杨sir等书上有包含分子生物学，这里我们分开谈论）。我尝试使用一种讲述性的语言进行，使无论是初次接触生化的同学，还是已有基础想要复习的同学，都能有所收获。
