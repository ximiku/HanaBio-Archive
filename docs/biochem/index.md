# 生物化学

生物化学研究生命体系中的分子组成、化学转化及其调节。它既要说明糖、脂质、蛋白质和核酸具有怎样的结构，也要解释这些分子为何能彼此识别、在酶的催化下发生反应，并在细胞和生物体内形成持续流动的物质与能量网络。静态结构与动态过程并不是两门分开的知识：一种官能团的质子化状态可以改变结合，一处构象变化可以重分配催化速率，一条通路的产物又可能成为另一条通路的底物或调节物。[^biochemistry-scope]

本栏目把这条连续的因果链分成若干页面，范围从生物分子的化学基础、蛋白质结构与研究方法，延伸到酶、辅酶、生物能学以及糖、脂质、氨基酸和核苷酸代谢。DNA 复制、转录、翻译和基因表达调控另归入分子生物学；这里保留核酸的结构化学与核苷酸代谢，因为它们分别是理解信息大分子和细胞核苷酸池的生化基础。

## 化学结构规定分子可进入的反应空间 { #chemical-structure }

生物分子并不是只靠名称区分的一组类别。羟基、羰基、羧基、氨基、磷酸基和含硫基团决定酸碱行为、亲核或亲电反应倾向；碳骨架、双键和手性中心限制分子的几何形状；氢键、静电作用、疏水效应和色散力又使许多弱相互作用能够在水溶液中共同形成选择性。因而，认识一个分子至少要同时追踪共价结构、质子化状态、立体化学、所处溶剂以及它与其他分子的相互作用。

[糖类](carbohydrate.md)、[脂质](lipid.md)、[氨基酸](amino_acid.md)与[核酸与核苷酸](nucleic_acid.md)分别从这些化学条件出发。糖的羟基与羰基化学产生异构体、环化和糖苷键；脂质由疏水部分与极性头基的组合获得膜组装、储能和信号功能；氨基酸的共同主链与多样侧链构成蛋白质化学的字母表；核苷酸则把可识别的碱基、定向连接的戊糖和带电磷酸骨架合为一体。

多肽形成以后，序列只给出结构问题的起点。[蛋白质结构](protein_structure.md)讨论肽键、主链构象、二级结构、折叠与亚基装配，[蛋白质功能](protein_function.md)进一步把配体结合、构象交换、协同作用和分子机器联系起来。[蛋白质研究方法](protein_methods.md)则提醒我们，纯化峰、电泳条带、质谱离子、三维密度和活性曲线只是不同实验条件下取得的证据，不能用其中一种投影代替完整的分子状态。

## 酶把化学可能性置于可调的时间尺度 { #enzymatic-catalysis }

热力学判断反应在给定条件下是否具有净驱动力，却不告诉我们未催化反应要等待多久。酶通过稳定过渡态、安排反应基团和耦联多个化学步骤降低活化自由能，使反应在生理时间尺度内发生；它改变速率而不改变反应的平衡常数。底物浓度、产物积累、pH、温度、离子、抑制剂和蛋白质构象都可能改变观测速率，因此“某酶活性高”只有在测定条件和比较基准明确时才有意义。

[酶通论](enzyme.md)建立催化、专一性、辅因子与活力测定的共同语言；[酶动力学](enzyme_dynamics.md)说明怎样从初始速率、稳态模型和抑制模式中估计参数；[酶的催化机制与调控](enzyme_mechanism_regulation.md)进入酸碱催化、共价催化、金属离子、别构、共价修饰和酶原激活；[维生素与辅酶](vitamin_and_coenzyme.md)则追踪电子、酰基、一碳单位及其他活化基团怎样在不同酶之间转移。NC-IUBMB 按催化反应而不是蛋白质折叠或来源对酶分类，所以同一 EC 编号指向一种反应能力，并不等同于某一条唯一的蛋白质序列。[^enzyme-nomenclature]

## 能量、电子与活化基团穿过代谢网络 { #energy-and-metabolism }

代谢不是把营养物依次送过一条长流水线。细胞中的反应共享中间物、辅酶和膜两侧的电化学梯度，并同时受到热力学、酶容量、物质供应、区室转运和生理需求约束。[代谢总论](metabolism.md)先区分代谢物池、交换反应与净通量；[生物能学](bioenergetics.md)给出 Gibbs 能、反应耦联、基团转移势和氧化还原势的定量语言；[电子传递与氧化磷酸化](oxp.md)再说明电子流怎样建立质子动力势，并由 ATP 合酶转换为磷酸化驱动力。

ATP 在这里不是抽象的“能量货币”，而是能够把磷酰基转移和构象变化耦联到不利过程的化学底物；NADH、NADPH、还原型黄素和辅酶 Q 也不是可以任意互换的“氢载体”，它们在反应化学、酶选择和细胞区室上各有边界。Reactome 的人类代谢知识库同样把糖、脂质、氨基酸、核苷酸、维生素与电子传递组织为互相连接的层级网络，而不是彼此封闭的章节。[^reactome-metabolism]

## 共同中间物连接分解与合成 { #shared-intermediates }

葡萄糖-6-磷酸可进入糖酵解、磷酸戊糖途径或糖原代谢；丙酮酸可被还原、羧化或氧化为乙酰辅酶 A；乙酰辅酶 A 既能进入三羧酸循环，也能用于脂肪酸、胆固醇和酮体代谢。三羧酸循环中的草酰乙酸、$\alpha$-酮戊二酸、琥珀酰辅酶 A 等一面接受分解代谢带来的碳，一面又被抽取去合成葡萄糖、氨基酸、血红素和其他分子。所谓“某条通路的中间物”因而只是便于说明的局部身份，不是分子被永久划定的去向。

理解这种网络需要分别保存几本账。碳原子去了哪里，与氮如何被收集和排出并非同一个问题；ATP 的净消耗或形成，不能替代 NADH、NADPH 和膜势的电子与能量账本；代谢物浓度保持不变，也不表示穿过该池的通量为零。阅读具体通路时，应把反应计量、净方向、区室、物种或组织、调节节点和实验条件放在同一张因果图中。

## 生化结论随条件取得明确边界 { #conditions-and-evidence }

离体酶的最适 pH 不等于细胞必须把区室维持在该数值；标准状态下的自由能变化不等于细胞内实际反应自由能；某种代谢物的丰度升高，也可能来自生成增加、消耗减少、转运改变或池体积变化。类似地，哺乳动物肝细胞、植物质体、酵母过氧化物酶体和细菌胞质中的同名反应，未必具有相同的酶、区室或调节方式。把条件写进结论，不是削弱规律，而是说明规律在哪些系统中成立。

结构、动力学、同位素示踪、遗传扰动和细胞定位回答的是不同层次的问题。结构可以提出反应基团怎样排列的假说，突变和动力学检验其因果作用，示踪报告原子流向，细胞与生物体实验再判断这种机制是否在真实语境中支配通量或表型。可靠的生化论证通常来自这些证据的相互约束，而不是一幅通路图或一个显著差异独自完成解释。
