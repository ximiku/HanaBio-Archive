# 蛋白质降解与氨基酸分解代谢

蛋白质中的碳和氮始终处在流动之中。细胞一面合成新的蛋白质，一面清除折叠失败、受损或已经完成任务的分子；食物蛋白和组织蛋白释放的氨基酸汇入同一个代谢池，再被用于合成、信号传递或氧化。人体没有一种专门储存多余氨基酸的聚合物，因此，当氨基酸超过蛋白质合成及其他含氮产物的需要时，氨基必须被安全转运和排出，碳骨架则回到糖、脂质和三羧酸循环网络。

这两个去向不能混成一句“脱氨后供能”。氨基酸的多数氨基先经转氨反应汇集到谷氨酸，再以谷氨酰胺、丙氨酸或铵的形式在组织间移动；肝脏把其中相当一部分氮装入尿素。与此同时，每种氨基酸特有的碳骨架会落到丙酮酸、乙酰-CoA、乙酰乙酸或四种三羧酸循环中间物。氮账本决定毒性与排泄，碳账本决定它能否净生糖或生酮，两者必须分别追踪。[^amino-acid-metabolism]

## 蛋白质周转把完整蛋白质送回氨基酸池 { #protein-turnover }

蛋白质降解首先是有选择的质量控制和调节过程，而不是把细胞内蛋白质随机水解。不同蛋白质的寿命可从数分钟到数年不等；降解速度取决于折叠状态、装配伙伴、细胞定位、翻译后修饰以及是否暴露可被识别的降解信号。胞内蛋白质主要由泛素—蛋白酶体系统和自噬—溶酶体系统处理，两者既有分工，也会在聚集蛋白和受损细胞器的清除中协作。[^protein-degradation]

### 泛素—蛋白酶体系统选择短寿命与异常蛋白 { #ubiquitin-proteasome }

泛素是一种由 76 个氨基酸组成的小蛋白。E1 泛素激活酶先消耗 ATP，使泛素 C 端形成高能硫酯中间体；泛素随后转给 E2 结合酶，再由 E3 连接酶把底物识别与共价转移联系起来。E3 的多样性使细胞能读取磷酸化、氧化损伤、错误折叠、未装配亚基或特定 N 端性质等降解信号。泛素可以单独连接，也可形成具有不同连接位点和拓扑的链；K48 链是常见的蛋白酶体降解信号，却不能据此把所有多聚泛素链都解释为“销毁标签”，因为一些链主要参与信号、膜运输或 DNA 修复。[^ubiquitin-system]

26S 蛋白酶体由 20S 核心颗粒和一个或两个 19S 调节颗粒组成。19S 颗粒识别底物、拆除并回收泛素、用 AAA$^+$ ATPase 展开蛋白质，再把伸直的多肽送入 20S 内部的蛋白水解腔。核心颗粒的催化性 $\beta$ 亚基以 N 端苏氨酸为亲核基团，把底物切成短肽；胞质肽酶继续水解这些肽，氨基酸由此返回代谢池。ATP 的主要作用包括泛素激活和底物展开、转运，肽键水解本身仍是加水反应。

20 世纪 70—80 年代的无细胞实验显示，网织红细胞裂解液中存在依赖 ATP 的蛋白降解体系，并由此分离出后来称为泛素的热稳定因子及 E1、E2、E3 级联。这个发现的重要之处不只是找到一种蛋白酶，而是证明“选择哪个蛋白被降解”与“怎样把它切开”是可以分离的两层机制。[^ubiquitin-history]

### 自噬—溶酶体系统处理较大货物并回收营养 { #autophagy-lysosome }

宏自噬启动后，隔离膜逐渐包围一部分胞质，闭合成双层膜自噬体；自噬体与溶酶体融合后，酸性水解酶降解其中的蛋白质、核酸、脂质以及受损细胞器，所得小分子再输出到胞质。饥饿可增强较广泛的物质回收，受体蛋白也能把带有特定泛素信号的聚集体、线粒体或病原体选择性送入自噬体。微自噬和伴侣介导自噬则使用不同的底物进入方式，不能把所有溶酶体蛋白降解都画成同一种双膜小泡。[^autophagy]

蛋白酶体适合把能够展开并穿入狭窄通道的单个蛋白质连续切解；自噬可以容纳大型复合物、聚集体和细胞器。两套系统都受到营养、应激与细胞状态调节，也都不等同于消化道中胃蛋白酶和胰蛋白酶对食物蛋白的腔内水解。后者决定膳食氨基酸的输入，完整的消化与吸收过程归入[消化生理](../physiology/digestive.md)。

## 转氨反应把多数 α-氨基集中到谷氨酸 { #transamination }

多数氨基酸开始分解时，并不直接释放游离氨。氨基转移酶把供体氨基酸的 $\alpha$-氨基交给一种 $\alpha$-酮酸，供体留下相应的碳骨架；$\alpha$-酮戊二酸是最常见的受体，产物因而是谷氨酸。用 AA 表示氨基酸，反应可简写为

$$
\mathrm{AA}+\alpha\text{-KG}
\rightleftharpoons
\alpha\text{-ketoacid}+\mathrm{Glu}
$$

磷酸吡哆醛（PLP）先以内部醛亚胺连接酶的 Lys，底物进入后形成外部醛亚胺；氨基转移给 PLP 生成磷酸吡哆胺（PMP）和相应酮酸。第二个半反应再把氨基从 PMP 交给受体酮酸，恢复 PLP。两个底物不必同时占据活性部位，所以这是典型的乒乓机制。PLP 的电子汇化学见[维生素与辅酶](vitamin_and_coenzyme.md#pyridoxal-phosphate)。[^aminotransferases]

丙氨酸氨基转移酶（ALT，基因常记作 *GPT*）把丙氨酸与丙酮酸相互转换，天冬氨酸氨基转移酶（AST，*GOT1/GOT2*）连接天冬氨酸、草酰乙酸与谷氨酸。二者反应在接近平衡时可随底物和产物浓度改变方向，血清 ALT、AST 活性升高也主要表示细胞内容物释放，不能由此反推“ALT 只在肝、AST 只在心肌”。不同氨基转移酶的底物范围各异；Lys 和 Pro 等氨基酸常从其他专门反应起步，Thr 也可走多条分解路线，因此“除三种氨基酸外均能转氨”只能当作粗略教学概括。

## 谷氨酸与谷氨酰胺组织氮的汇合和运输 { #nitrogen-collection-transport }

### 谷氨酸脱氢酶连接氨基氮与游离铵 { #glutamate-dehydrogenase }

转氨形成的谷氨酸可在线粒体基质中由谷氨酸脱氢酶 GLUD1 氧化脱氨，生成 $\alpha$-酮戊二酸和 NH$_4^+$，并把电子交给 NAD$^+$ 或 NADP$^+$：

$$
\begin{aligned}
\mathrm{Glu}+\mathrm{NAD(P)^+}+\mathrm{H_2O}
&\rightleftharpoons \alpha\text{-KG}+\mathrm{NH_4^+}\\
&\quad+\mathrm{NAD(P)H}+\mathrm{H^+}
\end{aligned}
$$

转氨与谷氨酸氧化脱氨合在一起常称联合脱氨或转脱氨。前一组反应把许多不同氨基汇到同一种载体，后一反应才形成可直接进入尿素循环的铵；$\alpha$-酮戊二酸则被再生。GLUD1 反应可逆，实际方向取决于底物、氧化还原状态和氮需求；哺乳动物酶还受 ADP／GDP 激活、GTP 抑制等别构作用，不能只凭一张单向箭头把它规定为所有组织恒定的“放氨阀门”。[^glutamate-metabolism]

### 氨基酸氧化酶是具有特定底物与组织背景的旁路 { #amino-acid-oxidases }

黄素依赖的氨基酸氧化酶可以不经过转氨，直接以 O$_2$接受电子，把氨基酸转为相应的 $\alpha$-酮酸、NH$_4^+$和 H$_2$O$_2$。人的 D-氨基酸氧化酶 DAO使用 FAD，参与 D-Ser等 D-氨基酸的处置；这些底物的构型与构成蛋白质主体的 L-氨基酸不同。人也有 L-氨基酸氧化酶 IL4I1，但它是以芳香族氨基酸为偏好底物的分泌蛋白，主要在免疫组织和细胞中发挥免疫调节作用。两类反应都会同时产生过氧化氢，因而还牵涉局部氧化还原控制。它们证明“氧化脱氨”不只发生在谷氨酸，却不应被扩写为人体分解多数 L-氨基酸的普遍入口；全身氮代谢的主线仍是转氨后汇入谷氨酸与谷氨酰胺。[^amino-acid-oxidases]

### 谷氨酰胺与丙氨酸承担器官间氮运输 { #glutamine-alanine }

NH$_3$ 与 NH$_4^+$ 在水中快速互变，生理 pH 下绝大多数总氨以 NH$_4^+$ 存在。许多肝外组织先用谷氨酰胺合成酶 GLUL 把铵固定到谷氨酸的侧链酰胺中；这一步消耗 ATP，得到电中性的谷氨酰胺。肝、肾和肠等组织的线粒体谷氨酰胺酶又可水解酰胺，重新生成谷氨酸与 NH$_4^+$：

$$
\begin{aligned}
\mathrm{Glu}+\mathrm{NH_4^+}+\mathrm{ATP}
&\rightarrow \mathrm{Gln}+\mathrm{ADP}+\mathrm{P_i}\\
\mathrm{Gln}+\mathrm{H_2O}
&\rightarrow \mathrm{Glu}+\mathrm{NH_4^+}
\end{aligned}
$$

谷氨酰胺因此既是安全程度较高的氮载体，也是核苷酸、氨基糖和多种合成反应的酰胺氮供体。它并非一个只为“排毒”而存在的惰性包装；同一分子到达肝可供尿素合成，到达肾近端小管可支持铵排泄和新生 HCO$_3^-$ 回补，到达增殖组织又可提供碳氮原料。[^nitrogen-transport]

骨骼肌还可把谷氨酸的氨基转给丙酮酸，形成丙氨酸。丙氨酸入肝后反向转氨，丙酮酸用于糖异生，氮则经谷氨酸和天冬氨酸进入尿素循环。这一[葡萄糖—丙氨酸循环](gng.md#interorgan-cycles)同时转移碳、氮和能量负担，但丙氨酸不是全身唯一氮载体，肌肉蛋白分解也不会在禁食中无限维持而没有组织代价。

### 嘌呤核苷酸循环提供另一条产氨入口 { #purine-nucleotide-cycle }

骨骼肌能量需求较高时，AMP 脱氨酶可把 AMP 变为 IMP并释放 NH$_4^+$；IMP 再与天冬氨酸、GTP形成腺苷琥珀酸，腺苷琥珀酸裂合酶释放延胡索酸并再生 AMP。整个循环净消耗天冬氨酸和 GTP，生成延胡索酸与铵，并与腺苷酸激酶、糖酵解及三羧酸循环相接。它是嘌呤核苷酸代谢和肌肉能量状态之间的联系，不是“把所有氨基酸联合脱氨”的第二套通用装置；肝脏也没有被证明以同样方式运行完整循环。[^purine-nucleotide-cycle]

## 氨的组织处置具有区室和浓度边界 { #ammonia-fates }

肠道、肝外组织和肝细胞自身都能产生氨。门静脉血首先到达肝小叶门管区附近，富含尿素循环酶的肝细胞承担高容量尿素生成；靠近中央静脉的少量谷氨酰胺合成酶阳性细胞可继续捕获逃逸的低浓度氨。这种串联布置比“肝脏用一条循环清除全部氨”更接近真实组织结构。肾脏则可把谷氨酰胺氮以 NH$_4^+$ 排入尿液，尤其在酸负荷增加时加强；人体还有少量氮经尿酸、肌酐及其他化合物排出。不同动物选择氨、尿素或尿酸为主要排氮形式的比较，留在动物与生理学页面展开。

!!! warning "高氨血症不是单一的‘耗尽 α-酮戊二酸’"
    氨浓度超过肝脏处置能力或绕过肝脏时，脑是主要受损器官。星形胶质细胞把氨固定成谷氨酰胺可暂时降低游离氨，却会改变渗透压、细胞体积、神经递质循环和线粒体功能；氧化还原、离子稳态及炎症信号也会参与。用“还原胺化耗尽 $\alpha$-酮戊二酸，三羧酸循环停转”作为唯一机制，既不能解释急慢性差异，也忽略了谷氨酰胺积累的双重作用。[^hyperammonemia]

## 尿素循环跨越线粒体与胞质 { #urea-cycle }

1932 年，Hans Krebs 与 Kurt Henseleit 用肝组织切片观察到鸟氨酸能促进氨转为尿素，并逐步确认鸟氨酸在反应后再生。尿素循环由此成为第一个被阐明的代谢循环。对人类而言，它的主要场所是肝细胞；前两步在线粒体基质完成，后三步位于胞质，鸟氨酸与瓜氨酸的跨膜交换把两部分接成闭合路径。[^urea-cycle-history]

| 反应阶段 | 主要反应与酶 | 区室及读图要点 |
| --- | --- | --- |
| 氨甲酰磷酸形成 | NH$_4^+$、HCO$_3^-$和 2 ATP经 CPS1形成氨甲酰磷酸 | 线粒体；CPS1必须由 N-乙酰谷氨酸激活 |
| 瓜氨酸形成 | OTC把氨甲酰基转给鸟氨酸，释放 P$_i$ | 线粒体；瓜氨酸输出到胞质，鸟氨酸随后输入 |
| 精氨琥珀酸形成 | ASS1使瓜氨酸与天冬氨酸缩合，ATP变成 AMP＋PP$_i$ | 胞质；天冬氨酸提供尿素的第二个氮 |
| 精氨酸形成 | ASL裂解精氨琥珀酸，生成精氨酸与延胡索酸 | 胞质；延胡索酸连接苹果酸、草酰乙酸与转氨反应 |
| 尿素释放 | ARG1水解精氨酸，生成尿素并再生鸟氨酸 | 胞质；鸟氨酸回到线粒体开始下一轮 |

第一份氮以游离 NH$_4^+$ 进入 CPS1，第二份来自天冬氨酸，羰基碳来自 HCO$_3^-$。忽略质子及不同离子化写法时，常用净账本为

$$
\begin{aligned}
\mathrm{NH_4^+}+\mathrm{HCO_3^-}+\mathrm{Asp}
&+3\,\mathrm{ATP}+\mathrm{H_2O}\\
&\rightarrow \mathrm{urea}+\mathrm{fumarate}\\
&\quad+2\,\mathrm{ADP}+2\,\mathrm{P_i}\\
&\quad+\mathrm{AMP}+\mathrm{PP_i}
\end{aligned}
$$

三分子 ATP在这里断裂四个高能磷酸键：CPS1两次生成 ADP，ASS1使 ATP生成 AMP，随后 PP$_i$通常继续水解。延胡索酸转为苹果酸、草酰乙酸时可以生成 NADH，草酰乙酸再经 AST接受谷氨酸的氨基形成天冬氨酸，这组联系称天冬氨酸—精氨琥珀酸旁路。NADH可补偿一部分能量成本，却不能在没有组织和呼吸条件的前提下断言尿素合成“收支相抵”或“必然获利”。[^urea-cycle-energy]

N-乙酰谷氨酸合成酶 NAGS以谷氨酸和乙酰-CoA生成 N-乙酰谷氨酸，精氨酸可促进其活性；N-乙酰谷氨酸又是 CPS1 的必需变构激活剂。蛋白质摄入增加或分解代谢增强时，底物供给、NAGS—CPS1激活以及尿素循环酶表达会在不同时间尺度共同提高处理能力。因此 CPS1是关键入口，却不是脱离转运、天冬氨酸供给和下游酶容量的唯一通量决定因素。[^urea-cycle]

### 尿素循环缺陷按受阻位置形成不同代谢图谱 { #urea-cycle-disorders }

尿素循环任何一步或关键转运发生缺陷都可能造成高氨血症，但积累物并不相同。线粒体氨甲酰磷酸若不能被 OTC有效使用，可逸入胞质嘧啶合成并提高乳清酸；CPS1或 NAGS缺陷则通常没有同样的氨甲酰磷酸过剩。这个分流说明代谢物组合比“氨升高”更能定位受阻位置。[^urea-cycle-disorders]

| 受影响蛋白 | 典型生化线索 | 对原素材的校正 |
| --- | --- | --- |
| NAGS或 CPS1 | 高氨、瓜氨酸偏低，尿乳清酸正常或偏低 | 二者都位于循环入口，但 NAGS缺陷首先缺少 CPS1激活物 |
| OTC | 高氨、瓜氨酸偏低，尿乳清酸明显升高 | OTC缺陷是 X连锁；升高的乳清酸来自氨甲酰磷酸分流 |
| ASS1 | 瓜氨酸显著升高 | 又称瓜氨酸血症 I型，不应与线粒体天冬氨酸载体缺陷混同 |
| ASL | 精氨琥珀酸升高 | 受阻后既影响排氮，也影响精氨酸供给与含氮网络 |
| ARG1 | 精氨酸升高 | 原素材所称“精氨酸血”应明确为 ARG1缺陷相关精氨酸酶 1缺乏 |
| SLC25A15 | 高鸟氨酸、高氨和同型瓜氨酸尿 | 这是 HHH综合征；并非 CPS1或鸟氨酸脱羧酶缺乏 |

本页保留受阻步骤与代谢物的对应关系；急性降氨、长期膳食、药物、透析及肝移植等处置属于高风险临床内容，将在[糖与能量代谢紊乱](../physiology/pathophysiology/metabolic_disorders.md)中结合诊疗指南展开。

## 碳骨架汇入七个共同代谢节点 { #carbon-skeleton-fates }

去掉氨基后，二十种常见蛋白质氨基酸并不是各自走到二十个孤立终点。它们的碳最终汇入七类节点；同一种氨基酸可有不止一个去路，所以表中重复出现是碳原子分流的结果，不是分类冲突。[^carbon-skeletons]

| 汇入节点 | 主要氨基酸来源 | 代谢意义 |
| --- | --- | --- |
| 丙酮酸 | Ala、Cys、Gly、Ser、Thr、Trp | 可经丙酮酸羧化进入生糖方向，也可形成乙酰-CoA |
| $\alpha$-酮戊二酸 | Arg、Glu、Gln、His、Pro | 先汇到 Glu或其相邻中间物，再补入三羧酸循环 |
| 琥珀酰-CoA | Ile、Met、Thr、Val | 多经丙酰-CoA和甲基丙二酰-CoA，连接生物素与腺苷钴胺素 |
| 延胡索酸 | Phe、Tyr | 与尿素循环旁路及三羧酸循环相接 |
| 草酰乙酸 | Asp、Asn | 可参与转氨、三羧酸循环和糖异生 |
| 乙酰-CoA | Ile、Leu、Thr、Trp | 在动物中不能产生净草酰乙酸，不能据此净合成葡萄糖 |
| 乙酰乙酸／乙酰乙酰-CoA | Leu、Lys、Phe、Trp、Tyr | 可形成酮体或转为乙酰-CoA，属于生酮出口 |

能生成丙酮酸或三羧酸循环中间物的氨基酸称生糖氨基酸，因为这些碳在适当条件下可进入[糖异生](gng.md#precursor-entry)；只形成乙酰-CoA或乙酰乙酸的碳不能在动物中净生糖。Leu与 Lys通常列为仅生酮氨基酸；Ile、Phe、Thr、Trp、Tyr兼有生糖和生酮碳；其余通常归入生糖类。这个分类描述的是碳原子终点，不表示摄入某种氨基酸便会必然升高血糖或酮体，也不替代对各组织实际通量的测量。

## 若干氨基酸分解需要独立反应模块 { #individual-amino-acid-catabolism }

### 支链氨基酸共用转氨和氧化脱羧入口 { #branched-chain-catabolism }

Leu、Ile和 Val先由支链氨基酸氨基转移酶形成相应的支链 $\alpha$-酮酸，线粒体支链 $\alpha$-酮酸脱氢酶复合体（BCKDH）再完成不可逆氧化脱羧。BCKDH与丙酮酸脱氢酶复合体在组织方式上相似：E1使用 ThDP，E2用硫辛酰胺摆臂把酰基交给 CoA，E3经 FAD把电子交给 NAD$^+$；但二者识别的底物和调控酶不同。BCKDH被 BCKDK磷酸化抑制，由 PPM1K去磷酸化激活。[^branched-chain-catabolism]

肝脏的 BCAT活性相对很低，支链氨基酸分解的第一步因而较多发生在骨骼肌等肝外组织，形成的支链酮酸再由不同组织继续氧化。BCKDH复合体活性严重降低会使支链氨基酸、支链酮酸和别异亮氨酸等积累，形成枫糖尿病。原素材把疾病只写成“缺少分支链酮酸脱氢酶”抓住了共同节点，却需要补上复合体多亚基、调控与代谢物谱的边界。[^maple-syrup-urine-disease]

### 苯丙氨酸与酪氨酸最终形成延胡索酸和乙酰乙酸 { #phenylalanine-tyrosine-catabolism }

苯丙氨酸羟化酶 PAH使用四氢生物蝶呤和 O$_2$把 Phe转为 Tyr。Tyr经 TAT转氨形成 4-羟苯丙酮酸，HPD将其氧化为尿黑酸；HGD打开芳环生成马来酰乙酰乙酸，异构化后形成延胡索酰乙酰乙酸，最后由 FAH水解为延胡索酸和乙酰乙酸。于是 Phe、Tyr同时具有生糖与生酮结局。[^phenylalanine-tyrosine]

| 受阻步骤 | 代表性疾病 | 代谢解释 |
| --- | --- | --- |
| PAH或 BH$_4$合成／再生 | 高苯丙氨酸血症；经典 PAH缺陷表型称苯丙酮尿症 | Phe及旁路产物积累，Tyr成为条件性必需氨基酸 |
| TAT | 酪氨酸血症 II型 | Tyr转氨入口受阻，不应与 HPD或 FAH缺陷混称一种“高酪氨酸血症” |
| HPD | 酪氨酸血症 III型 | 4-羟苯丙酮酸不能有效转为尿黑酸 |
| HGD | 尿黑酸症 | 尿黑酸不能转为马来酰乙酰乙酸；规范酶名为尿黑酸 1,2-双加氧酶 |
| FAH | 酪氨酸血症 I型 | 末端受阻产生延胡索酰乙酰乙酸及琥珀酰丙酮等有毒代谢物 |

这些缺陷也展示了“上游抑制”作为治疗逻辑：抑制 HPD可减少 FAH缺陷下游有毒代谢物的形成，但也会有意造成更上游的酪氨酸代谢阻断，因此必须同时管理新的底物积累。白化病则多由黑色素合成相关蛋白缺陷造成；酪氨酸酶催化的是黑色素生物合成，不属于这条分解主线，相关内容迁往[氨基酸及其衍生物的合成](aa_synthesis.md)。[^phenylalanine-tyrosine-disorders]

### 有机酸血症和含硫氨基酸缺陷定位于不同支路 { #representative-catabolic-defects }

| 原素材中的名称 | 主要分子节点 | 需要保留的边界 |
| --- | --- | --- |
| 甲基丙二酸血症 | MMUT或腺苷钴胺素形成／利用缺陷，使甲基丙二酰-CoA不能有效变为琥珀酰-CoA | 相关碳来自 Val、Ile、Met、Thr、奇数链脂肪酸等，不包括原表所列 Ser |
| 异戊酸血症 | IVD缺陷阻断 Leu分解中的异戊酰-CoA脱氢 | 是 Leu支路缺陷，不等同于整个 BCKDH复合体缺陷 |
| 高赖氨酸血症 | 双功能 AASS的赖氨酸—$\alpha$-酮戊二酸还原酶／酵母氨酸脱氢酶活性缺陷 | 生化异常可明显而临床表型不一，不能由血 Lys升高直接推定严重程度 |
| CBS缺陷型同型半胱氨酸尿症 | PLP依赖 CBS不能有效把同型半胱氨酸与 Ser缩合成胱硫醚 | 应写同型半胱氨酸而非“高胱氨酸”；这是转硫途径阻断 |
| 高脯氨酸血症 | I型常涉及 PRODH，II型常涉及 ALDH4A1 | 两型阻断 Pro至 Glu路径的不同步骤，不能把氧化酶和脱氢酶并成一种缺陷 |

这些疾病的共同点是某个支路受阻后，底物、旁路有机酸和下游产物同时改变；临床严重度还受残余活性、分解代谢压力和其他基因影响。这里承接分子步骤，筛查阈值、急性危象和长期治疗仍归病理生理页面。[^representative-inborn-errors]

## 脱羧与一碳转移构成氨基酸的其他去路 { #decarboxylation-and-one-carbon }

PLP依赖氨基酸脱羧酶通过外部醛亚胺稳定负电荷，移去 $\alpha$-羧基并释放 CO$_2$，最终生成生物胺；“醛亚胺”是酶促中间体，不是与胺并列的终产物。谷氨酸脱羧生成 $\gamma$-氨基丁酸，组氨酸脱羧生成组胺。多巴胺、5-羟色胺、儿茶酚胺和多胺等产物的完整合成、囊泡储存与受体作用超出了氨基酸分解主线，将分别由下一页及神经、内分泌页面承接。

Ser、Gly、Thr和 His分解时还能把不同氧化态的一碳单位交给四氢叶酸；Met经 S-腺苷甲硫氨酸提供活化甲基。原素材把“亚甲基、亚氨甲基、次甲基和甲基”列成氨基酸自身固定携带的四类产物，容易忽略一碳单位的载体、氧化态与反应方向。甘氨酸参与嘌呤、卟啉和肌酸合成，酪氨酸参与儿茶酚胺、甲状腺激素与黑色素合成，色氨酸可形成 5-羟色胺、褪黑素和烟酸；这些都属于以氨基酸为前体的合成网络，而非本页碳骨架氧化的统一末段，详见[氨基酸及其衍生物的合成](aa_synthesis.md)和[维生素与辅酶](vitamin_and_coenzyme.md#biotin-folate-one-carbon)。[^amino-acid-derivatives]
