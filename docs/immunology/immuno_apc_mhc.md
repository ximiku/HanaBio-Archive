# 抗原的T细胞呈递及MHC功能

T淋巴细胞的主要功能是消除细胞内微生物的感染并激活其他细胞，例如巨噬细胞和B淋巴细胞。

**为了启动免疫反应，抗原从其进入位点被捕获并集中在次级（外周）淋巴器官中，幼稚 T 细胞(naive T cell, Th0)通过这些器官不断循环。**微生物和其他抗原一般从与外界接触的上皮中进入人体，也可以定居在任何组织中产生抗原。由于淋巴细胞总数有限，对任何一种抗原特异的T细胞数量都非常少（1 in 10^5^ ~ 10^6^）。因此产生问题：这些特异的T细胞需要定位外来抗体，但由于它们太少了而不能“巡逻”（patrol）到体内每一个组织。

解决这个问题的机制是一种专门的系统，用于从抗原的进入或产生位点捕获抗原，并将其带到 naive T cell 循环的次级淋巴器官。捕获抗原并将其展示给 T 淋巴细胞的细胞称为**抗原呈递细胞（antigen-presenting cells, APCs）**。

**T 淋巴细胞识别细胞相关抗原并对其作出反应，但不识别可溶性无细胞抗原。**展示宿主细胞相关抗原以供 CD4+ 和 CD8+ T 细胞识别的任务是由 **主要组织相容性复合体 (major histocompatibility complex, MHC)** 分子执行，这些蛋白质在宿主细胞表面表达。

??? info "T/B细胞在抗原识别方面的区别"

    T 淋巴细胞的主要功能是消除细胞内存活的微生物以及帮助 B 细胞产生杀死细胞外微生物的抗体。在这两种情况下，T 细胞都必须与其他细胞相互作用并激活其他细胞，例如巨噬细胞和 B 淋巴细胞。T 细胞抗原受体（T cell antigen receptors, TCR）能够识别源自细胞内蛋白质并由细胞表面分子展示的抗原，这确保 T 细胞识别细胞相关抗原而不是游离抗原。这与 B 淋巴细胞形成鲜明对比，B 淋巴细胞的抗原受体和分泌产物抗体可以识别微生物和宿主细胞表面的完整抗原以及可溶性无细胞抗原。


???+ info "T 细胞识别 MHC 依赖性抗原的特征"

    | 识别特征                                                     | 表现                                                         |
    | ------------------------------------------------------------ | ------------------------------------------------------------ |
    | 大多数 T 细胞识别肽而不识别其他分子                          | 只有肽才能与 MHC 分子结合                                    |
    | T 细胞识别线性肽，而不识别蛋白质抗原的构象决定簇             | 线性肽与 MHC 分子的裂缝结合，并且在这些肽的生成过程中蛋白质构象会丢失 |
    | T 细胞识别细胞相关抗原和非可溶性抗原                         | 大多数 T 细胞受体仅识别肽 MHC 复合物，而 MHC 分子是膜蛋白，在细胞表面展示稳定结合的肽 |
    | CD4+和CD8+T细胞分别优先识别从细胞外环境摄取到囊泡中的抗原和胞质溶胶中存在的抗原 | MHC 分子的组装途径确保 II 类 MHC 分子展示在 APC **囊泡**中被蛋白水解降解的肽，而 I 类 MHC 分子展示来自被**胞质**蛋白酶体降解的胞质蛋白的肽 |


**MHC 分子将来自不同细胞区室的抗原展示给不同类别的 T 细胞**，以便正确类型的 T 细胞识别最擅长消除的微生物类型。

???+ info "举例说明"

    针对循环中微生物的防御必须由抗体介导，而最有效抗体的产生需要 CD4+ 辅助 T 细胞的参与。但如果同一种微生物（例如病毒）感染组织细胞，抗体就无法接近它，而根除它可能需要 CD8+ 细胞毒性 T 淋巴细胞 (CTL) 杀死受感染的细胞并消除感染库。 MHC 分子在将细胞内化的抗原展示给 CD4+ T 淋巴细胞以及将细胞内产生的抗原展示给 CD8+ T 细胞方面发挥着关键作用。
