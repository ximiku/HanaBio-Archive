# 屏障与黏膜免疫

皮肤、消化道和呼吸道都位于机体与外界相接的位置，却承担不同的交换任务。皮肤以角化表面减少物质通行，肠道每天接纳食物并容纳稠密的微生物群，呼吸道则必须让气体迅速到达极薄的肺泡界面。它们的免疫系统因而不能只追求“隔绝”：屏障需要选择性地排除、取样、耐受、清除并修复，在限制病原体的同时保留吸收、气体交换和共生关系。[^barrier-immunity]

黏膜免疫也不是覆盖各器官的一层均质防线。上皮类型、分泌物、局部淋巴组织、血管地址和驻留细胞共同构成具有区域差异的免疫环境。相同的微生物分子出现在腔面、细胞质或破损上皮下方，可以引出强度和性质不同的反应；抗原在稳态下随受控取样进入引流淋巴结，与伴随组织损伤进入时，也可能走向耐受或效应两种不同结局。

## 屏障以空间分层控制接触 { #spatial-layers }

屏障免疫的第一项工作是控制对象能到达哪一层。最外侧的角质层、黏液、纤毛运动和流体冲洗减少微生物在细胞表面停留；脂质、低 pH、溶菌酶、乳铁蛋白和抗菌肽改变局部化学环境；紧密连接与极性转运限制细胞旁通行。即使对象已经接触上皮，完整基底膜、固有层或真皮中的吞噬细胞及组织引流仍构成后续控制层。每层降低的不是抽象的“抗原量”，而是黏附、穿越、增殖和向深部扩散的机会。

上皮细胞同时是传感器和效应细胞。它们用膜面、内体和胞质中的模式识别受体读取微生物与损伤信号，并据此调整黏液、抗菌分子、趋化因子、细胞因子和修复程序。受体在细胞中的位置、配体是否越过屏障以及相邻细胞提供的信号都会改变输出，使持续存在于腔面的共生信号通常不必等同于组织侵袭。完整的模式识别与炎症级联见[固有免疫识别与炎症](innate_recognition_inflammation.md)。[^epithelial-sensing]

这种空间分层也为免疫反应设定代价。腔面中和和机械清除可以在较少组织损伤的情况下移走对象；一旦微生物进入上皮下方，补体、吞噬细胞和募集来的粒细胞才更充分地发挥作用。屏障免疫因此常先用排斥和局部效应控制接触，只有穿越、复制或损伤信号达到相应阈值时才扩大炎症。

## 皮肤、呼吸道与肠道采用不同隔离策略 { #regional-strategies }

### 皮肤依靠角化表面与局部驻留细胞 { #skin-barrier }

皮肤不属于黏膜，却是比较屏障免疫的重要参照。表皮最外侧由富含角蛋白的角质细胞和胞外脂质构成，连续脱屑、相对干燥的环境、汗液与皮脂中的成分共同限制定植。角质形成细胞并非被动砖块；它们能感知微生物和损伤，释放抗菌肽、趋化因子与细胞因子，并参与屏障修复。表皮中的朗格汉斯细胞、真皮树突状细胞与巨噬细胞负责不同情境下的取样和呈递，肥大细胞、先天淋巴样细胞以及组织驻留记忆 T 细胞则使局部能够迅速反应。[^skin-immunity]

皮肤各处的湿度、温度、皮脂和附属器官密度不同，微生物群落与免疫状态也随之变化。毛囊既可能成为微生物生态位，也为细胞交通和修复提供结构环境。健康皮肤的稳态来自角化、化学环境、共生群落和免疫调节的共同作用，并非表面无菌。

### 呼吸道以黏液纤毛清除保护交换面 { #airway-barrier }

鼻腔和传导气道持续接触吸入颗粒。杯状细胞与黏膜下腺产生的黏液捕获颗粒，纤毛协调摆动把黏液送向咽部，咳嗽和喷嚏在负荷较高时加强清除；分泌型抗体、抗菌蛋白与上皮信号构成化学和免疫层。颗粒的沉积位置取决于粒径、气流和气道几何，因此上呼吸道、支气管和细支气管面对的暴露并不相同。[^airway-defense]

肺泡必须维持极薄的气—血屏障，不能照搬传导气道的厚黏液覆盖。表面活性物质、肺泡上皮和常驻肺泡巨噬细胞在这里承担主要的稳态清除，炎症过强会增加弥散距离、充塞气腔并损害气体交换。呼吸免疫的组织目标因此同时包含清除病原体和尽快恢复透明、薄而干燥的交换界面；气体交换的结构约束见[肺通气与气体交换](../physiology/respiratory/gas_exchange.md)。

### 肠道在高通量吸收旁维持微生物隔离 { #intestinal-barrier }

肠上皮只有单层细胞，却要处理巨大的营养通量和微生物负荷。杯状细胞形成的黏液、上皮连接与快速更新、潘氏细胞等产生的抗菌分子、上皮下的免疫细胞和腔面的分泌型 IgA 共同限制微生物靠近组织。黏液结构具有区域性：结肠形成较清楚的内外分层，小肠则受流动、胆汁、抗菌分子和较疏松黏液共同影响，不能用一幅“均匀双层黏液”示意图代表全肠。肠屏障的生理结构与选择性通行见[消化系统的黏膜屏障](../physiology/digestive/index.md#mucosal-barrier)。[^intestinal-epithelium]

上皮内淋巴细胞紧贴上皮细胞，固有层容纳巨噬细胞、树突状细胞、先天淋巴样细胞、T 细胞和大量抗体分泌细胞。微生物信号可经髓系细胞等促进 ILC3 和 T 细胞产生 IL-22；IL-22 主要作用于非造血的上皮细胞，增强部分抗菌分子、黏液、连接和修复程序。这个回路既能维持稳态，也会随细胞来源、剂量与炎症阶段而改变作用，不能把 IL-22 固定称为“抗炎因子”。[^ilc3-il22]

## 黏膜淋巴组织把取样部位与效应部位相接 { #sampling-induction }

黏膜相关淋巴组织包括扁桃体、Peyer 集合淋巴结、孤立淋巴滤泡等有组织的诱导部位，也包括散布在上皮和固有层中的效应细胞。小肠 Peyer 集合淋巴结表面的滤泡相关上皮含有微皱褶细胞（microfold cell，M 细胞）。M 细胞以跨细胞转运将腔内颗粒送到基底侧的细胞囊袋，使树突状细胞、巨噬细胞和淋巴细胞能够接触这些材料。M 细胞是专门的转运型上皮细胞，不是用 MHC 激活初始 T 细胞的专业抗原呈递细胞；某些病原体也会借用这条取样通路进入组织。[^m-cell]

M 细胞不是唯一入口。可溶性抗原能经上皮转运，特定杯状细胞通路可将腔内成分交给固有层抗原呈递细胞，迁移性树突状细胞随后把信息带到肠系膜淋巴结。不同入口偏好颗粒或可溶物，所处区域和伴随信号也不同。取样的功能不是让屏障“漏开一个洞”，而是在可控位置把少量环境信息送入能够选择淋巴细胞反应的组织。

Peyer 集合淋巴结、孤立滤泡和肠系膜淋巴结可以启动 IgA 应答与 T 细胞反应，固有层和上皮则是浆细胞、效应 T 细胞与驻留记忆细胞工作的主要位置。这种“诱导部位—效应部位”分工解释了为什么黏膜应答既依赖淋巴回流和血液循环，又表现出明显的组织选择性；淋巴器官的一般结构见[免疫细胞、组织与迁移](immune_cells_tissues.md#mucosal-tertiary-lymphoid-tissues)。

## 分泌型 IgA 在腔面完成免疫排斥 { #secretory-iga }

肠固有层的浆细胞多产生带 J 链的二聚 IgA。它在上皮基底外侧与多聚免疫球蛋白受体（polymeric immunoglobulin receptor，pIgR）结合，经细胞转运到顶端；pIgR 被切割后，其胞外部分作为分泌片留在复合物中，形成分泌型 IgA。分泌片提高复合物在黏液和蛋白酶环境中的稳定性，多个抗原结合位点则有利于交联颗粒。血清 IgA 以单体为主，因此“所有 IgA 都是二聚体”并不成立。[^iga-transport]

分泌型 IgA 可阻断毒素或微生物与上皮受体结合，把颗粒交联并滞留在黏液中，再借蠕动或黏液纤毛运动排出；它还会包被部分共生微生物并影响其空间分布。这些作用统称免疫排斥，重点是在腔面限制接触，而不是先招募大量炎症细胞再杀伤。分泌型 IgA 触发 Fcα 受体和补体炎症效应的能力弱于组织中的 IgG，应表述为偏向低炎症的边界控制，而不是绝对“不会引起炎症”。[^iga-function]

IgA 应答既可在 T 细胞帮助下经过生发中心选择，也可由 BAFF、APRIL 等信号支持不依赖经典 T 细胞帮助的类别转换。具体途径随抗原、组织结构和物种而变；本页关注抗体如何抵达腔面，B 细胞类别转换、亲和成熟和浆细胞分化将在[B 细胞与抗体应答](b_cell_antibody.md)中展开。

## 归巢信号使激活后的细胞返回屏障组织 { #mucosal-homing }

在肠道诱导部位，局部树突状细胞和基质细胞代谢维生素 A 产生的视黄酸参与给新激活淋巴细胞写入归巢程序。α4β7 整联蛋白能与肠血管内皮的 MAdCAM-1 结合，CCR9 对小肠较丰富的 CCL25 作出趋化反应；这些信号帮助效应 T 细胞、浆母细胞等从循环回到肠固有层和上皮。进入组织后，TGF-β 等局部信号还可促进部分 T 细胞表达 αEβ7（CD103），加强其与上皮区室的联系。[^gut-homing]

这一模式常被概括为“共同黏膜免疫系统”，但共同之处是诱导部位、循环与效应部位相连，并不意味着任一黏膜激活的细胞会无差别进入所有黏膜。CCR9—CCL25 尤其偏向小肠，结肠、呼吸道、口腔和生殖道使用不同且可重叠的趋化与黏附组合。局部启动位置、炎症状态和分化阶段共同决定最终去向，组织归巢是一组地址而非一张全黏膜通票。[^regional-homing]

## 对食物与共生微生物的耐受是主动调节 { #oral-tolerance }

食物蛋白和共生微生物每天提供大量外源抗原。稳态时，携带可溶性食物抗原的迁移性树突状细胞进入肠系膜淋巴结；视黄酸与 TGF-β 等局部条件有利于诱导 FOXP3$^+$ 调节性 T 细胞，并同时赋予其肠道归巢能力。返回固有层后，这些细胞在 IL-10 等信号支持下扩增或维持，抑制不必要的效应反应。抗原剂量与呈递方式还可促成克隆无反应或删除，因而口服耐受不是单一路径。[^oral-tolerance]

耐受并不表示肠道停止识别外源物。针对同一环境，局部分泌型 IgA 可以限制腔面接触，调节性 T 细胞可以提高组织内炎症阈值，吞噬细胞仍会清除越过屏障的颗粒。病原体侵袭、毒素、上皮死亡或强烈炎症因子改变了呈递背景后，树突状细胞会提供不同的共刺激和极化信号，使效应 T、B 细胞应答占优。防御与耐受因而是由位置和情境分配的并行功能，而不是免疫系统在“开”和“关”之间整体切换。

## 共生群落参与稳态并受到免疫选择 { #microbiota-homeostasis }

共生微生物通过竞争黏附位点和营养、产生抑菌物质、消耗局部氧并改造胆汁酸等方式形成定植抗性。膳食纤维发酵产生的短链脂肪酸等代谢物又可影响上皮能量利用、黏液和免疫细胞分化。宿主反过来用运动、分泌、IgA 包被、抗菌分子和上皮糖基化改变微生物的可用生态位。微生物群与屏障免疫因此构成双向选择，而不是一组固定的“有益菌”单向增强免疫。[^microbiota-resistance]

微生物效应依赖菌株、群落组合、营养底物和宿主状态。同一代谢物或免疫回路在稳态、急性感染和慢性炎症中的结果可能不同；所谓菌群失调描述群落结构或功能与疾病状态相关的偏移，本身不能单独证明哪一种变化是病因。宿主相关微生物群的生态框架见[微生物生态学](../micro/ecology_applications.md#host-associated-microbiota)，病原体怎样突破屏障见[感染、宿主防御与免疫逃逸](../micro/infection_immunity.md#layered-host-defense)。

## 肠—肝轴在门静脉下游继续筛查 { #gut-liver-axis }

肠道吸收的营养与微生物产物经门静脉进入肝窦，使肝脏成为黏膜之后的重要免疫筛查站。Kupffer 细胞、肝窦内皮细胞、树突状细胞和淋巴细胞处在缓慢而充分接触的血流环境中，能够清除颗粒和微生物产物，也能在稳态下形成偏向耐受的信号环境。肝脏同时接收肝动脉血并保留有效抗感染能力，故其任务是平衡清除、耐受与效应，而非简单充当肠黏膜之后的“第二道防线”。[^liver-immunity]

当肠屏障通透性增加、微生物产物负荷上升或肝内清除和调节发生改变时，这一接口可转向持续炎症。反过来，胆汁酸组成和肝胆分泌也会重塑肠腔环境与微生物群。肝胆的一般代谢与分泌功能见[肝胆生理](../physiology/digestive/hepatobiliary.md)，本页只保留其与黏膜免疫相接的门静脉逻辑。

## 屏障破坏会把稳态接触转化为组织炎症 { #barrier-breakdown }

机械损伤、感染、缺血、毒素或异常免疫效应可减少黏液、破坏连接并杀伤上皮。腔内对象越过原有空间边界后，固有层或真皮细胞同时接收到微生物配体、细胞损伤信号和炎症因子，随后募集粒细胞、单核细胞与效应淋巴细胞。短暂反应清除对象并促进上皮再生；刺激持续存在时，炎症介质、蛋白酶和氧化产物又会进一步损伤连接与基质，形成通透性升高—易位—炎症的正反馈。

屏障病变的结局仍取决于部位。皮肤破损增加组织暴露，传导气道的纤毛失效延长颗粒停留，肺泡渗出直接妨碍气体交换，肠屏障破坏则扩大食物与微生物成分进入固有层及门静脉的机会。理解这些疾病不能只测量“炎症强弱”，还要判断隔离层、取样途径、归巢程序、耐受网络和修复能力中的哪一环首先改变。

[^iga-function]: 分泌型 IgA 的免疫排斥、黏液滞留、微生物群调节及较低炎症效应，参见 Mantis 等 [Secretory IgA's complex roles in immunity and mucosal homeostasis in the gut](https://www.nature.com/articles/mi201141)及 Herr [Secret(ory) revealed](https://www.nature.com/articles/s41422-020-0351-4)。
[^gut-homing]: 视黄酸赋予 α4β7／CCR9 归巢程序、MAdCAM-1 与 CCL25 的组织地址，参见 Sigmundsdottir 与 Butcher [Environmental cues, dendritic cells and the programming of tissue-selective lymphocyte trafficking](https://www.nature.com/articles/ni.f.208)及 [Intestinal dendritic cells in health and gut inflammation](https://pmc.ncbi.nlm.nih.gov/articles/PMC6291504/)。
[^regional-homing]: 肠道诱导部位与效应部位相接及不同黏膜的组织偏向，参见 Turner 等 [Guarding the perimeter: protection of the mucosa by tissue-resident memory T cells](https://www.nature.com/articles/mi201296)；非肠黏膜归巢的近期机制见 Liu 等 [A lymphocyte chemoaffinity axis for lung, non-intestinal mucosae and CNS](https://www.nature.com/articles/s41586-024-08043-2)。
[^oral-tolerance]: 肠系膜淋巴结中视黄酸／TGF-β、诱导型 Treg、肠道归巢和固有层 IL-10 支持的多步骤模型，参见 Pabst 与 Mowat [Oral tolerance to food protein](https://www.nature.com/articles/mi20124)及 NCBI Bookshelf [Mucosal Immunity](https://www.ncbi.nlm.nih.gov/books/NBK6628/)。
[^microbiota-resistance]: 共生群落的定植抗性、代谢物与宿主免疫双向作用，参见 Pickard 等 [Gut microbiota: role in pathogen colonization, immune responses, and inflammatory disease](https://pmc.ncbi.nlm.nih.gov/articles/PMC5390822/)；IgA 对微生物群的作用仍有机制缺口，参见 Pabst 与 Slack 的综述。
[^liver-immunity]: 门静脉输入、Kupffer 细胞、肝窦内皮与耐受—防御平衡，参见 Jenne 与 Kubes [Immune surveillance by the liver](https://www.nature.com/articles/ni.2691)及 Robinson 等 [The immunoregulatory function of liver sinusoidal endothelial cells](https://pmc.ncbi.nlm.nih.gov/articles/PMC6138562/)；旧素材中的“网状内皮系统第二道防线”据此改写。
