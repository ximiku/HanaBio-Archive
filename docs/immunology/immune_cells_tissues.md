# 免疫细胞、组织与迁移

免疫系统没有一个与心脏或肾脏相似的单一中心。它由散布在骨髓、胸腺、淋巴器官、屏障组织和血液中的细胞共同构成，又借助血管、淋巴管和组织间隙保持联系。血液中的白细胞只是这个系统短暂经过循环区室的一部分；许多巨噬细胞、肥大细胞和固有淋巴样细胞长期驻留于组织，初始淋巴细胞则反复巡行于血液和次级淋巴器官之间。理解免疫细胞，因而需要同时追踪其发育来源、组织位置与迁移路线。

这种空间组织解决了免疫应答的一个基本困难：能识别某一表位的初始 B 或 T 细胞在全部淋巴细胞中十分稀少，而抗原可能从任何一处屏障进入。组织中的哨兵细胞先感知局部变化，淋巴管把游离抗原和迁移细胞带到引流淋巴结，血源性抗原则进入脾；初始淋巴细胞不断穿行于这些汇聚点，使抗原、抗原呈递细胞和相应克隆相遇。[^immune-system-organization]

## 造血来源与组织身份 { #lineages-and-identities }

成年人的多数免疫细胞最终来自骨髓造血干细胞。经典谱系图把后代分成髓系和淋巴系，再分别连接粒细胞、单核细胞、树突状细胞、B 细胞、T 细胞、NK 细胞和其他固有淋巴样细胞。这张图适合标示亲缘与发育依赖，却不是一串所有细胞都必须依次经过的封闭格子；造血祖细胞存在连续的谱系偏向，炎症也会改变细胞生成与释放。造血干细胞龛、需求反馈和外周血计数的动力学见[血细胞生理](../physiology/blood/blood_cell.md#hematopoiesis)。

“髓系”与“固有免疫”、“淋巴系”与“适应性免疫”也不是两组完全重合的词。T、B 细胞以重排形成的抗原受体建立克隆特异性，是适应性免疫的主体；NK 细胞和固有淋巴样细胞同属淋巴系，却主要依靠胚系编码受体和细胞因子信号作出快速反应。反过来，树突状细胞和巨噬细胞不仅执行固有防御，也通过抗原呈递、共刺激和细胞因子塑造适应性应答。

### 粒细胞与肥大细胞 { #granulocytes-mast-cells }

中性粒细胞在骨髓中大量生成并保有成熟储备，进入血液后可在炎症信号驱动下迅速募集到组织。它们以吞噬、颗粒内容物、活性氧及其他胞外效应限制微生物，作用强而寿命和组织停留通常较短。嗜酸性粒细胞较多分布在黏膜等组织，参与抗蠕虫反应、2 型免疫和组织稳态，其颗粒蛋白在释放失控时也会损伤上皮。嗜碱性粒细胞数量很少，主要在血中巡行，以高亲和力 IgE 受体、组胺、脂质介质和细胞因子参与 2 型炎症。

肥大细胞的成熟形态常驻于皮肤、黏膜和血管周围。它们与嗜碱性粒细胞共享若干受体和颗粒介质，却是发育、组织位置和寿命均不同的细胞群，不能把二者简单视为血液型与组织型的同一种细胞。不同粒细胞与肥大细胞的净作用取决于刺激、组织和时程；吞噬杀伤由[固有免疫识别与炎症](innate_recognition_inflammation.md)展开，IgE 相关效应则归入[超敏反应与过敏](hypersensitivity_allergy.md)。[^granulocyte-mast-cell]

### 单核吞噬细胞与树突状细胞 { #mononuclear-phagocytes-dendritic-cells }

单核细胞在血中循环，可在稳态监视血管，也可在炎症时进入组织并形成具有吞噬、分泌或抗原呈递能力的单核来源细胞。许多组织驻留巨噬细胞却在出生前已经由胚胎期前体播种，并可在成年组织内自行维持；小胶质细胞、Kupffer 细胞和肺泡巨噬细胞等还接受各自组织龛的信号，取得清除细胞残骸、回收代谢物、支持器官发育或维持屏障等专门功能。某些组织或炎症后的空缺会由循环单核细胞补充，因此“所有巨噬细胞都由血中单核细胞变成”和“驻留巨噬细胞从不被替换”都无法概括真实的来源异质性。[^resident-macrophages]

树突状细胞（dendritic cell, DC）也是一组异质细胞。常规 DC 中的 cDC1 和 cDC2 在抗原摄取、呈递对象与诱导的 T 细胞反应上各有偏重；浆细胞样 DC（pDC）以核酸感知和大量产生 I 型干扰素著称；炎症环境还可产生单核来源 DC 样细胞。组织中的 DC 摄取抗原后可提高 CCR7 等迁移程序，经传入淋巴管到达引流淋巴结。激活初始 T 细胞的能力取决于 DC 亚群、成熟状态、抗原加工、共刺激和组织环境，不能脱离这些条件给所有树突状细胞冠以固定的“最强抗原呈递细胞”称号。[^dendritic-cell-nomenclature]

滤泡树突状细胞（follicular dendritic cell, FDC）虽有相似名称，却是位于 B 细胞滤泡内的间质来源基质细胞，并非上述造血来源的常规 DC。FDC 用补体受体和 Fc 受体长期保留未加工的抗原复合物，为 B 细胞选择提供表面抗原；经典 DC 则加工抗原并以 MHC—肽复合物刺激 T 细胞。名称相近的两类细胞承担不同的呈递任务。[^follicular-dendritic-cells]

### 淋巴细胞的多条功能路线 { #lymphocyte-routes }

B 细胞在骨髓完成主要发育步骤，T 细胞前体则进入胸腺接受选择；成熟的初始 B、T 细胞离开初级淋巴器官后，在次级淋巴器官间巡行。抗原受体重排、选择和成熟细胞库将在[淋巴细胞发育与受体多样性](lymphocyte_development_repertoire.md)中详述，本页关注这些细胞取得成熟身份后的空间路线。

NK 细胞综合多种激活与抑制受体信号，能够识别某些病毒感染细胞和转化细胞，并以穿孔素—颗粒酶等装置执行细胞毒作用。ILC1、ILC2 和 ILC3 等固有淋巴样细胞大多驻留于组织，能对上皮和髓系细胞发出的细胞因子迅速响应，参与屏障防御、组织修复和炎症调节。它们与不同辅助性 T 细胞程序存在功能上的相似性，但没有重排形成的 TCR。NK、ILC1、ILC2、ILC3 的界限还具有物种、组织和状态依赖性，细胞可塑性使少数表面标志不足以单独定义功能。[^innate-lymphoid-cells]

γδ T 细胞和自然杀伤 T（NKT）细胞保有重排的 TCR，却常以受限的受体库、特定抗原形式和快速效应联系固有与适应性免疫。NKT 细胞由 CD1d 呈递脂质抗原，不能仅凭同时表达某些 T 与 NK 标志就定义；以“K 细胞”“第三淋巴细胞”“第四淋巴细胞”为主干的旧分类，也已经被受体、发育与功能证据更清晰的命名体系取代。

## 初级淋巴器官提供发育与选择环境 { #primary-lymphoid-organs }

骨髓既是成年期主要造血器官，也是 B 细胞发育和中枢耐受的重要场所。B 细胞前体在特定基质细胞和细胞因子形成的微环境中逐步重排免疫球蛋白基因，能够表达功能性受体且通过选择的细胞才进入外周。骨髓也接纳长寿命浆细胞和部分记忆细胞，因此它不只是新生免疫细胞的“工厂”，还是维持既有免疫应答的组织龛。

胸腺接纳骨髓来源的 T 细胞前体。细胞依次经过皮质和髓质微环境，在胸腺上皮细胞、树突状细胞及其他基质与造血细胞提供的信号中完成 TCR 选择、CD4／CD8 谱系决定和中枢耐受。大量未获得合适信号或自身反应性过强的细胞在此被清除。胸腺随年龄出现显著脂肪化和输出下降，但并不等于成年后瞬间完全失去功能；外周 T 细胞库同时依靠既有克隆的存活和稳态增殖维持。

鸟类的法氏囊是 B 细胞发育的重要初级淋巴器官，“B cell”这一名称的历史由此而来；哺乳动物没有法氏囊，主要由骨髓承担相应发育环境。比较不同脊椎动物时，器官位置可以变化，初级淋巴器官所解决的共同问题仍是生成具有多样受体、同时受选择约束的成熟淋巴细胞库。[^primary-lymphoid-organs]

## 次级淋巴器官汇聚抗原与淋巴细胞 { #secondary-lymphoid-organs }

淋巴结、脾和黏膜相关淋巴组织是成熟淋巴细胞遇到抗原并启动适应性应答的主要场所。它们并非装满淋巴细胞的均质袋囊：血管和淋巴内皮控制出入，成纤维网状细胞、FDC 等基质细胞建立趋化因子和生存因子分区，T、B 细胞及不同抗原呈递细胞因此在微米到毫米尺度上被有序排列。[^lymphoid-stroma]

### 淋巴结与组织引流 { #lymph-node-drainage }

组织间液和其中的可溶性分子进入盲端毛细淋巴管，随后沿集合淋巴管流向区域淋巴结。淋巴结的传入淋巴管把游离抗原、囊泡以及来自外周组织的迁移 DC 带入被膜下窦；输出则由门部的传出淋巴管离开。全身淋巴最终主要经胸导管或右淋巴导管回到静脉循环。液体形成、瓣膜与回流动力见[组织液的淋巴回流](../physiology/blood/blood_vessel.md#lymphatic-return)，此处的重点是淋巴结怎样利用这条流路取样所引流的组织。

淋巴结外层皮质的 B 细胞形成滤泡，较深的副皮质为 T 细胞区，髓质则含髓索、窦道和输出通路。FDC 产生的 CXCL13 帮助 CXCR5 阳性 B 细胞定位于滤泡；成纤维网状细胞形成的网络及 CCL19／CCL21 帮助 CCR7 阳性的 T 细胞和 DC 汇聚于 T 细胞区。分区并非隔绝：激活后细胞改变趋化受体，在 T—B 边界、生发中心和髓质之间重新排列，使细胞接触按应答阶段发生。[^lymph-node-zoning]

### 脾的血液监视 { #spleen-blood-surveillance }

脾没有把外周组织淋巴带入器官的传入淋巴管，它直接取样血液。白髓围绕中央小动脉形成免疫区室：动脉周围淋巴鞘以 T 细胞为主，相邻滤泡以 B 细胞为主，边缘区接收来自血流的抗原并连接抗原捕获细胞与淋巴细胞。红髓则通过索和窦筛查红细胞、回收血液成分。由此，局部皮肤感染的抗原首先汇入引流淋巴结，而血中微生物、颗粒和衰老红细胞主要接受脾的监视；两种器官处理的输入通道不同。[^spleen-organization]

### 黏膜淋巴组织与可诱导结构 { #mucosal-tertiary-lymphoid-tissues }

扁桃体、Peyer 集合淋巴结、阑尾以及其他弥散或成组的黏膜淋巴组织紧邻上皮取样界面。它们既要应对病原体，又长期暴露于食物、吸入颗粒和共生微生物，因此在细胞组成、归巢分子和效应产物上形成专门化。上皮取样、分泌型 IgA 和黏膜耐受见[屏障与黏膜免疫](mucosal_immunity.md)。

慢性炎症、持续感染、自身免疫或肿瘤中，非淋巴器官内还可能形成三级淋巴结构（tertiary lymphoid structure, TLS）。它们可出现 B／T 细胞分区、FDC 网络和高内皮微静脉样结构，但成熟度和功能差异很大；“出现淋巴细胞团块”并不足以证明已经形成具备完整生发中心反应的 TLS。

## 白细胞迁移依赖分子地址 { #leukocyte-trafficking }

白细胞从血液进入组织通常经历捕获与滚动、趋化因子触发、整联蛋白介导的牢固黏附、腔面爬行和跨内皮迁移。选择素与糖基化配体适合承受血流中的短暂结合；趋化因子受体信号使整联蛋白迅速改变亲和力和聚集状态；LFA-1、VLA-4 等整联蛋白再与 ICAM、VCAM 等内皮配体建立较强连接。跨过内皮后，细胞还要穿越基底膜并沿组织内的趋化因子、脂质和其他信号定位。选择素、Ig 超家族和整联蛋白的一般结构见[黏附分子的识别语法](../cell/cell_interactions.md#adhesion-molecules)，炎症内皮的募集时序见[白细胞募集](../physiology/pathophysiology/fever_inflammation_stress.md#leukocyte-recruitment)。

这套多步过程使用共同的分子类别，却可通过不同组合形成“地址”。稳态淋巴结的高内皮微静脉（high endothelial venule, HEV）在管腔面提供外周淋巴结地址素（PNAd）及趋化因子。初始 T、B 细胞的 L-选择素（CD62L）先介导滚动，CCR7 感知 CCL19／CCL21 后激活 LFA-1，细胞由此牢固黏附并进入淋巴结。肠相关组织还突出 α4β7—MAdCAM-1 等组合；炎症组织则按局部诱导的选择素、黏附分子和趋化因子募集相应效应细胞。[^homing-addresses]

## 淋巴细胞再循环与应答后的改道 { #lymphocyte-recirculation }

未遇抗原的初始淋巴细胞从血液经 HEV 进入淋巴结，在基质网络上移动并扫描抗原呈递细胞。若没有获得相应抗原和必要的辅助信号，它们对淋巴结内趋化信号的敏感性逐渐改变，并借助鞘氨醇-1-磷酸受体 1（S1PR1）感知由组织向淋巴升高的 S1P 环境，进入输出淋巴管。传出淋巴汇入更大淋巴管，最终回到血液，开始下一轮巡查。脾中的淋巴细胞直接从血液进入并返回血液，不经过同一套传入—传出淋巴路线。[^lymphocyte-recirculation]

识别抗原并接受共刺激后，淋巴细胞会暂时滞留、增殖和分化，随后重写迁移受体组合。部分效应 T 细胞降低 CD62L 和 CCR7，取得指向炎症皮肤、肠道或其他组织的受体；抗体分泌细胞可迁往骨髓或黏膜组织；中央记忆 T 细胞保留进入次级淋巴器官的能力，效应记忆细胞更多巡查外周，组织驻留记忆 T 细胞则在局部长期维持。上述名称描述的是迁移与功能偏重，不表示细胞永远固定在互不转换的盒子里。

组织中的 DC 走的是互补路线：它们在外周摄取抗原和组织信息，成熟过程中提高 CCR7，沿 CCL21 等信号进入传入淋巴管，再到达引流淋巴结 T 细胞区。可溶性小抗原也能随淋巴进入结内并通过窦道或导管系统被相应细胞取得；较大颗粒、免疫复合物和细胞携带抗原则具有不同的转运与截留方式。因此“抗原到达淋巴结”不等于只有 DC 搬运一种路线，也不等于进入器官的全部抗原都会启动免疫。

## 空间相遇决定应答能否发生 { #spatial-encounter }

次级淋巴器官把三个原本分散的过程压缩到共同空间：外周组织或血液带来抗原，先天细胞带来刺激背景，持续再循环则不断更换候选淋巴细胞。DC 在 T 细胞区呈递加工后的肽，B 细胞在滤泡和被膜下区域取得较完整的抗原；相应克隆受激活后再在 T—B 边界、生发中心或效应区建立新的细胞组合。抗原形式、进入路线和基质分区共同决定谁先看见抗原，以及随后形成耐受、局部防御还是全身应答。

这一组织原则也解释了为什么外周血检测只能提供有限截面。血中某类细胞增减可能来自骨髓释放、去边集、进入组织、淋巴器官滞留或死亡的任意组合；组织内细胞的来源与状态也不能仅凭一个表面标志推出。可靠解释需要把细胞身份、所在区室、迁移方向和采样时点放在一起，而不是把血涂片中的五类白细胞当作整个免疫系统的静态清单。

[^dendritic-cell-nomenclature]: 单核细胞与 DC 命名由 [IUIS MonoDC 命名小组](https://iuis.org/committees/nom/nomenclature-sub-committees/nomenclature-of-monocytes-and-dendritic-cells-in-blood-sc/)持续维护；cDC、pDC 和单核来源细胞的发育边界参见 Durai 与 Murphy [Models of dendritic cell development correlate ontogeny with function](https://pmc.ncbi.nlm.nih.gov/articles/PMC10931540/)。
[^follicular-dendritic-cells]: FDC 的间质来源、CXCL13 分泌及抗原复合物保留，参见 Jarjour 等 [Characterization of human FDCs reveals regulation of T cells and antigen presentation to B cells](https://pmc.ncbi.nlm.nih.gov/articles/PMC8404474/) 与 Allen、Cyster [Follicular dendritic cell networks of primary follicles and germinal centers](https://pmc.ncbi.nlm.nih.gov/articles/PMC2366796/)。
[^innate-lymphoid-cells]: ILC1、ILC2、ILC3、NK 与淋巴组织诱导细胞的命名历史、组织驻留和功能边界，参见 Vivier [The discovery of innate lymphoid cells](https://www.nature.com/articles/s41577-021-00595-y) 与 Bal、Golebski、Spits [Plasticity of innate lymphoid cell subsets](https://www.nature.com/articles/s41577-020-0282-9)。
[^primary-lymphoid-organs]: 骨髓、胸腺与成熟淋巴细胞输出的基本关系，参见 NCBI Bookshelf [The components of the immune system](https://www.ncbi.nlm.nih.gov/books/NBK27092/)；受体生成与中枢选择在后续专页展开。
[^lymphoid-stroma]: 次级淋巴器官的造血细胞与基质分区，以及 FRC、FDC、血管和淋巴内皮的组织作用，参见 Rodda 等 [Single-Cell RNA Sequencing of Lymph Node Stromal Cells Reveals Niche-Associated Heterogeneity](https://pmc.ncbi.nlm.nih.gov/articles/PMC5971117/)。
[^lymph-node-zoning]: 淋巴结 B 细胞滤泡、T 细胞副皮质和抗原输入见 NCBI Bookshelf [The components of the immune system](https://www.ncbi.nlm.nih.gov/books/NBK27092/)；CCL19／CCL21 与 CXCL13 建立的细胞分区参见 Rodda 等的淋巴结基质细胞图谱。
[^spleen-organization]: 脾对白髓与红髓的分工、PALS 和 B 细胞滤泡组织，参见 NCBI Bookshelf [The components of the immune system](https://www.ncbi.nlm.nih.gov/books/NBK27092/)。
[^homing-addresses]: HEV 上 PNAd、CCL21 与 ICAM 配合 L-选择素、CCR7 和 LFA-1 完成淋巴细胞进入，参见 Ager [High Endothelial Venules and Other Blood Vessels](https://pmc.ncbi.nlm.nih.gov/articles/PMC5289948/)；黏膜与外周地址组合存在组织和物种差异。
[^lymphocyte-recirculation]: 初始淋巴细胞在血液、次级淋巴器官和淋巴之间的循环，参见 Alberts 等 [Lymphocytes and the Cellular Basis of Adaptive Immunity](https://www.ncbi.nlm.nih.gov/books/NBK26921/)；CCR7 引导进入与 S1PR1 引导输出的关系参见 Förster、Davalos-Misslitz、Rot [CCR7 and its ligands: balancing immunity and tolerance](https://pubmed.ncbi.nlm.nih.gov/18379575/)。
