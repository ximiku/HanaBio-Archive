# 超敏反应与过敏

免疫效应原本用于清除病原体、毒素和异常细胞，但同一套抗体、补体、粒细胞和 T 细胞若在不合适的靶标、强度或时程中运行，也会成为组织损伤来源。超敏反应概括这类由免疫机制引起、对宿主有害的反应；它既可以针对环境抗原，也可以出现在自身免疫和同种异体免疫中。

过敏是由特定免疫机制介导的超敏反应，诱因通常是多数人在相同暴露下可以耐受的外源物质。花粉、食物或药物只有在特定个体和情境中引起相应免疫反应时才成为过敏原。过敏常由 IgE 驱动，却也包括 T 细胞介导或多种机制并存的疾病；把“过敏”与“立即发生的 IgE 反应”完全画等号，会遗漏接触性皮炎和部分食物、药物反应。[^allergy-nomenclature]

## 四型框架按最终效应机制定位损伤 { #gell-coombs-framework }

Gell–Coombs 分类把超敏反应分为四种机制：I 型由 IgE 装载的肥大细胞和嗜碱性粒细胞快速启动；II 型由针对细胞表面或细胞外基质固定抗原的 IgG／IgM 改变功能或招募效应；III 型由可溶性抗原—抗体复合物形成、清除和沉积失衡引起；IV 型由抗原特异性 T 细胞组织炎症或直接杀伤。编号说明主要执行者和靶抗原位置，并不代表严重程度，也不能只凭发作快慢判定。[^hypersensitivity-classification]

真实疾病可以在不同阶段使用多个模块。哮喘可同时包含 IgE—肥大细胞的即刻反应、嗜酸性粒细胞和 2 型细胞因子维持的晚期炎症以及上皮重塑；自身免疫病也可能同时具有细胞表面抗体、免疫复合物和 T 细胞效应。四型框架最适合用来追问“当下这处损伤由什么分子和细胞完成”，而不是给整名疾病贴一张永久标签。

## I 型反应的致敏与再暴露 { #type-i-hypersensitivity }

### 致敏把特异性 IgE 装到效应细胞表面 { #allergic-sensitization }

过敏原从皮肤、呼吸道或消化道进入后，是否形成 IgE 应答取决于屏障状态、抗原剂量与蛋白酶活性、树突状细胞、既有微生物环境和宿主遗传背景。受损或被刺激的上皮可释放 TSLP、IL-25、IL-33 等警报因子，影响树突状细胞和 ILC2；抗原特异性 Th2／Tfh 细胞再以 IL-4、IL-13 和 CD40L 支持 B 细胞向 IgE 类别转换。这个启动阶段可以没有明显症状，却留下分泌 IgE 的浆细胞和可再次产生 IgE 的记忆克隆。[^allergic-sensitization]

分泌出的 IgE 以很高亲和力结合肥大细胞和嗜碱性粒细胞的 Fc$\varepsilon$RI，使这些细胞在抗原离开后仍保留对应识别面，这一状态称致敏。肥大细胞是皮肤、黏膜和血管周围的长期组织居民，嗜碱性粒细胞主要在血液循环并可被招募进组织；两者共享 IgE—Fc$\varepsilon$RI 轴，却不是同一种细胞的组织型与循环型。它们的谱系和位置见[免疫细胞、组织与迁移](immune_cells_tissues.md#granulocytes-mast-cells)。

### 再暴露把受体交联转换为介质释放 { #mast-cell-activation }

再次暴露时，多价过敏原同时结合邻近 IgE，使 Fc$\varepsilon$RI 聚集并经 Lyn、SYK 等信号启动 Ca$^{2+}$ 上升和脱颗粒。组胺、类胰蛋白酶等预先储存的介质可在数分钟内释放；细胞随后新合成白三烯、前列腺素和多种细胞因子。血管扩张和通透性增加、感觉神经刺激、黏液分泌和平滑肌收缩在鼻、眼、皮肤、气道或肠道产生不同症状，局部结果取决于肥大细胞亚群、抗原入口和周围组织。[^mast-cell-mediators]

早期反应之后，趋化因子与 IL-4、IL-5、IL-13 等信号可招募嗜酸性粒细胞、Th2 细胞、ILC2 和其他髓系细胞，形成数小时以后仍持续的晚期炎症。嗜酸性粒细胞可代谢部分介质并参与调节，也会释放主要碱性蛋白、嗜酸性粒细胞过氧化物酶、脂质介质和细胞因子，损伤气道等屏障。旧素材把它概括为抑制肥大细胞反应，遗漏了其在哮喘等疾病中的重要致损作用。[^eosinophilic-inflammation]

### 局部反应可扩展为全身性过敏反应 { #anaphylaxis }

当介质在全身快速释放并同时影响呼吸道、循环、皮肤或消化道时，可形成全身性过敏反应（anaphylaxis）。血管张力下降、毛细血管渗漏、支气管收缩和黏膜水肿可以迅速危及生命，皮肤表现并非诊断或严重反应的必要条件。同一诱因的结局还受剂量、进入途径、运动、感染、药物和基础疾病等辅助因素影响，既往较轻反应不能保证下次仍轻。[^anaphylaxis-guidance]

全身性过敏反应是临床急症，现行指南把肌内注射肾上腺素列为一线治疗；抗组胺药可以缓解部分皮肤症状，却不能替代肾上腺素纠正气道和循环危险。这里强调的是效应机制与治疗靶点的对应，休克时压力、流量和组织灌注的解耦见[休克与器官功能障碍](../physiology/pathophysiology/shock_organ_failure.md#shock-mechanisms)。

## II 型反应的固定靶标抗体效应 { #type-ii-hypersensitivity }

II 型反应中的 IgG 或 IgM 结合细胞表面、基底膜或其他细胞外基质抗原。抗体包被细胞后可招募吞噬细胞的 Fc$\gamma$ 受体、激活补体或让自然杀伤（NK）细胞执行抗体依赖的细胞毒；基质上的抗体则把中性粒细胞和补体反应固定在组织结构旁。输血不相容造成的红细胞清除、自身免疫性溶血和针对基底膜的炎症都可沿这些路线发生。[^type-ii-effectors]

“细胞毒型”不足以覆盖 II 型的全部结局。抗体还可改变受体功能而不立即杀死细胞：Graves 病抗体持续激动 TSH 受体，重症肌无力抗体可阻断、促使内化或经补体损伤乙酰胆碱受体，Lambert–Eaton 肌无力综合征中的抗体则减少突触前电压门控 Ca$^{2+}$ 通道功能。抗体究竟造成清除、炎症、阻断还是激动，取决于表位位置、抗体亚类与 Fc 性质、靶分子的生理任务和所在组织。[^type-ii-functional-antibodies]

自身抗体、同种抗体和药物附着于细胞后诱导的抗体都可进入 II 型效应；分类依据的是固定靶标和执行方式，而不是抗原是否来自自身。输血相容性及血细胞后果保留在生理栏目，自身耐受破坏的上游机制见[免疫耐受与自身免疫](tolerance_autoimmunity.md#autoimmune-effectors)。

## III 型反应的免疫复合物清除失衡 { #type-iii-hypersensitivity }

可溶性抗原与 IgG／IgM 在血液或组织液中结合时会形成大小不断变化的免疫复合物。大复合物常较容易被补体、红细胞 CR1 和肝脾吞噬系统清除；抗原相对过量时形成的较小或中等复合物可在循环中停留。复合物的电荷、亲合力、局部生成和血流动力学共同影响它们是否滞留在肾小球、滑膜、皮肤小血管或其他过滤与高压界面，因此 III 型反应不能简化成“复合物越大越容易沉积”。[^immune-complex-formation]

沉积复合物激活经典补体途径，C3a、C5a 促进血管反应和中性粒细胞募集；白细胞以 Fc$\gamma$ 受体抓住固定在基质上的复合物，却难以吞下整片组织，于是把蛋白酶、活性氧和其他颗粒成分释放到细胞外，造成血管炎和周围组织损伤。[补体](complement.md#anaphylatoxins)与 Fc 受体在这里是抗体和先天效应之间的桥梁，而非独立的另两种超敏反应。

局部注入抗原并在已有抗体背景下形成复合物，可产生 Arthus 反应；大量可溶性抗原持续进入循环则可能造成发热、皮疹、关节症状和肾脏受累等全身性血清病。旧式异种动物抗血清同时提供大量外来蛋白，初次或再次使用都可能形成相应抗体和免疫复合物；现代人源免疫球蛋白及单克隆制剂降低了部分风险，但具体反应仍由制剂、既有抗体和给药情境决定。[^serum-sickness]

## IV 型反应的 T 细胞效应 { #type-iv-hypersensitivity }

IV 型反应不依赖抗体作为最终执行者。致敏阶段，树突状细胞向初始 T 细胞呈递蛋白肽，或呈递小化学物与自身蛋白形成的半抗原复合物；扩增后的效应和记忆 T 细胞在再次暴露时回到组织。Th1 细胞的 IFN-$\gamma$ 可激活巨噬细胞，Th17 相关因子可招募中性粒细胞，2 型 T 细胞可组织嗜酸性炎症，CD8 T 细胞则通过穿孔素—颗粒酶或死亡受体杀伤靶细胞。IV 型是一组 T 细胞效应模块，不是旧资料所称固定的“迟发型超敏 T 细胞”谱系。[^type-iv-effectors]

抗原呈递、T 细胞迁入和细胞募集通常使可见反应在数小时至数日后达到高峰，“迟发型”由此得名；时间只是结果，不能代替机制判定。结核菌素皮试利用记忆 T 细胞与单核细胞在皮内形成的局部反应来读取既往致敏，测到的是细胞免疫反应而不是活动性结核病本身。

过敏性接触性皮炎展示了完整的致敏—激发两阶段。镍盐、植物小分子或其他接触致敏物改变自身蛋白、MHC 配体或脂质呈递，皮肤树突状细胞启动相应 T 细胞；再次接触后，CD4、CD8 T 细胞和先天细胞共同造成湿疹样炎症。刺激性接触性皮炎则可由化学或物理损伤直接启动先天炎症，不要求抗原特异性记忆；相似外观不能证明两者机制相同。[^contact-dermatitis]

## 非 IgE 肥大细胞激活 { #non-ige-hypersensitivity }

补体片段、某些药物、神经肽和组织损伤信号可以通过 C3aR／C5aR、MRGPRX2 或其他受体直接激活肥大细胞，产生与 IgE 过敏相似的潮红、风团、支气管收缩或全身反应。此时没有过敏原特异性 IgE 和经典致敏阶段，却仍可能发生严重介质释放。现代命名倾向把这类反应描述为非 IgE 介导的肥大细胞激活或非过敏性超敏反应，避免“假性过敏”让人误以为症状不真实。[^non-ige-mast-cell-activation]

并非所有非 IgE 反应都属于这一类。T 细胞介导的接触过敏和部分食物、药物超敏仍是抗原特异性免疫反应；乳糖酶缺乏、药物正常药理作用或食物毒素造成的症状则不由适应性免疫启动。区分这些路线需要暴露时序、器官表现和有针对性的检测，不能从“没有特异性 IgE”直接推出没有过敏或没有风险。

## 致敏证据与临床反应 { #allergy-evidence }

皮肤点刺试验或血清过敏原特异性 IgE 说明受试者已经产生相应致敏，数值受到总 IgE、交叉反应糖链、相关蛋白家族和检测平台影响。致敏者可能在日常暴露时没有症状，临床过敏者也可能由非 IgE 机制驱动；总 IgE 升高更不能指出具体诱因。诊断需要先建立可信的暴露—症状关系，再选择针对候选过敏原的检测，必要时由专业人员在有救治条件下进行激发试验。[^allergy-diagnosis]

斑贴试验把候选接触物在受控条件下留置于皮肤，主要读取延迟的 T 细胞反应，与点刺试验的即刻肥大细胞读出不同。两种阳性结果都需要结合临床相关性解释，不能把免疫学致敏、一次检测阳性和需要长期回避某物视为同一结论。

特应性（atopy）描述对常见环境抗原形成 IgE 致敏和相关疾病的个体或家族倾向；它提高过敏性鼻炎、部分哮喘或特应性皮炎的概率，却不是任何一种疾病的充分条件。哮喘、荨麻疹和皮炎都包含免疫学不同的内型，疾病名称不能替代 IgE、T 细胞、嗜酸性粒细胞或非免疫因素的实际证据。治疗若要精确作用于 IgE、IL-4／IL-13、IL-5、肥大细胞或其他节点，也必须先说明哪个机制真正维持当前疾病；具体检测与干预证据留给[免疫检测与免疫干预](immunological_methods_therapy.md)。
