# 合作、冲突与社会性进化

同一个社会关系往往同时包含合作与冲突。亲鸟供食使亲本和幼体都能留下更多后代，幼体却可能索取超过亲本最适水平的资源；工蜂共同维持蜂巢，蜂王、工蜂和不同父系的工蜂又可能对雄蜂来源与雌雄投资比例有不同利益；豆科植物和根瘤菌交换碳源与固定氮，双方仍会减少对低回报伙伴的投入。社会进化研究的核心，是把这些相互作用转化为可比较的存活、繁殖和遗传传递后果。

经典动物行为学先描述谁接近谁、谁照料幼体、谁争夺繁殖和群体怎样分工，这条观察路径不可省略。鱼群、鸟群、灵长类家庭、蜜蜂与白蚁巢群的形态和行为见[社会组织与群体生活](../zoology/behavior/social_organization.md)；本页在此基础上追踪选择如何作用于互动双方、亲属、群体和基因组中的不同遗传单位。现代亲子鉴定、群体遗传和基因组证据用于检验这些关系，不把真实社会生活压缩成一个公式。

## 社会行为按行动者与受作用者的适合度后果分类 { #social-fitness-effects }

社会行为的功能名称取决于相对于“不采取该行为”的反事实后果。若行动者与受作用者的直接适合度都增加，属于**相互受益**或互利合作；行动者降低而受作用者增加，称为**利他**；行动者增加、受作用者降低，是自利或剥削；双方都降低而行为仍受选择维持，才属于严格意义的**恶意行为**（spite）。合作是一个较宽的词，可包括相互受益和由间接收益或延迟回报维持的利他。[^social-semantics]

这些名称不描述动机。一只哨兵站到高处后若更早发现天敌、也更容易逃入洞穴，它可能在帮助同伴的同时获得直接收益；亲鸟冒险引开捕食者，是在保护自己的后代；受优势者威胁而守巢的从属个体，则可能以劳动换取留群。行为看起来勇敢、顺从或残酷，都不能替代对存活与繁殖后果的测量。

适合度后果还须选定时间窗和竞争基准。一次分享食物可能降低当日能量，却换来长期伙伴；帮助增加的幼体若随后与帮助者的后代争夺同一繁殖空位，最初收益会被部分抵消。旧材料所说“不加鉴别、无代价的利他”若把收益均匀给所有基因型，又完全不改变行动者的相对繁殖，帮助等位基因至多是中性的；一旦受益对象、竞争地点或未来回报并不随机，结论就要重新核算。

## 非亲缘合作由即时收益、重复互动与执行维持 { #nonkin-cooperation }

没有近亲关系的个体可以在一次互动中同时获益。合作捕猎者共同制服单独无法捕获的猎物，群体成员联合防御或交换互补服务，收益随参与者行动即时产生。这类**共同利益**不要求参与者先付出净适合度代价，也不要求以后精确偿还。伙伴彼此依赖时，一个成员状态下降会降低其他成员的收益，选择因而可维持协调、减少无效竞争并保留高质量伙伴。

**直接互惠**讨论的是另一条路径：个体当前付出代价帮助特定对象，以后在角色反转时由同一对象回报。重复相遇、个体识别、足够高的未来相遇概率，以及减少帮助、离开或拒绝欺骗者的能力，都是合作抵抗不回报策略的条件。Trivers 的经典模型由此把清洁共生、警报与交换列为候选，但观察到“你帮我、我帮你”仍须排除每次互动都即时互利、亲缘偏向或共同环境。[^reciprocal-altruism]

长期关系还可通过**伙伴选择**和**合作执行**稳定。个体把资源转向回报高的伙伴，或离开低回报对象，会使合作本身成为获得未来互动的条件；优势伙伴也可用惩罚、驱逐或撤回资源强制合作。豆科—根瘤菌系统提供了可操纵的实例：研究者让根瘤失去固氮条件后，大豆减少了这些根瘤获得的资源和细菌繁殖，支持宿主按伙伴表现实施制裁。[^rhizobium-sanctions] 这种结果证明合作可由差异回报维持，并不表示植物有意识地评判欺骗。

互惠、伙伴选择与强制可在同一系统叠加。从属慈鲷帮助守域可能同时取得庇护、等待继承位置，并避免被驱逐；社会性昆虫的工虫不繁殖可能同时受亲缘收益、蜂王状态信号和工虫监督影响。具体行为案例由[互惠与社会纽带](../ecology/behavioral_ecology/social_cooperation.md#reciprocity)和[合作执行](../ecology/behavioral_ecology/social_cooperation.md#coercion-and-enforcement)继续展开。

## 亲缘选择把社会效应折算为包容适合度 { #kin-selection }

个体通过自己的后代留下基因，构成**直接适合度**成分；行为使亲属额外繁殖后，按双方在相关等位基因上的关联折算回行动者，构成**间接适合度**成分。在明确因果归属且避免重复计算时，两者组成**包容适合度**。Hamilton 由此说明，一个降低自身繁殖的等位基因仍可能增加，因为它提高了携带同源拷贝者的繁殖。[^hamilton-social]

在线性、加性近似下，条件常写为

$$
rB>C,
$$

其中 $C$ 是行动者承担的适合度代价，$B$ 是受助者获得的收益，$r$ 是二者在候选社会性等位基因上的遗传关联。$B$ 与 $C$ 必须换算到同一后代、年龄和繁殖价值尺度；$r$ 也不是两只动物“共有多少基因”的普通百分比，而是相对于参照群体的统计关联。近亲通常产生正关联，有限扩散、群体建立方式和非随机互动也能产生关联。

帮助亲属不要求个体计算系谱。共同巢穴、共同成长形成的熟悉性、气味或叫声的表型匹配，都可让帮助在通常条件下偏向亲属。**绿胡须效应**的要求更严格：同一基因或紧密连锁系统须同时产生可识别标志、识别能力以及对相同携带者的差异行为。红火蚁社会染色体影响工蚁对不同基因型蜂后的处置，是接近这一结构的实证例子；它不能代表所有亲属识别。[^green-beard]

## 竞争尺度决定帮助与恶意的净结果 { #competition-scale }

亲属聚居可增加帮助对象的相关度，也会使亲属争夺相同食物、巢位和繁殖空缺。帮助一名亲属产生的额外后代，若主要挤掉另一名亲属的后代，间接收益便被局域竞争抵消。黏滞种群中“邻居都是亲属”因此不足以保证利他演化；需要同时知道后代向何处扩散、竞争发生在哪个尺度，以及帮助是否增加群体对外输出。[^local-competition]

恶意行为更依赖竞争基准。行为者付出代价伤害对象，只有当受害者相对于行为者的其他竞争者呈负关联，或受害者减少后释放的资源主要流向更近亲者时，伤害才可能增加行为者所代表等位基因的相对传递。某些细菌产生细菌素时自身裂解释放毒素，毒杀较少携带相同毒素—免疫系统的邻近菌株；局域竞争和菌株空间结构使它成为检验 spite 的重要系统。互相受伤本身不证明恶意受到选择。[^spite]

同一频率变化也可用不同选择层次描述。若合作型在每个群内都比自利型繁殖少，但合作型比例高的群体存活、分裂或输出更多，群间差异可超过群内劣势；亲缘选择则把同一结构写为互动伙伴基因型的关联与社会效应。在许多标准模型中，两种核算可给出相同的总变化，区别在于分解坐标，而不是两个互斥过程。[^kin-group-selection] 选择层次的通用框架见[选择层次与社会效应](selection_adaptation.md#levels-of-selection)。

## 家庭把共同利益与资源分配冲突置于同一关系 { #family-cooperation-conflict }

亲本与后代共享大量遗传利益，照料能显著提高幼体存活；同一亲本还须在当前幼体、未来后代、其他配偶与自身存活之间分配资源。双亲照料中，每个亲本都可能从配偶增加投入中获益，并把节省的资源用于再次繁殖。另一亲本能否补偿、离开后能否找到配偶、幼体对双亲照料的依赖程度，以及亲子关系把握，共同决定照料和离开的收益。父性把握，即旧材料所称的“父权自信度”，是预期亲缘的一项输入，并非雄性照料的单一开关。

杀婴、胚胎或幼体损失、窝仔削减和同胞残杀也须按行为者与情境分开。在部分哺乳动物中，新进入群体的雄体杀死未断奶幼体可缩短母体恢复繁殖的时间，但只有行为者身份、亲子关系和随后交配成功符合预测时，才支持性选择解释；亲本在资源严重不足时减少育雏数、同胞在食物短缺时杀死较小幼体，又涉及亲代分配和同胞竞争。胚胎吸收或流产还有发育异常、感染和生理应激等大量原因，不能见到妊娠终止就视为适应性选择。

帮助一个同胞还会改变其他同胞面对的竞争。若一窝中的 A 把食物让给 B，A 承担直接成本，B 状态改善，C 与 D 却可能面对更强的 B；完整包容适合度核算须把所有受影响对象、各自亲缘和资源替代关系纳入，而不能只计算 A 与 B。这保留了旧材料的同胞例题，也说明社会效应不是一条孤立的两两连线。

## 亲子与同胞的最适投入量并不相同 { #parent-offspring-conflict }

对普通远交二倍体而言，亲本与每个亲生后代通常有 $1/2$ 的系谱相关度，并在多个后代之间分配资源；某个后代与自身的关联为 1，与全同胞通常为 $1/2$。因此，在额外资源提高该后代收益、却减少亲本留给当前或未来同胞的资源时，后代偏好的投入水平常高于亲本偏好的水平。Trivers 的亲子冲突理论据此预测断奶、供食、繁殖时机以及后代是否帮助亲本继续育幼等问题上的利益差异。[^parent-offspring-conflict]

冲突不等于亲子关系缺少合作。亲本和后代对避免幼体死亡具有广泛共同利益，稳定信号可在部分冲突下传递饥饿、健康和边际收益。乞食叫声、张口、争位和激素信号既可能真实反映需要，也可能因争夺亲本投入而被夸大；研究须操纵饥饿、同胞数量或信号成本，并追踪亲本供食、幼体存活与亲本未来繁殖。

同胞之间的相关度和资源替代程度决定竞争强度。全同胞、半同胞和无亲缘巢友对彼此成功的间接收益不同，异步孵化产生的体型差又会改变抢食和残杀能力。亲本可能利用孵化顺序形成在丰年全部育成、歉年削减窝仔的缓冲，也可能只是受到产卵和孵化约束；区分这些解释需要多年食物条件、育雏操纵和终生繁殖记录。繁殖行为细节见[亲子冲突与同胞竞争](../ecology/behavioral_ecology/sexual_selection.md#family-conflict)。

## 合作繁殖从延迟扩散到实际帮助分两步演化 { #cooperative-breeding }

**合作繁殖**指亲本之外的个体共同照料一批后代。最常见的帮手是留在出生领域的早期后代，但共同巢也可包含多个繁殖雌雄和非亲帮手。Emlen 的家庭演化框架先问后代为何不独立扩散，再问留下后为何帮助：可用领域短缺、扩散风险和独立筑巢成本会提高留居价值；安全、食物、群体防御、继承位置和未来配偶则提供延迟直接收益。[^family-evolution]

留下并不必然帮助，帮助也不必只靠亲缘选择。照料弟妹可取得间接收益，守域和喂幼也可换取留群、育幼经验、群体扩大后的防卫收益或未来繁殖机会；优势繁殖者还可能以驱逐威胁执行帮助。验证机制须分别比较离开与留下、帮助与不帮助的后果，而不是由“帮手与亲本是亲属”直接宣布亲缘选择已经得到证明。完整自然史和帮手案例见[合作繁殖与延迟扩散](../ecology/behavioral_ecology/social_cooperation.md#cooperative-breeding)。

## 真社会性把共同育幼、世代重叠与繁殖分工结合起来 { #eusociality }

真社会性通常以三个可观察特征界定：多个个体合作照料幼体；亲代与成年的子代世代重叠；群体中形成繁殖者与少繁殖或不繁殖成员的稳定分工。所有现生白蚁、全部蚂蚁以及部分蜂、胡蜂、蚜虫、蓟马、甲虫和枪虾符合这些条件，裸鼹鼠等少数脊椎动物也常被纳入。职虫形态、蜂群和白蚁群周期、裸鼹鼠地下生活等传统比较内容见[社会性昆虫的判据与等级](../zoology/behavior/social_organization.md#social-insect-criteria)，这些结构是讨论适合度分配的实体基础。

传统演化路径包括两类。**亚社会路径**从亲代护幼和渐进供食开始，后代延迟离巢并照料下一窝；**类社会路径**从同代雌性共同筑巢、守卫和育幼开始，随后出现繁殖偏斜。它们是比较社会起源的模型，不是所有类群依次通过的社会进步阶梯。白蚁由一对雌雄及其后代形成二倍体家族群，膜翅目不同支系又多次从独栖祖先产生社会性，必须分别重建祖先婚配、筑巢和育幼方式。

### 单倍二倍体改变亲缘与性比分配 { #haplodiploidy }

在单蜂后、蜂后只交配一次、姐妹同父同母且群体无近交的简化膜翅目巢群中，雌性由受精卵发育、雄性由未受精卵发育。姐妹共享全部父源基因和平均一半母源基因，系谱相关度可达 $3/4$；工蜂与母亲为 $1/2$，与兄弟为 $1/4$。这一不对称使帮助母亲产生姐妹具有较高的潜在间接收益，也导致工蜂在控制性分配且雌雄生产成本相同时偏好约 $3:1$ 的雌雄投资，而蜂王对儿女的相关度都为 $1/2$，偏好约 $1:1$。Trivers 与 Hare 把这种蜂王—工蜂冲突转化为巢群性比预测。[^haplodiploidy-sex-ratio]

这些数值依赖严格条件。蜂后多次交配、巢内有多个蜂后、工蜂产雄、近交与不同性别繁殖价值都会改变相关度和最优分配；在蓄奴蚁中，承担育幼的奴隶工蚁与奴役种幼体无亲缘，不能按自身亲缘偏好调节性比，较接近蜂王控制的 $1:1$ 预期；多蜂后降低同巢成员平均亲缘后，也可能减弱雌偏，但方向仍取决于谁控制分配。大量单倍二倍体蜂类独栖，白蚁、真社会性虾和裸鼹鼠均不靠单倍二倍体遗传，故它既非真社会性的充分条件，也非必要条件。

### 家族起源与巢生态共同打开社会性路径 { #family-origin-eusociality }

对多次独立起源的真社会性膜翅目进行系统发育比较，发现其祖先多具有终生单配，最初留巢子代因而保持较高相关度；这支持高亲缘是社会性起源的条件之一，而不只是社会性形成后的结果。[^ancestral-monogamy] 亲缘仍须与生态可行性相接：耐久而可防御的巢、独立建巢的高失败率、幼体需要连续供食、食物可集中开发和亲代寿命足以形成世代重叠，都会提高留巢帮助的收益。

社会性起源后的维持条件可以改变。蜂后多次交配降低工蜂间相关度，却可能提高群体遗传多样性、抗病能力和任务互补；成熟群体可依赖不可逆职虫形态，而早期社会祖先的帮手可能仍具有独立繁殖能力。起源条件、后续稳定机制和现生群体功能须分开研究。

## 巢群整合没有消除繁殖利益冲突 { #colony-conflict }

蜂王、工虫和不同母系或父系成员会对雄性来源、雌雄投资、蜂王更替和工虫繁殖持有不同遗传利益。仍有卵巢的膜翅目工虫可产未受精雄卵，其他工虫可能攻击产卵者或清除其卵。蜂王多次交配时，工虫与蜂王所生雄蜂的平均相关度可高于与另一工虫所生雄蜂的相关度，**工虫监督**便可能由工虫自身的包容适合度支持；监督若同时提高群体生产力，直接的群体收益又会扩大其选择范围。[^worker-policing]

蜂王信息素可能诚实反映繁殖状态，使工虫依自身利益调整卵巢，也可能在特定系统中产生操纵；工虫不育同样可能来自发育上不可逆分化、社会抑制或行为监督。把巢群称为超个体有助于理解物质运输、稳态和繁殖集中，却不能把蜂王当成发号施令的大脑，也不能假定工虫之间没有竞争。合作与冲突的并存正是巢群组织演化的持续动力。

## 遗传冲突源于不同遗传单位的传递利益不一致 { #genetic-conflict }

一个等位基因、细胞器、质粒或转座因子若能提高自身传递，即使降低携带个体的存活或繁殖，也可能在短期内增加。这样的**自私遗传元件**把选择对象从完整个体展开到基因组内部。个体适合度受损又会选择出核基因、重组修饰、沉默通路和行为对策来抑制元件，于是形成驱动—抑制、毒素—解毒和胞质—细胞核的协同演化。[^selfish-elements]

遗传冲突不是“基因为自身利益作决定”的拟人叙述。它表示不同遗传单位的传递规则不完全一致，导致同一变异在配子、个体和群体尺度上受到方向不同的选择。许多冲突元件长期被抑制，部分序列后来还可被宿主共选为调控、着丝粒、免疫或生殖功能；当前功能与最初传播机制需要分别证明。

### 细胞质遗传形成核质冲突 { #cytonuclear-conflict }

线粒体和许多胞质共生体主要经卵传递，雄性对它们常是较少或不发生传递的终点。植物**细胞质雄性不育**（CMS）常由线粒体重排产生的嵌合开放阅读框损害花药或花粉发育；若减少雄性功能让植物把更多资源投入种子，相关线粒体型可获得传递优势。细胞核中恢复花粉育性的 *Rf* 等位基因又会因恢复个体整体繁殖和父系传递而上升，形成可在群体中循环或维持多态的核质冲突。分子机制和三系育种见[细胞质雄性不育](../genetics/sex_cytoplasmic.md#cytoplasmic-male-sterility)。[^cms-restoration]

胞质共生体还可造成雄性致死、雌性化、孤雌生殖或胞质不相容，宿主核基因与交配系统会演化抑制或补偿。效应取决于共生体株系和宿主背景；母系传递本身不保证所有胞质因子都损害雄性。

### 减数分裂驱动突破孟德尔式公平传递 { #meiotic-drive }

杂合体的两个等位基因在规则减数分裂中各进入约一半功能配子。**减数分裂驱动**或更广义的传递畸变使某一等位基因超过 $1/2$ 传入后代：不对称雌性减数分裂中，染色体可偏向进入卵而非极体；雄性发生中，驱动元件可损伤不携带它的精子；有些真菌则在孢子形成后杀死不携带者。驱动元件即使降低杂合体生育力，也可凭传递优势扩散。

驱动会扭曲性比、降低精子数或胚胎存活，极端时威胁种群持续，因此其余基因组中恢复公平分离的抑制因子、抗性靶位点和改变重组的等位基因会受到选择。自然群体结果取决于驱动强度、适合度成本、交配制度、空间结构和抑制基因，而不是所有驱动最终固定。[^meiotic-drive] 传递畸变也解释了为何实测偏离孟德尔比例时须先定位配子和合子阶段，不能笼统说分离律失效。

### 分离后致死使质粒留在细胞谱系中 { #postsegregational-killing }

某些质粒携带稳定毒素与较不稳定的解毒成分。子细胞保留质粒时可持续产生两者而存活；一旦质粒在分裂中丢失，解毒成分先衰减，残留毒素便抑制生长或杀死无质粒细胞。这种**分离后致死**提高了质粒在存活细胞谱系中的表观稳定性，旧材料所称“放毒者质粒”即属此类逻辑。

R1 质粒的 *hok/sok* 系统是经典实例：*hok* 编码膜毒性肽，*sok* 反义 RNA 阻止其表达；质粒丢失后不稳定的 Sok 消失，Hok 得以产生并杀死细胞。[^postsegregational-killing] 这一机制首先有利于质粒维持，宿主在某些环境中也可能从质粒抗性或代谢货物获益；毒素—解毒模块的存在本身不能证明质粒整体对宿主有害。

### 转座因子扩增与宿主沉默形成军备竞赛 { #transposable-element-conflict }

转座因子通过复制或移动增加自身拷贝，插入可破坏基因、促进异位重组并增加基因组负担。宿主利用 DNA 甲基化、异染色质、小 RNA 和序列特异抑制蛋白压低其活动，元件则可改变启动子、逃避识别或转移到新宿主。生殖系中的 piRNA 等通路尤其重要，因为只有进入配子的拷贝才能跨代延续。

长期冲突会留下大量失活片段，也会提供可共选材料。转座因子来源序列可成为增强子、启动子、绝缘元件或新蛋白质结构域；这类创新不表示元件最初为了宿主功能而传播。元件扩增、宿主伤害、抑制和后来共选是四个不同阶段。

### 亲本来源冲突可塑造基因组印记 { #parent-origin-conflict }

哺乳动物的某些核基因按父源或母源呈不同表达。亲缘冲突模型指出，在一个雌性不同后代可能有不同父亲的系统中，父源等位基因的未来拷贝较少受到母体保留资源给其他父系后代的收益约束，因而可能偏向提高当前胎儿取得的资源；母源等位基因存在于母体的所有后代中，可能更偏向限制单胎索取、保存母体未来繁殖。Haig 将这一逻辑用于胎盘信号、胎儿生长与母体生理冲突。[^pregnancy-conflict]

这是解释部分印记基因方向的进化模型，不是“父源基因一律促生长、母源基因一律抑制”的规则。单配程度、同胞父系组成、组织和发育阶段都会改变预测，印记还可能涉及剂量、共适应和性别特异选择。分子层面上，印记控制区的甲基化、长链非编码 RNA 和染色质状态在配子发生中建立，进入下一代生殖系后又擦除重设；详见[基因组印记的状态周期](../genetics/genomics_epigenetics.md#genomic-imprinting)。[^imprinting-mechanisms]

## 社会进化需要跨层次的因果证据 { #social-evolution-evidence }

社会行为的解释至少连接四类资料。长期行为记录确定谁帮助、伤害或与谁繁殖；移除帮手、改变伙伴回报、操纵亲缘或资源可估计 $B$ 与 $C$；亲子鉴定、系谱和群体基因组给出真实亲缘、受精份额与群体结构；系统发育比较检验单配、筑巢、供食和繁殖分工的时间顺序。只观察亲属相助不能区分亲缘收益与共同环境，只发现群体表现好也不能证明群体选择。

遗传冲突还需定位传递偏差发生在哪一层。互交和配子计数区分核质效应与合子死亡，四分体或单精子分析定位减数分裂驱动，质粒丢失实验检验分离后致死，等位特异表达和亲本定相检验印记。随后还要扰动驱动元件或抑制因子，并测量配子、个体和种群的后果。合作与冲突由这些可观察过程共同组成，而不是把“个体”“群体”或“基因”中的任一层次设为唯一真正的选择单位。
