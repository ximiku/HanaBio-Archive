# 表型、发育与数量性状进化

生物的形态不是基因型的直接摹本。遗传变异经由细胞增殖、组织相互作用、生长时序和环境响应形成表型，表型之间的存活与繁殖差异再反馈到下一代基因库。比较形态学记录结构怎样相同或不同，胚胎学与演化发育生物学说明这些结构怎样生成，数量遗传学则估计群体中可传递的差异能以多快速度响应选择或漂变。三条路径回答的问题不同，却共同构成表型进化的因果链。

经典形态术语仍是这条链的起点。人手、蝙蝠翼和鲸鳍的骨骼对应关系，不能由一个基因名称替代；异时、异速与异位发生也首先描述发育轨迹中可观察的改变。现代调控和统计证据的作用，是检验这些比较所暗示的祖先状态、发生机制和群体过程，而不是让传统观察失去价值。

## 从同源结构重建性状历史 { #homology-and-character-history }

同源性是结构或性状来自共同祖先的假说。近缘四足动物的前肢即使分别承担抓握、飞行、游泳或支撑功能，仍可依据位置、组成、连接关系、胚胎来源和系统发育连续性判为同源。具体状态却可能独立产生：人和鳄的前肢继承了共同祖先的五指型基础，而豚鼠和犀牛各自具有三趾状态，并不表示“三趾”源于同一次祖先改变。一个保守基因在两个器官中表达，也只能提供发生机制的线索，不能独自判定完整器官同源。[^wagner-homology]

**同塑性**是相似状态在不同谱系中独立出现的现象，传统上包括趋同、平行和逆转。趋同强调祖先状态不同的谱系在相似选择条件下获得相近功能或外形；平行常用于起点较相似、发生基础相近的谱系；逆转则指性状回到接近较早祖先的状态。这些类别之间的边界取决于祖先状态、比较层级和发生机制，必须把性状映射到系统树上，而不能只凭成体相似度命名。

多洛法则常概括为“复杂性状一旦丢失便不能重新获得”。它保留了一个重要的历史不对称：结构消失后，相关调控、组织互作和编码成分可逐步退化，完全按原路径重建通常很难。法则却不是绝对禁令；若发生程序仍因其他功能而保存，后代可以重新调用部分旧网络，外形上也可能出现逆转或新的趋同。所谓“重获”还须排除祖先性状误判、隐蔽残存和可塑性。[^dollo-reversal]

同一谱系的不同性状可以以不同速率改变，这就是**镶嵌演化**。一个生物同时保留祖征和具有衍征，因此不能把整个物种排成“高等—低等”的单一等级。形态改变有时由许多小变化累积，有时在记录中显得跳跃；后者可以来自大效应突变、重组、阈值型发育反应、短暂过渡阶段或化石取样空缺，并不自动证明每个结构都由一次巨变产生。

外形与功能经常共同变化，但结构也会被改用于新功能。膜翅目雌虫的产卵器在部分支系中成为注毒和防御用的螫针，识别这种转换要先确认组成部件和发生位置的同源，再比较功能、生活史与系统树。旧结构共选为新功能的历史判据见[适应与外适应](selection_adaptation.md#adaptation-exaptation-constraints)。

## 个体发生提供比较形态的时间坐标 { #ontogeny-and-comparison }

不同物种的相似性会随发育阶段改变。冯·贝尔指出，胚胎较早呈现较广泛类群共有的结构关系，专门化特征随后逐渐显现；一种动物的胚胎不会经过另一种动物的成体。海克尔“个体发生重演系统发生”的强形式因而不能成立。胚弓、尾芽和暂时性肾结构是现生胚胎自身的建成阶段，不能按外形直接读成成年鱼类或爬行动物祖先。比较胚胎仍然重要，只是研究对象转为发生过程怎样在共同祖先基础上分化。[^richardson-recapitulation]

生物体常由重复或半独立的**模块**构成。椎骨、体节、牙齿和附肢共享部分发生程序，传统上称系列同源或迭代同源；旧材料另列“异位同源”来指不沿单一体轴排列的重复单元，现代比较通常仍要逐项说明重复机制、位置和系统发育范围。模块并非互不相关的零件，它们只是内部关联通常强于模块之间，并可在共享图式基础上获得不同身份。

重复模块逐渐获得独立形态和功能称为**个性化**。门齿、犬齿和臼齿来自共同牙齿发生框架，却在位置身份、形状、生长和咬合负荷上分化；颈椎、胸椎和腰椎也在系列重复中形成区域特征。Hox 边界、局部信号、力学负荷和组织间互作都可参与个性化。比较形态先界定对应单元，调控研究再解释身份怎样产生，二者不可互相代替；调控网络和共选机制详见[演化发育生物学](../development/evo_devo.md#cooption-and-individuation)。

## 发育时序、比例与位置可以分别演化 { #heterochrony-allometry-heterotopy }

**异时发生**（heterochrony）指祖先与后代之间，发育事件的起始、终止、速率或相对顺序发生改变。后代成体保留祖先较早发育阶段的特征，称幼态形成（paedomorphosis）；它可来自体细胞发育速率减慢的幼态持续（neoteny），也可来自生殖成熟相对提前、体细胞发育较早终止的早熟发生（progenesis）。某些钝口螈在性成熟后仍保留外鳃等幼体特征，是常用例子，但不同种的内分泌和生态机制并不完全相同。

相反，过度形成（peramorphosis，旧译“过型形成”）使后代结构越过祖先的终末状态，可由发育起始提前、速率加快或终止推迟造成。幼态形成与过度形成是相对于推定祖先轨迹的比较结果，不能只凭“大、复杂”或“小、简单”的成体外观判定；年龄、发育阶段、体型和系统发育关系都必须对齐。

**异速生长**（allometry）描述一个部位随整体大小改变的比例关系，常写为

$$
y=ax^b,
$$

取对数后成为 $\log y=\log a+b\log x$。$b=1$ 表示两个同量纲尺度等速改变，$b>1$ 或 $b<1$ 分别表示相对增长更快或更慢。个体一生中的发生异速、同一年龄群个体之间的静态异速以及物种均值之间的演化异速属于不同比较，斜率相似不能自动证明它们由同一机制形成。异速关系本身也能演化，不能把一条比例线当成永恒约束。[^klingenberg-allometry]

**异位发生**（heterotopy）指性状发生位置、表达域或组织相互作用边界改变；表达量或细胞数改变可另称异量发生。旧材料以大熊猫“假拇指”说明异位发生，但这一结构首先是桡侧籽骨的增大、延长与重新参与抓握，是否属于严格的位置改变仍需比较胚胎来源、关节关系和调控域。这个例子正说明：成体形态可以提出发生假说，异时、异速、异量或异位的判定则要测量实际发育轨迹。

许多形态式样在分子层次也能看到，例如不同谱系的蛋白质可独立获得相似功能，调控网络也可在保守输出下更换内部连接。分子趋同与形态趋同未必发生在同一层级，具体的基因复制、调控创新和序列变化由[分子、基因与基因组进化](molecular_genome_evolution.md)承接。

## 数量性状的遗传架构 { #quantitative-genetic-architecture }

身高、喙长、开花期和行为倾向等数量性状往往由许多位点和环境共同影响。**遗传架构**包括因果位点的数量和效应分布、显性与上位作用、等位基因频率、连锁、多效性、基因型—环境互作，以及性状之间的遗传协方差。同一个成体均值可以由不同架构产生，同一个架构也可在不同环境中形成不同表型。

在指定群体和环境中，表型方差可概念性分为遗传与非遗传来源；遗传方差还可分为加性、显性和上位分量。狭义遗传率

$$
h^2=\frac{V_A}{V_P}
$$

表示该群体表型方差中可由加性育种值差异解释的比例。它不是某个个体表型中“基因占多少”，也不是性状跨种群不变的属性。等位基因频率、环境范围、年龄和测量误差改变，$V_A$、$V_P$ 与 $h^2$ 都会改变。方差分解、亲属设计和广义遗传率详见[数量遗传学](../genetics/quantitative_genetics.md#heritability)。[^hill-quantitative-variation]

QTL 作图利用实验杂交中的标记和重组，定位与数量性状差异共同分离的染色体区间。一个 QTL 可含多个基因，作图群体也只检验亲本间分离的等位差异；样本量小会使越过阈值的效应估计偏大。GWAS 利用自然群体的历史连锁不平衡，覆盖更多等位变异，却容易受亲缘、群体结构和环境混杂影响。QTL 或关联位点把遗传架构缩小到候选区域，精细定位、等位特异表达和功能扰动才继续建立因果链。

## 选择响应沿遗传协方差传播 { #selection-response-and-covariance }

人工截断选择只让超过某一性状阈值的个体繁殖，是观察数量性状响应的经典方法。设选择前均值为 $\bar z$，获选亲本均值为 $\bar z_s$，则选择差 $S=\bar z_s-\bar z$；后代均值相对选择前群体的改变为选择响应 $R$。在单性状、亲代和后代环境可比且加性线性近似成立时，育种者方程为

$$
R=h^2S.
$$

选择实验回算的 $h^2=R/S$ 称实现遗传率，只对该群体、选择方案和世代区间成立。连续选择会改变等位基因频率、连锁不平衡和遗传方差，近交、环境变化和生理边界也会使后续响应偏离首代预测。

自然选择同时作用于多个相关性状。表型相关 $r_P$ 可以来自遗传相关 $r_G$、共同环境相关 $r_E$ 及其协方差；遗传相关又常由多效性和连锁不平衡产生。若选择偏好某些性状组合，即使每个性状的初始遗传变异独立，也可形成**相关性选择**和新的连锁不平衡。观察到一个性状与适合度相关时，还必须控制其他相关性状，才能区分直接选择和间接响应。[^lande-arnold-selection]

把多个性状的平均值写成向量 $\bar{\mathbf z}$，加性遗传方差—协方差写成矩阵 $\mathbf G$，适合度对各性状的直接定向梯度写成 $\vec{\beta}$，一代响应近似为

$$
\Delta\bar{\mathbf z}=\mathbf G\vec{\beta}.
$$

矩阵对角线给出各性状的加性方差，非对角线给出可传递的协方差。即使某性状没有直接选择，只要它与受选性状有遗传协方差，均值也可改变；反之，选择方向若落在遗传变异很少的方向，响应会受限。$\mathbf G$ 本身随突变、重组、漂变、选择和环境改变而演化，因此既是短期预测工具，也是需要测量的历史结果。[^lande-multivariate]

## 突变与漂变提供数量性状的中性基准 { #neutral-quantitative-evolution }

数量性状即使没有选择，均值也会因有限群体的等位基因取样而分化，新突变同时补充遗传方差。令 $V_m$ 表示每代新突变为性状增加的方差。在简单的中性、加性、恒定小群体模型中，漂变清除与突变输入达到平衡时，群体内加性遗传方差的量级常写为

$$
E(V_A)\approx 2N_eV_m.
$$

这个式子是条件明确的近似，不是所有性状的固定常数。显性、连锁、交配系统、突变效应分布和选择都会改变平衡；更一般的中性模型可得到约 $2N_eV_m$ 到 $4N_eV_m$ 的范围。种群间均值的中性分化还随分离时间累积，不能只把当前群体内方差乘一个常数便预测所有谱系。[^lynch-hill-neutral]

比较数量性状分化与中性标记分化，是判断空间选择的一条路线。二倍体加性模型常用

$$
Q_{ST}=\frac{V_B}{V_B+2V_W}
$$

表示群体间加性方差 $V_B$ 相对于群体内加性方差 $V_W$ 的比例，再与中性标记的 $F_{ST}$ 零分布比较。$Q_{ST}$ 明显偏高可支持空间分化选择，偏低可与共同稳定选择相容；但显性、非加性方差、共同环境、群体历史、少量种群和参数估计误差都会改变比较。可靠检验应模拟中性分布，而不是把一个 $Q_{ST}>F_{ST}$ 当作充分证明。[^qst-fst]

共同园和互惠移植能够排除环境诱导并测量本地适合度，系统发育比较则处理物种数据的共同祖先相关。只有当表型差异可遗传、分化超过合适的中性预期，并与环境和繁殖结果相符时，定向或稳定选择的解释才真正加强。

## 反应规范、渠限化与遗传同化 { #plasticity-canalization-assimilation }

一个基因型在一系列环境中的期望表型构成**反应规范**。同一基因型随温度、营养、密度或社会环境改变表型，称表型可塑性；不同基因型的反应规范不平行，则存在基因型—环境互作。可塑性可以提高适合度，也可能只是生长受限、损伤或发育噪声的结果，必须比较环境匹配和完整生活史表现。发育输入、关键期和阈值机制详见[环境可塑性](../development/environmental_evo_devo.md#reaction-norms)。

**渠限化**表示发育系统缓冲扰动，使表型在一定范围内较稳定。环境渠限化降低外界变化造成的表型差异，遗传渠限化降低突变或遗传背景变化造成的差异；两者可以共享反馈与冗余机制，也可以独立演化。渠限化是特定性状和扰动范围内的稳健性，不表示整个生物不再变异。扰动越过缓冲范围后，隐蔽遗传变异可能显露，产生新的选择材料。

Waddington 的果蝇实验先用热刺激诱发缺横脉翅表型，再连续选择最易出现该表型的家系；若干世代后，一部分后代在没有热刺激时也形成相似表型。这就是**遗传同化**的经典路径：种群原有的遗传差异影响环境响应，选择逐代提高相应遗传背景的频率，使表型对原诱因的依赖降低。它不表示个体因热获得的翅形被直接遗传，也不要求环境定向制造适应性突变；缺乏可选择遗传变异时，同化便难以发生。[^waddington-assimilation]

旧材料把“先期适应”描述为环境变化时已有变异恰能提高适合度，把“后期适应”描述为变化后新变异出现并被选择。作为认识路径，这对应从**已有遗传变异**适应和从**新生突变**适应；两者都是变异先存在于选择过程，再因相对繁殖贡献改变频率。环境可改变哪些变异有利，却不按未来需要指挥变异方向。

## 表型整合、发育偏向与演化能力 { #integration-bias-evolvability }

功能上协作的性状常在发育、遗传或选择上相关，形成**表型整合**。整合可使牙齿咬合面、颌骨杠杆和肌肉附着共同变化，保持可工作的组合；同一相关结构也会阻碍其中一个部件单独向新方向移动。模块化把强关联集中在功能单元内部、减弱不同单元之间的多效性，既保存协调，也让一部分结构能够相对独立地改变。

发育系统不会以相同概率产生所有理论上可能的表型。有些突变被反馈吸收，有些沿已有生长轴产生连续变化，有些越过阈值后形成少数离散状态；这种不均匀称**发育偏向**。当某些方向极难产生可存活、可繁殖的变体时，可称发育约束。偏向规定变异较容易到达哪里，选择决定已出现变异的繁殖命运，二者共同塑造演化，不能当作互斥解释。[^uller-developmental-bias]

**变异性**是系统产生表型差异的倾向，**演化能力**则强调这些差异能否形成可遗传、可存活并可被选择利用的变化。基因重复、模块化增强子和部分独立的发育网络可能降低多效性代价，增加某些方向的演化能力；强整合与渠限化则可在一类扰动下保持稳健，同时把变异导向少数方向。基因型—表型映射本身也会演化，不能预设生物总能提供达到任何最优表型的变异。[^wagner-evolvability]

研究表型进化因而需要逐层连接证据：比较解剖和化石确定结构对应与出现顺序，胚胎和功能扰动定位发生变量，数量遗传设计估计可传递方差与相关响应，群体和系统发育模型再区分选择、漂变与共同祖先。现代分子证据使每一层更可检验，却只有回到真实结构、发育轨迹和繁殖结果时，才能解释一个表型怎样形成并在谱系中改变。
