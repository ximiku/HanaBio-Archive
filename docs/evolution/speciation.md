# 物种概念与物种形成

物种既是分类、命名和多样性统计的基本单位，也是具有自身历史的演化谱系。自然界中的谱系却并不总以整齐的边界存在：相邻种群可以沿地理距离连续变化，近缘物种可以偶尔杂交，无性生物没有可供检验的交配关系，而刚开始分化的群体可能只在生态、行为或基因组的一部分表现出差异。物种概念因此既要说明“物种是什么”，又要提供判断谱系是否已经分开的证据；这两个问题相关，却不能用同一个性状或一次检验完全解决。

物种形成是种群之间的基因交流逐渐受限、差异得以独立积累并形成可长期维持谱系的过程。地理阻隔、生态分化、性选择、遗传不相容、染色体变化和杂交都可能参与其中，且常在同一系统中先后或同时作用。传统的异域、边域、邻域和同域分类描述分化发生时的空间关系；现代群体基因组与实验研究则进一步追问哪些屏障真正降低了基因流，以及这些屏障是在何时、何种选择与重组条件下建立的。

## 物种概念从不同证据辨认独立谱系 { #species-concepts }

统一谱系观点把物种理解为独立演化的种群谱系。生殖隔离、形态可诊断性、生态差异和单系性不是所有物种都必须同时具备的定义条件，而是谱系在分化过程中先后获得的性质，也是划分物种时可以相互印证的证据。[^de-queiroz-species] 这种处理保留了各种经典物种概念的观察路径，也解释了它们为何会在不同类群和不同分化阶段得出不完全相同的边界。

### 生物学种概念以基因交流和生殖隔离为中心 { #biological-species-concept }

生物学种概念把物种界定为实际或潜在能够相互交配的自然种群集合，并强调它们与其他集合之间存在生殖隔离。它特别适合研究有性生殖动物和异交植物：求偶、授粉、受精、杂种存活与育性都可以转化为可观察或可实验的隔离屏障。这里的“潜在”不是指任意人工条件下能否产生后代，而是指自然种群在适当接触条件下是否能够维持基因交流。

这一概念难以直接处理无性谱系、化石以及地理上完全分离而无法进行交配检验的种群。近缘物种间少量杂交也不必立即抹去物种边界；关键在于杂交是否使两个谱系重新融合，还是只有少数基因穿过仍然存在的屏障。因此，生殖隔离更适合被量化为连续程度，而非仅用“能交配／不能交配”作二分判断。

### 形态、生态和系统发生概念使用不同可诊断性质 { #diagnostic-species-concepts }

形态种概念依靠稳定的形态差异辨认物种，是化石分类、野外鉴定和大量传统分类工作的基础。形态性状必须在个体发育、性别、季节、多型和环境可塑性的背景下比较；外形近似的隐存种可能具有深的谱系分化，而同一物种内部也可能表现出显著的两性异形或生态型差异。形态不是需要被分子证据取代的“旧标准”，而是记录结构、功能和发育差异的一条独立证据线。

生态种概念关注占据特定生态位、受共同选择体制维持的谱系。宿主选择、繁殖微生境、耐盐性或传粉者差异都可能揭示形态尚不明显的边界，但短期生态型并不自动等同于物种；还要检验这种差异能否遗传、是否降低群体间基因流，以及在环境改变后能否持续。

系统发生种概念的常见表述强调最小可诊断谱系，另一些表述强调单系性。固定性状、独特衍征或多个位点的一致聚类可以支持谱系独立，但地理结构本身也会产生可诊断群体；刚分开的物种又可能因祖先多态尚未完全分选而不具备互为单系的基因树。因而，可诊断性和单系性需要结合取样尺度、性状数目及种群过程解释，不能把任一固定差异机械地等同于已经完成物种形成。

进化种概念强调一个谱系在时间中维持自身同一性，并具有独立的演化倾向和历史命运，因而能够讨论无性生物与化石年代种。其难点在于“独立命运”需要由形态连续性、地层分布、生态和系统发生等可操作证据落实。实践中的整合分类学会同时比较形态、地理、行为、生态、染色体和多位点数据，并在证据冲突时明确替代解释，而不是简单计票；相关方法见[多证据系统学](phylogenetics.md#integrative-systematics)。

## 种内等级和过渡群体记录尚未闭合的边界 { #infraspecific-transitional-groups }

个体是选择与繁殖的直接参与者，种群则是同一地点和时期内具有实际繁殖联系的个体集合。广布物种常由多个局部种群构成，并通过迁移组成具有一定连通性的集合种群。分类学上的亚种通常指地理上可辨认、仍与同种其他地理群体发生过渡或基因交流的种内单元；它不是“只差一点就成种”的统一阶段。植物命名中的变种是受命名法规约束的种下等级，也不能仅按是否同域或是否具有生理差异来定义。

隐存种描述形态极为相似、却由多项证据显示为独立谱系的类群；旧教材还常把形态难以区分的一组近缘种称为“姊妹种”，现代系统发生语境中的姐妹种则专指彼此最近缘的两个物种。半种和初生种是物种形成研究中的历史性术语，常用于生殖隔离不完全、不同性质尚未全部分化的群体。它们提醒研究者，形态、交配、生态和基因组边界可能以不同速度形成，而谱系由种群到物种的过渡通常不是某一代突然跨过单一门槛。

## 生殖隔离屏障在生活史各阶段减少基因流 { #reproductive-barriers }

两个种群之间的基因流要经历相遇、交配或授粉、配子结合、合子发育、杂种存活和杂种繁殖等连续环节。作用较早的屏障会减少进入后续环节的个体数，因此总隔离强度不能把各屏障百分数直接相加。若第 $i$ 个屏障阻断了到达该阶段个体中的比例 $RI_i$，且各指标使用相容的顺序与尺度，累积隔离可写为

\[
RI_{\mathrm{total}}=1-\prod_i(1-RI_i).
\]

这一计算强调屏障的顺序依赖性：早期已被阻断的基因流不能在后期重复计数。猴面花近缘种的野外与温室研究同时测量地理分布、传粉者忠实度、花粉竞争和杂种适合度，显示多道屏障共同作用，而主要隔离发生在杂种形成以前。[^ramsey-mimulus]

### 合子前屏障限制相遇、交配和受精 { #prezygotic-barriers }

生态或生境隔离使种群占据不同宿主、土壤、水层或繁殖地点；时间隔离使繁殖季节、开花期或日活动节律错开；行为隔离来自求偶信号、鸣声、气味和配偶偏好的差异。机械隔离使生殖结构、花部结构与传粉者的配合不相容，配子隔离则发生在精子—卵细胞识别、花粉萌发、花粉管生长或受精竞争等阶段。交配已经发生但合子尚未形成的失败可进一步称为交配后—合子前隔离。

地理隔离会使种群无法相遇，是限制基因流的重要空间条件，却通常不视为重逢后仍起作用的内禀生殖屏障。山脉隆升、河流改道、岛屿形成或栖息地破碎首先改变的是接触机会；种群在分离期间积累的行为、生态和遗传差异，才决定它们再次接触时是否仍能融合。

### 合子后屏障降低杂种存活和繁殖贡献 { #postzygotic-barriers }

杂种不活表现为胚胎、幼体或成体存活率下降；杂种不育表现为个体能够存活却不能产生功能配子，骡是最熟悉的例子。F1 杂种有时具有较正常的存活与育性，而不相容的基因组合在 F2 或回交后代中重新组合，产生杂种衰败。环境依赖的合子后隔离还会使杂种在实验室可存活，却在亲本任一自然生境中竞争、觅食、避敌或繁殖能力较低。

Haldane 法则描述一个常见经验格局：若种间杂交后代中有一个性别缺失、稀少或不育，受影响者通常是异配性别。XY 系统中常为雄性，鸟类和鳞翅目等 ZW 系统中则可能为雌性，因此这条法则不能简化成“雄性杂种先不育”。显性—隐性不相容在只有一条 X 或 Z 的异配性别中暴露、雄性生殖基因较快演化以及减数分裂相关冲突，能够在不同类群中以不同组合产生这一格局。[^haldane-review] 性别决定系统的背景见[异配性别与性染色体组成](../genetics/sex_cytoplasmic.md#heterogametic-systems)。

## Dobzhansky–Muller 不相容连接分歧与杂种低适合度 { #dobzhansky-muller-incompatibility }

分开的种群不必各自经过低适合度中间状态，也能演化出彼此不相容的基因组合。设祖先基因型为 $aabb$：一个种群在自身遗传背景中固定 $A$，另一个种群固定 $B$，两个衍生等位基因在各自种群内都可为中性或有利；只有杂交使 $A$ 与 $B$ 首次相遇时，不利上位性互作才导致不活或不育。这就是 Dobzhansky–Muller 不相容的基本模型。

随着两个谱系积累更多差异，潜在的基因互作组合增加，不相容数目在简单模型中可以快于线性增长，形成“雪球效应”。[^orr-dmi] 自然种群中的屏障常由多位点网络、性染色体、细胞器—细胞核互作或染色体结构共同造成，也存在由单个位点、倍性或细胞质因子产生的强隔离，因而模型给出的是机制框架而非固定的基因数目。

## 基因树冲突保留祖先变异与杂交历史 { #ils-introgression }

若连续物种分化事件间隔很短，祖先种群中的多个等位谱系可能来不及在第一个分枝中共同溯祖，随后随机进入不同后代谱系，产生不完全谱系分选。单个基因树便可能与物种树不同；祖先有效种群越大、相邻分枝间隔按世代数越短，这种冲突越常见。基因复制与丢失也会造成类似的树形不一致，详见[基因树、物种树与网状历史](phylogenetics.md#gene-trees-and-species-trees)。[^maddison-gene-trees]

杂交后的回交可使一个谱系的等位基因进入另一个谱系，称为渐渗。渐渗与不完全谱系分选都能造成局部基因树冲突，却留下不同的全基因组分布、枝长和地理关联。D 统计量等方法利用不一致基因树频率的不对称性检验基因交流，但祖先种群结构、取样方式和其他人口历史仍需纳入模型比较。[^durand-admixture] 因此，一个线粒体树或少数标记的冲突只能提出杂交假说，不能单独证明渐渗，更不能直接证明杂交物种形成。

## 杂交带呈现接触、选择与扩散的平衡 { #hybrid-zones }

两个有差异的种群沿狭窄地带接触并产生杂种，就形成杂交带。初生渐变假说认为差异在连续分布中原位形成，次生接触假说认为谱系先在异域分化、扩张后相遇；现今的一条地理渐变本身往往不能区分二者，需要历史分布、谱系年代和空间基因组证据。

当杂种内禀适合度较低、但亲本个体持续从两侧迁入时，扩散与选择可维持张力带；若杂种在中间生态环境中适合度最高，则可形成环境边界维持的杂种优势带。渐渗通常按位点发生：有利等位基因可以越过大部分物种屏障，不相容或参与局部适应的位点则较难通过。与屏障位点紧密连锁的邻近区域也会暂时随之分化，重组随后逐渐拆散这种关联。

高相对分化度的“基因组岛”可能来自该区域抵抗基因流，也可能来自低重组、背景选择或某一群体内部多样性降低。仅凭高 $F_{ST}$ 不能在这些解释之间作选择；绝对序列分歧、群体内多样性、重组图谱和显式人口史模型需要共同检验。对多组近缘类群的重分析表明，不少所谓分化岛主要反映多样性降低，而非局部基因流必然受阻。[^cruickshank-islands]

## 空间关系构成物种形成的经典地理模型 { #geographic-modes }

异域、边域、邻域和同域物种形成描述分化过程中种群分布和基因流的空间格局，并不分别对应互斥的遗传机制。真实历史可以在阶段间转换，例如先异域分离、后次生接触并受强化；也可以在总体相邻分布中包含大量局部同域接触。迁移率 $m$ 的意义随世代、性别、空间尺度和交配结构改变，不能用固定阈值把四种模式机械区分。

### 异域与边域分化由空间分隔开启 { #allopatric-peripatric-speciation }

异域物种形成发生在基因交流因地理分隔显著降低时。原有连续分布被山脉、冰川、河流或海侵切开的过程称为地理隔断（vicariance）；少数个体跨越屏障建立新种群则属于扩散建群。分离以后，突变、漂变、自然选择和性选择改变各自的等位基因与性状，Dobzhansky–Muller 不相容可在没有杂种选择压力的情况下逐步积累。

边域物种形成通常视为异域模式的一种：位于分布边缘的小种群与主体种群隔离，并经历建立者取样、新生态环境和较小有效种群大小。Wright 的适合度峰转移以及建立者—冲刷模型曾把强漂变、种群扩张与快速重组看作跨越适合度谷的途径，具有重要理论史意义；但边域分化不要求种群必然先“漂变下坡”再由选择上坡。建立者数目、繁殖成功方差、近交、增长速度和后续迁入共同决定漂变强度，可与[瓶颈、建立者效应与扩张](variation_population.md#bottleneck-founder-expansion)中的群体过程对应。

传统教材常把银鸥—小黑背鸥复合群作为环物种范例：相邻地理种群可杂交，环绕北极分布的两端在欧洲相遇却保持差异。线粒体与核遗传研究显示其历史包含多次异域分化、冰期避难所扩张和远距离定殖，并非一条由连续基因流闭合的简单环。[^liebers-gulls] 这个修订没有消除环物种模型的教学价值，而是说明现代分子证据可以检验传统生物地理重建中的具体历史路径。

### 邻域与同域分化需要在基因流中维持关联 { #parapatric-sympatric-speciation }

邻域物种形成发生在相邻分布的种群之间，接触带仍有基因流。低迁移能力、陡峭环境梯度、不同土壤或宿主以及距离隔离有利于形成等位基因和表型渐变；低流动性的植物、地下动物和无翅昆虫是常用例子，但并不因此自动属于同一种历史模式。必须证明分化选择足以抵消迁移的均质化作用，并排除先异域分化后次生接触。

同域物种形成要求分化从同一地理区域内原本能够交配的种群开始。破坏性选择只有与同类交配、宿主忠诚、繁殖时间差异或生态性状—择偶性状的遗传关联结合，才可能使两个基因库逐渐分开。仅凭两个近缘种今天同域分布不能证明同域起源；历史范围、祖先状态、基因流方向和屏障形成次序都需要重建。

宽分布、扩散能力与传统的 r／K 对策不能直接判断物种形成模式。一个扩散能力强的谱系也可能被历史屏障分割，小型短世代生物也可能在连续环境中长期交流；相关生活史性状只有通过迁移率、有效种群大小、建群概率和选择强度等具体过程才影响分化。

## 生态、突变次序和性选择提供不同分化动力 { #drivers-of-divergence }

生态物种形成是不同环境中的分歧选择使生殖隔离演化的过程。迁入者在非本地环境中存活或繁殖较差、个体偏好与自身适应相符的生境、传粉者或宿主选择不同，以及生态性状同时影响配偶选择，都会把局部适应转化为基因流屏障。屏障性状与适应性状可由同一基因的多效性相连，也可由连锁不平衡或染色体低重组区保持组合；这条机制可以发生在异域、邻域或同域空间格局中。[^rundle-nosil]

突变次序物种形成则发生在群体面对相同或相似选择时，分别固定了不同的有利突变；这些替代在各自背景中提高适合度，组合到杂种中却可能相互不容。它与生态物种形成的区别在于选择方向未必因环境而分歧，也比笼统的“突变驱动物种形成”更明确地指出了等位基因固定次序和上位性。

性选择可以通过求偶信号和偏好共同分化而减少交配，也可放大生态环境对视觉、声学或化学信号传递的影响。近缘类群丰富与强烈性状差异之间的相关并不能单独证明性选择提高了物种形成率，因为信号差异也可能在谱系分开之后积累；行为实验、偏好的遗传基础、自然接触区的交配模式和比较系统发育分析需要共同支持因果方向。

## 强化在次生接触中增强合子前隔离 { #reinforcement }

若两个已分化种群相遇后产生低适合度杂种，选择会有利于避免异种交配的个体，使合子前隔离在接触区增强，这一过程称为强化。接触区中的配偶识别差异大于异域区，称为生殖性状置换，是强化可能产生的地理格局，却不等同于过程本身。生态性状置换、接触区局部环境差异、漂变、历史上差异较大的谱系才得以共存而较相似谱系融合或灭绝，都能产生相似格局。

有力的强化证据需要显示谱系仍有基因流、杂交确实降低适合度、配偶辨别能够遗传，并排除环境差异对信号或偏好的直接作用。理论与经验研究还表明，强化是否发生取决于基因流强度、择偶成本、偏好与不相容位点的关联，以及重组是否持续拆散有利组合。[^servedio-reinforcement]

## 基因流、选择与重组共同塑造分化基因组 { #speciation-with-gene-flow }

当迁移把等位基因带入另一个种群时，分歧选择必须足够强，或非随机交配必须足够稳定，才能维持差异。重组会拆散适应性状与交配偏好的组合，因此多效性“魔法性状”、紧密连锁、倒位和其他低重组区域可提高屏障位点之间的耦合。倒位还可能因杂合个体重组产物适合度低而抑制有效交换，但倒位本身并不必然导致物种形成。

分化常先集中在受到选择或不相容影响的位点，基因组其他部分仍可交流；随着更多屏障积累并相互耦合，受限制区域可能扩展。反过来，选择减弱、环境改变或大量迁入也可能使初生谱系重新融合。因此，物种形成既可完成、停滞或逆转，也可在长期保持部分渗透的边界下维持两个谱系。基因组数据的解释须同时考虑重组、选择和人口史，而不能把差异位点的数量直接换算成“完成百分比”。

## 多倍化可迅速建立倍性屏障 { #polyploid-speciation }

同源多倍体由同一物种的染色体组加倍形成，异源多倍体则结合不同物种的染色体组。未减数配子融合、早期胚胎或分生组织染色体加倍都可产生新的倍性。新四倍体与二倍体杂交时常形成三倍体，后者因减数分裂配对和分离不规则而育性较低，于是一次倍性改变即可造成强烈的合子后屏障；具体细胞遗传过程见[整倍性与多倍体](../genetics/chromosome_variation.md#euploidy-polyploidy)。

“立即隔离”不等于新多倍体必然建立。稀少的新倍性个体更容易遇到数量占优的二倍体，产生低育性后代，形成少数细胞型劣势；自交、无性繁殖、同倍性交配、局部聚集或反复独立产生能够提高建立机会。异源杂种若因亲本染色体缺少同源配对而不育，染色体加倍可为每套染色体提供配对伙伴并恢复育性，但基因互作、剂量平衡和细胞质—细胞核相容性仍会影响结果。

多倍体在植物中尤其常见，也存在于动物、真菌和其他真核谱系。多倍化带来基因冗余、杂合性和剂量改变，同时也带来减数分裂、基因表达与基因组稳定性成本；后续会发生基因丢失、表达分化和染色体重排。研究显示许多植物多倍体由不同亲本种群反复形成，因此同一命名多倍体内部也可能保留复杂来源。[^soltis-polyploidy] 多倍体马铃薯可说明倍性变异，却不能仅凭染色体数目就断定每个多倍体个体已经构成独立物种。

## 杂交既能渐渗也能参与新谱系形成 { #hybrid-speciation }

异源多倍体物种形成把种间杂交与基因组加倍结合，倍性差异和重建的配对关系可迅速隔离新谱系。同倍体杂交物种形成则不改变染色体组数，需要杂交产生的基因组合使新谱系与两个亲本都建立生殖隔离。适应新生境、重组产生的配偶信号、染色体重排或多个不相容位点的组合都可能提供屏障。

证明同倍体杂交物种形成至少需要三类相连证据：新谱系具有来自两个亲本的杂交祖源；它能够形成稳定、可延续的群体；由杂交获得或重组产生的性状对它与两个亲本的生殖隔离有因果作用。杂交在自然界很常见，而符合完整判据的同倍体杂交物种案例要少得多。[^schumer-hybrid] 向日葵研究将古老杂交种的极端生境性状与人工合成杂种中的亲本染色体片段组合相比较，显示杂交产生的新组合能够促进生态转变，是连接基因组重组、选择和谱系建立的经典证据。[^rieseberg-sunflower]

若少量基因通过回交进入一个仍保持原有身份的谱系，这是渐渗；若其中某个等位基因提高适合度，则是适应性渐渗。二者都能深刻影响演化，却不等于产生了第三个物种。只有当杂交对新谱系的起源和隔离都具有必要作用时，才应使用杂交物种形成这一更强的判断。

## 物种形成的时间和表型结果彼此独立 { #tempo-and-outcomes }

物种形成历时是一个谱系对从开始分化到建立稳定边界所需的时间，物种形成间隔则是一个支系连续产生新物种事件之间的等待时间；两者不能混用。倍性改变可以在一代内产生强屏障，但新细胞型建立仍需种群过程；许多动物谱系的生态、行为、杂种育性和基因组屏障则会在不同时间形成。隔离强度通常随分歧增加，却没有适用于所有类群的固定完成时长。

传统宏观进化术语把单一谱系随时间转变称为线系进化或渐进成种，把一个祖先谱系分枝为两个以上后代谱系称为分支成种。前者可以改变年代种的形态，却只有在谱系分枝或独立边界建立时才增加同时存在的物种数。“骤变式”或“量子物种形成”可作为描述多倍化、染色体改变和某些建立者模型中快速转变的历史术语，但不代表所有快速分化共享同一普遍机制。

物种形成与形态变化没有一一对应关系：谱系可以在外形变化很小的情况下建立强生殖隔离，形态也可以在一个连续谱系内显著改变而没有分枝。间断平衡讨论化石谱系中形态停滞与地质上较短变化期的分布，不能据此断定一切形态改变都由物种形成直接造成；相关尺度见[间断平衡与进化节律](history_evidence.md#punctuated-equilibria)。物种形成把种群内的变异、选择、漂变和基因流连接到谱系分枝与多样化，是微观进化通向宏观格局的过程接口。

## 物种形成研究依赖相互约束的证据链 { #evidence-for-speciation }

判断一种物种形成模式，需要把空间历史、隔离机制和遗传过程放在同一时间框架中。分布与地质资料重建屏障或接触，野外观察和交配、移植实验测量屏障与适合度，群体基因组估计分歧、迁移和重组，系统发生比较则检验性状与物种形成率之间的长期关联。任何单一现象——现今同域、一个高分化区、一个不一致基因树或一只人工杂种——都只能支持证据链中的一段。

完整解释还要比较替代历史：环境梯度中的分化可能来自邻域物种形成，也可能来自异域分化后的次生接触；强配偶隔离可能是强化，也可能是局部信号传递环境造成；基因树冲突可能是渐渗，也可能是不完全谱系分选。把传统形态、解剖、行为和地理证据与现代分子模型并列，并明确每条证据能够排除什么，才能把物种名称背后的边界转化为可检验的演化历史。
