# 遗传变异与群体进化过程

进化在群体中留下的直接记录，是可遗传性状和等位基因频率随世代发生变化。新突变产生从未存在过的序列状态，重组把已有变异重新组合，迁移把一个繁殖群体的等位基因带入另一个群体；自然选择使不同遗传背景对后代基因库的贡献出现系统差异，有限繁殖者的随机取样则造成遗传漂变。现实中的一代变化通常是这些过程叠加的结果。

这样的表述把微观进化落实到可以计数的对象，却不把个体一生中的生长、驯化或行为调整称作等位基因频率进化。对有性生殖生物，种群是主要观察单位；对无性繁殖生物，可以追踪克隆系、基因型或病毒谱系的频率。DNA 序列、生化表型、细胞性状和形态性状都能呈现种群变异，只是从分子差异走到可见表型，还要经过表达调控、发育和环境作用。

## 从表型差异辨认可遗传变异 { #heritable-variation }

同一物种的个体并不相同。点突变、插入缺失、基因复制、染色体重排和转座等过程产生新变异；减数分裂中的独立分配、交换以及有性结合重组已有等位基因。一个新变异能否成为进化材料，还取决于它是否进入可繁殖谱系并传给后代。体细胞突变可以深刻影响个体，却通常不进入下一代；植物分生组织、无性繁殖生物和具有复杂生活史的生物则需要按其实际传递途径判断。

表型差异可概念性地分成基因型效应、环境效应和基因型—环境互作：

$$
P=G+E+G\!\times\!E+\varepsilon.
$$

这是一种统计分解，不表示每个性状都能被切成彼此独立的物质部分。同一基因型在不同环境中的表型轨迹称为**反应规范**；不同基因型的反应规范不平行，便出现基因型—环境互作。环境还可能改变发育窗口、母体投入、微生物伙伴或后代表观状态，使一次观察到的差异跨越不止一个世代。

### 共同园实验比较同一环境中的来源差异

共同园实验（common-garden experiment，旧译“同质园实验”）把来自不同地点或种群的个体、种子或克隆放进尽量一致的环境，并以随机区组、重复家系和共同处理比较性状。若原有差异在共同环境中仍然保持，说明它具有可传递基础；若差异消失，原生境中的环境诱导可能占重要部分。多个温度、水分或土壤条件下的共同园还能画出各来源的反应规范，区分稳定的来源效应和跨环境改变排序的 $G\!\times\!E$。

共同环境本身还不是“差异必由 DNA 序列造成”的充分证明。种子大小、亲代营养、跨代环境效应、内生微生物以及采集后的驯化时间都可能随来源共同带入。使用共同亲本环境繁殖一代或多代、互换微生物组、设置家系与区组、测量相关协变量，能够逐层排除这些解释。数量性状的方差分解和反应规范模型详见[数量遗传学](../genetics/quantitative_genetics.md#genotype-environment-interaction)。

### 互惠移植检验来源与环境的交互作用

互惠移植（reciprocal transplant，亦称“交互移植”）把来源 A 与来源 B 的个体同时放回 A、B 两种环境，最好还有共同园和多个地点重复。局部适应最直接的判据，是某地点的本地来源在该地点比外来来源具有更高的适合度，即“local versus foreign”；另一种比较是同一来源在本地是否优于异地，即“home versus away”。后者容易受地点总体质量影响：一个贫瘠地点的本地种群可能在肥沃异地生长更好，同时仍在贫瘠本地胜过所有外来来源。因而，局部适应应优先比较同一环境内不同来源的相对繁殖贡献，并覆盖存活、交配和结实等足够完整的生活史阶段。[^local-adaptation]

来源与环境的显著交互可以揭示适合度权衡，也可能表现为某来源在一个环境占优、在另一个环境只是与其他来源相当。基因流会输入变异并缓和近交，也可能持续引入不适合本地的等位基因；漂变、小样本误差、亲代效应和未测环境差异又都能产生或遮蔽来源差别。因此，共同园和互惠移植提供的是从地理相关走向因果检验的实验框架，基因组差异可进一步定位候选区域，却不能代替适合度实验。

### 多态、生态型与渐变群描述不同空间格局

种群中同一座位存在多个等位基因，或一种性状存在两种以上较常见形式，可称遗传多态或表型多态；“多态”并不预先规定它由平衡选择维持。地理变异若随纬度、海拔、盐度或其他空间环境连续改变，可形成**渐变群**（cline）。渐变可以由空间选择梯度产生，也可来自隔离随距离、扩张历史或彼此相关的环境因子，观察到相关性后仍需比较替代机制。

贝格曼法则是经典地理梯度例证：许多鸟类和哺乳类在较冷地区具有较大体型，传统解释联系到体表面积与体积之比和散热成本。它既可在近缘物种间检验，也常被扩展到种内种群；不同类群却可能不符合甚至呈相反梯度。纬度还同时改变生产力、季节长度和发育温度，所以体型—纬度相关本身既不能证明遗传差异，也不能单独确认温度选择机制，仍需共同园、谱系比较和生理测量。[^bergmann-cline]

在不同生境中形成并维持遗传性差异的种群常称**生态型**。生态型可以沿梯度连续过渡，不必具有正式分类阶元；地理亚种则是分类学上对可诊断地理种群的命名判断，还涉及性状组合、地理边界和命名规范。连续渐变、生态型和亚种分别强调空间型式、生态分化和分类处理，不能只按差异大小排列成固定阶段。

## 基因库与 Hardy–Weinberg 基准 { #gene-pool-hardy-weinberg }

一个局部繁殖群体中能够传给后代的全部遗传变异构成它的**基因库**。等位基因频率必须对应明确的地点、时间、生活史阶段和抽样范围。对含 $N$ 个二倍体个体的常染色体二等位座位，若 $AA$、$Aa$、$aa$ 的个体数分别为 $n_{AA}$、$n_{Aa}$、$n_{aa}$，则

$$
p=f(A)=\frac{2n_{AA}+n_{Aa}}{2N},\qquad
q=f(a)=\frac{2n_{aa}+n_{Aa}}{2N},\qquad p+q=1.
$$

基因型频率描述等位基因在个体内怎样配对，等位基因频率则统计基因库中的拷贝。两者不能互换：同一组 $p$、$q$ 可以对应许多不同的纯合子和杂合子比例。

若雌雄配子库的等位基因频率相同，配子随机结合会产生

$$
(p+q)^2=p^2+2pq+q^2,
$$

即合子中 $AA$、$Aa$、$aa$ 的期望频率分别为 $p^2$、$2pq$、$q^2$。这是 Hardy–Weinberg 模型的核心。随机结合可在一代内重排基因型比例，本身不系统改变等位基因频率；若要使等位基因频率和上述比例继续跨代保持，还需忽略突变、迁移、选择和有限繁殖者造成的漂变，并明确倍性、遗传方式和交配模型。[^hardy-weinberg]

Hardy–Weinberg 比例因而是比较数据的零模型，而不是对“正常种群”下定义。杂合子不足可能来自近交或同类交配，也可能来自把频率不同的亚群混在一起所产生的 Wahlund 效应、年龄或性别混样、选择以及分型误差；杂合子过多同样有多种原因。一次不显著的检验只表示样本尚不能拒绝指定模型，并不逐条证明所有假设成立。多等位、性连锁、精确检验和群体结构的完整计算见[群体遗传学](../genetics/population_genetics.md#hardy-weinberg)。

## 遗传漂变是有限群体的随机取样 { #genetic-drift }

经典 Wright–Fisher 模型设群体由 $N$ 个二倍体个体组成，世代离散、随机交配、群体大小恒定，下一代的 $2N$ 个常染色体拷贝从当前配子库独立抽取。若当前 $A$ 的频率为 $p$，下一代拷贝数 $K$ 满足

$$
K\sim\operatorname{Binomial}(2N,p),\qquad p'=\frac{K}{2N}.
$$

因此

$$
\operatorname{E}(p')=p,\qquad
\operatorname{Var}(p')=\frac{p(1-p)}{2N}.
$$

“期望频率不变”和“每个真实群体频率不变”是两回事。把许多同样起始的群体一起平均，下一代平均频率仍为 $p$；逐个看时，各群体却会走上不同的随机轨迹，而且 $N$ 越小，一代波动的方差越大。漂变正是这种繁殖基因拷贝取样误差，不要求先发生灾害，也不表示每次频率改变的方向概率都严格相同；接近 0 或 1 时，可能的步长和边界都会改变。

### 固定、丢失与群体分化

在没有突变和迁移的有限封闭群体中，一个座位最终会到达频率 0 或 1 的吸收状态。中性等位基因最终固定的概率等于它当前的频率 $p$；一个刚在二倍体群体中以单拷贝出现的中性突变，固定概率为 $1/(2N)$。这不是说小群体每代产生的某一个新突变更有方向性，而是小群体中单拷贝起始频率较高、漂变更强。绝大多数新中性突变很快丢失，少数最终固定的突变会经历较长的随机轨迹。[^wright-drift]

教材常写中性突变“平均约 $4N$ 代固定”。更准确地说，在恒定、随机交配的理想二倍体群体中，一个起始很低且**以最终固定为条件**的中性突变，平均固定时间约为 $4N_e$ 代；不加这一条件时，还包括大量迅速丢失的轨迹，等待吸收的平均时间依赖初始频率。群体大小变化、连锁选择和空间结构都会改变这个时间尺度。[^fixation-time]

对同一座位的两个随机基因拷贝向过去追溯，它们可能在某一祖先拷贝处合并，这就是溯祖。理想二倍体群体中，一对拷贝每代以约 $1/(2N)$ 的概率合并；样本中的多条谱系逐步合并成共同祖先谱系。所谓“线粒体共同祖先”指现生样本线粒体谱系最近汇合到的一位女性，并不表示当时只有这一位女性，也不表示她是现生人类所有核基因的唯一祖先。单亲遗传、不同基因区域和重组后的片段会拥有不同的谱系树。

漂变还带来一组相互联系的结果：平行起始的孤立群体逐渐分化；群体内等位基因和杂合度逐代丢失；中性甚至轻度有害等位基因可以固定；随机单倍型取样会产生连锁不平衡。漂变没有朝向更高适合度的内在方向，小群体的平均适合度可能因有害变异固定或有利变异丢失而下降。选择仍可同时作用，只是结果取决于选择效应与漂变尺度的相对大小。

### 杂合度给出漂变速率

二等位座位在随机结合下的期望杂合度为 $H=2p(1-p)$。若只有漂变、没有新突变和迁移，理想二倍体群体的期望杂合度按

$$
H_t=H_0\left(1-\frac{1}{2N_e}\right)^t
$$

下降。漂变不会保证每一代、每一个位点都单调下降；公式描述大量重复群体或位点的期望。稀有等位基因通常比杂合度更快在瓶颈中丢失，因此等位基因数、杂合度和核苷酸多样性会以不同速度响应同一群体史。

## 有效种群大小连接真实种群与理想模型 { #effective-population-size }

自然种群很少满足 Wright–Fisher 假设。**有效种群大小** $N_e$ 把真实种群换算成在某一遗传量上具有相同变化速率的理想群体。方差有效大小以等位基因频率的抽样方差为准，近交有效大小以同祖概率增加为准，溯祖有效大小以谱系合并时间为准；在恒定理想群体中它们相合，在年龄结构、数量变化和空间结构下则可能不同。$N_e$ 因而不是普查个体数 $N_c$ 的别名，也未必是对一个物种终生固定不变的常数。[^effective-population-size]

繁殖结构决定哪些个体真正向下一代贡献基因。性比偏斜会让较少的一性被反复使用；少数个体拥有大量后代会增加家系间繁殖成功方差；自交、世代重叠、年龄特异繁殖和选择也会改变同祖与漂变速率。在离散世代、雌雄分离、随机交配且每一性别内繁殖成功近似的特殊模型中，繁殖雄性和雌性数分别为 $N_m$、$N_f$ 时，

$$
N_e=\frac{4N_mN_f}{N_m+N_f}.
$$

若群体大小在若干世代间为 $N_1,N_2,\ldots,N_t$，相应简化模型中的长期有效大小接近调和平均数：

$$
N_e\approx\frac{t}{\displaystyle\sum_{i=1}^{t}\frac{1}{N_i}}.
$$

调和平均对小值尤其敏感，所以短暂的小种群阶段可能长久影响遗传多样性。上述两个公式都依赖简化条件；不能把一次性别普查或若干年度成体数直接代入，就当作完成了对复杂生活史物种的 $N_e$ 估计。

现代研究可利用时间序列中的频率变化、连锁不平衡、杂合度、亲缘关系或全基因组溯祖模式估计 $N_e$。不同方法观察不同时间窗：亲子与短期频率法偏向最近几个世代，序列的溯祖分布可能整合很久以前的大小变化。选择、重组率差异、群体混合和错误的突变率都会改变估计，报告结果时必须连同模型、遗传系统、样本设计和时间尺度一起解释。

## 瓶颈、奠基与扩张前沿 { #bottleneck-founder-expansion }

**遗传瓶颈**指群体在一段时期内有效大小显著降低，使少量繁殖者的随机基因样本塑造后续基因库。损失取决于瓶颈最低大小、持续代数、瓶颈前等位基因频率、繁殖结构和恢复过程。个体数迅速回升并不会自动找回已经丢失的等位基因；新突变和后续基因流需要更长时间补充变异。一个短促的普查数量下降若没有相应减少繁殖贡献，也未必留下强烈遗传瓶颈信号。[^bottleneck]

**奠基者效应**发生在少数个体建立新群体时：奠基者携带的是来源基因库的一小份样本，新群体从一开始就可能具有不同频率和较低多样性。它首先是漂变和取样的结果，并非“新环境选择压力不同”的同义语。建立之后，自然选择、继续迁入、近交和新的漂变会再改变群体；只有用时间、对照与适合度证据把这些阶段分开，才能判断后续差异中哪些来自奠基取样、哪些来自适应。

范围扩张常由前沿少量繁殖者连续建立新群体。某个等位基因若恰好位于扩张前沿，可以随前沿增长而升至高频，称为**等位基因冲浪**。这种空间漂变能形成低多样性的扇区和陡峭频率边界，使中性甚至轻度有害变异扩散到广阔区域；看到高频或大范围分布，因而不能单凭型式断定该等位基因具有适应优势。[^allele-surfing]

## 突变、基因流、漂变与选择共同改变频率 { #evolutionary-forces }

突变持续输入新等位基因，重组改变它们所在的遗传背景；基因流把来源群体的频率带入本地，通常降低群体间差异，同时也可能妨碍局部适应。自然选择按特定环境和生活史中的相对繁殖贡献产生平均方向，漂变则把随机取样叠加在所有这些变化上。非随机交配首先重排个体内的等位基因组合；只有当不同配对带来不同繁殖贡献，或与选择、迁移和结构相联时，才会进一步系统改变等位基因频率。

一个选择系数为 $s$ 的变异能否稳定压过漂变，取决于 $s$ 与 $N_e$ 的共同尺度。常用 $N_es$，或在特定二倍体模型中用 $2N_es$、$4N_es$，判断弱选择处于何种范围；倍性、显性、遗传方式和生命周期不同，系数约定也不同。$|N_es|$ 很小时，变异对选择近似不可见，命运主要由漂变决定；数值增大后，选择变得更有效，但随机性并不会从有限群体中消失。

同一过程还会影响附近位点。有利变异快速上升时，与它连锁的中性等位基因可发生遗传搭便车；有害突变持续受到净化选择时，邻近中性多样性可因背景选择而下降。重组把这种关联逐渐打散，因此低重组区、选择靶点附近和基因组其他区域可以呈现不同的多样性。把所有位点当作彼此独立的中性标记，会把连锁选择误读成单纯的人口数量变化。

## 中性与近中性分子进化 { #neutral-nearly-neutral }

### 中性理论解释替换率与多态性

木村资生在 1968 年提出，分子层面大量已固定的替换由选择上近于中性的突变经漂变固定，而不是每一次替换都由正选择推动。这里的主张针对分子替换和多态性的相对贡献：许多新突变会因强烈有害而迅速清除，一部分对适合度影响很小的突变可能漂变，少数有利突变由正选择传播。中性理论没有声称所有突变中性，也没有否认形态、生理和行为适应中的自然选择。[^kimura-neutral]

在简单二倍体模型中，每代产生的某类新中性突变约为 $2N_e\mu_0$ 个，每个单拷贝突变的固定概率约为 $1/(2N_e)$，于是该类中性替换率

$$
k=(2N_e\mu_0)\frac{1}{2N_e}=\mu_0.
$$

这说明理想条件下中性替换率等于每代中性突变率，与群体大小抵消。它不表示所有分子钟严格匀速：不同位点的功能约束、中性突变比例、世代时间、复制错误与修复机制都会改变 $\mu_0$，谱系间还会有速率异质性。

突变不断增加种群内变异，漂变不断移除变异。在恒定、随机交配、无限位点且中性平衡的二倍体模型中，成对核苷酸多样性的期望近似为

$$
\pi\approx\theta=4N_e\mu_0.
$$

这一关系让序列多样性能够提供历史 $N_e$ 的信息，但只有在突变率、群体史、群体结构和连锁选择得到合理处理时才可反推。瓶颈、扩张、亚群混合、选择扫荡和背景选择都能让频率谱与 $4N_e\mu_0$ 的简单平衡预期偏离。[^neutral-genomic-null]

### 近中性理论把弱选择放回群体大小

太田朋子提出的近中性理论进一步考虑适合度效应很小、却并非严格为零的突变。一个轻度有害变异在较小 $N_e$ 中可能近似中性，在较大 $N_e$ 中则更容易被净化选择清除；轻度有利变异也会经历相应的选择效率变化。因而，同一个 $s$ 不能脱离群体大小被永久归为“中性”或“受选择”，其命运取决于 $N_es$ 以及显性、连锁和群体史。[^ohta-nearly-neutral]

近中性框架也修正了“种群大、世代短便有更多非同义替换”之类单向概括。大 $N_e$ 通常提高净化选择辨认轻度有害非同义变异的效率，可能降低其固定；世代时间又会改变按年计算的突变机会。实际蛋白质与非编码序列的速率还受到功能约束、表达量、重组、GC 偏向基因转换和正选择影响，必须按位点类别和谱系分别检验。

基因组数据没有把中性理论简单“证实”或“淘汰”，而是让中性模型成为辨认其他过程的定量基准。若一个频率谱偏离中性预期，人口扩张、瓶颈、结构和连锁选择可能产生相似信号；若某区域多样性低，也要比较低突变率、选择扫荡与背景选择。可靠推断需要联合频率谱、连锁、重组、跨种比较、时间样本和实验功能证据，并明确每条证据覆盖的时间尺度。[^neutral-theory-modern]

## 从微观过程通向更长尺度 { #microevolution-scale }

微观进化通常指种群或无性繁殖系内部遗传组成在相对短尺度上的变化。它既包括一个突变从稀有到固定，也包括多基因性状均值、遗传方差、单倍型频率和群体结构的改变。变化可以很快，例如强选择下几代内的抗性演化；也可以长久停留在多态状态。适应需要可遗传变异和差异繁殖成功，却不保证所有频率变化都有适应意义。

从种群变异到物种分化也没有一堵机制上的墙。突变、选择、漂变、重组和基因流持续作用，空间结构与繁殖隔离逐渐改变它们的范围；较长时间后，这些过程会累积为谱系分化、性状创新和物种形成。宏观型式还叠加了物种产生与灭绝以及化石保存偏差，不能只把一次短期频率递推机械放大。下一页将进一步讨论[自然选择、适应与约束](selection_adaptation.md)，物种边界的形成则在[物种概念与物种形成](speciation.md)中展开。

[^local-adaptation]: Kawecki 与 Ebert 的[局部适应概念综述](https://doi.org/10.1111/j.1461-0248.2004.00684.x)区分了 local-versus-foreign 与 home-versus-away 判据；Hereford 的[互惠移植定量综述](https://doi.org/10.1086/597611)显示局部适应常见却非必然，并讨论适合度权衡和环境差异。
[^bergmann-cline]: Guo 等的[全球陆生脊椎动物分析](https://doi.org/10.1093/biolinnean/blae092)比较了物种与群落尺度的体型—纬度和体型—温度关系，也显示该型式在不同类群中的支持程度并不相同。
[^hardy-weinberg]: Nature Education 的 [Hardy–Weinberg 原理说明](https://www.nature.com/scitable/knowledge/library/the-hardy-weinberg-principle-13235724/)区分随机配子结合产生的基因型比例与使频率跨代不变所需的完整条件。
[^wright-drift]: Wright 的[经典论文](https://doi.org/10.1093/genetics/16.2.97)把有限孟德尔群体中的随机过程、交配系统和选择放入共同的频率框架；这里的二项取样结论使用理想 Wright–Fisher 常染色体模型。
[^fixation-time]: Waxman 的[群体增长与中性固定时间研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3374318/)明确说明 $4N_e$ 是恒定、随机交配二倍体群体中低频中性突变在条件于固定时的平均尺度，并推导群体大小变化时的修正。
[^effective-population-size]: Wang、Santiago 与 Caballero 的[综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC5026755/)比较了近交、方差与溯祖有效大小，并系统讨论性比、繁殖成功、世代重叠、数量波动和估计时间窗。
[^bottleneck]: Nei、Maruyama 与 Chakraborty 的[瓶颈模型](https://doi.org/10.1111/j.1558-5646.1975.tb00807.x)说明瓶颈对等位基因数与杂合度的影响不同，并取决于瓶颈强度、持续时间和恢复过程。
[^allele-surfing]: Excoffier 与 Ray 的[扩张前沿综述](https://doi.org/10.1016/j.tree.2008.04.004)总结了低频等位基因在空间扩张前沿升频、形成遗传扇区与群体结构的理论和实验证据。
[^kimura-neutral]: Kimura 的[中性理论奠基论文](https://doi.org/10.1038/217624a0)由分子替换速率提出大量替换可能选择中性；这一论点讨论的是分子进化中替换来源的相对重要性。
[^neutral-genomic-null]: Charlesworth 与 Jensen 的[连锁选择综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC10120885/)给出恒定二倍体群体中 $\pi$ 与 $4N_e\mu$ 的中性基准，并说明人口史、群体结构、选择扫荡和背景选择如何改变多样性与频率谱。
[^ohta-nearly-neutral]: Ohta 的[近中性理论论文](https://doi.org/10.1038/246096a0)把轻度有害替换的命运与群体大小联系起来；Charlesworth 的[$N_e$ 与替换模式综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC2679941/)总结了后续理论和基因组证据。
[^neutral-theory-modern]: Jensen 等的[中性理论五十年评述](https://doi.org/10.1111/evo.13650)说明中性理论既是关于分子变异相对贡献的历史主张，也是人口遗传推断所需的零模型；现代资料需同时处理选择、连锁和人口史。
