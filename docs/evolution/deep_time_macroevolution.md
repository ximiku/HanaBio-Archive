# 化石记录、生命史与宏观进化

宏观进化研究的是谱系在漫长时间中的分支、延续和灭绝，以及这些过程怎样形成生物多样性、形态差异和生态系统更替。化石为深时历史提供直接记录，地层确定事件的先后和环境背景，现生生物的形态、发育与分子资料则帮助恢复亲缘关系。三类证据共同描绘的是一棵不断分枝、经常修剪而偶尔迅速扩张的生命树；传统教材中的地质时期、代表化石和形态序列仍是读懂这棵树的必要路径，但不能把排列在时间上的化石自动连成单一直系祖先链。

## 化石如何成为深时证据 { #fossils-as-evidence }

### 化石的范围与保存类型

化石是在地质背景中保存的过去生命证据，既包括生物体本身，也包括其活动留下的痕迹。地质背景可以是沉积岩，也可以是未固结沉积物、洞穴、土壤或少数火山沉积。旧教材常以全新世开始，即距今约 11 700 年，作为化石与现代遗存的年龄界线；古生物学并没有普遍适用的硬性年龄门槛，全新世沉积中的遗骸、花粉和粪化石同样可以构成化石记录。关键在于它们是否是自然保存、具有可解释地层关系的生命证据。[^nps-fossil-definition]

**遗体化石**或体化石保存生物身体的一部分。骨骼、牙齿、贝壳、木材和矿化细胞壁较常见，皮肤、羽毛和内脏只有在特殊条件下才能保存。矿物进入骨或木材孔隙称为矿化充填，原有物质被另一种矿物代换称为交代，矿物晶体改变而化学成分大体不变称为重结晶。硅化木属于矿化和交代的常见实例；冻土中的猛犸、干燥洞穴中的遗体和琥珀中的昆虫则可保留较多原始组织，因此“化石”并不等同于“已经变成石头”。

**模铸化石**记录生物形状。叶片或花在细粒沉积物中留下的压痕属于印痕；贝壳溶解后在围岩中留下的空腔是外模或内模，后来被沉积物填充则形成铸型。**遗迹化石**记录生物活动，包括足迹、爬痕、洞穴、啃食痕、根迹和粪化石，它们常能揭示运动、取食和群居行为。卵本身及巢穴通常按繁殖活动的痕迹研究，保存的胚胎则属于体化石。人类石器是考古遗物，若与古生物和地层问题共同出现，可以作为古环境与行为证据；把所有工具都称为“遗物化石”会混淆考古学与古生物学的分类。

按观察尺度，还可区分肉眼可见的大化石、需用光学显微镜研究的微体化石，以及必须借助电子显微镜或高分辨成像识别的超微化石。花粉、孢子、有孔虫和牙形石虽小，却常因数量多、分布广而提供连续地层记录。古代脂类、色素或其他生物分子的稳定降解产物称为生物标志物或化学化石；它们可以揭示肉眼化石未保存的代谢和环境，但必须排除后期污染，并验证一种分子是否真的只来自所推断的生物过程。

### 从死亡到发现的筛选

化石形成不是对古代生物群的随机抽样。埋藏学研究生物从死亡、腐败、搬运、埋藏、成岩到暴露和采集的全过程。快速埋藏、低氧环境和坚硬结构提高保存概率，山地和强侵蚀环境中的柔软生物则很少留下记录；海洋沉积生物因此通常比高地陆生生物丰富。少数化石库以高丰度或软组织精细保存见长，能够短暂打开平常缺失的观察窗口。[^nps-fossilization]

保存之后还会经历地质与研究筛选。岩层可能被侵蚀、变质或埋在无法到达的地下，露头面积和沉积环境随时间不均匀，容易采集、研究传统悠久的类群也会被记录得更充分。已知多样性曲线同时受到真实生物变化、可保存岩石数量、采集强度和分类方法影响；岩石记录与多样性又可能共同响应海平面等环境因素，不能用一条简单校正线完全分开。[^dunhill-fossil-bias] 化石记录不完整，却并非不可用：比较保存条件相似的样本、估计采样概率、合并多个地区，并把形态资料放入系统发育模型，可以从有偏记录中提取可靠信号。

标准化石，也称带化石或指数化石，通常演化较快、地理分布较广、数量较多且容易识别，可用于对比异地岩层；三叶虫适于划分寒武纪内部地层，但并不是整个寒武纪独有。指相化石主要反映沉积环境，例如特定盐度、深度或底质中的群落。一个贝壳只能在分类和生态已知时指示环境，不能笼统等同于“有水”。标准化石回答“何时”，指相化石回答“何种环境”，生物标志物则把线索延伸到难以保存形态的生物和代谢。

### 相对年代、数值年代与地质年代表

在未受强烈扰动的沉积层中，叠覆律说明下层通常早于上层；化石群具有可重复的出现、繁盛与消失次序，生物地层学据此进行相对对比。相对年代能判断先后，却不能单独给出相隔多少年。火山灰层中的锆石等矿物可用铀—铅、氩—氩等放射性体系测年，再为夹在上下灰层之间的化石提供数值年龄范围。可靠测年需要已知衰变常数、封闭体系、合适矿物和误差传播；碳十四的半衰期较短，适用于较年轻有机材料，不用于恐龙或古生代地层。USGS 对数值地质年表的说明强调，化石建立的相对序列与可测年的岩层彼此校准。[^usgs-numeric-time]

国际地层委员会以全球界线层型剖面和点位（GSSP）定义大多数显生宙单位的下界，数值年龄会随定年改进而修订。2024/12 版国际年代地层表把寒武纪底界置于约 538.8 Ma，古生代—中生代界线为 251.902 Ma，中生代—新生代界线为 66.00 Ma。这里的 Ma 表示“距今百万年”。精确数字帮助对比事件，但时期本身由地层界线而非四舍五入后的年龄定义。[^ics-chart]

## 从寒武纪到新生代的生命史 { #phanerozoic-history }

### 寒武纪动物多样化

寒武纪开始后，动物的体型、运动方式、取食结构和骨骼类型在地质上较短的时间内显著扩展，传统上称为“寒武纪大爆发”。它是动物史中规模突出的生态与形态辐射，但不是生命突然出现，也不是所有现代动物门在同一瞬间完成。埃迪卡拉纪已有大型多细胞生物、遗迹和若干动物支系；分子钟常把主要动物谱系的分化推到可辨认硬体化石之前。矿化骨骼增加、掘穴扰动加深、捕食关系建立以及富含软躯体化石的特异埋藏，共同扩大了早寒武世的可见记录。[^erwin-cambrian]

两侧对称动物的基本分支是理解这场辐射的形态框架。后口动物包括棘皮动物、半索动物和脊索动物；原口动物中的蜕皮动物包括节肢动物、线虫及其近缘类群，螺旋动物包括软体动物、环节动物、腕足动物等。胚胎卵裂和原口命运曾是命名与分类的重要依据，现代系统发育显示各大支系内部的发育方式也会改变。因此，“原口／后口”“蜕皮／螺旋”是谱系和发育特征的组合，不是一条从简单到复杂的阶梯。

### 奥陶纪海洋辐射

奥陶纪的主要事件不是简单增加几个纲和目，而是延续数千万年的海洋生态扩张，即奥陶纪生物大辐射。浮游生物、底栖滤食者、礁体和游泳动物在不同地区、不同时间先后增加，许多寒武纪已经出现的门类在这一时期获得更高的属种多样性和更复杂的群落结构。表栖动物仍然重要，深层掘穴、附着和水柱生活方式也不断扩展。研究者因此把寒武纪的体制与生态创新和奥陶纪的分类与群落扩张视为相接而不相同的过程。[^harper-ordovician]

晚奥陶世冰期、海退及随后快速气候变化引发了显生宙五次大灭绝中的第一次，重创海洋类群。进入志留纪后，礁生态恢复，有颌鱼类开始辐射，海蝎等节肢动物多样，陆地上出现可靠的维管植物大化石和节肢动物记录。传统材料中的“甲胄鱼占优势”概括了无颌装甲鱼在早期脊椎动物群中的醒目地位；肉鳍鱼、辐鳍鱼和其他有颌类群的分化横跨志留纪和泥盆纪，无法归结为一个时期中整齐替换。

### 泥盆纪陆地生态系统与四足形态

泥盆纪常称“鱼类时代”，有颌鱼类在海洋与淡水环境中形成多种体型和取食方式。肉鳍鱼的一支逐步获得与支撑、呼吸和浅水运动相关的头骨、肩带、脊柱和成对附肢特征。鱼石螈、棘螈及近缘四足形类共同记录了鳍—肢转变的镶嵌过程：指趾已经出现时，尾鳍、鳃和水生运动仍可保留；真正高效的陆地步行又在后续谱系中完善。鱼石螈因发现史而成为经典“过渡类型”，它是分支树上的代表，而非鱼类整体走向现代两栖类的一块唯一踏脚石。

陆地生命远早于裸蕨类植物。微生物膜和真菌等先建立了陆表生态，奥陶纪隐孢子提供早期陆生植物证据；晚志留世出现较明确的维管植物大化石，泥盆纪的裸蕨型植物和莱尼燧石群则详细保存了维管、气孔、孢子囊和菌根式共生。[^kenrick-land-plants] 维管组织、根叶系统、木质部与种子的逐步组合提高了植物高度和旱生能力，并改变风化、土壤和碳循环。泥盆纪末灭绝由多次脉冲组成，海洋缺氧与气候变化等过程共同作用，盾皮鱼和礁生态受到重创。

### 石炭纪、二叠纪与最大灭绝

石炭纪湿地森林留下大量煤层，石松类、木贼类和蕨类植物繁盛，种子植物继续分化。昆虫飞行的最早可靠大化石来自石炭纪，有翅昆虫的出现改变了逃逸、扩散和后来植物传粉的可能性。四足动物中，两栖型谱系多样化，羊膜卵和皮肤等特征使羊膜动物减少对水中繁殖的依赖。高氧、广阔湿地及其后环境破碎共同塑造了陆生节肢动物和脊椎动物的演化。

二叠纪各大陆聚合成泛大陆，内陆干旱化、海陆面积变化和环流重组构成长期背景。约 251.9 Ma 的二叠纪末灭绝是已知显生宙最严重的生物危机，三叶虫最终消失，许多海洋无脊椎动物和陆生脊椎动物谱系中断。泛大陆形成不能单独解释灭绝的迅速脉冲；西伯利亚大火成岩省的大规模火山活动及其释放的二氧化碳和其他物质，与极端增温、海洋缺氧、酸化和生态级联相吻合。[^saunders-end-permian]

### 中生代的海陆重组

中生代从三叠纪延续到白垩纪末，传统上称“爬行动物时代”。恐龙在晚三叠世由主龙类的一支形成，随后与鳄形类、翼龙、海生爬行动物和其他双孔类共同构成高度分化的爬行动物辐射；鸟类位于兽脚类恐龙内部，因而现代鸟类也是存活至今的恐龙。双孔类在中生代脊椎动物中极其多样，但“多样化程度最高”取决于按物种数、形态差异还是生态角色衡量，不能作为跨时代固定等级。

二叠纪末危机后，海洋中出现新的壳体捕食者、掘穴者和游泳捕食者，贝类也演化出厚壳、棘刺、狭窄壳口及更深埋栖等防御，构成所谓“中生代海洋革命”。珊瑚礁在古生代已经存在，中生代的变化在于造礁类群、食物网和碳酸盐平台重组，而不是珊瑚礁首次出现。三叠纪末与大西洋中央岩浆省火山活动相伴的灭绝再次重组海陆群落，恐龙在侏罗纪获得更广泛的生态优势。

传统材料把被子植物起源写在侏罗纪。某些花粉和生殖结构曾被解释为侏罗纪被子植物，严格复核后仍缺少公认的、无歧义的前白垩纪证据；可靠花粉和花的化石从早白垩世开始迅速增加，分子钟可能推断更早的支系分化。[^herendeen-angiosperm] 白垩纪被子植物辐射与多类昆虫的传粉、植食和寄生关系共同扩展，但昆虫在此之前已经拥有漫长而丰富的历史。

66 Ma 的白垩纪—古近纪灭绝结束了中生代。全球地层中的撞击喷出物、同龄的希克苏鲁伯陨石坑以及与黑暗、冷却和光合作用中断相符的选择性灭绝，共同支持撞击为直接触发因素。[^schulte-kpg] 非鸟恐龙、菊石和许多海洋浮游类群消失，鸟类、哺乳动物、硬骨鱼和开花植物的幸存支系在新生代重新扩张。新生代并非预先为哺乳动物准备的时代，而是灭绝留下生态机会后，多条幸存谱系在新的气候和大陆格局中分化的结果。

## 代表谱系：从化石序列到分支树 { #fossil-lineages }

### 长鼻目的辐射

传统象类进化图常写作“始祖象→埃及象兽→古柱牙象→柱牙象→掩齿象→猛犸和现代象”，并把嵌齿象放在旁支。图中的名称反映了早期发现史和不同中文译名，能够按时代比较体形、鼻部、门齿和臼齿变化；若把箭头理解为已证实的直系亲子关系，则会掩盖长鼻目的广阔分支。

古近纪非洲的早期长鼻类体型较小，鼻和獠牙尚未达到后期状态。中新世扩散出非洲后，乳齿象类、嵌齿象类、恐象类、剑齿象类和象科等多个分支在不同大陆长期共存。整体上确实出现过更大体形、更长鼻部和改造门齿，臼齿也随取食方式发生显著变化；这些性状在不同支系中以不同组合和平行方向演化，许多大型、长牙支系最终灭绝。全长鼻目资料显示，中新世的地理扩张伴随功能生态多样性快速增加，更新世晚期又急剧收缩。[^cantalapiedra-proboscideans]

象科内部同样不是一条直线。猛犸与亚洲象的亲缘关系比它们与非洲象更近，非洲草原象和森林象也是深度分化的谱系。古 DNA 还显示古菱齿象、猛犸和非洲象相关谱系之间发生过复杂基因交流。[^palkopoulou-elephants] 形态化石给出骨骼和生态变化，分子证据解析较晚分支及杂交；后者补充而没有取代前者，因为绝大多数早期长鼻类不可能保存可读 DNA。

### 马科的分枝与形态镶嵌

始祖马型的小型森林浏览者前足多趾、后足也保留多个功能趾；渐新世的渐新马型、中新世的三趾马型及更晚的上新马型记录了肢骨延长、中央趾强化、侧趾减小和臼齿增高等变化。经典“始祖马→渐新马→中新马→上新马→现代马”序列因此清楚展示了从多趾到单主趾、从低冠叶食到部分高冠草食的形态过渡。

完整化石记录同时表明，这些名称代表时代中若干支系的典型形态，而不是每一项都恰好位于现代马的直系祖先线上。森林型与草原型马科曾长期共存，多趾、高冠齿和大体形并非一次同步改变，部分支系还反向改变或灭绝。北美气候、植被、火山灰磨蚀和奔跑生态共同影响牙齿与足部，分支和迁移使历史呈灌木状。马化石仍是演化证据的经典范例，其力量恰恰来自大量中间组合和并存分支，而不是一张过分整齐的阶梯图。[^macfadden-horses]

### 生物分界的认识史

分类系统记录了人们如何理解生命树。林奈的两界体系把生物分为植物和动物；海克尔增加原生生物形成三界；科普兰把无核的原核生物分出为原核生物界，形成一种四界体系，黎德尔等学者也提出过不同边界的四界方案；魏泰克依据细胞结构、营养方式和生态角色提出原核生物、原生生物、真菌、植物和动物五界。传统“两界—三界—四界—五界”顺序应完整保留，因为它展示显微观察和细胞学怎样改变分类问题。

核糖体 RNA 比较进一步把细胞生命的最高层级分为细菌域、古菌域和真核域。[^woese-domains] 域与界回答的层级不同，三域体系也没有让真菌、植物和动物等形态分类失去价值。现代分类要求命名类群尽量对应共同祖先及其全部后代，具体树形又会随取样、模型和水平基因转移证据更新。分类从可见形态走向整合形态、细胞和分子证据，旧体系因此成为可解释的认识史与比较工具，而不是被简单抹去的错误名单。

## 表型创新的来源与判定 { #phenotypic-innovation }

### 多功能性、组合与旧结构改造

新构造通常从已有结构和发育网络中产生。一个器官可同时承担多种功能，一个基因也可影响多个性状；多功能性和多效性既提供可被选择利用的变化，也带来性状之间的遗传约束。相对独立模块能够重新组合，蛋白质与核酸在早期生命中的功能耦联可作为分子层面的例子；在器官层面，重复、分区和连接关系改变会产生新的工作方式。

传统“叠加组合—渐进适应—旧器官改造”三条路径仍很有启发性。脊椎动物心脏的分隔增加可以提高不同循环之间的压力控制，但多心房、多心室不是所有环境中的单向终点；鳄类、鸟类和哺乳类的分隔结构还包含独立演化。四足动物附肢来自肉鳍鱼祖先成对鳍内部骨骼的重组，不是任意鱼鳍直接变成腿。羽毛先参与保温、展示或其他功能，后来被用于飞行，是旧结构改变功能的外适应实例。

材料中还列有“有产者原则”：在鹰鸽博弈的一种资产者策略中，占有资源者采取鹰式行为，入侵者采取鸽式行为。它说明先占状态和条件性行为可以改变冲突收益，但属于频率依赖选择的行为模型，不是形态总趋势或“占有者必胜”的普遍宏观进化定律。详细的策略稳定条件由自然选择页和行为生态页承接，本页保留它作为历史偶然与生态条件影响长期结果的接口。

### 光合作用序列与同源判据

旧式生命史图有时写成“原始光合作用→光系统 I→光系统 II 与叶绿素 a→叶绿素 c 类群→叶绿素 b 类群”。这条序列把现生系统按复杂度排成时间链，便于记忆色素差异，却超过了证据。无氧光合作用很早出现，I 型和 II 型反应中心可能由古老共同反应中心经基因复制和分化产生；产氧光合作用在蓝细菌祖先中把两型反应中心串联为光系统 II 和 I。叶绿素 b、c 及其他辅助色素在不同藻类和植物谱系中的分布还受到质体内共生、基因转移和谱系丢失影响，不能按现生色素排成单线先后。[^cardona-photosystems]

形态同源的判断同样需要多种证据。位置关系、内部结构、与邻近器官的连接、胚胎发生和中间形态都可支持共同来源，系统发育则检验这些特征在树上的分布。两个器官不必“完全重叠”，也可能只有某一组成部分同源；鸟翼和人前肢作为四足动物前肢同源，作为飞行器官却分别改造。部分同源、重复结构和发育模块重用使边界出现嵌套或交叉，不能用“不可包含、不可交叉”作为机械判据。

## 演化的速度与方式 { #tempo-and-mode }

### 线系渐变与间断平衡

线系渐变强调一个谱系中的性状均值持续改变，时间种可以在不中断的地层序列中按可辨认形态划分。它并不要求每个世代以完全相同速度变化，也不要求新种只能由不分枝的线系进化产生。选择方向改变、环境波动和遗传约束都能让渐变过程加速、减速或逆转。

间断平衡强调许多化石种在大部分存在时间中保持相对稳定，显著形态改变集中在与地质持续期相比很短的物种形成阶段。早期模型常以周边隔离、奠基者效应和小种群分化解释新种为何在祖先分布区突然出现；这种机制可以产生模式，却不是间断平衡成立所必需的唯一遗传机制。地质上的“快速”仍可能持续数千至数十万年，也不等于一次突变瞬间造出完整新种。[^gould-eldredge]

两种模式描述的是可检验的化石时间序列，不是达尔文进化与另一套理论的二选一。真实谱系可表现定向变化、随机游走、长期停滞及其组合。对 250 多条化石性状序列的模型比较发现，停滞和无方向波动很常见，持续定向趋势相对少见。[^hunt-fossil-lineages] 新种可以由线系改变或分支物种形成产生，适应也能在物种形成之间继续发生；旧材料中“时间种不存在”“适应只能发生在种形成时”“新种只能渐进或只能跳跃”的互斥命题都应还原为需要按资料比较的极端模型。

稳定选择、发育约束和生境追踪都可能形成表型停滞。一个物种可以通过改变地理分布继续生活在熟悉环境中，局部种群产生的短期变化也可能因扩散、反向选择或灭绝而未成为长期趋势。停滞仍包含突变、漂变、基因流和选择，并不表示基因组冻结；它描述的是所测性状在所取时间和空间尺度上的净变化较小。

### 速率的单位与时间尺度

形态速率可以按单位时间的比例变化、测量值对数变化，或每世代改变多少个表型标准差来表示。前者常以达尔文（darwin）为单位，后者称豪尔丹（haldane）。使用不同性状、标准化方式、世代长度和时间窗得到的数值不可直接排名。短时间内的快速正反变化在长时间平均后会互相抵消，因此测量区间越长，表观速率通常越低；这正是化石速率不能直接与几年内选择实验相比的原因。[^gingerich-rates]

传统教材把鳄蜥、大熊猫、牡蛎、负鼠、矛尾鱼、银杏、海豆芽、水杉、鲎、鸭嘴兽和肺鱼列作“低速进化”，马科列作“中速”，人类和有袋类列作“高速”。这份名单保存了“活化石”和形态保守性的经典观察，却不能给整个生物盖上统一速度。矛尾鱼、鲎、银杏、海豆芽和鸭嘴兽都混合保留祖征与后生新特征；外形某部分长期稳定时，生理、生态、基因组和物种形成仍可变化。[^lidgard-living-fossils] 马科也经历过快速辐射、停滞和灭绝，人类某些表型改变快而许多分子功能高度保守。“速度”必须说明对象、性状、单位和时间窗。

### 决定速率的生物与环境因素

突变率、世代时间、重组、有效种群大小、选择强度、遗传结构、发育可变性、生态机会和地理分隔都能影响不同层面的速率。有性生殖或异花授粉可产生新的等位基因组合，却不保证形态或物种形成必然更快；大种群中选择辨别微小适合度差异更有效，小种群中漂变和分化又可能更强。种群数量与物种形成速率之间没有单调关系。

选择压力不会一般性地使生物“产生更多有用变异”。环境改变已有变异的繁殖结果，过强或过快的变化会使种群灭绝，适中的新环境也可能开启生态机会。所谓“越高等、适合度越高、越能保留变异，因而进化越快”混合了价值等级与不同速率；微生物能够迅速发生基因组和生态进化，结构复杂的长世代生物则可能很慢。生物没有统一的高低等级，只有在具体性状和环境中的适合度。

## 多样性、灭绝与谱系替换 { #diversity-and-extinction }

### 多样性曲线的读法

经典海洋多样性曲线显示寒武纪和奥陶纪显著上升，古生代中后期相对平台化，二叠纪末急降，随后在中生代和新生代总体增加并穿插多次危机。这条大轮廓仍然成立，但“余下古生代不变”“中、新生代稳定高幅增长”忽略了区域、类群和采样差异。物种、属、科三个层级的曲线也不等价，高阶类群数稳定时，种数仍可大量更替。

多样性变化由起源率和灭绝率的差决定。采样标准化、占据模型和系统发育方法可以估计未观察到的类群，却都依赖模型。海平面上升既增加浅海栖息地，又增加后来可采集的沉积岩，两者会让真实多样性与采样机会同时增加。因而，现代多样性曲线不是用统计方法“消除化石”，而是把化石形成和采集过程作为观测模型的一部分。

### 背景灭绝与五次大灭绝

背景灭绝是在各时期持续发生的谱系终止，大灭绝则是短时间内跨越许多生态和分类群、明显超过背景水平的全球性事件。背景灭绝率不会简单随地质时间不断下降，观察到的变化还受到类群组成和时间分箱影响。物种的狭小地理范围、小种群、强烈生态专化和剧烈数量波动通常增加风险；某些专化也可能提高新种形成率。自然选择只能改善当前条件下的繁殖结果，没有预见下一场火山、撞击或海洋缺氧的能力。

传统“五次大灭绝”表列出了奥陶纪末、晚泥盆世、二叠纪末、三叠纪末和白垩纪末五次事件。早期统计常把“动物科的几分之一”与“海洋物种百分比”放在同一表中，这些层级和估算方法不可直接比较。保留代表类群更有教学价值：晚奥陶世事件主要冲击海洋群落；晚泥盆世多次危机重创礁生态、盾皮鱼等类群；二叠纪末三叶虫消失并造成最大范围的海陆损失；三叠纪末菊石等多类群严重更替但若干支系随后重新辐射；白垩纪末非鸟恐龙、菊石和部分有孔虫、浮游生物消失。

大灭绝的选择规则与背景时期可以不同。平时极适应局部资源的类群，可能因食物网崩溃或全球环境阈值越过而灭绝；地理广布、休眠、淡水或深海庇护等特征有时提高幸存概率，却没有适用于所有危机的万能性状。Jablonski 把这种转换称为宏观进化制度的变化：一个谱系的长期存续要同时经受背景时期和罕见危机的不同筛选。[^jablonski-extinction]

### 多样化、竞争与优势占据

谱系的物种数常随可用生态空间逐渐填充而出现多样性依赖：物种增加后，新种形成率下降或灭绝率上升。这个模式可以产生近似平台和灭绝后的恢复，却不是所有类群都必然回到固定“承载量”。环境面积、生产力、地理隔离和竞争网络会改变上限，关键创新也可能打开新的资源维度。地区年龄较长可增加积累时间，地区面积和异质性可增加容纳量；谱系本身的年龄与净多样化率都影响今天的物种数。

竞争替代指后起谱系通过直接或间接竞争促使先前谱系衰退，优势占据或先占效应则指已经占据生态空间的类群抑制后来者分化。时间上的一增一减并不足以证明竞争，二者也可能共同响应气候、海平面或灭绝。可靠判断需要生态重叠、形态功能、地区次序和系统发育等多类证据。

重复姐妹群比较是检验性状与多样化关系的经典方法：在多个独立分支中，把获得某一新性状的谱系与保持祖征的姐妹群比较；若新性状反复伴随更高物种数，它可能影响新种形成或灭绝。姐妹群共享年龄的优势仍然成立，但单次比较样本量小，性状常与其他变化相关，现生物种数还忽略已灭绝分支。现代方法把化石、性状转变和随时间变化的出生—死亡过程纳入模型，仍需警惕模型把未测环境因素误归给“关键创新”。

### 物种分选与适应辐射

物种分选是不同物种具有不同形成率和灭绝率所造成的谱系不对称。严格意义的物种选择要求差异与物种层级的涌现属性相关，例如地理范围大小；若差异来自个体体型等性状对物种形成和灭绝的外溢作用，常称为效应宏观进化。[^jablonski-macroevolution] 表型趋异描述后代平均形态偏离祖先，谱系趋异描述不同方向的分支因形成与灭绝率不同而数量不对称。一个性状可以在线系内几乎不改变，却因携带它的物种更常分支而在整个类群中越来越常见。

适应辐射是在相对较短的演化时期内，一个祖先谱系产生许多占据不同生态位、具有相应适应性状的后代。传统“适应带”指这些近缘物种进入的一组生态机会；“关键适应”或关键创新使谱系能够利用新资源、移动到新栖息地或以新方式相互作用。空岛、湖泊、灭绝后的空缺和新构造都可创造机会。生态机会、性状分化、物种形成和繁殖隔离需要分别验证，物种数快速增加而生态差异很小的非适应性辐射也存在。[^stroud-adaptive-radiation]

## 宏观进化的型式与趋势 { #macroevolutionary-patterns }

### 线系、分支与灭绝

宏观进化型式是在一段时间内，由多个线系的表型改变、物种形成和灭绝共同构成的谱系特征。以时间为纵轴、性状为横轴绘制一条线系，可以显示渐变、停滞或波动；加入分支和终止后，才能表示类群历史。遗传系统的稳定性使性状可跨代保持，可变性提供突变、重组和染色体改变，选择、漂变与基因流决定这些变异在种群中的命运，物种形成和灭绝再把种群过程累积成宏观格局。

传统材料把“遗传、变异和选择”称为宏观动力，把“中性突变和遗传漂变”称为微观动力。更准确的关系是同一组机制在多个层级作用：选择与漂变都能改变种群，地理隔离和生殖屏障产生新谱系，谱系层级的形成与灭绝差异进一步改变多样性。突变在某环境中有害、在另一环境中可能有利；染色体融合、裂分和倍性改变可以参与隔离，却不意味着进化必然“上升”。宏观进化并非脱离遗传机制的另一种运动，也不能只由自然选择一个词概括。

### 复化、特化与简化

**复化式进化**或“全面进化”在传统语境中指结构部件增加、分化程度提高或组织层级加深。细胞内区室、多细胞分工、附肢关节和感觉系统确实在若干谱系中复杂化。复杂性必须先指定指标，例如细胞类型数、结构部件数、调控层级或功能分化；某一指标上升时，基因数或其他指标可能不变甚至下降。地球生命从最小复杂度边界出发，使最大复杂度随时间有机会扩展，但微生物长期占据生命多样性和数量的主体，没有证据支持所有谱系的平均状态都朝“高等”移动。[^mcshea-complexity]

**特化式进化**描述谱系对特定资源、运动方式或环境的精细适应。它可伴随某些器官加强、另一些功能范围收窄。**简化式进化**传统上又称退化，常见于寄生、洞穴生活、固着或回归水生的谱系：不再贡献适合度的眼、附肢、消化道或代谢通路可缩小或丢失，宿主识别、吸附或繁殖器官却可能高度发展。简化节省发育和维持成本，是适应、漂变和约束共同形成的结果，“退步”只描述结构减少，不能评价生物价值或适合度。

因此，复杂化与简化可以在同一生物中并存。寄生虫丢失自由生活所需器官而强化宿主侵入结构，蛇类丢失四肢同时演化高度特化的颅骨和感觉系统。长期演化的总结果是形态与生态多样性扩大，其中既有增加、减少、重组，也有长期稳定，而不是所有生物从低级走向高级。

### 分歧、辐射、平行与趋同

分歧或趋异是共同祖先的后代在不同环境与遗传背景中走向不同性状组合。北极熊与棕熊是近缘谱系分化的常用例子，同时保留过基因交流，说明分歧不总意味着瞬间完全隔离。适应辐射是分歧的一种快速、多支系情形，强调生态机会与多种适应组合。

平行进化和趋同进化都产生相似性。传统定义常把平行限定为共同祖先的后代分歧后又在相似环境中形成相似适应，把趋同用于亲缘较远的类群。现代用法更关注相似性是否基于相近的祖先发育基础：近缘谱系独立改变同源结构常称平行，远缘谱系以不同结构解决同一功能问题常称趋同。两者之间没有永远清晰的界线，需要系统发育、发育和遗传机制共同判断。

袋狼与狼、小袋鼠与啮齿类、袋食蚁兽与食蚁兽曾被教材列作“平行”，它们实际是有袋类和胎盘类在相似生态位中形成相似体型的经典趋同；若讨论两支有袋类对相同环境的重复响应，平行一词更合适。蝙蝠与翼龙的翼、三角龙与犀牛的角状防御结构也属于远缘趋同，承担相似功能的整体结构并不同源。把例子放回树上，比只按外形记忆术语更能区分共同来源和独立适应。

### 线系趋势与谱系趋势

进化趋势是在足够长时间中，一个线系或单系群的性状分布出现有方向的改变。**线系趋势**来自单条祖先—后代序列中的平均性状改变；**谱系趋势**则可由不同性状状态的物种具有不同形成率或灭绝率产生。二者可以同向、反向或只出现其中一种。体型增大的科普法则在某些哺乳类和海洋类群中获得支持，在另一些支系中不成立；只有把每条线系的性状变化和分支存亡分开，才能判断趋势机制。

中间过渡类型连接不同形态阶段，但过渡经常呈镶嵌：某些结构先改变，另一些仍保留祖征，旁支也会试验不同组合。环境变化、发育约束、选择、漂变和物种分选共同造成演化不平衡。宏观进化可以在具体谱系中呈现明确方向，却没有预定目标；“由少到多、由简单到复杂”的传统概括适合描述生命树所占形态空间的扩展，不应被理解为每条枝都沿同一阶梯上升。

## 证据边界与研究方法 { #evidence-boundaries }

化石的首次和末次出现只是已知记录的边界。保存和采样不完全会使一个类群看起来晚出现、早消失，灭绝前稀疏记录还会造成末次化石逐层提前的 Signor—Lipps 效应。形态相似可能来自共同祖先，也可能由趋同产生；分子钟可以推断分化时间，却依赖速率模型和化石校准。可靠的生命史结论通常来自多个剖面的地层次序、独立放射性年龄、形态系统发育、古环境指标和分子证据相互约束。

宏观进化研究也需要区分模式与机制。多样性在灭绝后上升是一种模式，生态机会、竞争释放、迁移和关键创新都是候选机制；长期停滞是一种模式，稳定选择、发育约束、生境追踪和空间种群结构需要分别检验。传统化石序列训练观察与比较，现代模型量化取样和不确定性，两者共同构成深时推理。保留细致形态与地层路径，才能知道分子树或统计曲线究竟在解释什么；加入现代证据边界，又能避免把一张清晰的教学图误认成唯一发生过的历史。谱系关系与分歧时间的建模见[系统发育与生物分类](phylogenetics.md)，形态变化、发育约束和数量性状响应的机制见[表型、发育与数量性状进化](quantitative_evolution.md)。
