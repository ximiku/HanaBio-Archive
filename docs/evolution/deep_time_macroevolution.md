# 化石记录与地质生命史

地质生命史以**化石**（fossil）及其地层背景为主要记录：保存过程决定哪些生物和性状能够进入记录，地层对比与放射性定年给事件排序并估计年龄，形态和系统发育资料则帮助辨认谱系关系。地质时期、代表化石和形态序列提供了深时历史的基本路径，谱系关系还需由共有衍征和系统发育分析确定。若要进一步解释物种形成、灭绝和性状变化怎样共同塑造多样性与长期趋势，可继续阅读[宏观进化的格局与机制](macroevolution_patterns.md)。

## 化石如何成为深时证据 { #fossils-as-evidence }

### 化石的范围与保存类型

化石是在地质背景中保存的过去生命证据，既包括生物体本身，也包括其活动留下的痕迹。地质背景可以是沉积岩，也可以是未固结沉积物、洞穴、土壤或少数火山沉积。全新世开始于距今约 11 700 年，曾被用作化石与现代遗存的简便年龄界线；古生物学更重视生命证据是否自然保存并具有可解释的地层关系，全新世沉积中的遗骸、花粉和粪化石也可构成化石记录。[^nps-fossil-definition]

**遗体化石**（body fossil）保存生物身体的一部分。骨骼、牙齿、贝壳、木材和矿化细胞壁较常见，皮肤、羽毛和内脏需要特殊保存条件。矿物进入骨或木材孔隙称为矿化充填，原有物质被另一种矿物代换称为交代，矿物晶体改变而化学成分大体不变称为重结晶。硅化木属于矿化和交代的常见实例；冻土中的猛犸、干燥洞穴中的遗体和琥珀中的昆虫则可保留较多原始组织。化石因而涵盖矿化、模铸和原始组织保存等多种状态。

**模铸化石**（mold and cast fossil）记录生物形状。叶片或花在细粒沉积物中留下的压痕属于印痕；贝壳溶解后在围岩中留下的空腔是外模或内模，后来被沉积物填充则形成铸型。**遗迹化石**（trace fossil）记录生物活动，包括足迹、爬痕、洞穴、啃食痕、根迹和粪化石，它们常能揭示运动、取食和群居行为。卵及巢穴通常按繁殖活动的痕迹研究，保存的胚胎则属于体化石。人类石器属于考古遗物，与古生物和地层问题共同出现时也可提供古环境与行为证据；这套分类把考古制品与自然保存的生命遗迹区分开来。

按观察尺度，还可区分肉眼可见的大化石、需用光学显微镜研究的微体化石，以及借助电子显微镜或高分辨成像识别的超微化石。花粉、孢子、有孔虫和牙形石虽小，却常因数量多、分布广而提供连续地层记录。古代脂类、色素或其他生物分子的稳定降解产物称为**生物标志物**（biomarker）或化学化石；它们可以揭示形态化石较少保存的代谢和环境，解释时需排除后期污染并检验分子的生物来源特异性。

### 从死亡到发现的筛选

化石记录是经过多重筛选的古代生物样本。**埋藏学**（taphonomy）研究生物从死亡、腐败、搬运、埋藏、成岩到暴露和采集的全过程。快速埋藏、低氧环境和坚硬结构提高保存概率，山地和强侵蚀环境中的柔软生物则很少留下记录；海洋沉积生物因此通常比高地陆生生物丰富。少数特异化石库以高丰度或软组织精细保存见长，能够打开平常缺失的观察窗口。[^nps-fossilization]

保存之后还会经历地质与研究筛选。岩层可能被侵蚀、变质或埋在难以到达的地下，露头面积和沉积环境随时间不均匀，容易采集且研究历史较长的类群也会被记录得更充分。已知多样性曲线同时受到真实生物变化、可保存岩石数量、采集强度和分类方法影响；岩石记录与多样性还可能共同响应海平面等环境因素，需要在模型中估计多种效应。[^dunhill-fossil-bias] 比较保存条件相似的样本、估计采样概率、合并多个地区，并把形态资料放入系统发育模型，可以从不完整且有偏的记录中提取可靠信号。

**标准化石**（index fossil），也称带化石，通常演化较快、地理分布较广、数量较多且容易识别，可用于对比异地岩层；三叶虫的不同组合适于划分寒武纪内部地层，其时间范围需落实到具体类群。**指相化石**（facies fossil）主要反映沉积环境，例如特定盐度、深度或底质中的群落。贝壳的环境指示意义取决于其分类和生态。标准化石回答“何时”，指相化石回答“何种环境”，生物标志物则把线索延伸到较少保存形态的生物和代谢。

### 相对年代、数值年代与地质年代表

在未受强烈扰动的沉积层中，叠覆律说明下层通常早于上层；化石群具有可重复的出现、繁盛与消失次序，**生物地层学**（biostratigraphy）据此进行相对对比。相对年代判断先后，数值年代则估计时间间隔。火山灰层中的锆石等矿物可用铀—铅、氩—氩等放射性体系测年，再为夹在上下灰层之间的化石提供数值年龄范围。可靠测年需要已知衰变常数、封闭体系、合适矿物和误差传播；碳十四的半衰期较短，适用于较年轻有机材料，其时间范围远短于恐龙或古生代地层。USGS 对数值地质年表的说明强调，化石建立的相对序列与可测年的岩层彼此校准。[^usgs-numeric-time]

国际地层委员会以**全球界线层型剖面和点位**（Global Boundary Stratotype Section and Point，GSSP）定义大多数显生宙单位的下界，数值年龄会随定年改进而修订。2024/12 版国际年代地层表把寒武纪底界置于约 538.8 Ma，古生代—中生代界线为 251.902 Ma，中生代—新生代界线为 66.00 Ma。这里的 Ma 表示“距今百万年”。精确数字帮助对比事件，地质时期的正式边界则由 GSSP 确定。[^ics-chart]

## 从寒武纪到新生代的生命史 { #phanerozoic-history }

### 寒武纪动物多样化

寒武纪开始后，动物的体型、运动方式、取食结构和骨骼类型在地质上较短的时间内显著扩展，这一事件称为**寒武纪大爆发**（Cambrian explosion）。它是动物史中规模突出的生态与形态辐射，其历史背景可追溯至埃迪卡拉纪的大型多细胞生物、遗迹和若干动物支系；分子钟也常把主要动物谱系的分化推到可辨认硬体化石之前。矿化骨骼增加、掘穴扰动加深、捕食关系建立以及富含软躯体化石的特异埋藏，共同扩大了早寒武世的可见记录。[^erwin-cambrian]

两侧对称动物的基本分支是理解这场辐射的形态框架。后口动物包括棘皮动物、半索动物和脊索动物；原口动物中的蜕皮动物包括节肢动物、线虫及其近缘类群，螺旋动物包括软体动物、环节动物、腕足动物等。胚胎卵裂和原口命运曾是命名与分类的重要依据，现代系统发育显示各大支系内部的发育方式也会改变。“原口／后口”“蜕皮／螺旋”因而表示谱系与发育特征的组合关系。

### 奥陶纪海洋辐射

**奥陶纪生物大辐射**（Great Ordovician Biodiversification Event，GOBE）是延续数千万年的海洋生态扩张。浮游生物、底栖滤食者、礁体和游泳动物在不同地区、不同时间先后增加，许多寒武纪已经出现的门类在这一时期获得更高的属种多样性和更复杂的群落结构。表栖动物仍然重要，深层掘穴、附着和水柱生活方式也不断扩展。寒武纪的体制与生态创新由此接续到奥陶纪的分类和群落扩张。[^harper-ordovician]

晚奥陶世冰期、海退及随后快速气候变化引发了显生宙五次大灭绝中的第一次，重创海洋类群。进入志留纪后，礁生态恢复，有颌鱼类开始辐射，海蝎等节肢动物多样，陆地上出现可靠的维管植物大化石和节肢动物记录。无颌装甲鱼在早期脊椎动物群中占有醒目地位；肉鳍鱼、辐鳍鱼和其他有颌类群的分化则横跨志留纪和泥盆纪，多个分支在这一时期并存和更替。

### 泥盆纪陆地生态系统与四足形态

泥盆纪常称“鱼类时代”，有颌鱼类在海洋与淡水环境中形成多种体型和取食方式。肉鳍鱼的一支逐步获得与支撑、呼吸和浅水运动相关的头骨、肩带、脊柱和成对附肢特征。鱼石螈、棘螈及近缘四足形类共同记录了鳍—肢转变的镶嵌过程：指趾出现时，部分支系仍保留尾鳍、鳃和水生运动能力；适于陆地步行的结构在后续谱系中继续完善。鱼石螈因发现史而成为经典“过渡类型”，在分支树上代表一种性状组合。

微生物膜和真菌等较早建立了陆表生态，奥陶纪隐孢子提供早期陆生植物证据；晚志留世出现较明确的维管植物大化石，泥盆纪的裸蕨型植物和莱尼燧石群则详细保存了维管、气孔、孢子囊和菌根式共生。[^kenrick-land-plants] 维管组织、根叶系统、木质部与种子的逐步组合提高了植物高度和旱生能力，并改变风化、土壤和碳循环。泥盆纪末灭绝由多次脉冲组成，海洋缺氧与气候变化等过程共同作用，盾皮鱼和礁生态受到重创。

### 石炭纪、二叠纪与最大灭绝

石炭纪湿地森林留下大量煤层，石松类、木贼类和蕨类植物繁盛，种子植物继续分化。昆虫飞行的最早可靠大化石来自石炭纪，有翅昆虫的出现改变了逃逸、扩散和后来植物传粉的可能性。四足动物中，两栖型谱系多样化，羊膜卵和皮肤等特征使羊膜动物减少对水中繁殖的依赖。高氧、广阔湿地及其后环境破碎共同塑造了陆生节肢动物和脊椎动物的演化。

二叠纪各大陆聚合成泛大陆，内陆干旱化、海陆面积变化和环流重组构成长期背景。约 251.9 Ma 的二叠纪末灭绝是已知显生宙最严重的生物危机，三叶虫最终消失，许多海洋无脊椎动物和陆生脊椎动物谱系中断。西伯利亚大火成岩省的大规模火山活动及其释放的二氧化碳和其他物质，在时间和机制上与灭绝的迅速脉冲、极端增温、海洋缺氧、酸化和生态级联相吻合。[^saunders-end-permian]

### 中生代的海陆重组

中生代从三叠纪延续到白垩纪末，常称“爬行动物时代”。恐龙在晚三叠世由主龙类的一支形成，随后与鳄形类、翼龙、海生爬行动物和其他双孔类共同构成高度分化的爬行动物辐射；鸟类位于兽脚类恐龙内部，因而现代鸟类也是存活至今的恐龙。双孔类在中生代脊椎动物中极其多样，具体程度可分别用物种数、形态差异和生态角色衡量。

二叠纪末危机后，海洋中出现新的壳体捕食者、掘穴者和游泳捕食者，贝类也演化出厚壳、棘刺、狭窄壳口及更深埋栖等防御，构成所谓“中生代海洋革命”。古生代已有珊瑚礁，中生代的造礁类群、食物网和碳酸盐平台发生了进一步重组。三叠纪末与大西洋中央岩浆省火山活动相伴的灭绝再次重组海陆群落，恐龙在侏罗纪获得更广泛的生态优势。

被子植物的可靠花粉和花化石从早白垩世开始迅速增加。某些更早的花粉和生殖结构曾被解释为侏罗纪被子植物，目前仍缺少公认且无歧义的前白垩纪化石；分子钟则可能推断更早的支系分化。[^herendeen-angiosperm] 白垩纪被子植物辐射与多类昆虫的传粉、植食和寄生关系共同扩展，而昆虫本身已有更早且丰富的演化历史。

66 Ma 的白垩纪—古近纪灭绝结束了中生代。全球地层中的撞击喷出物、同龄的希克苏鲁伯陨石坑以及与黑暗、冷却和光合作用中断相符的选择性灭绝，共同支持撞击为直接触发因素。[^schulte-kpg] 非鸟恐龙、菊石和许多海洋浮游类群消失，灭绝释放的生态机会以及新的气候和大陆格局，使鸟类、哺乳动物、硬骨鱼和开花植物的幸存支系在新生代广泛分化。

## 代表谱系与生命树 { #fossil-lineages }

### 长鼻目的辐射

经典象类进化图常写作“始祖象→埃及象兽→古柱牙象→柱牙象→掩齿象→猛犸和现代象”，并把嵌齿象放在旁支。图中的名称反映了早期发现史和不同中文译名，能够按时代比较体形、鼻部、门齿和臼齿变化；现代系统树则把这些代表形态放回长鼻目的广阔分支中。

古近纪非洲的早期长鼻类体型较小，鼻和獠牙尚未达到后期状态。中新世扩散出非洲后，乳齿象类、嵌齿象类、恐象类、剑齿象类和象科等多个分支在不同大陆长期共存。整体上确实出现过更大体形、更长鼻部和改造门齿，臼齿也随取食方式发生显著变化；这些性状在不同支系中以不同组合和平行方向演化，许多大型、长牙支系最终灭绝。全长鼻目资料显示，中新世的地理扩张伴随功能生态多样性快速增加，更新世晚期又急剧收缩。[^cantalapiedra-proboscideans]

象科内部呈分枝演化。猛犸与亚洲象的亲缘关系比它们与非洲象更近，非洲草原象和森林象也是深度分化的谱系。**古 DNA**（ancient DNA，aDNA）还显示古菱齿象、猛犸和非洲象相关谱系之间发生过复杂基因交流。[^palkopoulou-elephants] 形态化石给出骨骼和生态变化，分子证据解析较晚分支及杂交；两类证据覆盖的时段互补，而绝大多数早期长鼻类已超出 aDNA 的保存范围。

### 马科的分枝与形态镶嵌

始祖马型的小型森林浏览者前足多趾、后足也保留多个功能趾；渐新世的渐新马型、中新世的三趾马型及更晚的上新马型记录了肢骨延长、中央趾强化、侧趾减小和臼齿增高等变化。经典“始祖马→渐新马→中新马→上新马→现代马”序列因此清楚展示了从多趾到单主趾、从低冠叶食到部分高冠草食的形态过渡。

完整化石记录同时表明，这些名称代表时代中若干支系的典型形态，其中部分位于现代马的旁支。森林型与草原型马科曾长期共存，多趾、高冠齿和大体形在各支系中以不同次序改变，部分支系还反向改变或灭绝。北美气候、植被、火山灰磨蚀和奔跑生态共同影响牙齿与足部，分支和迁移使历史呈灌木状。马化石以大量中间组合和并存分支构成演化证据的经典范例。[^macfadden-horses]

### 生物分界的认识史

分类系统记录了人们如何理解生命树。林奈的两界体系把生物分为植物和动物；海克尔增加原生生物形成三界；科普兰把无核的原核生物分出为原核生物界，形成一种四界体系，黎德尔等学者也提出过不同边界的四界方案；魏泰克依据细胞结构、营养方式和生态角色提出原核生物、原生生物、真菌、植物和动物五界。“两界—三界—四界—五界”的认识史展示了显微观察和细胞学怎样改变分类问题。

核糖体 RNA 比较进一步把细胞生命的最高层级分为细菌域、古菌域和真核域。[^woese-domains] 域与界回答不同层级的问题，真菌、植物和动物等类群仍用于表达重要的形态与谱系结构。现代分类要求命名类群尽量对应共同祖先及其全部后代，具体树形又会随取样、模型和水平基因转移证据更新。分类由可见形态走向整合形态、细胞和分子证据，早期体系也由此成为可解释的认识史与比较工具。

## 证据边界与研究方法 { #evidence-boundaries }

化石的首次和末次出现只是已知记录的边界。保存和采样不完全会使一个类群看起来晚出现、早消失，灭绝前稀疏记录还会造成末次化石逐层提前的 Signor—Lipps 效应。形态相似可能来自共同祖先，也可能由趋同产生；分子钟可以推断分化时间，却依赖速率模型和化石校准。可靠的生命史结论通常来自多个剖面的地层次序、独立放射性年龄、形态系统发育、古环境指标和分子证据相互约束。

化石序列训练形态观察与地层比较，定量方法进一步估计保存、采样和年代的不确定性。细致形态与地层路径说明分子树或统计曲线所解释的对象，观测过程模型则把清晰的教学序列放回可能存在分支和缺口的历史。谱系关系与分歧时间的建模见[系统发育与生物分类](phylogenetics.md)，由记录进一步推断多样化与趋势的方法见[宏观进化的格局与机制](macroevolution_patterns.md#macroevolutionary-evidence)。
