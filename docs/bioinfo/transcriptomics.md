# 转录组测量与 RNA-seq 分析

转录组是一个细胞、组织或生物体在特定条件下产生的 RNA 分子集合。这个集合随细胞类型、发育阶段、环境刺激和时间迅速变化，还受到 RNA 合成、加工与降解共同控制。实验把其中一部分 RNA 转换为荧光、标签序列、测序片段或原位坐标，分析再从这些读出推断基因、转录本和细胞状态。因而，“某基因表达量”并不是脱离方法而独立存在的数字：qPCR 的扩增循环、芯片的杂交强度、RNA-seq 的片段计数和原位成像的分子点分别对应不同的观测模型。

转录组学的发展并非一次技术替换。EST 和 SAGE 建立了从 cDNA 抽样认识表达产物的路径，微阵列把已知探针并行化，RNA-seq 又扩展了动态范围与转录本结构观察。这些方法留下的数据今天仍广泛存在，经典方法所揭示的取样、杂交和计数问题也继续约束现代分析。本页沿着从群体样本到表达矩阵的测量脉络展开，并把实验读出、统计结果与机制结论分开；以细胞或组织坐标为分析单位的方法见[单细胞与空间转录组学](single_cell_spatial_transcriptomics.md)。

## 表达测量的对象与实验设计 { #expression-object-design }

广义转录组包括蛋白质编码 RNA、长链非编码 RNA、rRNA、tRNA、小 RNA、未完成加工的前体和降解中间体；许多常规文库却只富集带 poly(A) 尾的真核 RNA，或先去除 rRNA 后测量其余 RNA。3′ 端标签文库主要回答每个基因捕获到多少分子，全长或长读长文库更适合连接远距离外显子、转录起止位点和 poly(A) 位点。小 RNA、环状 RNA、新生 RNA、核糖体保护片段和 RNA—蛋白结合片段还需要各自的选择或富集步骤。分析开始前必须明确分母里有哪些 RNA，以及一个“feature”究竟是基因、转录本、外显子、剪接连接、峰还是细胞。

稳态 RNA 丰度是合成与清除的合成结果。一个 mRNA 增多，可能来自转录起始增强、延伸更充分、剪接或 3′ 端加工改变，也可能来自降解减慢。常规 RNA-seq 不能单独区分这些过程；代谢标记、GRO-seq／PRO-seq 等新生 RNA 测量、转录抑制后的衰减曲线和 RNA 半衰期实验提供互补信息。RNA 丰度也不等同于蛋白质产量，因为翻译效率、蛋白降解和亚细胞定位仍在下游起作用。相应的分子机制见[转录](../molecular/transcription.md)、[RNA 加工](../molecular/rna_processing.md)和[基因表达调控](../molecular/gene_regulation.md)。

样本设计决定了统计分析能回答什么问题。独立个体、独立培养物或独立组织制备是估计生物变异的实验单位；同一 RNA 被分到多个孔、多个 lane 或多次测序形成的是技术重复。技术重复可评估测量稳定性，合并后仍只有一个生物学样本。处理与批次完全重合时，例如全部对照先建库、全部处理后建库，设计矩阵无法把处理效应与批次效应分开。随机化、平衡建库、配对设计和预先记录性别、年龄、组织区域、细胞组成、处理时间与操作者，比分析末端再选择一个“去批次”算法更能保护可辨识性。

组织表达差异还可能来自细胞组成变化。炎症组织中免疫细胞比例上升，可以使免疫标志基因在 bulk RNA-seq 中整体升高，即使每种细胞内部的转录程序没有改变。流式分选、显微切割、单细胞／单核测量、空间定位或基于参考表达谱的去卷积，可以把组成与细胞内状态进一步拆开；这些方法本身又有选择偏倚和模型条件，不能把一次校正后的矩阵视为没有混杂的真值。

## 从 qPCR、芯片、EST 与 SAGE 到测序计数 { #historical-expression-profiling }

### qPCR 的扩增曲线与相对定量 { #qpcr-quantification }

实时定量 PCR 在每个扩增循环读取荧光。双链 DNA 结合染料报告体系简单，却也会读取引物二聚体和其他双链产物；序列特异探针通过报告基团与淬灭基团的分离增加识别层次，但探针效率、降解和错配仍影响信号。RT-qPCR 还包含 RNA 质量、逆转录效率和基因组 DNA 污染等上游变异。扩增曲线呈典型 sigmoid、熔解曲线出现单一主峰可以发现明显异常，却不能独自证明扩增产物身份和定量无偏；无模板对照、无逆转录对照、产物长度或测序确认及标准曲线共同构成更完整的质量证据。MIQE 指南正是为这些实验与报告环节建立可评价的最低信息框架。[^miqe]

荧光越早越过统一阈值，起始模板通常越多。阈值循环常记为 Cq；早期资料常写 Ct。若起始分子数为 $N_0$，每循环扩增效率为 $E$，第 $C_q$ 个循环达到阈值产物量 $N_q$，则

$$
N_q=N_0(1+E)^{C_q}.
$$

标准曲线用已知浓度梯度检验线性范围并估计效率，可用于绝对定量；这里的“绝对”仍依赖标准品纯度、拷贝数定义和逆转录是否被同等校准。相对定量先以参考基因校正样本输入和部分过程变异，再以一个校准样本定义倍数。目标与参考扩增效率相近且接近 100% 时，可计算

$$
\Delta C_q=C_{q,\mathrm{target}}-C_{q,\mathrm{reference}},
$$

$$
\Delta\Delta C_q=\Delta C_{q,\mathrm{sample}}-\Delta C_{q,\mathrm{calibrator}},
$$

并以 $2^{-\Delta\Delta C_q}$ 表示相对量。若效率不相等，应使用各自效率的模型而不能直接把底数写成 2。参考基因也需在当前组织、处理和输入范围内验证稳定性；所谓“管家基因”并不保证在所有条件下恒定，多个经验证的参考通常比未经检验的单基因更稳健。

qPCR 擅长对少量预设靶标做高灵敏验证和时间序列测量，也常用于确认测序结果。其重复孔首先描述移液和扩增技术变异，条件差异的推断仍以生物学重复为单位。报告应保留引物／探针序列、扩增子位置、效率、Cq 判定方法、排除规则、参考基因、阴性对照和原始 Cq，而不只给出一张倍数柱形图。

### 微阵列的探针、杂交与归一化 { #microarray-analysis }

表达微阵列把成千上万条已知 DNA 探针固定在固相载体上，再以荧光标记的样本核酸与其杂交。双通道阵列把两个样本以不同染料放在同一玻片上，信号天然形成样本比值，但染料效率和扫描通道可造成系统偏差，因此常需 dye swap 或平衡设计；单通道阵列每张芯片测一个样本，便于在多张芯片间比较，却更依赖批次一致性和跨阵列归一化。一个基因可由一个长 cDNA 点位或多个寡核苷酸探针代表，探针序列与目标转录本版本共同决定测到的对象。

扫描图像先经过网格定位、背景评估和异常点标记，再形成 probe-by-array 强度矩阵。双通道数据常在阵列内校正强度依赖的染料偏差，并在阵列间对齐分布；Affymetrix 等单通道寡核苷酸阵列可用 robust multi-array average（RMA）联合完成背景处理、quantile normalization 和 probe-set summarization。[^rma] 这些步骤依赖“大部分特征的总体分布可比较”等假设。若处理造成全局 RNA 产量改变或大量转录本同向变化，内部归一化会重新定义相对基线，外源 spike-in 或每细胞总 RNA 测量可帮助识别这种情形。

探针饱和限制高丰度动态范围，低强度信号接近背景；交叉杂交会把同源基因、重复序列或相近异构体混合。旧芯片的 probe annotation 可能仍指向退役基因编号或不再成立的转录本，重分析时要把探针序列重新映射到明确版本的参考注释。差异分析应使用包含处理、配对和批次的设计矩阵，并在探针或基因层面进行多重检验校正。聚类热图适合呈现模式，不应替代效应量、样本间变异和正式检验。

微阵列只能系统读取设计时已放置的探针，却在长期队列、疾病分型和标准化平台中积累了大量可复用数据。RNA-seq 提供了更宽的转录本发现空间，并没有使这些历史样本失效。只要保留原始强度文件、平台与探针版本，重新注释并控制研究间批次，芯片仍可用于复现、荟萃分析和与后续测序队列交叉验证。

### EST 与 SAGE 的表达抽样 { #est-sage }

表达序列标签（expressed sequence tag，EST）来自 cDNA 克隆的一次单向测序，常读取插入片段的 5′ 或 3′ 端。大量 EST 可聚类和拼接为较长的一致序列，帮助发现基因、定位外显子、识别 poly(A) 位点并为早期基因组注释提供转录证据。预处理要去除载体、接头、低质量、低复杂度和 poly(A) 序列，识别嵌合克隆，再谨慎处理同一家族和剪接异构体的重叠。一个 EST 簇既可能混合相近旁系同源基因，也可能把同一基因的可变剪接拆开；历史上的 UniGene 等聚类结果因此适合追溯，不等同于当前参考转录本集合。

EST 数量在一定条件下反映文库中转录本的抽样频率，但克隆、归一化、组织混合与测序方向会改变这个频率。dbEST 作为 GenBank 的组成部分保存了大量历史记录，现代短读长数据并未消除它们对旧物种、旧组织和基因发现史的价值。对于参考不足的物种，长读长转录组和经过质量控制的 de novo assembly 延续了“从表达产物建立转录本”的思路，只是读长、错误模型和定量方式发生了变化。

serial analysis of gene expression（SAGE）在每个转录本的特定位置切取短 tag，把多个 tag 串联后测序，再以 tag 出现次数估计表达丰度。它把表达分析从连续荧光强度推进为离散计数，并能在没有逐基因探针的情况下并行采样。经典 9–14 nt 标签可能在基因组中不唯一，也会受限制酶位点、转录本注释和测序错误影响；LongSAGE、SuperSAGE 等延长标签以改善定位。SAGE 的 tag-count 思想与后来的数字基因表达和 3′ RNA-seq 一脉相承，因此理解其“抽样—计数—多重映射”问题仍有教学意义。[^sage]

## bulk RNA-seq 从文库到计数矩阵 { #bulk-rnaseq }

RNA-seq 将样本中的 RNA 转换成可测序文库，并以片段序列连接表达量与转录本结构。早期哺乳动物 RNA-seq 已展示读段覆盖、剪接连接和数字定量可以同时用于已知与新转录本。[^rnaseq-foundation] 现代分析仍从文库类型开始：poly(A) selection、rRNA depletion、total RNA、小 RNA、链特异或非链特异、随机引物或 3′ 标签、短读长或长读长分别决定哪些分子进入结果。

### 原始读段与文库质量 { #bulk-rnaseq-qc }

FASTQ 层面的碱基质量、接头、长度、重复序列和污染检查只是第一层。比对或定量后还应报告总读段、唯一与多重比对比例、外显子／内含子／基因间分布、rRNA 与线粒体比例、链特异性、插入片段长度、5′—3′ gene-body coverage、文库复杂度和样本间相关。降解的 poly(A) RNA 常出现明显 3′ 偏倚；globin、rRNA 或少数极高表达基因可以吞噬大部分读深；样本交换则可能由性染色体、已知基因型或组织标志发现。

这些指标没有跨物种、跨文库通用的单一及格线。原核 mRNA 没有普遍稳定的 poly(A) 尾，内含子比例和操纵子结构也不同；单核 RNA-seq 本就含更多未剪接和内含子读段；新生 RNA 文库又有自己的基因体分布。质量判定应比较同批样本、阳性对照和实验对象的预期，而不是把一种常规哺乳动物 poly(A) 文库的阈值套到所有 RNA 测量。

生物学重复之间的主成分、样本距离和表达分布能发现离群与批次，但主成分本身不是原因标签。一个样本远离其他样本，可能是真实生物亚型、细胞组成差异、降解、低输入或污染。排除样本需要预先定义或有独立证据支持，并保留排除前后的敏感性分析；看到 PCA 位置后反复改分组会把探索性模式转化为难以校准的显著性。

### 剪接感知比对与转录本定量 { #alignment-quantification }

基因组比对器需要识别跨越内含子的读段。剪接感知算法把一个 read 分成与两个外显子端匹配的片段，并利用注释或数据中的 canonical junction 建立候选连接；STAR 等方法以索引和两阶段 junction 发现支持大规模比对。[^star] 基因组比对适合观察新连接、RNA editing 候选、等位表达和融合断点，同时会面对重复序列、伪基因、近缘基因家族和未注释转录本造成的多重比对。

转录组定量把读段与一组已知转录本比较。kallisto、Salmon 等方法不必为每个片段生成完整基因组 alignment，而是先确定与片段兼容的转录本集合，再用概率模型在共享外显子和异构体之间分配不确定的片段；Salmon 还显式处理序列、GC 和位置等偏倚。[^salmon] 这种路线速度快且适合已知注释的表达定量，但参考转录本遗漏、错误或高度相似时，模型只能在所给候选中分配。所谓“伪比对／轻量比对”没有消除多重归属，只是用适合定量的问题表示它。

基因层计数通常把与某基因外显子兼容的片段汇总成整数或近似计数；转录本层定量同时估计各 isoform 的有效长度和丰度。共享外显子越多、读段越短，异构体比例越依赖模型。paired-end、链特异、较长读段和 junction 信息能增加约束；长读长可以直接连接远距离外显子，却仍受逆转录、PCR、读长完整性和较高单读错误影响。发现完整转录本结构与精确估计其丰度是两个问题，常需短、长读长和靶向验证共同完成。

de novo transcriptome assembly 在缺乏高质量参考时从 k-mer／de Bruijn graph 等结构重建转录本。覆盖悬殊、等位变异、重复和异构体共享路径会造成碎片、冗余和嵌合。组装后应评估 read support、完整编码区、污染、冗余和与近缘物种同源关系，并保存原始 contig 与版本；把每个 contig 直接命名为一个新基因，会混淆等位、异构体和装配产物。

## 归一化、设计矩阵与差异表达 { #normalization-differential-expression }

一个样本中某基因获得的片段数同时取决于分子丰度、可被测到的有效长度、文库总片段数和各种序列偏倚。RPKM／FPKM 先按基因长度和测序量缩放；TPM 先按有效长度得到 rate，再使每个样本的 rate 总和为一百万。TPM 因而适合描述同一样本中转录本相对构成，或在方法与组成相近时用于可视化。它没有估计生物学重复间方差，也没有自动消除“少数转录本大量增加使其他转录本相对份额下降”的组成效应。

基因差异表达通常从未按样本间预先归一化的计数或由转录本定量正确汇总的 count-like quantity 出发。edgeR 的 TMM、DESeq2 的 median-of-ratios 等方法估计样本尺度因子，并以多数基因没有巨大同向变化或存在可用参考分布为前提。转录本汇总到基因时，isoform usage 改变会改变平均有效长度；tximport 一类方法可把转录本丰度估计及其长度偏移传递给基因计数模型。把 TPM 矩阵直接送入要求原始计数分布的模型，会破坏其均值—方差关系和 offset 定义。

RNA-seq 计数的样本间方差通常大于简单 Poisson 模型，负二项广义线性模型以均值和 dispersion 描述这种过度离散。DESeq2、edgeR 等方法在基因间共享信息以稳定小样本的 dispersion 或 log fold change 估计，再依据设计矩阵检验系数或 contrast。[^deseq2] 一个配对处理设计可以写成“个体 + 处理”，时间序列可以包含时间、处理及交互项；多个组别最好在同一模型中定义计划好的对比，而不是为每一对样本另做一次分析。

批次、性别、组织区和 RNA 质量可以作为协变量，但协变量过多会耗尽有限样本的自由度；完全共线的因素则无法同时估计。隐藏因子方法能概括未记录变异，却可能一并移除真实处理信号。模型诊断应检查样本距离、dispersion、mean–variance trend、离群影响和 contrast 方向。结果至少报告基因／转录本版本、base mean、log fold change、标准误、原始与校正后 P 值，以及独立生物样本数；只按“校正后 P 值小于 0.05”给出长名单，会掩盖效应大小和检测能力。

全局 RNA 输出变化是相对计数的特殊难题。如果每个细胞中几乎所有 mRNA 都增加，而测序仍从等量 RNA 建库，内部尺度归一化可能把总量变化消去。已知量外源 RNA、细胞数归一化、总 RNA 或独立分子计数可提供参照，但 spike-in 必须在能够经历目标技术变异的步骤加入，且其回收稳定。任何归一化都是以某个量为不变参照，不存在脱离生物问题的“绝对无偏矩阵”。

多重检验控制的是一组声明中的错误比例，不表示每个显著基因都具有同等生物意义。低计数过滤可以减少几乎无信息的检验，独立过滤规则应在观察效应方向前确定。基因集富集、通路和网络分析还会继承基因长度、表达检测能力、注释密度和基因间相关；这些下游方法由[功能注释、富集与功能预测](functional_annotation.md)进一步展开。

## 转录本结构、剪接、融合与非编码 RNA { #isoforms-splicing-fusions }

### 可变剪接与转录本使用 { #alternative-splicing }

外显子覆盖下降可能来自该外显子被跳过，也可能来自整个基因表达下降或比对困难。剪接分析因此常比较 junction、exon bin 或 transcript usage 在同一基因内部的相对变化。cassette exon、alternative 5′／3′ splice site、mutually exclusive exon 和 intron retention 各有不同的可观测读段；百分比剪入值（percent spliced in，PSI）是条件于可区分该事件的 reads 的比例，而不是基因全部 RNA 的绝对数量。

短读长能精确计数局部连接，却未必知道相隔很远的几个外显子是否位于同一分子。长读长或靶向扩增能连接完整 isoform，但低丰度分子、5′ 端不完整和测序错误仍影响发现与定量。正式结论应给出事件定义、覆盖、效应大小和重复一致性，并以 RT-PCR、长读段或独立数据验证关键异构体。RNA 加工因子的结合或扰动可以加强机制链，单次差异剪接统计本身只说明产物比例改变。

### 融合转录本与异常连接 { #fusion-transcripts }

融合检测寻找一端来自基因 A、另一端来自基因 B 的 split read 或 discordant pair。真实染色体重排可产生稳定融合转录本，trans-splicing、read-through transcription、模板切换、PCR 嵌合和样本污染也能形成类似 reads。候选评估要考虑断点是否落在可解释的外显子边界、支持片段是否独立、配对方向与插入长度、同源序列和正常样本背景，并与基因组结构变异证据相接。临床或机制性主张通常需要独立 RNA 验证、DNA 断点或蛋白产物证据，而不能只凭一个软件的候选列表。

### 非编码 RNA 的文库依赖 { #noncoding-rna }

长链非编码 RNA 常丰度低、组织特异，且与邻近编码基因、反义转录和重复序列重叠；它们需要链特异数据、可靠转录边界和独立表达证据。小 RNA 文库以接头连接和尺寸选择富集 miRNA、siRNA、piRNA 等短分子，ligation bias 会使不同末端和结构的 RNA 捕获效率不同。rRNA、tRNA 和其他高度修饰 RNA 会造成 reverse transcription stop 或错配；专用去修饰、末端处理和比对规则改变可见分子集合。把普通 poly(A) RNA-seq 中零读数解释为“该非编码 RNA 不表达”，往往忽略了文库根本没有设计去捕获它。

环状 RNA 候选常由 back-splice junction 支持，重复序列、转录本重排和模板切换可产生伪连接。RNase R 富集、不同建库策略、跨连接引物和长读段可加强证据，但稳定性、翻译或调控功能仍需独立实验。RNA editing 候选同样要排除 DNA 变异、比对偏倚、旁系同源序列和测序错误，并用配对 DNA 或特异实验区分。

### RNA—蛋白结合图谱 { #rna-protein-binding }

RIP-seq 在原生或较温和条件下用抗体沉淀 RNA-binding protein 及其关联 RNA，能发现处于同一复合物的候选转录本，却可能包含间接结合并受复合物重排影响。CLIP 家族先以紫外交联固定直接接触附近的 RNA—蛋白关系，再免疫沉淀、有限 RNase 消化并测序留下的 RNA 片段。HITS-CLIP、iCLIP、PAR-CLIP 和 eCLIP 在交联化学、接头连接、截短 cDNA 捕获、对照和重复处理上各有差异；iCLIP 利用 crosslink-induced truncation，PAR-CLIP 借助光活性核苷及特征转换帮助定位。[^clip-methods]

分析通常包括 barcode／UMI 处理、接头与低复杂度过滤、比对、PCR duplicate 控制、富集区或 crosslink site 识别、motif 与转录区域富集。交联效率具有碱基和结构偏好，抗体决定沉淀对象，RNase 强度改变片段边界，高丰度 RNA 又会提高背景。input、size-matched input、IgG／knockout 对照和生物学重复帮助区分非特异回收。一个 CLIP peak 表示当前流程中相对于背景富集的候选结合区，并不自动说明结合改变了 RNA 的剪接、稳定性或翻译；扰动该蛋白或位点并观察直接产物变化，才把定位接到功能。

## 从群体平均到细胞与空间解析 { #single-cell-spatial-interface }

bulk RNA-seq 的样本矩阵适合比较组织或群体的平均表达，却会把细胞组成和细胞内状态叠加在同一信号中。单细胞／单核方法以 cell barcode 和 UMI 建立稀疏的 gene-by-cell matrix，空间方法再把分子、细胞或捕获位置连接到组织坐标；分析对象由“样本中的基因”扩展为细胞类型、状态、轨迹、空间域和邻域。相关的数据模型、质量控制、整合及证据边界见[单细胞与空间转录组学](single_cell_spatial_transcriptomics.md)。

无论分辨率如何提高，转录组结果仍须回到分子与组织尺度验证。qPCR 可验证少量靶标，原位杂交保留位置，Western blot、质谱和成像检验蛋白输出，流式或组织计数检验细胞组成，功能扰动检验必要性和充分性。选择验证靶标时应覆盖不同效应大小、丰度和机制层级，而不只挑热图中最醒目的几个基因。

## 可复现分析与报告 { #reporting }

一个可复现的转录组项目应把样本表、原始数据、参考序列和注释版本、文库类型、软件与参数、过滤规则、设计矩阵、contrast、随机种子和主要中间矩阵连接起来。bulk 数据应保留 sample-by-feature raw counts，qPCR 和芯片分别保留原始 Cq 或强度文件；只保存最终归一化矩阵，会使后来无法重新判断过滤、计数和实验单位。单细胞 barcode matrix、空间坐标与图像的报告要求见[单细胞与空间转录组学](single_cell_spatial_transcriptomics.md#reporting)。

GEO、SRA／ENA 等档案分别承接 processed matrix、实验 metadata 与原始 reads，提交时应使用稳定样本标识连接 BioSample、run 和分析对象。人类可识别的基因型、疾病和空间病理数据可能需要受控访问或去标识化；FAIR 不等同于无条件公开。命令行、环境、容器、工作流与 provenance 的具体组织见[命令行、工作流与可重复研究](workflows.md)。

图表应让读者看见实验单位和不确定性。样本级 PCA、每样本 counts、effect size 与置信区间通常比只给 cluster heatmap 更能支撑比较。无论数据量多大，最终结论都应回到“测到了什么对象、在哪些独立样本中重复、模型假设是什么、还需要哪一种验证”。
