# 生态因子、耐受与适应

生态学从一个有明确边界的主体开始。研究对象可以是一株幼苗、一只正在繁殖的鸟、一群细菌，也可以是某个生活史阶段；研究者随后追问，周围哪些条件和资源改变了它的存活、生长、繁殖与活动，它又怎样改变周围环境。主体一旦改变，同一地点中值得测量的“环境”也会改变。林下的光斑对幼苗是碳获取条件，对蜥蜴可能是调节体温的位置，对捕食者则可能改变猎物的可见度。

个体生态学由此连接生理、行为和进化。它关心外界变量经过何种形态、生理或行为过程成为生物的实际暴露，也关心短时调节、个体一生中的可塑性和世代间遗传改变分别能够把生存边界推到哪里。生态学的组织层次及生物与非生物环境的共同作用，可参照主流基础教材的概述。[^ecology-scope]

## 环境、生境与生态因子 { #environment-habitat-factors }

一个生物的环境，是在指定时空尺度内包围它并可能影响其状态的外部事物与过程。空气、水、基质、温度和辐射属于物理化学环境；食物、竞争者、捕食者、寄生物和共生伙伴属于生物环境；耕作、照明、污染和捕捞等人类活动则通过改变这些条件、资源和相互作用进入环境。生态研究从问题出发，在景观、斑块、微生境乃至叶面边界层之间选择真正决定暴露的测量尺度。

**生境（habitat）**是生物实际生活或完成某一生命活动的场所及其典型环境组合。一个物种可以在林缘繁殖、在林内越冬，幼体和成体也可能占据不同生境。生境首先回答“生活在哪里”；[生态位](species_interactions.md)进一步描述它利用哪些资源、承受哪些条件，以及与其他生物发生何种作用。林地、池塘这样的名称是空间入口，同一种生境内部仍可能包含土温、含水量、植被遮蔽和资源密度截然不同的微生境。

环境要素在影响研究对象的某个过程时，成为这个问题中的**生态因子（ecological factor）**。常见分类把它们分为气候、土壤、地形、生物和人为因子，或简化为非生物与生物因子。按作用机制还可区分条件、资源、生物相互作用和扰动：

- 温度、pH 和盐度通常作为条件，生物会经历它们，却不会因利用而把温度或 pH “消耗掉”；
- 光量子、水、无机营养和食物可作为资源，被个体获得后会减少其他个体在同一时空内能够获得的份额；
- 捕食、寄生、竞争和互利把一个生物的活动变成另一个生物的环境；
- 火、洪水、风倒和耕作等扰动会突然改变个体、资源和物理结构，其后果取决于强度、频率、范围以及发生时的生活史阶段。

这些类别随研究对象和过程改变。水对陆生植物是可消耗资源，对水生动物同时构成介质、渗透条件和流体力学环境；阳光既提供光合作用能量，也影响温度和光周期信号。密度制约与非密度制约描述某一因子的效应是否随种群密度而变，具体判据见[种群增长、调节与空间动态](population_dynamics.md)。

## 多因子共同形成实际暴露 { #multiple-factors }

自然环境中的因子总在组合中起作用。高温可以加快蒸发，使相同土壤含水量造成更强水分胁迫；低氧会收窄动物可耐受的温度范围；遮阴既减少光合辐射，也降低叶温和蒸腾。一个实验中观察到“温度效应”，往往意味着在给定水分、食物、氧和暴露时间下的温度效应。综合分析生态因子需要把共同变化的变量、因果链和交互作用写进假说。

因子的重要性也随过程和阶段变化。萌发所需的温度与水分窗口可以不同于成熟植株维持生长的窗口；昆虫卵、幼虫、蛹和成虫面对同一次寒潮可能有不同结局；一个条件可以限制繁殖而尚未降低成体存活。“主导因子”指在已界定的响应变量、时段和背景下解释力或因果作用较强的因子。

补偿同样具有明确机制和边界。阴生叶可通过较低呼吸消耗和不同叶片结构，在较弱光照下维持正碳收支；某些软体动物可在生物矿化中容纳一定比例的锶，其余依赖钙的生理功能仍受各自分子机制约束。一个因子改变对另一个因子的需求或摄取效率，属于交互或部分补偿；必需元素、特定底物和生活史条件则受化学计量与功能约束。

## 生物也在塑造环境 { #organism-environment-feedback }

环境作用于生物的同时，生物的代谢、身体结构和行为不断改写局部环境。植物冠层截留辐射、减弱风速并改变林下湿度，根系吸水和凋落物分解改变土壤水分、酸碱度与养分形态；穴居动物搬运土壤，河狸筑坝改变水位、流速和沉积过程。微生物消耗氧或释放代谢产物，也能在毫米尺度内造成陡峭的化学梯度。

当生物通过改变物质的物理状态来创造、维持或破坏其他物种的生境时，可称为**生态系统工程者（ecosystem engineer）**。树木和珊瑚主要用自身结构改变环境，河狸和穴居动物则搬移外部材料。这个概念强调可测量的环境改造及其后果，影响可以有利或有害，也不以动物的意图为判据。[^ecosystem-engineers]

反馈还会改变选择压力。白蚁群体的产热、气体交换、运水和修筑行为同巢体孔隙结构共同形成巢内微环境；不同种类和不同外界气候下，风、温差和代谢热对通风的贡献各异。白蚁丘的通风和温度来自物理结构、群体行为与天气的耦合。[^termite-mounds] 个体或群体由此在一定范围内缓冲外界变化，缓冲能力仍受能量、材料和极端事件限制。

## 限制因子是相对于过程而言的 { #limiting-factors }

### 从最小量到资源限制 { #liebigs-minimum }

**利比希最小因子定律（Liebig's law of the minimum）**源于作物矿质营养研究：当其他条件给定时，产量首先受相对于生物需求最不足的必需资源限制。这里的“最少”指相对需求和生物可利用量。植物只需少量铁，却可能在铁的生物可利用形态不足时受铁限制；环境中氮总量很高，也可能因多数氮难以及时吸收而限制生产。

木桶短板是这一思想的直观比喻，真实系统还会发生限制因子转换和**共同限制（colimitation）**。补充氮后，磷、光或水可能成为新的瓶颈；一种营养元素可能参与另一种元素的摄取酶，两个资源便形成生化依赖；群落中不同物种受不同资源限制，整体生产对多种添加同时响应。海洋初级生产研究进一步把共同限制区分为独立、可替代和生化依赖等类型。[^colimitation]

### Blackman 的限制因子原理 { #blackman-limiting-factor }

Blackman 在 1905 年讨论光、二氧化碳和温度如何共同控制光合作用时提出：一个过程的速率由若干独立因子共同决定时，速率会受其中最慢的因子限制。原始论述强调的是过程中的瓶颈，并没有把“因子的最大状态”定义为限制因子。[^blackman]

例如弱光下提高二氧化碳浓度，光合作用速率可能几乎不变，因为光能输入仍是瓶颈；光照增强后，二氧化碳供应、温度或叶片内部的生化能力又可能接替成为限制。过高温度、过量盐分或毒物会使响应越过最适区，进入胁迫和损伤范围，这与资源不足造成的瓶颈属于不同机制。

识别限制因子需要指定过程并操纵候选变量。研究存活、生长速度和繁殖完成率会得到不同答案；一次短期补加实验可以发现当时的近端限制，其季节尺度作用还需长期测量。添加某资源后缺少效应，可能源于另一因子先行限制、添加物不可利用、暴露时间过短或测量指标不敏感。Blackman 原文已经指出，控制实验中保持相同的条件若恰好成为瓶颈，会掩盖真正想检验的效应。

## 耐受曲线连接环境与功能 { #tolerance-curves }

**谢尔福德耐受定律（Shelford's law of tolerance）**把限制从资源不足扩展到环境梯度的两端：一个物种需要处于若干关键条件的可耐受范围内，才能维持相应生命活动。[^shelford] 对单一因子作图时，横轴是温度、盐度或 pH 等环境变量，纵轴是明确的生物学响应，如酶活性、净生长、存活概率或繁殖成功。曲线中通常可辨认低端和高端界限、功能较低的胁迫区以及表现较好的范围。

“最适值”随测量对象改变。使短期生长最快的温度，可能不同于使整个生活史后代数最多的温度；个体可以在某一盐度下存活，但繁殖需要更窄范围；数小时暴露的致死上限也区别于长期慢性暴露上限。曲线还可能不对称、具有多个局部高点，或因资源、竞争和既往暴露而移动。实际研究应同时写明响应变量、生活史阶段、暴露持续时间和其他环境条件。

**生态幅（ecological amplitude）**或**生态价（ecological valence）**常用来描述生物在某一环境轴上的适用范围。“广温”“狭盐”等词需要同时给定环境轴和生命活动；一个物种可以耐受很宽的温度范围，却只在狭窄底质上繁殖。耐受范围由基因型、发育经历、个体状态和可塑性共同形成，并会随这些条件移动。

耐受曲线描述非生物条件与功能的关系；野外分布还受扩散、竞争、共生伙伴、捕食、干扰和历史事件影响。因此，非生物条件可排除明显难以存活的区域，实际出现位置则需结合种间关系和时间历史。这个区别见[竞争、生态位与共存](species_interactions.md)中的基础生态位和实现生态位。

## 个体一生中的调节与可塑性 { #regulation-and-plasticity }

环境改变后，生物可以在不同时间尺度上作出反应。离子泵、气孔开闭、血流分配和行为选位可在秒至小时内调节内部状态；酶量、膜组成、器官大小和季节性行为可在日、月或发育过程中改变。**内稳态（homeostasis）**是通过调节使关键内部变量维持在功能范围内的动态过程，调节的精度和代价因变量、物种与状态而异。同一个体可以严密调节血液 pH，同时让体温在一天中明显波动，说明不同内部变量具有不同调节强度。

同一基因型在不同环境中产生不同表型，称为**表型可塑性（phenotypic plasticity）**。其中有些变化可逆且在成年期发生，有些在发育窗口形成并长期保留；有些提高当前环境中的适合度，也有些是物理损伤或信息错误造成的非适应性反应。可塑性能够迅速改变表型，也受感知准确性、反应时间、能量与材料成本以及既有发育结构约束。环境变化过快或超出历史范围时，原有反应规则甚至可能把个体引向生态陷阱。[^plasticity]

生态与生理文献常把实验室中由一个或少数受控因子诱发的可逆改变称为**驯化（acclimation）**，把自然气候或季节的多因子变化引起的个体调整称为**气候驯化（acclimatization）**。这是一项常用工作约定，不同分支的词界略有差异。两者都发生在个体一生中；遗传适应则需要比较世代间的遗传差异。[^thermal-terms]

骆驼对干旱的耐受体现了多个层级的配合：水分保存、体温与代谢调节、行为和椭圆形红细胞的膜性质共同支持脱水与快速复水。低渗实验观察到骆驼红细胞在较低盐浓度下仍保持完整；细胞失水与复水能力需要根据渗透条件定量描述。驼峰中的脂肪主要作为局部储能组织，其分解供能和代谢水作用区别于脂肪在体内往返搬运。[^camel-cells] 水盐与热收支细节分别见[水、土壤、气候与营养](water_soil_climate.md)和[光、温度、风与火](energy_environment.md)。

## 休眠把不利时期从生活史中隔开 { #dormancy }

**休眠（dormancy）**是一组降低活动、发育或代谢的状态，其共同生态意义是让生活史同季节性资源和胁迫错开。休眠个体仍可能维持部分活动和代谢。植物种子和芽、微生物、无脊椎动物及脊椎动物使用的分子机制与触发方式差异很大，因此具体研究还需说明对象和状态。

昆虫研究通常区分**滞育（diapause）**与**静息（quiescence）**：滞育是在不利季节到来前由光周期、温度、营养等线索诱导的程序性发育停顿，进入和解除受内源调节；静息则直接由突发的不利条件造成，条件改善后可以较快恢复。两者表面上都不活动，却对季节预测和恢复信号有不同要求。[^diapause]

哺乳动物的**蛰眠（torpor）**是受调节的代谢和体温降低；持续数日或数周、由一连串蛰眠和周期性复温组成的季节过程称为**冬眠（hibernation）**。**夏眠（estivation）**常见于干热或缺水时期，既可发生在外温动物，也可见于少数内温动物。缓步动物、轮虫等在严重脱水时形成的隐生状态属于更深的代谢抑制，其代谢水平需依据检测限描述为“未检出”或“极低”。不同休眠策略的燃料利用、复苏代价和生理保护机制也各不相同。[^metabolic-dormancy]

休眠扩展的是生物在时间上的应对方式：个体避开不利时期，活动期的条件仍须落回可运作范围。节律怎样预测季节、动物怎样在蛰眠与清醒之间切换，可与[生物节律、迁移与导航](../zoology/behavior/rhythms_migration_navigation.md)和生理学中的[能量代谢与体温](../physiology/energy.md)对照阅读。

## 世代间的适应与生态型 { #adaptation-and-ecotypes }

演化意义上的**适应（adaptation）**是自然选择等过程造成的遗传性改变，使群体在特定环境中的适合度提高；“适应”也可指由这种历史形成的性状。个体在一生中驯化、学习或调整表型，可以改变当代选择压力，遗传适应则发生在世代间。区分调节、可塑性和演化，使“生物适应环境”从结果描述变成可以检验的时间过程。

同一物种的不同种群若在各自生境中演化出遗传性差异，常称为**生态型（ecotype）**。生态型可以未被正式命名为变种或亚种，边界也可能连续；沿海拔、纬度或土壤梯度连续变化的遗传性状可以形成渐变群。共同园实验把不同来源个体放到相同环境中，用来判断差异能否在共同条件下保持；互惠移植再比较各来源在本地和异地的存活或繁殖，检验“本地种群相对外来种群在本地表现更好”的局部适应预测。[^local-adaptation]

环境差异可以推动近缘种群的性状分化，形成**趋异适应（divergent adaptation）**；远缘类群面对相似功能问题时，可能独立形成相似性状，即**趋同适应（convergent adaptation）**。植物的乔木、灌木、垫状植物等生活型，是把体型与持久组织位置等生态外貌归类的工具，同一生活型可在不同支系重复出现，各物种仍可占据不同生态位。

**适应辐射（adaptive radiation）**比一般的趋异适应范围更窄，指一个祖先支系伴随多个物种形成事件而迅速占据不同生态机会，产生一簇生态和表型分化的近缘物种。一个物种内部形成两个生态型属于趋异和局部适应；支系多样化、生态差异与物种形成的证据共同成立时，才支持适应辐射。生态机会、选择、基因流和物种形成的证据见[进化生物学](../evolution/index.md)。[^adaptive-radiation]

## 从环境相关走向因果解释 { #causal-inference }

完整的个体生态问题至少包含四个相互对应的部分：明确主体和生活史阶段，选择存活、生长、繁殖或行为等响应量，测量生物真正经历的暴露，并在合适时间尺度上操纵或比较候选因子。气象站温度不一定等于叶片或洞穴内部温度，土壤总氮不一定等于根可获得的氮，地点间相关也可能同时混入历史与种间作用。野外梯度、受控实验、共同园、互惠移植和长期监测提供的是不同证据，应围绕同一机制互相校验。

[光、温度、风与火](energy_environment.md)分析辐射与热量怎样进入生物体并形成扰动，[水、土壤、气候与营养](water_soil_climate.md)讨论物质供应和介质性质，[种群数量、取样与统计](population_ecology.md)则把个体响应累积为出生、死亡、迁入与迁出。限制因子、耐受范围和适应共同形成从环境测量走向机制、再从个体功能连接到分布和数量的推理工具。
