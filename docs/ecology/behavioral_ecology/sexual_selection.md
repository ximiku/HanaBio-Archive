# 性选择与繁殖策略

繁殖把个体的生存资源转换成后代，却很少由雌雄各自完成同一组任务。配子的大小和数量、寻找配偶所需的时间、交配后仍可争夺的受精机会，以及抚育后代造成的机会成本，共同决定一次繁殖的收益。由此产生的配偶竞争、求偶选择、精子竞争和亲代照料，既保留了传统动物行为学所记录的形态与动作，也需要用种群性比、生活史和遗传亲子关系解释其生态后果。

本页集中讨论这些行为背后的收益结构。求偶序列、交配器官、授精方式和各动物类群亲代行为的形态学细节，完整保留在[繁殖与亲代行为](../../zoology/behavior/reproduction_parental.md)；一般性的繁殖投入、后代大小—数量和当前—未来繁殖权衡见[生活史生态学](../life_history.md)。领域和展示场的空间经济学则与前页[栖息地、领域与捕食关系](habitat_predation.md)相接。现代的遗传、内分泌和分子证据在这里用于解释传统现象、校正适用条件，而不取代自然史观察本身。

## 有性生殖、交配方式与性别功能 { #sex-and-mating }

有性生殖把来自不同配子或不同单倍体核的遗传物质结合起来，减数分裂和重组使后代形成新的等位基因组合。与克隆生殖相比，它可能付出寻找配偶、交配传播疾病、拆散已有适应性组合以及只把部分基因传给每个后代等代价；若资源相同且有性雌体所生的雄性不直接产仔，它相对于只产生雌性克隆后代的无性系还会面临经典的“雄性成本”。重组的优势则随有害突变清除、多个位点间干扰、寄生者追赶和环境选择的时间尺度而变。性为何能够长期维持因此没有一条“稳定环境无性、恶劣环境有性”的通则，而是若干机制在不同谱系中的合力。[^otto-sex][^barton-charlesworth]

雌雄同体描述一个个体具有两种性别功能，自交描述同一个体产生的雌雄配子结合，两者并不等同。许多开花植物兼有雌雄功能，却通过自交不亲和、雌雄异熟或空间分离促进异交；闭花受精则使花在不开放时完成自交。自交可在缺少传粉者或配偶时提供繁殖保障，也提高纯合度，使隐性有害等位基因暴露并造成近交衰退。自然种群常在自交保障、花粉输出、近交衰退和传粉环境之间形成混合交配率，而不是只有完全自交和完全异交两端。[^lande-schemske]

植物的性系统还包括雌雄同花、同株异花、雌雄异株以及雌株、雄株与两性株以不同组合共存。它们涉及花器官发育、资源分配、传粉和种子散布，不能由“木本或草本”“热带或温带”单一决定。玉米的雄穗和雌穗位于同株不同部位，属于雌雄同株异花；其性别器官发育受遗传调控和激素信号共同塑造。雌雄异株在若干具有肉质果、动物传粉或木本生活史的谱系中较常见，但这是一组相关趋势，并非植物繁殖系统的进化阶梯。[^barrett-plant]

## 性分配与性比 { #sex-allocation }

**性分配**是亲本在雄性功能和雌性功能之间投入资源的方式；对雌雄异体动物，它可表现为产生不同性别后代的数量和质量，对雌雄同体生物，则还包括个体把资源分给花粉、精子、胚珠或卵的比例。分析性分配时必须先说明测量的是哪一种性比：

| 性比 | 统计时点 | 主要决定过程 |
| --- | --- | --- |
| 初级性比 | 受精或合子形成时 | 减数分裂、配子竞争、受精机制与亲本分配 |
| 出生或孵化性比 | 幼体进入可观察阶段时 | 初级性比加胚胎、卵和幼体的性别差异死亡 |
| 成体性比 | 达到成熟或某一年龄阶段时 | 累积的性别差异存活、成熟、迁入与迁出 |
| 操作性性比 | 某时某地可交配雌雄的比例 | 成体性比、繁殖同步性、配偶搜寻时间和每次繁殖后的退出时间 |

Fisher 的经典论证从频率依赖收益出发：当某一性别稀少时，每个稀少性别个体平均获得的交配机会增加，生产该性别后代的遗传收益随之上升，选择趋向使亲代对两种性别的**总投入**相等。若两性单个后代的成本不同，平衡数量就不必是 1∶1；若性别决定受环境、受精控制或单倍—二倍体遗传影响，亲本或群体还可能在一定范围内改变性分配。这个模型描述选择结果，并不要求亲本有意识地“计算”性比。[^fisher-sex]

群体空间结构会改变稀有性的收益。Hamilton 的**局部配偶竞争**模型指出，若少数雌体的儿子主要在出生斑块内争夺姐妹，额外产生雄性会加强兄弟间竞争，偏雌的后代性比便可能演化；寄生蜂和一些高度局域交配的无脊椎动物提供了典型检验。[^hamilton-sex-ratio] 若某一性别更留居出生地并争夺亲本附近的食物或繁殖位置，**局部资源竞争**可使产生该性别的边际收益降低，选择偏向较常散布的一性。方向取决于究竟哪一性留居、资源如何继承和竞争是否发生，不能固定写成“鸟偏雄、兽偏雌”。

Trivers—Willard 假说进一步讨论亲本状态与后代性别：只有当亲本状态能够持续影响后代状态，而且状态对一性未来繁殖成功的边际作用更强时，条件较好的亲本才被预测对该性投入更多。[^trivers-willard] 这些假设在部分哺乳动物、鸟类和其他类群中可检验，但母体体况并不普遍决定“好时生儿、差时生女”。出生性比、幼体质量、成活率和最终繁殖成功需要分别测量。

## 顺序性雌雄同体与大小优势 { #sex-change }

一些动物在一生中先以一种性别繁殖，随后转变性别功能。**雌性先熟**指先为雌体后转为雄体，**雄性先熟**指先为雄体后转为雌体。大小优势模型给出一个直观条件：若体型增大对雄性繁殖成功的增益比对雌性更陡，先雌后雄可能有利；若大型雌体的产卵量增长特别快，而小型雄体仍能成功授精，则先雄后雌可能有利。[^warner-sex-change]

蓝头隆头鱼的社会群通常由一个优势大雄鱼和多只雌鱼组成。优势雄鱼消失后，群体中最大的雌鱼会迅速改变行为，随后性腺重塑并取得雄性功能。这是雌性先熟及社会调节性转换的经典实例。小丑鱼则以繁殖雌鱼、繁殖雄鱼和若干未成熟个体组成等级；雌鱼消失后，原繁殖雄鱼转为雌鱼，等级最高的未成熟个体成熟为雄鱼，属于雄性先熟。[^munday-sex-change]

性转换不是一条从“低等”到“高等”的排列，也不能由外表或领域位置单独判断。现代研究从神经内分泌、芳香化酶表达、性腺细胞命运和基因调控网络追踪转换过程，解释了社会线索怎样连接到传统解剖学所见的性腺重塑。[^todd-sex-change] 这些证据补充了行为和组织观察；具体物种是否转换，仍须由连续个体记录、性腺结构和实际配子功能共同确认。

## 性选择的测量与两性角色 { #sexual-selection }

Darwin 将因获得配偶或受精机会差异而产生的选择称为**性选择**。它既可发生在交配前——争夺领域、排斥对手、展示和选择配偶，也可发生在交配后——精子竞争、精液利用和隐蔽雌性选择。性选择作用于繁殖成功差异；若某一醒目性状同时降低存活并提高交配成功，它可能在两种选择力量的平衡下维持。[^darwin-selection]

Bateman 的果蝇实验把三项量联系起来：交配成功的方差、繁殖成功的方差，以及交配次数增加时繁殖成功上升的斜率，后者常称 Bateman 梯度。[^bateman] 这些量可以比较性选择机会，却不能仅凭一次观察判定因果；亲子鉴定误差、未计数的交配、精子储存和后代存活都会改变结果。跨动物类群的比较总体支持一个统计趋势：产生较小且数量多配子的性别，交配成功方差和性选择常较强；同时也记录到大量角色反转和双向选择。[^janicke-selection]

配子异型只是起点。成年性比、操作性性比、配偶可防卫性、每次繁殖后离开交配群体的时间、照料收益和再配偶机会会形成反馈。过去已经投入较多的一方并不因“舍不得”而必然继续照料；过去成本已经发生，当前决策取决于继续照料能够增加多少后代存活，以及放弃后能够获得什么未来繁殖机会。[^kokko-jennions] 因而“雄性竞争、雌性选择”是许多物种中的常见组合，而不是由生物学性别直接指定的固定角色。海马和海龙由雄体怀卵，部分水雉和鹬类由雄体主要育幼，雌体之间的配偶竞争便可更强。

## 配偶竞争与替代繁殖策略 { #mate-competition }

同一性别个体可以用身体武器、体型、耐力、社会地位或联盟取得交配机会。鹿角、甲虫角和扩大的犬齿等形态会影响格斗，鸟鸣、蛙鸣和蜥蜴展示则可先传递资源持有力，减少升级争斗。灵长类动物的支配关系还可由亲属支持、长期友谊和联盟改变；金丝猴的一雄多雌单元也嵌套在更大的社会层级中。形态、动作与感觉通道的完整比较属于动物行为学，生态分析则继续追问这些投入怎样改变交配数、受精数及后代存活。

竞争并不只产生一个“最强雄性”表型。频率依赖收益可以维持多种**替代繁殖策略或战术**：卫星雄体停在鸣叫或展示雄体附近截取来访雌体；体型较小的潜行雄体避开正面对抗；某些甲虫雄体模拟雌体外形或行为进入防卫区；海洋等足类 *Paracerceis sculpta* 的三种雄体形态分别防卫海绵腔、模拟雌体或趁隙进入，形态由遗传差异维持。[^shuster-isopod] 蝎蛉雄体可依次采用大型食物礼物、唾液团或强迫交配，个体状态和竞争环境会改变战术收益。Gross 的框架把这些情形区分为遗传多型、条件依赖策略和发育转换，避免把所有“偷配”都当成同一种机制。[^gross-tactics]

竞争和选择也常同时发生。园丁鸟雄体清理并装饰凉亭，以物体颜色、空间布局、叫声和拟声构成复合展示；雌体巡视多个凉亭后交配，并独自筑巢育幼。凉亭不是巢，装饰质量也不是脱离环境的固定审美值：雄体偷取装饰、展示场位置、捕食风险、雌体年龄和感觉能力都会改变选择。食物礼物、巢穴、产卵底物和领域资源则可能同时是求偶信号与直接收益。

## 配偶选择的收益与演化模型 { #mate-choice }

配偶选择可以带来几类并不互斥的收益。食物礼物、巢位、防卫和育幼属于**直接收益**；配偶的遗传变异若提高后代在多种环境下的平均表现，可称“好基因”收益；若收益取决于双方基因组合，例如免疫基因互补，则是**遗传相容性**。Mays 和 Hill 强调，绝对质量与组合适配在预测上不同：前者预期不同选择者偏好相似对象，后者允许每个选择者的最适配偶不同。[^mays-hill]

Fisher 过程讨论偏好与被偏好性状之间的遗传相关：偏好某性状的雌体产生既携带偏好又携带性状的后代，二者可能相互强化，形成失控式演化，直至自然选择成本、遗传约束或偏好变化使过程停止。[^lande-runaway] “性感儿子”收益是这一路径的通俗表述，但需要遗传相关和后代交配成功证据，而不是见到华丽性状就能成立。

昂贵信号模型讨论低质量个体为何难以伪装成高质量个体。传统材料常把夸张尾羽概括为“让步赛理论”，较准确的历史名称是**障碍原理**或代价信号思想。理论模型表明，可靠性依赖不同质量个体承担信号成本或获得收益的方式不同；信号在平衡时可以昂贵，也可能因物理约束、社会惩罚或共同利益而可靠。成本既不是可靠性的充分条件，也不总是必要条件。[^grafen-handicap][^penn-szamado]

Hamilton—Zuk 假说把华丽性状与寄生物抗性、宿主—寄生物协同进化联系起来，是“好基因”路径中的一个具体、可检验假说，并非所有装饰的总解释。[^hamilton-zuk] 感觉偏向、熟悉、早期学习和性印随还可使偏好在性状出现前已有基础。正同类交配与负同类交配描述配偶表型或基因型的相关方向；负同类交配可能维持稀有型或提高相容性，却不必源于躲避捕食者，也不在所有物种中都选择稀有型。

## 两性冲突与多次交配 { #sexual-conflict }

雌雄共享产生后代的利益，却可能在交配时机、次数、亲代投入和后代质量上具有不同最适值。两性冲突可发生在同一性状的表达上，也可表现为一方的把持、强迫或操纵引起另一方抵抗。冲突的结果取决于重复相遇、体型与武器、逃避机会、伤害成本和后代收益，而不是某一性别永远“占便宜”。[^arnqvist-rowe]

多次交配对雌体同样可能有收益，包括受精保障、从多个雄体取得食物或资源、选择相容精子和增加后代遗传多样性；它也可能带来受伤、感染、被捕食和照料损失。雄体多次交配也受精液生产、求偶、守卫和照料机会成本约束。鸟类的社会单配与遗传单配经常不一致，分子亲子鉴定显示巢内后代可由配偶外雄体所生，但发生率在物种和种群间差异很大。[^griffith-extra-pair]

杀婴是冲突的一个特殊结果。在部分灵长类、食肉类、啮齿类和其他动物中，新进入群体的雄体杀死尚未断奶幼体，可能缩短母体恢复排卵的时间；雌体的多雄交配、群体防卫和雄体保护可改变其收益。幼体也可能因资源竞争、营养压力或亲本状态而死亡，因此只有行为者身份、亲子关系、交配机会和后续繁殖变化共同符合预测时，才支持性选择性杀婴解释。

## 精子竞争与交配后选择 { #postcopulatory-selection }

雌体在一个繁殖周期内接受多个雄体的精子时，不同精子在受精上的竞争称为**精子竞争**。Parker 将这一概念引入行为生态学后，研究从交配次数扩展到精巢大小、射精量、精子速度与寿命、交配栓、精子储存器官、护配和再次交配间隔。[^parker-sperm] 雄体可依据竞争风险调整精液分配，但更多精子并非总能线性增加受精率；资源限制、精子老化和雌性生殖道环境都会改变结果。

黄粪蝇的交配顺序和护配研究显示，最后交配雄体可取得较高受精份额，雄体因而在雌体产卵前守卫。豆娘雄体阴茎上的结构能够移除或重新定位雌体储精器官中的部分既有精子，是交配器形态与精子竞争相连的经典证据。[^waage-sperm] 这种机制不能未经观察推广到蜻蜓目所有成员，更不能套用于鲨鱼。海胆等广播产卵动物还可出现精子速度、寿命和碰撞风险之间的权衡。

哺乳动物中曾流行“敢死精子会联合杀伤竞争者”的说法，受控实验没有发现人类精子存在这种功能分工。[^moore-kamikaze] 精子间竞争之外，雌性生殖道的储存、运输、排卵时机和配子相容性可能使不同雄体的精子获得不同利用概率，称为**隐蔽雌性选择**。精子竞争与隐蔽选择在结果上可能同时存在，须借助遗传亲子鉴定、精子标记和生殖道实验区分。

## 婚配制度的三个层面 { #mating-systems }

**婚配制度**描述一个繁殖季或更长时期内配偶关系的组织方式。传统的单配、多配和乱交术语仍然有用，但必须说明观察层面：**社会婚配制度**记录配对、同居、领域和照料；**行为婚配制度**记录实际交配；**遗传婚配制度**依据亲子关系记录受精贡献。一个物种可以社会单配而存在配偶外交配，也可以群体共同生活却由少数个体繁殖。

| 制度 | 传统定义 | 常见生态条件与可检验结果 |
| --- | --- | --- |
| 单配制 | 一雄一雌形成持续时间不等的配偶关系 | 配偶难以同时防卫、照料显著提高后代存活或配偶守卫重要；须区分季节性、连续性、社会性与遗传单配 |
| 一雄多雌制 | 一雄在同一时期与多雌繁殖 | 雌体或关键资源可被一个雄体防卫，或雄体在求偶场高度聚集展示；预期雄性繁殖成功方差常较大 |
| 一雌多雄制 | 一雌在同一时期与多雄繁殖 | 雄体照料限制产出、雌体能快速形成多窝，或雌体可防卫多名育幼雄体；性角色可能反转 |
| 多雄多雌制 | 多只雌雄在同一繁殖群中交配 | 配偶难以排他防卫、群体社交稳定或合作与竞争并存；受精格局需亲子鉴定 |

Emlen 和 Oring 用资源在时空中的分布、雌体可防卫性和环境所允许的一夫多妻潜力连接生态与婚配制度。[^emlen-oring] 资源均匀、雌体繁殖同步或后代需要双亲照料时，单配常更有利；资源成斑块、雌体聚集或成熟时间错开时，一雄多雌机会可能增加。然而捕食、移动能力、巢位限制、亲缘结构和个体差异都可改变结果。“单配低等、一雄多雌高等”或相反的进化阶梯均没有依据。

## 单配、多配与求偶场 { #mating-system-ecology }

单配关系可由几条路径维持。雄体守卫单个可育雌体，可能减少其与其他雄体交配；雄体供食、防卫或孵卵若显著提高后代存活，留在配偶旁也可超过寻找新配偶的收益；雌体主动排斥额外雌体或不接受已配对雄体，则形成雌体执行。鸟类繁殖期短且育幼任务多，社会单配常见；哺乳类的社会单配与雌体空间分散、雄性防卫能力和杀婴风险有关，并不只出现于食肉目。[^lukas-monogamy]

一雄多雌制可按雄体控制的对象继续细分。**雌体防卫型**中，雄体直接守卫雌群；**资源防卫型**中，雄体控制食物、巢位或产卵地，雌体因资源进入；**争夺竞争型**中，雄体在短暂繁殖期广泛搜寻可育雌体。多雌阈值模型预测，若优质领域上的“第二雌体”仍比劣质领域上独占雄体的雌体获得更高繁殖收益，她可能接受共享配偶。这个阈值取决于领域质量、雄体照料损失和雌体竞争，不能据此断言第二雌体必然不受损；雄体还可能隐瞒已有配偶或使雌体无法完整取样。

**求偶场制**（lek）中，雄体聚集展示，通常不向雌体提供育幼资源，雌体进入场地比较并交配。聚集可形成于雌体活动路线的热点、具有吸引力的雄体周围、场地中央较安全的位置或雌体便于同时比较的地点；这些“热点”“热手”“中心位置”和雌性偏好解释可共同作用。园丁鸟的凉亭、草原松鸡和某些鱼类或昆虫的展示场形态各异，是否属于严格 lek 要看雄体是否仅提供配子、雌体能否自由选择以及资源是否并非主要吸引物。

一雌多雄制常与雄体承担孵化、护卵或育幼相联。雌水雉可防卫包含多名雄体领域的空间，每名雄体孵育一窝；部分鹬类出现雌体产下第一窝交由一雄照料，再与另一雄形成第二窝的“双窝”系统。若繁殖季生产力高而时间短、雌体形成卵的速度超过单个雄体照料完成的速度，雄性照料会成为限制资源，雌性竞争增强。另一方面，篱雀等物种可在单配、一雄多雌、一雌多雄和多雄多雌之间变化，说明婚配制度可以是同一物种面对密度、领域重叠和亲子把握变化的可塑结果。

## 亲代照料、亲代投资与去留 { #parental-investment }

**亲代照料**是筑巢、护卵、孵化、供食、携带、哺乳和防卫等可观察行为；**亲代投资**是这些行为中提高某个后代存活或繁殖机会、同时降低亲本投资其他后代能力的部分。Trivers 的定义强调机会成本，同一次动作因环境不同可能带来不同投资。[^trivers-parental] 无脊椎动物的卵袋与护卵、鱼类口孵与巢护、两栖类背负、鸟类孵卵育雏和哺乳类妊娠哺乳等完整形态路径，见[繁殖与亲代行为](../../zoology/behavior/reproduction_parental.md)。

亲本在每一阶段都面临继续照料、减少投入或离开的选择。继续照料的收益取决于后代对食物、保温或防卫的需要，以及另一亲本能否补偿；离开的收益取决于再配偶机会、未来存活和另一次繁殖的价值。亲子关系把握会影响照料收益，却不是机械开关：雄体即使无法完全确定亲子，也可能因照料显著提高整窝存活、离开后缺少配偶或撤退无法挽回既有风险而继续投入。雌体同样会在产卵、哺乳、再次繁殖和自身存活之间调整。

双亲照料并不保证任务平均。一个亲本减少供食时，另一个可以完全补偿、部分补偿或也减少投入；反应取决于额外照料的边际收益和对配偶状态的信息。比较雌雄总投入时，还要把产卵、妊娠、巢防、供食和失去再次交配机会换成共同的适合度货币，而不能只数到巢次数。

## 亲子冲突与同胞竞争 { #family-conflict }

亲本与后代共享遗传利益，但对单个后代的最适投入量并不完全一致。对有性生殖二倍体，亲本通常与每个亲生后代有一半基因同祖，而一个后代与自身完全同祖；后代因而可能在亲本应何时停止供食、断奶或把资源转给兄弟姐妹的问题上要求更多。Trivers 的亲子冲突理论把这种差异放进亲缘和未来后代收益中，而不是把幼体行为解释成有意识的自私。[^trivers-offspring]

乞食叫声、张口、争位和生长抑制可以传递饥饿与竞争状态，也可能在亲本反应规则下被夸大。一个信号既可含有真实需要信息，又受到争夺资源的选择；仅凭叫得响不能断定欺骗，只有操纵饥饿、同胞数和信号成本，并测量亲本供食与后代存活，才能区分模型。Godfray 的信号模型说明，在一定成本和共同利益下，亲本—后代冲突并不排除稳定的信息交流。[^godfray-conflict]

同胞之间还会争夺食物、位置、温度和亲本注意。体型差由产卵顺序或孵化异步产生时，较大幼体可能在资源不足年份占优；某些鸟类出现强制性或条件性同胞残杀，另一些巢中竞争主要通过乞食和位置完成。评价这些行为要同时看亲本是否以异步孵化应对食物不确定性、弱幼体在丰年是否仍能存活，以及失去一个幼体怎样改变整窝产出。

## 从观察到机制证据 { #evidence-chain }

繁殖行为最容易因醒目的形态或个别故事而被过度解释。完整证据链应依次记录性状与动作、配偶相遇和交配次数、遗传亲子关系、后代存活以及个体终生繁殖成功。对性比模型，还要量化性别特异成本、局部交配和散布；对配偶选择，要操纵候选信号并排除资源质量；对精子竞争，要把交配顺序与实际受精份额相连；对亲代投资，则须计入未来繁殖机会而不只观察当前照料时间。

传统形态解剖学提供这些问题最重要的可观察起点：性腺与交配器结构、第二性征、巢与育幼器官、求偶动作和照料序列，决定了动物实际上能够做什么。分子亲子鉴定、激素测量和基因表达把这些现象连接到受精份额、状态转换和调控机制。两类证据相互校准，才能从“看见行为”走到“解释选择”，而无需删除任何一条经核验的自然史学习路径。
