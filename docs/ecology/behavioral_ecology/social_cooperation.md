# 社会生活、合作与利他

动物靠近同类以后，收益和代价便同时改变。群中的一只羚羊可能更早从邻居动作中发现捕食者，也必须同邻居争食；一只幼鸟留在出生领域，可以帮助亲鸟育雏并等待继承位置，也会延迟自己的繁殖；工蜂照料姐妹看似放弃了直接繁殖，却可能通过亲属和蜂群延续同源基因。社会行为的核心问题因此不是“动物是否善于合作”，而是某一行为怎样改变行动者与互动对象的存活和繁殖，这些后果又怎样随亲缘、群体组成、生态条件和时间尺度变化。

本页从适合度后果解释群居、合作繁殖、亲缘选择、互惠和真社会性。鱼群怎样同步、蜂群有哪些职虫、鸟兽如何结盟、灵长类怎样理毛，以及裸鼹鼠的隧道和繁殖等级，已在[社会组织与群体生活](../../zoology/behavior/social_organization.md)中沿形态、动作和类群完整展开；亲缘选择和现代遗传证据在这里用于解释这些传统观察，不替代它们。

## 从聚集到稳定社会 { #aggregation-and-society }

许多个体出现在同一地点，首先可能只是对同一资源或环境的共同反应。腐果周围的昆虫、退潮后水洼中的鱼和夜间被灯光吸引的飞虫形成**聚集**，成员不一定彼此识别，也未必协调行动。若个体主动保持邻近、根据同伴调整方向或反复互动，才进入广义的**群体生活**；成员身份、亲缘、等级和关系长期保持时，则形成更稳定的社会单元。

传统生态学按持续时间区分暂时性或开放性集群、季节性群和稳定群。这一分类仍然有用。十三年蝉、十七年蝉的大规模同步羽化只持续很短时间，个体密度足以使捕食者饱食，却不要求成员形成稳定关系；繁殖季蛙类鸣叫群和海鸟繁殖群落具有季节边界；象的母系家庭、狼的家族群和社会性昆虫巢群则可以跨越多年与世代。稳定性也不是物种的永久属性：鸟可白天分散取食、夜间集群栖息，灵长类和斑鬣狗的大群还可不断裂变成小队再融合。

群体组成比平均成员数更能说明社会功能。十只同龄雄体的繁殖联盟、十只雌体与幼体组成的母系群、十只互不相识的迁徙个体，在警戒、亲缘和资源竞争上完全不同。研究需要同时记录性别、年龄、繁殖状态、亲缘、迁入迁出和成员间的接触网络；只用“独居—群居—真社会”排列类群，会把多条独立演化路径误写成一条社会进步阶梯。

## 群居的收益通道 { #group-benefits }

群居收益可以沿环境缓冲、捕食防御、取食、繁殖和信息传递分别测量，而不应只用“群体更安全”概括。

在寒冷或干燥环境中，企鹅、啮齿类和蜂群的紧密聚集能够降低个体暴露表面积，巢体还可调节温湿度；内部成员和边缘成员获得的收益并不相同，过密也可能导致过热、缺氧或病原累积。资源搜索中，个体可以从同伴的移动、叫声、气味或成功进食位置取得信息，捕食者则可合作包围大型猎物、轮换攻击或共同保卫食物。合作狩猎提高一次成功概率时，每只成员的净收益仍取决于追逐成本、猎物大小和分食方式；狮群或狼群并非成员越多，每只都吃得越多。

面对捕食者，至少有四条不同路径。**稀释效应**使一次攻击落到某个个体的概率随群体增大而下降；**多眼效应**使更多感官同时搜索危险，从而允许单个成员减少警戒；同步运动可产生**混淆效应**，使捕食者难以锁定目标；成员共同围攻、踢咬或发出警报则构成集体防御。捕食者发现整个群体的概率可能随群体大小增加，单个成员的条件风险却同时下降，二者必须分开。Hamilton 的自私群模型进一步表明，个体只要向邻居靠近、缩小自己的危险域，就能形成密集团体；群体外形由许多个体避险规则涌现，不要求每个成员都为集体牺牲。[^hamilton-herd]

传统材料把鸵鸟夺取或接纳其他亲鸟的幼鸟列在稀释效应之下。扩大幼鸟群确实可能让自己的幼鸟在数量上被“稀释”，但成体还可能取得照料、支配或群体防御收益，被夺幼鸟承担的风险则未必相同。周期蝉的质数年周期和同步羽化属于捕食者饱食与生活史同步，不是成员互相协作的证据。混种群体也要区分类别：狒狒与高角羚可相互利用不同感官的警戒线索；牛背鹭随牛活动主要利用牛惊起的昆虫，属于种间取食关系，不等同于一个稳定的混种社会。

群体还提供配偶、共同照料和社会学习机会。幼体可观察成体选择食物、识别天敌和处理同伴关系，多个照料者能增加守护与供食；社会传播也可能放大错误警报和低效路线。文化传承需要行为通过学习在成员间持续传播，不能由同群个体行为相似直接推出，因为它们也可能共享同一环境或遗传背景。

## 群居代价与风险分配 { #group-costs }

同伴能够提供信息，也会消耗同一资源。食物越集中、可防卫或短缺，群内干扰、偷食和等级差异常越突出；共同巢穴和庇护处还会增加空间竞争。优势成员可能处在群体中央、先取食或垄断繁殖，边缘成员承担更高捕食风险，低等级者则可能以少量资源换取留群安全。群体平均收益因而不能代表每个身份。

近距离接触、共同粪场、理毛、食物反刍和巢材交换会增加病原与寄生虫传播。社会性昆虫的理毛、清尸、隔离和抗菌巢材可形成社会免疫，鸟兽也会回避患病个体或改变接触网络；这些防御本身消耗时间和资源。病原传播由接触网络、免疫差异和群体分区共同决定，成员数增加并不自动对应同一幅度的患病风险。

繁殖群体还会出现错配、偷卵、巢寄生、偷乳、毁卵和杀幼。它们分别涉及配偶识别、巢位记忆、亲子识别和繁殖偏斜，不宜合称为一个“错配”机制。警报也可能被用于赶走竞争者，乞食和招募信号可能被夸大；合作与欺骗因此发生在同一关系网中，而不是两个互不相容的社会类型。

## 群体大小与个体进入规则 { #group-size }

某一生态条件下可以存在使平均净收益最大的群体大小，但实际群体并不必停在那里。若一个处于平均收益最大值的群体仍比独居生活更有利，新个体就会继续加入；它加入后降低所有成员的平均收益，却仍提高自己的收益。Sibly 因此指出，**群体最优大小可能在个体进入规则下不稳定**，稳定群体甚至会大于平均收益最高的大小。[^sibly-group-size] 领域所有者是否能排斥加入者、群体能否分裂，以及成员能否辨认彼此，会改变这个结果。

群体大小也在日内和季节间变化。狒狒可在夜间睡眠地汇成较大群体，白天随食物斑块分成较小觅食队；繁殖季、迁徙期和旱季又会改变成员需求。旧材料把资源质量、空间分布和可预测性分别对应固定大小，方向过于简单。集中而大型的食物可支持较大群体共同寻找或防卫，也可能引发强烈争夺；分散的小食物可使成员分开取食，也可能靠共享信息提高发现率。正确预测需要写出每增加一名成员时，发现、取得、分食和竞争各改变多少。

低密度种群还可能因难以找到配偶、不能共同防御或无法维持社会分工而出现人均增长率下降，这属于 Allee 效应，已在[种群增长、调节与空间动态](../population_dynamics.md#allee-effect)中讨论。这里的“群体大小”是局部互动单元，“种群密度”是指定区域内的数量状态，二者只有在空间结构明确时才能互换。

## 社会行为的适合度分类 { #social-fitness-effects }

行为生态学按行动者和受作用者的**直接适合度后果**给社会行为命名。符号表示在同一生活史尺度上相对于不采取该行为的增减，不涉及动物的主观善恶：

| 行动者后果 | 受作用者后果 | 功能分类 | 典型解释入口 |
| --- | --- | --- | --- |
| 增加 | 增加 | 相互受益或互利合作 | 联合捕猎、共同防御、群体增益、即时交换 |
| 降低 | 增加 | 利他 | 亲缘选择、延迟回报、伙伴选择或多层次选择 |
| 增加 | 降低 | 自利或剥削 | 强迫劳动、巢寄生、资源盗取、信号操纵 |
| 降低 | 降低 | 恶意行为（spite） | 对负亲缘或竞争结构有严格要求，不能由互相伤害直接认定 |

**合作**是使受作用者获益、并因这种社会效应受到选择的广义词，可包含相互受益和利他；**利他**则专指行动者直接适合度下降而受助者上升。[^west-semantics] 一次高风险动作不一定是利他：亲鸟折翼展示把捕食者引离巢穴，若保存自己的后代，收益属于行动者的直接繁殖；狐獴哨兵若站在安全处且最先发现天敌，也可能在帮助同伴的同时降低自身风险。分类必须测量反事实后果，而不能由动作看起来勇敢或无私决定。

旧材料中的“行为操纵式利他”尤其需要重分。杜鹃雏鸟接受寄主喂食，是寄生者利用寄主的亲代反应，受操纵寄主通常付出繁殖代价，因而属于剥削；优势个体强迫从属者守巢，也不因从属者表面上帮助群体而自动成为利他。保留“操纵”这一传统观察类别，有助于追问行为由谁控制，但功能分类要回到双方实际收益。

## 直接适合度、间接适合度与 Hamilton 条件 { #inclusive-fitness }

个体通过自己的后代对后世基因库作出的贡献构成**直接适合度**成分；行为改变亲属繁殖后，因共享遗传变异而折算回行动者的成分称为**间接适合度**。二者在适当人口统计和基准下组成广义适合度。它不是“一个个体把基因传给后代的能力”的泛称，而是一种把社会效应归因到行为者的选择核算。

弱选择和加性效应下，Hamilton 条件常写为

$$
rB>C,
$$

其中 $C$ 是行为给行动者造成的繁殖代价，$B$ 是给受助者带来的繁殖收益，$r$ 是社会伙伴在相关遗传变异上的关联程度。[^hamilton-social] 三者必须使用相同的后代、时间和繁殖价值尺度。$r$ 也不是简单的“共同基因百分比”；在基准种群中，它刻画行为者与受助者携带相关等位基因的统计关联。

在普通二倍体、远交和无近交的简化谱系中，亲子和全同胞的系谱亲缘常都为 $1/2$，但“自己生一个”和“帮助父母多养活一个”并不因此等价。独立繁殖和帮助的成功概率、配偶贡献、额外幼体是否挤占同胞、未来繁殖机会与性别繁殖价值都可能不同。父权不确定会改变某些亲属间的预期亲缘，却不能推出雄性普遍更应帮助姐妹或某一性别总是更利他；需要用实际亲子资料和群体人口统计计算。

Hamilton 条件说明亲缘可以使昂贵帮助受到选择，也提醒研究者测量局部竞争。亲属留在同一斑块时，帮助产生的额外后代往往继续与行动者或其他亲属争夺有限位置；这种**亲缘竞争**可抵消部分间接收益。仅靠低散布提高邻居亲缘，不保证利他演化，竞争发生在哪一尺度、额外后代能否向外扩散同样关键。[^taylor-viscosity]

## 亲属识别、报警与亲缘偏向 { #kin-discrimination }

帮助亲属不要求动物理解谱系。最简单的规则是按地点或共同巢穴行动，例如“巢内幼体都喂”；它在巢寄生、幼体被移位或巢群合并时会出错。**熟悉性**来自共同成长和反复接触，**表型匹配**则把气味、声音或外形与已学习的亲属模板或自身表型比较。许多鸟兽、蝌蚪和社会性昆虫把这些线索组合使用，线索改变时会发生接纳错误与误拒。

“绿胡须效应”不是所有亲属识别的遗传总称。它要求同一基因或紧密连锁系统同时产生可识别表型、识别该表型的能力，以及对携带者的差异行为。红火蚁 *Solenopsis invicta* 的社会染色体区域影响工蚁对不同基因型蜂后的处置，是少数接近这一结构的实例。[^green-beard-ant] 熟悉性和表型匹配可以具有遗传基础，却不等于无需学习的绿胡须效应。

报警行为展示了亲缘与直接收益怎样并存。Belding 地松鼠雌体常留在出生地，附近亲属较多；Sherman 的长期研究发现雌体对陆生捕食者的报警与亲属分布相符，为亲缘偏向提供了经典证据。[^sherman-alarm] 报警者还可能已经靠近洞穴、借叫声使捕食者知道自己已被发现，或从群体协调逃跑中直接获益。黄鼠、旱獭和其他群居啮齿类的叫声都应分别检验调用者风险、接收者身份和亲缘，而不能把一切警报预先归为自我牺牲。

野生火鸡的雄性求偶联盟提供另一条传统实例。两只亲缘雄体共同展示时，优势雄体取得交配，从属雄体很少交配；遗传亲子和亲缘资料表明，从属者通过帮助兄弟获得的间接收益可超过独自展示的预期收益。[^krakauer-turkey] 这个结论依赖联盟成员的真实亲缘、独立繁殖基准和优势者增加的后代数，并不意味着所有雄性联盟都靠亲缘维持。

## 相互受益、群体增益与伙伴差异 { #mutual-benefits }

许多合作每次发生时就让各参与者获益，不需要先假定延迟偿还。雌狮共同包围猎物、雄狮联盟保卫雌群、鱼群同步逃逸和鸟群共同围攻捕食者，都可能是**相互受益**。狮群内部仍有分食和繁殖不均：较小雄狮联盟可以由非亲个体组成，较大联盟更常包含兄弟；低等级成员是否获益取决于联盟取得领域的概率、实际交配份额和亲缘折算。[^lion-coalitions]

**群体增益**指新增成员使所有成员的存活、领域保持或未来帮手数量上升。帮手喂大的幼体将来可能参与守域，更多成员也能降低单个成员的防卫负担。它是行动者的延迟直接收益，与帮助当前亲属的间接收益可以同时存在。食物分享、共同哺乳和守域同样可能兼有即时收益、关系维持和亲缘偏向，不能只用一项机制排除其余机制。

伙伴的能力和可靠性还会造成稳定差异。经验丰富的猎手、熟悉路线的年长雌体和积极警戒的成员给群体带来的边际收益较高；病弱幼体、竞争强的繁殖者或长期不参与防卫者可能带来净成本。个体选择加入谁、容忍谁和驱逐谁，会把群体成员资格变成一种可争夺资源。

## 直接互惠、换卵与长期社会纽带 { #reciprocity }

**直接互惠**指个体付出当前成本帮助特定伙伴，并因对方在以后角色反转时提供帮助而得到回报。它需要重复相遇、个体识别、未来相遇概率和对不回报者的反应；若双方在同一次行动中立即获益，称相互受益更清楚。Trivers 的互惠利他模型把清洁共生、警报和人类交换作为候选路径，同时明确欺骗者能否被拒绝是稳定性的核心。[^trivers-reciprocity]

黑色哈姆雷特鱼 *Hypoplectrus nigricans* 是同时雌雄同体的鮨科鱼，配对个体轮流释放小批卵，由对方以雄性功能授精；不再释放卵的一方会降低伙伴继续提供卵的机会。这种**换卵**把雌性功能的高投入拆成多轮交换，使角色反转和拒绝不回报者可以直接观察。[^fischer-egg-trading] 它比“石斑鱼互相受精”更精确，也说明互惠不要求长期道德式记账。

普通吸血蝠在觅食失败后可从同伴获得反刍血液，分享同时受亲缘、熟悉和既往帮助影响。控制亲缘与熟悉的实验支持过去帮助对捐赠有预测力，但严格互惠仍需排除骚扰、共同关系质量和单向伙伴偏好。现代研究因而把食物分享与理毛看成长时间建立的社会纽带：伙伴选择、过去回报和当前需要共同决定投入，而不是每餐立即等量偿还。[^carter-vampire]

灵长类理毛也可换取容忍、支持或以后理毛，但交换物不同、时间窗口长，简单的“一次换一次”很少适用。重复互动中的合作还可由伙伴选择、离开、惩罚或声誉维持；观察到时间上的相关回报只是起点，实验需要改变一次帮助机会，再看同一伙伴后续行为是否有方向性变化。

## 操纵、强迫与合作执行 { #coercion-and-enforcement }

合作关系中的权力并不对称。优势成员可以以驱逐、攻击或失去庇护相威胁，使从属者提供守域、清洁和育幼；从属者也可能通过减少帮助、偷繁殖或离开回应。这样的帮助在表面上给群体带来收益，维持机制却可能是行动者避免惩罚所取得的直接收益。

坦噶尼喀湖的丽鱼 *Neolamprologus pulcher* 群体包含繁殖对和多名帮手。实验阻止某帮手参与领域防御后，帮手随后增加安抚和帮助，符合“**付费居留**”路径：守域和育幼可换取在安全领域内被容忍。[^bergmueller-pay] 亲缘帮手仍可能取得间接收益，非亲帮手则可等待繁殖位置、享用庇护或积累状态；亲缘升高甚至可能降低为换取容忍而必须付出的照料。帮助、亲缘和强迫由此可以在同一物种中相互替代或叠加。

社会性昆虫的工虫监督、食卵和蜂后信号也体现执行与冲突。蜂后信息素可以如实表示繁殖状态，工虫据此抑制自身卵巢；在另一些情境，工虫清除其他工虫产下的卵，使群体繁殖集中。把一切工虫不繁殖写成蜂后“控制”或工虫“自愿牺牲”都过于单一，需分别检验信息、强迫、亲缘和工虫自身收益。

## 合作繁殖与延迟扩散 { #cooperative-breeding }

**合作繁殖**指超过一对亲本的个体共同抚育一批后代。最常见的巢中帮手是已成年的早期后代，它们推迟扩散，帮助双亲喂养弟妹；**共同繁殖**则可由多只雌雄共同产卵或产生后代。两者都可能有亲缘合作和生殖竞争，不能由“共同育幼”推定后代只有一父一母。

Emlen 的家庭演化框架把两步分开：幼体为什么不立即离开，以及留下后为什么帮助。适宜领域短缺、寻找配偶困难、扩散死亡率高和独立筑巢成本大，构成具体的生态约束；出生领域的安全、食物、群体防御、经验和继承机会构成留居收益。[^emlen-family] “坏年份做帮手、好年份独立繁殖”可作为条件预测，却不是通则；年景好时出生领域也可能更有价值，个体的年龄、性别、等级和队列位置都会改变去留。

留下也不必立即帮助。帮手的投入可能通过亲缘选择、群体增益、育幼练习、继承领域、取得配偶或付费居留维持。脊椎动物比较显示，亲缘路径重要，但非亲合作繁殖多次出现，直接收益在若干物种中足以维持群体。[^clutton-brock-cooperation][^riehl-nonkin] 因此，延迟扩散、共同生活和实际帮助是三个需分别测量的行为。

## 帮手效应、斑翠鸟与共同巢 { #helpers-and-communal-breeding }

帮手可守巢、报警、驱赶捕食者、清洁卵、修补巢穴、供食和与幼体互动。其结果可能是幼体长得更快、更多幼体出巢，也可能是亲本减少自己的供食而提高未来存活；无经验帮手还可能干扰亲本、吸引捕食者或消耗食物。要证明帮助有效，需要在相似领域中移除或增加帮手，分别测量幼体、亲本和帮手的长期后果，而不是把大群体本来较高的繁殖成功全归给帮手。狐獴实验显示帮手数量能够影响幼体生长和存活，是把群体规模连接到具体照料通道的实例。[^meerkat-helpers]

斑翠鸟 *Ceryle rudis* 的雄性帮手传统上分为亲缘的初级帮手和非亲缘的次级帮手。亲缘帮手可通过弟妹取得间接收益，非亲帮手则可能获得进入繁殖群、等待替补或未来配偶的机会；激素研究也不支持把初级帮手简单视为生理上被阉割的个体。[^reyer-kingfisher] 这个系统保留了旧材料的两类帮手，又说明同一种帮助动作可以由不同收益路径维持。

犀鹃（ani，*Crotophaga* 属）由多只雌雄共同筑巢、产卵和育幼。雌鸟在自己开始产卵前可能把巢中已有卵推出，开始产卵后移卵行为减少，因而较晚开始产卵者的卵可能占较大份额；孵化一旦开始，后来产下的卵发育机会下降。共同巢减少单独筑巢和防御成本，却产生明确的产卵顺序冲突。所谓“优势雌体后生殖”只有在优势、产卵时序和存活卵份额都被个体标记证实时才成立。

亲鸟死亡或被新繁殖者取代后，帮手与下一窝后代的亲缘可能从全同胞降为半同胞或无亲缘，帮助量、离群和繁殖竞争随之改变。繁殖者也可能驱逐已无亲缘的帮手，帮手则可能偷取繁殖或破坏卵。合作繁殖因此不是没有冲突的大家庭，而是亲缘、直接收益和权力关系随成员更替不断更新的制度。

## 真社会性、繁殖分工与家族起源 { #eusociality }

真社会性通常由三项可观察判据共同界定：合作照料幼体；繁殖个体与少繁殖或不繁殖成员之间有稳定分工；亲代与成年子代世代重叠。蚂蚁、白蚁和部分蜂、胡蜂、蚜虫、蓟马、甲虫与枪虾达到这些条件，裸鼹鼠等少数脊椎动物也常被纳入；具体的蜂王、工虫、兵蚁、巢体和发育可塑性见[社会组织与群体生活](../../zoology/behavior/social_organization.md#social-insect-criteria)。

膜翅目单倍—二倍体遗传曾给出一个著名线索：在单蜂后、单次交配等简化条件下，全姐妹之间的亲缘可高于母女亲缘，使帮助蜂后生产姐妹具有较高间接收益。但蜂后多次交配、多个蜂后、工虫产雄和性比冲突都会改变计算；大量单倍—二倍体物种仍然独栖。白蚁雌雄均为二倍体，工蚁和兵蚁也来自两性，说明单倍—二倍体既非真社会性所必需，也不能单独产生真社会性。[^thorne-termites]

比较研究发现，多个独立起源的真社会性膜翅目支系祖先具有终生单配结构，使最初留巢子代之间保持较高亲缘；这为亲缘选择提供了起点。[^hughes-monogamy] 随后仍需生态收益使家庭巢可持续：巢穴或食物可共同防卫，幼体需要渐进供食，亲代寿命允许世代重叠，成员留下的收益高于独立建巢。亲缘说明帮助收益如何折算，巢生态和发育机制说明可行路径，二者不能互相替代。

蜂群和蚁群内部仍有蜂后—工虫、工虫—工虫及不同母系间的繁殖冲突。工虫不育程度、雄性来源、蜂后更替和卵清除都可随亲缘结构改变。真社会性因而代表高度整合的繁殖分工，不是群体利益抹平个体冲突后的终点。

## 亲缘选择与多层次选择的两种表述 { #selection-levels }

“有利于整个群体”只能描述一个结果，不能独自构成选择解释。若合作个体在每个群内都比不合作个体繁殖少，合作仍可能因合作比例高的群体存活、分裂或输出后代更多而增加；完整分析必须同时量化群内差异和群间差异。亲缘选择把同一统计结构写成社会伙伴基因型的关联及其收益，多层次选择则把变化分解到群内和群间。在一系列标准模型中，两种核算可以给出等价的总变化，只是回答问题的坐标不同。[^lehmann-levels]

选择层次的表述不改变实证要求：需要知道谁与谁互动，行为对双方繁殖造成什么后果，群体怎样形成与解散，后代在什么尺度竞争，以及社会性状如何传递。看到一群动物共同受益，尚不能证明群体层次选择；看到亲属相助，也不能省略直接收益和局部竞争。

## 跨类群比较与证据链 { #comparative-evidence }

两栖类繁殖合唱、爬行动物亲族聚集、鱼类协同防卫、鸟类巢中帮手、狼的家族群、狮的雌群与雄性联盟、灵长类裂变—融合社会、昆虫巢群和裸鼹鼠繁殖等级，分别提供了从短时聚集到稳定社会的比较材料。旧材料中“爬行动物亲代行为普遍不发达”“狼群由一只雄性头狼统治”“黑熊形成固定雌雄社会”或“多数灵长类都是单雄群”等表述，都应回到具体物种、季节和成员关系。现代追踪、亲子鉴定和社会网络分析补足身份与繁殖结果，传统形态、动作和生活史观察仍决定研究者实际测量什么。

检验一个合作解释，至少需要四层证据：行为记录确定谁向谁提供何种服务；实验或自然变动估计帮助的 $B$ 与 $C$；亲子鉴定和谱系给出亲缘及受精份额；长期个体资料衡量留群、扩散、继承和未来繁殖。互惠还需操纵伙伴过去是否帮助，付费居留需操纵帮助机会并观察惩罚，真社会性起源则需系统发育比较祖先婚配和巢生态。把这些证据连接起来，才能判断同一动作究竟由直接收益、间接收益、互惠、强迫或多条路径共同维持。
