# 栖息地、领域与捕食关系

动物所处的空间并不是舞台背景。资源在何处出现、捕食者从何处接近、邻居是否允许进入、个体已经掌握哪些地点，都会改变一次停留、逃逸或迁出的收益。空间决策因而贯穿捕食过程、生境选择、活动区建立、领域防卫和散布；同一个地点也可能在觅食上有利，却在繁殖或避敌上代价高昂。

本页从生态后果出发讨论这些决策。反捕食动作及形态结构的完整比较见[取食、防御与反捕食行为](../../zoology/behavior/foraging_defense.md)，视觉、声、化学和电信号的产生与接收见[动物通讯](../../zoology/behavior/communication.md)；捕食造成的种群波动、营养级联、拟态和协同进化则在[捕食、寄生与互利](../consumer_resource_interactions.md)展开。这里关心的是：风险和资源怎样被动物转换为空间使用规则，这些规则又怎样改变个体之间及物种之间的相遇。

## 空间概念与观察尺度 { #spatial-concepts }

**栖息地**是个体完成生活史过程所利用的一类环境，**微生境**则把尺度收窄到洞穴内外、植株层位、水深、底质或林隙等局部条件。研究者还常区分生境的使用、选择、偏好与质量：使用是动物实际出现在哪里；选择是某类环境的使用比例相对于其可获得比例发生偏离；偏好是在可比选择机会下表现出的倾向；质量则由存活、繁殖或长期种群增长等结局衡量。动物频繁出现的地点未必质量最高，高密度可能来自资源集中，也可能来自竞争者排斥、迁入堆积或缺少替代地点。[^van-horne-density]

传统动物行为学常把个体经常活动的范围称为**巢域**，现代文献更常称**活动区**（home range）。它包括个体在取食、休息、交配、育幼和熟悉环境时通常使用的空间，却不要求整个范围都被排他防卫。活动强度最高的部分叫**核域**；活动区中被个体以攻击、驱赶或信号等方式防卫的部分才是**领域**（territory）。因此，活动区可以重叠，核域也可能随季节改变，而领域的边界取决于防卫行为及其对象。把定位点画出的多边形或概率等高线直接当作动物心中的固定边界，会混淆统计估计与生物学过程。[^powell-home-range]

这些概念还具有层级。鸟可以在地理分布区内选择繁殖区域，在区域内选择林分，再在林分中选择巢树和巢位；鱼可以先进入河段，再选择水深、流速和遮蔽物。Johnson 将这种过程区分为从分布区、活动区到活动点的多级选择，提醒研究者：结论取决于“可获得环境”的界定尺度。[^johnson-selection] 一个地点在日间是隐蔽处，在夜间可能成为觅食地；同一片草地对成体和幼体也可能属于不同质量的生境。

## 捕食过程中的空间风险 { #predation-risk }

捕食并非一次瞬时事件，而是一条可以在多个环节中断的过程。传统材料把它细分为六个阶段，这种分法仍然适合形态与行为观察：

| 阶段 | 捕食者面临的任务 | 猎物可改变的相遇或结局 |
| --- | --- | --- |
| 遭遇或发现 | 进入猎物所在时间与空间并开始搜索 | 错开活动时间，利用隐蔽微生境，静止或低密度分布；季节性、斑块性和多态性还可造成“表观稀少” |
| 检出 | 从背景噪声中取得感官信号 | 背景匹配、破坏性体色、降低气味或振动信号；群体同步运动可形成混淆效应 |
| 确认 | 判断对象是否值得攻击 | 伪装成环境物体，或以警戒色、拟态和展示影响捕食者的分类与学习 |
| 接近与追逐 | 缩短距离并保持追踪 | 提前警戒、逃跑、急转、惊吓展示、臀斑或尾斑转移攻击，结群与报警提高发现捕食者的概率 |
| 制服 | 固定并杀死猎物 | 壳、刺、黏液、自割、毒液、集体防卫及难以控制的体型增加处理成本 |
| 摄食与消化 | 吞食、消化并获得净收益 | 难吃、催吐或有毒物质降低收益；另一些寄生物和种子反而利用被食完成传播 |

六阶段表把“未被吃掉”拆成了不同机制。稀少的猎物可能较少被遇见；常见猎物也可能因为夜间活动、静止或只在短季节出现而显得稀少。捕食者对常见形态形成**搜索印象**后，可能提高对该形态的检出率，产生频率依赖的避稀现象；然而提高巡视速度或延长有利斑块内的搜索时间本身并不能证明捕食者偏向常见型。传统材料还把猎物比捕食者更早发现对方称为“单利现象”，它描述的是预警距离不对称，收益仍取决于猎物能否利用这段时间逃逸或发出追捕威慑信号。检验这些解释，需要分别测量遭遇率、检出率、攻击选择和处理成功率，而不能只看最终胃内容物。

隐蔽也不是“颜色灰暗”的同义词。它是相对于特定捕食者的感觉系统和背景而言的信噪比降低，鲜艳动物在色彩复杂的环境中也可能难以检出，并且对捕食者隐蔽的图案仍可在同类的视觉通道中醒目。警戒色同样不只表示毒性：难以捕捉、具有硬壳或处理代价很高的猎物，也可能用明显信号影响捕食者学习。拟态、警戒色和军备竞赛的完整证据边界见[捕食、寄生与互利](../consumer_resource_interactions.md)。

空间决策尤其集中在遭遇和接近阶段。猎物选择有遮蔽但食物较少的斑块，或在捕食者出现后减少暴露时间，会付出摄食、求偶或保温机会。逃跑同样有经济学边界：捕食者越近，继续停留的死亡风险通常越高；但过早逃走会损失食物、领域或配偶，并消耗能量。逃逸启动距离因此随捕食者速度、接近方向、遮蔽距离、猎物状态和重复惊扰而变，而不是物种恒定常数。[^ydenberg-dill]

Lima 和 Dill 将这类权衡系统化为风险下的行为决策：个体同时估计遭遇概率、攻击后的条件死亡概率与放弃当前活动的机会成本。[^lima-dill] 风险还在时间上成簇出现。风险分配假说预测，当危险期短而可辨认时，猎物会在危险期强烈抑制活动，并在安全期补偿；若危险几乎持续存在，过度压缩活动将导致饥饿，反捕食反应反而可能减弱。[^risk-allocation]

“恐惧景观”用空间表面表示动物感知到的危险及相应反应，它可由捕食者活动、视野、遮蔽、逃生距离和猎物经验共同塑造。这个概念适合提出取样位置、警戒或放弃密度的预测，却不应仅凭动物少出现就反推其害怕：食物少、热环境不适或竞争排斥也会形成同样的分布。可靠研究会同时记录捕食者、资源、动物行为与适合度结局。[^landscape-fear]

## 生境选择、线索与经验 { #habitat-selection }

动物不能直接预知一个地点未来产生多少存活后代，只能依靠当前线索决策。温度、湿度、植被结构、食物气味、同种个体、捕食者痕迹和以往繁殖成败，都可能成为生境线索。选择规则既受遗传差异影响，也可由印随、学习和出生地经验修改；竞争还会使较弱个体进入它们并不偏好的地点。

搜索能力和选择收益也限制“挑选最优生境”。两个地点质量差异很小时，继续采样的时间与风险可能超过改换地点的收益；搜索能力弱的幼体即使落在次优底物，也可能以立即定居获得更高的预期存活。种内竞争增强时，个体常扩展到更多生境，种间竞争也可把物种从偏好环境排出。因此，观察到的分布是偏好、可达性、信息与竞争共同作用的结果。

出生经验造成的偏好不只是“熟悉所以返回”。幼体在某种底质、寄主或群体环境中成功发育后，可能在成熟时把相关刺激当作质量线索；这种效应可以提高对稳定环境的匹配，也会在环境变化后造成滞后。综述研究把它概括为出生生境偏好诱导，但其强度和方向取决于经验发生的阶段、环境可预测性以及个体后来获得的信息。[^natal-experience]

管栖多毛类螺旋虫属 *Spirorbis* 的浮游幼虫，是传统教材中常见的底质选择实例。幼虫在沉降前能够辨别海藻表面和同种个体留下的线索；不同海岸种群对墨角藻类底物及聚集线索的反应并不完全相同。这个例子支持遗传差异、早期环境和局部选择共同塑造沉降规则，而不是说明幼虫只会机械地落到某一固定植物上。[^doyle-settlement]

线索与真实质量失配时会形成**生态陷阱**。例如，人工光源、光滑表面、道路边缘或经人为改变的植被仍可能保留强烈的定居线索，却使繁殖或存活低于可利用的替代生境。严格判定生态陷阱至少要比较生境偏好或不成比例使用，并证明被偏好的地点具有更差的适合度结局；“动物出现在低质量环境”本身还不够。[^robertson-trap]

生境选择也能积累演化差异。传统的“生态位变异假说”注意到，广生境种群可能由多个各自利用较窄资源的个体组成，歧化选择因而可能维持多型；但广生境并不必然产生多型，个体专化还可能来自学习、年龄、竞争或短期资源变化。若不同个体反复在不同资源或微气候中定居，选择会作用于感觉、形态、取食和生活史性状；非随机交配或低散布进一步增强分化。不过，从生态位差异到生殖隔离仍需要基因流、遗传变异和配偶选择等证据，不能把生境偏好直接等同于物种形成。

## 理想自由分布及其偏离 { #ideal-free-distribution }

竞争者可以不相遇而共同耗减资源，这叫**利用竞争**；也可以看见彼此，在斑块间移动以争取较高收益；若个体直接驱赶或阻止他者取用资源，则形成**干扰竞争**。传统材料把中间情形称为“争夺竞争”，但广义争夺常包含直接对抗，使用这一术语时需要说明是否实际发生排斥。不同机制会产生不同空间预期：单纯利用竞争主要改变斑块收益，干扰竞争还改变个体能否进入。

理想自由分布（ideal free distribution, IFD）把斑块选择写成一个清楚的基准模型。“理想”指个体知道各斑块的资源和竞争状况，“自由”指它们可无成本迁移且不被优势个体阻挡；个体能力相同，资源输入可被同一斑块中的竞争者分摊。若斑块 $i$ 在时刻 $t$ 的资源供给为 $Q_i(t)$，平衡时每个个体获得共同收益 $C$，则

$$
n_i(t)=\frac{Q_i(t)}{C},
$$

所以任意两个斑块中的个体数之比应匹配资源输入之比：$n_i/n_j=Q_i/Q_j$。一旦某斑块人均收益较高，个体就应迁入，直到各被占斑块的边际收益相等。Fretwell 和 Lucas 最初用这个框架连接生境分布与领域行为；在不能自由进入优质地点时，模型转向由优势个体占据高质量空间的**理想专制分布**。[^fretwell-lucas]

三刺鱼实验发现，鱼群在两个投食点之间的分布大体追随食物到达率，成为 IFD 的经典检验。[^milinski-stickleback] 野鸭实验也得到近似匹配的群体分布，但优势个体取得较多食物，说明“群体数目匹配”不保证个体收益真的相等。[^harper-ducks] 自然群体经常出现**欠匹配**，即高收益斑块聚集的个体少于简单比例预测；过度聚集则称超匹配。信息更新延迟、旅行成本、资源颗粒大小、捕食风险、干扰竞争、个体能力差异、同种吸引和领域排斥，都能造成这些偏离。它们不是模型失败后的杂项解释，而是把基准模型改造成可检验机制的入口。[^tregenza-ifd]

IFD 也不意味着动物为“物种整体”平均分配。每个个体依据自己的状态和局部信息调整，群体格局由许多个体规则涌现。研究时应操纵资源输入并追踪个体获得量、移动和支配关系；仅把某一时刻的动物数与食物量画在一起，无法区分自由匹配、共同偏好和优势排斥。

## 发育阶段与个体条件的空间分化 { #ontogenetic-niche }

同一物种内部的空间分布常随体型、年龄、性别、生理状态和经验而分层。幼鱼可停留在浅水育幼场，随着体形和游泳能力增长转入深水；昆虫幼体和成体可能分别取食叶片与花蜜；繁殖雌体对巢址、钙或安全隐蔽处的需求也可能不同于雄体。Werner 和 Gilliam 把这种变化称为**发育生态位**：体型增长同时改变摄食能力、资源收益和被捕食概率，阶段转换发生在净增长或存活收益的相对排序改变之处。[^werner-gilliam]

传统材料有时把这种现象称为年龄或大小的“截头分布”，强调某一地点只保留达到阈值的一段个体。这个描述适用于确有体型门槛、竞争排斥或迁移转换的群体，但不能由空间上缺少某一年龄组就直接推断发育程序。死亡、采样偏差和繁殖季节也会产生相似图形。它更不能自动证明顺序性雌雄同体；性转换需要性腺、个体追踪或明确的生活史证据。

## 活动区、核域与空间记忆 { #home-range }

动物建立活动区，意味着它在反复使用地点之间积累信息。熟悉的逃生洞、饮水点、果树更新周期、邻居边界和道路障碍，都能降低搜索和移动成本。活动区因此可以理解为一个不断更新的空间认知图，而不是只由体重或资源密度决定的圆形面积。资源越稀疏，觅食范围常会扩大；资源高度集中时，个体可能缩小日常移动，却加强对少数斑块的防卫。体型、营养级、性别、繁殖阶段、社会组织、运动方式和地形都会改变这一关系。[^mitchell-powell]

活动区可通过直接观察、足迹和标记重捕、无线电遥测、GPS 或自动声学记录估计。最小凸多边形保留了传统上直观的外围范围，核密度和布朗桥等方法则估计空间利用概率。常用的 95% 利用分布和 50% 核域只是分析约定，不是跨物种恒定的生物学边界；采样间隔、定位误差、季节长度和偶发远行都能明显改变面积。报告活动区时应同时说明时间窗、定位方法、样本量和核域定义。

## 领域的收益、成本与类型 { #territoriality }

领域的核心特征是对一个特定空间的防卫。不同研究曾用“排他使用”“地点特异的优势”或“积极驱赶”界定领域性，比较物种时应先说明采用哪种可观察标准。[^maher-lott] 领域行为并非鸟兽特有：硬骨鱼、蛙和蝾螈、蜥蜴与鳄类中都有明确实例，无脊椎动物中的蜻蜓、蟋蟀、膜翅目和蝇类、蝶类、端足类、蟹类、软体动物及其他底栖类群也可防卫取食点、巢穴或展示场。防卫可提高对食物、巢位、配偶、育幼空间或避难所的控制，也会消耗时间和能量，增加受伤、感染、被捕食和失去其他机会的风险。领域只有在资源带来的额外收益超过巡逻、信号和争斗成本时才具有经济可防卫性。[^brown-territory]

传统分类按领域承担的主要功能区分四种常见类型，它们仍适合作为形态、行为和生活史观察的框架：

1. **繁殖兼取食领域**：交配、筑巢、育幼和主要食物来源位于同一防卫空间，许多鸣禽繁殖领域接近这一类型。
2. **繁殖领域**：围绕巢位和幼体防卫，成体到领域外取食；海鸟或其他集群繁殖动物常见相邻的小巢域。
3. **集群巢位领域**：在繁殖地仅防卫巢及其周围的最小间距，群体共同利用外部食物区或警戒收益。
4. **求偶或交配领域**：雄体防卫展示场、产卵位点或雌体经过的空间，资源可能不是雌体进入的直接原因；集中求偶场中的小展示领域属于这一类。

真实物种可以在季节间转换类型，也可能同时防卫食物和配偶，分类的用途是提出可测量的收益，而不是给物种贴永久标签。求偶场和配偶防卫的细节见下一专题[性选择与繁殖策略](sexual_selection.md)。

领域大小通常随资源需求增加而扩大，却随单位面积资源密度增加而缩小；当资源过于零散或更新太快时，防卫可能不再划算。食性、体型和营养级因而常与面积相关，但这种异速关系受生产力和运动方式调节。动物也不必依据“历年最坏情况”预先圈定固定面积：边界可以随当前资源、季节需求、邻居压力和过去经验调整。鸟类取食领域的经典比较已经显示资源分布与领域面积相联，也提醒跨种回归不能替代同种内的成本测量。[^schoener-territory]

密度上升时，相邻领域可缩小、边界冲突可增多，未取得空间的个体可能成为“浮游者”或推迟繁殖。先到者因熟悉地点和建立信号而取得优先效应，同步定居与陆续定居会产生不同的边界格局。由此形成的密度效应能够影响繁殖成功和迁出，却不是领域所有者为了维持物种数量而主动实行的种群调节。传统分类还区分能够忍受身体接触的“接触性动物”和主动保持个体间距的“间隔性动物”；这是对空间容忍度的描述，间距仍会随亲缘、温度、危险和资源改变。

## 边界、防卫与信号 { #territory-defense }

领域防卫往往从远距离信号开始，再到展示、追逐和接触攻击。蜻蜓巡飞和姿势展示提供视觉边界；鸟鸣、马鹿呼号、海豹叫声和啄木鸟敲击提供声学信息；河马散布粪便、犀牛和原猴留下尿迹，臭鼬肛腺、羚羊眶前腺以及部分昆虫腺体产生的分泌物，都可参与化学标记；某些电鱼还利用电器官放电辨认个体并调节间距。不同通道各有传播距离、方向性、持续时间和环境限制：声信号可越过植被但会衰减，视觉信号定位精确却依赖光线，化学标记持续较久却更新缓慢，电信号主要适用于导电水体。信号机制的详细比较见[动物通讯](../../zoology/behavior/communication.md)。

一条常见的防卫序列可概括为三层：边界或远端标记降低偶然闯入，近距离展示评估对手，最后才发生直接攻击。初次建立领域时，直接争斗可能比边界稳定后频繁。所有者通常具有空间熟悉度、既有投入和邻居识别的优势；入侵者则可能因饥饿、繁殖状态或自身资源枯竭而具有更高争夺动机。胜负因此来自所有权、资源持有潜力和主观价值的共同作用，不能只按体型预测。由配偶共同防卫时，双方可能更强烈地驱赶同性入侵者；群体领域则可由多个成员共同警戒和追逐，具体分工须由观察确定。

鸟鸣曲目曾催生 **Beau Geste 假说**：一个个体用多个曲型从不同位置鸣唱，可能使陌生者误判为有多个防卫者，从而减少入侵。[^krebs-beau-geste] 这是有明确预测的历史假说，而不是“曲目越大就必然虚张领地”的通则；红翅黑鹂等物种的播放实验既有支持，也有未能排除其他解释的结果，效应会随物种、邻居熟悉度和播放设计改变。[^yasukawa-beau-geste]

领域也可针对异种个体。当两个物种依赖重叠的食物、庇护所或繁殖空间时，驱赶异种能够保住资源；珊瑚礁雀鲷防卫藻坪就是经典例子。资源重叠越强，异种攻击往往越可能出现，但共同捕食者、错误识别和演化历史也会造成相似行为，须通过资源操纵和系统发育比较加以区分。[^peiman-heterospecific]

一个领域还可能由配偶、后代或从属个体共同居住。偷窃者只取走资源而不承担防卫，共占者则可能通过警戒、育幼或驱赶入侵者给所有者带来收益。增加成员能够提高这些共同服务，也会增加食物竞争和繁殖偏斜。领域所有者容忍从属者的最适群体大小，未必等于从属者希望加入的群体大小；双方各自的留居、迁出和驱逐阈值共同决定观察到的群体。

## 散布、定居与空间信息 { #dispersal }

**散布**是个体离开原地点、经过转移并在新地点定居的过程，通常分为迁出、转移和迁入三个阶段。出生散布发生在出生地与首次繁殖地之间，繁殖散布则发生在连续繁殖地点之间。它们与周期性往返的迁徙不同，也不同于活动区内的日常移动；动物迁徙的方向机制和传统比较见[节律、迁徙与导航](../../zoology/behavior/rhythms_migration_navigation.md)。

迁出能够减轻亲属或资源竞争、避免近交、寻找配偶，并进入空缺或暂时改善的生境；代价包括移动能量、暴露于捕食者、失去熟悉信息和未能定居。决策因此具有条件依赖性。体况差者可能因竞争而被迫离开，体况好者也可能因更能承担转移成本而散布；低密度既可能吸引寻找空位的个体，也可能因配偶稀少而抑制定居。现代“信息散布”框架进一步强调，个体会利用自身繁殖成败、同种个体表现、捕食者线索和沿途环境来更新去留规则。[^bowler-benton][^clobert-dispersal]

经典比较发现，许多鸟类呈雌性偏向的出生散布，许多哺乳类呈雄性偏向，并以婚配制度、资源防卫和亲缘竞争解释这种趋势。[^greenwood-dispersal] 这不是适用于所有类群的两性定律。合作繁殖、单配偶制、雌体资源竞争、个体发育时间和局部死亡率都可改变方向；可靠结论需要区分出生散布与繁殖散布，并校正两性检出率。

也没有从“不迁移”经“短距离”再到“长距离”的普遍单向进化序列。散布距离可因栖息地破碎化、扩散器官、导航能力和生活史共同改变，短距和长距策略还可在同一种内并存。真正需要解释的是每个阶段的成本、信息与遗传变异，而不是把距离排成高低等级。

## 从个体决策到生态格局 { #ecological-consequences }

风险回避会把猎物从食物丰富处推向庇护处，改变植物摄食、种子传播和营养物流；领域排斥会使种群在优质地点低密度分布，同时让次质地点聚集较多非繁殖个体；散布则连接局部种群，使空缺斑块重新定殖。这些结果说明，空间分布既不是资源地图的简单复制，也不能只由捕食者数量解释。

检验空间决策时，应把四类证据连起来：定位或观察说明个体实际使用何处；资源、风险和竞争测量说明当时可获得什么；操纵或自然实验区分候选线索；存活、繁殖和后代招募衡量长期质量。使用—可获得设计还要预先说明空间尺度和对照集合，避免把研究者划定的“可选地点”误当作动物真正能够到达的行动集合。

本页所述空间收益也会进入交配竞争：展示场的位置、巢址质量和领域持有时间能够影响配偶接近，但空间资源与配偶选择并非同一过程。下一页将由[性选择与繁殖策略](sexual_selection.md)继续讨论配偶竞争、选择、婚配制度、精子竞争和亲代投资。
