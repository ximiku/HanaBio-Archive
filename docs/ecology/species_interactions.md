# 竞争、生态位与共存

两个个体利用同一份食物，并不必然已经发生竞争。食物充足时，二者可以高度重叠而互不限制；食物下降到影响存活、生长或繁殖时，一个个体的消耗才会降低另一个个体的适合度。竞争因此是一种由资源供给、个体需求和接触方式共同决定的负相互作用，既能发生于种内，也能发生于种间。它可以改变种群增长和分布，也可以通过资源分化、性状演化及到达历史塑造群落。

本页沿着传统生态学的学习路径，从竞争类型、经典实验和 Lotka–Volterra 模型进入生态位与共存理论。经典概念保留其原有细节，同时把“物种共存便说明从不竞争”“生态位重叠必然意味着强竞争”一类过度推论还原为需要实验检验的假说。捕食、寄生和互利的种群动力在[捕食、寄生与互利](consumer_resource_interactions.md)中展开；种内领域、群居和合作的行为决策分别由后续行为生态页面承接。

## 竞争始于共同限制 { #competition-limitation }

利用性竞争（exploitative competition）通过消耗共享资源间接发生。植物吸收同一层土壤中的氮，草食动物取食同一片草地，滤食者截留同一水团中的颗粒，都可能使后来者面对较低的资源浓度。发生竞争的关键是共享对象具有数量或更新速率限制，而且资源变化能够传递到个体表现。资源利用相似只提示潜在竞争；证明竞争还需要显示一个种的存在使另一个种的存活、增长或繁殖下降，并排除共同环境响应等替代解释。

干扰性竞争（interference competition）由个体间的直接作用限制对方获取资源。攻击和驱逐、占据洞穴、遮阴、根系接触及释放抑制性化合物都可能属于这一类。狮与虎的接触并非定义竞争所必需，二者也可通过消耗共同猎物发生利用性竞争；同一物种对又可能同时存在两种机制。竞争经常是不对称的，一方付出的生长或繁殖代价远高于另一方。

争夺式竞争（contest competition）和分摊式竞争（scramble competition）描述有限资源如何分配，而不是另两种相互排斥的生物机制。争夺式竞争中，部分个体控制到足够资源，失败者损失很大；分摊式竞争中，许多个体都取得一部分，资源过少时可能普遍表现不佳。植物的根竞争还会改变地上枝叶对光的争夺，某一资源上的优势因而可传递到另一资源轴；本地素材把这种联动称作竞争的“共轭性”。

### 共享资源与共享天敌形成不同路径 { #resource-apparent-competition }

两个消费者取食同一猎物或植物资源时，彼此通过降低资源量发生利用性竞争。两个猎物若被同一种捕食者或寄生者利用，则可能发生似然竞争（apparent competition）：物种 A 增多维持了更多天敌，天敌继而压低物种 B，即使 A 与 B 从未争夺资源。两条路径都能造成负相关、空间分离甚至局部排斥，却需要不同的因果检验；原素材把它们并列在“似然竞争”之下，本页据此分开。[^apparent-competition]

## 他感作用需要把化学作用从邻体效应中分离 { #allelopathy }

他感作用或化感作用（allelopathy）是生物产生的化合物经挥发、根系释放、淋溶或残体分解进入环境，进而改变另一生物的萌发、生长或繁殖。受体可以是异种，也可以是同种，因此连作中的自毒作用属于种内化学干扰，异株克生则常指种间效应。黑胡桃、香蒲、桉树、丁香和松类，以及早稻连作和歇地现象，均可作为提出化感假说的传统例子；具体结论仍须落实到物种、化合物、实际浓度、土壤和微生物背景。

把叶片浸提液在培养皿中直接施给种子，只能说明高浓度提取物具有生物活性。较完整的证据链还要测定化合物在野外如何释放、转化和降解，证明受体实际暴露量足以产生效应，并通过补加资源、活性炭、密度梯度或供体移除等设计排除遮阴、水肥消耗、盐分、凋落物物理覆盖和土壤微生物变化。这样才能把农林管理、群落组成和演替中的化学干扰同一般邻体效应区分开。[^allelopathy]

## 经典实验把排斥与共存放进可控制条件 { #classic-competition-experiments }

### 草履虫实验显示结果依赖培养环境 { #gause-paramecium }

Gause 分别培养大草履虫 *Paramecium caudatum*、双小核草履虫 *P. aurelia* 和袋状草履虫 *P. bursaria*，再比较混合培养。*P. aurelia* 与 *P. caudatum* 利用相近的水层和食物时，前者在经典培养条件下占优势，后者逐渐消失。这个结果常被用来说明竞争排斥，却也包含培养基补给、代谢产物积累、初始密度和实验时长等条件，不能直接升级为任何相似物种必有固定胜者。

另一组混合培养中，*P. caudatum* 与 *P. bursaria* 的密度都低于单独培养，却能共同延续；前者较多利用培养液上层的细菌，后者在底部利用酵母等资源。空间和食物分化使种间作用弱于各自的种内限制。经典实验由此同时给出排斥与共存，而非只证明前一种结局。[^gause]

### 硅藻实验把竞争能力连接到资源阈值 { #tilman-diatoms }

连续培养中的星杆藻 *Asterionella formosa* 与针杆藻 *Synedra ulna* 都需要溶解硅。单独培养达到平衡后，每个种会把硅维持在一个可继续补偿损失的水平，常以最低资源需求量 $R^*$ 表示；在单一限制资源、恒定供给和其他条件相同的模型中，能把资源压到更低 $R^*$ 的种可使竞争者的净增长率降到零以下。

实验结果还显示竞争排序受温度影响。在 Tilman、Mattson 与 Langer 的温度梯度实验中，低于 20 ℃时星杆藻排斥针杆藻，高于 20 ℃时针杆藻排斥星杆藻，20 ℃附近又出现模型未完全预测的结果。本地素材“硅酸盐不足时星杆藻很快被排斥”保留了资源竞争主题，却遗漏温度和物种资源动力学；补回这些条件后，$R^*$ 是可测的机制预测，而不是物种永久的竞争等级。[^tilman]

### 藤壶实验分开物理耐受与种间限制 { #connell-barnacles }

Connell 在苏格兰岩岸观察到小藤壶 *Chthamalus stellatus* 成体主要位于较高潮位，而藤壶 *Balanus balanoides*（现常作 *Semibalanus balanoides*）在较低潮位占优势。幼年小藤壶能够在较低处定着；移除周围藤壶后，它们在那里明显提高存活，说明低潮位的下界很大程度上由藤壶挤压和覆盖造成。相反，小藤壶在更高潮位的上界受干燥等物理条件限制。

这一移除实验比单看分带格局更有解释力：小藤壶能够在无竞争者时利用的范围大于自然条件下实际占据的范围，而藤壶自身的上界主要由非生物胁迫决定。环境忍受力与竞争共同形成了岸带分布，不能只把高处和低处视为两个物种主动选择的固定生境。[^barnacles]

### 达尔文雀把资源短缺连接到快速性状变化 { #darwin-finches }

本地素材以“勇地雀—仙人掌地雀分别利用小种子和大种子”说明资源分割；其中“勇地雀”不是稳定的现行中文种名，单凭共存食谱也不足以证明竞争造成了形态分化。长期野外研究提供了更清楚的案例：大地雀 *Geospiza magnirostris* 到达达夫尼大岛后，与中地雀 *G. fortis* 在旱年共同消耗较大而坚硬的种子；资源紧缺期间，小喙中地雀存活较好，下一代平均喙尺寸随之减小。研究同时记录竞争者到达、食物枯竭、表型选择和遗传响应，因此构成生态性状替换的强证据。[^finch-character]

## 竞争排斥原理陈述的是条件结论 { #competitive-exclusion }

竞争排斥原理可表述为：在空间和时间上近似恒定的封闭系统中，若两个种受同一限制因素调节，并以相同方式影响和响应这一因素，稳定平衡时通常不能都维持正的种群增长。一个种会被局部排斥，或系统会停在对初始条件敏感的边界状态。它没有断言自然界每对竞争者都必须有一方灭绝，因为资源可以沿空间、时间、粒径或化学形态分化，环境会波动，迁入和天敌也会改变密度反馈。

“同一稳定群落中没有直接竞争者”同样推得过远。共存种可以持续竞争，只要每个种在变稀少时获得相对优势；群落也可能处于缓慢排斥的暂态，或由区域迁入不断补充局部劣势种。多种群落是否比单种系统更充分利用资源、生产力更高或更稳定，是可检验的多样性—功能问题，不能仅由排斥原理推出。[^coexistence]

## Lotka–Volterra 模型把竞争压缩成两个系数 { #lotka-volterra-competition }

两种竞争者的经典方程是在各自逻辑斯蒂增长式中加入另一种的密度：

$$
\frac{\mathrm dN_1}{\mathrm dt}=r_1N_1\left(1-\frac{N_1+\alpha N_2}{K_1}\right),
$$

$$
\frac{\mathrm dN_2}{\mathrm dt}=r_2N_2\left(1-\frac{N_2+\beta N_1}{K_2}\right).
$$

$N_i$ 是种群数量，$r_i$ 是低密度增长参数，$K_i$ 是该种单独存在时的平衡数量。α 把一个种 2 个体对种 1 的作用折算成种 1 个体数，β 则作反向折算。这个折算是对所有资源、生命阶段和空间位置的平均，只有在参数近似恒定、竞争作用与密度成比例且没有显式时滞和年龄结构时才有清楚含义。

种 1 的零增长线为 $N_1=K_1-\alpha N_2$，种 2 的零增长线为 $N_2=K_2-\beta N_1$。比死记两条线的高低更直接的方法，是把每个种放到稀有状态，检验它能否侵入由另一种占据的系统：

$$
g_{1\mid 2}=r_1\left(1-\frac{\alpha K_2}{K_1}\right),
$$

$$
g_{2\mid 1}=r_2\left(1-\frac{\beta K_1}{K_2}\right).
$$

| 稀有时增长 | 长期结局 | 生态解释 |
| --- | --- | --- |
| $g_{1\mid2}>0$ 且 $g_{2\mid1}>0$ | 稳定共存 | 两种都能从低密度恢复；各自种内限制相对更强 |
| 只有种 1 为正 | 种 1 排斥种 2 | 种 1 可侵入种 2，种 2 不能反向侵入 |
| 只有种 2 为正 | 种 2 排斥种 1 | 种 2 可侵入种 1，种 1 不能反向侵入 |
| 二者都为负 | 优先效应或双稳态 | 谁先达到较高密度可能决定胜者；内部交点不稳定 |

本地素材列出的四种图解结局由此完整保留，其中“不稳定共存”更准确地说是一个不稳定内部平衡：它不能吸引受到轻微扰动的轨迹，实际长期结果通常是二者择一。模型里的 $1/K_i$ 可视作单位密度的种内限制尺度，α/$K_1$ 和 β/$K_2$ 则反映折算后的种间作用；“种间作用弱于种内作用”只有在相应参数和尺度下才导向稳定共存。

## 生态位把环境条件与种群增长联系起来 { #niche-concepts }

生态位概念经历了几条相互补充的传统。Grinnell 从加州嘲鸫等自然史出发，强调物种所需的生境条件和可占位置；Elton 强调食物关系以及物种在群落中的功能角色；Hutchinson 则把温度、湿度、资源浓度、巢位等变量作为坐标轴，将种群能够维持的环境组合表示为 $n$ 维超体积。现代研究常把三者结合：生态位既涉及生物对环境的要求，也涉及其获取资源、改变环境和影响其他种的方式。[^niche-history]

基础生态位是一个种在排除目标负相互作用的理想条件下保持非负种群增长的环境集合，不以物种是否已经到达为定义条件。实际生态位是它在竞争、捕食、互利、扩散限制和历史条件共同作用下真正维持种群的部分。竞争常使实际生态位缩小，互利者或生态工程者也能扩展可占条件，因此实际生态位并非必然是基础生态位的简单子集。专性互利种仍各有环境需求和作用方式，只是单独缺少伙伴时某些位置的增长率为负；“专性互利中单个种没有生态位”的说法据此应舍弃。

生态位也随尺度改变。幼体和成体、繁殖季和非繁殖季、丰水年和旱年可能使用不同资源；种群在不同地点具有遗传差异与反应规范。测得的生态位必须注明生命阶段、地点、时段和响应变量，不能把一次调查的出现范围当作物种永恒的属性。

## 资源利用曲线描述重叠却不直接测量竞争 { #niche-overlap }

在一条资源轴上，可以用偏好位置或平均利用值表示曲线中心，用宽度 $w$ 表示种内利用差异，再用两个种曲线中心的距离 $d$ 描述分离程度。$d$ 较大、$w$ 较小时，观测重叠通常较少；$d$ 较小、曲线较宽时，重叠较多。这种图形保留了本地素材中“位置—变异度—重叠”的直观含义，也便于提出应测哪一种种子、土层或活动时段的假说。

重叠量本身不等于竞争系数。资源丰富时，高重叠可以没有明显代价；强竞争已经造成生态位移动后，现存重叠反而很低；两种还可能在未测量的维度竞争，或因共享天敌而表现为负作用。MacArthur 与 Levins 的极限相似性模型说明过于相似的利用曲线在特定假设下不利于稳定共存，但阈值随资源分布、利用曲线形状、维度、环境波动和物种数改变。素材中的 $d/w=1$ 应作为某类简化模型的示意边界，而不是自然群落的普适常数。[^limiting-similarity]

## 竞争释放与性状替换发生在不同时间尺度 { #release-character-displacement }

竞争释放是移除或缺少竞争者后，一个种的数量、分布或资源利用范围扩大；若强调可用资源谱变宽，也常称生态释放。竞争者存在时，实际生境范围缩小可称生态位压缩；在食物、微生境或活动时间上改变利用中心，则是生态位移动。资源分割描述共存种在一个或多个轴上的差异，可能来自既有性状、行为可塑性、种间选择或这些过程的组合。

生态性状替换专指竞争造成的遗传性状分化。近缘种在同域时比异域时差异更大，只是候选格局；还应排除环境差异、随机漂变、杂交和物种筛选，证明所测性状影响资源利用、竞争确实发生、差异具有遗传基础且分化能减弱竞争。行为性的短期生态位移动可以先于遗传改变，也可能在环境恢复后逆转，不宜与性状替换混为一词。达尔文雀的长期数据之所以重要，正是因为它连接了资源、存活选择和跨代响应。

## 现代共存理论比较稳定化与平均适合度差异 { #modern-coexistence }

稳定共存要求一个种在稀有时能够增长。稀有种主要与异种相遇，常见种主要承受同种个体造成的限制；若资源分割、不同天敌或不同环境响应使种内负反馈强于种间负反馈，变稀少便能带来恢复优势。这类过程称为稳定化机制或生态位差异。它们维持负频率依赖，是两种 Lotka–Volterra 竞争者互相侵入的生物学解释。

平均适合度差异描述两个种在没有稳定化优势时，获取资源、耐受环境或逃避损失的平均能力差距。差距较小能延缓排斥并扩大稳定化机制可维持共存的范围，称为均等化作用；单独把平均能力变得相似，只会使排斥变慢，不保证低密度恢复。现代共存分析因此同时估计两条轴，而不把所有差异都称为“生态位分化”。[^coexistence]

互相侵入是强而实用的判据，却仍需匹配模型。若系统有强优先效应，低密度侵入失败的种可能在高密度保持；若环境变化太慢，短期正增长也未必代表长期共存。实验上可用密度梯度、邻体移除、资源补加和低密度引入估计种内与种间作用，再用种群增长率而非仅凭共现或资源重叠作判断。

## 时空异质性使竞争没有足够时间收敛到单一结局 { #heterogeneity-coexistence }

斑块环境中，极端天气、死亡和扰动产生空缺。竞争力较弱而扩散快的种可以先占新斑块，随后被局部优势种替代；只要斑块生成、定殖和排斥的时间尺度允许，区域尺度仍可共存。环境在年份间变化时，不同种可在不同年份获得招募窗口；休眠种子、滞育或长寿成体把种群保存到下一次有利期，并可形成储存效应。空间和时间分化的实质仍是让每个种在某些状态下从低密度恢复，而不是“变化越大，多样性必然越高”。

浮游生物悖论由 Hutchinson 提出：看似均一的水体中，许多浮游植物竞争少数限制资源，为何没有迅速只剩少数胜者？日周期、季节、水层混合、光和营养梯度、天敌、休眠与非平衡动力都可延缓或改变排斥。现代观测也显示远洋环境并不真正均质。这个悖论提醒我们先检验环境和生态位是否真的单一，再讨论排斥原理是否失效。[^plankton]

优先效应则把历史加入竞争。先到者可以预先占据空间和资源，或改造土壤、微生物群和化学环境，使后来者面对另一套生态位条件；不同到达顺序可形成替代稳定状态、替代暂态或循环。早到并非天然有利，若先到者改善后来者所需环境，也可能产生促进作用。识别优先效应需要操纵到达顺序和时间，同时保持物种库与环境背景可比。[^priority-effects]

## 共存结论来自过程证据的组合 { #testing-competition-coexistence }

竞争研究通常从自然史开始：先列出可能受限的资源、干扰方式、天敌与非生物梯度，再选择适合的尺度。共现说明种能在某时某地同时出现，负相关提示潜在排斥，稳定共存则要求长期低密度增长证据。移除实验能分开竞争者与物理条件，资源补加能检验限制因素，围栏或天敌排除能区分直接竞争与似然竞争，稳定同位素、肠道内容物和追踪数据则帮助定位资源轴。

长期序列还要记录扰动、迁入和环境变化，因为静态格局可能是过去竞争留下的性状分化，也可能是尚未完成的排斥。模型参数应由对应过程估计，并检验其随密度、阶段和环境是否改变。这样，竞争排斥、生态位分化、性状替换与优先效应构成一条连续的推理路径：从作用机制提出预测，用操纵和人口统计辨认因果，最后判断局部或区域尺度上何种共存能够持续。
