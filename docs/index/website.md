# 网站资源

该页面会持续收集总结我常用的一些生物学习网站

## 学术搜索

1. [Pubmed](https://pubmed.ncbi.nlm.nih.gov)：美国NIH开发的生物医学文献搜索网站

2. [Google Scholar](https://scholar.google.com)：很全的文献搜索引擎，~~可以看引用量找综述水ref~~


## 综合知识搜集

1. [osm&bio](https://osm.bio)：生物竞赛知识综合平台，很多佬贡献

2. [PKUHUB](https://pkuhub.cn)：北京大学课程资料收集平台（仅限校内学生访问）

## 生物信息&计算机资料

1. [runoob.com](https://www.runoob.com)：编程语言学习网站

2. [CSDIY](https://csdiy.wiki)：北大信科学长整理的计算机自学资料

3. [huaxz1986](https://www.huaxiaozhuan.com)：AI阿里工程师深度学习笔记

4. [Applied Bioinformatics Course](https://abc.gao-lab.org)：北大罗静初老师开发的实用生物信息技术课程，旨在为生物学湿实验室学生提供最基本的信息检索和生物信息技术

5. [MIT Missing Semester](https://missing-semester-cn.github.io)：计算机教育中缺失的一课，由MIT开发，讲授命令行、强大的文本编辑器的使用、使用版本控制系统提供的多种特性等等

6. [DeeperPlayGround](https://deeperplayground.org)：可视化的神经网络学习平台

7. [sklearn API](https://scikit-learn.org/stable/api)：sklearn的API查询

8. [CNN Explainer](https://poloclub.github.io/cnn-explainer/)：可视化的CNN学习平台
