# 心血管与淋巴系统

心血管系统以心为动力中心，以动脉、毛细血管和静脉构成闭合的血流通路；淋巴系统则从组织间隙起始，沿毛细淋巴管、集合淋巴管、淋巴结、淋巴干和淋巴导管把液体单向送回血液。两者在静脉角汇合，也共同决定组织液、脂质和免疫细胞怎样在身体各区室之间迁移。[^fipat-cardiolymph]

本页以成人的大体解剖和必要的微细结构为主。压力、阻力、心动周期、冠脉灌流和淋巴回流的定量机制见[血液与循环生理总论](../../physiology/blood/index.md)、[心脏的泵血功能](../../physiology/blood/blood_heart_pump.md)与[血管生理](../../physiology/blood/blood_vessel.md)；淋巴细胞发育、抗原递呈和免疫应答见[免疫细胞、组织与迁移](../../immunology/immune_cells_tissues.md)。

## 血流回路与血管层级 { #circulation-architecture }

成人血液沿两套串联回路循环。体静脉血经上、下腔静脉和冠状窦进入右心房，依次通过右房室口、右心室、肺动脉口和肺动脉干到达两肺；肺毛细血管后的血由肺静脉回到左心房，再经左房室口、左心室和主动脉口进入主动脉及其分支。肺循环和体循环各自包含动脉、微循环与静脉，两个心室逐搏排出的血量在稳态下相等。[^openstax-heart]

动脉和静脉按血流相对于心的方向命名，而不是按含氧量命名。肺动脉干及左右肺动脉把相对低氧血带离右心室，肺静脉把相对高氧血送回左心房；胎儿的脐动、静脉同样遵守方向定义。冠状循环属于体循环的一支，却在心肌内形成从主动脉根部出发、再直接回到右心房或心腔的小回路。

### 血管壁、微循环与吻合 { #vessel-wall-anastomoses }

除毛细血管外，多数血管壁可辨内膜、中膜和外膜。弹性动脉以多层弹性膜承接心室射血，肌性动脉以平滑肌调节区域分配，小动脉把血送入微循环；毛细血管主要由内皮和基膜构成，按内皮连接、窗孔与基膜连续性分为连续型、有窗型和血窦型。毛细血管汇为微静脉，继而进入中、大静脉；静脉中膜较薄、外膜常较发达，肢体静脉的瓣膜与浅深静脉交通共同适应低压回流。[^openstax-vessels]

相邻动脉之间可在关节周围、体壁和器官表面形成动脉吻合；静脉网、静脉丛以及浅深静脉之间的交通使回流具有较多替代路径。皮肤某些区域的动静脉吻合可绕过毛细血管床，迅速改变皮肤血流与散热。侧支循环则指主干狭窄或阻断后，既有吻合支在压力差和重塑作用下承担更多血流；它需要足够管径和发展时间，因此解剖上“有吻合”并不保证急性闭塞时能够完全代偿。

真正的终动脉与相邻动脉之间缺少有效吻合，视网膜中央动脉常作为代表。功能性终动脉具有细小吻合，但在突然阻断时供血仍不足，冠状动脉、脑内许多分支、肾段动脉和脾段动脉具有这种临床性质。终动脉描述的是供区之间的功能关系，不表示血管末端没有继续分成小动脉和毛细血管。

## 心的位置、外形与心包 { #heart-position }

心位于中纵隔的心包内，约三分之二在正中矢状面左侧，长轴从右后上方向左前下方倾斜。心尖由左心室形成，朝向左前下方，体表投影常在左第五肋间隙、锁骨中线附近；解剖学上的心底朝向后上方，主要由左心房形成，并有一部分右心房。大血管根集中于心的上方，不能把“心底”简单理解为所有大血管附着的水平顶面。[^heart-anatomy]

胸肋面主要由右心室形成，另有右心房和左心室的一部分；膈面主要由左心室和部分右心室形成，贴于膈中心腱；右肺面以右心房为主，左肺面以左心室为主。右缘主要为右心房，左缘主要为左心室及左心耳。房室之间的冠状沟、两心室之间的前后室间沟容纳冠状血管和脂肪，外表沟与内部间隔大体对应，却不处处落在同一垂直平面。

纤维心包包围心及大血管根，并与膈、胸骨和大血管外膜相连；浆膜心包分壁层与脏层，脏层即心外膜，两层之间为心包腔。动脉端和静脉端的浆膜反折形成心包横窦与斜窦：横窦位于升主动脉、肺动脉干之后和上腔静脉之前，斜窦为左心房后方、肺静脉之间的盲隐窝。心壁由心外膜、心肌层和心内膜构成，心内膜与血管内皮连续。[^heart-pericardium]

右位心表示心尖及心脏长轴朝向右侧，应与胸腔病变把正常心推向右侧的“右移位”区分。它可伴完全内脏反位，也可见于内脏正位或异位；孤立、结构完整的右位心可以无症状，伴随异位综合征、大血管连接异常、间隔缺损或原发性纤毛运动障碍时则具有不同表现。预后取决于连接关系和伴随畸形，而不由“心在右侧”或“同时反位”单独决定。[^dextrocardia]

## 心腔、瓣膜与传导结构 { #cardiac-chambers }

### 右心房与右心室 { #right-heart }

上腔静脉、下腔静脉和冠状窦开口于右心房。右心房后部的静脉窦部内面平滑，前部与右心耳内有梳状肌，两者以终嵴为界；房间隔上的卵圆窝及其缘为胎儿卵圆孔闭合后的遗迹。血液经右房室口的三尖瓣进入右心室，三尖瓣的前、后、隔侧瓣叶由腱索连到相应乳头肌。乳头肌和腱索在心室收缩时限制瓣叶向心房翻转，它们本身并不主动拉开房室瓣。

右心室流入部内有肉柱，隔缘肉柱或节制索跨向前乳头肌并传递右束支的一部分纤维。流出部逐渐变得平滑，形成动脉圆锥，通向肺动脉瓣和肺动脉干。肺动脉瓣的三个半月瓣与肺动脉壁形成小窦，关闭时阻止肺动脉干内血液返流；半月瓣没有腱索和乳头肌。

### 左心房与左心室 { #left-heart }

左心房通常接受四支肺静脉，左右各两支，但肺静脉在入房前合并、额外分支或开口数变化均较常见。左心房大部内面平滑，梳状肌主要局限于左心耳。血液经左房室口的二尖瓣进入左心室；二尖瓣有前、后两叶，腱索连到前外侧和后内侧乳头肌，使每个瓣叶都得到两组乳头肌支持。

左心室壁明显厚于右心室，内面同样有肉柱，流出道的主动脉前庭通向主动脉瓣。主动脉瓣有右冠瓣、左冠瓣和无冠瓣，瓣叶与主动脉壁之间形成主动脉窦；左右冠状动脉分别从相应冠状窦开口。左右心室承受的压力不同，却在稳定循环中排出相同的逐搏血量，壁厚差异反映所连接血管床的阻力，而不是一侧负责更多血液。

四个瓣口周围的致密结缔组织环、纤维三角和膜性间隔共同构成心纤维骨架，为瓣叶和心肌提供附着，也在心房肌与心室肌之间形成电隔离。窦房结位于上腔静脉与右心房交界附近，房室结位于房间隔下部、冠状窦口与三尖瓣隔侧瓣邻近区；房室束穿过纤维骨架后分为左右束支，再沿心内膜下分布为浦肯野纤维。传导结构的位置解释了兴奋从心房到心室的唯一正常肌性通路，动作电位、传导时序和心电图见[心脏电生理](../../physiology/blood/blood_heart_electrical.md#cardiac-conduction)。

## 冠状循环 { #coronary-circulation }

左右冠状动脉起自升主动脉根部的左、右冠状窦。左冠状动脉主干短，常分为前室间支和旋支：前室间支沿前室间沟下行，供应两心室前部和室间隔前部的大部分；旋支沿左侧冠状沟绕向后方，发出左缘支并供应左心房、左心室外侧和后部。右冠状动脉沿右侧冠状沟行走，常发出窦房结支、右缘支和房室结支，并在多数个体中发出后室间支。所谓右优势或左优势，依据后室间支及房室结附近后壁血供主要来自哪一侧冠状动脉判定，不以心脏哪一侧更大判定。[^coronary-anatomy]

冠状动脉在心外膜下及心肌内存在吻合，但许多分支在急性阻断时表现为功能性终动脉。慢性狭窄可使吻合支逐渐扩大，仍不能据此推断任一急性闭塞都可由侧支补偿。冠脉灌流随舒缩周期变化的机制见[器官循环](../../physiology/blood/blood_organ.md#coronary-circulation)。

心静脉的大部分血经冠状窦流入右心房。心大静脉与前室间支伴行后延续为冠状窦，心中静脉沿后室间沟、心小静脉沿右冠状沟汇入冠状窦，此外还有左心室后静脉和左心房斜静脉等属支。心前静脉跨过右心室表面直接开口于右心房，最小心静脉则从心肌内直接开口于一个或多个心腔。因此“冠状静脉主要流入右心房”概括了终点，却会掩盖冠状窦、直接心房回流和最小心静脉三条路径。[^coronary-sinus]

## 主要动脉的连续通路 { #major-arteries }

肺动脉干从右心室向上、向后并略向左走行，在主动脉弓下方分为右、左肺动脉。右肺动脉较长，横过升主动脉和上腔静脉后方，在右肺门位于主支气管前方；左肺动脉较短，在左肺门位于左主支气管上方。成人可见一支肺动脉干和两支主肺动脉，旧提要的“肺动脉一支”只有明确指肺动脉干时才成立。肺动脉与支气管动脉分别承担气体交换回路和肺组织营养性供血，二者在肺内有细小交通。

主动脉分为升主动脉、主动脉弓和降主动脉。升主动脉首先发出左右冠状动脉；主动脉弓通常依次发出头臂干、左颈总动脉和左锁骨下动脉，头臂干再分为右颈总动脉和右锁骨下动脉。颈总动脉在颈部分为颈内、颈外动脉；椎动脉由锁骨下动脉发出并与颈内动脉系统共同供应脑。锁骨下动脉越过第一肋外缘改称腋动脉，继而成为肱动脉，在肘附近分为桡、尺动脉，二者在手掌形成掌浅弓和掌深弓。[^systemic-vessels]

降主动脉在膈以上为胸主动脉，发出后肋间、支气管、食管、纵隔和上膈等壁支与脏支；经主动脉裂孔后续为腹主动脉。腹主动脉的重要不成对脏支依次为腹腔干、肠系膜上动脉和肠系膜下动脉：腹腔干分向胃、脾、肝与胰十二指肠区域，肠系膜上动脉供应中肠来源器官，肠系膜下动脉供应后肠大部。成对分支包括下膈、肾上腺、肾、性腺和腰动脉等。腹主动脉约在 L4 水平分为左右髂总动脉；髂内动脉供应盆壁和盆腔器官，髂外动脉越过腹股沟韧带后成为股动脉，再经腘动脉、胫前和胫后动脉通向足背与足底动脉网。

这些连续名称既反映血管跨过解剖标志后进入新区域，也便于在标本和影像中定位。分支起点、共干和缺如存在变异，尤其是主动脉弓、肝动脉、肾动脉和小腿动脉；学习主干模式的目的在于建立追踪路线，最终仍应从实际起点沿血管到达供区。

## 主要静脉与肝门静脉系统 { #major-veins-portal }

头颈和上肢的深静脉多与同名动脉伴行。颈内静脉与锁骨下静脉在胸锁关节后方汇成头臂静脉，左右头臂静脉再汇成上腔静脉；奇静脉弓越过右肺根上方注入上腔静脉，奇静脉、半奇静脉和副半奇静脉在脊柱两侧构成胸壁及纵隔的重要侧支通路。上肢浅静脉中的头静脉和贵要静脉分别沿外侧与内侧上行，肘正中静脉常连接二者；浅静脉格局的个体差异大于主干动脉。

下腔静脉通常由左右髂总静脉在 L5 附近汇成，沿腹主动脉右侧上行，经膈的腔静脉孔进入右心房。它接受腰静脉、肾静脉、肝静脉以及右侧性腺静脉和右肾上腺静脉等；左性腺静脉和左肾上腺静脉多先汇入较长的左肾静脉。下肢深静脉沿胫、腘、股和髂外静脉回流，浅层大隐静脉汇入股静脉，小隐静脉通常汇入腘静脉；穿静脉将浅、深系统相连，瓣膜方向使血液多由浅入深。

肝门静脉系统位于前后两套微血管床之间。来自胃肠道、脾、胰和胆囊的静脉血汇成肝门静脉，进入肝血窦后再经中央静脉、肝静脉流入下腔静脉。肝门静脉通常在胰颈后方由肠系膜上静脉与脾静脉汇成，肠系膜下静脉多汇入脾静脉，也可进入肠系膜上静脉或二者汇合处；肝门静脉在肝十二指肠韧带内位于胆总管和肝固有动脉之后，到肝门附近分为左右支。肝内形态和门静脉—肝静脉分区见[肝与肝门](viscera.md#liver)。[^portal-system]

门静脉属支与体循环静脉在食管下段、直肠肛管、脐周和腹膜后等处形成门—体静脉吻合。正常情况下这些细小通路只承担有限交通；门静脉压力升高时可扩张为曲张静脉和腹壁侧支，却不能等价替代肝内灌流。门静脉本身把血送入肝，而肝静脉把血由肝送入下腔静脉，两者名称相近、方向与功能层级完全不同。

## 胎儿分流与成人遗迹 { #fetal-circulation-remnants }

胎儿循环利用胎盘而非肺完成气体交换。脐静脉血进入肝脏，一部分经静脉导管到下腔静脉；进入右心房后，较富氧血经卵圆孔导向左心房，右心室射出的多数血经动脉导管从肺动脉干进入降主动脉，再由两条脐动脉返回胎盘。出生后肺血流增加、房间压力改变和脐带阻断促使这些分流关闭。

成人可在房间隔见卵圆窝，动脉导管闭锁形成动脉韧带，静脉导管形成静脉韧带，脐静脉形成肝圆韧带；脐动脉远端形成脐内侧韧带，近端仍参与膀胱上动脉。遗迹名称记录了原通路，却不表示所有闭合都在同一时刻完成或必然完全融合；持续开放和左右连接异常需要按具体血流和结构判断。

## 淋巴管道与回流区域 { #lymphatic-pathways }

组织间液进入毛细淋巴管后称淋巴。多数组织淋巴清亮或淡黄色；小肠乳糜管在吸收长链脂质后含大量乳糜微粒，形成乳白色乳糜并进入肠干、乳糜池或胸导管。因此白色来自餐后脂质负荷，不是“乳糜池至胸导管”整段淋巴恒定具有的颜色。

毛细淋巴管以盲端起始，内皮细胞相互重叠形成可随内外压力差开放的连接，基膜不连续或缺如，并由锚定丝与周围结缔组织相连。液体、蛋白质、颗粒和细胞可由这些入口进入。较大的集合淋巴管具有连续性更强的内皮连接、平滑肌和成对瓣膜，相邻瓣膜之间的管段构成功能性淋巴管单元；淋巴结插在集合管路上，传入管把淋巴送入结内，传出管再送往下一组结或更大的淋巴干。[^lymphatic-structure]

淋巴由集合管自身节律性收缩、骨骼肌运动、呼吸造成的胸腹压力变化、邻近动脉搏动和外部组织运动共同推进，瓣膜限制返流。回流量随毛细血管滤过、进食、运动、炎症和静脉压力改变，并不恒等于某个固定的“全身血浆总量”。流体平衡和泵机制见[组织液的淋巴回流](../../physiology/blood/blood_vessel.md#lymphatic-return)。

浅淋巴管多与浅静脉同行，深部和内脏淋巴管多随深血管走行。局部淋巴经颈、腋、支气管纵隔、腰、髂和腹股沟等结群逐级汇聚，最终形成左右颈干、锁骨下干、支气管纵隔干、腰干和肠干。教材常把肠干画成单一而其余成对，但干的汇合、数目和静脉开口具有变异，图式用于表示主要引流区，不是每个人都能分离出完全相同的成套管道。

左右腰干与肠干常在 L1—L2 附近汇入乳糜池，乳糜池本身约只在半数个体形成清楚囊状扩张；缺如时，多支腰淋巴管可直接组成胸导管。胸导管经主动脉裂孔进入后纵隔，在主动脉与奇静脉之间、食管后方上行，约在 T5 附近跨向左侧，最后形成颈部弓并汇入左静脉角或其邻近静脉。它引流双下肢、腹盆部以及左侧胸、左上肢和左侧头颈的大部分淋巴。[^thoracic-duct]

右侧头颈、右上肢和右侧胸部的淋巴主要由右颈干、右锁骨下干和右支气管纵隔干汇向右静脉角。这三干可合成短的右淋巴导管，也可分别或以不同组合直接开入静脉，所以“右淋巴导管”比胸导管更不恒定。左右静脉角是主要回流终点，但终末管可开入颈内、锁骨下或头臂静脉邻近段。

## 淋巴组织、淋巴结与脾 { #lymphoid-tissues-organs }

### 弥散淋巴组织与淋巴小结 { #diffuse-lymphoid-tissue }

弥散淋巴组织由散在淋巴细胞、浆细胞、巨噬细胞、树突状细胞和网状基质构成，常位于消化道、呼吸道及其他黏膜的固有层。细胞聚集成较清楚的球形或卵圆形淋巴小结，受抗原刺激时可出现浅染生发中心和较深的套区。扁桃体、小肠集合淋巴小结和阑尾壁内淋巴小结均属黏膜相关淋巴组织的具体组织方式；它们与局部上皮、隐窝或抗原取样结构共同工作，不是沿淋巴管串联的“微型淋巴结”。

胸腺是初级淋巴器官，儿童期主体位于上纵隔并可向颈根延伸，由被膜和隔分成小叶，每一小叶有深染皮质和浅染髓质；青春期后实质逐渐被脂肪替代，但可保留功能性胸腺组织。骨髓提供造血和 B 细胞发育环境。淋巴结、脾和黏膜淋巴组织属于次级淋巴器官，它们的共同任务是把抗原、递呈细胞和循环淋巴细胞组织到可相遇的空间；细胞选择与免疫反应见[初级淋巴器官](../../immunology/immune_cells_tissues.md#primary-lymphoid-organs)和[次级淋巴器官](../../immunology/immune_cells_tissues.md#secondary-lymphoid-organs)。

### 淋巴结的结构与引流 { #lymph-nodes }

淋巴结常沿大血管或区域回流通路成群分布，数目、大小和具体位置均有个体差异。豆形结外有纤维被膜，结缔组织小梁伸入内部；凸面接受多条传入淋巴管，凹面的门供血管和传出淋巴管进出。淋巴依次经过被膜下窦、皮质或小梁旁的窦道和髓窦，再由门部传出。皮质含 B 细胞淋巴小结，深皮质或副皮质以 T 细胞和高内皮微静脉为特征，髓质由髓索与髓窦交错组成。这样的流路增加组织来源物质与吞噬、递呈和淋巴细胞区接触的机会。[^lymph-node-anatomy]

哨位淋巴结是某一原发肿瘤最可能首先引流到的一个或数个结，其位置由具体器官和个体淋巴通路决定。它是判断区域淋巴结转移概率和分期的取样概念，并不是一道能够保证阻止病变扩散的解剖屏障；肿瘤细胞可停留、增殖、越过该结或经替代引流通路播散。[^sentinel-node]

### 脾的血液通路与红白髓 { #spleen }

脾是最大的淋巴器官，位于左季肋区腹膜内，长轴大致沿第十肋，膈面邻膈和第九至十一肋，脏面与胃、左肾、结肠左曲和胰尾相关。胃脾韧带连接脾与胃并容纳胃短和胃网膜左血管，脾肾韧带连接脾与左肾前方并容纳脾血管和胰尾。脾门位于脏面，是脾动静脉、神经和传出淋巴管的通路；脾缺少像淋巴结那样把组织淋巴送入实质的传入淋巴管。[^spleen-anatomy]

被膜和小梁支撑脾实质。脾动脉在门附近分成节段性分支，进入小梁后形成小梁动脉；离开小梁的中央动脉被动脉周围淋巴鞘包绕，构成白髓 T 细胞区，并与 B 细胞小结相邻。血液随后进入边缘或滤泡周围区域、笔毛微动脉、鞘毛细血管以及红髓的脾索和血窦，最后经小梁静脉汇入脾静脉。红髓通过狭窄、富巨噬细胞的结构筛除衰老或变形红细胞，白髓组织对血源性抗原的免疫应答；脾因而主要过滤血液，而不是过滤来自外周组织的淋巴。

胎儿脾参与造血，正常成人稳态造血主要在骨髓；严重贫血、骨髓疾病或其他应激可重新出现脾内髓外造血。人脾可储存一定血细胞和血小板，但不像某些哺乳动物那样作为强大的、可迅速收缩的红细胞库。原材料中的“储血、造血、产生淋巴细胞”需要分别放在物种、发育时期和病理条件下理解。

## 淋巴侧支、淋巴水肿与管网新生 { #lymphatic-remodeling }

集合淋巴管之间存在交通，淋巴结切除或管路阻断后，一部分淋巴可经邻近管道、跨区域侧支和新形成的连接改道。代偿能力取决于阻断位置、残余管网、静脉压力、炎症和组织纤维化；超过运输能力时，富含蛋白的组织间液、脂肪和纤维组织逐渐积聚为淋巴水肿。早期淋巴水肿常可凹陷并随抬高减轻，慢性阶段随纤维化和皮肤增厚才逐渐转为难以凹陷；象皮肿指高度进展并伴明显皮肤、皮下组织改变的阶段。[^lymphedema]

胚胎早期血管从中胚层来源的前体细胞原位建立，称血管发生；既有血管再以出芽或内插分裂增加管支，称血管生成。出芽过程中，内皮细胞改变连接并跨越基膜，前导细胞引导延伸，后随细胞增殖、形成管腔，新的管支再经历吻合、剪枝、周细胞募集和基膜重建。成人的创伤修复、子宫内膜与卵巢周期性重塑、运动适应和缺血均可伴受控血管生成；淋巴管也能在发育、炎症、修复和肿瘤环境中发生类似的出芽与重塑。[^angiogenesis]

肿瘤相关血管不是单一的“孔内皮加片状基膜”。不同肿瘤及同一肿瘤不同区域可同时见弯曲、分支紊乱、管径不一、局灶内皮连接松散、基膜厚薄不均和周细胞覆盖异常，也可能利用既有血管而不立即形成新管。结构异常可造成渗漏、低灌流和缺氧，淋巴管则可成为细胞迁移的通道。现代证据把这些表现理解为内皮、周细胞、基质、血流和肿瘤细胞共同塑造的异质管网。[^tumor-vasculature]

## 标本与影像的追踪方法 { #cardiolymph-observation }

观察心脏标本时，先用心尖、心底和大血管确定方位，再沿上、下腔静脉进入右心，依次通过三尖瓣、右心室、肺动脉瓣和肺动脉干；随后从肺静脉进入左心，经过二尖瓣、左心室、主动脉瓣和主动脉。沿冠状沟和前后室间沟寻找冠状动静脉，再切开各腔辨认梳状肌、肉柱、乳头肌、腱索、间隔与卵圆窝。用这一连续路线可以避免仅凭壁厚或标本摆放猜测左右。

观察全身血管时，动脉从心向外沿分支追踪，静脉从区域回流向腔静脉追踪，门静脉则必须确认“消化器官毛细血管—门静脉—肝血窦—肝静脉”两套微血管床。超声心动图显示心腔、瓣膜和流向，CT 与 MR 血管成像显示大血管和冠脉的三维连接，导管造影与多普勒超声进一步显示管腔和流向。淋巴管在普通解剖标本中细而易塌陷，定位时先找区域淋巴结和伴行血管，再用淋巴显像、近红外示踪或 MR 淋巴成像追踪实际引流；胸导管和乳糜池尤其应预期形态变异。
