# 泌尿系统

泌尿系统由肾、输尿管、膀胱和尿道组成。肾把由肾单位形成的尿液汇入肾盏和肾盂，输尿管以肌性管壁把尿送入膀胱，膀胱储存尿液，尿道则把尿排出体外。沿这条通路观察时，既要追踪连续的腔，也要注意器官所在的腹膜后、腹膜下和会阴空间：双肾与输尿管大部位于腹膜后，膀胱主要位于盆腔腹膜下，尿道穿过盆底后通向体表。[^fipat-urinary]

以下内容以正常成人的大体解剖为主，并说明儿童、性别和常见变异所涉及的结构差异。滤过、肾小管转运、尿液浓缩及排尿反射分别见[泌尿生理总论](../../physiology/urinary/index.md)、[肾小球滤过与肾小管转运](../../physiology/urinary/filtration_transport.md)和[尿液浓缩、清除率与排尿](../../physiology/urinary/concentration_clearance.md)。

## 泌尿器官的空间连续性 { #urinary-tract-overview }

每侧肾的集合管开口于肾乳头，尿液依次经过肾小盏、肾大盏、肾盂和输尿管；两侧输尿管分别穿入膀胱后外侧壁，尿液在膀胱内汇合储存，再经一条尿道排出。肾盏以下的管道均覆有尿路上皮。尿路上皮是能随扩张改变细胞形态、又能隔离高渗或酸性尿液的复层上皮；它从肾小盏连续到近端尿道，向远端逐渐过渡为柱状或复层扁平上皮。[^openstax-urine-transport]

肾实质仍能改变管液组成，尿液离开肾乳头后，下游器官的主要任务转为传送、储存和排放。输尿管蠕动并不依赖重力，膀胱也不是一只被动容器：其平滑肌、尿道括约肌、盆底和神经共同调节低压储尿与间歇排空。这里先说明这些功能所依赖的形态和层次，神经控制时序留在生理页面展开。

## 肾的位置、外形与毗邻 { #kidney-position }

### 腹膜后位置与外形 { #kidney-surface }

双肾位于腹后壁上部，脊柱两侧、壁腹膜之后，大致跨越 T12—L3 椎体高度。肾随呼吸和体位可上下移动，右肾受肝的影响通常略低于左肾，因此椎体水平只是成人仰卧位的近似参照。肾长轴并非与脊柱平行：上极相对靠近正中并偏后，下极相对向外并偏前。每个肾有前、后两面，上、下两极，凸出的外侧缘和中央凹陷的内侧缘；内侧缘中央的裂隙为肾门。[^kidney-gross]

后面较平，贴近膈、腰大肌、腰方肌和腹横肌。第 12 肋越过两肾后方，左肾上部还常与第 11 肋相邻；肋下血管神经、髂腹下神经和髂腹股沟神经斜过肾后方肌面。由后方接近肾时，穿行层次与神经走向决定切口或穿刺所能利用的间隙。

两肾前方毗邻并不对称。右肾上极邻右肾上腺，前上大部邻肝，内侧邻十二指肠降部，前下部邻结肠右曲和小肠；左肾上极邻左肾上腺，前面依次与胃、脾、胰、结肠左曲及空肠袢形成不同范围的接触。所谓“肾的前方关系”通常隔着筋膜、脂肪、腹膜或系膜，并非上述器官都直接贴在肾纤维囊上。肾上腺与肾同处肾筋膜围成的区域，却有筋膜隔相分，属于独立内分泌器官。

### 肾的被膜与固定 { #kidney-coverings }

由内向外，肾实质表面紧贴**纤维囊**，其外为肾周脂肪，再外为肾筋膜；肾筋膜外侧还可见肾旁脂肪。纤维囊是薄而坚韧的致密结缔组织层，正常时借细小结缔组织束与实质相连，较容易剥离，炎症或瘢痕可使其粘连。某些组织学传统曾用“肌织膜”描述包膜内侧少量平滑肌样或肌成纤维样细胞；现代大体解剖术语将纤维囊列为紧贴实质的包膜，不再把“肌织膜”设为与三层被膜平行的独立肉眼层次。

肾周脂肪填充肾与肾筋膜之间的肾周间隙，并经肾门延入肾窦，对器官有缓冲和支持作用。肾筋膜具有前、后两层，向外侧融合并与周围筋膜连续，向上包围肾与肾上腺，二者之间有隔；向下则与输尿管周围结缔组织相续。肾旁脂肪位于肾筋膜之外，后外侧较明显。筋膜、脂肪、肾血管蒂、邻近器官、腹内压和后腹壁共同维持肾的位置，各界面的连接方式也不相同。

## 肾门、肾窦与内部结构 { #renal-hilum-internal }

### 肾门与肾窦 { #renal-hilum }

肾门是内侧缘上的出入口，向内通入由肾实质围成的肾窦。肾窦内有肾盂、肾盏、肾血管分支、神经、淋巴管和脂肪。典型肾门从前向后可依次见肾静脉、肾动脉和肾盂或输尿管上端，但血管提前分支、附加血管和肾盂形态变异都能改变截面顺序。因而，“静脉—动脉—肾盂”是寻找结构的起点，最终仍须沿管腔和分支确认。

肾盂是输尿管上端在肾窦内的漏斗状扩张，常由两至三支肾大盏汇成；每支大盏又收纳数支肾小盏。肾小盏杯口包绕肾乳头，乳头顶端筛区的乳头孔是乳头管开口。肾盂可以较多位于肾窦内，也可有较大的肾外部分；肾盏数目、分支角度和壶腹型或分支型外观都存在正常变异。盏、盂与输尿管的黏膜和肌层连续，不能把肾盂看成与输尿管分离的囊。

### 皮质、髓质与集合通路 { #renal-parenchyma }

额状切面上，外周颜色较深、颗粒感较明显的部分是肾皮质，内侧呈条纹状的部分是肾髓质。皮质不仅形成周边的皮质带，还向肾窦方向伸入相邻肾锥体之间，形成肾柱。髓质由数个锥形肾锥体组成，锥体底朝向皮质，尖端形成肾乳头。一个肾锥体连同覆盖其底部和两侧的相关皮质构成一个肾叶；肾叶是形态单位，不应与按动脉供应划分的肾段混为一谈。[^openstax-kidney]

皮质内的髓放线是成束排列的直小管和集合管在皮质中的条纹，周围盘曲小管和肾小体较多的区域称皮质迷路。所有肾小体都位于皮质，近端、远端曲部也主要位于皮质；髓袢、直小管和集合管则按不同深度进入髓质。集合管向乳头方向反复汇合为乳头管，最终经乳头孔把尿送入肾小盏。由此可在切面上建立两条相反的追踪方向：从皮质沿小管向乳头看尿流汇聚，或从肾盂沿大盏、小盏和乳头反向寻找一个肾叶。

肾单位由肾小体和与之相连的肾小管构成，集合管在发育定义上属于另一套分支系统，却与连接小管连续并接纳多个肾单位的尿液。肾小球滤过屏障、各段上皮转运与皮髓渗透梯度属于生理和微观结构内容，在大体解剖中主要用于定位其所在的皮质—髓质区域。

## 肾血管、肾段与神经 { #renal-vasculature }

### 肾动静脉的原位关系 { #renal-vessels }

左右肾动脉多由腹主动脉侧面发出。右肾动脉需越过正中到达右肾，通常从下腔静脉后方通过；左肾动脉行程较短。肾静脉汇入下腔静脉，右肾静脉短，左肾静脉较长并从腹主动脉前、肠系膜上动脉后通过。左肾静脉还常接纳左肾上腺静脉和左性腺静脉。动静脉的数量和进入位置变异常见，来自主动脉或其他邻近动脉、直接进入肾极的附加肾动脉同样供应特定实质，不能因其“额外”便视作可任意牺牲的血管。

肾动脉在肾门附近分为前、后支，再形成若干肾段动脉。肾段动脉之间实质内吻合很少，某支阻断可使相应区域缺血，因此其供区具有外科意义。经典模式把肾分为上段、前上段、前下段、下段和后段；实际分支数、起点和边界可变，五段模式是最常用的空间图，不是所有肾都完全相同的模板。前后段动脉之间在肾外侧缘后方附近形成相对少血管平面，可为进入集合系统提供路径。[^renal-arteries]

肾段动脉继续分为叶间动脉，沿肾柱走向皮髓交界；弓状动脉在锥体底部弯行，皮质放射动脉由此进入皮质并发出入球小动脉。血液经肾小球毛细血管后由出球小动脉离开，再形成管周毛细血管或直小血管。静脉大致由皮质放射静脉、弓状静脉和叶间静脉汇入肾静脉，但不必为每条动脉强配一条完全同名、同级的静脉。肾叶以锥体和相邻皮质为界，肾段以段动脉供区为界，两套分区可能交错。

肾淋巴主要沿肾血管流向腰淋巴结。肾丛围绕肾动脉进入肾门。肾传出神经以交感纤维最明确，分布于肾血管、肾小管和球旁装置；内脏传入纤维在肾盂区域较为集中，参与扩张和伤害性刺激的传递。人肾副交感支配的存在与范围仍有争议：近年解剖研究在肾动脉、肾盂和肾丛提示胆碱能或迷走相关通路，但其中直接追踪证据主要来自动物，尚不能据此认定肾实质具有明确而广泛的副交感支配。[^renal-innervation] 输尿管上段神经也与肾丛连续。肾血管阻力、肾素释放和痛觉传入的生理效应由泌尿与循环生理页面展开。

## 输尿管 { #ureter }

### 行程与毗邻 { #ureter-course }

输尿管是一对由肾盂延续至膀胱的腹膜外肌性管。腹段在腰大肌前方下行，生殖股神经位于其后，性腺血管通常从其前方跨过；右侧还与十二指肠、升结肠、回盲部邻近，左侧与降结肠和乙状结肠邻近。到骨盆上口附近，输尿管跨过髂总动脉分叉或髂外动脉起始处，继而沿盆侧壁下行，在坐骨棘附近转向前内，斜穿膀胱后外侧壁。[^ureter-anatomy]

盆段与邻近生殖管道的关系有稳定差异。典型男性盆腔内，输精管在膀胱附近从输尿管上方跨过，输尿管位于精囊腺外侧后方；典型女性盆腔内，输尿管从子宫动脉下方经过，并靠近子宫颈外侧和阴道穹侧部。这里记录的是输尿管定位所必需的毗邻关系，不另展开生殖器官系统。

输尿管末段斜穿膀胱逼尿肌和黏膜下层，形成壁内段。膀胱充盈或逼尿肌收缩时，壁内段受到周围肌壁压迫，有助于限制尿液反流；其效力还取决于壁内段长度、进入角度和三角区结构，不能把它想象成一片独立开闭的瓣膜。

### 管壁与狭窄部位 { #ureter-wall-constrictions }

输尿管黏膜由尿路上皮和富含弹性纤维的固有层组成，没有清楚的黏膜下层。肌层在上段以纵行和环行平滑肌束为主，向下可增添外纵行肌束；最外为含血管、神经和脂肪的外膜。肌束并非整齐的管道同心圆，而是以螺旋和交织方式排列，使由肾盂起始的蠕动波能沿管壁推进尿液。尿路上皮及黏膜皱襞让空虚输尿管横切面呈星形，扩张时管腔可明显改变。

传统解剖把结石较易停留的三个位置记为肾盂输尿管连接处、越过髂血管或骨盆上口处，以及输尿管膀胱连接处。现代测量提示前后两个连接处是较稳定的腔径约束，髂血管交叉处更重要的是管道转折、活动受限和影像定位，并非每个人都有相同程度的固有狭窄。因此应把“三处”保留为临床定位序列，同时区分真正的壁内狭窄与由走行造成的相对停留点。

输尿管血供来自沿途多支小动脉，上段接受肾动脉分支，中段可来自主动脉、性腺动脉和髂总动脉，下段由髂内动脉系统分支供应。这些分支在外膜内纵向吻合；剥离过多外膜会破坏分段血供。疼痛传入随自主神经丛回到胸腰段，能够沿腰腹、腹股沟及外生殖器方向产生牵涉痛，这种分布来自节段神经关系，不等同于结石的精确高度。

## 膀胱 { #urinary-bladder }

### 位置、分部与腹膜关系 { #bladder-position }

空虚膀胱位于小骨盆前部、耻骨联合之后，二者之间为含疏松组织和脂肪的耻骨后隙。膀胱充盈时上壁展开，器官可越过耻骨联合进入下腹部；儿童尤其是新生儿的膀胱位置相对较高，随盆腔生长逐渐下降。成人膀胱功能容量受年龄、体型、感觉阈值、神经状态和测量条件影响，群体平均差异不能化为“女性膀胱固定小于男性”，新生儿容量也不宜用成人容量的固定十分之一概括。

膀胱分为尖、体、底和颈。膀胱尖朝向前上方，经正中脐韧带与脐相连；该韧带是脐尿管闭锁后的遗迹。膀胱体构成大部分可扩张壁，底或基底朝向后下方，颈围绕尿道内口并是相对最固定的部分。典型男性膀胱底隔输精管壶腹和精囊腺与直肠相邻，膀胱颈位于前列腺上；典型女性膀胱底邻阴道前壁，膀胱上后方与子宫相关，膀胱颈由盆底和盆内筋膜支持。[^bladder-anatomy]

空虚膀胱上面和后上部由腹膜覆盖，腹膜从膀胱反折到邻近器官，形成性别不同的盆腔陷凹；前面和下外侧面主要由外膜及盆内筋膜包被。随着充盈，上面抬高并把腹膜推向上方，前壁较大范围可直接贴近前腹壁。膀胱的位置与覆盖因充盈而改变，是理解耻骨上穿刺、盆腔手术和断层影像的基础；腹膜内位、腹膜后位和腹膜下位的共同框架见[腹膜与腹腔空间](viscera.md#peritoneum)。

### 膀胱壁、三角与输尿管开口 { #bladder-wall-trigone }

膀胱黏膜覆尿路上皮，空虚时大部形成皱襞。左右输尿管口与尿道内口围成膀胱三角，三角区黏膜与深层结合较紧，表面相对平滑；两输尿管口之间可见输尿管间襞。尿液从壁内输尿管喷入膀胱，随后经位于三角尖端的尿道内口进入尿道。三角区把两条上尿路与一条下尿路的腔隙关系固定在同一观察面上。

黏膜外的平滑肌束交织成逼尿肌，传统可辨内纵、中环和外纵方向，但各层在许多区域相互交错，不能像小肠肌层那样处处清楚分开。膀胱颈的平滑肌和近端尿道平滑肌共同形成内括约功能区，男性通常更明显；远端的尿道外括约肌由横纹肌构成。上面被腹膜覆盖处最外层为浆膜，其余大部为外膜和盆内筋膜。

膀胱血供主要来自髂内动脉系统的膀胱上动脉，以及男性的膀胱下动脉或女性相应的阴道、子宫动脉分支；静脉在膀胱周围形成丛后流向髂内静脉。交感与副交感纤维经下腹下丛到达膀胱，盆内脏神经含来自 S2—S4 的副交感纤维；阴部神经支配尿道外括约肌。神经来自何处属于解剖，储尿和排尿时各通路怎样按时序转换见[排尿调节](../../physiology/urinary/concentration_clearance.md#micturition-switch)。

## 尿道 { #urethra }

尿道从膀胱颈的尿道内口开始，穿过盆底并开口于体表。近端上皮与膀胱尿路上皮连续，向远端过渡为复层或假复层柱状上皮，外口附近转为非角化复层扁平上皮。尿道周围的平滑肌、黏膜下血管丛、弹性组织和横纹肌括约结构共同维持闭合；把控尿简化为“内括约肌不随意、外括约肌随意”有助入门，却不足以描述从膀胱颈至盆底连续而重叠的括约肌复合体。[^urethral-sphincter]

### 女性尿道与尿道旁腺 { #female-urethra }

典型女性尿道较短，约 4 cm，自膀胱颈向前下方走行，嵌在阴道前壁和周围结缔组织内，穿过盆底与会阴膜后开口于阴道前庭。其外口位于阴蒂后、阴道口前。较短的距离并不表示管道结构简单：黏膜下有丰富静脉丛和平滑肌，外周横纹肌构成尿道括约肌、尿道压迫肌和尿道阴道括约肌等复合结构，分别环绕或压迫尿道及其邻近阴道壁。

尿道旁腺分布在远端尿道旁，导管多开口于尿道外口附近。它们与男性前列腺具有发生和部分分泌标志上的同源关系，这也是“女性前列腺”这一名称的来源；但尿道旁腺是沿尿道分布的腺组织，形态、体积和导管格局均有个体差异，不能把它直接等同为一枚与男性前列腺同形的器官。[^paraurethral-glands]

### 男性尿道 { #male-urethra }

典型男性尿道较长，约 20 cm，并兼作泌尿与生殖管道。按位置可分为壁内或前列腺前部、前列腺部、中间部（传统称膜部）和海绵体部。壁内部自膀胱颈至前列腺，短而受膀胱颈平滑肌包围；前列腺部穿过前列腺，是较宽的一段，后壁可见尿道嵴、精阜、前列腺小囊和前列腺导管等开口。中间部穿过尿道外括约肌复合体和会阴膜，短、位置固定且伸展性较小。[^male-urethra]

海绵体部进入尿道海绵体，先在阴茎球内扩为尿道球部，远端在龟头内形成舟状窝，最后经尿道外口通向体表；外口通常是管腔较窄处。尿道球腺导管和许多尿道腺开口于海绵体部。松弛状态下尿道具有耻骨下的固定弯曲和阴茎游离部形成的可变弯曲，抬起阴茎可展平后一弯曲；插管时所感受到的方向变化来自这些曲线、前列腺和括约肌层次，而不是一条均匀直管。

## 正常变异与发生线索 { #urinary-variations }

肾的数量、位置、旋转、融合、血管和集合系统均可出现变异。盆位肾或其他异位肾常保留与异常上升过程相应的多支血管，肾门可能朝前；肾盂、输尿管可部分或完全重复，输尿管开口位置随分支发生改变。附加肾动脉是常见变异，它供应的区域仍属于功能性实质，特别是跨越肾盂输尿管连接处的下极血管还会改变局部走行。

马蹄肾通常由两肾下极在正中以实质性或纤维性峡相连。融合影响上升和旋转，肾常处于较低位置，肾盂偏前，输尿管从峡前方下行，血管来源和数目变化较大。经典教材常说峡受到肠系膜下动脉限制而停止上升，这能解释一部分常见位置，却不是所有马蹄肾都具有的单一机械原因；观察影像时应把融合、位置、旋转、集合系统和血管分别记录。[^horseshoe-kidney]

多囊肾病是一组遗传性囊性疾病，常见常染色体显性和隐性类型，囊性扩张可发生在肾单位或集合系统的不同管段，并可伴肝等肾外表现；其病因由遗传和细胞机制解释，而非“胚胎期肾小管没有接上集合管”。它与局部集合系统重复、肾盂输尿管连接部梗阻以及后天获得性肾囊性病变属于不同问题。多发囊肿可以显著改变肾外形和实质，这项形态观察仍需与具体疾病类型相结合。[^polycystic-kidney]

膀胱尖与脐之间的脐尿管通常闭锁成正中脐韧带，未完全闭锁可形成瘘、窦或囊肿；输尿管芽分支和开口重排可形成重复输尿管或异位开口。发生学在这里用于解释为何变异成套出现，不把一种形态直接归结为单一胚胎“未连接”。

## 标本、内镜与断层影像的观察 { #urinary-observation }

观察原位标本时，先在腹膜后确认肾的上下极、外侧凸缘和内侧肾门，记录左右高度及前方器官，再逐层辨认肾筋膜、肾周脂肪和纤维囊。沿肾门由前向后分离静脉、动脉与肾盂，随后在额状切面上寻找皮质带、肾柱、锥体、乳头、小盏、大盏和肾盂。最后沿输尿管经过腰大肌、髂血管和盆侧壁追到膀胱，避免把性腺血管或输精管误认成输尿管。

膀胱内面可借膀胱镜辨认两侧输尿管口、输尿管间襞、膀胱三角和尿道内口。沿尿道观察时，应先确认性别与分部，再结合括约肌和周围器官判断层次。超声适合显示肾轮廓、皮髓质和集合系统扩张；计算机断层成像（computed tomography，CT）横断面可用椎体、腰大肌、主动脉和下腔静脉定位肾门血管，再沿连续切层追踪输尿管。排泄期造影把肾盏—肾盂—输尿管—膀胱的腔隙连续性显示出来，而血管期影像用于辨认肾段和附加动脉。实质、集合系统和周围间隙应分层观察，以区分肾内尿路与肾实质。
