# 消化系统、呼吸系统与腹膜

内脏学首先处理的是连续性和毗邻关系。消化管从口腔延续到肛管，呼吸道从鼻腔延续到肺泡；肝、胰、唾液腺等实质器官虽不构成食物经过的管道，却以导管、血管和神经与消化管相连。胸膜与腹膜又把器官表面、体壁和潜在腔隙组织成可活动的空间。因而，学习内脏不能停留在器官名称上，而要同时回答四个问题：管腔通向哪里，壁由哪些层次组成，器官表面被何种浆膜覆盖，以及血管、神经和导管从何处进出。[^fipat-terminology]

本页沿着食物和空气的路径展开，重点放在正常成人的形态、位置、分部和相互关系。分泌、吸收、通气与气体交换的调节机制分别见[消化系统生理](../../physiology/digestive/index.md)和[呼吸生理](../../physiology/respiratory/index.md)。

## 内脏学的观察框架 { #viscera-framework }

“内脏”通常指胸腔、腹腔和盆腔内与消化、呼吸、泌尿和生殖有关的器官，但不同解剖传统对心、脾和内分泌腺是否纳入内脏学有不同处理。这个词适合表示一个教学范围，不宜据此推断器官的发生来源或功能类别。比分类更稳定的是结构观察：中空器官沿管腔追踪，实质器官沿表面、门和内部管道追踪，最后把它们放回胸腹腔的筋膜与浆膜关系中。

许多中空器官具有由内向外排列的黏膜、黏膜下层、肌层和外膜。黏膜通常由上皮、固有层和黏膜肌层组成；黏膜下层容纳较大的血管、淋巴管、神经和腺体；肌层推动或控制腔内容物；最外层若被脏层浆膜覆盖称浆膜，直接以结缔组织固定于周围结构时常称外膜。这个四层框架在消化管尤其清楚，但口腔、咽、胆囊、气管和膀胱等各有局部改造，不能把固定层数套用于所有中空器官。

实质器官没有一条贯穿全器官、用来容纳外界内容物的主腔，其内部仍可有导管、血窦、胆道或集合系统。器官表面的**门**是血管、神经、淋巴管和导管集中出入的区域，例如肝门与肺门；这些结构连同结缔组织共同形成器官根部。某些实质器官由反复出现的微小结构单位组成，可称小叶，但肝小叶、肺小叶和腺小叶的边界与功能并不相同。解剖标本上应把肉眼可见的叶、段和门，同组织学中的小叶和细胞排列区分开来。

## 消化管的连续结构 { #digestive-tract }

消化管依次为口腔、咽、食管、胃、小肠和大肠，肛管通向体表。牙、舌和唾液腺参与食物的机械处理与初步化学处理，肝、胆囊和胰把分泌物送入十二指肠。临床上“上消化道”和“下消化道”的界线随内镜、出血定位或胚胎血供的语境而变化；系统解剖更适合直接说出具体管段，而不把十二指肠—空肠交界当作唯一界线。

从食管向下，消化管壁大体遵循黏膜—黏膜下层—肌层—浆膜或外膜的顺序。黏膜上皮随局部任务改变：食管的复层扁平上皮抵抗摩擦，胃与肠的单层柱状上皮适合分泌和吸收。肌层通常有内环、外纵两层平滑肌，胃另有斜行肌束；上段食管含骨骼肌，下段以平滑肌为主。肌层之间的肌间神经丛和黏膜下神经丛构成肠神经系统的重要部分。不同管段还以皱襞、绒毛、腺体、括约肌和局部淋巴组织改变表面积与通行节律。[^openstax-digestive-overview]

消化管并非全部悬在腹膜腔内。食管主要位于纵隔，十二指肠大部、升结肠和降结肠在发育中贴附后腹壁成为继发性腹膜后器官；空肠、回肠和部分结肠由系膜悬系，既保留活动度，也获得血管、神经和淋巴通路。判断一段肠管的位置时，应把壁层结构与腹膜关系分开描述。

## 口腔、咽与食管 { #oral-pharynx-esophagus }

### 口腔、牙与舌 { #oral-cavity }

口腔由牙列和牙龈分成外侧的口腔前庭与内侧的固有口腔。前庭位于唇、颊与牙列之间；固有口腔的顶由前方硬腭和后方软腭构成，底部以口底肌群为支架并由舌占据大部分空间。闭口时两部分仍经最后磨牙后方相通。软腭后缘中央的腭垂以及两侧腭舌弓、腭咽弓围进口咽，腭扁桃体位于两弓之间的扁桃体窝。上唇正中的人中是面部表面标志，与口腔内部的功能分区不同。

乳牙通常为 20 颗，恒牙通常为 32 颗。恒牙由中线向后依次为切牙、尖牙、前磨牙和磨牙；乳牙列没有前磨牙。每颗牙分为暴露于口腔的牙冠、牙龈缘附近的牙颈和嵌入牙槽的牙根。釉质覆盖牙冠，牙本质构成牙体主体，牙骨质覆盖牙根，中央牙髓腔经根管与根尖孔相通。牙周组织由牙龈、牙周膜、牙槽骨和牙骨质共同构成，把牙固定在牙槽内并缓冲咬合力。不同牙位的牙根数存在常见模式和个体变异，辨认时应以具体牙位和影像为准，不把一个固定数值当作定义。[^openstax-mouth]

舌由彼此交织的骨骼肌构成。舌内肌改变舌的形状，舌外肌使舌整体前伸、后缩、抬高或下压。界沟把前方约三分之二的舌体与后方舌根分开，界沟顶端的舌盲孔是甲状舌管起始处的发生遗迹。舌背乳头具有不同形态；味蕾的分布跨越多类乳头和口咽黏膜，并不存在“一种基本味只占舌面一个固定区域”的严格味觉地图。舌下面的舌系带连接口底，舌动脉、舌下神经和舌神经等结构在舌及口底深部形成紧密的神经血管关系。

三对大唾液腺通过导管开口于口腔。腮腺位于耳前下方，腮腺管跨过咬肌后穿颊肌，通常开口于上颌第二磨牙相对处；下颌下腺环绕下颌舌骨肌后缘，其导管向前开口于舌系带两侧的舌下阜；舌下腺位于口底黏膜下，多条小导管沿舌下襞开口。唇、颊、腭和舌内还散布许多小唾液腺。各腺的浆液性与黏液性成分比例不同，不能把小唾液腺一概看作只分泌黏液的腺体。

### 咽与食管 { #pharynx-esophagus }

咽位于鼻腔、口腔和喉的后方，由颅底向下延续至食管。鼻咽只传导空气，借咽鼓管咽口与中耳相通；口咽位于软腭至会厌上缘之间，是空气与食团的共同通道；喉咽位于喉后方，下端延续为食管。咽缩肌由上而下重叠，在吞咽时依次收缩；茎突咽肌等纵行肌抬高咽。咽扁桃体、咽鼓管扁桃体、腭扁桃体和舌扁桃体围绕鼻咽与口咽入口形成黏膜相关淋巴组织环。舌根与会厌之间的会厌谷、喉口两侧的梨状隐窝都是内镜和异物定位时的重要凹陷。[^pharynx]

食管在环状软骨下缘附近接续咽，先位于气管后方，穿过上、后纵隔，再经膈的食管裂孔进入腹腔并接胃贲门。其通路受到咽食管交界、主动脉弓与左主支气管邻近处以及膈裂孔处的约束，内镜或吞咽影像可见相应狭窄；它们是相对关系，不是三只完全相同的固定“环”。食管上段肌层以骨骼肌为主，中段混合，下段以平滑肌为主。颈段和胸段大部外覆外膜，短腹段可有浆膜覆盖。食管下端的抗反流屏障由下食管括约肌功能区、膈脚、食管裂孔周围筋膜及胃食管交界形态共同形成，并非仅靠一个肉眼清楚的环形肌。

## 胃、小肠与大肠 { #stomach-intestines }

### 胃 { #stomach }

胃位于上腹部，以贲门接食管，以幽门接十二指肠。胃的前、后两面在右侧相交成胃小弯，在左下侧相交成胃大弯；贲门周围为贲门部，贲门切迹以上的穹隆为胃底，中央大部为胃体，远端依次为幽门窦、幽门管和幽门。幽门括约肌由环形肌增厚形成，在十二指肠球部前调节胃内容物排出。胃的形状和位置随充盈、呼吸、体位、年龄和体型而改变，“钩形、角形”等影像类型是常见形态描述，不是不可变的人体分类。

胃黏膜在空虚时形成皱襞，充盈后可展开；胃小弯附近的纵行皱襞可形成相对直接的液体通路。黏膜下层允许黏膜移动，肌层除内环、外纵外还有内斜肌束。胃前方邻近肝左叶、膈和前腹壁，后方隔小网膜囊与胰、脾、左肾和肾上腺等结构相邻，这组关系常称“胃床”。胃小弯连于小网膜，胃大弯连于大网膜及胃脾韧带；这些腹膜反折同时是血管抵达胃壁的路径。[^openstax-stomach]

### 小肠 { #small-intestine }

小肠分十二指肠、空肠和回肠。十二指肠围绕胰头形成 C 形，依次有上部、降部、水平部和升部。上部近幽门的一小段较活动，其余大部继发性固定于后腹壁。胆总管和主胰管通常共同或相邻开口于降部内侧壁的大十二指肠乳头；副胰管存在时可开口于其上方的小乳头。升部在十二指肠空肠曲转为空肠，十二指肠悬肌及其结缔组织束把这一交界联系到膈脚附近，是手术和影像定位的重要标志。

空肠和回肠由小肠系膜悬于后腹壁，二者之间没有清楚的外部界线。近端空肠常见管壁较厚、环状襞较高、系膜脂肪较少、动脉弓级数较少而直动脉较长；远端回肠常呈相反趋势，并在系膜缘对侧聚集较多回肠集合淋巴小结。所有这些都是逐渐变化的组合特征，单一特征不能独立决定管段。小肠黏膜以环状襞、绒毛和微绒毛增加吸收表面积，隐窝向黏膜深部延伸；其细胞生理见[消化与吸收](../../physiology/digestive/digestion_absorption.md)。

### 大肠、直肠与肛管 { #large-intestine }

回肠经回盲口进入盲肠。盲肠下方连有蚓状阑尾，三条结肠带在阑尾根部汇合，可辅助术中定位；阑尾长度和走向变异很大，可位于盲肠后、盆腔或回肠旁。阑尾壁富含淋巴组织，但阑尾炎是管腔阻塞、感染和局部炎症等多种因素共同作用的结果，不能简单归因为某一年龄段淋巴组织“过多”。

结肠依次为升结肠、横结肠、降结肠和乙状结肠。升、降结肠通常继发性贴附后腹壁，横结肠与乙状结肠具有系膜而较活动。结肠外表可见结肠带、结肠袋和肠脂垂：纵行肌集中为三条结肠带，管壁在其间膨出成结肠袋，浆膜下脂肪形成肠脂垂。结肠带在直肠上端扩散为连续纵肌层，直肠不再有典型结肠袋和肠脂垂。结肠管径总体由盲肠向远端趋小，却可受充盈和肌张力显著影响，不宜作为单独的管段判据。

直肠沿骶骨曲度下行，在穿过盆膈时转为肛管。矢状面上可辨骶曲和会阴曲，腔内还可见数条直肠横襞。肛管上段的纵行肛柱下端由肛瓣相连，其连线构成齿状线。齿状线上下分别主要来自后肠内胚层与肛凹外胚层，因而在上皮、感觉神经、动脉来源、静脉回流和淋巴引流上形成成套差异：线上方以自主性内脏感觉和直肠上血管系统为主，线下方以躯体感觉和阴部内血管系统为主。直肠上静脉汇入门静脉系统，直肠中、下静脉汇入体循环，两者在壁内形成门—体静脉吻合；这比“肛管静脉只属于某一个系统”的说法更准确。肛门内括约肌是环形平滑肌的延续，外括约肌为骨骼肌并与盆底肌协同维持控便。[^anal-canal]

## 肝、胆囊与胰 { #hepatobiliary-pancreas }

### 肝与肝门 { #liver }

肝是人体最大的腺体，大部分位于右季肋区和上腹部，紧贴膈下方并越过正中线进入左季肋区。膈面光滑隆起，借冠状韧带、三角韧带和镰状韧带等腹膜反折与膈及前腹壁相连；脏面朝向后下方，可见胃、十二指肠、结肠、右肾和右肾上腺等结构形成的压迹。冠状韧带两层之间的裸区没有腹膜覆盖，肝的其余大部分表面由脏腹膜覆盖。

肝的传统形态分叶以表面沟裂和镰状韧带为界，分为右叶、左叶，并在脏面辨认方叶与尾状叶。功能与外科分区则依据门静脉、肝动脉和胆管在肝内的分支以及肝静脉走行，把肝分为相对独立的门脉供血区域；这一分区与表面左右叶并不重合。进一步的 Couinaud 分段用肝静脉平面分隔相邻段，尾状叶常列为独立的第Ⅰ段。形态叶适合描述表面，功能段适合解释供血、胆汁引流和局部切除，两套名称应说明语境。[^liver-anatomy]

肝门位于脏面的横沟，门静脉和肝固有动脉在此进入，左右肝管在此汇出；三者连同淋巴管和神经走在肝十二指肠韧带内。肝静脉并不经过肝门，而是在肝后上方直接汇入下腔静脉。肝因此具有双重入流：门静脉携带来自消化管、脾和胰的血，肝动脉供应富氧血；二者在肝窦混合后经中央静脉、肝静脉流向下腔静脉。圆韧带是胎儿脐静脉的纤维遗迹，静脉韧带是静脉导管的遗迹，它们在肝脏面形成稳定的发生学标志。

### 胆道与胆囊 { #biliary-tree }

肝内小胆管逐级汇合为右、左肝管，二者组成肝总管。胆囊位于肝脏面的胆囊窝，分为底、体和颈；胆囊管与肝总管相接后形成胆总管。胆总管沿肝十二指肠韧带下行，经过十二指肠上部后方并邻近或穿过胰头，常与主胰管汇合成肝胰壶腹，开口于大十二指肠乳头。汇合形式和开口方式存在变异，胆道影像和手术辨认不能只依赖一张标准模式图。

胆囊黏膜形成分支状皱襞，缺少典型消化管的黏膜肌层和黏膜下层，肌层也不是规则的内环外纵排列。它储存并浓缩胆汁，再经胆囊管和胆总管排入十二指肠。胆汁形成、胆囊收缩和肠肝循环见[肝胆系统与代谢整合](../../physiology/digestive/hepatobiliary.md)。[^openstax-accessory-organs]

### 胰 { #pancreas }

胰横卧于胃后方，分为头、颈、体和尾，胰头下部向左伸出钩突。胰头嵌在十二指肠 C 形弯曲内，胆总管常在其后上方的沟内或穿过腺体；钩突绕到肠系膜上血管后方，胰颈位于门静脉汇合处前方，胰体跨过主动脉等后腹膜结构，胰尾沿脾肾韧带抵达脾门。头、颈和体主要位于腹膜后，尾部进入脾肾韧带内，因此“胰是腹膜后器官”描述总体关系时成立，观察局部仍要保留尾部的例外。[^pancreas-anatomy]

主胰管自尾向头贯穿腺体并接纳小导管，常与胆总管共同开口；副胰管的发育与开口存在变异。胰腺外分泌腺泡与导管构成消化液通路，内分泌胰岛散在实质中。这里的头尾分部、导管和血管毗邻属于肉眼解剖，消化酶分泌和胰岛激素调节分别在消化生理与内分泌页面展开。

## 呼吸道 { #respiratory-airway }

呼吸系统可按位置分为上、下呼吸道，也可按功能分为传导部与呼吸部。前一种划分的界线在不同教材中可置于喉或气管，后一种划分较稳定：鼻腔至终末细支气管负责传导、调温、湿化和清除颗粒，呼吸性细支气管、肺泡管、肺泡囊和肺泡构成发生气体交换的呼吸部。咽同时属于消化与呼吸通道，喉既保持气道通畅，也参与发声和吞咽保护。

### 鼻腔与鼻旁窦 { #nasal-cavity }

鼻腔由鼻中隔分为左右两半，前经鼻孔与外界相通，后经鼻后孔通向鼻咽。外侧壁的上、中、下鼻甲向内卷曲，其下方分别形成上、中、下鼻道；鼻甲增加黏膜表面积并使气流形成复杂路径。鼻前庭覆有皮肤和鼻毛，向后转为呼吸区黏膜；鼻腔顶部和上鼻甲附近为嗅区。鼻中隔前下部血管吻合丰富，是常见鼻出血部位。

额窦、上颌窦、筛窦和蝶窦是围绕鼻腔的含气腔。额窦、上颌窦和前、中筛窦多引流到中鼻道，后筛窦引流到上鼻道，蝶窦开口于蝶筛隐窝。窦口狭窄，黏膜肿胀可影响引流；上颌窦自然开口位于其内侧壁较高处，使直立位引流受窦口位置制约。鼻旁窦参与颅面骨的轻量化、声音共鸣和黏液纤毛清除，对吸入气体的处理是整个鼻腔—鼻咽系统共同完成的，不能归给某一个窦。

### 喉 { #larynx }

喉位于咽下部前方，上接舌骨和咽，下续气管。喉软骨支架包括不成对的甲状软骨、环状软骨和会厌软骨，以及成对的杓状、角状和楔状软骨。环状软骨是气道中唯一完整的软骨环；杓状软骨坐落在环状软骨板上，其转动和滑动改变声带突的位置。会厌在吞咽时随喉上提和舌根运动参与关闭喉口，但气道保护还依赖杓会厌襞、前庭襞、声襞和吞咽反射的协同，并非一块“盖子”独立完成。

喉腔从喉口延续到环状软骨下缘。前庭襞位于上方，声襞位于下方，两声襞之间为声门裂；声襞及声门裂合称声门。喉内肌均为骨骼肌，通过改变杓状软骨位置和声带张力控制声门，其中环杓后肌是使声襞外展的主要肌。除环甲肌由喉上神经外支支配外，多数喉内肌由喉返神经支配；喉返神经与甲状腺、气管食管沟和主动脉弓或锁骨下动脉的毗邻，使声音变化成为相关区域损伤的重要线索。[^larynx]

### 气管与支气管树 { #tracheobronchial-tree }

气管自环状软骨下缘向下进入胸腔，在隆嵴处分为左右主支气管。气管壁的 C 形透明软骨环在后方缺口处由气管肌和纤维弹性组织连接，既保持管腔开放，也让后方食管在吞咽时扩张。黏膜纤毛把黏液和被捕获的颗粒向咽部运送；越向远端，软骨由环变为不规则软骨板，至细支气管消失，平滑肌的相对作用增大。

右主支气管通常较短、较宽并更接近垂直方向，左主支气管较长并绕过心与主动脉相关结构。因此在许多成人体位下，吸入异物更常进入右侧，但落点还受年龄、体位、异物大小和吸气气流影响。主支气管进入肺门后分为叶支气管，再分为段支气管；此后反复分支为小支气管、细支气管和终末细支气管，进入呼吸性细支气管、肺泡管与肺泡囊。分支级次存在个体差异，解剖上的“树”是反复分叉的拓扑关系，而不是每个人都完全相同的编号图。[^respiratory-tract]

## 肺、胸膜与纵隔 { #lungs-pleura-mediastinum }

### 肺叶、肺门与肺段 { #lungs }

左右肺位于胸膜囊内，肺尖越过第一肋进入颈根部，肺底贴膈；肋面凸向胸壁，纵隔面容纳肺门，膈面随膈穹隆下凹。右肺由斜裂和水平裂分为上、中、下三叶，左肺由斜裂分为上、下两叶；左上叶前下部的舌叶与心切迹围绕心脏形成特征性轮廓。肺叶边界在深呼吸和病变时仍由裂的位置确定，裂发育不全或副裂属于常见变异。

肺门是纵隔面上各结构出入的区域，这些结构被胸膜包裹后共同组成肺根。肺根包括主支气管、肺动脉、上下肺静脉、支气管血管、淋巴管与淋巴结、自主神经纤维和结缔组织。肺动脉相对于主支气管通常在右侧偏前、左侧偏上，两条肺静脉多位于较前下方；实际标本应结合壁厚、管腔和分支方向辨认，而不是只背一个前后顺序。

每一叶支气管继续分为段支气管。由一个段支气管及伴行肺动脉分支供应、外形近似锥体的肺组织称支气管肺段，段间结缔组织中的肺静脉支流常标志相邻段的边界。右肺常描述为 10 段，左肺因部分段融合可记为 8—10 段。肺段具有相对独立的通气和动脉供应，是影像定位与局部切除的实用单位，但段间仍有静脉、淋巴与实质连续性，不能理解为完全隔绝的小肺。[^lungs]

肺循环由肺动脉把右心泵出的血送到肺泡毛细血管，再由肺静脉回到左心；支气管循环则由体循环动脉供应支气管壁、结缔组织和脏胸膜的一部分。两套血供在肺内存在吻合，部分支气管静脉血也可进入肺静脉。这种双重血供解释了肺根内同名“肺血管”和“支气管血管”承担不同任务，具体气体扩散与通气灌注关系见[肺通气与气体交换](../../physiology/respiratory/gas_exchange.md)。

胎儿肺浮沉试验曾利用含气肺组织在水中浮起的现象，推断新生儿是否呼吸过。它保留了肺泡充气会改变组织整体密度这一直观联系，却不能单独证明活产：复苏通气或腐败产气可造成假阳性，呼吸短暂、肺透明膜病、肺炎或充气不均可造成假阴性。现代法医学把它放在产科资料、全身尸检、组织学、微生物学和影像证据中综合解释。[^lung-float-test]

### 胸膜与胸膜隐窝 { #pleura }

脏胸膜紧贴肺表面并深入叶间裂，在肺门处反折为壁胸膜。壁胸膜依所贴结构分为肋胸膜、膈胸膜、纵隔胸膜和颈胸膜。两层之间的胸膜腔是含少量浆液的潜在腔隙，左右胸膜腔彼此分开；液体润滑使肺表面可随胸壁与膈运动。脏胸膜的感觉主要随自主神经，壁胸膜由肋间神经和膈神经提供躯体感觉，因此壁胸膜刺激通常定位更清楚。

壁胸膜在肋部转向膈部形成肋膈隐窝，在肋部转向纵隔部形成肋纵隔隐窝。安静呼吸时肺缘没有占满这些反折空间，深吸气时肺可进入隐窝，却通常仍不完全填满肋膈隐窝。肺根下方两层纵隔胸膜向下形成肺韧带，为肺根在呼吸与血管充盈时提供一定活动余地。胸膜反折、肺下缘和肋骨的体表投影并不重合，这是胸腔穿刺和影像判读必须同时考虑的层次关系。[^pleura-mediastinum]

### 纵隔 { #mediastinum }

纵隔是两侧纵隔胸膜之间的中央区域，上起胸廓上口，下至膈，前后位于胸骨与胸椎之间。经过胸骨角和第 T4—T5 椎间盘的水平面把它分为上纵隔和下纵隔；下纵隔再依心包的位置分为前、中、后纵隔。这些分区没有天然隔壁，却能稳定描述器官、筋膜间隙和病变扩展方向。

上纵隔容纳胸腺或其遗迹、头臂静脉和上腔静脉上段、主动脉弓及其分支、气管、食管、胸导管以及迷走神经、膈神经和左喉返神经等。中纵隔以心包、心和大血管根部为核心，并含膈神经及心包膈血管；前纵隔是胸骨与心包之间较窄的结缔组织区；后纵隔位于心包后、胸椎前，容纳胸主动脉、食管、胸导管、奇静脉系统、迷走神经干和内脏神经。纵隔结构按前后关系层叠，横断影像中应从胸骨、心包和椎体三个固定参照向内辨认。

## 腹膜与腹腔空间 { #peritoneum }

腹膜是连续的浆膜。壁腹膜衬覆腹盆壁内面，脏腹膜覆盖器官表面；两层相互反折，其间的腹膜腔只含少量润滑液。腹腔是膈以下、盆膈以上的整个解剖空间，内含腹膜腔、腹膜后间隙和器官本身，不能与腹膜腔互换。典型男性的腹膜腔为封闭腔；典型女性的腹膜腔可经输卵管、子宫和阴道与外界形成潜在交通，这是一项腔隙拓扑关系，并不改变本页的系统边界。[^peritoneum]

胃后方的腹膜腔称小网膜囊，其余大部分为大网膜囊，两者经网膜孔相通。网膜孔前界是含肝门静脉、肝固有动脉和胆总管的肝十二指肠韧带，后界为下腔静脉表面的腹膜，上界邻肝尾状叶，下界邻十二指肠上部。小网膜连接肝与胃小弯、十二指肠上部；大网膜自胃大弯下垂后折返并与横结肠及其系膜融合。系膜把肠管悬于体壁，腹膜韧带连接器官与器官或体壁；它们均由两层腹膜及其中的结缔组织构成，并为血管、神经和淋巴管提供通路。[^omental-foramen]

器官与腹膜的关系可按发生和活动度理解：

| 腹膜关系 | 结构特征 | 代表器官或管段 |
| --- | --- | --- |
| 腹膜内位 | 器官大部分由脏腹膜覆盖，并由系膜或韧带连接体壁或邻近器官 | 胃、空肠、回肠、盲肠与阑尾、横结肠、乙状结肠、脾；肝大部分亦被腹膜覆盖 |
| 继发性腹膜后位 | 胚胎早期曾有系膜，旋转和贴附后其系膜与后壁腹膜融合 | 十二指肠大部、胰的大部、升结肠和降结肠 |
| 原发性腹膜后位 | 自发生早期即位于壁腹膜后方 | 肾、肾上腺、输尿管、腹主动脉和下腔静脉等 |

“腹膜内位”不表示器官漂浮在空腔中，也不要求表面百分之百被覆；肝有裸区，卵巢表面也具有特殊覆盖。“腹膜后位”则描述器官位于壁腹膜之后，继发性腹膜后器官前面常仍有腹膜。旧式以“被腹膜覆盖三面或一面”判定位置的方法难以容纳发生和局部变异，系膜是否保留及器官与后腹壁的关系更有解释力。[^retroperitoneum]

腹膜反折还把液体可能流动的空间分成相互连通的区域。膈下间隙位于膈与肝之间，肝下间隙位于肝脏面下方；右肝肾隐窝在仰卧位处于较低位置。升、降结肠外侧的结肠旁沟沟通上腹和盆腔，肠系膜根及横结肠系膜又改变液体横向扩散路径。直立位液体可向盆腔最低处聚集。这样的空间地图用于解释腹腔积液、炎症和气体的分布，也提醒标本观察者：器官之间看似空白的间隙，实际由连续的浆膜反折和筋膜层界定。

## 从标本到断层影像 { #viscera-observation }

观察消化系统标本时，先沿口腔—咽—食管—胃—小肠—大肠确认管腔连续性，再寻找唾液腺、肝胆和胰的导管汇入点。随后比较各段壁厚、黏膜表面和浆膜覆盖，最后沿肠系膜与韧带追踪血管。观察呼吸系统时，先由鼻腔和喉进入气管，在隆嵴处分左右，再依主支气管、叶支气管和段支气管进入肺；肺门处同时分辨气道、肺动静脉和支气管血管。打开胸膜或腹膜前，应先在原位记录反折和隐窝，因为一旦切开并牵拉器官，原有空间关系很容易消失。

横断影像中，骨骼和大血管是稳定参照。胸部可先找椎体、胸骨、气管隆嵴、主动脉和心包，再辨肺门与纵隔分区；上腹部可先找脊柱、主动脉、下腔静脉和门静脉，再定位肝门、胰颈和肠系膜根。冠状面适合追踪膈、肺底、肝和结肠的上下关系，矢状面适合显示咽—喉、气管—食管以及直肠—肛管的前后曲度。把管腔连续、器官表面和固定参照结合起来，才能在标本、内镜和 CT 之间保持同一套三维解剖。
